# Lyra UI 目录总览（文件清单）

> **路径**：`Source/LyraGame/UI/`
>
> **一句话**：这是 Lyra 项目**自己**写的 UI 代码（🎭 本剧舞美组），全部**继承并使用 CommonUI**（🎛️ 舞台监督），CommonUI 又建在 UMG（🧱 木工坊）之上。三层关系见 [人物介绍/10_UI三层](../../人物介绍/10_UI三层_UMG_CommonUI_LyraUI人物谱.md)。
>
> **目录组织逻辑**：根目录放"UI 框架基类 + 全局控件"，子目录按**功能场景**分类（基础控件 / 通用控件 / 底层弹窗 / 大厅 / 指示器 / 性能 / 子系统 / 武器）。

---

## 一、整体结构（8 个子目录 + 根目录）

```
UI/
├─ 【根目录】框架基类 + 全局控件（10 个类）
├─ Basic/            基础控件（进度条）
├─ Common/           通用控件（按钮/列表/页签/工厂）
├─ Foundation/       底层弹窗（确认框/断连屏/加载屏）
├─ Frontend/         大厅/主菜单（前端流程）
├─ IndicatorSystem/  头顶指示器（血条/名字/3D→2D投影）
├─ PerformanceStats/ 性能调试显示（FPS/内存）
├─ Subsystem/        UI 子系统（管理器/消息弹窗）
└─ Weapons/          武器 UI（准星/命中标记）
```

---

## 二、根目录：框架基类 + 全局控件

> 这一层是"骨架"——其他子目录的控件都继承自这里的基类。

| 文件 | 继承自 | 干什么 |
|------|--------|--------|
| `LyraActivatableWidget` | `UCommonActivatableWidget` | **所有可激活 UI 的本剧基类**。比 CommonUI 多一个 `ELyraWidgetInputMode`（声明这块板子激活时按键要不要穿透给游戏）+ 鼠标捕获模式。 |
| `LyraHUDLayout` | `ULyraActivatableWidget` | **HUD 布局壳**。玩家血条/弹药等的主布局。绑 `UI.Action.Escape` 弹暂停菜单；监听手柄断连弹"请重连"提示。 |
| `LyraTaggedWidget` | `UCommonUserWidget` | **按标签控制显隐的控件**。玩家身上带某 GameplayTag 时自动隐藏（如"隐藏准星""隐藏队友标记"）。 |
| `LyraSimulatedInputWidget` | `UCommonUserWidget` | **模拟输入的控件基类**。把触摸/点击转成 Enhanced Input 的按键注入给玩家（触屏模拟手柄摇杆用）。 |
| `LyraJoystickWidget` | `ULyraSimulatedInputWidget` | **虚拟摇杆**。触屏上算出 -1~1 的 2D 向量，模拟手柄左摇杆移动。 |
| `LyraTouchRegion` | `ULyraSimulatedInputWidget` | **触摸区域**。手指按屏幕某区域触发一个输入（触屏自定义按键）。 |
| `LyraSettingScreen` | `UGameSettingScreen` | **设置界面基类**。绑定"返回/应用/取消"三个输入动作，创建设置项注册表。 |
| `LyraGameViewportClient` | `UGameViewportClient` | **视口客户端**。初始化时按平台决定用硬件光标还是软件光标（主机/手机用软件光标）。 |
| `LyraHUD` | `AHUD` | **HUD Actor**。实际**主要给 debug 渲染用**；真正加 UI 靠 GameFeatureAction_AddWidget，而非改这个类。 |

## 三、子目录详解

### 📁 Basic/ — 基础控件

| 文件 | 干什么 |
|------|--------|
| `MaterialProgressBar` | 用材质做的**进度条/血条**。支持材质驱动（如渐变、流光效果），比引擎自带 ProgressBar 更灵活。 |

### 📁 Common/ — 通用控件（跨场景复用）

| 文件 | 干什么 |
|------|--------|
| `LyraBoundActionButton` | **会随输入设备换皮肤的按钮**。手柄→GamepadStyle（显示"按 A"）、触摸→TouchStyle、键鼠→KeyboardStyle（显示"点击"）。 |
| `LyraListView` | **列表控件**（继承 CommonUI 的 `UCommonListView`），带按钮式导航的列表。 |
| `LyraTabButtonBase` | **页签按钮基类**。顶部/侧边切换栏里的单个页签按钮。 |
| `LyraTabListWidgetBase` | **页签列表容器**。管理一组页签按钮的切换逻辑（设置界面顶部标签栏就用它）。 |
| `LyraWidgetFactory` | **控件工厂（抽象）**。按类型创建控件的接口。 |
| `LyraWidgetFactory_Class` | **按类创建的工厂实现**。配一个 `TSubclassOf` 就能造出对应控件。 |

### 📁 Foundation/ — 底层弹窗（全局通用对话框）

| 文件 | 干什么 |
|------|--------|
| `LyraButtonBase` | **按钮基类**。全项目按钮的共同父类，统一样式/行为。 |
| `LyraActionWidget` | **动作控件**。绑定一个 UI 动作（如"确认/取消"）触发逻辑的通用控件。 |
| `LyraConfirmationScreen` | **确认弹窗**。"确定要这么做吗？"式的模态对话框。 |
| `LyraControllerDisconnectedScreen` | **手柄断连提示屏**。玩家手柄断开时弹出，提示重新连接。 |
| `LyraLoadingScreenSubsystem` | **加载屏子系统**。管理加载界面的显示（配合 LoadingScreen 流程）。 |

### 📁 Frontend/ — 大厅 / 主菜单（前端）

| 文件 | 干什么 |
|------|--------|
| `LyraFrontendStateComponent` | **大厅流程调度组件**（挂在 GameState 上）。用 `FControlFlow` 串起"按开始→用户登录→加入会话→显示主菜单"整条前端流程。 |
| `LyraLobbyBackground` | **大厅背景**。主菜单的背景画面/视频控件。 |
| `ApplyFrontendPerfSettingsAction` | **前端性能设置动作**。进大厅时应用一套性能档位（降低画质保帧率）。 |

### 📁 IndicatorSystem/ — 头顶指示器系统（3D→2D 投影）

> 用途：把 3D 世界里的角色/物体，投影到 2D 屏幕上显示头顶标记（血条、名字、任务箭头）。

| 文件 | 干什么 |
|------|--------|
| `IActorIndicatorWidget` | **指示器控件接口**。头顶标记控件要实现它，才能"绑定"到指示器数据。 |
| `IndicatorDescriptor` | **指示器描述符**（核心数据对象）。记录指示器绑哪个组件/插槽、用什么控件类、投影模式、对齐、是否贴边、优先级、世界/屏幕偏移等。 |
| `IndicatorLayer` | **指示器层**。管理一层指示器的容器。 |
| `IndicatorLibrary` | **指示器蓝图函数库**。给蓝图用的便捷函数（创建/移除指示器）。 |
| `LyraIndicatorManagerComponent` | **指示器管理组件**。挂在 Actor 上，统一管理它身上所有指示器。 |
| `SActorCanvas` | **Actor 画布（Slate 底层）**。真正做 3D→2D 投影计算 + 绘制指示器的底层 Slate 控件。 |

### 📁 PerformanceStats/ — 性能调试显示

| 文件 | 干什么 |
|------|--------|
| `LyraPerfStatWidgetBase` | **性能统计控件基类**。显示单项性能数据（如 FPS、帧时间、内存）。 |
| `LyraPerfStatContainerBase` | **性能统计容器**。装一组性能控件的容器（如把 FPS/GPU/内存摆一起）。 |

### 📁 Subsystem/ — UI 子系统

| 文件 | 继承自 | 干什么 |
|------|--------|--------|
| `LyraUIManagerSubsystem` | `UGameUIManagerSubsystem` | **UI 管理子系统**。每帧同步根布局的显隐与 HUD 状态（如隐藏 HUD 时一起隐藏 UI）。 |
| `LyraUIMessaging` | `UCommonMessagingSubsystem` | **统一消息弹窗子系统**。覆写 `ShowConfirmation`/`ShowError`，把确认框/错误框推进 `UI.Layer.Modal` 模态层。 |

### 📁 Weapons/ — 武器 UI（准星 / 命中标记）

| 文件 | 干什么 |
|------|--------|
| `LyraReticleWidgetBase` | **准星基类**。武器瞄准准星的共同父类。 |
| `LyraWeaponUserInterface` | **武器 UI 容器**。装准星等武器相关控件的容器。 |
| `CircumferenceMarkerWidget` | **环形标记控件**（UMG 层）。准星周围那圈散布标记。 |
| `SCircumferenceMarkerWidget` | 环形标记的 **Slate 底层实现**（S 前缀 = Slate 原生控件）。 |
| `HitMarkerConfirmationWidget` | **命中确认标记**（UMG 层）。打中敌人时准星上弹出的"命中"提示。 |
| `SHitMarkerConfirmationWidget` | 命中确认标记的 **Slate 底层实现**。 |

## 四、命名规律速记

| 前缀/后缀 | 含义 |
|-----------|------|
| `ULyra...Widget` | 普通 UMG 控件（继承 `UCommonUserWidget` / `ULyraActivatableWidget`） |
| `ULyra...Subsystem` | 子系统（全局单例服务，如消息/管理） |
| `ULyra...Component` | Actor 组件（挂 Actor 上，如指示器管理/前端流程） |
| `ULyra...Screen` | 一整块屏幕（确认屏/设置屏/断连屏） |
| `S...Widget`（S 开头） | **Slate 底层原生控件**，比 UMG 更底层、性能更高（准星/命中标记用） |
| `I...Widget`（I 开头） | **接口**（Indicator 指示器接口） |

---

## 五、一句话总结

- **根目录** = UI 骨架（基类 + 全局控件 + 触摸模拟输入）
- **Basic/Common/Foundation** = 通用积木（进度条/按钮/列表/页签/弹窗）
- **Frontend** = 大厅主菜单流程
- **IndicatorSystem** = 头顶血条/名字（3D→2D 投影）
- **PerformanceStats** = 性能调试显示
- **Subsystem** = UI 全局服务（管理/消息）
- **Weapons** = 准星 + 命中标记（含 Slate 底层 S 控件）

> 全部继承/使用 CommonUI，最终建在 UMG 之上。要理解"为什么这么分层"，回看 [人物介绍/10_UI三层](../../人物介绍/10_UI三层_UMG_CommonUI_LyraUI人物谱.md)。

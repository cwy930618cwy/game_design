## 四、注释规范（唯一允许的「不一比一」）

| 项 | 规则 |
|---|---|
| 语言 | **全中文**。Lyra 原有英文注释逐条翻译，不保留英文原文 |
| **位置（★ 血泪）** | **注释独占一行，写在被注释代码的正上方**。缩进与下一行代码对齐 |
| 密度 | 每行代码上方至少一行中文注释；复杂表达式可在行尾补一句 |
| 位置（结构体级） | 类 / 结构体 / 枚举 / 每个方法 / 每个 `UPROPERTY` / 每个成员变量**正上方**必须有中文注释 |
| 不翻译 | `TEXT("...")` 字符串、`UE_LOG` 消息、`[Obsolete("...")]`、宏名、类名、函数名、`FName` 字面量 |
| 禁止 | **行尾注释**（`"FileVersion": 3, // 注释`）、行内教学提示（`// ← 改成XXX`）、空注释占位、`TODO 以后补` |

**正确写法**：

```jsonc
// .uproject 格式版本号；UE5 固定写 3，写错引擎不认
"FileVersion": 3,
// 绑定本机注册的 UE 5.4；双击工程时引擎按这个版本启动
"EngineAssociation": "5.4",
```

**错误写法（一律返工）**：

```jsonc
"FileVersion": 3,                    // ← 错：注释在行尾
"EngineAssociation": "5.4",          // ← 错：注释在行尾
```

## 五、讲义格式（每个文件两件套，平铺在阶段目录）

```
<讲义根>\<阶段号>_<阶段名>\
├─ NN_<文件名>_总md.md          ← ① 总 md（3~5KB / 85 行内）
└─ NN_<文件名>复制文件.md        ← ② 完整代码 + 每行上方中文注释（用户照抄）
```

> ⚠️ **只有两件，没有第三件**。**AI 绝不往 `<工程根>` 里写任何代码文件** —— 代码由用户自己敲。
> ⚠️ **不建 `答疑文件\` 子目录**。两件套全部平铺在阶段目录下。

**① 总 md 骨架**：

```markdown
# NN — `<相对路径>/<文件名>` —— 总 md

> 依据：`<源根>\Source\LyraGame\<相对路径>\<文件名>`（**N 行**）
> 你新建文件：`<工程根>\Source\LyraGame\<相对路径>\<文件名>`
> **✅ 本节可独立编译** / **⚠️ 本节不能独立编译**——依赖 xxx

## 一、这个文件解决什么问题（为什么）
   —— 场景 + 核心设计 ①②③ + 🔑 一句话比喻

## 二、内部结构全景
   —— 树形图（├─ └─），把成员/方法全列出来 + 行号区间

## 三、依赖分析
   —— 表格：文件 | 依赖工程内类？ | 能否独立编译 | 需挂起？
   —— 关键依赖表：文件 | 作用

## 四、怎么教（推进节奏）
   —— 本轮三件套说明

**下一步**：下一个是 xxx
```

**② 复制文件 md 骨架**：

```markdown
# NN — `<文件名>` 复制文件

> 依据：`<源根>\...`（**N 行**）
> 你新建文件：`<工程根>\...`
> **用法**：照着下面代码逐行敲。**注释在每行上方，敲的时候整行 `//` 注释都不要抄**。

```<语言>
// 中文注释（独占一行，在被注释代码正上方）
<代码行>
// 中文注释
<代码行>
```

## 敲完自查
| 检查项 | 通过标准 |

## 源码依据
```

> ⚠️ **复制文件里必须包含完整代码**（不许切片、不许省略），注释**逐行写在代码上方**。

## 六、推进节奏（★ 一次只教一个文件）

1. 我按 `01_复刻路线总纲.md` 的顺序，**一轮只发一份讲义 = 只讲一个文件**。
2. 发完就**停**，等用户敲完说「下一步」。
3. 收到「下一步」→ 先验收上一份（剔除注释后逐字比对代码行），通过才发下一份。
4. 一个阶段全部敲完 → 我发该阶段的「编译里程碑检查单」。
5. **禁止**：一次连发多份讲义、一次讲多个文件、提前把后面几轮的讲义都写出来。
6. **不跳文件、不合并文件、不提前发下一个阶段的讲义。**
7. **禁止往工程里写代码** —— 用户说「教学只教 我来写」，代码必须用户自己敲。

## 七、验收标准（每次「下一步」必做）

| 检查项 | 通过标准 |
|---|---|
| 路径 / 文件名 | 与 Lyra 同名同层级 |
| 代码行 | 复制文件 md 里的代码剔除注释后**逐字一致**（`codeOurs == codeEngine`，`diff == 0`） |
| 注释 | 全中文，无英文残留，无教学噪声 |
| **注释位置** | **全部在代码行上方**，零行尾注释 |
| 完整性 | 一比一贴全，无 `TODO`、无省略 |
| **AI 未越界** | **AI 没有往 `<工程根>` 写任何代码文件** |

> 比对脚本必须按文件类型剔注释：`.h/.cpp` 剔 `//` + `/* */`；`.cs` 剔 `//`；`.xml` 剔 `<!-- -->`；`.json` 直接比。

## 八、踩坑清单（2026-11-20 血泪，务必避开）

| # | 坑 | 后果 | 正确做法 |
|---|---|---|---|
| 1 | **AI 代写代码文件**（★ 最严重） | 用户说「教学只教 我来写」，代写 = 剥夺用户练习机会，用户暴怒 | **只产出 md 讲义，绝不往工程里写代码** |
| 2 | **一次连发多份讲义** | 用户没法逐个敲，节奏全乱 | 一轮只做一个文件，发完就停 |
| 3 | **注释写在代码行尾** | 用户看不懂、复制后要手工挪 | 注释**独占一行**，写在代码**正上方** |
| 4 | **代码切片分段** | 用户没法整块复制 | 复制文件里必须是**完整代码**，不许省略 |
| 5 | **建 `答疑文件\` 子目录** | 用户找不到文件 | 两件套**平铺**在阶段目录下 |
| 6 | **JSON 里写 `//` 注释** | 引擎解析失败 | 复制文件用 `jsonc` 代码块，并注明「敲的时候删掉注释」 |
| 7 | **只写总 md 就停** | 用户拿不到代码 | 两件套同一轮全部产出 |
| 8 | **凭记忆写代码** | 与 Lyra 不一致 | 每次先 `read_file` 源文件，再写讲义 |
| 9 | **`diff > 0` 直接报未通过** | 假报警（块注释被当代码行） | 先打印前 8 条差异确认，再下结论 |
| 10 | **英文注释没译完** | 违反「英文注释一律改中文」 | 交付前扫一遍，`//` 后无中文的行逐条处理（被注释掉的代码除外） |

> **改动文件**：无（纯规范课）
> **前置**：00.2 编译与运行
> ✅ 本课结束：你知道新建一个类该放哪个目录、叫什么名字。

## 一、为什么先定规范（场景 + 类比）

UE 的 C++ 有个硬约束：**`#include` 的路径必须能被编译器找到**。

如果你把文件乱放，会出现：

```
error : Cannot open include file: 'MyActor.h'
```

或者更隐蔽的：

```
error : Unrecognized type 'AMyActor'
```

**根因**：UE 默认只把**模块根目录**（`Source\texiaoue54\`）加入头文件搜索路径。子目录里的文件，`#include` 时必须带相对路径。

> 🔑 **类比**：`Source\texiaoue54\` 是「小区」，子目录是「楼栋」。
> 快递（`#include`）只写「张三」找不到人，必须写「3 号楼 张三」。

## 二、本教程的目录规范

```
Source\texiaoue54\
├── texiaoue54.Build.cs
├── texiaoue54.cpp
├── texiaoue54.h
│
├── 01_Actor\              ← 阶段 1：第一个 Actor
│   ├── MyFirstActor.h
│   └── MyFirstActor.cpp
│
├── 02_Blueprint\          ← 阶段 2：蓝图协作
├── 03_Input\              ← 阶段 3：输入与控制
├── 04_Character\          ← 阶段 4：角色
├── 05_UI\                 ← 阶段 5：UI
├── 06_Data\               ← 阶段 6：数据驱动
├── 07_GAS\                ← 阶段 7：GAS
└── 08_Core\               ← 阶段 8：收口
```

**规则**：
1. **一个阶段一个目录**，目录名 = `NN_英文名`。
2. **一个类一对文件**：`类名.h` + `类名.cpp`（纯头文件类只有 `.h`）。
3. **文件名 = 类名去掉前缀**：`AMyFirstActor` → `MyFirstActor.h`。

> ⚠️ **UE 硬规则**：`#include "XXX.generated.h"` 里的 `XXX` **必须**与 `.h` 文件名完全一致（不含路径）。所以文件名不能随便起。

## 三、`#include` 怎么写（关键）

### 3.1 同目录引用

```cpp
// 在 01_Actor\MyFirstActor.cpp 里引用同目录的 .h
#include "MyFirstActor.h"
```

✅ 直接写文件名即可（同目录优先）。

---

### 3.2 跨目录引用

```cpp
// 在 03_Input\MyPawn.cpp 里引用 01_Actor\MyFirstActor.h
#include "01_Actor/MyFirstActor.h"
```

✅ 从**模块根目录**（`Source\texiaoue54\`）开始写相对路径。

❌ 不要写 `#include "../01_Actor/MyFirstActor.h"` —— UE 的包含路径机制不认 `..`。

---

### 3.3 引用引擎头文件

```cpp
#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "Components/StaticMeshComponent.h"
```

✅ 引擎头文件直接写引擎内的相对路径（引擎已把 `Engine\Source\Runtime\` 等加入搜索路径）。

## 四、要不要分 `Public` / `Private`？

**本教程：不分。**

| 方案 | 适用场景 | 本教程 |
|---|---|---|
| 扁平（所有文件在模块根 + 子目录） | 单模块、文件 < 100 个 | ✅ **用这个** |
| `Public/` + `Private/` | 多模块、要给别的模块暴露头文件 | ❌ 不用 |

**为什么不分**：
- 分 `Public/Private` 需要在 `Build.cs` 里加 `PublicIncludePaths` / `PrivateIncludePaths`，多一层配置。
- 单模块工程，所有代码都在一个模块里，没有"对外暴露"的需求。
- 文件少的时候，扁平结构更好找。

> 💡 如果以后文件超过 100 个想重构，再分也不迟。

## 五、命名规范（UE 官方约定）

| 类型 | 前缀 | 例子 |
|---|---|---|
| `UObject` 派生类 | `U` | `UMyComponent` |
| `AActor` 派生类 | `A` | `AMyFirstActor` |
| `SWidget`（Slate） | `S` | `SMyWidget` |
| 结构体（`USTRUCT`） | `F` | `FMyStruct` |
| 接口（`UINTERFACE`） | `I` + `U` | `IMyInterface` / `UMyInterface` |
| 枚举（`UENUM`） | `E` | `EMyState` |
| 模板类 | `T` | `TMyArray` |
| 布尔变量 | `b` | `bIsActive` |

**本段新元素**
- `U` 前缀 —— `UObject` 派生类（组件、子系统、数据资产） —— UE 官方命名规范
- `A` 前缀 —— `AActor` 派生类（能放进关卡的东西） —— UE 官方命名规范
- `F` 前缀 —— 普通结构体 / 非 UObject 类 —— UE 官方命名规范
- `b` 前缀 —— 布尔变量 —— UE 官方命名规范

**这段在干什么**

| 前缀 | 决定什么 |
|---|---|
| `U` / `A` / `F` | 决定这个类**能不能被 GC 管理**、**能不能放进关卡** |
| `b` | 只是可读性约定，不影响编译 |

> 类比：前缀 = 身份证上的「类别」。`A` 是「能站在场景里的实体」，`U` 是「挂在实体上的零件」，`F` 是「纯数据」。

## 六、文件内容模板（后面每课都按这个）

### 6.1 `.h` 模板

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "MyFirstActor.generated.h"

UCLASS()
class TEXIAOUE54_API AMyFirstActor : public AActor
{
	GENERATED_BODY()

public:
	AMyFirstActor();

protected:
	virtual void BeginPlay() override;

public:
	virtual void Tick(float DeltaTime) override;
};
```

**关键点**：
- `#pragma once` —— 防重复包含
- `#include "XXX.generated.h"` —— **必须是最后一个 include**，且文件名与 `.h` 一致
- `TEXIAOUE54_API` —— 模块导出宏（模块名全大写 + `_API`）
- `GENERATED_BODY()` —— UHT 必需

---

### 6.2 `.cpp` 模板

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

#include "MyFirstActor.h"

AMyFirstActor::AMyFirstActor()
{
	PrimaryActorTick.bCanEverTick = true;
}

void AMyFirstActor::BeginPlay()
{
	Super::BeginPlay();
}

void AMyFirstActor::Tick(float DeltaTime)
{
	Super::Tick(DeltaTime);
}
```

**关键点**：
- 第一行 `#include "自己的.h"` —— **必须第一行**（UE 的 IWYU 规则）
- 构造函数里设 `PrimaryActorTick.bCanEverTick`
- 每个 override 都要调 `Super::`

## 八、常见报错

| 症状 | 原因 | 改法 |
|---|---|---|
| `Cannot open include file: 'MyFirstActor.h'` | 跨目录引用没写路径 | 改成 `#include "01_Actor/MyFirstActor.h"` |
| `Unable to find 'XXX.generated.h'` | `.h` 文件名和 `#include` 里的名字不一致 | 两者必须完全一致 |
| `Unrecognized type 'AMyFirstActor'` | 没 `#include` 对应头文件 | 补 include |
| `TEXIAOUE54_API` 报未定义 | 模块名拼错 | 必须是 `模块名全大写_API` |
| 编译报 `generated.h` 必须在最后 | include 顺序错 | 把 `XXX.generated.h` 移到所有 include 之后 |

## 九、本课新元素汇总

| 元素 | 一句话 | 出处 |
|---|---|---|
| `#pragma once` | 防重复包含 | C++ 标准 |
| `XXX.generated.h` | UHT 生成的头，必须最后 include | UE 规范 |
| `TEXIAOUE54_API` | 模块导出宏 | `texiaoue54.Build.cs:5`（模块名） |
| `GENERATED_BODY()` | UHT 必需宏 | UE 规范 |
| `U` / `A` / `F` / `b` 前缀 | 类型命名约定 | UE 官方规范 |
| `PrimaryActorTick.bCanEverTick` | 是否启用 Tick | `AActor` 成员 |

# Q04c — 第 02 课 · 第 2 步【核心疑问】：空构造函数 `UTenkaichiAttributeSet::UTenkaichiAttributeSet(){}` 写它干嘛？不写不也能 NewObject？

> **所属章节**：第 02 课 · 第 2 步【2/4】建基类 `TenkaichiAttributeSet.cpp`
>
> **对应 Lyra**：`LyraAttributeSet.cpp:12-14`（Lyra 基类构造函数也是空的）
>
> **一句话**：你说得对——**这个空构造函数不写，程序照样能 `NewObject`、照样能跑**。它不是功能必需的。写它纯粹是"代码风格 / 明确意图 / 给子类打样"。真正有内容、真正有意义的构造函数是**子类**那个（写 `Health(100.0f)` 的）。

---

## 一、你的疑问（原话，非常尖锐，而且是对的）

```cpp
UTenkaichiAttributeSet::UTenkaichiAttributeSet()
{
}
```
> "不写我也能 NewObject，那这代码意义在哪？为什么写它？"

**先给你吃个定心丸**：你的判断 **100% 正确**。这个空构造函数**删掉，工程照样编译、照样能 `NewObject` 造对象**。它不是"为了让 NewObject 能工作"才写的。

---

## 二、不写会怎样？（验证你的判断）

C++ 有个规则：**如果你不写任何构造函数，编译器会自动帮你生成一个"默认构造函数"**（什么都不做，但存在）。

所以：

| 情况 | 能不能编译 | 能不能 NewObject |
|------|-----------|-----------------|
| 写了空构造函数 `UTenkaichiAttributeSet() {}` | ✅ 能 | ✅ 能 |
| **完全不写**（让编译器自动生成默认的） | ✅ 能 | ✅ 能 |

**两种情况效果完全一样。** 所以你说"不写也能 NewObject"——**对，没毛病**。这个构造函数不是为了"让 NewObject 能用"而存在的。

---

## 三、那为什么还要写它？（4 个真实理由，都不是"功能必需"）

既然不写也能跑，为什么 Lyra 和我们还要写这个空壳？——纯粹是**工程习惯**，不是技术必需：

### 理由 1：明确意图（告诉读代码的人"这个类有构造函数"）

空构造函数像一张**名片**——它明确告诉看代码的人："这个类是被设计成'有构造逻辑'的类。"

> 如果不写，别人看头文件不知道有没有构造函数，得去猜。写了，一眼就知道"有，而且是空的（基类不需要初始化任何东西）"。

### 理由 2：给子类打样（最重要的理由）★

基类写一个空构造函数，是在**做示范、占位置**：

> "子类注意——**你们的构造函数要写在这里、照着这个格式写**，把你们的属性初值（比如 `Health(100.0f)`）写进去。"

真正"设置属性初值"的活，是**子类**干的（见第四节）。基类这个空壳，就是给子类指了个位置："构造逻辑写这儿。"

### 理由 3：预留扩展点（将来基类可能要用）

现在基类没属性要初始化，所以空。**但将来**如果基类要加一个"所有属性集共用的初始化"（比如注册到某个系统），直接往这个壳里加就行，不用临时补。

### 理由 4：Lyra 的代码风格（Epic 的规范）

Lyra 里**几乎所有类都显式写构造函数**，哪怕空。这是 Epic 的代码规范——"构造函数显式写出来，别靠编译器自动生成"。我们一比一还原 Lyra，所以也这么写。

---

## 四、重点：真正有意义的构造函数是"子类"那个 ★

基类这个空，**真正干活的是子类的构造函数**。看 Lyra 真实的子类 `LyraHealthSet`：

```cpp
// LyraHealthSet.cpp 第 21-28 行（子类构造函数，这个才有内容！）
ULyraHealthSet::ULyraHealthSet()
	: Health(100.0f)       // ← 真正设置血量初值 = 100
	, MaxHealth(100.0f)    // ← 最大血量初值 = 100
{
	bOutOfHealth = false;
	...
}
```

**对比一下**：

| 构造函数 | 内容 | 有没有实际意义 |
|---------|------|--------------|
| 基类 `UTenkaichiAttributeSet()` | 空 `{}` | ❌ 功能上可有可无（风格/打样） |
| 子类 `UTenkaichiHealthSet()` | `Health(100.0f)` | ✅ **必须有**——不写，血量就没有初始值 |

> **结论**：你纠结的"空构造函数意义在哪"——**它确实没实质功能意义，是风格 + 打样**。真正不能省、真正干活的，是**子类的构造函数**（设 `Health` 初值那个）。等我们第 3 步写血量集，你就能看到那个"有意义的构造函数"长什么样。

---

## 五、一句话结论

**你说得对：这个空基类构造函数不写也能 `NewObject`、也能跑——它不是功能必需的。写它只是 4 个非功能理由：①明确意图②给子类打样（最重要）③预留扩展④Lyra 风格。真正有内容、真正必须写的构造函数是子类的（`Health(100.0f)` 设初值那个），那才是"属性集构造函数"存在的真正意义。**

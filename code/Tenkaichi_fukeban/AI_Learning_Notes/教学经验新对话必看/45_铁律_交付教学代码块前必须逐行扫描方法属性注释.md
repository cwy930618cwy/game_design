## 二、核心规则（强制动作，不再软提醒）

**交付任何教学代码块前，强制执行以下动作，缺一不可：**

1. **写完代码块后，从第一行数到最后一个 `}`。**
2. **每遇到一个方法/构造函数**：检查上方是否有 `// 中文注释` 或 `/** 中文 */`，讲清"这方法干嘛、何时被调用"。没有就立刻补。
3. **每遇到一个 UPROPERTY / 成员变量**：检查上方（或行尾）是否有 `// 中文注释` 说明含义。没有就立刻补。
4. **构造函数最容易漏**，每次第一个检查它。
5. **`.h` 和 `.cpp` 两处都要补扫**，同一方法两处注释意思一致（铁律 32/43）。
6. **代码块 = 交付物**。讲解段落、表格、正文只是辅助，**绝不能替代代码块里的注释**。

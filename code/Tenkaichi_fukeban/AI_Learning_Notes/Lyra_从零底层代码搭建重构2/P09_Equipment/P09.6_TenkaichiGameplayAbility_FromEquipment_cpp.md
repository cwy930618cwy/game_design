### 2. `GetAssociatedEquipment`（追溯装备，核心）

```cpp
UTenkaichiEquipmentInstance* UTenkaichiGameplayAbility_FromEquipment::GetAssociatedEquipment() const
{
	if (FGameplayAbilitySpec* Spec = UGameplayAbility::GetCurrentAbilitySpec())
	{
		return Cast<UTenkaichiEquipmentInstance>(Spec->SourceObject.Get());
	}
	return nullptr;
}
```

- `UGameplayAbility::GetCurrentAbilitySpec()`：拿到**当前正在运行的技能描述符**（引擎提供）。
- `Spec->SourceObject`：技能描述符里存的"来源对象"。装备授予技能时（P09.3 `GiveToAbilitySystem(..., Result)`）把装备实例 `Result` 存成了 `SourceObject`。
- `Cast<UTenkaichiEquipmentInstance>(...)`：把来源对象转回装备实例。
- 这就是"技能追溯装备"的关键——**通过 SourceObject 关联**。

> 关联建立（P09.3）：`AbilitySet->GiveToAbilitySystem(ASC, &GrantedHandles, Result)` → 装备实例 `Result` 成为技能的 SourceObject。
> 关联读取（本方法）：技能运行时 `GetCurrentAbilitySpec()->SourceObject` → 拿回装备实例。

### 3. `GetAssociatedItem`（追溯物品）

```cpp
UTenkaichiInventoryItemInstance* UTenkaichiGameplayAbility_FromEquipment::GetAssociatedItem() const
{
	if (UTenkaichiEquipmentInstance* Equipment = GetAssociatedEquipment())
	{
		return Cast<UTenkaichiInventoryItemInstance>(Equipment->GetInstigator());
	}
	return nullptr;
}
```

- 先拿到关联装备，再 `Equipment->GetInstigator()`（P09.2 里记录的"穿戴者"）。
- 在 P09.5 快捷栏里，`EquippedItem->SetInstigator(SlotItem)` 把**物品实例**设成了装备的 Instigator。所以这里 `GetInstigator()` 拿到的就是物品实例。
- 链条：技能 → 装备（SourceObject）→ 物品（Instigator）。

> 三层追溯：技能通过 `SourceObject` 找到装备，装备通过 `Instigator` 找到物品。

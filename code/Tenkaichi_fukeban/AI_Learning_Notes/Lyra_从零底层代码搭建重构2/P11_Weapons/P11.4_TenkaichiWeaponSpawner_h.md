## 一、本文件要解决什么

定义"武器生成器"这个场景类：继承 `AActor`，在地图上摆一把悬浮旋转的枪，玩家走近自动拾取，捡走后冷却重生。`.h` 里声明了：
- 3 个子组件（碰撞范围 / 底座 / 枪模型）
- 数据配置 `WeaponDefinition`（指向 P09.4 的拾取配置）
- 网络同步标志 `bIsWeaponAvailable`（复制 + OnRep）
- 拾取/重生/特效等一堆方法（含 2 个蓝图可覆盖的 NativeEvent）

> ✅ **本 `.h` 零挂起点**：只依赖引擎 `AActor`/`UCapsuleComponent` + P09.4 `UTenkaichiPickupDefinition`，可直接编译。

## 二、完整代码（`.h`，已替换前缀 + 注释中文化）

```cpp
// 版权声明（Lyra 项目自带，保留）
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "GameFramework/Actor.h"

#include "TenkaichiWeaponSpawner.generated.h"

#define UE_API TENKAICHIGAME_API

namespace EEndPlayReason { enum Type : int; }

class APawn;
class UCapsuleComponent;
class UTenkaichiInventoryItemDefinition;
class UTenkaichiWeaponPickupDefinition;
class UObject;
class UPrimitiveComponent;
class UStaticMeshComponent;
class FFrame;
struct FGameplayTag;
struct FHitResult;

UCLASS(MinimalAPI, Blueprintable,BlueprintType)
class ATenkaichiWeaponSpawner : public AActor
{
	GENERATED_BODY()
	
public:	
	// 设置这个 Actor 的默认属性
	UE_API ATenkaichiWeaponSpawner();

protected:
	// 游戏开始或生成时调用：校验武器配置，把冷却时间套到配置上
	UE_API virtual void BeginPlay() override;
	// 游戏结束或销毁时调用：清掉所有计时器，防止悬空引用
	UE_API virtual void EndPlay(const EEndPlayReason::Type EndPlayReason) override;

public:	
	// 每一帧调用：更新重生倒计时进度条 + 让武器模型持续旋转
	UE_API virtual void Tick(float DeltaTime) override;

	// 编辑器里摆放/修改参数时实时预览武器外观（设计师所见即所得）
	UE_API void OnConstruction(const FTransform& Transform) override;

protected:
	// 用来配置武器生成器的数据资产
	UPROPERTY(EditInstanceOnly, BlueprintReadOnly, Category = "Lyra|WeaponPickup")
	TObjectPtr<UTenkaichiWeaponPickupDefinition> WeaponDefinition;

	UPROPERTY(EditDefaultsOnly, BlueprintReadWrite, ReplicatedUsing = OnRep_WeaponAvailability, Category = "Lyra|WeaponPickup")
	bool bIsWeaponAvailable;

	// 从武器被捡到重新生成之间隔的时间（秒）
	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Lyra|WeaponPickup")
	float CoolDownTime;

	// 武器重新可用后，延迟检测"是否有人正站在刷新点上"的时间。
	// 用来给 bIsWeaponAvailable 的 OnRep 留出触发时间，先播完特效再检测。
	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Lyra|WeaponPickup")
	float CheckExistingOverlapDelay;

	// 用来驱动"武器重生倒计时"显示条（0~1）
	UPROPERTY(BlueprintReadOnly, Transient, Category = "Lyra|WeaponPickup")
	float CoolDownPercentage;

public:

	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Lyra|WeaponPickup")
	TObjectPtr<UCapsuleComponent> CollisionVolume;

	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Lyra|WeaponPickup")
	TObjectPtr<UStaticMeshComponent> PadMesh;

	UPROPERTY(BlueprintReadOnly, Category = "Lyra|WeaponPickup")
	TObjectPtr<UStaticMeshComponent> WeaponMesh;

	UPROPERTY(EditDefaultsOnly, BlueprintReadWrite, Category = "Lyra|WeaponPickup")
	float WeaponMeshRotationSpeed;

	FTimerHandle CoolDownTimerHandle;

	FTimerHandle CheckOverlapsDelayTimerHandle;

	// 进入刷新点的碰撞回调：玩家走进来就尝试把武器交给他（只有服务器执行）
	UFUNCTION()
	UE_API void OnOverlapBegin(UPrimitiveComponent* OverlappedComponent, AActor* OtherActor, UPrimitiveComponent* OtherComp, int32 OtherBodyIndex, bool bFromSweep, const FHitResult& SweepHitResult);

	// 枪重新生成时，检测是否有人正站在刷新点上
	UE_API void CheckForExistingOverlaps();

	// 尝试把武器发给目标玩家：成功就隐藏武器 + 播拾取特效 + 开始冷却重生
	UFUNCTION(BlueprintNativeEvent)
	UE_API void AttemptPickUpWeapon(APawn* Pawn);

	// 真正把武器"塞给"玩家背包/装备（纯蓝图实现，走 P08/P09 的拾取逻辑）
	UFUNCTION(BlueprintImplementableEvent, Category = "Lyra|WeaponPickup")
	UE_API bool GiveWeapon(TSubclassOf<UTenkaichiInventoryItemDefinition> WeaponItemClass, APawn* ReceivingPawn);

	// 开启冷却重生倒计时
	UE_API void StartCoolDown();

	// 冷却结束：重置为"可捡"，重新显示武器 + 播重生特效 + 延迟检测脚下是否有人
	UFUNCTION(BlueprintCallable, Category = "Lyra|WeaponPickup")
	UE_API void ResetCoolDown();

	// 冷却计时到点的回调：调用 ResetCoolDown 进入重生流程
	UFUNCTION()
	UE_API void OnCoolDownTimerComplete();

	// 显示或隐藏武器模型（捡走时隐藏，重生时显示）
	UE_API void SetWeaponPickupVisibility(bool bShouldBeVisible);

	// 播放"武器被捡走"的音效 + 特效（Niagara，蓝图可覆盖）
	UFUNCTION(BlueprintNativeEvent, Category = "Lyra|WeaponPickup")
	UE_API void PlayPickupEffects();

	// 播放"武器重新出现"的音效 + 特效（Niagara，蓝图可覆盖）
	UFUNCTION(BlueprintNativeEvent, Category = "Lyra|WeaponPickup")
	UE_API void PlayRespawnEffects();

	// 服务器同步"武器可捡状态"变化时回调：可捡→播重生特效；不可捡→隐藏 + 播拾取特效
	UFUNCTION()
	UE_API void OnRep_WeaponAvailability();

	/** 在某个物品定义类型里查找匹配的属性并返回它的值，找不到就返回 0 */
	UFUNCTION(BlueprintCallable, BlueprintPure, Category = "Lyra|WeaponPickup")
	static UE_API int32 GetDefaultStatFromItemDef(const TSubclassOf<UTenkaichiInventoryItemDefinition> WeaponItemClass, FGameplayTag StatTag);
};

#undef UE_API
```

> 与 Lyra 原文件只差前缀：`ALyraWeaponSpawner`→`ATenkaichiWeaponSpawner`、`ULyraWeaponPickupDefinition`→`UTenkaichiWeaponPickupDefinition`、`ULyraInventoryItemDefinition`→`UTenkaichiInventoryItemDefinition`、`LYRAGAME_API`→`TENKAICHIGAME_API`、`LyraWeaponSpawner.generated.h`→`TenkaichiWeaponSpawner.generated.h`。代码块里已是替换后的最终版，直接照抄即可。

## 三、逐段讲解

### 1. include 与宏

```cpp
#include "GameFramework/Actor.h"
#include "TenkaichiWeaponSpawner.generated.h"

#define UE_API TENKAICHIGAME_API
...
#undef UE_API
```

- `GameFramework/Actor.h`：父类 `AActor`（场景对象）。
- `TenkaichiWeaponSpawner.generated.h`：UHT 生成的反射代码头，必须最后 include。
- `UE_API TENKAICHIGAME_API`：模块导出宏，让类跨模块可见（P11 里每个类都这么用）。

### 2. 前置声明

```cpp
namespace EEndPlayReason { enum Type : int; }

class APawn;
class UCapsuleComponent;
class UTenkaichiInventoryItemDefinition;
class UTenkaichiWeaponPickupDefinition;
class UObject;
class UPrimitiveComponent;
class UStaticMeshComponent;
class FFrame;
struct FGameplayTag;
struct FHitResult;
```

- 全部是**前置声明**（`.h` 里只出现指针/引用，不需要完整定义），编译更快、避免循环 include。
- `EEndPlayReason` 是引擎枚举，`EndPlay` 参数要用。

### 3. 类声明

```cpp
UCLASS(MinimalAPI, Blueprintable, BlueprintType)
class ATenkaichiWeaponSpawner : public AActor
```

- `MinimalAPI`：只导出部分 API（配 `UE_API`）。
- `Blueprintable`：允许被蓝图继承/放置（设计师能在场景里放）。
- `BlueprintType`：允许蓝图把该类型当变量/参数类型（比如蓝图函数参数传"武器生成器"）。
- 继承 `AActor`：普通场景对象，不依赖 Controller/Pawn。

### 4. 生命周期 + 编辑器回调

```cpp
UE_API ATenkaichiWeaponSpawner();
UE_API virtual void BeginPlay() override;
UE_API virtual void EndPlay(const EEndPlayReason::Type EndPlayReason) override;
UE_API virtual void Tick(float DeltaTime) override;
UE_API void OnConstruction(const FTransform& Transform) override;
```

- 构造函数：搭子组件、设默认值（`CollisionTime=30` 等）。
- `BeginPlay`/`EndPlay`：配置冷却、清理计时器。
- `Tick`：每帧驱动重生进度条 + 枪旋转。
- `OnConstruction`：编辑器里放枪时实时预览外观（设计师福音）。

### 5. 数据配置

```cpp
UPROPERTY(EditInstanceOnly, BlueprintReadOnly, Category = "Lyra|WeaponPickup")
TObjectPtr<UTenkaichiWeaponPickupDefinition> WeaponDefinition;
```

- `EditInstanceOnly`：只能在场景实例上编辑（不放蓝图类里），因为每个刷新点配不同的枪。
- 指向 P09.4 的 `UTenkaichiWeaponPickupDefinition`（含枪模、音效、冷却时间）。

```cpp
UPROPERTY(EditDefaultsOnly, BlueprintReadWrite, ReplicatedUsing = OnRep_WeaponAvailability, Category = "Lyra|WeaponPickup")
bool bIsWeaponAvailable;
```

- `ReplicatedUsing = OnRep_...`：属性复制，变化时调 `OnRep_WeaponAvailability` 客户端回调（播特效）。
- `EditDefaultsOnly`：默认值在类默认里配（初始都是"可捡"）。

```cpp
UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Lyra|WeaponPickup")
float CoolDownTime;
// 重生倒计时（秒），默认 30，可在配置里覆盖
UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Lyra|WeaponPickup")
float CheckExistingOverlapDelay;
// 重生后延迟检测"是否有人站着"，默认 0.25 秒
UPROPERTY(BlueprintReadOnly, Transient, Category = "Lyra|WeaponPickup")
float CoolDownPercentage;
// 重生进度 0~1，每帧更新，UI 进度条直接绑定
```

### 6. 子组件

```cpp
UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Lyra|WeaponPickup")
TObjectPtr<UCapsuleComponent> CollisionVolume;
// 碰撞范围（根组件），玩家走进就触发

// 底座（地面圆盘）
```

- `PadMesh`/`WeaponMesh` 都是 `UStaticMeshComponent`（静态网格，不带骨骼）。

### 6. 计时器句柄

```cpp
FTimerHandle CoolDownTimerHandle;
FTimerHandle CheckOverlapsDelayTimerHandle;
```

- 两个纯 C++ 句柄（非反射，不设 `UPROPERTY` 也行，但设了更利于调试可见）。Lyra 源码里没加 `UPROPERTY`。

### 7. 核心方法

```cpp
UFUNCTION()
UE_API void OnOverlapBegin(UPrimitiveComponent* OverlappedComponent, AActor* OtherActor, UPrimitiveComponent* OtherComp, int32 OtherBodyIndex, bool bFromSweep, const FHitResult& SweepHitResult);
```

- `UFUNCTION()` 空参数标记 = **动态委托签名**，能绑到组件碰撞事件 `OnComponentBeginOverlap`。

```cpp
UE_API void CheckForExistingOverlaps();
// 重生后调用：取所有重叠的 Pawn，逐个尝试给枪
```

```cpp
UFUNCTION(BlueprintNativeEvent)
UE_API void AttemptPickUpWeapon(APawn* Pawn);
```

- `BlueprintNativeEvent`：C++ 写默认实现，蓝图能**覆盖**。`.cpp` 里实现 `AttemptPickUpWeapon_Implementation`。

```cpp
UFUNCTION(BlueprintImplementableEvent, Category = "Lyra|WeaponPickup")
UE_API bool GiveWeapon(TSubclassOf<UTenkaichiInventoryItemDefinition> WeaponItemClass, APawn* ReceivingPawn);
```

- `BlueprintImplementableEvent`：**纯蓝图实现**，C++ 只声明不给实现。把枪真正发给玩家的逻辑放在蓝图（调 P09 的装备/拾取）。
- 返回 `bool` 表示"是否成功给了"。

```cpp
UE_API void StartCoolDown();
UFUNCTION(BlueprintCallable, Category = "Lyra|WeaponPickup")
UE_API void ResetCoolDown();
UFUNCTION()
UE_API void OnCoolDownTimerComplete();
```

- 冷却三件套：开始（设定时器）→ 到时回调 → 重置（清定时器 + 重新显示枪 + 延迟检测）。

```cpp
UE_API void SetWeaponPickupVisibility(bool bShouldBeVisible);
// 显示/隐藏枪
UFUNCTION(BlueprintNativeEvent, Category = "Lyra|WeaponPickup")
UE_API void PlayPickupEffects();
UFUNCTION(BlueprintNativeEvent, Category = "Lyra|WeaponPickup")
UE_API void PlayRespawnEffects();
// 拾取/重生的音效+特效（C++ 默认播 Sound+Niagara，蓝图可覆盖）
```

```cpp
UFUNCTION()
UE_API void OnRep_WeaponAvailability();
// 客户端收到复制时触发：可用→重生特效；不可用→隐藏+拾取特效
```

### 8. 静态工具

```cpp
UFUNCTION(BlueprintCallable, BlueprintPure, Category = "Lyra|WeaponPickup")
static UE_API int32 GetDefaultStatFromItemDef(const TSubclassOf<UTenkaichiInventoryItemDefinition> WeaponItemClass, FGameplayTag StatTag);
```

> **说明**：Lyra 源码里这个静态函数的函数名是 `GetDefaultStatFromItemDef`（以 `Def` 结尾）。功能：从一个物品定义类型里，按 `StatTag` 查属性值（通过 `UInventoryFragment_SetStats`），找不到返回 0。

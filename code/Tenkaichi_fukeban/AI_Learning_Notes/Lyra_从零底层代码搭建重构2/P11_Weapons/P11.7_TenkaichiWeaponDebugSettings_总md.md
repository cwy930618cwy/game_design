## 一、这是什么？解决什么问题？

**一句话**：给"武器调试"提供 3 个开关——要不要画子弹轨迹？画多久？命中点画多大？

前面 P11.5 教了开枪技能（射线追踪 + 命中）。调试武器时，你**看不到子弹飞过**，很难判断：
- 射线有没有打偏？
- 命中了哪个点？
- 散布对不对？

`UTenkaichiWeaponDebugSettings` 就是给这些调试提供**可视化开关**：
- 打开"画子弹轨迹"→ 屏幕上画一条线显示子弹飞行路径。
- 打开"画命中点"→ 在命中位置画一个圆点。
- 设置持续时间 / 半径大小。

它是**引擎提供的配置机制** `UDeveloperSettingsBackedByCVars` 的一个实现：
- 在**编辑器里**以"项目设置"面板形式配置（图形化，不用改代码）。
- 配置值自动同步到**控制台变量（CVar）**，运行时可以用控制台命令实时开关。

## 二、为什么这么写？

整个类就 **3 个属性 + 1 个构造函数 + 1 个 `GetCategoryName`**，核心是 3 个 float：

```cpp
UPROPERTY(config, EditAnywhere, Category=General, meta=(ConsoleVariable="lyra.Weapon.DrawBulletTraceDuration", ForceUnits=s))
float DrawBulletTraceDuration;

UPROPERTY(config, EditAnywhere, Category = General, meta = (ConsoleVariable = "lyra.Weapon.DrawBulletHitDuration", ForceUnits = s))
float DrawBulletHitDuration;

UPROPERTY(config, EditAnywhere, Category = General, meta = (ConsoleVariable = "lyra.Weapon.DrawBulletHitRadius", ForceUnits=cm))
float DrawBulletHitRadius;
```

**逐项拆解：**

| 属性 | 类型 | 作用 |
|------|------|------|
| `DrawBulletTraceDuration` | float | 子弹轨迹画多久（秒）。>0 才画轨迹 |
| `DrawBulletHitDuration` | float | 命中点画多久（秒）。>0 才画命中点 |
| `DrawBulletHitRadius` | float | 命中点圆的半径（厘米） |

**3 个关键词 `meta` 各有什么意义：**
- `ConsoleVariable="lyra.Weapon.DrawBulletTraceDuration"` → 让这个属性自动绑定到同名控制台变量（CV）。**改配置 = 改 CV，运行时可用控制台命令 `lyra.Weapon.DrawBulletTraceDuration 2` 实时改。**
- `ForceUnits=s` → 编辑器里显示"秒"单位。
- `ForceUnits=cm` → 编辑器里显示"厘米"单位。

**为什么用 `UDeveloperSettingsBackedByCVars` 基类（而不是普通 UObject）？**
- 它自动把"配置面板 + 控制台变量 + 运行时读取"三者绑定，开发者只需声明属性，不用写任何读写逻辑。
- 这是引擎的"配置驱动调试"标准做法，Lyra 在 `LyraDeveloperSettings` 等地方也这么用。

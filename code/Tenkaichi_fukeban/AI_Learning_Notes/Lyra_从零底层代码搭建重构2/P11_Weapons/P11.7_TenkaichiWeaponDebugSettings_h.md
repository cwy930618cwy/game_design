## 一、完整代码（`.h`，已替换前缀 + 注释中文化 + 零教学提示）

```cpp
// 版权声明（Lyra 项目自带，保留）
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "Engine/DeveloperSettingsBackedByCVars.h"

#include "TenkaichiWeaponDebugSettings.generated.h"

class UObject;

/**
 * 武器调试设置（开发用）
 */
UCLASS(config=EditorPerProjectUserSettings)
class UTenkaichiWeaponDebugSettings : public UDeveloperSettingsBackedByCVars
{
	GENERATED_BODY()

public:
	UTenkaichiWeaponDebugSettings();

	//~UDevelopmentSettings 接口开始
	virtual FName GetCategoryName() const override;
	//~UDevelopmentSettings 接口结束

public:
	// 是否绘制子弹轨迹调试（如果大于 0，则设置绘制时长（秒））
	UPROPERTY(config, EditAnywhere, Category=General, meta=(ConsoleVariable="tenkaichi.Weapon.DrawBulletTraceDuration", ForceUnits=s))
	float DrawBulletTraceDuration;

	// 是否绘制子弹命中点调试（如果大于 0，则设置绘制时长（秒））
	UPROPERTY(config, EditAnywhere, Category = General, meta = (ConsoleVariable = "tenkaichi.Weapon.DrawBulletHitDuration", ForceUnits = s))
	float DrawBulletHitDuration;

	// 启用子弹命中点调试绘制时（见 DrawBulletHitDuration），命中点圆的半径大小？（单位：厘米）
	UPROPERTY(config, EditAnywhere, Category = General, meta = (ConsoleVariable = "tenkaichi.Weapon.DrawBulletHitRadius", ForceUnits = cm))
	float DrawBulletHitRadius;
};
```

## 二、逐行讲解

### 1. 头文件依赖

```cpp
#include "Engine/DeveloperSettingsBackedByCVars.h"
#include "TenkaichiWeaponDebugSettings.generated.h"
```

| 头文件 | 提供什么 |
|--------|---------|
| `Engine/DevelopmentSettingsBackedByCVars.h` | 引擎基类 `UDevelopmentSettingsBackedByCVars`（自动绑定配置项 + 控制台变量） |
| `TenkaichiWeaponDebugSettings.generated.h` | UHT 自动生成的反射代码（每个 UCLASS 都要 include） |

> **为什么这个类用引擎头文件？**
> - `UDevelopmentSettingsBackedByCVars` 是引擎自带类，不需要项目自己实现。
> - 它让"编辑器项目设置面板"和"运行时控制台变量"自动同步——改配置 = 改 CV，不用写任何读写代码。

### 2. 前置声明

```cpp
class UObject;
```

- 前置声明引擎 `UObject`（其实这个头文件里没直接用 `UObject` 指针成员，但 Lyra 原版保留了这行，保持一致）。

### 3. 类声明

```cpp
UCLASS(config=EditorPerProjectUserSettings)
class UTenkaichiWeaponDebugSettings : public UDevelopmentSettingsBackedByCVars
{
	GENERATED_BODY()
```

| 部分 | 含义 |
|------|------|
| `UCLASS(config=EditorPerProjectUserSettings)` | 配置项**存到 `EditorPerProjectUserSettings.ini`**（每个项目/每台电脑各自保存，不改团队的默认配置） |
| `class UTenkaichiWeaponDebugSettings` | 类名，`UTenkaichi` 前缀（Lyra 换前缀） |
| `: public UDevelopmentSettingsBackedByCVars` | 继承引擎配置基类 |
| `GENERATED_BODY()` | UHT 宏，必须有 |

### 4. 构造函数声明

```cpp
UTenkaichiWeaponDebugSettings();
```

- 构造函数在 `.cpp` 里定义（空实现）。类实例化时会先跑它。

### 5. 接口重写声明

```cpp
//~UDevelopmentSettings 接口开始
virtual FName GetCategoryName() const override;
//~UDevelopmentSettings 接口结束
```

- `GetCategoryName()` —— 返回这个配置在"项目设置"里显示的**分组名**。
- `.cpp` 里返回 `FApp::GetProjectName()`（当前项目名），这样配置会显示在"项目设置 → 项目名"分组下。
- `//~Xxx 接口开始/结束` —— Lyra 的分隔注释，标记接口实现范围。

### 6. 三个调试属性

```cpp
// 是否绘制子弹轨迹调试绘制（如果大于 0，则设置绘制时长（秒））
UPROPERTY(config, EditAnywhere, Category=General, meta=(ConsoleVariable="tenkaichi.Weapon.DrawBulletTraceDuration", ForceUnits=s))
float DrawBulletTraceDuration;

// 是否绘制子弹命中点调试（如果大于 0，则设置绘制时长（秒））
UPROPERTY(config, EditAnywhere, Category = General, meta = (ConsoleVariable = "tenkaichi.Weapon.DrawBulletHitDuration", ForceUnits = s))
float DrawBulletHitDuration;

// 启用子弹命中点调试绘制时（见 DrawBulletHitDuration），命中点圆的半径大小？（单位：厘米）
UPROPERTY(config, EditAnywhere, Category = General, meta = (ConsoleVariable = "tenkaichi.Weapon.DrawBulletHitRadius", ForceUnits = cm))
float DrawBulletHitRadius;
```

**逐项拆解：**

| 属性 | 类型 | 默认值 | 作用 |
|------|------|--------|------|
| `DrawBulletTraceDuration` | float | 0（不画） | 子弹轨迹画多久（秒）。>0 才画轨迹 |
| `DrawBulletHitDuration` | float | 0（不画） | 命中点画多久（秒）。>0 才画命中点 |
| `DrawBulletHitRadius` | float | 0 | 命中点圆的半径（厘米） |

**`UPROPERTY` 参数：**
| 参数 | 含义 |
|------|------|
| `config` | 配置项——从 `.ini` 读取，编辑器里可改 |
| `EditAnywhere` | 编辑器任何地方可编辑 |
| `Category=General` | 在"项目设置"里归到"General"分组 |

**`meta` 参数：**
| 参数 | 含义 |
|------|------|
| `ConsoleVariable="tenkaichi.Weapon.DrawBulletTraceDuration"` | 绑定到同名控制台变量。运行时控制台敲 `tenkaichi.Weapon.DrawBulletTraceDuration 2` 就能实时改 |
| `ForceUnits=s` / `ForceUnits=cm` | 编辑器里显示单位（秒 / 厘米） |

> ⚠️ **注意**：CV 名从 Lyra 的 `lyra.Weapon.` 换成了 `tenkaichi.Weapon.`（按铁律 24 只换前缀）。

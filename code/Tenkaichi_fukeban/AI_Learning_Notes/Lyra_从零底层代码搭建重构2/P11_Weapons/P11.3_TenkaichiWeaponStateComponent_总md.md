## 一、这个类解决什么问题

P11.2 讲了"远程武器怎么算准"（散布/热量/衰减）。但**子弹打中人之后，怎么让玩家看到"我打中了"？**

`UTenkaichiWeaponStateComponent` 就是**武器状态组件**：它挂在**控制器（Controller）**上，负责两件核心事：

1. **驱动武器更新**：每帧找到玩家手上那件远程武器，调用它的 `Tick()`（让热量/散布持续演化）。
2. **命中反馈（准星提示）**：服务器确认"你打中谁了"后，把命中位置换算成**屏幕坐标**，推给客户端显示准星红点/白点（命中标记）。

> 一句话：**P11.2 是"枪"，P11.3 是"枪打到哪、玩家怎么看"的反馈中枢。**

## 二、全景：这个类里有什么

### 两个结构体（定义在同名 `.h` 里）

| 结构体 | 作用 |
|--------|------|
| `FTenkaichiScreenSpaceHitLocation` | 一次命中：屏幕坐标 + 命中部位标签 + 是否算"成功命中" |
| `FTenkaichiServerSideHitMarkerBatch` | 一"批"命中标记（服务器确认后批量下发），带唯一 `UniqueId` 用于对账 |

### 组件核心成员

| 成员 | 类型 | 作用 |
|------|------|------|
| 构造函数 | — | 开启复制、开启 Tick |
| `TickComponent()` | 覆写 | 每帧：找手上远程武器 → 调它的 `Tick(DeltaTime)` |
| `ClientConfirmTargetData()` | Client RPC | 服务器把"命中批次"结果推给客户端（成功/失败 + 需替换的命中点） |
| `AddUnconfirmedServerSideHitMarkers()` | 方法 | 本地记录一批"待确认"命中标记（含屏幕坐标 + 命中部位） |
| `UpdateDamageInstigatedTime()` | 方法 | 更新"最近一次打出伤害"的时间戳 |
| `GetLastWeaponDamageScreenLocations()` | 查询 | 返回最近一次成功命中的屏幕坐标列表（给准星 UI 用） |
| `GetTimeSinceLastHitNotification()` | 查询 | 距最近一次命中提示过了多久 |
| `GetUnconfirmedServerSideHitCount()` | 查询 | 有多少"待确认"命中标记 |

### 私有状态
| 成员 | 类型 | 作用 |
|------|------|------|
| `LastWeaponDamageInstigatedTime` | double | 最近一次打出伤害时刻 |
| `LastWeaponDamageScreenLocations` | TArray | 已确认的成功命中屏幕坐标（给 UI 画准星点） |
| `UnconfirmedServerSideHitMarkers` | TArray | 待服务器确认的命中批次队列 |

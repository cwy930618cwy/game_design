## 一、本文件要解决什么

定义"武器实例"这个类：继承 `UTenkaichiEquipmentInstance`（P09），补上**武器专属的记录**——开火时间、上次装备时间、装备/卸下时的动画层选择集、手柄震动属性。核心方法：`OnEquipped`/`OnUnequipped`（记录时间 + 应用震动）、`UpdateFiringTime`（开火时记录）、`GetTimeSinceLastInteractedWith`（距上次开火/装备多久）。

> ⚠️ **本 `.h` 的挂起点（铁律 33/34）**：`FTenkaichiAnimLayerSelectionSet`（P17 Cosmetics）作为**成员变量的类型，需要完整定义**，其 include 文件 `Cosmetics/TenkaichiCosmeticAnimationTypes.h` 尚未建立 → **这 3 处（include + 2 个成员变量）必须 `#if 0` 注释挂起**，否则编译不过。`PickBestAnimLayer` 的声明因依赖这两个成员类型，也一并挂起。已登记注释备忘录 **㉜**。

## 三、逐段讲解

### 1. include 与宏

```cpp
#include "Equipment/TenkaichiEquipmentInstance.h"
#include "GameFramework/InputDevicePropertyHandle.h"
```

- `Equipment/TenkaichiEquipmentInstance.h`：父类 `UTenkaichiEquipmentInstance`（P09 ✅）。
- `GameFramework/InputDevicePropertyHandle.h`：`FInputDevicePropertyHandle`（手柄震动句柄，引擎）。

> ⚠️ **挂起**：`Cosmetics/TenkaichiCosmeticAnimationTypes.h`（`FTenkaichiAnimLayerSelectionSet` 的定义处）P17 未建，include 已注释挂起。

```cpp
#define UE_API TENKAICHIGAME_API
...
#undef UE_API
```

- `UE_API` 宏：给类/方法标记导出宏（模块外部可见）。`TENKAICHIGAME_API` 在模块入口声明。`#define`（顶部）和 `#undef`（底部）成对出现。

### 2. 类标记

```cpp
UCLASS(MinimalAPI)
class UTenkaichiWeaponInstance : public UTenkaichiEquipmentInstance
```

- `MinimalAPI`：只导出部分 API（配合 `UE_API` 逐个标记方法），相比 `UCLASS()` 更省。
- 继承 `UTenkaichiEquipmentInstance`（P09）——武器是装备的子类。

### 3. 构造函数

### 5. 开火时间记录


### 7. 手柄震动（核心逻辑）

```cpp
UPROPERTY(EditDefaultsOnly, Instanced, BlueprintReadOnly, Category = "Input Devices")
TArray<TObjectPtr<UInputDeviceProperty>> ApplicableDeviceProperties;
```

- `ApplicableDeviceProperties`：装备期间要应用的手柄震动属性数组。
- `Instanced`：每个实例独立一份（蓝图可逐项配置）。
- `EditDefaultsOnly`：只能在类默认值编辑。

```cpp
// 返回拥有者 Pawn 的平台用户 ID（用于手柄震动）
UFUNCTION(BlueprintCallable)
UE_API const FPlatformUserId GetOwningUserId() const;

// 拥有者死亡时的回调：移除所有已生效的手柄震动
UFUNCTION()
UE_API void OnDeathStarted(AActor* OwningActor);

// 把 ApplicableDeviceProperties 应用到拥有者 Pawn 上（循环播放，生命周期跟随武器装备期间）
UE_API void ApplyDeviceProperties();

// 移除 ApplyDeviceProperties 里激活的所有手柄震动属性
UE_API void RemoveDeviceProperties();
```

- `GetOwningUserId`：返回拥有者 Pawn 的 `FPlatformUserId`（找不到返回 `PLATFORMUSERID_NONE`）。
- `OnDeathStarted`：`UFUNCTION()` 无参标记 → 可作动态委托回调。宿主死亡时调用，防止震动残留。
- `ApplyDeviceProperties` / `RemoveDeviceProperties`：应用/移除震动。`Apply` 循环播放（`Params.bLooping = true`），句柄存 `DevicePropertyHandles`，`Remove` 时按句柄移除。

### 8. 私有字段

```cpp
// 本武器激活的手柄震动句柄集合（由 ApplyDeviceProperties 填充）
UPROPERTY(Transient)

// 上次装备时间
double TimeLastEquipped = 0.0;
// 上次开火时间
double TimeLastFired = 0.0;
```

- `DevicePropertyHandles`：`Transient`（不序列化）——震动句柄是运行时数据，存盘无意义。
- `TimeLastEquipped` / `TimeLastFired`：记录时间（double 世界时间）。

## 一、本文件要解决什么

这个 `.h` 声明了"开枪技能"的**骨架**。它不是一个场景对象（不是 Actor/Component），而是一个 **GAS 技能**（继承 P09 的 `UGameplayAbility_FromEquipment`）。

它声明的东西：
1. **一个枚举** `ETenkaichiAbilityTargetingSource`：6 种"从哪瞄准、朝哪打"的模式。
2. **一个内部结构体** `FRangedWeaponFiringInput`：一次开火的输入参数包（射线起点/终点/方向/武器）。
3. **一组技能生命周期方法**：`CanActivateAbility` / `ActivateAbility` / `EndAbility` —— 控制"能不能开火、开火、收火"。
4. **一堆射线追踪方法**：真正的"打枪"逻辑（`PerformLocalTargeting` → `TraceBulletsInCartridge` → `DoSingleBulletTrace` → `WeaponTrace`）。
5. **一个蓝图事件** `OnRangedWeaponTargetDataReady`：把打中的结果丢给蓝图，让蓝图为所欲为（伤害/特效/声音）。

> ✅ **本 `.h` 零挂起点**：依赖 P09 装备技能基类 + P11.2 远程武器实例，全部就位，可直接编译。

## 二、完整代码（`.h`，已替换前缀 + 注释中文化）

```cpp
// 版权声明（Lyra 项目自带，保留）
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "Equipment/TenkaichiGameplayAbility_FromEquipment.h"

#include "TenkaichiGameplayAbility_RangedWeapon.generated.h"

enum ECollisionChannel : int;

class APawn;
class UTenkaichiRangedWeaponInstance;
class UObject;
struct FCollisionQueryParams;
struct FFrame;
struct FGameplayAbilityActorInfo;
struct FGameplayEventData;
struct FGameplayTag;
struct FGameplayTagContainer;

/** 定义一次开火从哪里开始射线追踪、以及朝向哪里 */
UENUM(BlueprintType)
enum class ETenkaichiAbilityTargetingSource : uint8
{
	// 从玩家的镜头朝"镜头焦点"打（默认，FPS 手感）
	CameraTowardsFocus,
	// 从 Pawn 中心，沿 Pawn 的朝向打
	PawnForward,
	// 从 Pawn 中心，朝镜头焦点打
	PawnTowardsFocus,
	// 从武器枪口位置，沿 Pawn 的朝向打
	WeaponForward,
	// 从武器枪口位置，朝镜头焦点打
	WeaponTowardsFocus,
	// 自定义起点（需要蓝图自己设置起始位置和朝向）
	Custom
};



/**
 * UTenkaichiGameplayAbility_RangedWeapon
 *
 * 由远程武器实例授予、并与该武器关联的"开枪"技能
 */
UCLASS()
class UTenkaichiGameplayAbility_RangedWeapon : public UTenkaichiGameplayAbility_FromEquipment
{
	GENERATED_BODY()

public:

	// 构造函数
	UTenkaichiGameplayAbility_RangedWeapon(const FObjectInitializer& ObjectInitializer = FObjectInitializer::Get());

	// 取关联的远程武器实例（装备实例强转）
	UFUNCTION(BlueprintCallable, Category="Tenkaichi|Ability")
	UTenkaichiRangedWeaponInstance* GetWeaponInstance() const;

	//~UGameplayAbility interface
	// 开火前校验：必须有远程武器实例才能开火
	virtual bool CanActivateAbility(const FGameplayAbilitySpecHandle Handle, const FGameplayAbilityActorInfo* ActorInfo, const FGameplayTagContainer* SourceTags = nullptr, const FGameplayTagContainer* TargetTags = nullptr, OUT FGameplayTagContainer* OptionalRelevantTags = nullptr) const override;
	// 激活技能：绑定目标数据回调 + 更新武器开火时间
	virtual void ActivateAbility(const FGameplayAbilitySpecHandle Handle, const FGameplayAbilityActorInfo* ActorInfo, const FGameplayAbilityActivationInfo ActivationInfo, const FGameplayEventData* TriggerEventData) override;
	// 技能结束：解绑回调 + 清目标数据
	virtual void EndAbility(const FGameplayAbilitySpecHandle Handle, const FGameplayAbilityActorInfo* ActorInfo, const FGameplayAbilityActivationInfo ActivationInfo, bool bReplicateEndAbility, bool bWasCancelled) override;
	//~End of UGameplayAbility interface

protected:
	// 一次开火的输入参数：射线起点/终点/方向 + 武器数据 + 能否播放弹道特效
	struct FRangedWeaponFiringInput
	{
		// 射线追踪的起点
		FVector StartTrace;

		// 若瞄准完美时的射线终点
		FVector EndAim;

		// 若瞄准完美时的射线方向
		FVector AimDir;

		// 武器实例（这次开火的数据来源）
		UTenkaichiRangedWeaponInstance* WeaponData = nullptr;

		// 本次开火命中时，能否播放弹道特效（客户端才播放）
		bool bCanPlayBulletFX = false;

		// 构造函数：把 3 个向量清零
		FRangedWeaponFiringInput()
			: StartTrace(ForceInitToZero)
			, EndAim(ForceInitToZero)
			, AimDir(ForceInitToZero)
		{
		}
	};

protected:
	// 在一堆命中结果里，找第一个"命中 Pawn（或其挂载物）"的索引
	static int32 FindFirstPawnHitResult(const TArray<FHitResult>& HitResults);

	// 真正调用物理引擎打射线/球体扫描（SweepRadius>0 时用球体扫描）
	FHitResult WeaponTrace(const FVector& StartTrace, const FVector& EndTrace, float SweepRadius, bool bIsSimulated, OUT TArray<FHitResult>& OutHitResults) const;

	// 单颗子弹：先尝试纯射线，没打中就回退到球体扫描（SweepRadius>0 时）
	FHitResult DoSingleBulletTrace(const FVector& StartTrace, const FVector& EndTrace, float SweepRadius, bool bIsSimulated, OUT TArray<FHitResult>& OutHits) const;

	// 按"每弹夹子弹数"循环：每颗子弹按散布角散开，单独打一条射线
	void TraceBulletsInCartridge(const FRangedWeaponFiringInput& InputData, OUT TArray<FHitResult>& OutHits);

	// 追加需要忽略的碰撞体（默认忽略挂在角色身上的附属物）
	virtual void AddAdditionalTraceIgnoreActors(FCollisionQueryParams& TraceParams) const;

	// 决定这次开火用哪个碰撞通道（默认用武器碰撞通道）
	virtual ECollisionChannel DetermineTraceChannel(FCollisionQueryParams& TraceParams, bool bIsSimulated) const;

	// 本地射线追踪：算起点/方向/终点，打出一串命中结果
	void PerformLocalTargeting(OUT TArray<FHitResult>& OutHits);

	// 取枪口位置（当前简单取 Pawn 位置）
	FVector GetWeaponTargetingSourceLocation() const;

	// 按瞄准模式算这次开火的起点+朝向（返回一个 Transform：位置=起点，X 轴=朝向）
	FTransform GetTargetingTransform(APawn* SourcePawn, ETenkaichiAbilityTargetingSource Source) const;

	// 目标数据就绪回调：上报服务器 + 提交技能 + 触发蓝图接口
	void OnTargetDataReadyCallback(const FGameplayAbilityTargetDataHandle& InData, FGameplayTag ApplicationTag);

	// 触发一次"瞄准→射线→回调"完整流程（蓝图可调用）
	UFUNCTION(BlueprintCallable)
	void StartRangedWeaponTargeting();

	// 命中结果就绪事件：蓝图在这里实现"伤害/特效/声音"
	UFUNCTION(BlueprintImplementableEvent)
	void OnRangedWeaponTargetDataReady(const FGameplayAbilityTargetDataHandle& TargetData);

private:
	// 目标数据回调的委托句柄（用于技能结束时取消注册）
	FDelegateHandle OnTargetDataReadyCallbackDelegateHandle;
};
```

## 三、逐段讲解

### 1. 头文件依赖

```cpp
#include "Equipment/TenkaichiGameplayAbility_FromEquipment.h"
#include "TenkaichiGameplayAbility_RangedWeapon.generated.h"
```

- **`Equipment/TenkaichiGameplayAbility_FromEquipment.h`**：继承 P09 的"装备技能"基类。这很重要 —— 它让这个技能自动获得"我属于哪个装备"的能力（`GetAssociatedEquipment()` 等）。
- **`TenkaichiGameplayAbility_RangedWeapon.generated.h`**：UHT 生成的反射代码头，必须最后 include。

> 注意：这里没有 `include` P11.2 的头文件，只在前面**前置声明**了 `UTenkaichiRangedWeaponInstance`。因为 `.h` 里只用了它的**指针**，不需要完整定义。

### 2. 前置声明

```cpp
enum ECollisionChannel : int;
class APawn;
class UTenkaichiRangedWeaponInstance;
...
struct FGameplayTag;
struct FGameplayTagContainer;
```

全部是**前置声明**（`class`/`struct`），因为 `.h` 里只用到了**指针/引用/返回值**，不需要完整定义。编译更快、避免循环 include。

### 3. 瞄准模式枚举

```cpp
UENUM(BlueprintType)
enum class ETenkaichiAbilityTargetingSource : uint8
{
	CameraTowardsFocus,
	PawnForward,
	PawnTowardsFocus,
	WeaponForward,
	WeaponTowardsFocus,
	Custom
};
```

- `UENUM(BlueprintType)`：允许蓝图层用这个枚举做变量/参数。
- 这 6 种模式决定"**从哪发射、朝哪打**"：
  - `CameraTowardsFocus`：从镜头朝屏幕中心打（FPS 手感，**默认推荐**）
  - `PawnForward`：从角色身上，朝角色朝向打
  - `PawnTowardsFocus`：从角色身上，朝镜头焦点打
  - `WeaponForward`：从枪口，朝角色朝向打
  - `WeaponTowardsFocus`：从枪口，朝镜头焦点打
  - `Custom`：起点/朝向完全由蓝图自己定

### 4. 类声明

```cpp
UCLASS()
class UTenkaichiGameplayAbility_RangedWeapon : public UTenkaichiGameplayAbility_FromEquipment
```

- 继承 P09 的装备技能基类 —— 所以它天然知道"我属于哪把枪"（`GetAssociatedEquipment()`）。
- 没有加 `BlueprintType`/`Blueprintable`（跟 Lyra 源码一致），因为技能通常是**实例化策略**，通过 Gameplay Ability 系统授予，不需要蓝图直接构造。

### 5. 构造函数 + 公开方法

```cpp
UTenkaichiGameplayAbility_RangedWeapon(const FObjectInitializer& ObjectInitializer = FObjectInitializer::Get());
UFUNCTION(BlueprintCallable, Category="Tenkaichi|Ability")
UTenkaichiRangedWeaponInstance* GetWeaponInstance() const;
```

- 构造函数：把"禁止开火"标签加入 `SourceBlockedTags`（具体在 `.cpp` 里做）。当角色身上有这个标签时，技能无法激活。
- `GetWeaponInstance()`：把 `GetAssociatedEquipment()` 的结果强转成 `UTenkaichiRangedWeaponInstance`。这就是"我手上那把枪"。

### 6. 技能生命周期（三大方法）

```cpp
virtual bool CanActivateAbility(...) const override;
virtual void ActivateAbility(...) override;
virtual void EndAbility(...) override;
```

这是 GAS 技能的**生命周期三件套**：
| 方法 | 作用 |
|------|------|
| `CanActivateAbility` | 开火前检查：必须有远程武器实例，否则拒绝并报错 |
| `ActivateAbility` | 激活瞬间：绑定"目标数据就绪"回调 + 更新武器开火时间戳 + 交给父类 |
| `EndAbility` | 结束瞬间：解绑回调 + 消费掉已复制的目标数据，防止内存泄漏 |

### 7. 内部结构体 `FRangedWeaponFiringInput`

```cpp
struct FRangedWeaponFiringInput
{
    FVector StartTrace;   // 射线起点
    FVector EndAim;       // 完美瞄准时的终点
    FVector AimDir;       // 完美瞄准时的方向
    UTenkaichiRangedWeaponInstance* WeaponData = nullptr;  // 这把枪的数据
    bool bCanPlayBulletFX = false;  // 能否播放弹道特效
    ...
};
```

- 这是一次开火的**"输入参数包"**，把射线相关的数据打包成一个结构体，方便在多个方法间传递。
- 注意 `WeaponData` 是普通指针（非智能指针）——因为这是 GAS 技能内部使用的临时数据，不持有所有权。

### 8. 射线追踪工具（私有/保护）

```cpp
static int32 FindFirstPawnHitResult(...);
FHitResult WeaponTrace(...);
FHitResult DoSingleBulletTrace(...);
void TraceBulletsInHit(...);
virtual void AddAdditionalTraceIgnoreActors(...);
virtual ECollisionChannel DetermineTraceChannel(...);
void PerformLocalTargeting(...);
FVector GetWeaponTargetingSourceLocation();
FTransform GetTargetingTransform(...);
void OnTargetDataCallback(...);
void StartRangedWeaponTargeting();
```

这是一条**"从瞄准到命中"的调用链**：

```
StartRangedWeaponTargeting()          ← 蓝图点一下/按开火键触发
  └→ PerformLocalTargeting()          ← 算起点/方向/终点
       └→ TraceBulletsInHit()         ← 按弹夹子弹数循环
            └→ DoSingleBulletTrace()  ← 每颗子弹：先射线，空就球扫
                 └→ WeaponTrace()     ← 真正调用物理引擎
                      └→ FindFirstPawnHitResult()  ← 找到第一个命中的人
```

- **`WeaponTrace`**：核心物理调用。`SweepRadius>0` 时用 `SweepMultiByChannel`（球体扫描），否则用 `LineTraceMultiByChannel`（纯射线）。返回的命中结果会**去重**（同一个 Actor 只算一次）。
- **`AddAdditionalTraceIgnoreActors`**：默认忽略角色身上的附属物（防止自伤）。
- **`DetermineTraceChannel`**：默认返回武器碰撞通道（`Tenkaichi_TraceChannel_Weapon`），虚函数便于子类覆盖。
- **`GetTargetingTransform`**：根据瞄准模式（`ETenkaichiAbilityTargetingSource`）返回一个 `FTransform`，位置 = 射线起点，X 轴 = 射线方向。
- **`OnTargetDataReadyCallback`**：这是**网络同步的核心** —— 客户端把瞄准结果通过 `CallServerSetReplicatedTargetData` 上报给服务器，服务器验证后触发 `OnRangedWeaponTargetDataReady` 蓝图事件。

### 9. 蓝图事件（收尾）

```cpp
UFUNCTION(BlueprintImplementableEvent)
void OnRangedWeaponTargetDataReady(const FGameplayAbilityTargetDataHandle& TargetData);
```

- `BlueprintImplementableEvent`：**纯蓝图实现**，C++ 只声明。
- 这是"开枪"的**最终出口**：所有射线/网络逻辑跑完后，把命中的目标数据丢给蓝图，蓝图为所欲为（施加伤害、播放特效、音效…）。
- 玩家（设计者）看到的唯一需要关心的地方。

### 10. 私有委托句柄

```cpp
FDelegateHandle OnTargetDataReadyCallbackDelegateHandle;
```

- 记录"目标数据就绪"回调的句柄，在 `EndAbility` 时用来**取消注册**，防止悬空回调。

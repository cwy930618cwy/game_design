## 一、这个类解决什么问题

P11.1 讲了"武器实例基类"（`UTenkaichiWeaponInstance`）——记录"开火时间、装备时间 + 手柄震动"。但武器基类只是**骨架**，它还不知道"枪怎么算准不准"。

`UTenkaichiRangedWeaponInstance` 就是**远程武器（枪）实例**：它继承了武器基类，再补上枪械最核心的三样东西：

1. **散布（Spread）** —— 枪打出去弹道多散（连射越来越飘、停下瞄准越来越准）。
2. **过热（Heat）** —— 连续射击会发热，越热越不准；停止射击会冷却，慢慢恢复准度。
3. **伤害衰减（Damage Attenuation）** —— 子弹打远了威力变弱（距离衰减）；打到不同材质（木头/钢板/肉体）伤害不同（物理材质衰减）。

一句话：**P11.1 是"这是一件武器"，P11.2 是"这是一把会发热、会飘、打远了威力会变小的枪"。**

## 二、全景：这个类里有什么

### 核心玩法参数（`.h` 里的 UPROPERTY，可在蓝图调）

| 参数 | 类型 | 作用 |
|------|------|------|
| `SpreadExponent` | float | 散布指数，越大弹道越往中心聚拢（准） |
| `HeatToSpreadCurve` | FRuntimeFloatCurve | 曲线：热量 → 散布角度（X=热、Y=散布角） |
| `HeatToHeatPerShotCurve` | FRuntimeFloatCurve | 曲线：当前热量 → 每发子弹再加多少热 |
| `HeatToCoolDownPerSecondCurve` | FRuntimeFloatCurve | 曲线：当前热量 → 每秒冷却多少热 |
| `SpreadRecoveryCooldownDelay` | float | 停止射击后，过多久才开始冷却回准 |
| `bAllowFirstShotAccuracy` | bool | 是否允许"第一发必准" |
| `SpreadAngleMultiplier_Aiming` | float | 瞄准（开镜）时的散布倍率（一般 <1 更准） |
| `SpreadAngleMultiplier_StandingStill` | float | 站定时散布倍率 |
| `TransitionRate_StandingStill` | float | 站定准度切换速度 |
| `StandingStillSpeedThreshold` | float | 低于此速度算"静止" |
| `StandingStillToMovingRange` | float | 从静止到移动的过渡区间 |
| `SpreadAngleMultiplier_Crouching` | float | 蹲下时散布倍率 |
| `TransitionRate_Crouching` | float | 蹲下准度切换速度 |
| `SpreadAngleMultiplier_JumpingOrFalling` | float | 空中时散布倍率 |
| `TransitionRate_JumpingOrFalling` | float | 空中准度切换速度 |
| `BulletsPerCartridge` | int | 一枪打几发（散弹枪=多，步枪=1） |
| `MaxDamageRange` | float | 最大有效射程（超出不造成伤害） |
| `BulletTraceSweepRadius` | float | 弹道扫描半径（0=射线，>0=球体扫描） |
| `DistanceDamageFalloff` | FRuntimeFloatCurve | 距离 → 伤害倍率（远=衰减） |
| `MaterialDamageMultiplier` | TMap<GameplayTag,float> | 物理材质 Tag → 伤害倍率 |

### 运行时状态（私有，代码内部）

| 变量 | 类型 | 作用 |
|------|------|------|
| `LastFireTime` | double | 上次开火时间 |
| `CurrentHeat` | float | 当前热量 |
| `CurrentSpreadAngle` | float | 当前散布角（度） |
| `bHasFirstShotAccuracy` | bool | 当前是否第一发必准 |
| `CurrentSpreadAngleMultiplier` | float | 综合散布倍率 |
| `StandingStillMultiplier` / `JumpFallMultiplier` / `CrouchingMultiplier` | float | 三个分项倍率 |

### 公开接口

| 方法 | 作用 |
|------|------|
| `Tick(float)` | 每帧调用，更新散布/热量/倍率，算出 `bHasFirstShotAccuracy` |
| `AddSpread()` | 开枪时调用：加热量 → 重算散布角 |
| `GetBulletsPerCartridge()` | 返回一枪几发 |
| `GetCalculatedSpreadAngle()` | 返回当前散布角 |
| `GetCalculatedSpreadAngleMultiplier()` | 返回综合倍率（第一发必准时为 0） |
| `HasFirstShotAccuracy()` | 是否第一发必准 |
| `GetSpreadExponent()` / `GetMaxDamageRange()` / `GetBulletTraceSweepRadius()` | 参数读取 |
| `OnEquipped()` / `OnUnequipped()` | 装备/卸下（把热量初始化到中间值） |
| `GetDistanceAttenuation()` | 实现 ILyraAbilitySourceInterface：距离伤害倍率 |
| `GetPhysicalMaterialAttenuation()` | 实现 ILyraAbilitySourceInterface：材质伤害倍率 |

> **核心玩法逻辑一句话**：**热量是"看不见的手"** —— 开枪 → 热量↑ → 散布角↑（飘）；停止 → 冷却 → 散布角↓（稳）；散布角再乘以"站/蹲/跳/瞄"四个倍率，就是最终这枪准不准。

## 〇、CheatManager 是干嘛的（为什么需要它）

游戏调试时，你需要快速输入一些"作弊指令"——**无敌 / 加血 / 杀自己 / 切相机 / 加标签**。这些指令不能写在正式玩法里，而是走一条**后台作弊通道**。`ULyraCheatManager` 就是这条通道的管理员：

| 职责 | 类比 | 对应源码段 |
|------|------|-----------|
| **作弊指令入口** | 后台控制台 | 所有 `UFUNCTION(exec)` 函数 |
| **跨服务器执行** | 后台发全局指令 | `ServerCheat` / `ServerCheatAll`（转发到服务端） |
| **玩家作弊** | 改自己的状态 | `God` / `UnlimitedHealth` / `AddTagToSelf` / `RemoveTagFromSelf` |
| **伤害/治疗** | 改数值 | `DamageSelf` / `DamageTarget` / `HealSelf` / `HealTarget` / `DamageSelfDestruct` |
| **调试相机切换** | 切上帝视角 | `EnableDebugCamera` / `DisableDebugCamera` / `ToggleFixedCamera` / `CycleDebugCameras` |
| **游戏流程作弊** | 跳关 | `PlayNextGame` / `CancelActivatedAbilities` |

> **关键认知**：
> 1. `CheatManager` 挂在 **PlayerController 上**（`Within = PlayerController`），它通过 `GetOuterAPlayerController()` 拿到自己的"司机"。
> 2. 它只负责**本地执行**，但需要跨服务器时，通过 `ServerCheat` / `ServerCheatAll` 把指令发给服务端执行（`exec` 函数 + `UFUNCTION` 蓝图调用）。
> 3. 它把 GAS（P05）、Health（P06）、AssetSystem（P14）、Settings（P18）全部串起来了，所以 `.cpp` 是重依赖断点。

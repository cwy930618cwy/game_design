## 一、这个类在解决什么

玩家复活/出生时，需要有一个**空位置**放下来。引擎自带的 `APlayerStart` 只是个"标记点"，不会自动判断"被占了/没被占"。

`ALyraPlayerStart` 在引擎基础上加了**占位管理**：

| 能力 | 作用 |
|------|------|
| **GetLocationOccupancy** | 检测出生点状态：`Empty`（空）/ `Partial`（部分被占）/ `Full`（满了） |
| **IsClaimed** | 这个出生点是否已被某个玩家"认领" |
| **TryClaim** | 没被占 → "认领"给一个玩家控制器，并开启定时检查 |
| **CheckUnclaimed** | 定时检查：认领者离开没？位置空出来没？空出来就自动释放 |
| **StartPointTags** | 出生点可打标签（如"红队出生点"/"出生点A"），供选择逻辑按需匹配 |

一句话：**PlayerStart = 带"占位检测 + 认领 + 自动释放"的智能出生点**。

| 配置 | `ExpirationCheckInterval` | 认领后多久检查一次是否释放（默认 1 秒） |

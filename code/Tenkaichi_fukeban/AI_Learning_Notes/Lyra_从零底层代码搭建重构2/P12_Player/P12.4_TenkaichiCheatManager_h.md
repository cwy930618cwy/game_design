## 〇、这个 `.h` 在解决什么

`UTenkaichiCheatManager` 是**整个项目的作弊管理器基类**。它定义了"作弊指令的入口清单"（哪些指令可用），以及作弊时调用的辅助工具（发指令到服务端、打日志、给玩家加标签/伤害/治疗）。真正的执行逻辑大多在 `.cpp`（下一步教，整体挂起）。

**类声明拆解（从上到下 5 块）：**

| 块 | 代码 | 作用 |
|----|------|------|
| ① 宏 | `UCLASS(config = Game, Within = PlayerController, MinimalAPI)` | 配置存 Config/Game；只能挂在 PlayerController 下；MinimalAPI 只导出类声明 |
| ② 静态日志 | `DECLARE_LOG_CATEGORY_EXTERN(LogTenkaichiCheat, Log, All)` | 作弊日志类别（.cpp 里定义） |
| ③ public 指令入口 | 所有 `UFUNCTION(exec)` | 玩家在控制台/蓝图敲的作弊指令 |
| ④ public 辅助 | `CheatOutputText()` | 同时输出到控制台和日志 |
| ⑤ protected 实现 | 相机切换 / 伤害治疗核心 | 被指令调用的内部函数 |

## 一、完整代码（可直接照抄）

```cpp
// 版权声明（可保留或省略，不影响编译）
#pragma once

#include "GameFramework/CheatManager.h"
#include "TenkaichiCheatManager.generated.h"

class UTenkaichiAbilitySystemComponent;


#ifndef USING_CHEAT_MANAGER
#define USING_CHEAT_MANAGER (1 && !UE_BUILD_SHIPPING)
#endif // #ifndef USING_CHEAT_MANAGER

DECLARE_LOG_CATEGORY_EXTERN(LogTenkaichiCheat, Log, All);


/**
 * UTenkaichiCheatManager
 *
 *	本工程使用的作弊管理器基类。
 */
UCLASS(config = Game, Within = PlayerController, MinimalAPI)
class UTenkaichiCheatManager : public UCheatManager
{
	GENERATED_BODY()

public:

	UTenkaichiCheatManager();

	virtual void InitCheatManager() override;

	// 把文本同时输出到控制台和日志。
	static void CheatOutputText(const FString& TextToOutput);

	// 为当前玩家在服务器上执行一条作弊指令。
	UFUNCTION(exec)
	void Cheat(const FString& Msg);

	// 为所有玩家在服务器上执行一条作弊指令。
	UFUNCTION(exec)
	void CheatAll(const FString& Msg);

	// 开始下一场比赛（直接调用系统工具，无需经过服务器）。
	UFUNCTION(Exec, BlueprintAuthorityOnly)
	void PlayNextGame();

	UFUNCTION(Exec)
	virtual void ToggleFixedCamera();

	UFUNCTION(Exec)
	virtual void CycleDebugCameras();

	UFUNCTION(Exec)
	virtual void CycleAbilitySystemDebug();

	// 强制取消所有已激活的技能（用于排查技能打断问题）。
	UFUNCTION(Exec, BlueprintAuthorityOnly)
	virtual void CancelActivatedAbilities();

	// 给当前玩家的技能系统组件加上一个动态标签。
	UFUNCTION(Exec, BlueprintAuthorityOnly)
	virtual void AddTagToSelf(FString TagName);

	// 移除当前玩家技能系统组件上的一个动态标签。
	UFUNCTION(Exec, BlueprintAuthorityOnly)
	virtual void RemoveTagFromSelf(FString TagName);

	// 对当前玩家造成指定伤害。
	UFUNCTION(Exec, BlueprintAuthorityOnly)
	virtual void DamageSelf(float DamageAmount);

	// 对玩家当前瞄准的目标造成伤害。
	virtual void DamageTarget(float DamageAmount) override;

	// 对当前玩家进行一定治疗。
	UFUNCTION(Exec, BlueprintAuthorityOnly)
	virtual void HealSelf(float HealAmount);

	// 对玩家当前瞄准的目标进行一定治疗。
	virtual void HealTarget(float HealAmount);

	// 对当前玩家造成足以致死的伤害。
	UFUNCTION(Exec, BlueprintAuthorityOnly)
	virtual void DamageSelfDestruct();

	// 无敌模式（开启/关闭）。
	virtual void God() override;

	// 无限生命（生命值不低于 1）。
	UFUNCTION(Exec, BlueprintAuthorityOnly)
	virtual void UnlimitedHealth(int32 Enabled = -1);

protected:

	virtual void EnableDebugCamera() override;
	virtual void DisableDebugCamera() override;
	bool InDebugCamera() const;

	virtual void EnableFixedCamera();
	virtual void DisableFixedCamera();
	bool InFixedCamera() const;

	void ApplySetByCallerDamage(UTenkaichiAbilitySystemComponent* TenkaichiASC, float DamageAmount);
	void ApplySetByCallerHeal(UTenkaichiAbilitySystemComponent* TenkaichiASC, float HealAmount);

	UTenkaichiAbilitySystemComponent* GetPlayerAbilitySystemComponent() const;
};
```

## 二、关键点讲解

### 1. `UCLASS(config = Game, Within = PlayerController, MinimalAPI)`

- `config = Game`：类配置存在 `Game.ini`，作弊指令的配置项可写进配置文件。
- `Within = PlayerController`：**这个类只能创建在 PlayerController 内部**（`NewObject` 的 Outer 必须是 PlayerController）。所以它通过 `GetOuterAPlayerController()` 拿"司机"。
- `MinimalAPI`：只导出类型信息，不导出所有成员函数（本项目用，保持编译干净）。

### 2. `#ifndef USING_CHEAT_MANAGER ... #endif`
定义作弊管理器是否启用。`(1 && !UE_BUILD_SHIPPING)` = **正式发布版（Shipping）里关闭作弊，其余构建开启**。这是引擎的惯用宏，防止作弊代码泄漏到发布版。

### 3. `UFUNCTION(exec)`

**exec 函数** = 能在**控制台直接敲命令**调用的函数。作弊指令全都用 `exec`，这样在游戏里按 `~` 打开控制台，直接敲 `God`、`AddTagToSelf ...` 就能执行。带 `BlueprintAuthorityOnly` 的只能在服务端（权威）调用，防止客户端乱调。

### 4. `CheatOutputText()`（static）

把作弊反馈同时打到**控制台**（`GEngine->GameViewport->ViewportConsole`）和**日志**（`LogTenkaichiCheat`）。这样作弊时能看到即时反馈。

### 5. protected 相机切换方法

`EnableDebugCamera` / `DisableDebugCamera` / `EnableFixedCamera` / `DisableFixedCamera` 是**虚函数**，覆盖了引擎 `UCheatManager` 的对应钩子。作弊指令（如引擎自带 `EnableDebugCamera`）会调用它们。`InDebugCamera()` / `InFixedCamera()` 查询当前是否处于对应相机模式。

> ⚠️ 注意：这些方法在 `.cpp` 里都有实现，但 `.cpp` 整体会 `#if 0` 挂起（依赖 P14/P18/P12.6 断点类），所以这里先只写 `.h` 声明，实现下一步再写。

### 6. `GetPlayerAbilitySystemComponent()` / `ApplySetByCallerDamage` / `ApplySetByCallerHeal`

这三个是作弊指令的"幕后工具"：
- `GetPlayerAbilitySystemComponent()`：通过 PlayerController 拿到玩家的 ASC（P05 的 `UTenkaichiAbilitySystemComponent`）。
- `ApplySetByCallerDamage` / `ApplySetByCallerHeal`：用 `SetByCaller` 方式给玩家施加伤害/治疗效果（依赖 P14 的 `AssetManager` 拿伤害/治疗 GameplayEffect 蓝图）。

## 〇、这个 `.cpp` 在解决什么

`.h` 只声明了"出生点管家"的骨架，`.cpp` 把**收集出生点 + 选出生点 + 重生回调**的整套逻辑真正写出来。全部实现，一行注释挂起都没有。

**实现拆解（从上到下 8 个函数）：**

| 块 | 函数 | 作用 |
|----|------|------|
| ① 构造 | `UTenkaichiPlayerSpawningManagerComponent(...)` | 配置组件心跳/复制属性 |
| ② 启动 | `InitializeComponent` | 扫描场景出生点 + 注册"新关卡/新 Actor"监听 |
| ③ 监听 | `OnLevelAdded` / `HandleOnActorSpawned` | 新关卡/新出生点加入缓存 |
| ④ 选点 | `ChoosePlayerStart` | 给玩家选出生点（观战随机/虚函数/随机空位/认领） |
| ⑤ 编辑器 | `FindPlayFromHereStart` | PIE "从这开始玩"优先 |
| ⑥ 校验 | `ControllerCanRestart` | 能否重生（默认恒真） |
| ⑦ 完成 | `FinishRestartPlayer` | 重生完成回调（虚函数 + 蓝图事件） |
| ⑧ 工具 | `GetFirstRandomUnoccupiedPlayerStart` | 随机选"空"出生点 |

UTenkaichiPlayerSpawningManagerComponent::UTenkaichiPlayerSpawningManagerComponent(const FObjectInitializer& ObjectInitializer)
: Super(ObjectInitializer)
{
	// 默认不复制，自动注册/激活，想要初始化。
	SetIsReplicatedByDefault(false);
	bAutoRegister = true;
	bAutoActivate = true;
	bWantsInitializeComponent = true;
	// 组件心跳：PrePhysics 阶段、可以 tick、专用服务器也 tick、默认不开（需要时才开）。
	PrimaryComponentTick.TickGroup = TG_PrePhysics;
	PrimaryComponentTick.bCanEverTick = true;
	PrimaryComponentTick.bAllowTickOnDedicatedServer = true;
	PrimaryComponentTick.bStartWithTickEnabled = false;
}

void UTenkaichiPlayerSpawningManagerComponent::InitializeComponent()
{
	Super::InitializeComponent();

	// 监听"新关卡加入世界"，把新关卡里的出生点收进缓存。
	FWorldDelegates::LevelAddedToWorld.AddUObject(this, &ThisClass::OnLevelAdded);

	// 监听"场景里新出生 Actor"，若是出生点就收进缓存。
	UWorld* World = GetWorld();
	World->AddOnActorSpawnedHandler(FOnActorSpawned::FDelegate::CreateUObject(this, &ThisClass::HandleOnActorSpawned));

	// 扫描场景里所有已存在的出生点，先全部收进缓存。
	for (TActorIterator<ATenkaichiPlayerStart> It(World); It; ++It)
	{
		if (ATenkaichiPlayerStart* PlayerStart = *It)
		{
			CachedPlayerStarts.Add(PlayerStart);
		}
	}
}

void UTenkaichiPlayerSpawningManagerComponent::OnLevelAdded(ULevel* InLevel, UWorld* InWorld)
{
	// 只处理本世界的新关卡。
	if (InWorld == GetWorld())
	{
		for (AActor* Actor : InLevel->Actors)
		{
			if (ATenkaichiPlayerStart* PlayerStart = Cast<ATenkaichiPlayerStart>(Actor))
			{
				ensure(!CachedPlayerStarts.Contains(PlayerStart));
				CachedPlayerStarts.Add(PlayerStart);
			}
		}
	}
}

void UTenkaichiPlayerSpawningManagerComponent::HandleOnActorSpawned(AActor* SpawnedActor)
{
	// 新出生的是出生点，就收进缓存。
	if (ATenkaichiPlayerStart* PlayerStart = Cast<ATenkaichiPlayerStart>(SpawnedActor))
	{
		CachedPlayerStarts.Add(PlayerStart);
	}
}

// ATenkaichiGameMode 代理调用 —— 需要处理有人用引擎常规方式重生玩家的情况。
//======================================================================

AActor* UTenkaichiPlayerSpawningManagerComponent::ChoosePlayerStart(AController* Player)
{
	if (Player)
	{
#if WITH_EDITOR
		// 编辑器里优先用"从这开始玩"的出生点。
		if (APlayerStart* PlayerStart = FindPlayFromHereStart(Player))
		{
			return PlayerStart;
		}
#endif

		// 把缓存里仍然有效的出生点收集进临时列表（顺手清掉失效的弱引用）。
		TArray<ATenkaichiPlayerStart*> StarterPoints;
		for (auto StartIt = CachedPlayerStarts.CreateIterator(); StartIt; ++StartIt)
		{
			if (ATenkaichiPlayerStart* Start = (*StartIt).Get())
			{
				StarterPoints.Add(Start);
			}
			else
			{
				StartIt.RemoveCurrent();
			}
		}

		// 纯观战者：随便挑一个出生点位置，但不认领它。
		if (APlayerState* PlayerState = Player->GetPlayerState<APlayerState>())
		{
			if (PlayerState->IsOnlyASpectator())
			{
				if (!StarterPoints.IsEmpty())
				{
					return StarterPoints[FMath::RandRange(0, StarterPoints.Num() - 1)];
				}

				return nullptr;
			}
		}

		// 先让子类（Experience）自己选；没选到就走"随机空位"。
		AActor* PlayerStart = OnChoosePlayerStart(Player, StarterPoints);

		if (!PlayerStart)
		{
			PlayerStart = GetFirstRandomUnoccupiedPlayerStart(Player, StarterPoints);
		}

		// 选中的出生点被这个玩家认领，避免别人再用。
		if (ATenkaichiPlayerStart* LyraStart = Cast<ATenkaichiPlayerStart>(PlayerStart))
		{
			LyraStart->TryClaim(Player);
		}

		return PlayerStart;
	}

	return nullptr;
}

#if WITH_EDITOR
APlayerStart* UTenkaichiPlayerSpawningManagerComponent::FindPlayFromHereStart(AController* Player)
{
	// 只有真正的玩家控制器才用"从这开始玩"，机器人等一律走普通出生点。
	if (Player->IsA<APlayerController>())
	{
		if (UWorld* World = GetWorld())
		{
			for (TActorIterator<APlayerStart> It(World); It; ++It)
			{
				if (APlayerStart* PlayerStart = *It)
				{
					if (PlayerStart->IsA<APlayerStartPIE>())
					{
						// 在 PIE 模式下找到"从这开始玩"的出生点，永远优先用第一个。
						return PlayerStart;
					}
				}
			}
		}
	}

	return nullptr;
}
#endif

APlayerStart* UTenkaichiPlayerSpawningManagerComponent::GetFirstRandomUnoccupiedPlayerStart(AController* Controller, const TArray<ATenkaichiPlayerStart*>& StartPoints) const
{
	if (Controller)
	{
		// 分成"空位"和"半空"两组。
		TArray<ATenkaichiPlayerStart*> UnOccupiedStartPoints;
		TArray<ATenkaichiPlayerStart*> OccupiedStartPoints;

		for (ATenkaichiPlayerStart* StartPoint : StartPoints)
		{
			ETenkaichiPlayerStartLocationOccupancy State = StartPoint->GetLocationOccupancy(Controller);

			switch (State)
			{
				case ETenkaichiPlayerStartLocationOccupancy::Empty:
					UnOccupiedStartPoints.Add(StartPoint);
					break;
				case ETenkaichiPlayerStartLocationOccupancy::Partial:
					OccupiedStartPoints.Add(StartPoint);
					break;

			}
		}

		// 有"空位"优先挑空位；没有就挑"半空"的。
		if (UnOccupiedStartPoints.Num() > 0)
		{
			return UnOccupiedStartPoints[FMath::RandRange(0, UnOccupiedStartPoints.Num() - 1)];
		}
		else if (OccupiedStartPoints.Num() > 0)
		{
			return OccupiedStartPoints[FMath::RandRange(0, OccupiedStartPoints.Num() - 1)];
		}
	}

	return nullptr;
}

## 二、关键点讲解

### 1. 构造函数：组件配置
| 配置 | 含义 |
|------|------|
| `SetIsReplicatedByDefault(false)` | 出生点选择只在服务器做，不复制 |
| `bAutoRegister = true` / `bAutoActivate = true` / `bWantsInitializeComponent = true` | 自动注册、激活、初始化 |
| `PrimaryComponentTick.TickGroup = TG_PrePhysics` | 心跳在物理模拟前跑 |
| `bCanEverTick = true` / `bAllowTickOnDedicatedServer = true` | 能 tick，专用服务器也 tick |
| `bStartWithTickEnabled = false` | 默认不开 tick（需要时才开） |

### 2. `InitializeComponent`：收集出生点 + 注册监听
启动时做三件事：
1. 注册 `FWorldDelegates::LevelAddedToWorld` 监听 → 新关卡加载时回调 `OnLevelAdded`。
2. `World->AddOnActorSpawnedHandler` → 场景里新出生 Actor 时回调 `HandleOnActorSpawned`。
3. `TActorIterator<ATenkaichiPlayerStart>` 遍历场景所有出生点，全收进 `CachedPlayerStarts`。

> `TActorIterator` = 引擎的 Actor 遍历器，扫出指定类型的所有 Actor。

### 3. `OnLevelAdded` / `HandleOnActorSpawned`：增量收出生点
两个监听都做同一件事：**把新出现的 `ATenkaichiPlayerStart` 加进缓存**。区别只是触发来源不同（新关卡 / 新出生 Actor）。`ensure(!Contains(...))` 防止重复加入。

### 4. `ChoosePlayerStart`：核心选点逻辑（被 GameMode 代理调用）
完整流程：
1. **编辑器**：优先用 `FindPlayFromHereStart`（"从这开始玩"）。
2. **清理缓存**：把失效弱引用踢掉，剩下有效出生点进 `StarterPoints`。
3. **纯观战者**（`IsOnlyASpectator`）：随便挑一个位置，**不认领**。
4. **正常玩家**：先 `OnChoosePlayerStart`（虚函数，子类可自定义）→ 没选到就走 `GetFirstRandomUnoccupiedPlayerStart`（随机空位）。
5. 选中的出生点 `TryClaim(Player)` **认领**。

### 5. `FindPlayFromHereStart`（`#if WITH_EDITOR` 编辑器专用）
只在编辑器 PIE 模式编译。玩家控制器（非 Bot）找 `APlayerStartPIE` 类型的出生点，优先用"从这开始玩"。

### 6. `ControllerCanRestart`：能否重生
目前**恒返回 true**（`bCanRestart = true`），留了 `// TODO 能重生吗？` 注释，未来可扩展"复活冷却/条件"。

### 7. `FinishRestartPlayer`：重生完成回调
重生完成后依次调用 `OnFinishRestartPlayer`（C++ 虚函数）+ `K2_OnFinishRestartPlayer`（蓝图事件），C++ 和蓝图都能接住回调。

### 8. `GetFirstRandomUnoccupiedPlayerStart`：随机空位
遍历出生点，按 `GetLocationOccupancy` 三态分组：`Empty` 进"空位组"，`Partial` 进"半空组"。**有空位优先随机空位**，否则随机半空位。`FMath::RandRange(0, N-1)` 随机下标。
> ⚠️ 注意：Lyra 原版 switch 里 `Full` 分支没有写（既不加组也不 break，直接落到 switch 结束），这是 Lyra 原样，照抄不动。

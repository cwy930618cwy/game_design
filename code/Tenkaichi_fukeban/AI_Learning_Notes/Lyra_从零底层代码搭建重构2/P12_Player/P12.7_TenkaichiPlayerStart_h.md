## 〇、这个 `.h` 在解决什么

`ATenkaichiPlayerStart` 继承引擎 `APlayerStart`，给它加了**"占位检测 + 认领 + 自动释放"**能力。让玩家出生时能自动找到一个**空位置**，而不是挤在别人身上。

**类声明拆解（从上到下 5 块）：**

| 块 | 代码 | 作用 |
|----|------|------|
| ① 枚举 | `ETenkaichiPlayerStartLocationOccupancy` | 出生点三态：`Empty`/`Partial`/`Full` |
| ② 查询 | `GetGameplayTags()` / `GetLocationOccupancy()` | 读标签 / 检测能否放 Pawn |
| ③ 认领 | `IsClaimed()` / `TryClaim()` | 是否被占、认领给指定控制器 |
| ④ 释放 | `CheckUnclaimed()`（protected） | 定时器回调：认领者走了自动释放 |
| ⑤ 状态与配置 | `ClaimingController` / `ExpirationCheckInterval` / `StartPointTags` / `ExpirationTimerHandle` | 认领者记录、检查间隔、标签、定时器句柄 |

## 一、完整代码（可直接照抄）

```cpp
// 版权声明（可保留或省略，不影响编译）
#pragma once

#include "GameFramework/PlayerStart.h"
#include "GameplayTagContainer.h"

#include "TenkaichiPlayerStart.generated.h"

#define UE_API TENKAICHIGAME_API

class AController;
class UObject;

// 出生点的占用状态：空 / 部分被占 / 满。
enum class ETenkaichiPlayerStartLocationOccupancy
{
	Empty,
	Partial,
	Full
};

/**
 * ATenkaichiPlayerStart
 *
 * 很多玩法模式都能用的基础玩家出生点。
 */
UCLASS(MinimalAPI, Config = Game)
class ATenkaichiPlayerStart : public APlayerStart
{
	GENERATED_BODY()

public:
	ATenkaichiPlayerStart(const FObjectInitializer& ObjectInitializer = FObjectInitializer::Get());

	// 读取这个出生点的标签集合。
	const FGameplayTagContainer& GetGameplayTags() { return StartPointTags; }

	// 检测这个出生点现在能不能放得下一个指定控制器要操控的 Pawn。
	UE_API ETenkaichiPlayerStartLocationOccupancy GetLocationOccupancy(AController* const ControllerPawnToFit) const;

	/** 这个出生点是否已经被某个控制器认领了？ */
	UE_API bool IsClaimed() const;

	/** 如果没被认领，就把它认领给指定控制器 */
	UE_API bool TryClaim(AController* OccupyingController);

protected:
	/** 检查这个出生点是否还被占着（定时器回调） */
	UE_API void CheckUnclaimed();

	/** 认领了这个出生点的控制器 */
	UPROPERTY(Transient)
	TObjectPtr<AController> ClaimingController = nullptr;

	/** 每隔多久检查一次这个出生点是否已经没人在附近了 */
	UPROPERTY(EditDefaultsOnly, Category = "Player Start Claiming")
	float ExpirationCheckInterval = 1.f;

	/** 用来标识这个出生点的标签 */
	UPROPERTY(EditAnywhere)
	FGameplayTagContainer StartPointTags;

	/** 记录过期检查的循环定时器句柄 */
	FTimerHandle ExpirationTimerHandle;
};

#undef UE_API
```

## 二、关键点讲解

### 1. `enum class ETenkaichiPlayerStartLocationOccupancy`
出生点的**三种状态**，用于给"出生点选择逻辑"判断：
- `Empty`：空位，可以放
- `Partial`：部分被占（比如有障碍物挡住一半），还能挤一挤
- `Full`：满了，放不下

### 2. `GetLocationOccupancy(AController*)`
核心检测函数：用 `World->EncroachingBlockingGeometry`（是否撞上阻挡几何体）判断能不能放 Pawn。返回 `Empty`/`Partial`/`Full`。在 `.cpp` 里实现。

### 3. `GetGameplayTags()`
返回出生点的标签（`FGameplayTagContainer`）。用于"选择出生点"时按标签过滤（如只要红队出生点）。

### 4. `TryClaim(AController*)` / `IsClaimed()` / `CheckUnclaimed()`
**认领机制**：玩家选到这个出生点后调用 `TryClaim` 认领，避免别人再用；认领后启动一个**循环定时器**（间隔 `ExpirationCheckInterval`，默认 1 秒），定期检查认领者是否已经离开（`CheckUnclaimed`），离开了就释放认领。

### 5. `UE_API` 宏
`.h` 用 `#define UE_API TENKAICHIGAME_API`，让 `GetLocationOccupancy`/`IsClaimed`/`TryClaim`/`CheckUnclaimed` 被标记为 DLL 导出（供其他模块/蓝图访问）。这是 Lyra 原版做法，保留即可。

> ⚠️ 注意：`TENKAICHIGAME_API` 必须在项目的 API 宏里已经定义（`TenkaichiGame.Build.cs` 里 `.AddModule` 生成 `TENKAICHIGAME_API`）。你的工程已建过类似类，这个宏已就绪。

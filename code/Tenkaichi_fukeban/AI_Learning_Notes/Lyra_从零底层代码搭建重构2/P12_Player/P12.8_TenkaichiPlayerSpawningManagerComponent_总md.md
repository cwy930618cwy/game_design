## 一、这个类在解决什么

玩家出生点选哪个、能不能复活、复活后在哪出生——这些逻辑**不应该写在 GameMode 里**（因为每个玩法模式（Experience）想要的出生规则可能不同）。

`ULyraPlayerSpawningManagerComponent` 把**出生点选择逻辑**从 GameMode 中抽出来，挂到 GameState 上，让每个 Experience 都能**自定义自己的出生规则**。

| 能力 | 作用 |
|------|------|
| **收集出生点** | 启动时扫描场景里所有 `ATenkaichiPlayerStart`，并监听新生成的/新载入关卡的出生点 |
| **ChoosePlayerStart** | 给某个玩家挑一个出生点（优先用虚函数让子类自定义，否则随机选空位） |
| **ControllerCanRestart** | 判断这个控制器现在能不能重生 |
| **FinishRestartPlayer** | 重生完成后回调（虚函数 + 蓝图事件双通道） |
| **GetFirstRandomUnoccupiedPlayerStart** | 从出生点里随机挑一个"空"的，没空的就挑"半空"的 |

一句话：**PlayerSpawningManagerComponent = "出生点管家"，把出生规则从 GameMode 里拆出来，给每个玩法模式自定义**。

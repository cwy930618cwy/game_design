## 〇、这个 `.h` 在解决什么

`UTenkaichiPlayerSpawningManagerComponent` 继承引擎 `UGameStateComponent`（挂在 GameState 上的组件）。它把**出生点选择逻辑**从 GameMode 里抽出来，让每个玩法模式（Experience）能自定义自己的出生规则。

**类声明拆解（从上到下 5 块）：**

| 块 | 代码 | 作用 |
|----|------|------|
| ① 基类 | `UGameStateComponent` | 挂在 GameState 上的组件（引擎/S1） |
| ② 生命周期 | `InitializeComponent` / `TickComponent` | 启动时扫描出生点 + 组件心跳钩子 |
| ③ 选点工具 | `GetFirstRandomUnoccupiedPlayerStart` / `OnChoosePlayerStart` | 随机选"空"出生点 / 虚函数让子类自定义 |
| ④ 重生完成 | `OnFinishRestartPlayer` / `K2_OnFinishRestartPlayer` | C++ 虚函数 + 蓝图事件双通道 |
| ⑤ 私有代理 | `ChoosePlayerStart` / `ControllerCanRestart` / `FinishRestartPlayer` | 被 `friend class ATenkaichiGameMode` 代理调用 |
| ⑥ 缓存与监听 | `CachedPlayerStarts` / `OnLevelAdded` / `HandleOnActorSpawned` | 收集到的出生点 + 新关卡/新 Actor 监听 |

## 一、完整代码（可直接照抄）

```cpp
// 版权声明（可保留或省略，不影响编译）
#pragma once

#include "Components/GameStateComponent.h"

#include "TenkaichiPlayerSpawningManagerComponent.generated.h"

#define UE_API TENKAICHIGAME_API

class AController;
class APlayerController;
class APlayerState;
class APlayerStart;
class ATenkaichiPlayerStart;
class AActor;

/**
 * UTenkaichiPlayerSpawningManagerComponent
 *
 * 出生点管理组件：挂在 GameState 上，把出生点选择逻辑从 GameMode 里拆出来，
 * 让每个玩法模式（Experience）都能自定义自己的出生规则。
 */
UCLASS(MinimalAPI)
class UTenkaichiPlayerSpawningManagerComponent : public UGameStateComponent
{
	GENERATED_BODY()

public:
	UE_API UTenkaichiPlayerSpawningManagerComponent(const FObjectInitializer& ObjectInitializer);

	/** UActorComponent */
	UE_API virtual void InitializeComponent() override;
	UE_API virtual void TickComponent(float DeltaTime, enum ELevelTick TickType, FActorComponentTickFunction* ThisTickFunction) override;
	/** ~UActorComponent */

protected:
	// 工具函数：从出生点列表里随机挑一个"空"的，没空的就挑"半空"的。
	UE_API APlayerStart* GetFirstRandomUnoccupiedPlayerStart(AController* Controller, const TArray<ATenkaichiPlayerStart*>& FoundStartPoints) const;

	// 虚函数：给指定玩家选出生点（子类可重载自定义；默认返回空指针 = 走随机空位逻辑）。
	virtual AActor* OnChoosePlayerStart(AController* Player, TArray<ATenkaichiPlayerStart*>& PlayerStarts) { return nullptr; }
	// 虚函数：重生完成后回调（子类可重载）。
	virtual void OnFinishRestartPlayer(AController* Player, const FRotator& StartRotation) { }

	// 蓝图事件：重生完成后回调（蓝图里可绑定，DisplayName 同名）。
	UFUNCTION(BlueprintImplementableEvent, meta=(DisplayName=OnFinishRestartPlayer))
	UE_API void K2_OnFinishRestartPlayer(AController* Player, const FRotator& StartRotation);

private:

	/** 这些方法被 ATenkaichiGameMode 代理调用，转发到这个组件，让每个 Experience 更容易自定义复活系统。 */
	UE_API AActor* ChoosePlayerStart(AController* Player);
	UE_API bool ControllerCanRestart(AController* Player);
	UE_API void FinishRestartPlayer(AController* NewPlayer, const FRotator& StartRotation);
	friend class ATenkaichiGameMode;
	/** ~ATenkaichiGameMode */

	// 缓存收集到的所有出生点（弱引用，防止引用失效）。
	UPROPERTY(Transient)
	TArray<TWeakObjectPtr<ATenkaichiPlayerStart>> CachedPlayerStarts;

private:
	// 新关卡加载时，把该关卡里的出生点加入缓存。
	UE_API void OnLevelAdded(ULevel* InLevel, UWorld* InWorld);
	// 场景里新出生一个 Actor 时，若是出生点就加入缓存。
	UE_API void HandleOnActorSpawned(AActor* SpawnedActor);

#if WITH_EDITOR
	// 编辑器专用：找"从这开始玩"的出生点（PIE 调试用）。
	UE_API APlayerStart* FindPlayFromHereStart(AController* Player);
#endif
};

#undef UE_API
```

## 二、关键点讲解

### 1. `friend class ATenkaichiGameMode`
这是这个类**最核心的伏笔**（预告 P13 GameMode）：`ChoosePlayerStart` / `ControllerCanRestart` / `FinishRestartPlayer` 三个方法都是 **private**，但声明了 `friend class ATenkaichiGameMode`，让 P13 的 `ATenkaichiGameMode` 能调用它们——从而 GameMode 把出生点逻辑**代理**给这个组件。这正是 P13 的入口，现在先照写，不用深究。

### 2. 选点工具：`GetFirstRandomUnoccupiedPlayerStart`
输入出生点列表，**随机**挑一个 `Empty`（空位）的，没空的就挑 `Partial`（半空）的。实现体在 `.cpp`。

### 3. 可重载虚函数：`OnChoosePlayerStart` / `OnFinishRestartPlayer`
Lyra 让子类（不同 Experience）能重载这两个虚函数，自定义"选点"和"重生完成"逻辑。**默认返回 `nullptr` / 空**，表示走默认逻辑。这是"让每个玩法模式自定义"的关键。

### 4. 蓝图事件：`K2_OnFinishRestartPlayer`
`BlueprintImplementableEvent` = 蓝图里实现的事件，和 C++ 虚函数 `OnFinishRestartPlayer` 通过 `DisplayName=OnFinishRestartPlayer` 同名。C++ 侧调虚函数，蓝图侧也能收到回调。

### 5. 缓存与监听：`CachedPlayerStarts` / `OnLevelAdded` / `HandleOnActorSpawned`
`InitializeComponent` 时扫描场景里所有 `ATenkaichiPlayerStart` 存进 `CachedPlayerStarts`（`TWeakObjectPtr` 弱引用防悬挂），并注册两个监听：新关卡加载（`OnLevelAdded`）、新 Actor 出生（`HandleOnActorSpawned`），把后续新增的出生点也收进来。

### 6. `TickComponent`
空实现，保留"组件心跳"钩子，`DeltaTime` 参数在 `.cpp` 里被忽略。

### 7. `UE_API` 宏
`.h` 用 `#define UE_API TENKAICHIGAME_API`，把公开/代理方法标记为 DLL 导出。Lyra 原版 `LYRAGAME_API` 换成 `TENKAICHIGAME_API`（你工程已定义过）。

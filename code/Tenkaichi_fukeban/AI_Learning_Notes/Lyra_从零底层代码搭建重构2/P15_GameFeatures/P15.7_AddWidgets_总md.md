## 一、这个类解决什么问题（先讲为什么）

GameFeature 插件常需要**加 UI**（比如"新武器 DLC"激活时，在 HUD 上加载具栏、弹药数）。`UGameFeatureAction_AddWidgets` 就是把 UI 控件加到 HUD：

1. **Layout（布局层）**：往 CommonUI 的某个"层"（`LayerID`，如 `UI.Layer.Game`）推一个布局控件（`PushContentToLayer_ForPlayer`）。
2. **Widget（HUD 元素）**：往某个"插槽"（`SlotID`）注册一个控件（`UIExtensionSubsystem::RegisterExtensionAsWidgetForContext`）。

> **类比**：HUD 是一块"公告板"，Layout = 整块面板（血条区、小地图区），Widget = 插在面板某个卡槽里的小卡片。

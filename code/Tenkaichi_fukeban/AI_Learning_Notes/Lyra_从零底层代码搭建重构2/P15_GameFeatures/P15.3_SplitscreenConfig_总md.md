## 一、这个类解决什么问题（先讲为什么）

有些游戏模式**不支持分屏**（比如竞技对战需要全屏）。Lyra 需要一种机制：某个 GameFeature 插件激活时"禁用分屏"，插件停用时"恢复分屏"。

难点：**多个插件可能同时要求禁用分屏**。如果插件 A 和 B 都要求禁用，A 停用时不能直接恢复分屏（B 还在要求）。

`UGameFeatureAction_SplitscreenConfig` 用**投票计数（Vote）**解决：
- 每个要求禁用分屏的 Action 实例给对应 viewport "投一票"（`VoteCount++`）。
- 票数从 0 变 1 时，真正禁用分屏。
- 停用时"撤一票"（`VoteCount--`），票数降到 0 时才真正恢复分屏。

> **类比**：会议室空调——多个人都想开（投票），只有所有人都走了（票数归零）才关。避免"我走了就把空调关了，但别人还在"。

## 二、内部结构全景

| 成员 | 作用 |
|------|------|
| `OnGameFeatureDeactivating`（覆写） | 停用：对每个投票的 viewport 撤票 |
| `AddToWorld`（覆写 P15.1 纯虚） | 激活：对 world 的 viewport 投票 |
| `bDisableSplitscreen`（`UPROPERTY`） | 是否禁用分屏（默认 true） |
| `LocalDisableVotes` | 本 Action 投过票的 viewport 列表 |
| `GlobalDisableVotes`（**静态**） | 全局投票表（viewport → 票数） |

## 二、关键点讲解

### 1. 三个类在同一个文件里

Lyra 把 3 个紧密相关的类放在一个 `.h`/`.cpp` 里（策略 + 它的 2 个观察者）。这是"**一个模块一个文件**"的组织方式——观察者只服务于这个策略，不单独拆文件。

> 铁律 10（代码放哪个文件也要对应 Lyra）：这里 Lyra 就放一个文件，所以我们也放一个文件，**不拆**。

### 2. `UCLASS(MinimalAPI, Config = Game)`

和前面一致：`MinimalAPI`（精简导出）+ `Config = Game`（从 `DefaultGame.ini` 读配置）。

> `Config = Game` 很关键——策略类由引擎通过配置 `[/Script/TenkaichiGame.TenkaichiGameFeaturePolicy]` 指定使用。

### 3. `static UTenkaichiGameFeaturePolicy& Get()`

```cpp
TENKAICHIGAME_API static UTenkaichiGameFeaturePolicy& Get();
```

静态单例 getter（`.cpp` 里 `UGameFeaturesSubsystem::Get().GetPolicy<...>()`）。注意导出宏直接写 `TENKAICHIGAME_API`（没有用 `UE_API` 别名——Lyra 原文这里就直接用宏，照抄）。

### 4. 6 个覆写——策略的定制点

| 方法 | 作用 |
|------|------|
| `InitGameFeatureManager` | 初始化（注册 2 个观察者） |
| `ShutdownGameFeatureManager` | 关闭（移除观察者） |
| `GetPreloadAssetListForGameFeature` | 预加载资产列表（Lyra 直接回退父类） |
| `IsPluginAllowed` | 插件是否允许（直接回退父类） |
| `GetPreloadBundleStateForGameFeature` | 预加载 Bundle（直接回退父类） |
| `GetGameFeatureLoadingMode` | **真正定制**：按 NetMode 决定加载客户端/服务器数据 |

> 注意：4 个方法只是 `return Super::...`（占位，便于将来定制），只有 `InitGameFeatureManager`/`ShutdownGameFeatureManager`/`GetGameFeatureLoadingMode` 有实际逻辑。

### 5. 观察者模式：`UObject` + `IGameFeatureStateChangeObserver`

```cpp
class UTenkaichiGameFeature_HotfixManager : public UObject, public IGameFeatureStateChangeObserver
```

- `UObject`：必须是 UObject（引擎 GameFeatures 系统管理其生命周期）。
- `IGameFeatureStateChangeObserver`：引擎的"状态变化观察者"接口，提供 `OnGameFeatureLoading`/`Registering`/`Unregistering` 等回调。
- 只覆写自己关心的方法（HotfixManager 只要 `OnGameFeatureLoading`，AddGameplayCuePaths 要 `Registering`/`Unregistering`）——接口其他方法是空实现。

### 6. `UPROPERTY(Transient) TArray<TObjectPtr<UObject>> Observers`

```cpp
UPROPERTY(Transient)
TArray<TObjectPtr<UObject>> Observers;
```

`Transient`（不存盘）+ `TObjectPtr`（UE5 智能指针）——确保观察者对象被 GC 引用（不会意外回收）。

> 为什么用 `TArray<TObjectPtr<UObject>>` 而不是具体类型？因为要存两个不同的观察者类型，用基类 `UObject` 统一管理。

### 7. `// checked` 注释

```cpp
// checked
UCLASS()
class UTenkaichiGameFeature_HotfixManager : ...
```

Lyra 源码里的 `// checked` 是开发者的笔记（"已检查过这个类"）。按铁律 28 注释中文化 → `// 已检查`。

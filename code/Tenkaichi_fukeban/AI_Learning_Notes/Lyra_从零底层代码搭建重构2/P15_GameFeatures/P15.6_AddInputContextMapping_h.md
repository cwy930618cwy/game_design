## 二、关键点讲解

### 1. `FInputMappingContextAndPriority` 结构体

```cpp
USTRUCT()
struct FInputMappingContextAndPriority
{
	UPROPERTY(...) TSoftObjectPtr<UInputMappingContext> InputMapping;
	UPROPERTY(...) int32 Priority = 0;
	UPROPERTY(...) bool bRegisterWithSettings = true;
};
```

三个字段：IMC 资产（软引用）+ 优先级（数值大优先）+ 是否注册到 Settings。

### 2. 四个 hook（比 P15.5 多两个）

```cpp
virtual void OnGameFeatureRegistering() override;      // 注册（Settings）
virtual void OnGameFeatureActivating(...) override;    // 激活（玩家输入）
virtual void OnGameFeatureDeactivating(...) override;  // 停用
virtual void OnGameFeatureUnregistering() override;    // 注销（Settings）
```

对比 P15.5 只有 Activating/Deactivating。**Registering/Unregistering 是进程级**（插件注册到系统时），**Activating/Deactivating 是 world 级**。

### 3. 六个 Register/Unregister 方法（两级）

```cpp
// 进程级入口
void RegisterInputMappingContexts();          // 绑 OnStartGameInstance + 遍历所有 GameInstance
void UnregisterInputMappingContexts();
// GameInstance 级
void RegisterInputContextMappingsForGameInstance(UGameInstance*);
void UnregisterInputContextMappingsForGameInstance(UGameInstance*);
// LocalPlayer 级
void RegisterInputMappingContextsForLocalPlayer(ULocalPlayer*);
void UnregisterInputMappingContextsForLocalPlayer(ULocalPlayer*);
```

三级嵌套：All → 每个 GameInstance → 每个 LocalPlayer。这样保证"新 GameInstance 出现"和"新 LocalPlayer 加入"时都能补注册。

### 4. `RegisterInputContextMappingsForGameInstanceHandle`

```cpp
FDelegateHandle RegisterInputContextMappingsForGameInstanceHandle;
```

存 `OnStartGameInstance` 的绑定句柄（`.cpp` 里 `RegisterInputMappingContexts` 注册、`UnregisterInputMappingContexts` 移除）。

### 5. `FPerContextData` 用 `TWeakObjectPtr<APlayerController>`

```cpp
TArray<TWeakObjectPtr<APlayerController>> ControllersAddedTo;
```

对比 P15.5 是 `APawn`，这里是 `APlayerController`（因为 IMC 加到"玩家控制器"的本地玩家子系统上，不是 Pawn）。

### 6. `AddInputMappingForPlayer(UPlayer* Player, ...)` 参数类型

```cpp
void AddInputMappingForPlayer(UPlayer* Player, FPerContextData& ActiveData);
```

参数是 **`UPlayer*`**（不是 `APawn*`）——因为它从 `APlayerController->GetLocalPlayer()` 拿 Player，可能不是 LocalPlayer（`.cpp` 里再 `Cast<ULocalPlayer>`）。

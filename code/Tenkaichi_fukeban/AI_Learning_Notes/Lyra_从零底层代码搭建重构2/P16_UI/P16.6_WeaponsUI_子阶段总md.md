## 一、这 6 个类是什么

| 类 | 类型 | 作用 |
|----|------|------|
| `UTenkaichiWeaponUserInterface` | `UCommonUserWidget` | 武器 UI 基类（监听武器切换） |
| `UTenkaichiReticleWidgetBase` | `UCommonUserWidget` | 准星基类（算散布角度/最大半径） |
| `SCircumferenceMarkerWidget` | **Slate 控件**（`SLeafWidget`） | 圆周标记的 Slate 实现（画） |
| `UCircumferenceMarkerWidget` | `UWidget` | 圆周标记的 UMG 包装（数据 + 转 Slate） |
| `SHitMarkerConfirmationWidget` | **Slate 控件** | 命中标记的 Slate 实现（画 + 动画） |
| `UHitMarkerConfirmationWidget` | `UWidget` | 命中标记的 UMG 包装 |

### UMG ↔ Slate 的包装模式（关键概念）

```
UMG 层（UWidget）         Slate 层（SWidget）
UCircumferenceMarkerWidget  →  SCircumferenceMarkerWidget
   （属性/蓝图可配）              （真正绘制）
        ↓ RebuildWidget() 创建
```

- `UWidget`（UObject）：属性、编辑器可配、序列化。
- `SWidget`（Slate）：真正的渲染 + 交互逻辑。

> 这是 UE 自绘控件的标准做法：**U 层管数据，S 层管画**。

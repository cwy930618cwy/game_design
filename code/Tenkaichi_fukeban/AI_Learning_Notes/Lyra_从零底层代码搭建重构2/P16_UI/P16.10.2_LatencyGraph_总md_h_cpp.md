## 一、这两个类解决什么问题（先讲为什么）

性能面板除了显示"当前 FPS 数字"，还要显示**曲线图**（最近 N 帧的延迟走势）——一眼看出"卡顿是持续的还是偶发的"。

两个类分工：
| 类 | 层 | 作用 |
|----|----|------|
| `STenkaichiLatencyGraph` | **Slate** | 真正画折线（`OnPaint` + `MakeLines`） |
| `UTenkaichiPerfStatGraph` | **UMG** | 包装（`RebuildWidget` 创建 Slate + 转发 Setter） |

> 和 P16.6.3/6.4、P16.6.5/6.6 是**同一个 UMG↔Slate 包装模式**。

	MaxYAxisOfGraph = InArgs._MaxLatencyToGraph;
	LineColor = InArgs._LineColor;
	BackgroundColor = InArgs._BackgroundColor;

// 绘制：先画背景，再画折线。
int32 STenkaichiLatencyGraph::OnPaint(const FPaintArgs& Args, const FGeometry& AllottedGeometry, const FSlateRect& MyClippingRect,
	FSlateWindowElementList& OutDrawElements, int32 LayerId, const FWidgetStyle& InWidgetStyle, bool bParentEnabled) const
{
	int32 MaxLayerId = LayerId;

	// 画背景
	FSlateDrawElement::MakeRotatedBox(
		OutDrawElements,
		MaxLayerId,
		AllottedGeometry.ToPaintGeometry(),
		FCoreStyle::Get().GetBrush("BlackBrush"),
		ESlateDrawEffect::NoPixelSnapping,
		0,
		TOptional<FVector2D>(),
		FSlateDrawElement::RelativeToElement,
		BackgroundColor);

	// 我们需要把曲线图真正画在背景上面
	// 所以把层级加一
	MaxLayerId++;

	// 真正画曲线图
	DrawTotalLatency(AllottedGeometry, OutDrawElements, MaxLayerId);
	
	MaxLayerId++;

	return MaxLayerId;
}

	return DesiredSize;

## 四、关键点讲解

### 1. `SLATE_BEGIN_ARGS` 里设 `_Clipping`（新知识点）

```cpp
SLATE_BEGIN_ARGS(STenkaichiLatencyGraph)
	: _DesiredSize(150, 50),
	_MaxLatencyToGraph(33.0),
	_LineColor(255, 255, 255, 255),
	_BackgroundColor(0, 0, 0, 128)
{
	_Clipping = EWidgetClipping::ClipToBounds;   // ← 在函数体里设
}
```

`_Clipping` 是 `SWidget` 的**内置参数**（所有 Slate 控件都有）——在 `SLATE_BEGIN_ARGS` 的**函数体**里设默认值。

`ClipToBounds`：超出控件边界的绘制被裁掉（曲线不会画到外面）。

> 对比自定义参数（`_DesiredSize` 等）在**初始化列表**里设——`_Clipping` 是内置的，要在函数体里设。

### 2. `OnPaint` 里画背景（`MakeRotatedBox` + `BlackBrush`）

```cpp
FSlateDrawElement::MakeRotatedBox(
	OutDrawElements,
	MaxLayerId,
	AllottedGeometry.ToPaintGeometry(),          // 整个控件区域
	FCoreStyle::Get().GetBrush("BlackBrush"),     // 引擎内置黑刷
	ESlateDrawEffect::NoPixelSnapping,
	0,                                            // 旋转 0
	TOptional<FVector2D>(),
	FSlateDrawElement::RelativeToElement,
	BackgroundColor);                             // 用配置的背景色
```

`FCoreStyle::Get().GetBrush("BlackBrush")`：引擎内置的纯黑画刷（`CoreStyle` 里预定义）。

**技巧**：用"黑刷 + 自定义颜色"画任意纯色背景（不用自己建画刷）。

`NoPixelSnapping`：不做像素对齐（曲线图不需要，避免抖动）。

### 3. `DrawTotalLatency`——折线算法（挂起）

```cpp
const double XSlice = WidgetSize.X / static_cast<double>(GraphData->GetSampleSize());
...
GraphData->ForEachCurrentSample([&](const double Stat)
{
	double Y = WidgetSize.Y - FMath::Clamp((Stat * ScaleFactor), 0.0, MaxYAxisOfGraph) / MaxYAxisOfGraph * WidgetSize.Y;
	Y = FMath::Clamp(Y, Border, WidgetSize.Y - Border);

	Points.Emplace(XSlice * double(++i), Y);
});
```

**算法**：
1. `XSlice`：每个采样点的 X 间距（控件宽度 / 采样数）。
2. 遍历每个采样值 `Stat`：
   - `Stat * ScaleFactor`：缩放。
   - `Clamp(..., 0, MaxYAxisOfGraph)`：钳制到 Y 轴范围。
   - `/ MaxYAxisOfGraph * WidgetSize.Y`：归一化到像素高度。
   - `WidgetSize.Y - ...`：**Y 轴翻转**（Slate 的 Y 向下，但数值大的应该在上面）。
   - `Clamp(Y, Border, WidgetSize.Y - Border)`：留 1px 边距。
3. `Points.Emplace(XSlice * ++i, Y)`：加入点列表。

**`static TArray<FVector2D> Points`**：用 `static` 避免每帧分配（性能优化）。

> ⚠️ `static` 局部变量在**多线程/多实例**下不安全——但 Slate 绘制是单线程的，且同一时刻只有一个图在画，所以 OK。

### 4. `MakeLines`——画折线

```cpp
FSlateDrawElement::MakeLines(
	OutDrawElements,
	LayerId,
	AllottedGeometry.ToPaintGeometry(),
	Points,                          // 点列表
	ESlateDrawEffect::NoPixelSnapping,
	LineColor,
	false,                           // bAntialias
	LineThickness);                  // 线宽
```

`MakeLines(输出, 层级, 几何, 点数组, 效果, 颜色, 抗锯齿, 线宽)`：把点数组连成折线。

> 注释 `// Why does this not just draw a straight line??` 是 Lyra 开发者的吐槽（可能遇到过奇怪的绘制问题）。按铁律 28 中文化。

### 5. `UTenkaichiPerfStatGraph` 的 `SetClipping(EWidgetClipping::ClipToBounds)`

```cpp
UTenkaichiPerfStatGraph::UTenkaichiPerfStatGraph(const FObjectInitializer& ObjectInitializer)
	: Super(ObjectInitializer)
{
	SetClipping(EWidgetClipping::ClipToBounds);
}
```

`UWidget::SetClipping(...)`：UMG 层的裁剪设置（对应 Slate 的 `_Clipping`）。

**为什么两处都设？** 因为 UMG 层和 Slate 层是两套——UMG 的 `SetClipping` 会传给 Slate，但 Slate 的 `SLATE_BEGIN_ARGS` 里也设了（双保险）。

### 6. `SAssignNew(SlateLatencyGraph, STenkaichiLatencyGraph)`——创建并赋值

```cpp
TSharedRef<SWidget> UTenkaichiPerfStatGraph::RebuildWidget()
{
	return SAssignNew(SlateLatencyGraph, STenkaichiLatencyGraph);
}
```

`SAssignNew(变量, 类)`：创建 Slate 控件并赋给变量，**返回 `TSharedRef`**（可以直接 `return`）。

> 对比 P16.7.5-3 的 `SAssignNew(Indicator->CanvasHost, SBox)[...]`（带子控件）——这里没有子控件，所以直接返回。

### 7. 4 个 Setter 都是纯转发

```cpp
void UTenkaichiPerfStatGraph::SetLineColor(const FColor& InColor)
{
	SlateLatencyGraph->SetLineColor(InColor);
}
```

**注意**：这些 Setter **没有检查 `SlateLatencyGraph` 是否有效**（直接 `->`）。

> 因为调用时机保证在 `RebuildWidget` 之后（P16.10.3 的 `NativeConstruct` 里调）。按铁律 23 照抄。

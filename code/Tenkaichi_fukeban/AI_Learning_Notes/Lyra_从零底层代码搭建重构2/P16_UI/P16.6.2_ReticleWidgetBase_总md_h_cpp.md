## 一、这个类解决什么问题（先讲为什么）

准星（reticle）要**随武器散布动态变化**——开枪时准星张开（散布变大），静止时收缩。

要画准星，需要三个数：
1. **当前散布角度**（度）：武器基础散布 × 散布倍率。
2. **第一次射击是否精准**（first shot accuracy）：某些武器首枪无散布。
3. **散布在屏幕上的像素半径**：把"角度"换算成"屏幕像素"（准星画多大）。

`ULyraReticleWidgetBase` 就是从 P11 武器实例里算出这三个数，供蓝图绘制准星。

> **类比**：这是"准星的尺子"——它不画准星（蓝图画），只负责**测量**："现在散布多少度""屏幕上该多大""是不是精准首枪"。

### `TenkaichiReticleWidgetBase.cpp`（95 行）

```cpp
// 版权声明（可保留或省略，不影响编译）
#include "TenkaichiReticleWidgetBase.h"

#include "Inventory/TenkaichiInventoryItemInstance.h"
#include "Weapons/TenkaichiRangedWeaponInstance.h"
#include "Weapons/TenkaichiWeaponInstance.h"

#include UE_INLINE_GENERATED_CPP_BY_NAME(TenkaichiReticleWidgetBase)

// 构造函数：空实现。
UTenkaichiReticleWidgetBase::UTenkaichiReticleWidgetBase(const FObjectInitializer& ObjectInitializer)
	: Super(ObjectInitializer)
{
}

// 用指定武器初始化准星。
void UTenkaichiReticleWidgetBase::InitializeFromWeapon(UTenkaichiWeaponInstance* InWeapon)
{
	WeaponInstance = InWeapon;
	InventoryInstance = nullptr;
	if (WeaponInstance)
	{
		// 武器的 Instigator 实际是"库存物品实例"
		InventoryInstance = Cast<UTenkaichiInventoryItemInstance>(WeaponInstance->GetInstigator());
	}
	OnWeaponInitialized();
}


// 返回当前武器的直径散布角度（度）。
float UTenkaichiReticleWidgetBase::ComputeSpreadAngle() const
{
	if (const UTenkaichiRangedWeaponInstance* RangedWeapon = Cast<const UTenkaichiRangedWeaponInstance>(WeaponInstance))
	{
		const float BaseSpreadAngle = RangedWeapon->GetCalculatedSpreadAngle();
		const float SpreadAngleMultiplier = RangedWeapon->GetCalculatedSpreadAngleMultiplier();
		const float ActualSpreadAngle = BaseSpreadAngle * SpreadAngleMultiplier;

		return ActualSpreadAngle;
	}
	else
	{
		return 0.0f;
	}
}

// 是否处于"第一次射击精准"状态。
bool UTenkaichiReticleWidgetBase::HasFirstShotAccuracy() const
{
	if (const UTenkaichiRangedWeaponInstance* RangedWeapon = Cast<const UTenkaichiRangedWeaponInstance>(WeaponInstance))
	{
		return RangedWeapon->HasFirstShotAccuracy();
	}
	else
	{
		return false;
	}
}

// 返回当前武器的最大散布半径（屏幕空间像素）。
float UTenkaichiReticleWidgetBase::ComputeMaxScreenspaceSpreadRadius() const
{
	const float LongShotDistance = 10000.f;

	APlayerController* PC = GetOwningPlayer();
	if (PC && PC->PlayerCameraManager)
	{
		// 武器的散布可以想象成一个圆锥。要找到准星可视化的屏幕空间散布，
		// 我们在很远距离处圆锥边缘上创建一个点。那个点落在圆锥截面的边缘上。
		// 然后把它投影回屏幕。它到屏幕中心的距离就是散布半径。

		// 这不完全精确，因为相机位置和枪口之间有一些距离。

		const float SpreadRadiusRads = FMath::DegreesToRadians(ComputeSpreadAngle() * 0.5f);
		const float SpreadRadiusAtDistance = FMath::Tan(SpreadRadiusRads) * LongShotDistance;

		FVector CamPos;
		FRotator CamOrient;
		PC->PlayerCameraManager->GetCameraViewPoint(CamPos, CamOrient);

		FVector CamForwDir = CamOrient.RotateVector(FVector::ForwardVector);
		FVector CamUpDir   = CamOrient.RotateVector(FVector::UpVector);

		FVector OffsetTargetAtDistance = CamPos + (CamForwDir * LongShotDistance) + (CamUpDir * SpreadRadiusAtDistance);

		FVector2D OffsetTargetInScreenspace;

		if (PC->ProjectWorldLocationToScreen(OffsetTargetAtDistance, OffsetTargetInScreenspace, true))
		{
			int32 ViewportSizeX(0), ViewportSizeY(0);
			PC->GetViewportSize(ViewportSizeX, ViewportSizeY);

			const FVector2D ScreenSpaceCenter(FVector::FReal(ViewportSizeX) * 0.5f, FVector::FReal(ViewportSizeY) * 0.5f);

			return (OffsetTargetInScreenspace - ScreenSpaceCenter).Length();
		}
	}
	
	return 0.0f;
}
```

## 三、关键点讲解

### 1. `InitializeFromWeapon`——从武器拿库存物品

```cpp
WeaponInstance = InWeapon;
InventoryInstance = nullptr;
if (WeaponInstance)
{
	InventoryInstance = Cast<UTenkaichiInventoryItemInstance>(WeaponInstance->GetInstigator());
}
OnWeaponInitialized();
```

**注意**：武器的 `GetInstigator()` 实际返回的是 `UTenkaichiInventoryItemInstance`（P08 库存物品），不是 Pawn！

> 这是 P09/P11 的链条：库存物品（InventoryItem）→ 装备到槽位 → 武器实例（WeaponInstance）→ 其 Instigator 指回库存物品。

调用完 `OnWeaponInitialized()`（蓝图事件）让子类做初始化显示。

### 2. `Cast<const UTenkaichiRangedWeaponInstance>`——只处理远程武器

```cpp
if (const UTenkaichiRangedWeaponInstance* RangedWeapon = Cast<const UTenkaichiRangedWeaponInstance>(WeaponInstance))
{
	...
}
else
{
	return 0.0f;
}
```

**为什么转 `RangedWeapon`？** 因为只有**远程武器**（枪）有散布概念。近战武器（`UTenkaichiWeaponInstance` 但非 Ranged）返回 0（无散布）。

> P11.1 是 `UTenkaichiWeaponInstance`（基础），P11.2 是 `UTenkaichiRangedWeaponInstance`（远程子类，带散布）。

### 3. `ComputeSpreadAngle`——基础 × 倍率

```cpp
const float BaseSpreadAngle = RangedWeapon->GetCalculatedSpreadAngle();           // 基础散布
const float SpreadAngleMultiplier = RangedWeapon->GetCalculatedSpreadAngleMultiplier();  // 当前倍率
const float ActualSpreadAngle = BaseSpreadAngle * SpreadAngleMultiplier;
```

两个数相乘：
- `GetCalculatedSpreadAngle()`：武器配的**基础散布角**（度）。
- `GetCalculatedSpreadAngleMultiplier()`：**当前倍率**（静止 1.0，移动/开枪会变大）。

> 这两个方法都是 P11.2 `UTenkaichiRangedWeaponInstance` 的（已教）。

### 4. `ComputeMaxScreenspaceSpreadRadius`——角度 → 屏幕像素（最复杂）

**核心思路**（注释里说明）：

```
散布是圆锥 → 在远处（10000单位）圆锥边缘取一个点
            → 把那个点投影到屏幕
              → 它到屏幕中心的距离 = 屏幕散布半径（像素）
```

分步骤：
```cpp
// ① 半角转弧度，算远处圆锥半径
const float SpreadRadiusRads = FMath::DegreesToRadians(ComputeSpreadAngle() * 0.5f);
const float SpreadRadiusAtDistance = FMath::Tan(SpreadRadiusRads) * LongShotDistance;

// ② 拿相机位置和朝向
PC->PlayerCameraManager->GetCameraViewPoint(CamPos, CamOrient);

// ③ 算相机的"前"和"上"方向
FVector CamForwDir = CamOrient.RotateVector(FVector::ForwardVector);
FVector CamUpDir   = CamOrient.RotateVector(FVector::UpVector);

// ④ 目标点 = 相机位置 + 前方×距离 + 上方×圆锥半径
FVector OffsetTargetAtDistance = CamPos + (CamForwDir * LongShotDistance) + (CamUpDir * SpreadRadiusAtDistance);

// ⑤ 投影到屏幕
PC->ProjectWorldLocationToScreen(OffsetTargetAtDistance, OffsetTargetInScreenspace, true);

// ⑥ 到屏幕中心的距离 = 半径
return (OffsetTargetInScreenspace - ScreenSpaceCenter).Length();
```

**为什么乘 0.5？** 因为 `ComputeSpreadAngle` 返回的是**直径**角度（整个圆锥顶角），所以取半角算半径。

### 5. `ProjectWorldLocationToScreen(..., true)` 第三个参数

```cpp
PC->ProjectWorldLocationToScreen(OffsetTargetAtDistance, OffsetTargetInScreenspace, true);
```

第三个参数 `bPlayerViewportRelative = true`：返回的屏幕坐标**相对于玩家视口**（而不是整个窗口）。分屏时每个玩家视口不同，所以要相对化。

### 6. `FVector::FReal`——大世界坐标安全类型

```cpp
const FVector2D ScreenSpaceCenter(FVector::FReal(ViewportSizeX) * 0.5f, FVector::FReal(ViewportSizeY) * 0.5f);
```

`FVector::FReal`：`FVector` 内部用的浮点类型（双精度或单精度，取决于 `UE_LARGE_WORLD_COORDINATES`）。用它转换避免精度警告。

### 7. `HasFirstShotAccuracy`——委托给武器

```cpp
return RangedWeapon->HasFirstShotAccuracy();
```

直接问武器（P11.2 已实现该逻辑：武器允许首枪精准 + 当前处于最小散布）。

### 8. 全部 `BlueprintPure`（纯函数）

```cpp
UFUNCTION(BlueprintCallable, BlueprintPure)
float ComputeSpreadAngle() const;
```

`BlueprintPure`：蓝图里是**纯函数节点**（无执行引脚，只输出值）。适合"只读计算"。

## 一、这个类解决什么问题（先讲为什么）

性能统计面板（FPS/Ping/延迟）通常有**多个 stat 控件**，玩家可以逐个开关（比如"只显示 FPS，不显示 Ping"）。

`ULyraPerfStatContainerBase` 是**容器**：
1. 遍历自己 WidgetTree 里所有 `ULyraPerfStatWidgetBase` 子控件。
2. 按**用户设置**（每个 stat 的显示模式）决定每个子控件显示/隐藏。
3. 监听设置变化，实时更新。

> **类比**：这是"性能面板的开关总控"——它不显示数据，只决定"哪些数据显示"。

## 三、关键点讲解

### 1. `WidgetTree->ForEachWidget(...)`——遍历蓝图里所有控件

```cpp
check(WidgetTree);
WidgetTree->ForEachWidget([&](UWidget* Widget)
{
	if (UTenkaichiPerfStatWidgetBase* TypedWidget = Cast<UTenkaichiPerfStatWidgetBase>(Widget))
	{
		...
	}
});
```

`UWidgetTree::ForEachWidget(lambda)`：遍历这个 Widget Blueprint 里的**所有**控件（递归）。

**为什么用这个？** 因为容器不知道蓝图里放了哪些 stat 控件——只能遍历后 `Cast` 筛选。

> 对比"用 `BindWidget` 一个个声明"——那样每加一个 stat 就要改 C++。遍历更灵活。

### 2. 两级过滤（容器级 + 单个 stat 级）

```cpp
// ① 容器级：这个容器显示文字还是图表？
const bool bShowTextWidgets = (StatDisplayModeFilter == TextOnly) || (StatDisplayModeFilter == TextAndGraph);
const bool bShowGraphWidgets = (StatDisplayModeFilter == GraphOnly) || (StatDisplayModeFilter == TextAndGraph);

// ② 单个 stat 级：这个 stat 用户设成什么模式？
const ELyraStatDisplayMode SettingMode = UserSettings->GetPerfStatDisplayState(TypedWidget->GetStatToDisplay());
```

**两级**：
| 级别 | 来源 | 作用 |
|------|------|------|
| 容器级 | `StatDisplayModeFilter`（本类属性） | 这个容器整体显示文字/图表/两者 |
| 单个 stat 级 | `UserSettings->GetPerfStatDisplayState(stat)` | 这个 stat 用户设成什么 |

**最终**：`switch (SettingMode)` 里结合两级判断。

### 3. `switch` 四分支

```cpp
switch (SettingMode)
{
case ELyraStatDisplayMode::Hidden:       bShowWidget = false; break;
case ELyraStatDisplayMode::TextOnly:     bShowWidget = bShowTextWidgets; break;
case ELyraStatDisplayMode::GraphOnly:    bShowWidget = bShowGraphWidgets; break;
case ELyraStatDisplayMode::TextAndGraph: bShowWidget = bShowTextWidgets || bShowGraphWidgets; break;
}
```

**逻辑**：
- `Hidden`：用户关了这个 stat → 不显示。
- `TextOnly`：用户要文字 → 看容器是否显示文字。
- `GraphOnly`：用户要图表 → 看容器是否显示图表。
- `TextAndGraph`：用户要两者 → 容器显示任一即可。

### 4. `HitTestInvisible` vs `Collapsed`

```cpp
TypedWidget->SetVisibility(bShowWidget ? ESlateVisibility::HitTestInvisible : ESlateVisibility::Collapsed);
```

- `HitTestInvisible`：可见但**不吃鼠标**（性能面板不该拦截点击）。
- `Collapsed`：完全隐藏 + 不占布局。

> 和 P16.2.1 的 `UIManagerSubsystem` 用同样的选择（`SelfHitTestInvisible` / `Collapsed`）。

### 5. `OnPerfStatDisplayStateChanged()`——设置变化事件

```cpp
// NativeConstruct
UTenkaichiSettingsLocal::Get()->OnPerfStatDisplayStateChanged().AddUObject(this, &ThisClass::UpdateVisibilityOfChildren);

// NativeDestruct
UTenkaichiSettingsLocal::Get()->OnPerfStatDisplayStateChanged().RemoveAll(this);
```

`ULyraSettingsLocal::OnPerfStatDisplayStateChanged()`：返回一个**事件**（`DECLARE_EVENT`），玩家改设置时广播。

**效果**：玩家在设置里开关某个 stat → 面板立刻更新（不用重开）。

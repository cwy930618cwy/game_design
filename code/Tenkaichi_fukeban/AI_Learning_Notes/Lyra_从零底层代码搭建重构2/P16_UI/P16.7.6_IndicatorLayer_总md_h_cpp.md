## 一、这个类解决什么问题（先讲为什么）

P16.7.5 的 `SActorCanvas` 是 Slate 控件——**编辑器里用不了**。`UIndicatorLayer` 是它的 UMG 包装，让策划能在 HUD 的 Widget Blueprint 里拖一个"指示器层"。

> 和 P16.6.4（`UCircumferenceMarkerWidget`）、P16.6.6（`UHitMarkerConfirmationWidget`）是**同一个模式**。但这里有个新东西：**`SNew` 传自定义参数**（`FLocalPlayerContext` + `&ArrowBrush`）。

## 二、完整代码（可直接照抄）

### `IndicatorLayer.h`（31 行）

```cpp
// 版权声明（可保留或省略，不影响编译）
#pragma once

#include "Components/Widget.h"

#include "IndicatorLayer.generated.h"

class SActorCanvas;
class SWidget;
class UObject;

// 指示器层的 UMG 包装（内部是 SActorCanvas）。
UCLASS()
class UIndicatorLayer : public UWidget
{
	GENERATED_UCLASS_BODY()

public:
	/** 当 UI 被钳制到屏幕边缘、需要显示箭头时用的默认箭头画刷。 */
	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category=Appearance)
	FSlateBrush ArrowBrush;

protected:
	//~UWidget 接口开始
	// 释放 Slate 资源。
	virtual void ReleaseSlateResources(bool bReleaseChildren) override;
	// 重建 Slate 控件（创建 SActorCanvas）。
	virtual TSharedRef<SWidget> RebuildWidget() override;
	//~UWidget 接口结束

protected:
	// 内部 Slate 画布。
	TSharedPtr<SActorCanvas> MyActorCanvas;
};
```

### `IndicatorLayer.cpp`（44 行）

```cpp
// 版权声明（可保留或省略，不影响编译）
#include "IndicatorLayer.h"

#include "SActorCanvas.h"
#include "Widgets/Layout/SBox.h"

#include UE_INLINE_GENERATED_CPP_BY_NAME(IndicatorLayer)

class SWidget;

/////////////////////////////////////////////////////
// UIndicatorLayer

// 构造函数：标记为变量 + 设默认可见性。
UIndicatorLayer::UIndicatorLayer(const FObjectInitializer& ObjectInitializer)
	: Super(ObjectInitializer)
{
	bIsVariable = true;
	SetVisibility(ESlateVisibility::HitTestInvisible);
}

// 释放 Slate 资源。
void UIndicatorLayer::ReleaseSlateResources(bool bReleaseChildren)
{
	Super::ReleaseSlateResources(bReleaseChildren);

	MyActorCanvas.Reset();
}

// 重建 Slate 控件（创建 SActorCanvas）。
TSharedRef<SWidget> UIndicatorLayer::RebuildWidget()
{
	if (!IsDesignTime())
	{
		ULocalPlayer* LocalPlayer = GetOwningLocalPlayer();
		if (ensureMsgf(LocalPlayer, TEXT("Attempting to rebuild a UActorCanvas without a valid LocalPlayer!")))
		{
			MyActorCanvas = SNew(SActorCanvas, FLocalPlayerContext(LocalPlayer), &ArrowBrush);
			return MyActorCanvas.ToSharedRef();
		}
	}

	// 给它一个简单的盒子，NullWidget 从 UWidget 里用不安全
	return SNew(SBox);
}
```

## 三、关键点讲解

### 1. `GENERATED_UCLASS_BODY()`——因为要自定义构造函数

```cpp
UCLASS()
class UIndicatorLayer : public UWidget
{
	GENERATED_UCLASS_BODY()
```

对比 P16.6.4/6.6 用的 `GENERATED_BODY()`。

**区别**：
- `GENERATED_BODY()`：自动生成默认构造函数。
- `GENERATED_UCLASS_BODY()`：**不生成**构造函数，要求你自己写（这里 `.cpp` 里写了 `UIndicatorLayer(const FObjectInitializer&)`）。

> P13.6 的 `UAsyncAction_ExperienceReady` 也是这个原因用 `GENERATED_UCLASS_BODY()`。

### 2. `bIsVariable = true`——允许蓝图变量引用

```cpp
bIsVariable = true;
```

`UWidget::bIsVariable`：这个控件是否作为**蓝图变量**暴露（可以在蓝图里用 `Get` 节点拿到它）。

> 因为指示器层可能需要在蓝图里动态操作（比如临时隐藏），所以设为 true。

### 3. `SNew(SActorCanvas, FLocalPlayerContext(LocalPlayer), &ArrowBrush)`——传自定义参数

```cpp
MyActorCanvas = SNew(SActorCanvas, FLocalPlayerContext(LocalPlayer), &ArrowBrush);
```

对应 P16.7.5-2 的声明：
```cpp
void Construct(const FArguments& InArgs, const FLocalPlayerContext& InCtx, const FSlateBrush* ActorCanvasArrowBrush);
```

**两个自定义参数**：
1. `FLocalPlayerContext(LocalPlayer)`：本地玩家上下文（临时构造，`Construct` 里会拷贝）。
2. `&ArrowBrush`：箭头画刷的**地址**（Slate 直接读 UMG 那份数据，零拷贝共享）。

> 和 P16.6.6 的 `SNew(SHitMarkerConfirmationWidget, PlayerContextRef, PerHitMarkerZoneOverrideImages)` 是同一模式。

### 4. `IsDesignTime()`——编辑器设计器保护

```cpp
if (!IsDesignTime())
{
	...
}
```

`IsDesignTime()`：是否在 UMG **设计器**里（不是运行时）。

**为什么？** 因为设计器里没有真实的 LocalPlayer，`SActorCanvas` 无法工作。所以设计器里返回一个空 `SBox`（占位）。

### 5. `ensureMsgf(LocalPlayer, ...)`——带消息的断言

```cpp
if (ensureMsgf(LocalPlayer, TEXT("Attempting to rebuild a UActorCanvas without a valid LocalPlayer!")))
```

`ensureMsgf(条件, 格式, ...)`：条件为假时**打警告 + 打印自定义消息**（比 `ensure` 多一个消息参数）。

> 注意消息里写的是 `UActorCanvas`（Lyra 原文的旧类名，现在叫 `SActorCanvas`）——**Lyra 的笔误**，按铁律 23 照抄不改。

### 6. `return SNew(SBox);`——兜底返回

```cpp
// 给它一个简单的盒子，NullWidget 从 UWidget 里用不安全
return SNew(SBox);
```

**为什么不能返回 `SNullWidget`？** 注释说"NullWidget isn't safe to use from a UWidget"——因为 `UWidget` 体系期望一个真实的 Slate 控件（`SNullWidget` 是单例，被多个 UWidget 共享会出问题）。

所以返回一个**空的 `SBox`**（真实控件，但什么都不画）。

### 7. `ReleaseSlateResources` 里 `Reset()`

```cpp
void UIndicatorLayer::ReleaseSlateResources(bool bReleaseChildren)
{
	Super::ReleaseSlateResources(bReleaseChildren);

	MyActorCanvas.Reset();
}
```

和 P16.6.4/6.6 一样——必须 `Reset()` 释放 `TSharedPtr`，否则 Slate 控件泄漏。

### 8. 没有 `SynchronizeProperties`

这个类**没有**覆写 `SynchronizeProperties`——因为 `ArrowBrush` 只在 `RebuildWidget` 里传一次（Slate 层没有 Setter）。

> 同 P16.6.6 的情况（Slate 层无 Setter → 靠重建）。

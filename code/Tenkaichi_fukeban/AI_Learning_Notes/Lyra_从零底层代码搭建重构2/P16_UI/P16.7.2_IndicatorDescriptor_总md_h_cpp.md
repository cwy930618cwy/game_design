## 一、这个类解决什么问题（先讲为什么）

系统里同时有很多指示器（队友 3 个、任务 2 个、敌人 5 个）。每条都需要记：
- **绑在哪个 Actor 的哪个组件上**（世界位置来源）。
- **用哪个 UI 控件显示**。
- **怎么投影到屏幕**（只算点？算包围盒？算屏幕包围盒？）。
- **对齐/偏移/是否贴边/是否显示箭头/排序优先级**。

`UIndicatorDescriptor` 就是**一条指示器的完整数据**（纯数据类，不含绘制逻辑）。

另外它还带一个工具结构体 `FIndicatorProjection`——负责"把 3D 位置投影成屏幕位置"（这是 `SActorCanvas` 用的核心算法）。

> **类比**：`Descriptor` 是"一张任务卡的完整配置"，`FIndicatorProjection` 是"换算器"——把世界坐标换算成屏幕坐标。

```cpp
#include "Components/SceneComponent.h"
#include "Types/SlateEnums.h"

#define UE_API TENKAICHIGAME_API

class SWidget;

// 投影工具：把指示器的世界位置换算成屏幕位置（含深度）。
struct FIndicatorProjection
{
	// 执行投影：成功返回 true，结果写入 OutScreenPositionWithDepth（XY=屏幕位置，Z=深度）。
	bool Project(const UIndicatorDescriptor& IndicatorDescriptor, const FSceneViewProjectionData& InProjectionData, const FVector2f& ScreenSize, FVector& OutScreenPositionWithDepth);
};

// 指示器的投影模式（决定"用什么来算屏幕位置"）。
UENUM(BlueprintType)
enum class EActorCanvasProjectionMode : uint8
{
	ComponentPoint,             // 组件上的一个点
	ComponentBoundingBox,       // 组件的包围盒（算中心点）
	ComponentScreenBoundingBox, // 组件的"屏幕空间包围盒"（算包围盒的屏幕矩形）
	ActorBoundingBox,           // 整个 Actor 的包围盒（算中心点）
	ActorScreenBoundingBox      // 整个 Actor 的"屏幕空间包围盒"
};
```

### 讲解

**1. `FIndicatorProjection` 是纯 C++ 结构体（无 `USTRUCT`）**

```cpp
struct FIndicatorProjection
{
	bool Project(...);
};
```

没有 `USTRUCT()` = 不是反射类型，只在 C++ 内部用。它是"工具类"（只有一个方法）。

**2. 为什么返回 `FVector`（XY 屏幕位置 + Z 深度）？**

```cpp
FVector& OutScreenPositionWithDepth
```

- `X`/`Y` = 屏幕像素坐标。
- `Z` = 到相机的距离（用于**排序**——近的指示器画在上面）。

**3. `FVector2f`（float 版 Vector2D）**

```cpp
const FVector2f& ScreenSize
```

`FVector2f` 是 UE5 新增的"float 精度的 FVector2D"（`FVector2D` 默认是 double）。用于性能敏感的 Slate 代码。

**4. 5 种投影模式**

| 模式 | 算什么 | 用途 |
|------|--------|------|
| `ComponentPoint` | 组件位置（或 socket 位置）单点 | 简单标记 |
| `ComponentBoundingBox` | 组件包围盒 → 中心点 | 中等大小物体 |
| `ComponentScreenBoundingBox` | 组件包围盒 → **屏幕矩形** | 血条贴包围盒边缘 |
| `ActorBoundingBox` | 整个 Actor 包围盒 → 中心点 | 大物体 |
| `ActorScreenBoundingBox` | 整个 Actor 包围盒 → **屏幕矩形** | 大物体的血条 |

## 四、`.cpp` 完整代码（140 行）

```cpp
// 版权声明（可保留或省略，不影响编译）
#include "IndicatorDescriptor.h"

#include "Engine/LocalPlayer.h"
#include "SceneView.h"
#include "UI/IndicatorSystem/TenkaichiIndicatorManagerComponent.h"

#include UE_INLINE_GENERATED_CPP_BY_NAME(IndicatorDescriptor)

// 执行投影：把指示器的世界位置换算成屏幕位置（含深度）。
bool FIndicatorProjection::Project(const UIndicatorDescriptor& IndicatorDescriptor, const FSceneViewProjectionData& InProjectionData, const FVector2f& ScreenSize, FVector& OutScreenPositionWithDepth)
{
	if (USceneComponent* Component = IndicatorDescriptor.GetSceneComponent())
	{
		// ① 拿世界位置（有 socket 名就用 socket 变换，否则用组件位置）
		TOptional<FVector> WorldLocation;
		if (IndicatorDescriptor.GetComponentSocketName() != NAME_None)
		{
			WorldLocation = Component->GetSocketTransform(IndicatorDescriptor.GetComponentSocketName()).GetLocation();
		}
		else
		{
			WorldLocation = Component->GetComponentLocation();
		}

		// ② 加上世界偏移
		const FVector ProjectWorldLocation = WorldLocation.GetValue() + IndicatorDescriptor.GetWorldPositionOffset();
		const EActorCanvasProjectionMode ProjectionMode = IndicatorDescriptor.GetProjectionMode();
		
		switch (ProjectionMode)
		{
			case EActorCanvasProjectionMode::ComponentPoint:
			{
				if (WorldLocation.IsSet())
				{
					FVector2D OutScreenSpacePosition;
					// ③ 世界点 → 屏幕点
					const bool bInFrontOfCamera = ULocalPlayer::GetPixelPoint(InProjectionData, ProjectWorldLocation, OutScreenSpacePosition, &ScreenSize);

					// ④ 加屏幕偏移（在相机背后时 X 取反，让标记往另一侧偏）
					OutScreenSpacePosition.X += IndicatorDescriptor.GetScreenSpaceOffset().X * (bInFrontOfCamera ? 1 : -1);
					OutScreenSpacePosition.Y += IndicatorDescriptor.GetScreenSpaceOffset().Y;

					// ⑤ 相机背后的点会被投影到屏幕内，需要推到屏幕边缘
					if (!bInFrontOfCamera && FBox2f(FVector2f::Zero(), ScreenSize).IsInside((FVector2f)OutScreenSpacePosition))
					{
						const FVector2f CenterToPosition = (FVector2f(OutScreenSpacePosition) - (ScreenSize / 2)).GetSafeNormal();
						OutScreenSpacePosition = FVector2D((ScreenSize / 2) + CenterToPosition * ScreenSize);
					}

					// ⑥ 输出（Z = 到相机距离，用于排序）
					OutScreenPositionWithDepth = FVector(OutScreenSpacePosition.X, OutScreenSpacePosition.Y, FVector::Dist(InProjectionData.ViewOrigin, ProjectWorldLocation));

					return true;
				}

				return false;
			}
			case EActorCanvasProjectionMode::ComponentScreenBoundingBox:
			case EActorCanvasProjectionMode::ActorScreenBoundingBox:
			{
				// ⑦ 先拿包围盒（组件包围盒 or 整个 Actor 包围盒）
				FBox IndicatorBox;
				if (ProjectionMode == EActorCanvasProjectionMode::ActorScreenBoundingBox)
				{
					IndicatorBox = Component->GetOwner()->GetComponentsBoundingBox();
				}
				else
				{
					IndicatorBox = Component->Bounds.GetBox();
				}

				// ⑧ 包围盒 → 屏幕矩形（左下 LL / 右上 UR）
				FVector2D LL, UR;
				const bool bInFrontOfCamera = ULocalPlayer::GetPixelBoundingBox(InProjectionData, IndicatorBox, LL, UR, &ScreenSize);
			
				const FVector& BoundingBoxAnchor = IndicatorDescriptor.GetBoundingBoxAnchor();
				const FVector2D& ScreenSpaceOffset = IndicatorDescriptor.GetScreenSpaceOffset();

				// ⑨ 按锚点在这两个角之间插值
				FVector ScreenPositionWithDepth;
				ScreenPositionWithDepth.X = FMath::Lerp(LL.X, UR.X, BoundingBoxAnchor.X) + ScreenSpaceOffset.X * (bInFrontOfCamera ? 1 : -1);
				ScreenPositionWithDepth.Y = FMath::Lerp(LL.Y, UR.Y, BoundingBoxAnchor.Y) + ScreenSpaceOffset.Y;
				ScreenPositionWithDepth.Z = FVector::Dist(InProjectionData.ViewOrigin, ProjectWorldLocation);

				// ⑩ 相机背后处理（同 ⑤）
				const FVector2f ScreenSpacePosition = FVector2f(FVector2D(ScreenPositionWithDepth));
				if (!bInFrontOfCamera && FBox2f(FVector2f::Zero(), ScreenSize).IsInside(ScreenSpacePosition))
				{
					const FVector2f CenterToPosition = (ScreenSpacePosition - (ScreenSize / 2)).GetSafeNormal();
					const FVector2f ScreenPositionFromBehind = (ScreenSize / 2) + CenterToPosition * ScreenSize;
					ScreenPositionWithDepth.X = ScreenPositionFromBehind.X;
					ScreenPositionWithDepth.Y = ScreenPositionFromBehind.Y;
				}
				
				OutScreenPositionWithDepth = ScreenPositionWithDepth;
				return true;
			}
			case EActorCanvasProjectionMode::ActorBoundingBox:
			case EActorCanvasProjectionMode::ComponentBoundingBox:
			{
				// ⑪ 先拿包围盒（同上）
				FBox IndicatorBox;
				if (ProjectionMode == EActorCanvasProjectionMode::ActorBoundingBox)
				{
					IndicatorBox = Component->GetOwner()->GetComponentsBoundingBox();
				}
				else
				{
					IndicatorBox = Component->Bounds.GetBox();
				}

				// ⑫ 包围盒里按锚点算一个点（锚点 - 0.5 后乘尺寸）
				const FVector ProjectBoxPoint = IndicatorBox.GetCenter() + (IndicatorBox.GetSize() * (IndicatorDescriptor.GetBoundingBoxAnchor() - FVector(0.5)));

				FVector2D OutScreenSpacePosition;
				const bool bInFrontOfCamera = ULocalPlayer::GetPixelPoint(InProjectionData, ProjectBoxPoint, OutScreenSpacePosition, &ScreenSize);
				OutScreenSpacePosition.X += IndicatorDescriptor.GetScreenSpaceOffset().X * (bInFrontOfCamera ? 1 : -1);
				OutScreenSpacePosition.Y += IndicatorDescriptor.GetScreenSpaceOffset().Y;

				// ⑬ 相机背后处理（同 ⑤）
				if (!bInFrontOfCamera && FBox2f(FVector2f::Zero(), ScreenSize).IsInside((FVector2f)OutScreenSpacePosition))
				{
					const FVector2f CenterToPosition = (FVector2f(OutScreenSpacePosition) - (ScreenSize / 2)).GetSafeNormal();
					OutScreenSpacePosition = FVector2D((ScreenSize / 2) + CenterToPosition * ScreenSize);
				}

				OutScreenPositionWithDepth = FVector(OutScreenSpacePosition.X, OutScreenSpacePosition.Y, FVector::Dist(InProjectionData.ViewOrigin, ProjectBoxPoint));
					
				return true;
			}
		}
	}

	return false;
}

// 设置所属的指示器管理器（只能设一次）。
void UIndicatorDescriptor::SetIndicatorManagerComponent(UTenkaichiIndicatorManagerComponent* InManager)
{
	// 确保没人设过这个
	if (ensure(ManagerPtr.IsExplicitlyNull()))
	{
		ManagerPtr = InManager;
	}
}

// 从管理器注销自己（移除指示器）。
void UIndicatorDescriptor::UnregisterIndicator()
{
	if (UTenkaichiIndicatorManagerComponent* Manager = ManagerPtr.Get())
	{
		Manager->RemoveIndicator(this);
	}
}
```

## 五、关键点讲解

### 1. `GetPixelPoint` / `GetPixelBoundingBox`——引擎提供的"世界→屏幕"工具

```cpp
ULocalPlayer::GetPixelPoint(InProjectionData, ProjectWorldLocation, OutScreenSpacePosition, &ScreenSize);
ULocalPlayer::GetPixelBoundingBox(InProjectionData, IndicatorBox, LL, UR, &ScreenSize);
```

`ULocalPlayer` 的两个静态方法（`Engine/LocalPlayer.h`），做"世界坐标 → 屏幕像素"投影：
- `GetPixelPoint`：单个点 → 一个屏幕坐标。
- `GetPixelBoundingBox`：3D 包围盒 → 屏幕矩形（左下 + 右上两个角）。

**返回值 `bool bInFrontOfCamera`**：点在不在相机前面。**很关键**——因为在相机背后的点投影会"翻转"，需要特殊处理。

### 2. 相机背后的处理（三处重复的同一段逻辑）

```cpp
if (!bInFrontOfCamera && FBox2f(FVector2f::Zero(), ScreenSize).IsInside((FVector2f)OutScreenSpacePosition))
{
	// 把点从屏幕中心往外推，推到屏幕边缘
	const FVector2f CenterToPosition = (FVector2f(OutScreenSpacePosition) - (ScreenSize / 2)).GetSafeNormal();
	OutScreenSpacePosition = FVector2D((ScreenSize / 2) + CenterToPosition * ScreenSize);
}
```

**问题**：相机背后的点，投影公式会算出"镜像"的屏幕坐标（落在屏幕内），但实际它在身后不该显示在屏幕中间。

**解决**：如果"点在相机背后" **且** "投影结果落在屏幕内" → 从屏幕中心往那个方向推出去，推到**屏幕外**（`CenterToPosition * ScreenSize` 让距离足够远）。

> 这是"背后目标的方向指示"技巧——你能看到"目标在你身后那个方向"。

### 3. `ScreenSpaceOffset.X * (bInFrontOfCamera ? 1 : -1)`

```cpp
OutScreenSpacePosition.X += IndicatorDescriptor.GetScreenSpaceOffset().X * (bInFrontOfCamera ? 1 : -1);
```

**为什么只在相机背后时 X 取反？** 因为相机背后时屏幕左右是镜像的（你往左转，背后目标在屏幕上往右）。所以 X 偏移要反过来，视觉上才一致。

### 4. 包围盒两种算法的区别

| 模式 | 算法 | 输出 |
|------|------|------|
| `*ScreenBoundingBox` | `GetPixelBoundingBox` → 屏幕矩形 → **按锚点 Lerp** | 精确贴合屏幕上的包围盒边缘 |
| `*BoundingBox`（非 Screen） | 包围盒 → **3D 里算一个点** → `GetPixelPoint` | 只投一个点 |

**举例**：
- `ComponentScreenBoundingBox` + 锚点 `(0.5, 1.0, 0)` → 指示器贴在"屏幕上包围盒的底边中点"（适合血条在头顶/脚下的情况）。
- `ComponentBoundingBox` + 锚点 `(0.5, 1.0, 0)` → 3D 包围盒底边中点投影（3D 里的位置，不一定贴合屏幕矩形的边）。

### 5. `BoundingBoxAnchor` 的数学

```cpp
const FVector ProjectBoxPoint = IndicatorBox.GetCenter() + (IndicatorBox.GetSize() * (BoundingBoxAnchor - FVector(0.5)));
```

- `BoundingBoxAnchor` 是 0~1 的"归一化锚点"（0.5,0.5,0.5 = 中心）。
- `Anchor - 0.5` → 转成 -0.5~+0.5 的偏移比例。
- `× Size` → 转成实际世界偏移。
- `+ Center` → 得到世界坐标点。

> 例：锚点 `(0.5, 1.0, 0.5)` → Y 方向偏移 `(1.0-0.5) = +0.5 × Size.Y` → 盒子顶部。

### 6. 屏幕包围盒的 Lerp

```cpp
ScreenPositionWithDepth.X = FMath::Lerp(LL.X, UR.X, BoundingBoxAnchor.X);
ScreenPositionWithDepth.Y = FMath::Lerp(LL.Y, UR.Y, BoundingBoxAnchor.Y);
```

`LL`（左下）到 `UR`（右上）之间按锚点插值：
- 锚点 X = 0 → 左边缘。
- 锚点 X = 0.5 → 水平中心。
- 锚点 X = 1 → 右边缘。

### 7. `ensure(ManagerPtr.IsExplicitlyNull())`——只能设一次

```cpp
void UIndicatorDescriptor::SetIndicatorManagerComponent(UTenkaichiIndicatorManagerComponent* InManager)
{
	if (ensure(ManagerPtr.IsExplicitlyNull()))
	{
		ManagerPtr = InManager;
	}
}
```

`IsExplicitlyNull()`：弱指针**显式为空**（不是"对象已销毁"）。确保"从没被设置过"——防止两个管理器抢同一条指示器。

> `ensure` 而非 `check`：重复设置是逻辑错误但不该崩，打警告即可。

### 8. `friend class SActorCanvas;`——友元

```cpp
private:
	friend class SActorCanvas;
	...
	TWeakPtr<SWidget> Content;
	TWeakPtr<SWidget> CanvasHost;
```

`SActorCanvas` 需要读写 `Content`/`CanvasHost`（Slate 控件指针），所以声明友元让它访问私有成员。

> 这是"紧密协作的两个类"的常见做法——比加一堆 public 访问器更简洁。

### 9. `TWeakPtr<SWidget>`（Slate 弱指针）vs `TWeakObjectPtr`（UObject 弱指针）

```cpp
TWeakObjectPtr<UUserWidget> IndicatorWidget;   // UObject 弱引用
TWeakPtr<SWidget> Content;                     // Slate 弱引用
TWeakPtr<SWidget> CanvasHost;
```

**两套智能指针**：
- `TWeakObjectPtr<T>`：用于 `UObject` 体系（GC 管理）。
- `TWeakPtr<T>`：用于非 UObject（Slate 的 `SWidget` 是 `TSharedPtr` 管理的）。

> 这是 UE 里"两套内存管理"的体现：UObject 走 GC，Slate 走引用计数。

### 10. `TEnumAsByte<EHorizontalAlignment>`

```cpp
UPROPERTY()
TEnumAsByte<EHorizontalAlignment> HAlignment = HAlign_Center;
```

`TEnumAsByte<T>`：包装一个 `uint8` 存储的枚举（`EHorizontalAlignment` 是 `namespace` 里的 `enum`，不是 `enum class`）。

> 这是 UE 里对"旧式枚举"的标准包装（`UPROPERTY` 需要）。

### 11. 所有访问器都是内联

注意 `.h` 里几十个 getter/setter **全是内联实现**（函数体直接写在类里）。只有 3 个方法在 `.cpp`：
- `FIndicatorProjection::Project`
- `SetIndicatorManagerComponent`
- `UnregisterIndicator`

> 因为 getter/setter 都只是一行赋值/返回，内联没有额外开销。

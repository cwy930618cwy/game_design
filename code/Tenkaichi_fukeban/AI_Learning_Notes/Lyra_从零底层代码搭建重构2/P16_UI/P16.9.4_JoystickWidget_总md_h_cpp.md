## 一、这个类解决什么问题（先讲为什么）

移动端需要**虚拟摇杆**——玩家手指按在屏幕某处，拖动产生方向向量（-1~1），模拟手柄摇杆。

`ULyraJoystickWidget` 继承 P16.9.2 的 `UTenkaichiSimulatedInputWidget`，做三件事：
1. **算触摸偏移**：手指位置 - 摇杆中心 = 偏移向量。
2. **钳制到 `StickRange`**：偏移长度不能超过摇杆范围（`StickRange = 50`）。
3. **归一化成 -1~1**：`StickVector = 偏移 / StickRange`，然后 `InputKeyValue2D(StickVector)` 注入。

同时**移动前景图**（`JoystickForeground`）——让玩家看到"摇杆头跟着手指动"。

> **类比**：这是"真摇杆"——P16.9.3 的 TouchRegion 是"按钮"（按了就是 1），这个是"摇杆"（按哪推多少就是多少）。

## 二、完整代码：`.h`（80 行）

```cpp
// 版权声明（可保留或省略，不影响编译）
#pragma once

#include "UI/TenkaichiSimulatedInputWidget.h"

#include "TenkaichiJoystickWidget.generated.h"

#define UE_API TENKAICHIGAME_API

class UImage;
class UObject;
struct FGeometry;
struct FPointerEvent;

/**
 *  Tenkaichi 虚拟摇杆的 UMG 包装。
 *
 *  这会计算一个钳制在 -1 到 1 之间的二维向量，
 *  作为键值输入给玩家，模拟手柄模拟摇杆。
 *
 *  这是为配合增强输入玩家使用而设计的。
 */
UCLASS(MinimalAPI, meta=( DisplayName="Tenkaichi Joystick" ))
class UTenkaichiJoystickWidget : public UTenkaichiSimulatedInputWidget
{
	GENERATED_BODY()
	
public:
	
	// 构造函数：开启"消费指针输入"。
	UE_API UTenkaichiJoystickWidget(const FObjectInitializer& ObjectInitializer);

	//~UUserWidget 接口开始
	// 触摸开始（记录原点 + 捕获鼠标）。
	UE_API virtual FReply NativeOnTouchStarted(const FGeometry& InGeometry, const FPointerEvent& InGestureEvent) override;
	// 触摸移动（算偏移 + 捕获鼠标）。
	UE_API virtual FReply NativeOnTouchMoved(const FGeometry& InGeometry, const FPointerEvent& InGestureEvent) override;
	// 触摸结束（停止模拟 + 释放鼠标）。
	UE_API virtual FReply NativeOnTouchEnded(const FGeometry& InGeometry, const FPointerEvent& InGestureEvent) override;
	// 鼠标离开（停止模拟）。
	UE_API virtual void NativeOnMouseLeave(const FPointerEvent& InMouseEvent) override;
	// 每帧 Tick（移动前景图 + 注入输入）。
	UE_API virtual void NativeTick(const FGeometry& MyGeometry, float InDeltaTime) override;
	//~UUserWidget 接口结束
	
protected:

	/**
	 * 计算当前触摸相对原点的偏移位置。
	 *
	 * 在玩家身上输入关联的手柄键
	 *
	 * 让前景摇杆图跟着给定输入移动，营造"跟着玩家手指动"的视觉效果
	 */
	UE_API void HandleTouchDelta(const FGeometry& InGeometry, const FPointerEvent& InGestureEvent);
	
	/** 清空已注入的玩家输入，并禁用这个模拟摇杆。 */
	UE_API void StopInputSimulation();

	/** 摇杆内部图片最多能移动多远？ */
	UPROPERTY(BlueprintReadOnly, EditAnywhere)
	float StickRange = 50.0f;

	/** 用作摇杆背景的图片 */
	UPROPERTY(BlueprintReadWrite, meta = (BindWidget))
	TObjectPtr<UImage> JoystickBackground;

	/** 用作摇杆前景的图片 */
	UPROPERTY(BlueprintReadWrite, meta = (BindWidget))
	TObjectPtr<UImage> JoystickForeground;

	/** 是否要反转摇杆的 Y 轴值？这对"移动"摇杆很常见 */
	UPROPERTY(BlueprintReadWrite, EditAnywhere)
	bool bNegateYAxis = false;

	/** 触摸的原点。在 NativeOnTouchStarted 里设置 */
	UPROPERTY(Transient)
	FVector2D TouchOrigin = FVector2D::ZeroVector;

	// 摇杆向量（-1~1）。
	UPROPERTY(Transient)
	FVector2D StickVector = FVector2D::ZeroVector;
};

#undef UE_API
```

## 三、完整代码：`.cpp`（108 行）

```cpp
// 版权声明（可保留或省略，不影响编译）
#include "UI/TenkaichiJoystickWidget.h"

#include "CommonHardwareVisibilityBorder.h"
#include "Components/Image.h"

#include UE_INLINE_GENERATED_CPP_BY_NAME(TenkaichiJoystickWidget)

#define LOCTEXT_NAMESPACE "TenkaichiJoystick"

// 构造函数：开启"消费指针输入"。
UTenkaichiJoystickWidget::UTenkaichiJoystickWidget(const FObjectInitializer& ObjectInitializer)
	: Super(ObjectInitializer)
{
	SetConsumePointerInput(true);
}

// 触摸开始（记录原点 + 捕获鼠标）。
FReply UTenkaichiJoystickWidget::NativeOnTouchStarted(const FGeometry& InGeometry, const FPointerEvent& InGestureEvent)
{
	Super::NativeOnTouchStarted(InGeometry, InGestureEvent);
	
	TouchOrigin = InGestureEvent.GetScreenSpacePosition();

	FReply Reply = FReply::Handled();
	if (!HasMouseCaptureByUser(InGestureEvent.GetUserIndex(), InGestureEvent.GetPointerIndex()))
	{
		Reply.CaptureMouse(GetCachedWidget().ToSharedRef());
	}
	return Reply;
}

// 触摸移动（算偏移 + 捕获鼠标）。
FReply UTenkaichiJoystickWidget::NativeOnTouchMoved(const FGeometry& InGeometry, const FPointerEvent& InGestureEvent)
{
	Super::NativeOnTouchMoved(InGeometry, InGestureEvent);
	HandleTouchDelta(InGeometry, InGestureEvent);

	FReply Reply = FReply::Handled();
	if (!HasMouseCaptureByUser(InGestureEvent.GetUserIndex(), InGestureEvent.GetPointerIndex()))
	{
		Reply.CaptureMouse(GetCachedWidget().ToSharedRef());
	}
	return Reply;
}

// 触摸结束（停止模拟 + 释放鼠标）。
FReply UTenkaichiJoystickWidget::NativeOnTouchEnded(const FGeometry& InGeometry, const FPointerEvent& InGestureEvent)
{
	StopInputSimulation();
	return FReply::Handled().ReleaseMouseCapture();
}

// 鼠标离开（停止模拟）。
void UTenkaichiJoystickWidget::NativeOnMouseLeave(const FPointerEvent& InMouseEvent)
{
	Super::NativeOnMouseLeave(InMouseEvent);
	StopInputSimulation();
}

// 每帧 Tick（移动前景图 + 注入输入）。
void UTenkaichiJoystickWidget::NativeTick(const FGeometry& MyGeometry, float InDeltaTime)
{
	Super::NativeTick(MyGeometry, InDeltaTime);

	if (!CommonVisibilityBorder || CommonVisibilityBorder->IsVisible())
	{
		// 让内部摇杆图标跟着向量移动
		if (JoystickForeground && JoystickBackground)
		{
			JoystickForeground->SetRenderTranslation(
				(bNegateYAxis ? FVector2D(1.0f, -1.0f) : FVector2D(1.0f)) *
				StickVector *
				(JoystickBackground->GetDesiredSize() * 0.5f)
			);
		}
		InputKeyValue2D(StickVector);
	}
}

// 计算当前触摸相对原点的偏移位置。
void UTenkaichiJoystickWidget::HandleTouchDelta(const FGeometry& InGeometry, const FPointerEvent& InGestureEvent)
{
	const FVector2D& ScreenSpacePos = InGestureEvent.GetScreenSpacePosition();
	
	// 几何的本地中心就是它的大小
	FVector2D LocalStickCenter = InGeometry.GetAbsoluteSize();

	FVector2D ScreenSpaceStickCenter = InGeometry.LocalToAbsolute(LocalStickCenter);
	// 取相对原点的偏移
	FVector2D MoveStickOffset = (ScreenSpacePos - ScreenSpaceStickCenter);
	if (bNegateYAxis)
	{
		MoveStickOffset *= FVector2D(1.0f, -1.0f);
	}
	
	FVector2D MoveStickDir = FVector2D::ZeroVector;
	float MoveStickLength = 0.0f;
	MoveStickOffset.ToDirectionAndLength(MoveStickDir, MoveStickLength);

	MoveStickLength = FMath::Min(MoveStickLength, StickRange);
	MoveStickOffset = MoveStickDir * MoveStickLength;

	StickVector = MoveStickOffset / StickRange;
}

// 清空已注入的玩家输入，并禁用这个模拟摇杆。
void UTenkaichiJoystickWidget::StopInputSimulation()
{
	TouchOrigin = FVector2D::ZeroVector;
	StickVector = FVector2D::ZeroVector;
}

#undef LOCTEXT_NAMESPACE
```

## 四、关键点讲解

### 1. `HandleTouchDelta`——核心算法（4 步）

```cpp
// ① 算摇杆中心（屏幕空间）
FVector2D LocalStickCenter = InGeometry.GetAbsoluteSize();          // 本地中心 = 尺寸（注意：不是尺寸/2！）
FVector2D ScreenSpaceStickCenter = InGeometry.LocalToAbsolute(LocalStickCenter);

// ② 算偏移
FVector2D MoveStickOffset = (ScreenSpacePos - ScreenSpaceStickCenter);
if (bNegateYAxis) { MoveStickOffset *= FVector2D(1.0f, -1.0f); }

// ③ 拆成"方向 + 长度"，长度钳制到 StickRange
MoveStickOffset.ToDirectionAndLength(MoveStickDir, MoveStickLength);
MoveStickLength = FMath::Min(MoveStickLength, StickRange);
MoveStickOffset = MoveStickDir * MoveStickLength;

// ④ 归一化成 -1~1
StickVector = MoveStickOffset / StickRange;
```

**⚠️ 注意 ① 的注释**：
```cpp
// The center of the geo locally is just its size
FVector2D LocalStickCenter = InGeometry.GetAbsoluteSize();
```

**Lyra 的写法是"本地中心 = 尺寸"**（不是 `尺寸 * 0.5`）——这看起来是**bug**（中心应该是尺寸的一半）。

但注释明确说"the center of the geo locally is just its size"——可能 Lyra 的摇杆控件布局特殊（比如 pivot 在右下角）。按铁律 23 **照抄不改**。

### 2. `ToDirectionAndLength`——拆方向 + 长度

```cpp
MoveStickOffset.ToDirectionAndLength(MoveStickDir, MoveStickLength);
```

`FVector2D::ToDirectionAndLength(OutDir, OutLength)`：把向量拆成"单位方向 + 长度"。

**为什么拆？** 因为要**只钳制长度**（方向不变）：
```cpp
MoveStickLength = FMath::Min(MoveStickLength, StickRange);   // 长度钳制
MoveStickOffset = MoveStickDir * MoveStickLength;            // 重组
```

### 3. `StickVector = MoveStickOffset / StickRange`——归一化

```cpp
StickVector = MoveStickOffset / StickRange;
```

因为 `MoveStickLength <= StickRange`，所以 `StickVector` 的模长 `<= 1` —— 正好是摇杆的 -1~1 范围。

### 4. `NativeTick` 里移动前景图

```cpp
JoystickForeground->SetRenderTranslation(
	(bNegateYAxis ? FVector2D(1.0f, -1.0f) : FVector2D(1.0f)) *
	StickVector *
	(JoystickBackground->GetDesiredSize() * 0.5f)
);
```

**三段相乘**：
1. `(bNegateYAxis ? (1,-1) : (1,1))`：Y 轴反转（如果需要）。
2. `StickVector`：-1~1 的摇杆向量。
3. `JoystickBackground->GetDesiredSize() * 0.5f`：背景尺寸的一半（最大位移）。

**效果**：前景图跟着手指移动，最大偏移 = 背景半径。

> `SetRenderTranslation`：只改**渲染**位置（不改布局位置）——性能好，适合每帧更新。

### 5. `CaptureMouse` / `ReleaseMouseCapture`——鼠标捕获

```cpp
// 开始/移动时
if (!HasMouseCaptureByUser(InGestureEvent.GetUserIndex(), InGestureEvent.GetPointerIndex()))
{
	Reply.CaptureMouse(GetCachedWidget().ToSharedRef());
}

// 结束时
return FReply::Handled().ReleaseMouseCapture();
```

**为什么需要捕获？** 因为手指可能**移出摇杆区域**——捕获后，即使移出去，`Moved` 事件仍然发给摇杆（不会中断）。

`HasMouseCaptureByUser(用户索引, 指针索引)`：检查是否已捕获（避免重复捕获）。

> 注意用 `GetUserIndex()` + `GetPointerIndex()`（支持多点触控——每个手指独立）。

### 6. `NativeOnMouseLeave`——鼠标离开也停止

```cpp
void UTenkaichiJoystickWidget::NativeOnMouseLeave(const FPointerEvent& InMouseEvent)
{
	Super::NativeOnMouseLeave(InMouseEvent);
	StopInputSimulation();
}
```

**为什么？** 桌面端用鼠标拖摇杆时，鼠标移出控件区域要停止（否则摇杆卡住）。

> 移动端有 `CaptureMouse` 保护，但桌面端可能没捕获成功，所以加这个兜底。

### 7. `StopInputSimulation`——只清向量，不 flush

```cpp
void UTenkaichiJoystickWidget::StopInputSimulation()
{
	TouchOrigin = FVector2D::ZeroVector;
	StickVector = FVector2D::ZeroVector;
}
```

**注意**：它**没有**调 `FlushSimulatedInput()`（P16.9.2 的方法）！

**为什么？** 因为 `NativeTick` 里每帧都 `InputKeyValue2D(StickVector)`——`StickVector` 归零后，下一帧注入的就是 `(0,0)`（摇杆回中），自然就"松开"了。

> 对比 P16.9.3 TouchRegion 的 `NativeOnTouchEnded` 会调 `FlushSimulatedInput`（因为它是"按键"，需要显式松开）。

### 8. `CommonVisibilityBorder->IsVisible()` 检查

```cpp
if (!CommonVisibilityBorder || CommonVisibilityBorder->IsVisible())
{
	...
	InputKeyValue2D(StickVector);
}
```

`CommonVisibilityBorder`（P16.9.2 的 `BindWidget` 成员）：按硬件类型显示/隐藏的边框。

**逻辑**：如果没配边框（`!CommonVisibilityBorder`）**或**边框可见 → 才注入输入。

**效果**：在"不该显示摇杆的平台"（比如 PC）上，即使控件存在也不注入输入。

### 9. `TouchOrigin` 记录了但没用

```cpp
TouchOrigin = InGestureEvent.GetScreenSpacePosition();   // NativeOnTouchStarted 里记录
...
void UTenkaichiJoystickWidget::StopInputSimulation()
{
	TouchOrigin = FVector2D::ZeroVector;   // 清空
	...
}
```

**`TouchOrigin` 记录了但从未被读取**（`HandleTouchDelta` 用的是 `InGeometry` 的中心，不是 `TouchOrigin`）。

> 这是 Lyra 的**冗余成员**（可能早期版本用过）。按铁律 23 照抄保留。

## 一、这个类解决什么问题（先讲为什么）

`UCommonTabListWidgetBase` 是 CommonUI 的"标签页列表"——一排标签按钮 + 一个切换容器（每个标签对应一页内容）。

但它只提供"注册标签 ID + 按钮类"这种底层接口。实际项目需要：
- 每个标签带**标题文字 + 图标**。
- 标签可以被**隐藏**（不删，但看不见）。
- 标签内容控件**按需创建**（`TabContentType` 蓝图类）。
- 标签按钮创建后能**自动填标题图标**。

`ULyraTabListWidgetBase` 用 `FLyraTabDescriptor`（标签描述结构体）把这些都封装好，并用 `ILyraTabButtonInterface`（标签按钮接口）让按钮自己接收描述。

> **类比**：`UCommonTabListWidgetBase` 是"标签页骨架"，`ULyraTabListWidgetBase` 是"带目录卡片的标签页系统"——你给它一堆卡片描述（`FLyraTabDescriptor`），它自动建页、建按钮、填标题图标。

```cpp
// 版权声明（可保留或省略，不影响编译）
#pragma once

#include "CommonTabListWidgetBase.h"

#include "TenkaichiTabListWidgetBase.generated.h"

#define UE_API TENKAICHIGAME_API

class UCommonButtonBase;
class UCommonUserWidget;
class UObject;
class UWidget;
struct FFrame;

// 一个标签的描述：ID / 标题 / 图标 / 是否隐藏 / 按钮类 / 内容类 / 已创建的内容控件。
USTRUCT(BlueprintType)
struct FTenkaichiTabDescriptor
{
	GENERATED_BODY()

public:
	// 构造函数：默认不隐藏、内容控件为空。
	FTenkaichiTabDescriptor()
	: bHidden(false)
	, CreatedTabContentWidget(nullptr)
	{ }

	// 标签 ID（唯一标识）。
	UPROPERTY(EditAnywhere, BlueprintReadOnly)
	FName TabId;

	// 标签标题文字。
	UPROPERTY(EditAnywhere, BlueprintReadWrite)
	FText TabText;

	// 标签图标画刷。
	UPROPERTY(EditAnywhere, BlueprintReadWrite)
	FSlateBrush IconBrush;

	// 是否隐藏这个标签。
	UPROPERTY(EditAnywhere, BlueprintReadOnly)
	bool bHidden;

	// 标签按钮类。
	UPROPERTY(EditAnywhere, BlueprintReadOnly)
	TSubclassOf<UCommonButtonBase> TabButtonType;

	//TODO NDarnell - 这个应该改成 TSoftClassPtr<>，底层通用标签列表要能处理懒加载的标签内容构造。
	// 标签内容控件类。
	UPROPERTY(EditAnywhere, BlueprintReadOnly)
	TSubclassOf<UCommonUserWidget> TabContentType;

	// 已创建的标签内容控件（运行时生成）。
	UPROPERTY(Transient)
	TObjectPtr<UWidget> CreatedTabContentWidget;
};

// 标签按钮接口：让标签按钮接收自己的标签描述。
UINTERFACE(BlueprintType)
class UTenkaichiTabButtonInterface : public UInterface
{
	GENERATED_BODY()
};

// 标签按钮接口的 C++ 侧（实现它就能接收标签描述）。
class ITenkaichiTabButtonInterface
{
	GENERATED_BODY()

public:
	// 设置标签信息（蓝图原生事件）。
	UFUNCTION(BlueprintNativeEvent, Category = "Tab Button")
	void SetTabLabelInfo(const FTenkaichiTabDescriptor& TabDescriptor);
};

// 标签列表控件：带预注册标签信息。
UCLASS(MinimalAPI, Blueprintable, BlueprintType, Abstract, meta = (DisableNativeTick))
class UTenkaichiTabListWidgetBase : public UCommonTabListWidgetBase
{
	GENERATED_BODY()
	
public:
	// 获取某个预注册标签的信息。
	UFUNCTION(BlueprintCallable, BlueprintPure, Category = "Tab List")
	UE_API bool GetPreregisteredTabInfo(const FName TabNameId, FTenkaichiTabDescriptor& OutTabInfo);

	/** 获取所有预注册标签信息的辅助方法 */
	const TArray<FTenkaichiTabDescriptor>& GetAllPreregisteredTabInfos() { return PreregisteredTabInfoArray; }

	// 切换某个标签的隐藏状态（只能在 switcher 关联之前调）。
	UFUNCTION(BlueprintCallable, Category = "Tab List")
	UE_API void SetTabHiddenState(FName TabNameId, bool bHidden);

	// 运行时注册一个新标签。
	UFUNCTION(BlueprintCallable, Category = "Tab List")
	UE_API bool RegisterDynamicTab(const FTenkaichiTabDescriptor& TabDescriptor);

	// 第一个标签是否是激活状态。
	UFUNCTION(BlueprintCallable, Category = "Tab List")
	UE_API bool IsFirstTabActive() const;

	// 最后一个标签是否是激活状态。
	UFUNCTION(BlueprintCallable, Category = "Tab List")
	UE_API bool IsLastTabActive() const;

	// 某个标签是否可见。
	UFUNCTION(BlueprintCallable, BlueprintPure, Category = "Tab List")
	UE_API bool IsTabVisible(FName TabId);

	// 可见标签数量。
	UFUNCTION(BlueprintCallable, BlueprintPure, Category = "Tab List")
	UE_API int32 GetVisibleTabCount();

	/** 新标签创建时广播。允许创建后挂钩。 */
	DECLARE_DYNAMIC_MULTICAST_DELEGATE_TwoParams(FOnTabContentCreated, FName, TabId, UCommonUserWidget*, TabWidget);
	// C++ 原生版委托。
	DECLARE_EVENT_TwoParams(UTenkaichiTabListWidgetBase, FOnTabContentCreatedNative, FName /* TabId */, UCommonUserWidget* /* TabWidget */);

	/** 新标签创建时广播（蓝图可绑）。 */
	UPROPERTY(BlueprintAssignable, Category = "Tab List")
	FOnTabContentCreated OnTabContentCreated;
	// C++ 原生版事件。
	FOnTabContentCreatedNative OnTabContentCreatedNative;

protected:
	// UUserWidget 接口开始
	// 控件初始化。
	UE_API virtual void NativeOnInitialized() override;
	// 控件构造完成（建立标签）。
	UE_API virtual void NativeConstruct() override;
	// 控件销毁（移除标签内容）。
	UE_API virtual void NativeDestruct() override;
	// UUserWidget 接口结束

	// switcher 变化前的回调（移除旧内容）。
	UE_API virtual void HandlePreLinkedSwitcherChanged() override;
	// switcher 变化后的回调（重建标签）。
	UE_API virtual void HandlePostLinkedSwitcherChanged() override;

	// 标签创建完成的回调（填标签信息）。
	UE_API virtual void HandleTabCreation_Implementation(FName TabId, UCommonButtonBase* TabButton) override;

private:
	// 建立所有标签（创建内容 + 注册）。
	UE_API void SetupTabs();

	// 预注册的标签信息数组。
	UPROPERTY(EditAnywhere, meta=(TitleProperty="TabId"))
	TArray<FTenkaichiTabDescriptor> PreregisteredTabInfoArray;
	
	/**
	 * 存储运行时注册但还没创建的标签信息。
	 * 元素在创建后移除。
	 */
	UPROPERTY()
	TMap<FName, FTenkaichiTabDescriptor> PendingTabLabelInfoMap;
};

#undef UE_API
```

## 三、关键点拆解（`.h`）

### 1. 一个文件里 4 个声明

| 声明 | 作用 |
|------|------|
| `FTenkaichiTabDescriptor`（USTRUCT） | 标签描述数据 |
| `UTenkaichiTabButtonInterface`（UINTERFACE） | 接口的 UObject 壳 |
| `ITenkaichiTabButtonInterface` | 接口的 C++ 类（`I` 前缀） |
| `UTenkaichiTabListWidgetBase`（UCLASS） | 标签列表控件 |

### 2. `UINTERFACE` + `I` 前缀类的成对写法

```cpp
UINTERFACE(BlueprintType)
class UTenkaichiTabButtonInterface : public UInterface
{
	GENERATED_BODY()
};

class ITenkaichiTabButtonInterface
{
	GENERATED_BODY()
public:
	UFUNCTION(BlueprintNativeEvent, Category = "Tab Button")
	void SetTabLabelInfo(const FTenkaichiTabDescriptor& TabDescriptor);
};
```

UE 的接口需要**两个类**：
- `UTenkaichiTabButtonInterface`（`U` 前缀）：UObject 壳（给反射系统看）。
- `ITenkaichiTabButtonInterface`（`I` 前缀）：真正的 C++ 接口（成员函数在这）。

> 对比 P10 的 `IInteractableTarget`（也是同样模式）。

### 3. 两个委托（动态 + 原生）

```cpp
DECLARE_DYNAMIC_MULTICAST_DELEGATE_TwoParams(FOnTabContentCreated, FName, TabId, UCommonUserWidget*, TabWidget);
DECLARE_EVENT_TwoParams(UTenkaichiTabListWidgetBase, FOnTabContentCreatedNative, FName, UCommonUserWidget*);
```

- `DYNAMIC_MULTICAST`：蓝图可绑（`UPROPERTY(BlueprintAssignable)`）。
- `DECLARE_EVENT_TwoParams`：**C++ 专用事件**（更轻量，蓝图不可见，只有 C++ 能绑）。

两套并存——蓝图和 C++ 各有入口。

## 四、完整代码：`.cpp`（208 行）

```cpp
// 版权声明（可保留或省略，不影响编译）
#include "TenkaichiTabListWidgetBase.h"

#include "CommonAnimatedSwitcher.h"
#include "CommonButtonBase.h"

#include UE_INLINE_GENERATED_CPP_BY_NAME(TenkaichiTabListWidgetBase)

// 控件初始化。
void UTenkaichiTabListWidgetBase::NativeOnInitialized()
{
	Super::NativeOnInitialized();
}

// 控件构造完成（建立标签）。
void UTenkaichiTabListWidgetBase::NativeConstruct()
{
	Super::NativeConstruct();

	SetupTabs();
}

// 控件销毁（移除标签内容）。
void UTenkaichiTabListWidgetBase::NativeDestruct()
{
	for (FTenkaichiTabDescriptor& TabInfo : PreregisteredTabInfoArray)
	{
		if (TabInfo.CreatedTabContentWidget)
		{
			TabInfo.CreatedTabContentWidget->RemoveFromParent();
			TabInfo.CreatedTabContentWidget = nullptr;
		}
	}

	Super::NativeDestruct();
}

// 获取某个预注册标签的信息。
bool UTenkaichiTabListWidgetBase::GetPreregisteredTabInfo(const FName TabNameId, FTenkaichiTabDescriptor& OutTabInfo)
{
	const FTenkaichiTabDescriptor* const FoundTabInfo = PreregisteredTabInfoArray.FindByPredicate([&](FTenkaichiTabDescriptor& TabInfo) -> bool
	{
		return TabInfo.TabId == TabNameId;
	});

	if (!FoundTabInfo)
	{
		return false;
	}

	OutTabInfo = *FoundTabInfo;
	return true;
}

// 切换某个标签的隐藏状态。
void UTenkaichiTabListWidgetBase::SetTabHiddenState(FName TabNameId, bool bHidden)
{
	for (FTenkaichiTabDescriptor& TabInfo : PreregisteredTabInfoArray)
	{
		if (TabInfo.TabId == TabNameId)
		{
			TabInfo.bHidden = bHidden;
			break;
		}
	}
}

// 运行时注册一个新标签。
bool UTenkaichiTabListWidgetBase::RegisterDynamicTab(const FTenkaichiTabDescriptor& TabDescriptor)
{
	// 如果它是隐藏的就忽略。
	if (TabDescriptor.bHidden)
	{
		return true;
	}
	
	PendingTabLabelInfoMap.Add(TabDescriptor.TabId, TabDescriptor);

	return RegisterTab(TabDescriptor.TabId, TabDescriptor.TabButtonType, TabDescriptor.CreatedTabContentWidget);
}

// switcher 变化前的回调（移除旧内容）。
void UTenkaichiTabListWidgetBase::HandlePreLinkedSwitcherChanged()
{
	for (const FTenkaichiTabDescriptor& TabInfo : PreregisteredTabInfoArray)
	{
		// 从绑定的 switcher 移除标签内容控件，因为正在解除关联。
		if (TabInfo.CreatedTabContentWidget)
		{
			TabInfo.CreatedTabContentWidget->RemoveFromParent();
		}
	}

	Super::HandlePreLinkedSwitcherChanged();
}

// switcher 变化后的回调（重建标签）。
void UTenkaichiTabListWidgetBase::HandlePostLinkedSwitcherChanged()
{
	if (!IsDesignTime() && GetCachedWidget().IsValid())
	{
		// 在编辑器设计器里或还没构造完，就别建标签了
		SetupTabs();
	}

	Super::HandlePostLinkedSwitcherChanged();
}

// 标签创建完成的回调（填标签信息）。
void UTenkaichiTabListWidgetBase::HandleTabCreation_Implementation(FName TabId, UCommonButtonBase* TabButton)
{
	FTenkaichiTabDescriptor* TabInfoPtr = nullptr;
	
	FTenkaichiTabDescriptor TabInfo;
	if (GetPreregisteredTabInfo(TabId, TabInfo))
	{
		TabInfoPtr = &TabInfo;
	}
	else
	{
		TabInfoPtr = PendingTabLabelInfoMap.Find(TabId);
	}
	
	if (TabButton->GetClass()->ImplementsInterface(UTenkaichiTabButtonInterface::StaticClass()))
	{
		if (ensureMsgf(TabInfoPtr, TEXT("A tab button was created with id %s but no label info was specified. RegisterDynamicTab should be used over RegisterTab to provide label info."), *TabId.ToString()))
		{
			ITenkaichiTabButtonInterface::Execute_SetTabLabelInfo(TabButton, *TabInfoPtr);
		}
	}

	PendingTabLabelInfoMap.Remove(TabId);
}

// 第一个标签是否是激活状态。
bool UTenkaichiTabListWidgetBase::IsFirstTabActive() const
{
	if (PreregisteredTabInfoArray.Num() > 0)
	{
		return GetActiveTab() == PreregisteredTabInfoArray[0].TabId;
	}

	return false;
}

// 最后一个标签是否是激活状态。
bool UTenkaichiTabListWidgetBase::IsLastTabActive() const
{
	if (PreregisteredTabInfoArray.Num() > 0)
	{
		return GetActiveTab() == PreregisteredTabInfoArray.Last().TabId;
	}

	return false;
}

// 某个标签是否可见。
bool UTenkaichiTabListWidgetBase::IsTabVisible(FName TabId)
{
	if (const UCommonButtonBase* Button = GetTabButtonBaseByID(TabId))
	{
		const ESlateVisibility TabVisibility = Button->GetVisibility();
		return (TabVisibility == ESlateVisibility::Visible
			|| TabVisibility == ESlateVisibility::HitTestInvisible
			|| TabVisibility == ESlateVisibility::SelfHitTestInvisible);
	}

	return false;
}

// 可见标签数量。
int32 UTenkaichiTabListWidgetBase::GetVisibleTabCount()
{
	int32 Result = 0;
	const int32 TabCount = GetTabCount();
	for ( int32 Index = 0; Index < TabCount; Index++ )
	{
		if (IsTabVisible(GetTabIdAtIndex( Index )))
		{
			Result++;
		}
	}

	return Result;
}

// 建立所有标签（创建内容 + 注册）。
void UTenkaichiTabListWidgetBase::SetupTabs()
{
	for (FTenkaichiTabDescriptor& TabInfo : PreregisteredTabInfoArray)
	{
		if (TabInfo.bHidden)
		{
			continue;
		}

		// 如果标签内容还没创建过，就创建它。
		if (!TabInfo.CreatedTabContentWidget && TabInfo.TabContentType)
		{
			TabInfo.CreatedTabContentWidget = CreateWidget<UCommonUserWidget>(GetOwningPlayer(), TabInfo.TabContentType);
			OnTabContentCreatedNative.Broadcast(TabInfo.TabId, Cast<UCommonUserWidget>(TabInfo.CreatedTabContentWidget));
			OnTabContentCreated.Broadcast(TabInfo.TabId, Cast<UCommonUserWidget>(TabInfo.CreatedTabContentWidget));
		}

		if (UCommonAnimatedSwitcher* CurrentLinkedSwitcher = GetLinkedSwitcher())
		{
			// 把标签内容加到新绑定的 switcher 里。
			if (!CurrentLinkedSwitcher->HasChild(TabInfo.CreatedTabContentWidget))
			{
				CurrentLinkedSwitcher->AddChild(TabInfo.CreatedTabContentWidget);
			}
		}

		// 如果标签还没注册过，就注册它。
		if (GetTabButtonBaseByID(TabInfo.TabId) == nullptr)
		{
			RegisterTab(TabInfo.TabId, TabInfo.TabButtonType, TabInfo.CreatedTabContentWidget);
		}
	}
}
```

## 五、关键点拆解（`.cpp`）

### 1. `SetupTabs`——核心建页流程（三段）

```cpp
for (FTenkaichiTabDescriptor& TabInfo : PreregisteredTabInfoArray)
{
	if (TabInfo.bHidden) continue;                        // ① 隐藏的跳过

	if (!TabInfo.CreatedTabContentWidget && TabInfo.TabContentType)
	{
		TabInfo.CreatedTabContentWidget = CreateWidget<UCommonUserWidget>(GetOwningPlayer(), TabInfo.TabContentType);
		OnTabContentCreatedNative.Broadcast(...);          // ② 建内容 + 广播
		OnTabContentCreated.Broadcast(...);
	}

	if (UCommonAnimatedSwitcher* Switcher = GetLinkedSwitcher())
	{
		if (!Switcher->HasChild(TabInfo.CreatedTabContentWidget))
		{
			Switcher->AddChild(TabInfo.CreatedTabContentWidget);   // ③ 挂到 switcher
		}
	}

	if (GetTabButtonBaseByID(TabInfo.TabId) == nullptr)
	{
		RegisterTab(TabInfo.TabId, TabInfo.TabButtonType, ...);   // ④ 注册按钮
	}
}
```

**幂等设计**：每步都先检查"是否已做过"（`!CreatedTabContentWidget` / `!HasChild` / `== nullptr`），所以 `SetupTabs` 可以**重复调用**（`NativeConstruct` 和 `HandlePostLinkedSwitcherChanged` 都会调）。

### 2. `HandleTabCreation_Implementation`——填标签信息

```cpp
FTenkaichiTabDescriptor* TabInfoPtr = nullptr;
FTenkaichiTabDescriptor TabInfo;
if (GetPreregisteredTabInfo(TabId, TabInfo))     // 先从预注册里找（注意：拷到局部变量 TabInfo）
{
	TabInfoPtr = &TabInfo;                        // 指向局部变量
}
else
{
	TabInfoPtr = PendingTabLabelInfoMap.Find(TabId);   // 再从待注册 map 找（指向 map 内元素）
}

if (TabButton->GetClass()->ImplementsInterface(UTenkaichiTabButtonInterface::StaticClass()))
{
	if (ensureMsgf(TabInfoPtr, TEXT("..."), *TabId.ToString()))
	{
		ITenkaichiTabButtonInterface::Execute_SetTabLabelInfo(TabButton, *TabInfoPtr);
	}
}

PendingTabLabelInfoMap.Remove(TabId);
```

> ⚠️ 注意 `TabInfoPtr = &TabInfo` 指向的是**局部变量**——离开作用域就失效。但因为 `Execute_SetTabLabelInfo` 在同一个作用域内调用，所以安全（Lyra 这么写的）。

### 3. `Execute_SetTabLabelInfo`——执行接口方法

```cpp
ITenkaichiTabButtonInterface::Execute_SetTabLabelInfo(TabButton, *TabInfoPtr);
```

`I接口::Execute_方法名(对象, 参数...)`：**执行**接口的 `BlueprintNativeEvent` 方法（会正确分发到蓝图或 C++ 实现）。

> 这是 UE 接口的标准调用方式（不能直接 `对象->SetTabLabelInfo(...)`）。

### 4. `ImplementsInterface`——检查是否实现接口

```cpp
if (TabButton->GetClass()->ImplementsInterface(UTenkaichiTabButtonInterface::StaticClass()))
```

先检查按钮类是否实现了这个接口，没实现就跳过（不报错）。

### 5. `IsDesignTime()` + `GetCachedWidget().IsValid()`——编辑器保护

```cpp
if (!IsDesignTime() && GetCachedWidget().IsValid())
{
	SetupTabs();
}
```

- `IsDesignTime()`：是否在 UMG 设计器里（设计器里不该真建标签）。
- `GetCachedWidget().IsValid()`：Slate 控件是否已创建（没创建就没法建标签）。

### 6. `IsTabVisible`——三种"可见"

```cpp
return (TabVisibility == ESlateVisibility::Visible
	|| TabVisibility == ESlateVisibility::HitTestInvisible
	|| TabVisibility == ESlateVisibility::SelfHitTestInvisible);
```

三种都算"可见"（后两种是"看得见但不可交互"）。

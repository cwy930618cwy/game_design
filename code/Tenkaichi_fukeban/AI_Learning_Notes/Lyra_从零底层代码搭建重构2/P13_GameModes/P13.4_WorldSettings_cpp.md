## 一、完整代码（可直接照抄）

```cpp
// 版权声明（可保留或省略，不影响编译）
#include "TenkaichiWorldSettings.h"
#include "GameFramework/PlayerStart.h"
#include "EngineUtils.h"
#include "Misc/UObjectToken.h"
#include "Logging/MessageLog.h"
#include "TenkaichiLogChannels.h"
#include "Engine/AssetManager.h"

#include UE_INLINE_GENERATED_CPP_BY_NAME(TenkaichiWorldSettings)

// 构造函数：只调用父类构造，本类没有需要额外初始化的成员。
ATenkaichiWorldSettings::ATenkaichiWorldSettings(const FObjectInitializer& ObjectInitializer)
	: Super(ObjectInitializer)
{
}

// 返回这张地图默认要用的经验（解析成主资产 ID，供 AssetManager 加载）。
FPrimaryAssetId ATenkaichiWorldSettings::GetDefaultGameplayExperience() const
{
	FPrimaryAssetId Result;
	if (!DefaultGameplayExperience.IsNull())
	{
		// 把软引用路径交给引擎资产管理器，解析成主资产 ID。
		Result = UAssetManager::Get().GetPrimaryAssetIdForPath(DefaultGameplayExperience.ToSoftObjectPath());

		if (!Result.IsValid())
		{
			// 解析失败：说明这个软引用路径指不到一个合法的主资产（可能要在 GameFeature 插件或项目设置里加资产规则）。
			UE_LOG(LogTenkaichiExperience, Error, TEXT("%s.DefaultGameplayExperience is %s but that failed to resolve into an asset ID (you might need to add a path to the Asset Rules in your game feature plugin or project settings"),
				*GetPathNameSafe(this), *DefaultGameplayExperience.ToString());
		}
	}
	return Result;
}

#if WITH_EDITOR
// 地图检查时的校验：警告地图里放了普通的 APlayerStart，应换成 ATenkaichiPlayerStart。
void ATenkaichiWorldSettings::CheckForErrors()
{
	Super::CheckForErrors();

	// 消息日志分类 "MapCheck"，用于编辑器地图检查面板。
	FMessageLog MapCheck("MapCheck");

	// 遍历当前世界里的所有 APlayerStart 出生点。
	for (TActorIterator<APlayerStart> PlayerStartIt(GetWorld()); PlayerStartIt; ++PlayerStartIt)
	{
		APlayerStart* PlayerStart = *PlayerStartIt;
		if (IsValid(PlayerStart) && PlayerStart->GetClass() == APlayerStart::StaticClass())
		{
			// 普通 APlayerStart（不是 Lyra 自定义的子类）→ 警告用户换成 ATenkaichiPlayerStart。
			MapCheck.Warning()
				->AddToken(FUObjectToken::Create(PlayerStart))
				->AddToken(FTextToken::Create(FText::FromString("is a normal APlayerStart, replace with ATenkaichiPlayerStart.")));
		}
	}

	//@TODO: 确认这个软引用路径真的能解析成主资产 ID（例如不要指向一个没被扫描的目录里的经验）。
}
#endif
```

## 二、关键点讲解

### 1. 构造函数：空实现

```cpp
ATenkaichiWorldSettings::ATenkaichiWorldSettings(const FObjectInitializer& ObjectInitializer)
	: Super(ObjectInitializer)
{
}
```

本类没有需要初始化的成员（`DefaultGameplayExperience` 是 `TSoftClassPtr` 默认空，`ForceStandaloneNetMode` 有默认值 `false`），所以构造体空着，只把 `ObjectInitializer` 传给父类。

### 2. `GetDefaultGameplayExperience`：软引用 → 主资产 ID

```cpp
FPrimaryAssetId Result;
if (!DefaultGameplayExperience.IsNull())
{
	Result = UAssetManager::Get().GetPrimaryAssetIdForPath(DefaultGameplayExperience.ToSoftObjectPath());
	if (!Result.IsValid()) { UE_LOG(... Error ...); }
}
return Result;
```

- `IsNull()`：软引用是否为空（没配置）。
- `ToSoftObjectPath()`：把 `TSoftClassPtr` 转成 `FSoftObjectPath`（纯路径字符串）。
- `UAssetManager::Get()`：拿引擎资产管理器**单例**（`Engine/AssetManager.h`，引擎类，不是 P14 的 `ULyraAssetManager`）。
- `GetPrimaryAssetIdForPath(路径)`：把路径解析成主资产 ID，解析不出返回非法 ID。
- `UE_LOG(LogTenkaichiExperience, Error, ...)`：解析失败打 Error 日志（`LogTenkaichiExperience` 在 P02 已定义）。

### 3. `CheckForErrors`：编辑器地图检查

```cpp
FMessageLog MapCheck("MapCheck");
for (TActorIterator<APlayerStart> PlayerStartIt(GetWorld()); PlayerStartIt; ++PlayerStartIt)
{
	APlayerStart* PlayerStart = *PlayerStartIt;
	if (IsValid(PlayerStart) && PlayerStart->GetClass() == APlayerStart::StaticClass())
	{
		MapCheck.Warning()->AddToken(...)->AddToken(...);
	}
}
```

- `FMessageLog("MapCheck")`：编辑器"地图检查"面板的日志分类。
- `TActorIterator<APlayerStart>(GetWorld())`：**遍历世界里所有 `APlayerStart` 类型的 Actor**（`EngineUtils.h` 提供）。
- `GetClass() == APlayerStart::StaticClass()`：**精确判断**这个出生点是"普通 `APlayerStart`"还是它的子类（比如 `ATenkaichiPlayerStart`）。只有**普通** `APlayerStart` 才警告（因为 Lyra 希望用自定义的 `ATenkaichiPlayerStart` 出生点）。
- `MapCheck.Warning()->AddToken(...)->AddToken(...)`：链式添加两个消息 token——一个指向那个 Actor 对象（`FUObjectToken`），一个是文字说明（`FTextToken`），点消息能跳转到对应 Actor。

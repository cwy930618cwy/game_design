## 一、这个类解决什么问题（先讲为什么）

前面 P13.1 定义了"经验"（`UTenkaichiExperienceDefinition`，一局的剧本单），P13.4 让地图能指定"默认用哪个经验"。但**光有剧本单和默认指定还不够**——还缺一个"把剧本真正执行起来"的东西。

> **剧本单（ExperienceDefinition）只是数据，谁来照着它一步步把游戏开起来？**

答案就是这个组件：`UTenkaichiExperienceManagerComponent`。它挂在 **GameState** 上，负责**整个经验的加载状态机**——从"还没加载"一路走到"完全加载完、放玩家进来"。

它要做的事，按顺序：
1. 有人指定了要用的经验（`SetCurrentExperience`）
2. 加载这个经验相关的所有资产（Pawn、能力、GameFeature 插件等）
3. 激活经验里声明的 GameFeature 插件
4. 执行经验里的所有 Action（`UGameFeatureAction`，比如"给这个角色加输入映射"）
5. 全部完成后广播"经验加载完毕"，其他系统（角色生成、HUD 等）收到信号才开始干活

> **类比**：经验（Experience）是剧本单，`ExperienceManagerComponent` 是**舞台总监**。导演（GameMode）把剧本单交给他，他就一步步排戏：先装道具（加载资产）、再请演员（激活 GameFeature）、再念台词（执行 Action），全排完了喊一声"开演"（广播 loaded），台下的人才上场。

## 二、内部结构全景（这个类里有什么）

### 加载状态机（核心概念）

用一个枚举 `ELyraExperienceLoadState` 表示加载走到哪一步：

```
Unloaded（未加载）
  → Loading（加载资产中）
    → LoadingGameFeatures（激活 GameFeature 插件中）
      → LoadingChaosTestingDelay（可选：测试用随机延迟）
        → ExecutingActions（执行 Action 中）
          → Loaded（加载完成 ✅）
  → Deactivating（卸载中，退出时反向走）
```

### 公开方法（外部怎么用它）

| 方法 | 作用 |
|------|------|
| `SetCurrentExperience(FPrimaryAssetId)` | 指定要加载哪个经验，启动状态机 |
| `CallOrRegister_OnExperienceLoaded_HighPriority` | 注册"加载完成"回调（高优先级，先触发） |
| `CallOrRegister_OnExperienceLoaded` | 注册"加载完成"回调（普通优先级） |
| `CallOrRegister_OnExperienceLoaded_LowPriority` | 注册"加载完成"回调（低优先级，后触发） |
| `GetCurrentExperienceChecked()` | 拿当前经验（必须已 loaded，否则 assert） |
| `IsExperienceLoaded()` | 问"加载完了吗" |

### 私有方法（状态机内部流水线）

| 方法 | 作用 |
|------|------|
| `OnRep_CurrentExperience` | 网络复制回调：客户端收到经验后也启动加载 |
| `StartExperienceLoad` | 开始加载资产（Bundle + 原始资产） |
| `OnExperienceLoadComplete` | 资产加载完 → 收集并激活 GameFeature 插件 |
| `OnGameFeaturePluginLoadComplete` | 单个插件激活完成回调 |
| `OnExperienceFullLoadCompleted` | 全部就绪 → 执行 Action → 广播 loaded |
| `OnActionDeactivationCompleted` / `OnAllActionsDeactivated` | 卸载时反向停 Action |
| `EndPlay` | 组件销毁时停用 GameFeature、卸载 Action |

### 成员变量

| 变量 | 作用 |
|------|------|
| `CurrentExperience`（`ReplicatedUsing`） | 当前经验（网络复制，客户端同步） |
| `LoadState` | 当前加载状态 |
| `NumGameFeaturePluginsLoading` | 还在加载中的插件计数 |
| `GameFeaturePluginURLs` | 本经验要激活的插件 URL 列表 |
| `NumObservedPausers` / `NumExpectedPausers` | 卸载时"暂停者"计数（异步卸载协调） |
| `OnExperienceLoaded_*`（3 个委托） | 三档优先级的"加载完成"委托 |

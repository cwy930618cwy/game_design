## 〇、这个 `.h` 在解决什么

`UTenkaichiExperienceDefinition` 继承 `UPrimaryDataAsset`，是"一局游戏的剧本单"（总 md 已讲）。`.h` 声明 4 个字段 + 2 个编辑器钩子 + 构造。

**类声明拆解：**

| 块 | 代码 | 作用 |
|----|------|------|
| ① 基类 | `UPrimaryDataAsset` | 数据资产（蓝图可配置） |
| ② 构造 | `UTenkaichiExperienceDefinition()` | 空构造 |
| ③ 校验钩子 | `IsDataValid`（编辑器） | 数据资产校验（仅编辑环境） |
| ④ 资源钩子 | `UpdateAssetBundleData`（编辑器数据） | 更新资源包（仅编辑数据） |
| ⑤ 四字段 | `GameFeaturesToEnable`/`DefaultPawnData`/`Actions`/`ActionSets` | 剧本单的实际内容 |

## 一、完整代码（可直接照抄）

```cpp
// 版权声明（可保留或省略，不影响编译）
#pragma once

#include "Engine/DataAsset.h"
#include "TenkaichiExperienceDefinition.generated.h"

class UGameFeatureAction;
class UTenkaichiPawnData;
class UTenkaichiExperienceActionSet;

/**
 * 经验定义（ExperienceDefinition）
 *
 * 一局游戏要用哪套规则：加载哪些 GameFeature、玩家默认用什么 Pawn、
 * 要执行哪些动作、复用哪些动作集。只存数据，执行逻辑在 ExperienceManagerComponent。
 */
UCLASS(BlueprintType, Const)
class UTenkaichiExperienceDefinition : public UPrimaryDataAsset
{
	GENERATED_BODY()

public:
	UTenkaichiExperienceDefinition();

	//~UObject 接口
#if WITH_EDITOR
	// 数据资产校验（仅编辑器环境）：检查依赖数据是否有效。
	virtual EDataValidationResult IsDataValid(class FDataValidationContext& Context) const override;
#endif
	//~UObject 接口结束

	//~UPrimaryDataAsset 接口
#if WITH_EDITORONLY_DATA
	// 更新资源包数据（仅编辑器数据）：让资源的依赖能被打进 Bundle。
	virtual void UpdateAssetBundleData() override;
#endif
	//~UPrimaryDataAsset 接口结束

public:
	// 这一局要激活的 Game Feature 插件列表（写插件名，如 "TenkaichiGameplayAbilities"）。
	UPROPERTY(EditDefaultsOnly, Category = Gameplay)
	TArray<FString> GameFeaturesToEnable;

	/** 玩家默认生成的 Pawn 数据（✅4.3 已教的 PawnData）。 */
	//@TODO: 考虑改成软引用
	UPROPERTY(EditDefaultsOnly, Category=Gameplay)
	TObjectPtr<const UTenkaichiPawnData> DefaultPawnData;

	// 这一局加载/激活/停用时执行的动作列表（引擎 GameFeatureAction）。
	UPROPERTY(EditDefaultsOnly, Instanced, Category="Actions")
	TArray<TObjectPtr<UGameFeatureAction>> Actions;

	// 追加进这一局的额外动作集列表（P13.2 待教，先前置声明软引用）。
	UPROPERTY(EditDefaultsOnly, Category=Gameplay)
	TArray<TObjectPtr<UTenkaichiExperienceActionSet>> ActionSets;
};
```

## 二、关键点讲解

### 1. `UCLASS(BlueprintType, Const)`
- `BlueprintType`：这个类**能在蓝图里作为变量类型**用。
- `Const`：标记为"不可变数据"（只读，作为资产引用时不能改内部）。

### 2. 基类 `UPrimaryDataAsset`
和 PawnData/TeamDisplayAsset 同类，是"**可以被蓝图当作资产编辑**"的数据容器。引擎提供 `UpdateAssetBundleData` 钩子管理资源打包。

### 3. 前置声明的 3 个类
```cpp
class UGameFeatureAction;      // 引擎类，动作基类
class UTenkaichiPawnData;      // ✅已教
class UTenkaichiExperienceActionSet;  // P13.2，仅声明不 include → 软引用不阻塞编译
```
只 `class X;` 前置声明，不 `#include`，因为这里只用了 `TObjectPtr` 指针（前向声明够用）。这保证 `.h` 不拖一堆依赖。

### 4. 编辑器钩子（`#if WITH_EDITOR` / `#if WITH_EDITORONLY_DATA`）
| 钩子 | 何时 | 干嘛 |
|------|------|------|
| `IsDataValid` | 编辑器校验资产时 | 检查剧本单上的数据是否合法 |
| `UpdateAssetBundleData` | 编辑器保存/打包时 | 把依赖资产包进 Bundle |
两者**只在编辑器编译**（`#if WITH_EDITOR` 包裹），游戏运行时编译会跳过。

### 5. 四个字段的 `EditDefaultsOnly` + `Category`
- `EditDefaultsOnly`：**只能在默认值（Class Defaults / 资产默认）里编辑**，不能在实例上改——符合"剧本单"只读语义。
- `Category`：编辑器里的属性分组。
- `Actions` 多一个 `Instanced`：这个数组的每个 `UGameFeatureAction` 是**实例化的**（能各自配置自己的参数）。

### 6. `GameFeaturesToEnable`：`TArray<FString>`
只存**插件名**（字符串），比如 `"TenkaichiGameplayAbilities"`。运行时由 `ExperienceManagerComponent`（P13.5）按这些名字激活对应 Game Feature 插件。

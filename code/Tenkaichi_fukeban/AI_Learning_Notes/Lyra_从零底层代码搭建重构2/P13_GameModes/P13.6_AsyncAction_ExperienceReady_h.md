## 〇、这个 `.h` 在解决什么

`UAsyncAction_ExperienceReady` 是"等经验加载完"的蓝图异步节点。`.h` 声明了：1 个静态蓝图函数（入口）+ 1 个 `Activate` 覆写 + 1 个 `OnReady` 事件委托 + 4 个私有步骤方法 + 1 个 World 弱引用。

**类声明拆解：**

| 块 | 代码 | 作用 |
|----|------|------|
| ① 基类 | `UBlueprintAsyncActionBase` | 引擎"蓝图异步节点"基类 |
| ② 特殊宏 | `GENERATED_UCLASS_BODY()` | 因为要自定义构造函数 |
| ③ 静态蓝图函数 | `WaitForExperienceReady(...)` | 蓝图节点入口，创建这个节点 |
| ④ 覆写 | `Activate()` | 节点激活时启动流程 |
| ⑤ 事件委托 | `OnReady`（`BlueprintAssignable`） | 蓝图绑定的"经验就绪"事件 |
| ⑥ 私有步骤 | `Step1~Step4` | 4 步状态机 |
| ⑦ 成员 | `WorldPtr`（`TWeakObjectPtr<UWorld>`） | 弱引用保存 World |

## 一、完整代码（可直接照抄）

```cpp
// 版权声明（可保留或省略，不影响编译）
#pragma once

#include "Kismet/BlueprintAsyncActionBase.h"

#include "AsyncAction_ExperienceReady.generated.h"

class AGameStateBase;
class UTenkaichiExperienceDefinition;
class UWorld;
struct FFrame;

// 声明一个"经验就绪"的动态多播委托（蓝图可绑定）。
DECLARE_DYNAMIC_MULTICAST_DELEGATE(FExperienceReadyAsyncDelegate);

/**
 * 异步等待 GameState 就绪且有效，然后调用 OnReady 事件。
 * 如果 GameState 已经有效，就立刻调用 OnReady。
 */
UCLASS()
class UAsyncAction_ExperienceReady : public UBlueprintAsyncActionBase
{
	GENERATED_UCLASS_BODY()

public:
	// 等待经验被确定并加载完成。
	UFUNCTION(BlueprintCallable, meta=(WorldContext = "WorldContextObject", BlueprintInternalUseOnly="true"))
	static UAsyncAction_ExperienceReady* WaitForExperienceReady(UObject* WorldContextObject);

	// 节点激活时调用：启动"等 GameState → 听经验 → 广播"的流程。
	virtual void Activate() override;

public:

	// 经验被确定且就绪/加载完成时调用。
	UPROPERTY(BlueprintAssignable)
	FExperienceReadyAsyncDelegate OnReady;

private:
	// 第 1 步：GameState 出现后的回调。
	void Step1_HandleGameStateSet(AGameStateBase* GameState);
	// 第 2 步：找到 GameState 上的经验管理器组件，开始听"经验加载完成"。
	void Step2_ListenToExperienceLoading(AGameStateBase* GameState);
	// 第 3 步：经验加载完成的回调。
	void Step3_HandleExperienceLoaded(const UTenkaichiExperienceDefinition* CurrentExperience);
	// 第 4 步：广播 OnReady，然后销毁自己。
	void Step4_BroadcastReady();

	// 弱引用保存 World，防止 World 销毁后悬空。
	TWeakObjectPtr<UWorld> WorldPtr;
};
```

## 二、关键点讲解

### 1. 基类 `UBlueprintAsyncActionBase`（P07.9 已教过）

`UBlueprintAsyncActionBase` 是引擎"蓝图异步节点"的基类。继承它，这个类就能在蓝图里生成一个**可以等待的节点**（有输入执行引脚、输出执行引脚，输出引脚要等异步操作完成才触发）。P07.9 `AsyncAction_ObserveTeam` 已经详细讲过，这里复用。

### 2. `GENERATED_UCLASS_BODY()`（P07.9 已教过）

普通 `UCLASS()` 用 `GENERATED_BODY()`，它会**自动生成**一个默认构造函数。但本类要**自定义构造函数**（`.cpp` 里写 `UAsyncAction_ExperienceReady(const FObjectInitializer&)`），所以用 `GENERATED_UCLASS_BODY()` 告诉 UHT"构造函数我自己写，别自动生成"。

### 3. 静态蓝图函数 `WaitForExperienceReady`

```cpp
UFUNCTION(BlueprintCallable, meta=(WorldContext = "WorldContextObject", BlueprintInternalUseOnly="true"))
static UAsyncAction_ExperienceReady* WaitForExperienceReady(UObject* WorldContextObject);
```

- `BlueprintCallable`：蓝图可调用（作为节点入口）。
- `meta=(WorldContext="WorldContextObject")`：告诉蓝图系统，`WorldContextObject` 参数是"世界上下文"（用来定位 World）。
- `meta=(BlueprintInternalUseOnly="true")`：这个函数**只为生成蓝图节点服务，不直接暴露给用户手动调用**（P07.9 已教过这个 meta）。
- `static`：静态函数，蓝图里直接 `WaitForExperienceReady(...)` 就能用，不需要先有一个实例。

### 4. `Activate()` 覆写（P07.9 已教过）

`Activate()` 是 `UBlueprintAsyncActionBase` 的虚函数，节点被激活（连进蓝图执行流）时调用。这里覆写它，就是为了在激活时启动"等 GameState → 听经验"的流程。

### 5. 事件委托 `OnReady`

```cpp
UPROPERTY(BlueprintAssignable)
FExperienceReadyAsyncDelegate OnReady;
```

- `DECLARE_DYNAMIC_MULTICAST_DELEGATE(FExperienceReadyAsyncDelegate)`：声明一个**动态多播委托**（无参数），蓝图可绑定。
- `BlueprintAssignable`：这个委托字段能在蓝图里绑事件（连线到自定义事件）。
- `OnReady` 就是蓝图最终要等的那个输出引脚——经验加载完，这个事件触发。

### 6. 前置声明（为什么零挂起）

```cpp
class AGameStateBase;
class UTenkaichiExperienceDefinition;
class UWorld;
struct FFrame;
```

`.h` 里 `UTenkaichiExperienceDefinition` 只出现在 `Step3_HandleExperienceLoaded` 的**参数指针**里，`AGameStateBase` 只出现在 `Step1/Step2` 的参数指针里——**指针只需前置声明 `class X;`，不用 include**。所以 `.h` 零挂起。

### 7. `TWeakObjectPtr<UWorld>`（P07.9 已教过弱引用）

`WorldPtr` 用 `TWeakObjectPtr`（弱对象指针）保存 World——World 销毁后 `Get()` 自动返回 `nullptr`，不会悬空。异步节点生命周期可能比 World 长，所以用弱引用防崩。

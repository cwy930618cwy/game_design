## 二、关键点讲解

### 1. `ProcessAutoLogin`——返回 true 禁用默认行为

```cpp
bool ATenkaichiGameSession::ProcessAutoLogin()
{
	// 这实际上由 TenkaichiGameMode::TryDedicatedServerLogin 处理
	return true;
}
```

引擎 `AGameSession::ProcessAutoLogin` 默认会**主动帮玩家自动登录**（走一套默认登录流程）。Lyra 覆盖它返回 `true`——意思是"我已经处理了自动登录，你别再跑默认逻辑了"。

> 实际上登录流程由 `ATenkaichiGameMode::TryDedicatedServerLogin`（P13.7 教的）自己管，所以这里直接 `return true` 跳过默认行为。

### 2. 两个比赛钩子——只调 Super

```cpp
void ATenkaichiGameSession::HandleMatchHasStarted()
{
	Super::HandleMatchHasStarted();
}
```

`HandleMatchHasStarted` / `HandleMatchHasEnded` 是比赛生命周期的钩子。Lyra 目前没加自定义逻辑，只调 `Super`（保留引擎默认行为），作为将来扩展的占位。

### 3. 没有 include 日志通道

这个 `.cpp` 很特殊：**没有 `#include "TenkaichiLogChannels.h"`**，因为里面没有任何 `UE_LOG`。这是"按需 include"的体现——用不到日志就不 include。

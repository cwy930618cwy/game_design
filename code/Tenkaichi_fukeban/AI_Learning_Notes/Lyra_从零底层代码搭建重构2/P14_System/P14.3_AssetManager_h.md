## 〇、这个 `.h` 在解决什么

`UTenkaichiAssetManager` 是资产管理单例。`.h` 声明了：1 个 `FLyraBundles` 结构体 + 1 个构造 + 静态单例 `Get()` + 2 个模板函数（内联）+ 若干方法 + 成员字段。

**类声明拆解：**

| 块 | 代码 | 作用 |
|----|------|------|
| ① Bundle 结构体 | `struct FLyraBundles` | 定义 `Equipped` 常量 |
| ② 基类 | `UAssetManager` | 引擎资产管理器 |
| ③ 特殊宏 | `UCLASS(MinimalAPI, Config=Game)` + `#define UE_API` | 精简导出 + ini 配置 |
| ④ 单例 | `Get()` | 返回全局唯一实例 |
| ⑤ 模板函数 | `GetAsset`/`GetSubclass`（内联） | 同步加载软引用资产/类 |
| ⑥ 工具方法 | `DumpLoadedAssets`/`SynchronousLoadAsset`/`ShouldLogAssetLoads`/`AddLoadedAsset` | 打印/同步加载/登记 |
| ⑦ 数据方法 | `GetGameData`/`GetDefaultPawnData`/`GetOrLoadTypedGameData`/`LoadGameDataOfClass` | 游戏数据/默认 Pawn |

## 一、完整代码（可直接照抄）

```cpp
// 版权声明（可保留或省略，不影响编译）
#pragma once

#include "Engine/AssetManager.h"
#include "TenkaichiAssetManagerStartupJob.h"
#include "Templates/SubclassOf.h"
#include "TenkaichiAssetManager.generated.h"

#define UE_API TENKAICHIGAME_API

class UPrimaryDataAsset;

class UTenkaichiGameData;
class UTenkaichiPawnData;

// 定义 Bundle 名常量（用于按 Bundle 加载资产）。
struct FTenkaichiBundles
{
	static const FName Equipped;
};


/**
 * UTenkaichiAssetManager
 *
 *	资产管理器的游戏实现，覆写功能并存储游戏特定类型。
 *	大多数游戏都想要覆写 AssetManager，因为它是放"游戏特定加载逻辑"的好地方。
 *	这个类通过在 DefaultEngine.ini 里设置 'AssetManagerClassName' 来使用。
 */
UCLASS(MinimalAPI, Config = Game)
class UTenkaichiAssetManager : public UAssetManager
{
	GENERATED_BODY()

public:

	// 构造函数：初始化 DefaultPawnData。
	UE_API UTenkaichiAssetManager();

	// 返回 AssetManager 单例对象。
	static UE_API UTenkaichiAssetManager& Get();

	// 返回 TSoftObjectPtr 引用的资产（如果还没加载就同步加载）。
	template<typename AssetType>
	static AssetType* GetAsset(const TSoftObjectPtr<AssetType>& AssetPointer, bool bKeepInMemory = true);

	// 返回 TSoftClassPtr 引用的子类（如果还没加载就同步加载）。
	template<typename AssetType>
	static TSubclassOf<AssetType> GetSubclass(const TSoftClassPtr<AssetType>& AssetPointer, bool bKeepInMemory = true);

	// 打印所有当前被资产管理器加载和追踪的资产。
	static UE_API void DumpLoadedAssets();

	// 返回全局游戏数据。
	UE_API const UTenkaichiGameData& GetGameData();
	// 返回默认 Pawn 数据。
	UE_API const UTenkaichiPawnData* GetDefaultPawnData() const;

protected:
	// 加载（或取缓存的）指定类型的游戏数据。
	template <typename GameDataClass>
	const GameDataClass& GetOrLoadTypedGameData(const TSoftObjectPtr<GameDataClass>& DataPath)
	{
		if (TObjectPtr<UPrimaryDataAsset> const * pResult = GameDataMap.Find(GameDataClass::StaticClass()))
		{
			return *CastChecked<GameDataClass>(*pResult);
		}

		// 如果需要就做一次阻塞加载
		return *CastChecked<const GameDataClass>(LoadGameDataOfClass(GameDataClass::StaticClass(), DataPath, GameDataClass::StaticClass()->GetFName()));
	}


	// 同步加载指定路径的资产。
	static UE_API UObject* SynchronousLoadAsset(const FSoftObjectPath& AssetPath);
	// 返回"是否要记录资产加载日志"。
	static UE_API bool ShouldLogAssetLoads();

	// 线程安全地把一个已加载资产加入内存保持列表。
	UE_API void AddLoadedAsset(const UObject* Asset);

	//~UAssetManager 接口开始
	// 启动初始加载（扫描 + 跑启动任务）。
	UE_API virtual void StartInitialLoading() override;
#if WITH_EDITOR
	// PIE 开始前（编辑器专用）。
	UE_API virtual void PreBeginPIE(bool bStartSimulate) override;
#endif
	//~UAssetManager 接口结束

	// 真正加载指定类的游戏数据。
	UE_API UPrimaryDataAsset* LoadGameDataOfClass(TSubclassOf<UPrimaryDataAsset> DataClass, const TSoftObjectPtr<UPrimaryDataAsset>& DataClassPath, FPrimaryAssetType PrimaryAssetType);

protected:

	// 要使用的全局游戏数据资产。
	UPROPERTY(Config)
	TSoftObjectPtr<UTenkaichiGameData> TenkaichiGameDataPath;

	// 已加载的游戏数据版本。
	UPROPERTY(Transient)
	TMap<TObjectPtr<UClass>, TObjectPtr<UPrimaryDataAsset>> GameDataMap;

	// 玩家状态上没有设置 Pawn 数据时，生成玩家 Pawn 用的 Pawn 数据。
	UPROPERTY(Config)
	TSoftObjectPtr<UTenkaichiPawnData> DefaultPawnData;

private:
	// 冲刷 StartupJobs 数组，处理所有启动工作。
	UE_API void DoAllStartupJobs();

	// 设置能力系统。
	UE_API void InitializeGameplayCueManager();

	// 加载过程中周期性调用，可用来把状态喂给加载屏。
	UE_API void UpdateInitialGameContentLoadPercent(float GameContentPercent);

	// 启动时要执行的任务列表，用来追踪启动进度。
	TArray<FTenkaichiAssetManagerStartupJob> StartupJobs;

private:

	// 被资产管理器加载和追踪的资产。
	UPROPERTY()
	TSet<TObjectPtr<const UObject>> LoadedAssets;

	// 修改加载资产列表时用的作用域锁。
	FCriticalSection LoadedAssetsCritical;
};


// 模板函数内联实现（返回 TSoftObjectPtr 引用的资产）。
template<typename AssetType>
AssetType* UTenkaichiAssetManager::GetAsset(const TSoftObjectPtr<AssetType>& AssetPointer, bool bKeepInMemory)
{
	AssetType* LoadedAsset = nullptr;

	const FSoftObjectPath& AssetPath = AssetPointer.ToSoftObjectPath();

	if (AssetPath.IsValid())
	{
		LoadedAsset = AssetPointer.Get();
		if (!LoadedAsset)
		{
			LoadedAsset = Cast<AssetType>(SynchronousLoadAsset(AssetPath));
			ensureAlwaysMsgf(LoadedAsset, TEXT("Failed to load asset [%s]"), *AssetPointer.ToString());
		}

		if (LoadedAsset && bKeepInMemory)
		{
			// 加入已加载资产列表
			Get().AddLoadedAsset(Cast<UObject>(LoadedAsset));
		}
	}

	return LoadedAsset;
}

// 模板函数内联实现（返回 TSoftClassPtr 引用的子类）。
template<typename AssetType>
TSubclassOf<AssetType> UTenkaichiAssetManager::GetSubclass(const TSoftClassPtr<AssetType>& AssetPointer, bool bKeepInMemory)
{
	TSubclassOf<AssetType> LoadedSubclass;

	const FSoftObjectPath& AssetPath = AssetPointer.ToSoftObjectPath();

	if (AssetPath.IsValid())
	{
		LoadedSubclass = AssetPointer.Get();
		if (!LoadedSubclass)
		{
			LoadedSubclass = Cast<UClass>(SynchronousLoadAsset(AssetPath));
			ensureAlwaysMsgf(LoadedSubclass, TEXT("Failed to load asset class [%s]"), *AssetPointer.ToString());
		}

		if (LoadedSubclass && bKeepInMemory)
		{
			// 加入已加载资产列表
			Get().AddLoadedAsset(Cast<UObject>(LoadedSubclass));
		}
	}

	return LoadedSubclass;
}

#undef UE_API
```

## 二、关键点讲解

### 1. `FLyraBundles` 结构体——Bundle 常量

```cpp
struct FTenkaichiBundles
{
	static const FName Equipped;
};
```

`FLyraBundles::Equipped` 是一个 `FName` 常量（"Equipped"），在 `.cpp` 里定义（`const FName FTenkaichiBundles::Equipped("Equipped")`）。它是"Bundle"（资产打包组）的名字，加载"已装备"类资产时用。

> 这就是 P13.5 挂起的 `FTenkaichiBundles::Equipped`——它就在这个 `.h` 里声明、`.cpp` 里定义。本类教完，P13.5 的 `StartExperienceLoad` 就能解开了。

### 2. `UCLASS(MinimalAPI, Config = Game)`

- `MinimalAPI`：精简导出（同 P13.4/P13.5/P13.7）。
- `Config = Game`：支持 `DefaultGame.ini` 配置（`DefaultPawnData`、`TenkaichiGameDataPath` 这些 `UPROPERTY(Config)` 字段从 ini 读）。

### 3. 单例 `Get()`

```cpp
static UE_API UTenkaichiAssetManager& Get();
```

返回全局唯一实例（`.cpp` 里从 `GEngine->AssetManager` 拿）。这就是 P13.5/P13.7 里 `UTenkaichiAssetManager::Get()` 一直调用的那个。

### 4. 模板函数 `GetAsset` / `GetSubclass`（内联在 `.h`）

```cpp
template<typename AssetType>
static AssetType* GetAsset(const TSoftObjectPtr<AssetType>& AssetPointer, bool bKeepInMemory = true);
```

模板函数**必须内联在 `.h`**（编译器要看到模板定义才能实例化）。所以这两个函数的完整实现写在 `.h` 末尾（`#undef UE_API` 之前）。

- `GetAsset`：加载一个**资产**（如纹理、数据资产），返回 `AssetType*`。
- `GetSubclass`：加载一个**类**（如 Pawn 类），返回 `TSubclassOf<AssetType>`。
- 逻辑：先 `AssetPointer.Get()`（已加载就返回），没加载就 `SynchronousLoadAsset` 同步加载，再按需 `AddLoadedAsset` 保活。

### 5. `GetOrLoadTypedGameData` 模板（内联）

```cpp
template <typename GameDataClass>
const GameDataClass& GetOrLoadTypedGameData(const TSoftObjectPtr<GameDataClass>& DataPath)
{
	if (TObjectPtr<UPrimaryDataAsset> const * pResult = GameDataMap.Find(GameDataClass::StaticClass()))
	{
		return *CastChecked<GameDataClass>(*pResult);
	}
	return *CastChecked<const GameDataClass>(LoadGameDataOfClass(...));
}
```

- 先查 `GameDataMap` 缓存（有就直接返回）。
- 没有就 `LoadGameDataOfClass` 阻塞加载，再返回。
- `GetGameData()` 就是调用 `GetOrLoadTypedGameData<UTenkaichiGameData>(TenkaichiGameDataPath)`。

### 6. 成员字段——三种用途

```cpp
UPROPERTY(Config) TSoftObjectPtr<UTenkaichiGameData> TenkaichiGameDataPath;   // 配置：游戏数据路径
UPROPERTY(Transient) TMap<...> GameDataMap;                                    // 缓存：已加载游戏数据
UPROPERTY(Config) TSoftObjectPtr<UTenkaichiPawnData> DefaultPawnData;         // 配置：默认 Pawn
TArray<FTenkaichiAssetManagerStartupJob> StartupJobs;                          // 启动任务列表
UPROPERTY() TSet<TObjectPtr<const UObject>> LoadedAssets;                      // 已加载资产
FCriticalSection LoadedAssetsCritical;                                         // 线程锁
```

- `UPROPERTY(Config)`：从 ini 读（`TenkaichiGameDataPath`、`DefaultPawnData`）。
- `UPROPERTY(Transient)`：运行时缓存，不存盘（`GameDataMap`）。
- `FCriticalSection`：临界区锁，`AddLoadedAsset` 里用 `FScopeLock` 保护 `LoadedAssets`（多线程安全）。

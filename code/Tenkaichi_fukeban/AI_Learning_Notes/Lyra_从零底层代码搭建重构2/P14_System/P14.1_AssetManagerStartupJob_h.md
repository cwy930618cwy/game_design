## 〇、这个 `.h` 在解决什么

`FTenkaichiAssetManagerStartupJob` 是启动加载任务单。`.h` 声明了：1 个委托类型 + 1 个结构体（5 个成员 + 1 个构造 + 3 个方法）。

**结构体拆解：**

| 块 | 代码 | 作用 |
|----|------|------|
| ① 委托 | `DECLARE_DELEGATE_OneParam(FLyraAssetManagerStartupJobSubstepProgress, float)` | 进度回调委托（单播，带 float 进度） |
| ② 结构体 | `struct FLyraAssetManagerStartupJob` | 任务单 |
| ③ 成员 | `SubstepProgressDelegate`/`JobFunc`/`JobName`/`JobWeight`/`LastUpdate` | 回调/函数/名字/权重/上次时间 |
| ④ 构造 | `FLyraAssetManagerStartupJob(...)` | 初始化名字/函数/权重 |
| ⑤ 方法 | `DoJob()`/`UpdateSubstepProgress`/`UpdateSubstepProgressFromStreamable` | 执行/上报进度 |

## 一、完整代码（可直接照抄）

```cpp
// 版权声明（可保留或省略，不影响编译）
#pragma once

#include "Engine/StreamableManager.h"

// 声明"启动任务子步骤进度"的委托：带一个参数（新进度，float）。
DECLARE_DELEGATE_OneParam(FTenkaichiAssetManagerStartupJobSubstepProgress, float /*NewProgress*/);

// 处理从流式句柄上报进度。
struct FTenkaichiAssetManagerStartupJob
{
	// 子步骤进度回调委托。
	FTenkaichiAssetManagerStartupJobSubstepProgress SubstepProgressDelegate;
	// 实际要执行的加载函数（接收任务引用 + 流式句柄引用）。
	TFunction<void(const FTenkaichiAssetManagerStartupJob&, TSharedPtr<FStreamableHandle>&)> JobFunc;
	// 任务名（日志用）。
	FString JobName;
	// 进度权重。
	float JobWeight;
	// 上次上报进度的时间（节流用）。
	mutable double LastUpdate = 0;

	// 构造函数：初始化任务函数、名字、权重。
	FTenkaichiAssetManagerStartupJob(const FString& InJobName, const TFunction<void(const FTenkaichiAssetManagerStartupJob&, TSharedPtr<FStreamableHandle>&)>& InJobFunc, float InJobWeight)
		: JobFunc(InJobFunc)
		, JobName(InJobName)
		, JobWeight(InJobWeight)
	{}

	// 执行真正的加载，如果创建了句柄就返回它。
	TSharedPtr<FStreamableHandle> DoJob() const;

	// 上报子步骤进度。
	void UpdateSubstepProgress(float NewProgress) const
	{
		SubstepProgressDelegate.ExecuteIfBound(NewProgress);
	}

	// 从流式句柄取进度并上报（带节流，最多每秒 60 次）。
	void UpdateSubstepProgressFromStreamable(TSharedRef<FStreamableHandle> StreamableHandle) const
	{
		if (SubstepProgressDelegate.IsBound())
		{
			// StreamableHandle::GetProgress 遍历一张很大的图，开销不小
			double Now = FPlatformTime::Seconds();
			if (LastUpdate - Now > 1.0 / 60)
			{
				SubstepProgressDelegate.Execute(StreamableHandle->GetProgress());
				LastUpdate = Now;
			}
		}
	}
};
```

## 二、关键点讲解

### 1. `DECLARE_DELEGATE_OneParam`——单播委托

```cpp
DECLARE_DELEGATE_OneParam(FTenkaichiAssetManagerStartupJobSubstepProgress, float /*NewProgress*/);
```

- `DECLARE_DELEGATE_OneParam(委托名, 参数类型)`：声明一个**单播委托**（只能绑一个回调）。
- 对比前面学的：
  - `DECLARE_MULTICAST_DELEGATE_OneParam`（P13.5）：多播，能绑多个回调。
  - `DECLARE_DYNAMIC_MULTICAST_DELEGATE`（P13.6）：动态多播，蓝图可绑。
  - 这里的 `DECLARE_DELEGATE_OneParam`：**单播**，C++ 专用，蓝图不可见。
- 参数 `float /*NewProgress*/`：带一个 float 进度参数（参数名注释掉了）。

### 2. `TFunction`——可调用对象

```cpp
TFunction<void(const FTenkaichiAssetManagerStartupJob&, TSharedPtr<FStreamableHandle>&)> JobFunc;
```

`TFunction<返回值(参数...)>` 是 UE 的 `std::function` 等价物——存一个"可调用对象"（lambda、函数指针、仿函数都行）。

这里 `JobFunc` 的类型是"接收（任务引用 + 流式句柄引用），返回 void"的函数。执行时它负责真正去加载资产，并通过第二个参数 `TSharedPtr<FStreamableHandle>&` **把创建的流式句柄传出来**（引用传出）。

### 3. `mutable double LastUpdate = 0`

```cpp
mutable double LastUpdate = 0;
```

- `mutable`：允许在 `const` 成员函数里修改这个成员。因为 `UpdateSubstepProgressFromStreamable` 是 `const` 方法，但它要更新 `LastUpdate`（节流时间戳），所以 `LastUpdate` 必须 `mutable`。
- `= 0`：C++11 成员默认初始化。

### 4. 构造函数——内联初始化

```cpp
FTenkaichiAssetManagerStartupJob(const FString& InJobName, const TFunction<...>& InJobFunc, float InJobWeight)
	: JobFunc(InJobFunc)
	, JobName(InJobName)
	, JobWeight(InJobWeight)
{}
```

构造函数**直接写在 `.h` 里**（内联），用初始化列表赋值。三个参数：名字、函数、权重。

### 5. `UpdateSubstepProgress` vs `UpdateSubstepProgressFromStreamable`

两个方法都是"上报进度"，但来源不同：

| 方法 | 进度来源 | 是否节流 |
|------|---------|---------|
| `UpdateSubstepProgress` | 直接传 `NewProgress` | 不节流 |
| `UpdateSubstepProgressFromStreamable` | 从 `FStreamableHandle->GetProgress()` 取 | 节流（60fps） |

为什么第二个要节流？因为 `StreamableHandle::GetProgress()` 要遍历整张依赖图（开销大），每帧都调会卡。所以限制"最多每秒 60 次"。

### 6. `ExecuteIfBound` vs `Execute`

- `ExecuteIfBound`：**如果绑定了**就执行（没绑定就跳过，安全）。
- `Execute`：直接执行（没绑定会崩，所以外面先用 `IsBound()` 判断）。

`UpdateSubstepProgress` 用 `ExecuteIfBound`（简单安全），`UpdateSubstepProgressFromStreamable` 先 `IsBound()` 再 `Execute`（因为要先判断才进 if）。

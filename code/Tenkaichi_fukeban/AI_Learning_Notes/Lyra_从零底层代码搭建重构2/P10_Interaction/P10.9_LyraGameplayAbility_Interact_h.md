## 二、完整代码

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "AbilitySystem/Abilities/TenkaichiGameplayAbility.h"
#include "Interaction/InteractionOption.h"

#include "TenkaichiGameplayAbility_Interact.generated.h"

class UIndicatorDescriptor;
class UObject;
class UUserWidget;
struct FFrame;
struct FGameplayAbilityActorInfo;
struct FGameplayEventData;

/**
 * UTenkaichiGameplayAbility_Interact
 *
 * 用于角色交互的游戏能力
 */
UCLASS(Abstract)
class UTenkaichiGameplayAbility_Interact : public UTenkaichiGameplayAbility
{
	GENERATED_BODY()

public:

	// 构造函数（在 .cpp 里设置激活/实例化/网络执行策略）
	UTenkaichiGameplayAbility_Interact(const FObjectInitializer& ObjectInitializer = FObjectInitializer::Get());

	// 能力激活入口：在服务端启动交互扫描并授予附近目标
	virtual void ActivateAbility(const FGameplayAbilitySpecHandle Handle, const FGameplayAbilityActorInfo ActorInfo, const FGameplayAbilityActivationInfo ActivationInfo, const FGameplayEventData* TriggerEventData) override;

	UFUNCTION(BlueprintCallable)
	// 接收扫描结果，更新目标头上的交互指示器
	void UpdateInteractions(const TArray<FInteractionOption>& InteractiveOptions);

	UFUNCTION(BlueprintCallable)
	// 玩家按下交互键时调用，触发目标上的交互技能
	void TriggerInteraction();

protected:
	UPROPERTY(BlueprintReadWrite)
	// 当前可交互选项列表
	TArray<FInteractionOption> CurrentOptions;

	UPROPERTY()
	// 当前显示在目标头上的指示器
	TArray<TObjectPtr<UIndicatorDescriptor>> Indicators;

protected:

	UPROPERTY(EditDefaultsOnly)
	// 扫描频率（秒）
	float InteractionScanRate = 0.1f;

	UPROPERTY(EditDefaultsOnly)
	// 扫描半径
	float InteractionScanRange = 500;

	UPROPERTY(EditDefaultsOnly)
	// 默认指示器 UI（软引用）
	TSoftClassPtr<UUserWidget> DefaultInteractionWidgetClass;
};
```

## 三、逐段讲解

### 1. 头文件引入（第 1~15 行）


| 头文件 | 作用 |
|--------|------|
| `AbilitySystem/Abilities/TenkaichiGameplayAbility.h` | 继承 P05 的能力基类（`LyraGameplayAbility.h` → **`Tenkaichi`**）。 |
| `Interaction/InteractionOption.h` | 用 `FInteractionOption`（P10.1）。 |
| `.generated.h` | UHT 生成。 |
| `UIndicatorDescriptor` 等前向声明 | 软引用，避免重头文件。 |

> ⚠️ 注意：`.h` 里 `UIndicatorDescriptor` 只是**指针成员**（前向声明就够），所以 `.h` **无 P16 硬依赖**，可以完整写。真正挂起的是 `.cpp`。


- `UCLASS(Abstract)`：抽象能力，**不直接实例化**，需被子类实现。

- 带默认参数的构造函数。`.cpp` 里会设置**激活策略/实例化策略/网络执行策略**（这是交互能力的"配置灵魂"）。

### 4. 覆写 `ActivateAbility`（第 31 行）

```cpp
	// 能力激活入口：在服务端启动交互扫描并授予附近目标

```

- 能力激活入口。`.cpp` 里在服务端启动 `UAbilityTask_GrantInteractions`（P10.5）扫描并授予附近目标。

### 5. 两个 BlueprintCallable 方法（第 33~38 行）

```cpp
	UFUNCTION(BlueprintCallable)
	// 接收扫描结果，更新目标头上的交互指示器
	void UpdateInteractions(const TArray<FInteractionOption>& InteractiveOptions);

	UFUNCTION(BlueprintCallable)
	// 玩家按下交互键时调用，触发目标上的交互技能
	void TriggerInteraction();
```

- **`UpdateInteractions`**：UI 侧每收到扫描结果就调用，在目标头上**更新交互指示器**。
- **`TriggerInteraction`**：玩家按下交互键时调用，**触发目标上的交互技能**。
- 都被蓝图调用，所以是 `BlueprintCallable`。

### 6. 成员变量（第 40~55 行）

```cpp
	UPROPERTY(BlueprintReadWrite)
	// 当前可交互选项列表
	TArray<FInteractionOption> CurrentOptions;

	UPROPERTY()
	// 当前显示在目标头上的指示器
	TArray<TObjectPtr<UIndicatorDescriptor>> Indicators;

	UPROPERTY(EditDefaultsOnly)
	// 扫描频率（秒）
	float InteractionScanRate = 0.1f;

	UPROPERTY(EditDefaultsOnly)
	// 扫描半径
	float InteractionScanRange = 500;

	UPROPERTY(EditDefaultsOnly)
	// 默认指示器 UI（软引用）
	TSoftClassPtr<UUserWidget> DefaultInteractionWidgetClass;
```

- **`CurrentOptions`**：存当前可交互选项（蓝图可读写）。
- **`Indicators`**：存所有活跃指示器，扫描更新时先清掉旧的再建新的。
- **三个配置项**：`EditDefaultsOnly` → 只在**蓝图类默认值**里可编辑（类配置，不实例化）。
- `TSoftClassPtr`（软类引用）：`DefaultInteractionWidgetClass` 用软引用，**加载时才真加载**，省内存。

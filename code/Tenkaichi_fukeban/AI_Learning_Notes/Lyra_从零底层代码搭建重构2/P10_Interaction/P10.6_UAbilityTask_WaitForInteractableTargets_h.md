## 二、完整代码

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.
#pragma once

#include "Abilities/Tasks/AbilityTask.h"
#include "Engine/CollisionProfile.h"
#include "Interaction/InteractionOption.h"

#include "AbilityTask_WaitForInteractableTargets.generated.h"

class AActor;
class IInteractableTarget;
class UObject;
class UWorld;
struct FCollisionQueryParams;
struct FHitResult;
struct FInteractionQuery;
template <typename InterfaceType> class TScriptInterface;

// 委托：当「可交互选项列表」变化时广播（参数是新列表）
DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam(FInteractableObjectsChangedEvent, const TArray<FInteractionOption>&, InteractableOptions);

// 抽象基类：等待玩家当前可交互目标，变化时广播给上层（UI 等）
UCLASS(Abstract)
class UAbilityTask_WaitForInteractableTargets : public UAbilityTask
{
	GENERATED_UCLASS_BODY()

public:
	// 蓝图可绑定的委托：可交互选项列表变化时触发
	UPROPERTY(BlueprintAssignable)
	FInteractableObjectsChangedEvent InteractableObjectsChanged;

protected:

	// 做一次射线检测，取最近命中点（供子类调用）
	static void LineTrace(FHitResult& OutHitResult, const UWorld* World, const FVector& Start, const FVector& End, FName ProfileName, const FCollisionQueryParams Params);

	// 从玩家视角计算射线终点（考虑瞄准方向、最大射程，可选忽略俯仰角）
	void AimWithPlayerController(const AActor* InSourceActor, FCollisionQueryParams Params, const FVector& TraceStart, float MaxRange, FVector& OutTraceEnd, bool bIgnorePitch = false) const;

	// 把相机射线裁剪到技能作用半径范围内（相机朝外射时保证终点落在能力范围内）
	static bool ClipCameraRayToAbilityRange(FVector CameraLocation, FVector CameraDirection, FVector AbilityCenter, float AbilityRange, FVector& ClippedPosition);

	// 核心：把「可交互目标列表」变成「选项列表」、过滤不可用项、并广播变化
	void UpdateInteractableOptions(const FInteractionQuery& InteractQuery, const TArray<TScriptInterface<IInteractableTarget>>& InteractableTargets);

	// 射线检测用的碰撞配置名（子类传入）
	FCollisionProfileName TraceProfile;

	// 射线是否影响瞄准俯仰角（默认 true）
	bool bTraceAffectsAimPitch = true;

	// 当前生效的选项列表（用于对比是否有变化）
	TArray<FInteractionOption> CurrentOptions;
};
```

## 三、逐段讲解

### 1. 头文件引入（第 1~17 行）

```cpp
#include "Abilities/Tasks/AbilityTask.h"

#include "Interaction/InteractionOption.h"

```

| 头文件/前置声明 | 作用 |
|----------------|------|
| `AbilityTask.h` | 引入 `UAbilityTask` 基类。 |
| `CollisionProfile.h` | 用 `FCollisionProfileName`（碰撞配置名类型）。 |
| `InteractionOption.h` | 用 `FInteractionOption`（委托和列表的类型）。 |
| `AbilityTask_WaitForInteractableTargets.generated.h` | UHT 生成代码，`UCLASS` 必须有。 |
| 其余前置声明 | 方法参数/返回值只用指针或引用，不需要完整定义，保持头文件轻量（铁律 30）。 |

### 2. 委托声明（第 19 行）

```cpp
DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam(FInteractableObjectsChangedEvent, const TArray<FInteractionOption>&, InteractableOptions);
```

- **动态多播委托宏**：声明一个委托类型 `FInteractableObjectsChangedEvent`，带 1 个参数（`TArray<FInteractionOption>`）。
- 多播 = 可以绑多个回调；动态 = 蓝图可绑定。
- 当选项列表变化时广播 `InteractableObjectsChanged`，把新列表作为参数传出。

### 3. `UCLASS(Abstract)` + `GENERATED_UCLASS_BODY()`（第 22~25 行）

```cpp
UCLASS(Abstract)
class UAbilityTask_WaitForInteractableTargets : public UAbilityTask
{
	GENERATED_UCLASS_BODY()
```

- `UCLASS(Abstract)`：**抽象类**，不能直接在蓝图上创建，必须由子类（如 P10.7）实现具体行为。
- `GENERATED_UCLASS_BODY()`：要求带 `FObjectInitializer` 参数的构造函数（`.cpp` 中实现）。
- 继承 `UAbilityTask`，是能力任务。

### 4. 委托成员（第 27~29 行）

```cpp
	UPROPERTY(BlueprintAssignable)
	FInteractableObjectsChangedEvent InteractableObjectsChanged;
```

- `UPROPERTY(BlueprintAssignable)`：这个委托属性**蓝图可绑定**（在蓝图里能拖线连接事件）。
- 这是整个任务对外"发信号"的出口——上层（UI）监听它来更新交互选项显示。

### 5. 受保护区：工具方法 + 核心处理 + 数据（第 31~46 行）

```cpp
protected:

	static void LineTrace(FHitResult& OutHitResult, const UWorld* World, const FVector& Start, const FVector& End, FName ProfileName, const FCollisionQueryParams Params);

	void AimAtPlayerController(const AActor* InSourceActor, FCollisionQueryParams Params, const FVector& TraceStart, float MaxRange, FVector& OutTraceEnd, bool bIgnorePitch = false) const;

	static bool ClipCameraRayToAbilityRange(Vector CameraLocation, Vector CameraDirection, Vector AbilityCenter, float AbilityRange, Vector& ClippedPosition);

	void UpdateInteractableOptions(const FInteractionQuery& InteractQuery, const TArray<TScriptInterface<IInteractorTarget>>& InteractorTargets);

	FCollisionProfileName TraceProfile;

	bool bTraceAffectsAimPitch = true;

	TArray<FInteractionOption> CurrentOptions;
```

- `protected`：只给子类用，不对外暴露。
- `LineTrace`：纯函数工具，做射线检测（静态）。
- `AimAtPlayerController`：从玩家视角算瞄准射线终点（`.cpp` 里实现，涉及玩家相机）。
- `ClipCameraRayToAbilityRange`：把相机射线裁剪到技能作用范围，确保射线终点不越界（静态）。
- `UpdateInteractableOptions`：核心入口，子类找到目标后调用它来统一处理。
- 数据成员：`TraceProfile`（碰撞配置）、`bTraceAffectsAimPitch`（俯仰角开关）、`CurrentOptions`（当前选项，用于对比变化）。

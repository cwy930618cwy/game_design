## 一、我犯的错（反面教材）

教 `Core.Build.cs` 时，我把「总 md」写成了 **185 行 / 12.9KB 的逐行大表格**：330 行代码按行号切成 5 张表，每行都列「行 / 内容 / 一句话作用」。

**用户不要这个。** 问题：

1. **总 md 太长**：旧讲义总 md 只有 **3~5KB / 60 行左右**，我写了 12.9KB。
2. **总 md 里塞了逐行细节**：逐行拆解属于「完整代码 md」，不该进总 md。
3. **没有「完整代码 md」**：旧讲义每个文件都是 **两份 md**（`_总md.md` + `_完整代码.md`），我只建了一份。
4. **缺旧讲义固定栏目**：没有「内部结构全景（树形图）」「依赖分析表」「我们这版 vs 引擎的差异表」「收尾 + 待确认」「源码依据」。

## 二、旧讲义标准格式（照抄这个）

### 2.1 每个文件 = 两份 md

| md | 大小 | 装什么 |
|---|---|---|
| `NN_<文件名>_总md.md` | **3~5KB / 50~65 行** | 为什么 + 内部结构全景（树形图）+ 依赖分析 + 怎么教 + 下一步 |
| `NN_<文件名>_完整代码.md` | 5~11KB | 完整代码（可直接照抄）+ 逐段拆解 + 差异表 + 收尾 + 待确认 + 源码依据 |

`.h` 与 `.cpp` **分开两份完整代码 md**（旧讲义：`P01.2_xxx_h.md`、`P01.2_xxx_cpp.md`）。

### 2.2 总 md 的固定骨架（6 段，不许加）

```
# P01.1 FLyraVerbMessage —— 总 md

> 依据：<引擎/原工程真实路径>（N 行）
> 你新建文件：<还原路径>
> **✅ 本节可独立编译** / ⚠️ 挂起说明

---

## 一、这个类解决什么问题（为什么）
   —— 场景故事 + 一句话概括 + 🔑 一句话比喻

## 二、内部结构全景
   —— 树形图（├─ └─），把成员/方法全列出来

## 三、依赖分析
   —— 表格：文件 | 依赖工程内类？ | 能否独立编译 | 需挂起？

## 四、怎么教（推进节奏）
   —— 先建总 md → 停 → 教 .h → 停 → 教 .cpp

---

**下一步**：你确认这个总 md 没问题（懂了/继续），我就开始教 xxx。
```

### 2.3 完整代码 md 的固定骨架（5 段 + 收尾）

```
# P01.1 FLyraVerbMessage —— `.h` 声明层

> 依据：<真实路径>（N 行）
> 你新建文件：<还原路径>
> **✅ 本节可独立编译**

---

## 一、这个 `.h` 解决什么问题（为什么）
   —— 场景 + 🔑 一句话

## 二、完整代码（注释已中文化，你照这个抄）
   —— 一个 ```cpp 代码块，整份贴完，零教学噪声

## 三、逐段拆解（先讲清为什么，再给代码）
   ### include 区        —— 代码块 + 表格（行 | 干什么）+ 类比
   ### 类/结构体声明      —— 代码块 + 表格
   ### 每个成员/方法      —— 代码块 + 表格
   —— 每段都是「小代码块 + 小表格 + 一句类比」

## 四、我们这版 vs 引擎的差异
   —— 表格：项 | 引擎 | 我们 | 说明

## 五、收尾 + 待确认
   —— 结构总结 + 关键概念

---

## 待确认
1. 看懂了吗？照着「完整代码」抄一遍到 <路径>
2. 确认后，本节完结，下一节教 xxx

---

## 源码依据
- 引擎：<真实路径>（N 行）
- 你的还原：<还原路径>（新建）
```

## 三、硬性要求（逐条对照）

| # | 要求 |
|---|---|
| 1 | **总 md 控制在 65 行内 / 5KB 内**，只讲「为什么 + 全景 + 依赖 + 节奏」 |
| 2 | **逐行拆解一律放完整代码 md**，总 md 里不许出现逐行表格 |
| 3 | **完整代码 md 的代码块必须整份贴完**，不许切片、不许省略号 |
| 4 | 逐段拆解用「**小代码块 + 小表格 + 一句类比**」三件套，不用大表格 |
| 5 | 必须有「**我们这版 vs 引擎的差异**」表（UE5 路线下差异只有「注释中文化」一项） |
| 6 | 必须有「**待确认**」段，明确让用户抄完再推进 |
| 7 | 必须有「**源码依据**」段，写真实路径 + 行数 |
| 8 | 头部 `>` 引用块写：依据路径 / 还原路径 / 能否独立编译 |
| 9 | 用 `🔑` `⚠️` `✅` `💡` 标记重点，和旧讲义一致 |
| 10 | 树形图用 `├─` `└─`，**新讲义不用 mermaid**（旧讲义总 md 全是树形图）；已建的 5 份 md 里的 mermaid 图**不返工**，后续新写的按树形图 |

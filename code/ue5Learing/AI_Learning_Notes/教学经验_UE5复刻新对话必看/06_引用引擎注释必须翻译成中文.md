# 06 — 引用引擎注释必须翻译成中文（不许直接贴英文原文）

> **定位**：2026-11-17 用户明确要求 —— 「遇到注释 翻译成中文」。
> **用户原话**：「清遇到注释 翻译成中文 新建md记录下来」（「清」= 请）。
> **触发场景**：我在 `11_Core_APL.xml逐行注释版.md` 里直接贴了英文原文：
> `UPL is a simple XML-based language for manipulating XML and returning strings. ...`
> 用户看不懂，要求翻译。

---

## 一、我犯的错

在 `11_Core_APL.xml逐行注释版.md` 第二节「UPL 是什么」里，我写了：

```markdown
**核心机制**（`UnrealPluginLanguage.cs:17~26` 注释原话）：

> UPL is a simple XML-based language for manipulating XML and returning strings. It contains an `<init>` section which is evaluated once per architecture before any other sections. The state is maintained and carried forward to the next section evaluated so the order the sections are executed matters.
```

**问题**：直接贴英文原文，用户看不懂。

---

## 二、正确做法

**引用引擎注释时，必须翻译成中文**，格式：

```markdown
**核心机制**（`UnrealPluginLanguage.cs:17~26` 注释原文）：

> UPL 是一种简单的、基于 XML 的语言，用于操作 XML 并返回字符串。它包含一个 `<init>` 段，该段在每个架构下、在任何其他段之前执行一次。状态会被保留并传递到下一个被执行的段，因此各段的执行顺序很重要。
```

**规则**：
1. **英文原文 → 中文译文**，不许直接贴英文
2. 保留出处（`文件:行号`）
3. 专有名词（`UPL` / `<init>` / `XML`）保留原文
4. 如果译文有歧义，可加「（原文：xxx）」补充

---

## 三、适用范围

| 场景 | 要不要翻译 |
|---|---|
| 引用引擎源码里的 `/// <summary>` 注释 | ✅ **必须翻译** |
| 引用引擎源码里的 `/* ... */` 块注释 | ✅ **必须翻译** |
| 引用引擎源码里的 `//` 行注释 | ✅ **必须翻译** |
| 引用引擎源码里的 `[Obsolete("...")]` 字符串 | ❌ **不翻译**（那是 API 契约，不是注释） |
| 引用引擎源码里的 `UE_LOG` 日志字符串 | ❌ **不翻译**（那是运行时输出） |
| 引用引擎源码里的宏名 / 类名 / 函数名 | ❌ **不翻译**（那是代码标识符） |

## 四、为什么（用户痛点）

| 痛点 | 后果 |
|---|---|
| 讲义里贴英文原文 | 用户看不懂，等于没讲 |
| 用户要自己去查词典 | 浪费时间，体验差 |
| 英文注释里有关键信息（如「顺序很重要」） | 漏掉就理解错 |

**解法**：**引用引擎注释 = 翻译成中文 + 保留出处**。

## 一、先分清两类（关键）

`UnrealTargetPlatform.Android` 这种写法之所以成立，是因为 `UnrealTargetPlatform` 是**类型**，`Android` 是它的**静态属性**。UBT 里同类的「静态成员类型」分两种：

| 类别 | 特征 | 例子 |
|---|---|---|
| **A. `partial struct` + 静态属性** | 内部只有一个 `int Id` + `UniqueStringRegistry`，名字可运行时注册 | `UnrealTargetPlatform`、`UnrealPlatformGroup`、`UnrealArch` |
| **B. `enum`** | 编译期固定，值不可追加 | `UnrealTargetConfiguration`、`TargetType`、`BuildSettingsVersion`… |

> 🔑 **一句话**：**A 类是「白板」（可被插件追加），B 类是「印刷菜单」（编译期定死）**。`Core.Build.cs` 里两种都用到了。

## 五、怎么快速判断一个 `Xxx.Yyy` 属于哪类

| 判断依据 | 结论 |
|---|---|
| 名字以 `Unreal` 开头 + 是「平台 / 平台组 / 架构」 | **A 类 struct**（可被插件追加） |
| 名字是 `UnrealTargetConfiguration` / `TargetType` / `BuildSettingsVersion` 等 | **B 类 enum**（编译期固定） |
| 点后面是 `Android` / `Windows` / `Arm64` 这种「环境名」 | 大概率 A 类 |
| 点后面是 `Shipping` / `Editor` / `Error` 这种「状态名」 | 大概率 B 类 |

> 最可靠的办法：在 `Engine\Source\Programs\UnrealBuildTool\` 下搜 `public partial struct <名字>` 或 `public enum <名字>`。

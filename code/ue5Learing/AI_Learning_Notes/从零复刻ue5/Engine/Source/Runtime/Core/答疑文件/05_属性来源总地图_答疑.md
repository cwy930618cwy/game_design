## 一、先记住这张「来源地图」（核心）

`Core.Build.cs` 里出现的属性，**只可能来自 6 个地方**：

```
Core.Build.cs 里能点的东西
├─ ① Target.xxx                    ← ReadOnlyTargetRules（296 个属性）★ 最多
│    ├─ Target.Platform / Configuration / Type / Architectures ...
│    ├─ Target.bBuildEditor / bCompileICU / bUseIris / bMergeModules ...
│    └─ Target.RelativeEnginePath / EngineDirectory ...
├─ ② Target.WindowsPlatform.xxx    ← ReadOnlyWindowsTargetRules（78 个属性）
│    ├─ Target.WindowsPlatform.Architecture
│    ├─ Target.WindowsPlatform.bUseBundledDbgHelp
│    ├─ Target.WindowsPlatform.bPixProfilingEnabled
│    └─ Target.WindowsPlatform.bEnableInstrumentation
├─ ③ Target.MacPlatform.xxx        ← ReadOnlyMacTargetRules（6 个）
├─ ④ Target.IOSPlatform.xxx        ← ReadOnlyIOSTargetRules（13 个）
├─ ⑤ Target.LinuxPlatform.xxx      ← ReadOnlyLinuxTargetRules（8 个）
├─ ⑥ Target.AndroidPlatform.xxx    ← ReadOnlyAndroidTargetRules（8 个）
└─ ⑦ 本类自己的成员（不加 Target 前缀）
     ├─ PrivatePCHHeaderFile / SharedPCHHeaderFile / NumIncludedBytesPerUnityCPPOverride
     ├─ PrivateDependencyModuleNames / PublicDefinitions ...
     └─ ModuleDirectory / EngineDirectory / PluginDirectory
```

> 🔑 **一句话**：**凡是 `Target.` 开头的，全在 `ReadOnlyTargetRules.cs`（748 行 / 296 个属性）里；凡是 `Target.WindowsPlatform.` 开头的，全在 `UEBuildWindows.cs` 的 `ReadOnlyWindowsTargetRules`（902 行起 / 78 个属性）里。**

# 05-00 — Lyra 插件详解（Plugins/）

> **定位**：Lyra 工程的 `Plugins/` 目录——它用了大量插件（GameFeature 拆玩法、CommonUI、消息路由等）。这是**插件详解系列的开篇**。
>
> **一句话**：Lyra 的 Plugins 分两类——**引擎插件**（CommonUI/GameplayMessageRouter 等，来自引擎）和 **玩法插件**（GameFeatures，把玩法拆成模块）。插件让 Lyra 高度模块化。
>
> **文件**：`e:\code\lyra_fifty_six\LyraStarterGame\Plugins/`（13 个插件）

---

## 一、Lyra 实际有哪些插件（我看的真实目录）

```
LyraStarterGame/Plugins/（13 个插件）
├── GameFeatures/        ← 玩法插件（最大，5841 文件）
├── CommonGame/          ← 通用游戏框架

```

---

## 二、插件分两类（核心认识）

Lyra 的插件分两大类：

| 类型 | 例子 | 作用 |
|------|------|------|
| **引擎插件** | CommonUI、GameplayMessageRouter、GameSettings | 引擎/通用功能 |
| **玩法插件（GameFeature）** | GameFeatures/ 下各种 | 把玩法拆成模块 |

**关键**：`GameFeatures/` 是**玩法插件**（最大），其他多是**引擎/通用插件**。

---

## 三、GameFeatures/ —— 玩法插件（最重要）

**这是 Lyra 的核心**，把玩法拆成可插拔模块。

```
GameFeatures/（5841 文件）
├── 5746 个 .uasset（资产：地图/蓝图/数据）
├── 27 个 .h + 26 个 .cpp（代码）
├── 17 个 .umap（地图）
└── 5 个 .uplugin（插件定义）
```

**一个玩法 = 一个 GameFeature 插件**：
```
GameFeatures/
├── 团队死斗玩法（一个 GameFeature）
├── 占点玩法（一个 GameFeature）
└── 俯视角玩法（一个 GameFeature）
```

---

## 四、其他重要插件（逐个说明）

### ① CommonGame —— 通用游戏框架
提供通用的游戏逻辑（如游戏实例、通用的消息、扩展点）。

### ② CommonLoadingScreen —— 加载屏幕
启动/切换关卡时的加载画面。

### ③ CommonUser —— 用户身份
抽象玩家身份（登录、邀请、会话），配合 Epic 在线服务。

### ④ GameplayMessageRouter —— 消息路由
**系统间通信**——发送/接收消息，让 UI、技能等解耦（游戏消息驱动）。

### ⑤ GameSettings —— 游戏设置
管理玩家设置（画质、音量、键位），支持 UI 绑定。

### ⑥ AsyncMixin —— 异步工具
把异步操作（加载资产）封装成易用的工具。

### ⑦ ModularGameplayActors —— 模块化 Actor
让 Actor 支持模块化扩展（配合 GameFeature）。

### ⑧ UIExtension —— UI 扩展
UI 的扩展机制，让不同系统往 UI 里加内容。

### ⑨ PocketWorlds —— 口袋世界
小型的子世界（用于菜单/预览场景）。

---

## 五、这些插件解决什么问题（组合起来）

Lyra 用这些插件拼出完整游戏框架：

```
CommonGame（游戏框架）
  + CommonUser（用户身份）
  + GameplayMessageRouter（消息通信）
  + GameSettings（设置）
  + UIExtension（UI 扩展）
  + GameFeatures（玩法模块）
  = Lyra 的完整游戏
```

**关键**：这些插件让 Lyra 高度**模块化、可复用、解耦**。

---

## 六、插件和 GameFeature 的关系（回顾）

```
Plugins/（所有插件）
├── 引擎/通用插件（CommonUI、消息路由...）→ 常驻，提供能力
└── GameFeatures/（玩法插件）→ 按需加载，拆玩法

GameFeature 特殊：能运行时加载/卸载（普通插件不能）
```

**区别**：
- 普通插件：引擎启动就加载，提供通用能力
- GameFeature：运行时按需加载，拆玩法模块

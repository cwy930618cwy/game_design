## 三、推进方式

- **一轮一个文件 = 两件套**（不是三件套）：`NN_<文件名>_总md.md`（3~5KB/85 行内）+ `NN_<文件名>复制文件.md`（完整代码 + 每行上方中文注释）。平铺阶段目录，不建 `答疑文件\` 子目录。
- **AI 只教不写**：绝不往 `<还原根>` 写任何代码文件。代码用户自己敲。
- 发完就停，等「下一步」；收到「下一步」**先验收上一份**再推进。
- **就地教 + 台账**：`AI_Learning_Notes\Lyra复刻\属性与新元素台账.md`，写讲义前查表、同轮追加、回复报"新登记 N 项"。

## 四、验收（最高优先级）

1. 同时读源文件 + 用户还原文件 → 剔注释逐字比对（`codeOurs == codeEngine` 且 `diff == 0`）。
2. 六项：路径/名字、代码行逐字一致、注释全中文、注释全在代码上方零行尾、零教学噪声、完整性。
3. 结论格式：`✅ 已核对 <文件>：路径 ✓、代码行逐字一致 ✓（codeOurs=N / codeEngine=N / diff=0）、注释全中文 ✓、零教学噪声 ✓、完整性 ✓ → 准推进`。
4. 不过 → 列差异让用户改，本轮不推进；用户没写就报"未找到还原文件"，不代写。
5. 比对脚本按文件类型剔注释；`diff > 0` 先怀疑脚本、打印前 8 条差异再下结论。

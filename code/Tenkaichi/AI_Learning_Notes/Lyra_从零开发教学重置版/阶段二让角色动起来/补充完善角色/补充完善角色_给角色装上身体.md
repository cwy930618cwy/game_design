## 一、这一步要解决什么问题（先讲为什么）

现在我们的 `ATenkaichiCharacterWithAbilities` 构造函数里只有三件事：造 ASC、造 HealthSet、设网络频率。**角色的「身体」没搭**：

1. **胶囊体（碰撞体积）** 用的引擎默认尺寸，不是 Lyra 的 `40 × 90`。
2. **移动手感**（加速度、摩擦、旋转速率）全是引擎默认，跟 Lyra 不一样。
3. **没开 `bUseControllerRotationYaw`**——这个开关不开，后面 P04 鼠标转视角**根本不生效**（这是关键！）。
4. **没设眼睛高度**（`BaseEyeHeight`），相机初始高度不对。

> 类比：角色现在是个「没量过身高、没调过肌肉、没定过眼睛位置」的素体。要先把它「量体裁衣」，后面接输入、接相机才顺。

---

## 二、为什么这一步要「插在 P04 之前」？

原计划是 P04 直接讲输入接入。但 Lyra 里，这些「身体参数」是在 `ALyraCharacter` 的构造函数里**一次性配好的**，而且其中 `bUseControllerRotationYaw` 是 P04「鼠标转视角」的**前置条件**。

如果先讲 P04（转视角），会发现「写了 `AddControllerYawInput` 却转不动」——因为角色没开旋转开关。所以把「身体参数」提前，P04 就能一气呵成，不会卡在「为什么转不动」。

> 这就是「按 Lyra 步骤」：Lyra 是先搭好角色身体（构造函数），再谈输入。

## 三、全景：这一步要补的「身体」清单

对照 Lyra `ALyraCharacter` 构造函数（`LyraCharacter.cpp` 第 30-81 行），要补五块：

| 身体部件 | 引擎类 | Lyra 怎么配 | 作用 |
|---------|--------|-----------|------|
| **胶囊体** | `UCapsuleComponent` | `InitCapsuleSize(40, 90)` + 碰撞配置 | 角色的碰撞体积（半径 40、半高 90） |
| **骨骼网格** | `USkeletalMeshComponent` | `SetRelativeRotation(0, -90, 0)` | 网格转正（建模时是 Y 前向，UE 是 X 前向） |
| **移动组件** | `UCharacterMovementComponent` | 重力/加速度/摩擦/旋转速率/蹲伏 | 移动手感（加速多快、停下多快、转身多快） |
| **控制器旋转** | `APawn` 的 bool | `bUseControllerRotationYaw = true` | **鼠标转视角生效的总开关** |
| **眼睛高度** | `APawn` 的 float | `BaseEyeHeight = 80` | 相机/视角的基准高度 |

## 四、这一步的减法（相对 Lyra，我们砍掉什么、为什么）

按铁律「只做减法、说清删了什么」，对照 Lyra 构造函数，这一步要**分清楚哪些补、哪些留到后面**：

| Lyra 有 | 我们这一步 | 为什么 |
|---------|-----------|--------|
| `ULyraCharacterMovementComponent`（**自定义**移动组件） | **不建**，用引擎原生 `UCharacterMovementComponent`，只调它的公开参数 | Lyra 的自定义移动组件覆写了跳跃/网络/地面检测等一堆逻辑，阶段二用不到；参数（重力/摩擦等）在原生组件上一样能调 |
| `SetDefaultSubobjectClass<ULyraCharacterMovementComponent>` | **不写**（保持引擎默认 `UCharacterMovementComponent`） | 同上 |
| `PawnExtensionComponent` / `HealthComponent` / `CameraComponent` | **不建** | 组件化是 P05、相机是 P06，别塞进来 |
| 团队系统 / 死亡序列 / 网络复制 / SignificanceManager | **不建** | 阶段更后面 |
| 自定义碰撞配置名 `LyraPawnCapsule` / `LyraPawnMesh` | **不写**，用引擎默认碰撞 | 自定义碰撞配置文件是独立主题，先不引入 |

> **保留（一比一照抄，只换前缀 + 用引擎原生类）**：
> - 胶囊体 `InitCapsuleSize(40, 90)`
> - 网格 `SetRelativeRotation(0, -90, 0)`
> - 移动组件的**具体参数值**（`MaxAcceleration=2400`、`BrakingDecelerationWalking=1400`、`RotationRate=(0,720,0)` 等）
> - `bUseControllerRotationYaw = true`
> - `BaseEyeHeight = 80`

## 五、这一步会新出现、需要先教的方法（先预告，写代码前逐个讲）

1. **`GetCapsuleComponent()`** —— 引擎 `ACharacter` 方法，拿角色自带的胶囊体组件。
2. **`InitCapsuleSize(半径, 半高)`** —— 胶囊体方法，设碰撞体积尺寸。
3. **`GetMesh()`** —— 引擎 `ACharacter` 方法，拿角色自带的骨骼网格组件。
4. **`GetCharacterMovement()`** —— 引擎 `ACharacter` 方法，拿角色自带的移动组件。
5. **`UCharacterMovementComponent` 的一堆参数**（`GravityScale`/`MaxAcceleration`/`GroundFriction`/`RotationRate`/`bOrientRotationToMovement` 等）——移动手感的具体旋钮。
6. **`bUseControllerRotationYaw`** —— `APawn` 的 bool，控制「是否用控制器的偏航旋转角色」。
7. **`BaseEyeHeight`** —— `APawn` 的 float，视角基准高度。

> 这些都会在写 `.cpp` 时，先讲「干嘛 + 源码在哪 + 为什么」，再给代码。

# Q04a — 第 02 课 · 第 2 步【故事篇】：`CreateDefaultSubobject` 到底在干嘛？（记分牌印档案卡）

> **所属章节**：第 02 课 · 第 2 步【2/4】建基类 `TenkaichiAttributeSet.cpp`
>
> **对应 Lyra**：`LyraPlayerState.cpp` 第 39 行
>
> **一句话**：`CreateDefaultSubobject` = **"我造自己的时候，顺手把某个零件也一起造好"**。就像记分牌一出生，就顺手把"血型档案卡"印好塞进自己怀里。

---

## 一、先看这行代码（就这一行，别怕）

```cpp
// LyraPlayerState.cpp 第 39 行
HealthSet = CreateDefaultSubobject<ULyraHealthSet>(TEXT("HealthSet"));
```

拆开看，就 3 块：

| 代码 | 人话 |
|------|------|
| `HealthSet =` | 把造好的东西，**存进"HealthSet 这个格子"里**（记分牌身上预留的格子） |
| `CreateDefaultSubobject<ULyraHealthSet>` | **"造一个血量集零件"** |
| `(TEXT("HealthSet"))` | 给它**起个名字**叫 "HealthSet"（方便调试时认出来） |

---

## 二、剧场故事：记分牌出生时，顺手印了张档案卡

> 用你的人物谱世界观（[02_开演后人物谱](../../人物介绍/02_开演后_玩家与角色人物谱.md)）。

### 角色对照

| 代码里的东西 | 剧场里是谁 |
|-------------|-----------|
| `PlayerState`（记分牌） | 📊 **记分牌**——记这个玩家的分数、队伍 |
| `HealthSet`（血量集） | 📇 **血型档案卡**——记这个演员的血量 |
| `CreateDefaultSubobject` | **"顺手印一张卡"这个动作** |

### 故事

📊 **记分牌**一"出生"（被游戏造出来时），它要做一件事：

> "我是记分牌，我得**随身带一张血型档案卡**，不然演员受伤了没东西记血量。"

于是记分牌在**自己的构造函数里**喊一声：

```cpp
HealthSet = CreateDefaultSubobject<ULyraHealthSet>(TEXT("HealthSet"));
//          └── "顺手印一张血型档案卡，塞进我怀里"
```

**"印卡"这个动作一发生，档案卡上的"初始血量 100"就自动写好了**（这就是血量集构造函数 `Health(100.0f)` 干的活）。

从此，这张卡就**挂在记分牌身上**，记分牌管血量时直接摸出这张卡用。

---

## 三、关键：为什么叫"顺带造"？—— 因为它跟着"记分牌出生"一起发生

你不用单独跑一趟去"造血量集"。**记分牌被造出来的那一刻，它怀里的档案卡也一起被印好了。**

```
游戏开演，导演造出一个记分牌
        ↓
记分牌执行自己的构造函数（"我出生了，开始装备自己"）
        ↓
   遇到这一行：CreateDefaultSubobject<ULyraHealthSet>
        ↓
   "顺手印一张血型档案卡" → 档案卡构造函数自动跑 → 初始血量写成 100
        ↓
记分牌出生完毕，怀里已经揣着这张卡了
```

> **类比**：你生下来（记分牌出生），妈妈顺手给你别上一张**出生证明卡**（档案卡），卡上已经印好"体重 3 公斤"（初始血量）。你不用长大后自己去办这张卡——**出生那一刻它就自动别在你身上了**。

---

## 四、这跟"构造函数"什么关系？（回扣你上一个问题）

你上一个问题问"构造函数谁调用"——**答案就在这**：

- 记分牌用 `CreateDefaultSubobject<ULyraHealthSet>` **造**血量集的那一刻，
- 血量集的**构造函数就自动执行了**（写好了初始血量 100）。

所以：

> **`CreateDefaultSubobject` = "造对象"的动作** → 一造，构造函数自动跑。
> 你从头到尾**没写一行"调用构造函数"**，因为"造"这个动作本身就触发了构造函数。

---

## 五、一句话结论

**`CreateDefaultSubobject<ULyraHealthSet>` 就是记分牌出生时"顺手印一张血型档案卡塞进怀里"——印卡（造对象）的瞬间，卡上的初始血量 100（构造函数）就自动写好了。这就是"造对象 → 构造函数自动触发"的过程，你不用手动调构造函数。**

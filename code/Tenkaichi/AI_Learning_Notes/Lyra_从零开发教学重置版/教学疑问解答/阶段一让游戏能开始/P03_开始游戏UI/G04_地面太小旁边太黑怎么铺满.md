# G04 — 地面太小、旁边太黑，怎么铺满地面

> **问题**：开始搞地面，发现地面只有一小块，旁边看出去是黑的，怎么铺满？
>
> **一句话**：旁边黑是因为**超出地面的地方没有几何体，就是黑的虚空**。解决 = 把地面做大铺满视野。用引擎内置 `Plane` 拖出来，Scale 放大到 100+，再给个材质。

---

## 一、为什么旁边是黑的

- 关卡里"看得见的地"就是地面这个几何体。
- **超出地面范围的地方没有任何物体**（没有地、没有光反射），相机看到的就是黑色虚空。
- 所以"旁边黑"不是光照问题，是**地面不够大**。

---

## 二、做法：用引擎内置 Plane 放大铺地（引擎真实资源，已核实）

引擎内置平面资源路径：`/Engine/BasicShapes/Plane`（`BasicShapes/Plane.uasset`）。

**操作**：
1. 底部 **`Content Browser`**（内容浏览器），路径栏输入 `/Engine/BasicShapes/` 回车
2. 找到 **`Plane`**，拖进视口
3. 选中它 → 右侧 `Details` → `Transform` → **Scale** 的 X、Y 改成 **100**（甚至 500）
   - Plane 默认 100×100cm（1米×1米）；Scale 100 = 100米×100米，够铺满视野
4. 位置 Z 保持 0（贴地）

---

## 三、给地面一个材质（不然纯灰/纯黑不好看）

- 选中地面 → `Details` → `Material` 槽
- 简单方案：Content Browser 搜 **`WorldGridMaterial`**（引擎内置网格材质），拖到材质槽 → 有网格地面效果
- 或搜 `M_Basic_Wall` 等内置材质

> 更省事：用 `BasicShapes/Cube` 拉扁（Scale Z 设 0.5）当地板，比 Plane 有厚度、角色不会穿模。

---

## 四、为什么这步只能手动（19 号铁律的例外）

地面是**关卡里的 Actor**，放大/位置/材质都是拖拽 + 面板调的，产物存进二进制 `.umap`，**没法用代码/配置表达**。属于 19 号铁律里"确实只能手动"的例外。

---

## 五、一句话结论

**旁边黑 = 超出地面没有几何体。用引擎内置 `/Engine/BasicShapes/Plane` 拖出来，Scale X/Y 放大到 100+ 铺满，再给个材质（如 `WorldGridMaterial`）。地面是关卡 Actor，只能编辑器手动放大，没法用代码写。**

# 3.1 CommonGame + CommonUser 插件 —— 总 md

> **定位**：阶段三第 1 小步。把 Lyra 的 `CommonGame` / `CommonUser` 两个插件**拷贝进用户工程**。
> 源码依据：`E:\ue5\LyraStarterGame5.6\LyraStarterGame\Plugins\CommonGame\` 和 `...\Plugins\CommonUser\`
> 性质：**装插件（拷贝目录）**，不是写代码。装完就能编。

---

## 一、为什么要先装这两个插件（解决什么问题）

你工程 `.uproject` **早就声明了** `CommonUser` 和 `CommonGame`（都 `Enabled: true`），但 `Plugins\` 里**只有 `ModularGameplayActors` 和 `GameplayMessageRouter`**——两个插件本体没拷过来。

为什么必须现在装：

1. **`GameInstance` 的父类**：Lyra 的 `LyraGameInstance` 继承 **`UCommonGameInstance`**（来自 CommonGame）。
2. **`PlayerController` 的父类**：Lyra 的 `LyraPlayerController` 继承 **`ACommonPlayerController`**（也来自 CommonGame）。
3. **本地玩家**：`ULyraLocalPlayer` 继承 **`UCommonLocalPlayer`**。

> 阶段四的角色体系（GameInstance / PlayerController / LocalPlayer）**全部继承自 CommonGame**。不装它，阶段四、阶段五直接编译不过、卡死。

**用大白话讲**：CommonGame 是"玩家 + 会话 + UI"的地基，Lyra 的很多"玩家级"类都站在它肩膀上。它是**别人都要用的底座**，所以必须先铺。

---

## 二、要装哪几个插件（依赖核对，铁律 30）

### 2.1 直接拷的 2 个（Lyra 私有，用户工程没有）

| 插件 | 作用 | 来源 |
|------|------|------|
| **CommonUser** | 在线/平台操作（登录、切换用户、初始化）的蓝图包装 | Lyra `Plugins\CommonUser\` |
| **CommonGame** | 通用 gameplay 类：GameInstance / PlayerController / LocalPlayer / UI 策略 | Lyra `Plugins\CommonGame\` |

### 2.2 它们依赖什么（查 `.uplugin` 确认，不用拷，已有/引擎自带）

**CommonGame.uplugin** 依赖：
- `CommonUI`（引擎自带 ✅）
- `CommonUser`（**一起拷** ✅）
- `ModularGameplayActors`（你已装 ✅）
- `OnlineFramework`（引擎自带 ✅）

**CommonUser.uplugin** 依赖：
- `OnlineSubsystem`、`OnlineSubsystemUtils`、`OnlineServices`（引擎自带 ✅）

> 结论：**只需要拷 `CommonGame` 和 `CommonUser` 两个目录**，其余依赖引擎自带或你已装。一条依赖链全部闭合，不会缺头。

## 三、怎么装（操作步骤）

> ⚠️ 这是**拷贝文件**操作。两个插件的 `Binaries\`、`Intermediate\` 是 Lyra 的构建产物，**不需要拷**——拷贝 `.uplugin` + `Source\` + `Config\`（如有）+ `Resources\`（如有）即可，进你工程会重新编译。

1. 从 Lyra 复制目录：
   - `E:\ue5\LyraStarterGame5.6\LyraStarterGame\Plugins\CommonGame\` → 你的 `E:\ue5\game_design\code\Tenkaichi\Plugins\CommonGame\`
   - `E:\ue5\LyraStarterGame5.6\LyraStarterGame\Plugins\CommonUser\` → 你的 `E:\ue5\game_design\code\Tenkaichi\Plugins\CommonUser\`
2. `.uproject` **不用改**（已声明）。
3. 重新编译/启动工程，让 Unreal 识别并编译两个插件。

## 四、装完后的全景（CommonGame 里都有啥）

拷进来后，CommonGame 提供这些"地基类"（现在先只认个脸，用到再细讲）：

| 类 | 作用 | 阶段 |
|----|------|------|
| `UCommonGameInstance` | 游戏实例基类（InitState 管理） | 阶段五 GameInstance 继承它 |
| `ACommonPlayerController` | 玩家控制器基类 | 阶段四 PlayerController 继承它 |
| `UCommonLocalPlayer` | 本地玩家基类 | 阶段四 LocalPlayer 继承它 |
| `UCommonPlayerInputKey` / `UCommonUIExtensions` / `UPrimaryGameLayout` / `UGameUIManagerSubsystem` / `UGameUIPolicy` | UI 布局与管理 | 阶段六 UI 用 |

> 这步**只装不拆**——CommonGame/CommonUser 是插件（不是我们项目 Source 要一比一还原的文件），装好能编译即可，里面的类等用到时再讲。

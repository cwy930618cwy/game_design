| # | 理由 | 不做的后果 |

| 1 | `.uproject` 是引擎唯一读的入口 | 模块名不对 → `Source\LyraGame\` 不被识别 → 后面 449 个文件全白建 |


## 五、教学原则（为什么这么设计）

### 5.1 三条铁律

| # | 铁律 | 具体表现 |
|---|---|---|
| 1 | **AI 只教不写** | 我只产出 md 讲义，**绝不往 `Source\` 写任何 `.h/.cpp/.cs/.uproject`** —— 代码你自己敲 |
| 2 | **一轮一个文件** | 发完即停，等「下一步」；禁止一次连发多份 |
| 3 | **注释写在代码正上方** | 中文注释**独占一行**，严禁行尾注释；零英文注释；零教学噪声（`// ← 改成XXX`） |

### 5.2 为什么「先讲为什么，再给代码」

每个文件的**总 md 都在复制文件之前**，讲清三件事：

```
① 这个文件解决什么问题   ← 没有它会发生什么
② 内部结构是什么         ← 一眼看清全貌
③ 依赖谁、被谁依赖       ← 为什么放在这个顺序
```

懂了「为什么」再敲「怎么写」，敲的时候才知道每一行在干什么。

### 5.3 为什么「就地教」而不是「攒到末统一讲」

复制文件 md 里，**每段代码后面立刻列「本段新元素」**：

```cpp
// 段 2：前置声明
class UObject;

// 本段新元素（立刻列，不许攒到末尾）：
// - class UObject;  —— 前置声明，只为让指针类型成立
```

攒到最后统一列 → 你敲到一半就忘了这段在讲什么。

### 5.4 为什么「渐进式偏差」要写清楚

Lyra 是完整工程，我们是从零搭。有些东西 S00 阶段**不能一次到位**：

| 偏差 | Lyra | 我们 S00 | 何时收敛 |
|---|---|---|---|
| `Modules` | `LyraGame` + `LyraEditor` | 只有 `LyraGame` | S22 补 `LyraEditor` 模块 |
| `Plugins` | 76 项 | **70 项** | `PocketWorlds`→S05；5 个示例玩法→S23 |
| `LyraEditor.Build.cs` | 13+12 个依赖 | **5 个依赖（占位）** | S22 换正式版 |
| `LyraEditor.cpp` | 10470 B | **393 B（占位）** | S22 换正式版 |
| `DefaultEngine.ini` 类替换 | 9 行 | 空 | S07/S12/S19/S22 分批 |
| `DefaultGame.ini` 资产规则 | 8 条 | **1 条** | S07/S08 |
| 碰撞 Profile | 5 个自定义 | **1 个（WaterBodyCollision）** | S06 |

> 📌 **每次偏差都写在对应讲义的总 md 里**，标明「什么时候收敛」。不藏着掖着，避免你以后困惑「为什么跟 Lyra 不一样」。

## 八、常见疑问（FAQs）

**Q1：为什么 S00 敲完还是编不过？**
A：设计如此。`LyraGame.Build.cs` 依赖 9 个插件模块（`ModularGameplayActors` 等），那些要 S01~S05 才建。S05 末才是第一个「能编译」的里程碑。

**Q2：为什么 `LyraEditor` 要放个「占位版」，不直接照抄 Lyra？**
A：Lyra 正式版依赖 `FLyraEditorEngine` / `GameEditorStyle` / `EditorValidator` 等类，那些 S22 才复刻。现在照抄 → 找不到类 → 报新错。

**Q3：为什么 `.uproject` 只写 70 项插件，不写 Lyra 的 76 项？**
A：差的 6 项（`PocketWorlds` + 5 个示例玩法）源码还没建。**先建目录再写清单**，反过来必报错。

**Q4：为什么 9 个插件本机没有却不报错？**
A：全部 `Enabled: false` → 引擎压根不查。另有 2 个靠 `Optional: true` / 平台白名单豁免。详见 `00A`。

**Q5：`Config` 里碰撞配置到底该写哪个文件？**
A：**`DefaultEngine.ini`**。`UCollisionProfile` 类头是 `UCLASS(config=Engine)`，读取代码写死 `GEngineIni`。写 `DefaultEditor.ini` = 静默失效。详见 `00B` 第 2 步。

**Q6：为什么每轮只教一个文件？**
A：一轮一个 → 你敲完能立刻验证、我也能立刻验收。一次发 5 个 → 你敲到第 3 个就记不清第 1 个的细节了。

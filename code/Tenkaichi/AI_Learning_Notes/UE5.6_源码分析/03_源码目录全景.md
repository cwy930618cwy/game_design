# 03 - 源码目录全景（Source/）

> 路径：`c:\Program Files\Epic Games\UE_5.6\Engine\Source\`
> 规模：63,078 文件（27,370 .h + 16,732 .hpp + 12,111 .cpp + 2,378 .cs）

## 一、五大分区

```
Source/
├── Runtime/        ← 运行时（17,858 文件）⭐⭐⭐ 游戏运行必需
├── Editor/         ← 编辑器（7,511 文件）⭐⭐  编辑器专用
├── Developer/      ← 开发工具（3,309 文件）⭐   打包/调试
├── Programs/       ← 独立程序（2,609 文件）     命令行工具
├── ThirdParty/     ← 第三方库（31,789 文件）    外部依赖
├── UnrealEditor.Target.cs
└── UnrealGame.Target.cs
```

## 二、Runtime/ — 运行时模块（最重要）

### 2.1 三大基石模块 ⭐⭐⭐

| 模块 | 文件数 | 作用 | 必须掌握 |
|------|--------|------|---------|
| **Core** | 1,993 | 基础类型/容器/数学/委托/内存管理 | ✅ |
| **CoreUObject** | 856 | UObject 系统/反射/序列化/GC | ✅ |
| **Engine** | 3,832 | 游戏引擎核心（Actor/Component/World/GameInstance） | ✅ |

这三块是 UE 的**地基**，所有其他模块都依赖它们。

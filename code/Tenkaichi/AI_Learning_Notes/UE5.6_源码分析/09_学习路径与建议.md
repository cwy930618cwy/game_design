## 二、学习方法

### 2.1 阅读源码的顺序

```
1. 先看 .h 头文件 → 了解接口和成员
2. 再看 .cpp 实现 → 理解逻辑
3. 找使用示例 → Lyra 里的用法
4. 画图记忆 → 类图/时序图
```

### 2.2 善用 IDE

| IDE | 推荐度 | 特点 |
|-----|--------|------|
| **Visual Studio 2022** | ⭐⭐⭐ | 官方支持，调试强大 |
| **Rider** | ⭐⭐⭐ | 跨平台，重构强大 |
| **VS Code** | ⭐⭐ | 轻量，需配置 |
| **CLion** | ⭐⭐ | C++ 专业版 |

**必备插件**：
- Visual Assist（VS）
- Unreal Engine Tools（Rider）
- C++ IntelliSense（VS Code）

### 2.3 搜索技巧

```bash
# 全局搜索类名
Ctrl+Shift+F "class.*LyraCharacter"

# 搜索函数定义
Ctrl+Shift+F "void.*BeginPlay"

# 搜索宏
Ctrl+Shift+F "UPROPERTY.*Replicated"

# 搜索特定文件
Ctrl+P "Lyra*.h"
```

### 2.4 调试技巧

```cpp
// 1. 加日志
UE_LOG(LogTemp, Log, TEXT("Health = %f"), Health);

// 2. 断点
F9 设置断点 → F5 启动调试 → F10 单步跳过 → F11 单步进入

// 3. 查看调用栈
Debug → Windows → Call Stack

// 4. 查看变量
Debug → Windows → Locals / Watch
```

## 三、常见问题

### Q1：源码太大，看不完怎么办？
**A**：不要试图看完。UE 源码 6 万+ 文件，没人能全看完。按需深入：
- 遇到不懂的类 → 去看它的定义
- 遇到不懂的函数 → 去找它的实现
- 遇到不懂的宏 → 去查它的展开

### Q2：应该先看引擎还是先看 Lyra？
**A**：**先看引擎基础**（Core/CoreUObject/Engine），再看 Lyra。因为 Lyra 的所有代码都建立在这三大模块之上。没有基础直接看 Lyra 会一头雾水。

### Q3：需要记住所有 API 吗？
**A**：不需要。记住**概念和查找方法**即可：
- 知道有 TArray/TMap/TSet 这些容器
- 知道 UPROPERTY/UFUNCTION 的作用
- 知道 Actor 的生命周期函数
- 具体 API 用时再查

### Q4：蓝图重要还是 C++ 重要？
**A**：都要学。Lyra 是**C++ 为主，蓝图为辅**：
- C++ 负责核心逻辑、性能敏感部分
- 蓝图负责表现层、快速迭代部分
- 两者通过 UFUNCTION/UPROPERTY 桥接

### Q5：如何验证自己理解了？
**A**：三个标准：
1. 能画出 Core/CoreUObject/Engine 的关系图
2. 能解释 Lyra 为什么这样组织代码
3. 能独立实现一个简单功能（如新 GA/新 UI）

---

## 一、Metasound — 下一代音频引擎

### 1.1 什么是 Metasound？

**Metasound** 是 UE5 的新一代音频系统，替代传统的 Sound Cue / Sound Class：

| 特性 | 传统音频 | Metasound |
|------|---------|-----------|
| 架构 | 层级式（Sound Cue → Sound Class） | 节点图式（类似材质编辑器） |
| 参数化 | 有限 | 完全参数化 |
| DSP | 固定 | 可编程 |
| 性能 | 一般 | 优化更好 |

### 1.2 核心概念

| 类 | 作用 |
|----|------|
| `UMetasoundSource` | Metasound 资产 |
| `UMetasoundComponent` | 播放组件 |
| `FMetasoundContext` | 播放上下文 |
| `UMetasoundSettings` | 设置 |

### 1.3 节点图

Metasound 用**节点图**编辑音频：

```
[Oscillator] → [Gain] → [Filter] → [Output]
     ↑            ↑         ↑
  频率控制    音量控制   滤波控制
```

### 1.4 Lyra 中的用途

- 武器音效（枪声、换弹声）
- 脚步音效（根据地面材质变化）
- 环境音效（风声、背景音）
- UI 音效（按钮点击、提示音）

## 二、Niagara — 粒子特效系统

### 2.1 什么是 Niagara？

**Niagara** 是 UE5 的主力粒子系统，替代旧的 Cascade：

| 特性 | Cascade | Niagara |
|------|---------|---------|
| 架构 | 固定管线 | 可编程模块 |
| 脚本 | 无 | HLSL / 可视化脚本 |
| 性能 | 一般 | 更好（GPU 粒子） |
| 扩展性 | 有限 | 高度可扩展 |

### 2.2 核心概念

| 类 | 作用 |
|----|------|
| `UNiagaraSystem` | 特效系统资产 |
| `UNiagaraEmitter` | 发射器 |
| `UNiagaraComponent` | 播放组件 |
| `UNiagaraDataInterface` | 数据接口 |

### 2.3 模块系统

Niagara 用**模块**构建特效：

```
Emitter
├── Spawn Rate (生成速率)
├── Lifetime (生命周期)
├── Velocity (速度)
├── Color (颜色)
├── Size (大小)
└── Custom HLSL Module (自定义)
```

### 2.4 Lyra 中的用途

- 枪口火焰
- 子弹轨迹
- 爆炸效果
- 烟雾/尘土
- 技能特效

## 三、AudioGameplay — 音频玩法集成

### 3.1 核心功能

将音频与 Gameplay 事件绑定：

```cpp
// 监听 GameplayTag 触发音效
UCLASS()
class UMyAudioGameplayListener : public UGameplayListener
{
    void OnTagAdded(FGameplayTag Tag);
};
```

### 3.2 Lyra 中的用途

- 击杀提示音
- 得分音效
- 技能释放音效
- 受击反馈音

---

## 四、SoundFields — 声场

### 4.1 核心功能

在场景中放置**声场区域**，自动调整混响：

```cpp
// 小房间 → 短混响
// 大教堂 → 长混响
// 户外 → 无混响
```

### 4.2 Lyra 中的用途

- 室内/室外环境区分
- 不同房间的声学特性

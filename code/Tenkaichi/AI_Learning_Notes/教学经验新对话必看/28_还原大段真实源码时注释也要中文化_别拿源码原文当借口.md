# 28 — 教学铁律：还原「大段真实源码」时，注释也必须中文化，别拿"这是源码原文"当借口

> **定位**：本文件是 [21_教学代码注释一律写成中文](./21_教学代码注释一律写成中文.md) 在「**还原大段真实源码（如 `Target.cs` / `Build.cs` 等）**」这个具体场景上的精确补强。新对话开始教学前，除 00~27 外，**必须读本文件**。
>
> **一句话**：只要是我贴出来**给用户照着写**的代码，不管它是 `.h` / `.cpp` 还是 `Target.cs` / `Build.cs` / `.uproject`，**里面的注释一律翻译成中文**；不能因为"这段是 Lyra 源码原文"就原样保留英文。

---

## 一、这条铁律怎么来的（真实教训，2026-10-08）

教「阶段一第 1.5 步 · Game 与 Editor Target 完整还原」时，AI 把 `TenkaichiGame.Target.cs`（283 行）和 `TenkaichiEditor.Target.cs`（24 行）完整贴进了教学 md，但**注释全是英文**，原样照抄了 Lyra。

用户当场纠正：

> "教学遇到注释英文要改为中文，你为什么都不看经验呢？"

**根因复盘**：21 号铁律的原始例子是 `.h`（`FTenkaichiInputAction`）里的注释，AI 把这个经验**只记住了 `.h`/`.cpp` 场景**。等到还原 `Target.cs` 这种**几十上百行、注释密集的真实源码**时，AI 产生了"这是源码原文，引用要保真，注释就别动了"的错误念头，于是整段照抄英文。

**关键澄清**（和 21 号一脉相承）：

| 维度 | 语言 |
|------|------|
| **代码本身**（类名/方法/宏/关键字/参数） | 英文，原样不动（一比一还原） |
| **注释**（`//`、`/* */`） | **中文**，翻译成人话（哪怕在 `Target.cs` 里也一样） |

> 注释是给人看的说明文字，**不是源码保真的一部分**。翻译成中文，既不破坏"一比一还原"，也不破坏"引用真实源码"。

---

## 二、核心规则（一条）

**凡是贴出来「给用户照着写」的代码——不分文件类型——注释一律翻译成中文；代码本身原样不动。**

适用范围（都要中文化注释）：

| 文件类型 | 例子 | 注释要不要中文 |
|---------|------|--------------|
| `.h` / `.cpp` | `TenkaichiGameModule.cpp` | ✅ 要 |
| `Build.cs` | `TenkaichiGame.Build.cs` | ✅ 要 |
| `Target.cs` | `TenkaichiGame.Target.cs`（283 行）、`TenkaichiEditor.Target.cs` | ✅ 要 |
| `.uproject` / `.ini` 等配置 | `Tenkaichi.uproject` | ✅ 要（如有注释） |

> 一句话：**注释中文化，不看文件类型、不看行数多少，只看"这是不是贴给用户照着写的代码"。**

---

## 三、什么算违规（反面清单）

| ❌ 违规说法 | ✅ 正确做法 |
|-----------|-----------|
| "这是 `Target.cs`，源码原文引用，注释保留英文保真" | "`Target.cs` 里的注释也翻译成中文，代码原样" |
| "这段代码 283 行注释太多，先保留英文后面再翻" | "283 行注释全部当场翻成中文，一字不落" |
| "`.uproject` 是配置文件，注释英文没关系" | "配置文件里的注释也中文化" |
| "21 号只说了 `.h`，`Target.cs` 不在范围" | "21 号管所有教学代码，`Target.cs` 一样要翻" |

---

## 四、执行要求（贴任何代码前自检）

1. **文件类型不管**：这段代码是 `.h` 还是 `Target.cs`？——**不重要**，注释都要中文。
2. **扫注释**：这段代码里有哪些 `//`、`/* */` 注释？都翻译成中文了吗？
3. **代码原样**：翻译注释时，有没有误改类名/方法/宏/关键字？（不能改）
4. **别等提醒**：注释中文化是**主动做**，不是等用户纠正"你怎么又不翻"。

---

## 五、一句话结论

**贴给用户照着写的代码，不分文件类型（`.h`/`.cpp`/`Target.cs`/`Build.cs`/配置文件），注释一律翻译成中文、代码原样不动。不能拿"这是源码原文要保真"当借口保留英文注释——注释是给人看的说明文字，不在"一比一还原"和"源码保真"的范围内。**

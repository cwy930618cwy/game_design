## 一、【最高铁律】教学必须基于真实源码，禁止自己瞎想

**教任何 Lyra / UE5 知识点前，必须先在下面两个权威来源里找到对应的真实代码/实现，再据此讲解。绝不凭记忆或想象编造。**

| 权威来源 | 路径 | 用途 |
|---------|------|------|
| 🎯 **Lyra 示例项目源码** | `e:\ue5\LyraStarterGame5.6\LyraStarterGame` | 讲 Lyra 架构/写法/范式时，**必须引用这里的真实源文件**（`Source/LyraGame/...`、`Plugins/...`） |
| 🎯 **UE 5.6 引擎源码** | `c:\Program Files\Epic Games\UE_5.6` | 讲引擎机制/底层 API 时，**必须引用这里的真实实现**（`Engine/Source/...`、`Engine/Plugins/...`） |

### 执行要求（每次教学都要做到）
1. **先查后教**：讲解前，用工具到上述两个目录里**搜索/读取真实文件**，确认 Lyra/引擎里到底怎么写的。
2. **引用到具体文件**：教学时要点明"参考 `xxx.h/.cpp` 第几行 / 哪个函数"，给出**真实代码证据**，而不是泛泛而谈。
3. **不确定的就不教**：如果在这两个来源里找不到对应实现，**明确告诉用户"未找到源码依据"**，而不是自己编一个"应该是这样"。
4. **区分"源码事实"与"我的推断"**：凡是我自己延伸的类比/总结，要显式标注"这是我的类比，非源码"，不能和真实源码混为一谈。

> ⚠️ **反面教材**：凭记忆说"Lyra 的 ASC 挂在 PlayerState 上"——这必须去 `LyraCharacterWithAbilities` / `LyraPawnExtensionComponent` 里核实真实挂载点后再教。宁可慢一步查源码，不要快一步编答案。

# 37 — 新建 md 前必须先看目录既有命名格式，照抄，不自创

> **定位**：本文件是 [15_教学md文件命名也要一比一对应Lyra](./15_教学md文件命名也要一比一对应Lyra.md) 和 [29_新内容先总md再教h再教cpp_别凭进度表猜下一步](./29_新内容先总md再教h再教cpp_别凭进度表猜下一步.md) 的**落地执行版**，教训来自 2026-10-14 阶段四 4.8.0。
> 新对话开始教学前，除 00~36 外，**必须读本文件**。

---

## 一、这条铁律怎么来的（真实教训，2026-10-14）

教 4.8.0 `CameraAssistInterface` 时，我新建了教学 md，起名：

```
❌ 4.8.0-h_CameraAssistInterface_接口声明.md
```

**错误点**：
1. 用了连字符 `-h`，而目录里既有规范是下划线 `_h`（`4.7.3_Character_h.md`）。
2. 用了中文后缀「接口声明」，而既有规范是 `_h` / `_cpp` / `_总md` 三种固定后缀。
3. 编号用了 `4.8.0`（带 `.0`），而既有编号体系类从 `.1` 开始（4.7.1 / 4.7.2 / 4.7.3…）。

**用户当场怒斥**：「为什么开始乱命名了 这是啥啊」「看下之前的」。

**根因复盘**：
1. **建 md 前没 `list_files` 看目录里已有的命名格式**，凭脑子里的印象随手起名。
2. **把"命名"当成了可以"即兴发挥"的事**——自创了 `-h`、中文后缀、`.0` 编号，而不是机械照抄目录既有模式。
3. 深层病根：和 [14](./14_禁止自作聪明搞二选一简化.md) / [15](./15_教学md文件命名也要一比一对应Lyra.md) / [24](./24_前缀替换规则_lyra对应Tenkaichi其余一模一样.md) 反复骂的是同一个——**该照抄的地方动脑子、自创一套**。

---

## 二、核心规则（硬动作）

**新建任何教学 md 前，第一步永远是：`list_files` 看当前目录里已有哪些文件、命名格式是什么，然后照抄。绝不自创。**

具体三步：
1. **先看目录**：用 `list_files` 列出目标目录（如 `阶段四：角色体系`），看清楚既有文件命名格式。
2. **提炼格式**：既有格式是 `主号_类名_总md.md` / `主号_类名_h.md` / `主号_类名_cpp.md`（如 `4.7.3_Character_h.md`），就照这个格式。
3. **套用格式**：新文件沿用同一套 `主号_类名_层级后缀`，只换类名和编号，不自创分隔符、不换中文后缀、不乱用 `.0`。

---

## 三、阶段四目录的既有命名规范（作为参照模板）

```
4.7.3_Character_总md.md          ← 总 md：主号_类名_总md
4.7.3_Character_h.md             ← .h：主号_类名_h
4.7.3_Character_cpp.md           ← .cpp：主号_类名_cpp
4.7.4-2_CharacterWithAbilities_h.md   ← 同类的后续步骤：主号-N
4.7_CharacterPawn_总md.md        ← 节总览：x.x_节名_总md
```

**要点**：
- 分隔符一律用下划线 `_`，层级后缀是 `_总md` / `_h` / `_cpp` 三种。
- 类名部分和 Lyra 一一对应（[15](./15_教学md文件命名也要一比一对应Lyra.md) / [24](./24_前缀替换规则_lyra对应Tenkaichi其余一模一样.md)），只换 `Lyra`→`Tenkaichi`。
- 同类多文件用 `主号-N`（如 `4.7.4-2`），不用 `.0`、不用连字符 `-h`。

## 四、和 29 号的关系（澄清一个易踩的坑）

> ⚠️ **注意**：铁律 [29](./29_新内容先总md再教h再教cpp_别凭进度表猜下一步.md) 规则 4 里写过「`.h` 用 `x.x-h_..._h.md`」——这个写法**与实际目录不一致**（目录实际用 `x.x_类名_h.md`，没有连字符）。**以实际目录为准**，不要被 29 号那个 `x.x-h` 写法带偏。

- **29 号**管的是「先总 md → 教 h → 教 cpp」的**节奏**。
- **本文件（37）**管的是「建 md 时**命名格式**怎么定」——**先看目录既有格式，照抄**。
- 两者不冲突：节奏按 29 号，命名按「目录实际格式」。

## 五、对照表（做什么 / 不做什么）

| 场景 | ✅ 我做 | ❌ 我不做 |
|------|--------|----------|
| 新建教学 md | 先 `list_files` 看目录既有格式，照抄 | 凭印象/惯性直接起名 |
| 层级后缀 | `_总md` / `_h` / `_cpp`（下划线） | 用 `-h` / `-cpp` / 中文后缀 |
| 同类多文件编号 | `主号-N`（如 `4.7.4-2`） | 用 `.0` / 连字符 `-h` |
| 类名部分 | 和 Lyra 一一对应，只换前缀 | 自创 / 简化 / 改短 |
| 拿不准 | 打开目录数一遍已有文件格式 | 猜一个 |

## 六、执行要求（每次建 md 自检）

1. **建 md 前**：`list_files` 列出目标目录，看清既有命名格式。
2. **提炼格式**：确定 `主号_类名_层级后缀` 的具体写法。
3. **套用**：新文件沿用同一格式，只换类名和编号。
4. **自检**：我起的文件名，是不是和目录里既有文件「同一套格式」？是不是自创了分隔符/后缀/编号？是就是违规。

---

## 七、一句话结论

**新建任何教学 md 前，先 `list_files` 看当前目录的既有命名格式，机械照抄 `主号_类名_总md/h/cpp` 这套格式，只换类名和编号，绝不自创分隔符（`-h`）、不换中文后缀、不用 `.0` 编号。拿不准就数一遍目录，不许猜。**

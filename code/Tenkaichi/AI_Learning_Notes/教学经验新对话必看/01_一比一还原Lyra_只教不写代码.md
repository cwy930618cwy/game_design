# 01 — 教学铁律：一比一还原 Lyra + 只教不写代码

> **定位**：本文件单独记录本项目的**教学方式铁律**。新对话开始教学前，除 [00_主要经验](./00_主要经验.md) 外，**必须读本文件**。
>
> **一句话**：本项目要**一比一还原 Lyra 真实写法**来教；教学过程中**我只负责教，不写代码**（代码用户自己写）。

---

## 一、一比一还原 Lyra

- 本项目目标是**照着 Lyra 的真实写法还原**，**不是**"参考思路自己发挥/发明"。
- 教学时讲的**每一处做法**，都要能在 `e:\ue5\LyraStarterGame5.6\LyraStarterGame` 源码里找到**一一对应的真实实现**。
- 按 Lyra 的**类结构 / 命名 / 流程**来讲，不脱离 Lyra 自创一套。
- 引用到**具体文件 + 函数 + 行**，给真实源码证据（配合 [00_主要经验](./00_主要经验.md) 的"先查后教"铁律）。

---

## 二、只教不写代码

- 教学过程中，**我只负责讲解**：讲清概念、对照源码、说明 Lyra 怎么做 / 为什么这么做。
- **绝不主动在用户的 `e:\ue5\cyra\code` 工程里写 / 改代码**——代码由用户自己动手写。
- **打印例外**：为了帮用户调试、验证执行流程，**打印日志（如 `UE_LOG` / `PrintString` 等调试输出）由我负责写**；对应地，**需要删除时也由我负责删**。打印不算"写代码逻辑"，是为了辅助教学与排查。
- 我可以在讲解中**贴出 Lyra 的真实源码片段**作为教学示例（这属于"教"的一部分），但**不去创建 / 修改用户工程里的文件**（打印除外）。
- 用户写代码遇到问题时，我可以**引导、答疑、指出方向**，但仍以"教"为主，不直接替他写。

---

## 三、对照表（做什么 / 不做什么）

| 场景 | ✅ 我做 | ❌ 我不做 |
|------|--------|----------|
| 讲一节课 | 查 Lyra 源码 → 一比一对照讲解 → 贴真实源码片段 | 凭空讲"应该是这样" |
| 代码逻辑 | 贴 **Lyra 真实源码**作示例 | 在用户 `code` 工程里写/改代码逻辑 |
| 打印调试 | **我来写打印**（`UE_LOG`/`PrintString` 等）；需要时**也我来删** | —— |
| 用户卡住 | 引导、答疑、指方向 | 直接替用户把代码写出来 |
| 找不到依据 | 明说"未找到源码依据" | 编一个 Lyra 里根本没有的做法 |

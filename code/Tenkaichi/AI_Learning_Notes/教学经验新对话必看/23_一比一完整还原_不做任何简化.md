## 四、md 编号规则（多级编号拆小）

内容多时，用**多级编号**把大主题拆成多个小 md，**不砍内容**：

```
阶段一（L1 模块地基）
├─ 01_模块与Build.cs（总概念）
│   ├─ 01.1_模块入口Module（.cpp）
│   ├─ 01.2_Build.cs依赖逐行讲
│   │   ├─ 01.2.1_核心引擎模块（Core/Engine/...）
│   │   └─ 01.2.2_GAS与Gameplay模块（GameplayAbilities/...）
│   └─ 01.3_日志通道LogChannels
└─ 02_GameplayTags
```

- `xx`：一个类/主题的主编号。
- `xx.1`：该主题下的子主题。
- `xx.1.1`：再下一层。
- **编号拆小 ≠ 删内容**：拆是为了"每 md 3~5 知识点"（铁律 05），不是把知识点砍掉。

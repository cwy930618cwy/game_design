#pragma once

#include "UObject/Interface.h"

#include "TenkaichiAbilitySourceInterface.generated.h"

class UObject;
class UPhysicalMaterial;
struct FGameplayTagContainer;

/** 作为「技能计算来源」的任何东西都要实现的基础接口 */
UINTERFACE()

	GENERATED_UINTERFACE_BODY()

## 四、逐段讲解

### 1. 头文件与前置声明

```cpp
#pragma once
#include "UObject/Interface.h"
#include "TenkaichiAbilitySourceInterface.generated.h"

class UObject;
class UPhysicalMaterial;
struct FGameplayTagContainer;
```

- `#include "UObject/Interface.h"`：引入 `UInterface` 基类（引擎自带）。
- `#include "...generated.h"`：UHT 生成的头文件，**必须放在所有 include 之后**（固定规则）。
- 三个前置声明（`class UObject;` / `class UPhysicalMaterial;` / `struct FGameplayTagContainer;`）：
  因为下面函数里只用到了这些类型的**指针**（`const UPhysicalMaterial*`、`const FGameplayTagContainer*`），
  不需要完整定义，前置声明即可——这是 C++ 减少编译依赖的惯用做法。

### 2. U 类壳子

```cpp
/** 作为「技能计算来源」的任何东西都要实现的基础接口 */
UINTERFACE()
class UTenkaichiAbilitySourceInterface : public UInterface
{
	GENERATED_UINTERFACE_BODY()
};
```

- `UINTERFACE()`：告诉 UHT「这是一个接口的 U 类壳子」。
- `GENERATED_UINTERFACE_BODY()`：UHT 生成的宏，提供默认构造函数等。
- 这个类**没有逻辑**，就是给反射系统用的空壳。带 `U` 前缀。

### 3. I 类接口（真正的接口）

```cpp
class ITenkaichiAbilitySourceInterface
{
	GENERATED_IINTERFACE_BODY()
	...
};
```

- 带 `I` 前缀，是真正的 C++ 接口。
- `GENERATED_IINTERFACE_BODY()`：UHT 为接口生成的宏（注意和上面的 `UINTERFACE_BODY` 不同，这里是 `IINTERFACE_BODY`）。

### 4. 两个纯虚函数

```cpp
virtual float GetDistanceAttenuation(float Distance, const FGameplayTagContainer* SourceTags = nullptr, const FGameplayTagContainer* TargetTags = nullptr) const = 0;
virtual float GetPhysicalMaterialAttenuation(const UPhysicalMaterial* PhysicalMaterial, const FGameplayTagContainer* SourceTags = nullptr, const FGameplayTagContainer* TargetTags = nullptr) const = 0;
```

- `virtual ... = 0`：纯虚函数，这个接口是抽象的，必须由实现类重写。
- `const`：不修改对象状态。
- 参数里 `SourceTags` / `TargetTags` 都有默认值 `nullptr`，调用时可省略。
- 两个函数都返回 `float`（衰减系数），含义上一节总 md 已讲。

## 五、几个要记住的点

1. **双类结构**：`U` 类（反射壳子）+ `I` 类（真接口），是 UE 接口的固定套路，后面还会反复遇到。
2. **`generated.h` 放最后**：所有 `#include` 之后，这是 UHT 的硬性要求。
3. **前置声明用指针**：参数里只用指针，就能用前置声明，不必 include 完整头文件。
4. **纯虚函数 `= 0`**：让接口抽象，强制实现类提供这两个衰减算法。

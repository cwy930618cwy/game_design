## 三、USTRUCT —— FTenkaichiCharacterGroundInfo（地面信息）

```cpp
/**
 * FTenkaichiCharacterGroundInfo
 *
 *	关于角色脚下地面的信息。只在需要时更新。
 */
USTRUCT(BlueprintType)
struct FTenkaichiCharacterGroundInfo
{
	GENERATED_BODY()

	FTenkaichiCharacterGroundInfo()
		: LastUpdateFrame(0)
		, GroundDistance(0.0f)
	{}

	uint64 LastUpdateFrame;

	UPROPERTY(BlueprintReadOnly)
	FHitResult GroundHitResult;

	UPROPERTY(BlueprintReadOnly)
	float GroundDistance;
};
```

| 成员 | 干什么 |
|------|--------|
| `LastUpdateFrame`（`uint64`） | **记录"哪一帧算的"**。和引擎全局 `GFrameCounter` 比对，同帧不重算（缓存机制核心） |
| `GroundHitResult`（`FHitResult`，蓝图只读） | 射线命中地面的结果（命中了谁、法线、距离等） |
| `GroundDistance`（`float`，蓝图只读） | 角色脚底到地面的距离 |

> 类比：它是"地面速查表"，记三栏——**几帧查的**、**查到啥**、**多远**。构造函数把帧号归零、距离归零，保证初始状态干净。
>
> 关键：`UPROPERTY(BlueprintReadOnly)` 让蓝图能**读**这个值但**不能写**（只读，数据由 C++ 维护）。

	/** 模拟移动（网络模拟端调用）：如果外部传入了复制加速度，就跑完模拟再把它还原回去 */

| 方法 | 干什么（详解见 `.cpp`） |
|------|------------------------|
| `SimulateMovement` | **覆盖**引擎模拟移动。若标记了复制加速度，跑完 `Super` 后把 `Acceleration` 还原成外部传入的值 |

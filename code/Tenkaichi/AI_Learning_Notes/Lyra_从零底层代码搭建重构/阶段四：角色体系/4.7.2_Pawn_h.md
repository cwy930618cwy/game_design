```cpp
/**
 * ATenkaichiPawn
 */
UCLASS(MinimalAPI)
class ATenkaichiPawn : public AModularPawn, public ITenkaichiTeamAgentInterface
{
	GENERATED_BODY()

public:

	UE_API ATenkaichiPawn(const FObjectInitializer& ObjectInitializer = FObjectInitializer::Get());

	//~AActor 接口开始
	UE_API virtual void PreInitializeComponents() override;
	UE_API virtual void EndPlay(const EEndPlayReason::Type EndPlayReason) override;

	//~APawn 接口结束
```

| 行 | 干什么 |
|----|--------|
| `UCLASS(MinimalAPI)` | 只导出类本身，够用 |
| `: public AModularPawn, public ITenkaichiTeamAgentInterface` | **多重继承**：Modular 底座 + 队伍感知接口 |
| 构造函数 `(const FObjectInitializer& = FObjectInitializer::Get())` | 带默认参数，便于蓝图/编辑器创建 |
| `PreInitializeComponents` | **覆盖**Actor 组件初始化前的回调 |
| `EndPlay` | **覆盖**Actor 结束播放（销毁/关卡卸载）时的回调 |
| `PossessedBy` | **覆盖**被控制器接管——队伍同步的关键入口 |
| `UnPossessed` | **覆盖**被释放——决定队伍去向 |

> 类比：`PossessedBy`/`UnPossessed` 是队伍的"接管仪式"和"移交仪式"——什么时候从控制器拿队、什么时候还队，都在这里定义。

## 三、队伍接口三件套 + 释放策略

```cpp
	//~ITenkaichiTeamAgentInterface 接口开始
	UE_API virtual void SetGenericTeamId(const FGenericTeamId& NewTeamID) override;
	UE_API virtual FGenericTeamId GetGenericTeamId() const override;
	UE_API virtual FOnTenkaichiTeamIndexChangedDelegate* GetOnTeamIndexChangedDelegate() override;
	//~ITenkaichiTeamAgentInterface 接口结束

protected:
	// 决定接管结束后队伍 ID 的去向
	virtual FGenericTeamId DetermineNewTeamAfterPossessionEnds(FGenericTeamId OldTeamID) const
	{
		// 这里可以改成：想释放后保留旧队就返回 OldTeamID，
		// 或者返回某个中立阵营的 ID 等等……
		return FGenericTeamId::NoTeam;
	}
```

| 行 | 干什么 |
|----|--------|
| `SetGenericTeamId` | **覆盖**设置队伍。Lyra 里 Pawn 不让自己随便改队——没被占用时仅权威端能改，被占用时只能由控制器驱动 |
| `GetGenericTeamId` | **覆盖**报出当前队伍（返回 `MyTeamID`） |
| `GetOnTeamIndexChangedDelegate` | **覆盖**返回"队伍变更委托"指针 |
| `DetermineNewTeamAfterPossessionEnds` | **protected + 内联默认实现**：释放后队伍怎么办。默认返回 `NoTeam`（恢复无队伍）；可改逻辑保留旧队 |

> 关键：`DetermineNewTeamAfterPossessionEnds` 是 **protected 虚函数**，默认实现内联在 `.h` 里。想"释放后保留旧队"就覆写它返回 `OldTeamID`——这是给子类留的"策略钩子"。

## 四、private 区（队伍数据 + 复制 + 监听）

```cpp
private:
	UFUNCTION()
	UE_API void OnControllerChangedTeam(UObject* TeamAgent, int32 OldTeam, int32 NewTeam);

private:
	UPROPERTY(ReplicatedUsing = OnRep_MyTeamID)
	FGenericTeamId MyTeamID;

	UPROPERTY()
	FOnTenkaichiTeamIndexChangedDelegate OnTeamChangedDelegate;

private:
	UFUNCTION()
	UE_API void OnRep_MyTeamID(FGenericTeamId OldTeamID);
};
```

| 行 | 干什么 |
|----|--------|
| `OnControllerChangedTeam` | **UFUNCTION 动态委托回调**：控制器换队时被触发，Pawn 跟着更新自己的队并广播 |
| `MyTeamID`（`ReplicatedUsing = OnRep_MyTeamID`） | **复制属性**：队伍ID。`ReplicatedUsing` 表示客户端收到复制后自动调 `OnRep_MyTeamID` |
| `OnTeamChangedDelegate` | 队伍变更委托实例（广播给监听者） |
| `OnRep_MyTeamID` | **复制回调**：客户端收到新队伍ID后，本地广播队伍变更（让 UI 等感知） |

> 类比：`MyTeamID` 是"胸牌"，通过 `ReplicatedUsing` 网络同步；`OnRep_MyTeamID` 是"戴上胸牌后喊一嗓子"（本地广播），`OnTeamChangedDelegate` 是那根喊话的喇叭。

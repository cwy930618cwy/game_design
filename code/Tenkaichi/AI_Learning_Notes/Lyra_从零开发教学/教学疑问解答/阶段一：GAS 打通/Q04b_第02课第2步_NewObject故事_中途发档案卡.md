# Q04b — 第 02 课 · 第 2 步【故事篇】：`NewObject` 到底在干嘛？（中途发一张档案卡）

> **所属章节**：第 02 课 · 第 2 步【2/4】建基类 `TenkaichiAttributeSet.cpp`
>
> **对应 Lyra**：`LyraAbilitySet.cpp` 第 94-95 行
>
> **一句话**：`NewObject` = **"半路现造一个属性集"**。跟 Q04a 的"出生就带卡"不同，这个是"演员演到一半，因某个原因才临时发一张新卡"。

## 一、先看这两行代码

```cpp
// LyraAbilitySet.cpp 第 94-95 行
UAttributeSet* NewSet = NewObject<UAttributeSet>(LyraASC->GetOwner(), SetToGrant.AttributeSet);  // ① 现造一个
LyraASC->AddAttributeSetSubobject(NewSet);   // ② 挂到 ASC 上
```

拆成 2 步：

| 代码 | 人话 |
|------|------|
| `NewObject<UAttributeSet>(...)` | **"半路现造一个属性集对象"** |
| `AddAttributeSetSubobject(NewSet)` | **"把它挂到技能总管（ASC）身上"**，让它开始管事 |

---

## 二、和 Q04a 的区别（一个出生带，一个中途发）

| | Q04a（`CreateDefaultSubobject`） | 本篇（`NewObject`） |
|--|--------------------------------|---------------------|
| 什么时候造 | **出生时就造好**（记分牌一出生） | **演到一半才造**（游戏进行中） |
| 谁触发 | 记分牌构造函数里，固定写死 | 满足某个条件时才触发（如拿到某装备/技能集） |
| 类比 | 出生就别好的出生证明 | 中途发的临时工牌 |

---

## 三、剧场故事：演到一半，临时发一张工牌

> 用你的人物谱世界观（[02_开演后人物谱](../../人物介绍/02_开演后_玩家与角色人物谱.md)）。

### 角色对照

| 代码里的东西 | 剧场里是谁 |
|-------------|-----------|
| `NewObject<UAttributeSet>` | **"临时印一张档案卡"的动作** |
| `AddAttributeSetSubobject` | **"把卡挂到技能总管身上"** |
| `ASC`（技能总管） | 🧠 **技能总管**——属性集必须挂在他身上才生效 |
| 新属性集 | 📇 **一张新档案卡**（比如护甲卡） |

### 故事

演员**一出生**时，只带了最基础的"血型档案卡"（Q04a 讲的，出生就印好）。

但演到一半，演员**捡到一件"巨人铠甲"**（某个装备 / 技能集）——这件铠甲带一套**全新的数值**（护甲值、抗性……）。

技能总管（ASC）这时才反应过来：

> "他需要一张**新的档案卡**来记护甲数值！他出生时没带这张卡。"

于是技能总管**临时现造一张**：

```cpp
UAttributeSet* NewSet = NewObject<UAttributeSet>(...);   // ① "现印一张护甲档案卡"
LyraASC->AddAttributeSetSubobject(NewSet);               // ② "挂到我身上，让它开始管事"
```

**现印这张卡的瞬间，卡上的初始值（比如护甲 50）就自动写好了**（构造函数自动跑）。挂到技能总管身上后，这套新数值就正式生效了。

---

## 四、为什么不用 Q04a 那种"出生就带"？

因为**有些数值是"看情况才需要"的**：

- 血型卡（血量）→ 每个演员都要，**出生就带**（Q04a）。
- 护甲卡（护甲值）→ **只有穿了铠甲的人才需要**，没穿的人带着一张空白卡纯属浪费。

所以这种"看情况才有的数值"，就用 `NewObject` **等需要时再临时发**——不穿铠甲就不发，穿上了才发。

> **类比**：公司入职时（出生）人人发一张工牌（血型卡）。但"实验室门禁卡"（护甲卡）不是人人有——**只有进了实验室的人才临时发一张**，离开就收回。`NewObject` 就是"临时发门禁卡"这个动作。

---

## 五、这跟"构造函数"什么关系？（回扣你的问题）

跟 Q04a 完全一样：

> **`NewObject` = "造对象"的动作** → 一造，构造函数自动跑（写好初始值）。

区别只是**触发时机**：Q04a 是"出生时"触发，本篇是"中途需要时"触发。但**"造对象→构造函数自动跑"这个机制，两者一模一样**。

---

## 六、一句话结论

**`NewObject` + `AddAttributeSetSubobject` = "演到一半，技能总管临时现造一张新档案卡（比如护甲卡）挂到自己身上"——现造（NewObject）的瞬间构造函数自动跑、初始值写好，挂上去（AddAttributeSetSubobject）就生效。用于"看情况才需要的数值"，跟 Q04a"出生就带"的血量卡互补。**

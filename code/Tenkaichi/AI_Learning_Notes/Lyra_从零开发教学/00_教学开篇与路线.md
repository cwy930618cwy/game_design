# 00 — Lyra 从零开发教学（开篇与路线）

> **定位**：**从 0 开始、参考 Lyra、由浅到深**的完整教学目录。不是拆解源码，而是"跟着 Lyra 的思路，从零搭一个游戏"。
>
> **和 `Lyra_项目分析/` 的区别**：
> - `Lyra_项目分析/`：**拆解** Lyra 已有代码（分析）
> - `Lyra_从零开发教学/`：**从 0 搭**（一步步教怎么做）

---

## 一、这个目录教什么

从 0 开始，参考 Lyra 的架构，由浅到深**搭建一个完整的游戏**。每篇是一课，教"这一步怎么做、为什么这么做"。

```
教学主线（从浅到深）：
  环境准备 → 工程搭建 → 角色 → 输入 → 相机 → 动画
  → 技能(GAS) → 武器 → 反馈 → 背包装备 → 队伍
  → UI → 多人 → 工程化
```

## 三、教学原则

1. **从 0 开始**：不假设你会，每步讲清楚
2. **参考 Lyra**：用 Lyra 的做法，不自己发明
3. **由浅到深**：先跑通，再加深
4. **每课有产出**：学完一课能"看到"成果
5. **动手为主**：不只讲理论，要动手做

---

## 四、学习前置

- 学过 `UE5.6_深入理解/`（引擎基础）
- 看过 `Lyra_项目分析/`（Lyra 结构）
- 能编译运行 Lyra 工程

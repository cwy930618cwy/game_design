# 06-01 — Lyra 24 功能学习排序（从 0 开发）

> **定位**：从 0 开发时，Lyra 的 24 个功能**该按什么顺序学**。按"依赖驱动 + 由核心到外围"排序。
>
> **一句话**：先让游戏动起来（规则+角色+输入+相机+动画）→ 再能战斗（技能+武器+反馈）→ 再能成长（交互+背包+装备）→ 再多人（队伍）→ 再完善（UI/音频）→ 最后发布（热修复/测试）。

---

## 一、排序逻辑（3 条原则）

1. **先学依赖**：UI 依赖角色，角色依赖技能 → 先学被依赖的
2. **先学核心**：技能/角色/输入是核心，外围（回放/热修复）靠后
3. **先跑通再扩展**：先让游戏"能动起来"，再加深功能

---

## 二、完整排序（7 个阶段）

### 第一阶段：先让游戏"跑起来"（地基）

| 顺序 | 功能 | 为什么 |
|:---:|------|--------|
| 1 | **GameModes**（Experience） | 规则地基，定"这局怎么玩" |
| 2 | **Character**（角色） | 玩家/敌人的身体 |
| 3 | **Player**（玩家） | PlayerController/State 控制角色 |
| 4 | **GameFeatures** | 玩法模块化 |
| 5 | **System**（系统） | 全局工具 |

**产出**：一个角色能在关卡里跑起来。

### 第二阶段：能"操作角色"（核心交互）

| 顺序 | 功能 | 为什么 |
|:---:|------|--------|
| 6 | **Input**（输入） | 玩家操作（WASD） |
| 7 | **Camera**（相机） | 视角（第三人称/第一人称） |
| 8 | **Animation**（动画） | 角色动起来（走/跑） |

**产出**：能操作角色移动、切换视角、播动画。

### 第三阶段：能"战斗"（核心玩法）

| 顺序 | 功能 | 为什么 |
|:---:|------|--------|
| 9 | **AbilitySystem**（技能） | 战斗核心（GAS） |
| 10 | **Weapons**（武器） | 攻击手段 |
| 11 | **Feedback**（反馈） | 伤害数字/特效 |
| 12 | **Physics**（物理） | 物理碰撞 |

**产出**：能战斗、有伤害反馈。

### 第四阶段：能"成长"（物品/交互）

| 顺序 | 功能 | 为什么 |
|:---:|------|--------|
| 13 | **Interaction**（交互） | 拾取 |
| 14 | **Inventory**（背包） | 存物品 |
| 15 | **Equipment**（装备） | 用装备 |

**产出**：能拾取、存、装备。

### 第五阶段：能"多人"（联机）

| 顺序 | 功能 | 为什么 |
|:---:|------|--------|
| 16 | **Teams**（队伍） | 阵营 |
| 17 | **Messages**（消息） | 系统通信 |
| 18 | **Replays**（回放） | 联机回放 |

**产出**：能多人对战。

### 第六阶段：能"完善"（外观/体验）

| 顺序 | 功能 | 为什么 |
|:---:|------|--------|
| 19 | **Cosmetics**（换装） | 外观 |
| 20 | **Audio**（音频） | 音效 |
| 21 | **UI**（最大） | HUD/菜单 |
| 22 | **Settings**（设置） | 玩家设置 |

### 第七阶段：能"发布"（工程化）

| 顺序 | 功能 | 为什么 |
|:---:|------|--------|
| 23 | **Hotfix**（热修复） | 线上更新 |
| 24 | **Performance / Development / Tests** | 性能/工具/测试 |

---

## 三、核心学习排序（精简版，重点记这个）

```
游戏规则(GameModes) → 角色(Character) → 玩家(Player) → 输入(Input) → 相机(Camera)
→ 动画(Animation) → 技能(AbilitySystem) → 武器(Weapons) → 反馈(Feedback)
→ 交互(Interaction) → 背包(Inventory) → 装备(Equipment) → 队伍(Teams)
→ UI → 其他
```

**一句话**：**先让游戏动起来（规则+角色+输入+相机+动画）→ 再能战斗（技能+武器+反馈）→ 再能成长（交互+背包+装备）→ 再多人（队伍）→ 再完善（UI/音频/换装）→ 最后发布（热修复/测试）**。

---

## 四、从 0 开发：不用 24 个全学！

**从 0 开发，只需要学核心几个**：

| 必学（核心） | 可选（按需） |
|------------|------------|
| GameModes / Character / Player | Cosmetics（换装） |
| Input / Camera / Animation | Replays（回放） |
| AbilitySystem / Weapons / Feedback | Hotfix（热修复） |
| Inventory / Equipment / Interaction | Performance / Tests |
| Teams / UI / Settings | Audio（可后补） |

**新手从 0 开发建议先学这 5 个**：
```
1. Character（角色）
2. Input（输入）
3. GameModes（规则）
4. AbilitySystem（技能）
5. UI
```

**这 5 个能做出一个"能操作、能战斗、有 UI"的基础游戏**，其他的按需求加。

---

## 五、总结速查

```
完整排序（7 阶段）：
  地基（规则/角色/玩家）→ 操作（输入/相机/动画）→ 战斗（技能/武器/反馈）
  → 成长（交互/背包/装备）→ 多人（队伍/消息）→ 完善（UI/音频/换装）
  → 发布（热修复/测试）

从 0 开发必学 5 个：
  Character → Input → GameModes → AbilitySystem → UI
```

**一句话**：**从 0 开发先学 Character（角色）→ Input（输入）→ GameModes（规则）→ AbilitySystem（技能）→ UI 这 5 个核心**，能做出基础游戏；其余功能按需求往上加。

# 00 — Lyra 项目分析开篇

> **定位**：这个文件夹专门做 **Lyra 项目的逐系统分析**——把 Lyra 工程拆开，看每个系统（Experience、GAS、输入、UI、装备、队伍...）是怎么实现的、和 UE5 底层的关系。
>
> **和 `UE5_Lyra与UE5底层对比` 的区别**：
> - `UE5_Lyra与UE5底层对比/`：讲"Lyra 和 UE5 底层**有什么不同**"（概念对比）
> - `Lyra_项目分析/`：讲"Lyra **项目里每个系统具体怎么实现**"（源码分析）
>
> **一句话**：这是 Lyra 项目的"解剖室"，一个系统一个系统地拆开看。

---

## 一、这个文件夹讲什么

Lyra 是一个完整游戏工程（`LyraGame/`），包含很多系统。这个文件夹**逐个系统分析**：

```
Lyra 项目主要系统：
├── Experience（规则数据资产）
├── GAS 技能系统（ASC/GA/GE/AttributeSet）
├── 输入系统（EnhancedInput + Tag）
├── 角色系统（Pawn/Character/PawnExtension/HeroComponent）
├── UI 系统（CommonUI + GameplayMessage）
├── 装备系统（Inventory/Equipment/Weapon）
├── 队伍系统（Team Subsystem）
├── 游戏阶段（GamePhase）
├── 机器人系统（Bot）
└── ...（还有很多）
```

---

## 二、分析方式（每个系统按这个套路）

每个系统分析都按：
1. **这个系统解决什么问题**（为什么需要）
2. **核心类有哪些**（源码）
3. **类之间的关系**（图）
4. **和 UE5 底层的关系**（继承了什么/扩展了什么）
5. **实际用法**（怎么用）

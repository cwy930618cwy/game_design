# 07 — 组件系统详解（UActorComponent 家族）

> **定位**：理解 UE 的**组件系统**——Actor 靠挂组件获得具体能力。
>
> **一句话**：**Actor 是"东西"，组件（Component）是"零件"。** 角色、宝箱、敌人这些 Actor，都是靠挂各种组件（模型、移动、碰撞、技能）组装出来的。
>
> **文件**：`Engine/Source/Runtime/Engine/Classes/Components/`

---

## 一、组件体系继承树（先看全貌）

```
UActorComponent（组件根：能挂到 Actor 上，无位置）
  └─ USceneComponent（有位置：能放在世界哪里）
       └─ UPrimitiveComponent（可渲染 + 有碰撞）
            ├─ UStaticMeshComponent（静态模型：房/墙/石头）
            ├─ USkeletalMeshComponent（骨骼动画模型：角色/怪物）
            └─ ...（各种 Mesh 组件）
  └─（无位置组件）
       ├─ UAbilitySystemComponent（技能，GAS）
       ├─ UInventoryComponent（背包，例子）
       └─ ...
```

**能力一层层叠加**：
| 层级 | 加了什么能力 |
|------|------------|
| UActorComponent | 能挂到 Actor 上 |
| USceneComponent | **有位置**（能放世界） |
| UPrimitiveComponent | **能看见 + 能碰撞** |
| UStaticMeshComponent | **显示静态模型** |
| USkeletalMeshComponent | **显示动画模型** |

## 二、逐个讲解（配具体场景）

### 2.1 UActorComponent —— 组件根

所有组件的基类。**没有位置**，只是"一个能挂到 Actor 上的功能单元"。

**具体场景**：不需要位置的逻辑组件继承它：

```cpp
UCLASS()
class UInventoryComponent : public UActorComponent {   // 背包组件
    GENERATED_BODY()
public:
    TArray<FItem> Items;   // 装物品，不需要位置
    void AddItem(const FItem& I) { Items.Add(I); }
};
```

### 2.2 USceneComponent —— 有位置的组件

在 UActorComponent 基础上**加了位置（Transform）**，能决定"这个组件在世界哪里"。

```cpp
// 能设置位置/旋转/缩放
Comp->SetRelativeLocation(FVector(100.f, 0.f, 0.f));   // 相对位置
Comp->SetRelativeRotation(FRotator(0.f, 90.f, 0.f));   // 相对旋转
```

**具体场景**：所有需要"摆在哪"的组件（模型、光源、音效）都继承它。

### 2.3 UPrimitiveComponent —— 可渲染 + 碰撞组件

在 USceneComponent 基础上，**加了"能被看见"（渲染）和"能被撞到"（碰撞）**。

```cpp
// 能设置碰撞
Comp->SetCollisionEnabled(ECollisionEnabled::QueryAndPhysics);  // 能碰撞
// 能设置可见
Comp->SetVisibility(true);
```

**具体场景**：场景里"看得见、撞得到"的东西（墙、箱子、角色）都用它。

### 2.4 UStaticMeshComponent —— 静态模型组件

显示一个**不会动的模型**（Static Mesh）。

**具体场景**：房子、石头、地板这类静态物体：

```cpp
// 给 Actor 挂一个静态模型
UCLASS()
class ARock : public AActor {
    GENERATED_BODY()
public:
    ARock() {
        // 创建静态模型组件
        UStaticMeshComponent* Mesh = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("Mesh"));
        // 加载石头模型
        Mesh->SetStaticMesh(LoadObject<UStaticMesh>(nullptr, TEXT("/Game/Mesh/Rock.Rock")));
        RootComponent = Mesh;
    }
};
```

### 2.5 USkeletalMeshComponent —— 骨骼动画模型组件

显示一个**会动的模型**（有骨骼动画）。

**具体场景**：角色、怪物这类要播放动画的：

```cpp
// ACharacter 自带的就是这个
USkeletalMeshComponent* GetMesh() { return Mesh; }

// 播放动画
GetMesh()->PlayAnimation(IdleAnim, true);   // 播放待机动画
```

### 2.6 UAbilitySystemComponent —— 技能组件（GAS）

处理**技能/属性/效果**，是 GAS（Gameplay Ability System）的核心组件。

**具体场景**：角色要放技能：

```cpp
UCLASS()
class AMyCharacter : public ACharacter {
    GENERATED_BODY()
public:
    UPROPERTY()
    UAbilitySystemComponent* ASC;   // 技能组件

    AMyCharacter() {
        ASC = CreateDefaultSubobject<UAbilitySystemComponent>(TEXT("ASC"));
    }
};
```

## 四、怎么挂组件（核心操作）

### 4.1 静态创建（构造函数里）

```cpp
UCLASS()
class AMyActor : public AActor {
    GENERATED_BODY()
public:
    UPROPERTY()
    UStaticMeshComponent* MeshComp;

    AMyActor() {
        // 构造函数里创建组件
        MeshComp = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("MeshComp"));
        RootComponent = MeshComp;   // 设为根组件（决定 Actor 位置）
    }
};
```

**关键**：用 `CreateDefaultSubobject` 创建组件，`RootComponent` 设根。

### 4.2 动态添加（运行时）

```cpp
// 运行时给 Actor 加一个组件
UStaticMeshComponent* NewMesh = NewObject<UStaticMeshComponent>(this);
NewMesh->RegisterComponent();   // 注册才生效
AddInstanceComponent(NewMesh);  // 挂到 Actor 上
```

### 4.3 查找组件

```cpp
// 找某类组件
UStaticMeshComponent* Mesh = Actor->FindComponentByClass<UStaticMeshComponent>();
// 找根组件
USceneComponent* Root = Actor->GetRootComponent();
```

## 五、组装一个完整角色（把组件串起来）

```cpp
UCLASS()
class AMyCharacter : public ACharacter {
    GENERATED_BODY()
public:
    AMyCharacter() {
        // ACharacter 自带：骨骼模型 + 移动 + 胶囊碰撞

        // ① 给角色加一个技能组件
        ASC = CreateDefaultSubobject<UAbilitySystemComponent>(TEXT("ASC"));
    }
};
```

```
一个角色（ACharacter）的完整组成：
  ├─ USkeletalMeshComponent（显示模型 + 动画）  ← 自带
  ├─ UCharacterMovementComponent（移动）        ← 自带
  ├─ UCapsuleComponent（胶囊碰撞）              ← 自带
  └─ UAbilitySystemComponent（技能）             ← 你加的
```

## 六、常见陷阱

**① 用 NewObject 创建组件（应该 CreateDefaultSubobject）**
```cpp
// ❌ 构造函数里用 NewObject 创建组件
MeshComp = NewObject<UStaticMeshComponent>(this);
// ✅ 用 CreateDefaultSubobject
MeshComp = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("MeshComp"));
```

**② 动态组件忘了 RegisterComponent**
```cpp
// ❌ 动态创建的组件没注册，不生效
UStaticMeshComponent* M = NewObject<UStaticMeshComponent>(this);
// ✅ 要注册
M->RegisterComponent();
```

**③ 忘了设 RootComponent**
```cpp
// ❌ 组件没设根，Actor 没有位置参考
CreateDefaultSubobject<UStaticMeshComponent>(TEXT("Mesh"));
// ✅ 设根
RootComponent = MeshComp;
```

**④ 把需要位置的组件继承 UActorComponent（应该 USceneComponent）**
```cpp
// ❌ 需要位置的组件却继承 UActorComponent（没位置）
class UMeshComp : public UActorComponent { ... };
// ✅ 有位置的继承 USceneComponent
class UMeshComp : public USceneComponent { ... };
```

## 七、总结速查

```
组件 = 挂到 Actor 上的零件
├── UActorComponent（根：能挂，无位置）
│   ├── USceneComponent（有位置）
│   │    └── UPrimitiveComponent（可渲染+碰撞）
│   │         ├── UStaticMeshComponent（静态模型）
│   │         ├── USkeletalMeshComponent（动画模型）
│   │         └── ...
│   └── UAbilitySystemComponent（技能）等无位置组件

能力分层：UActorComponent(挂) → UScene(位置) → UPrimitive(渲染+碰撞) → Mesh(模型)

挂组件：CreateDefaultSubobject（构造函数）
设根：RootComponent = 组件
找组件：FindComponentByClass<UXX>()
```

**一句话**：组件系统让 Actor **通过挂零件获得能力**。核心分层是 `UActorComponent`（挂）→ `USceneComponent`（位置）→ `UPrimitiveComponent`（渲染+碰撞）→ `UStaticMesh/SkeletalMesh`（模型）。挂组件用 `CreateDefaultSubobject`，设 `RootComponent`，查找用 `FindComponentByClass`。

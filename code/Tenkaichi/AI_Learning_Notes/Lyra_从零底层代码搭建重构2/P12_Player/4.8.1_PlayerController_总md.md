## 〇、PlayerController 是干嘛的（为什么需要它）

一个玩家要真正"开起这辆车"，光有 4.7 的**角色 Pawn**（车本身）还不够——还需要一个"司机"。**PlayerController（玩家控制器）就是那个司机**：它不占物理位置、不是场景里的物体，而是**站在 Pawn 背后的那双手**。

| 职责 | 类比 | 对应源码段 |
|------|------|-----------|
| **输入入口** | 司机握方向盘 | `PreProcessInput` / `PostProcessInput` |
| **相机** | 司机看路 | `UpdateHiddenComponents`（处理穿墙）、`ILyraCameraAssistInterface` |
| **队伍** | 司机属于哪个队 | `SetGenericTeamId` / `GetGenericTeamId`（✅4.1） |
| **玩家档案** | 司机查行驶证 | `GetLyraPlayerState` / `GetLyraHUD` |
| **回放** | 司机录行车记录仪 | `TryToRecordClientReplay` / `ShouldRecordClientReplay` |
| **作弊指令** | 后台改车 | `ServerCheat` / `ServerCheatAll` / `AddCheats` |
| **自动奔跑** | 一键自动驾驶 | `SetIsAutoRunning` / `OnStartAutoRun` |

> **关键认知**：PlayerController 是**本地玩家专属**（司机只有一个），它管的是"操作 + 表现"，**不负责复制**。要复制给所有人的信息放在 PlayerState（4.8.2）。

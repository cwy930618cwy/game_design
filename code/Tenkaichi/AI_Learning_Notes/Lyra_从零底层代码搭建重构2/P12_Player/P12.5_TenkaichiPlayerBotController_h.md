## 〇、这个 `.h` 在解决什么

`ALyraPlayerBotController` 是**机器人玩家（AI 对手/队友）的控制器**。它把"队伍属性"（P07）接到"AI 控制器"上，让机器人：
- 属于某支队伍（`ITenkaichiTeamAgentInterface`）
- 队伍变了能收到回调（`OnTeamChangedDelegate`）
- 有 PlayerState（`bWantsPlayerState` 在 `.cpp` 里设）
- 死掉后能重生（`ServerRestartController`，依赖 P13，`.cpp` 挂起）

**类声明拆解（从上到下 5 块）：**

| 块 | 代码 | 作用 |
|----|------|------|
| ① 基类 | `AModularAIController` + `ITenkaichiTeamAgentInterface` | AI 控制器 + 队伍接口 |
| ② 队伍接口实现 | `SetGenericTeamId` / `GetGenericTeamId` / `GetTeamChangedDelegate` | 机器人的队伍逻辑（.cpp） |
| ③ 公开方法 | `ServerRestartController` / `UpdateTeamAttitude` | 重生 + 刷 AI 敌我判定 |
| ④ 私有回调 | `OnPlayerStateChangedTeam` | 队伍变更事件 → 转发广播 |
| ⑤ 控制器钩子 | `InitPlayerState` / `CleanupPlayerState` / `OnRep_PlayerState` | PlayerState 挂载/移除时触发 |

## 一、完整代码（可直接照抄）

```cpp
// 版权声明（可保留或省略，不影响编译）
#pragma once

#include "ModularAIController.h"
#include "Teams/TenkaichiTeamAgentInterface.h"

#include "TenkaichiPlayerBotController.generated.h"

namespace ETeamAttitude { enum Type : int; }
struct FGenericTeamId;

class APlayerState;
class UAIPerceptionComponent;
class UObject;
struct FFrame;

/**
 * ATenkaichiPlayerBotController
 *
 *	本工程机器人玩家使用的控制器类。
 */
UCLASS(Blueprintable)
class ATenkaichiPlayerBotController : public AModularAIController, public ITenkaichiTeamAgentInterface
{
	GENERATED_BODY()

public:
	ATenkaichiPlayerBotController(const FObjectInitializer& ObjectInitializer = FObjectInitializer::Get());

	// ~ITenkaichiTeamAgentInterface 队伍接口
	// 给机器人设置队伍（机器人禁止手动设，这里直接报错）。
	virtual void SetGenericTeamId(const FGenericTeamId& NewTeamID) override;
	// 查询机器人当前队伍 ID（从关联的 PlayerState 拿）。
	virtual FGenericTeamId GetGenericTeamId() const override;
	// 获取"队伍变更回调"的委托对象。
	virtual FOnTenkaichiTeamIndexChangedDelegate* GetOnTeamIndexChangedDelegate() override;
	// 判定对方是敌/友/中立（AI 感知系统用）。
	ETeamAttitude::Type GetTeamAttitudeTowards(const AActor& Other) const override;
	// ~ITenkaichiTeamAgentInterface 队伍接口结束

	// 尝试重启本控制器（例如用于重生机器人）。
	void ServerRestartController();

	// 更新 AI 感知系统对队伍的敌我判定。
	UFUNCTION(BlueprintCallable, Category = "Tenkaichi AI Player Controller")
	void UpdateTeamAttitude(UAIPerceptionComponent* AIPerception);

	virtual void OnUnPossess() override;


private:
	// 当关联的 PlayerState 队伍改变时回调。
	UFUNCTION()
	void OnPlayerStateChangedTeam(UObject* TeamAgent, int32 OldTeam, int32 NewTeam);

protected:
	// 当 PlayerState 被设置或清除时调用（留给子类扩展）。
	virtual void OnPlayerStateChanged();

private:
	// 广播 PlayerState 变更（解绑旧、绑定新、转发队伍变更）。
	void BroadcastOnPlayerStateChanged();

protected:
	// ~AController 接口
	virtual void InitPlayerState() override;
	virtual void CleanupPlayerState() override;
	virtual void OnRep_PlayerState() override;
	// ~AController 接口结束

private:
	// 本控制器的队伍变更委托（存储用）。
	UPROPERTY()
	FOnTenkaichiTeamIndexChangedDelegate OnTeamChangedDelegate;

	// 上一次见过的 PlayerState（用来解绑旧的状态）。
	UPROPERTY()
	TObjectPtr<APlayerState> LastSeenPlayerState;
};
```

## 二、关键点讲解

### 1. `AModularAIController` 基类
`AModularAIController` 是 S1 插件 `ModularGameplayActors` 提供的 AI 控制器基类，负责管理 **PlayerState 生命周期**（`InitPlayerState`/`CleanupPlayerState`/`OnRep_PlayerState` 这些钩子就是它提供的）。机器人控制器继承它 = "这是个 AI，但也能有 PlayerState"。

### 2. 同时实现 `ITenkaichiTeamAgentInterface`（P07）
机器人也要有队伍，所以实现 P07 的队伍接口。四个方法：
- `SetGenericTeamId` —— **重写后直接报错**（机器人队伍由 PlayerState 决定，不许外部改）
- `GetGenericTeamId` —— 从关联的 PlayerState 拿队伍
- `GetOnTeamIndexChangedDelegate` —— 返回内部委托
- `GetTeamAttitudeTowards` —— AI 判定敌我（`.cpp` 里有具体逻辑）

### 3. `ServerRestartController()`（重生命令）
服务器端重生的入口，在 `.cpp` 里调 `GameMode->RestartPlayer()` 实现。**依赖 P13 GameMode**，所以 `.cpp` 里这个方法体会挂起。

### 4. `OnUnPossess()`（失配清理）
AI 失配（失去控制的 Pawn）时，要确保**被失配的 Pawn 不再作为 ASC 的 Avatar**（防止技能系统引用悬空）。在 `.cpp` 里处理 GAS 引用。

### 5. PlayerState 生命周期钩子（`InitPlayerState`/`CleanupPlayerState`/`OnRep_PlayerState`）
机器人控制器重写这三个 AController 钩子，统一调 `BroadcastOnPlayerStateChanged()`：
- `InitPlayerState`：新状态挂上时
- `CleanupPlayerState`：状态被清时
- `OnRep_PlayerState`：客户端收到状态复制时

这样"PlayerState 换了"这个事件，在任何触发路径下都会被捕获，并转发给队伍系统。

### 6. `LastSeenPlayerState` + `BroadcastOnPlayerStateChanged()`
`.h` 里声明的核心机制：
- `LastSeenPlayerState` 记**上一次**的状态
- `BroadcastOnPlayerStateChanged()` 负责：**解绑旧 PlayerState 的队伍回调 → 绑定新 PlayerState 的队伍回调 → 广播队伍变更**
- `OnTeamChangedDelegate` 是队伍变更时向外广播的委托存储

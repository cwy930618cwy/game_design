## 〇、PlayerState 是干嘛的（为什么需要它）

4.8.1 教了 PlayerController（司机）。但一个玩家"开起车"后，还需要一个"行驶证"——**PlayerState（玩家档案）就是那个行驶证**：记录这个玩家是谁、哪个队、哪个小队、什么状态，**服务器权威，复制给所有客户端**。

| 职责 | 类比 | 对应源码段 |
|------|------|-----------|
| **玩家档案** | 行驶证（谁/哪队/哪小队） | `MyTeamID` / `MySquadID` / `SetGenericTeamId` |
| **PawnData** | 行驶证上的"车型配置" | `SetPawnData` / `GetPawnData<T>` / `OnRep_PawnData` |
| **能力系统** | 行驶证上的"技能清单" | `GetLyraAbilitySystemComponent` / `AbilitySystemComponent` / `HealthSet` / `CombatSet` |
| **统计标签** | 行驶证上的"战绩计数" | `AddStatTagStack` / `RemoveStatTagStack` / `GetStatTagStackCount` |
| **连接类型** | 司机是否在岗 | `ELyraPlayerConnectionType` / `SetPlayerConnectionType` |
| **旁观视角** | 旁观看车视角 | `GetReplicatedViewRotation` / `SetReplicatedViewRotation` |

> **关键认知**：PlayerController 管"操作 + 表现"（本地专属，不复制）；**PlayerState 管"档案 + 状态"（复制给所有人）**。要广播给全服务器的信息放 PlayerState。

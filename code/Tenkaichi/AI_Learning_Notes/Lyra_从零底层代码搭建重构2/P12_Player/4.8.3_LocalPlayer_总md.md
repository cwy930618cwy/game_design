## 〇、LocalPlayer 是干嘛的（为什么需要它）

4.8.1 教了 PlayerController（司机）、4.8.2 教了 PlayerState（行驶证）。但还有最后一位——**LocalPlayer（车主本人）**：它代表**本地这台电脑上的"人"**，管本地设置和音频，**只存在于本地这台机器**。

| 职责 | 类比 | 对应源码段 |
|------|------|-----------|
| **本地设置** | 车主本人调自己的偏好 | `GetLocalSettings`（读配置文件，进程启动时就有效） |
| **共享设置** | 车主登录后的存档设置 | `GetSharedSettings` / `LoadSharedSettingsFromDisk` / `OnSharedSettingsLoaded` |
| **音频切换** | 车主换音响设备 | `OnAudioOutputDeviceChanged` / `OnCompletedAudioDeviceSwap` |
| **队伍观察** | 车主看"自己这个司机的队" | `OnPlayerControllerChanged` / `OnControllerChangedTeam` |
| **生命周期** | 车主开关车 | `PostInitProperties` / `SwitchController` / `SpawnPlayActor` / `InitOnlineSession` |

> **关键认知**：三个类的关系（"开车的三个人"）：
> - **PlayerController = 司机**——握方向盘（输入）、看路（相机），本地玩家专属。
> - **PlayerState = 行驶证**——档案级信息，服务器权威，全车（所有客户端）可见。
> - **LocalPlayer = 车主本人**——本地这台电脑上的"人"，管设置和音频，只存在于本地。

## 〇、这个 `.h` 在解决什么

`TenkaichiReplicationGraph.h` 声明了 3 个类：1 个主复制图类 + 2 个复制节点类。同时声明了新日志通道 `LogTenkaichiRepGraph`。

**文件拆解：**

| 块 | 代码 | 作用 |
|----|------|------|
| ① 日志通道 | `DECLARE_LOG_CATEGORY_EXTERN(LogTenkaichiRepGraph, ...)` | 声明复制图日志通道 |
| ② 主类 | `UTenkaichiReplicationGraph` | 复制图本体 |
| ③ 节点类1 | `UTenkaichiReplicationGraphNode_AlwaysRelevant_ForConnection` | 连接级始终相关节点 |
| ④ 节点类2 | `UTenkaichiReplicationGraphNode_PlayerStateFrequencyLimiter` | PlayerState 频率限制节点 |

	// 注册类的复制节点映射。

## 二、关键点讲解

### 1. `DECLARE_LOG_CATEGORY_EXTERN(LogTenkaichiRepGraph, Display, All)`

```cpp
DECLARE_LOG_CATEGORY_EXTERN(LogTenkaichiRepGraph, Display, All);
```

声明一个新日志通道 `LogTenkaichiRepGraph`（`.cpp` 里 `DEFINE_LOG_CATEGORY` 定义）。注意这个日志通道**就定义在本文件**，不是 LogChannels 文件（Lyra 的约定，复制图专属日志）。

- `Display`：默认详细度（Display 级别）。
- `All`：默认编译详细度（所有级别都编译）。

### 2. 主类 `UTenkaichiReplicationGraph`

```cpp
UCLASS(transient, config=Engine)
class UTenkaichiReplicationGraph : public UReplicationGraph
```

- `transient`：临时类（不存盘）。
- `config=Engine`：从 `DefaultEngine.ini` 配置。
- 继承 `UReplicationGraph`（引擎复制图基类）。

### 3. 6 个覆写方法（复制图核心流程）

```cpp
virtual void ResetGameWorldState() override;
virtual void InitGlobalActorClassSettings() override;
virtual void InitGlobalGraphNodes() override;
virtual void InitConnectionGraphNodes(...) override;
virtual void RouteAddNetworkActorToNodes(...) override;
virtual void RouteRemoveNetworkActorToNodes(...) override;
```

- `InitGlobalActorClassSettings`：初始化"类 → 节点映射"（哪些类路由到哪个节点）。
- `InitGlobalGraphNodes` / `InitConnectionGraphNodes`：创建全局/连接级节点。
- `RouteAddNetworkActorToNodes` / `RouteRemoveNetworkActorToNodes`：Actor 加入/离开时路由到节点。

### 4. 三个成员（节点 + 类列表）

```cpp
TArray<TObjectPtr<UClass>> AlwaysRelevantClasses;   // 始终相关类
TObjectPtr<UReplicationGraphNode_GridSpatialization2D> GridNode;   // 空间化网格
TObjectPtr<UReplicationGraphNode_ActorList> AlwaysRelevantNode;    // 始终相关列表
```

这三个是复制图的核心结构：空间化网格（按位置）+ 始终相关列表（全局）+ 始终相关类列表。

### 5. `IsSpatialized` 内联判断

```cpp
bool IsSpatialized(EClassRepNodeMapping Mapping) const { return Mapping >= EClassRepNodeMapping::Spatialize_Static; }
```

利用枚举值的大小关系判断"是否空间化"——`Spatialize_Static`/`Dynamic`/`Dormancy` 三个空间化枚举值都 `>= Spatialize_Static`（P14.6-2 枚举定义时注释里就暗示了"下面这些是空间化"）。

### 6. 两个节点类——覆写 `Notify*` 空实现

两个节点类都覆写了 `NotifyAddNetworkActor` / `NotifyRemoveNetworkActor` 等，且**大部分是空实现**（`{ }` 或 `{ return false; }`）。因为它们不维护持久列表（每帧重建），所以不需要在 Actor 增删时做什么。

### 7. `TargetActorsPerFrame = 2`

```cpp
int32 TargetActorsPerFrame = 2;
```

PlayerState 频率限制节点的核心参数：每帧只复制 2 个 PlayerState（滚动子集），降低大连接数下的带宽。

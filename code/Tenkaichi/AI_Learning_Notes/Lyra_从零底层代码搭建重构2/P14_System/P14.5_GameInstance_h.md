#include "CommonGameInstance.h"

UCLASS(MinimalAPI, Config = Game)
class UTenkaichiGameInstance : public UCommonGameInstance

	GENERATED_BODY()

public:

	// 构造函数：空实现（父类处理初始化）。

	UE_API virtual bool CanJoinRequestedSession() const override;
	// 用户初始化完成的回调。

## 二、关键点讲解

### 1. 基类 `UCommonGameInstance`

`UCommonGameInstance` 是 CommonGame 插件（S1 已装）提供的游戏实例基类。它比引擎 `UGameInstance` 多了"本地玩家/会话/用户"管理能力。Lyra 的 GameInstance 继承它，而不是直接继承 `UGameInstance`。

### 2. 强类型 getter `GetPrimaryPlayerController`

```cpp
ATenkaichiPlayerController* GetPrimaryPlayerController() const;
```

父类 `UCommonGameInstance` 有个 `GetPrimaryPlayerController(bool)` 返回 `APlayerController*`（基类指针）。这里覆写（其实是重载/包装）成返回 `ATenkaichiPlayerController*`（强类型），调用方就不用自己 `Cast` 了。

### 3. 四个覆写方法（会话/登录/加密）

```cpp
virtual bool CanJoinRequestedSession() const override;
virtual void HandlerUserInitialized(...) override;
virtual void ReceivedNetworkEncryptionToken(...) override;
virtual void ReceivedNetworkEncryptionAck(...) override;
```

这些都是 `UCommonGameInstance` 的虚函数，Lyra 覆写定制行为：
- `CanJoinRequestedSession`：判断能否加入会话。
- `HandlerUserInitialized`：用户登录完成回调。
- `ReceivedNetworkEncryptionToken` / `ReceivedNetworkEncryptionAck`：加密握手回调。

### 4. `FOnEncryptionKeyResponse` 委托类型

`ReceivedNetworkEncryptionToken` 的参数 `const FOnEncryptionKeyResponse& Delegate`——这是一个委托（回调），加密处理完后调用它返回结果。这个类型来自 `CommonGameInstance.h`（或相关头文件），所以 `.h` 里不用前置声明。

### 5. `Init` / `Shutdown`（保护生命周期）

```cpp
virtual void Init() override;      // 初始化
virtual void Shutdown() override;  // 关闭
```

`UGameInstance` 的生命周期钩子。`Init` 里注册 InitState + 绑会话事件，`Shutdown` 里解绑。

### 6. `DebugTestEncryptionKey` 成员

```cpp
TArray<uint8> DebugTestEncryptionKey;
```

硬编码的 32 字节调试密钥（`Init` 里填 0~31）。注释明确说"不安全，生产环境别用"。

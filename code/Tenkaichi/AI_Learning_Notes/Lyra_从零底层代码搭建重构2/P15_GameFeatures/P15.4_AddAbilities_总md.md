## 一、这个类解决什么问题（先讲为什么）

GameFeature 插件常需要"给某类 Actor 加能力"。比如"英雄 A 的 DLC"激活时，要给所有 `ATenkaichiCharacter` 加 3 个技能、1 个属性集、1 个能力集。

`UGameFeatureAction_AddAbilities` 就是做这个的：
1. 配置里写"给哪个类加什么"（`AbilitiesList`，每项含 `ActorClass` + 要给的能力/属性/能力集）。
2. 插件激活 → 通过 `UGameFrameworkComponentManager` 注册"这个类出现时通知我"。
3. 这类 Actor 出现（或已存在）→ 给它加 ASC 组件（没有就请求加）+ 给能力 + 给属性集 + 给能力集。
4. 插件停用 → 全部移除（`RemoveAbility`/`RemoveSpawnedAttribute`/`TakeFromAbilitySystem`）。

> **类比**：这是"装备发放处"——插件激活时贴一张告示"凡是 XX 类角色，来领这 3 个技能 + 这套属性"；角色一出现就来领，插件卸载时统一收回。

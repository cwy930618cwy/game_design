## 二、关键点讲解

### 1. `UCLASS(MinimalAPI, meta = (DisplayName = "Add Gameplay Cue Path"))`

- `MinimalAPI`：精简导出（P13.4 起一直用）。
- `meta=(DisplayName="Add Gameplay Cue Path")`：编辑器里显示的名字（中文可译"添加 GameplayCue 路径"，但这里是 **meta 字符串**，属于编辑器 UI 文案——按铁律 21/24 的要求，注释中文化；meta 里的显示名保持英文或按需翻译，Lyra 原样是英文，此处保留英文更安全，因为它是编辑器查找用的标识）。**注意**：这里没有 `Lyra` 字样，所以铁律 24 不涉及。

### 2. `class UGameFeatureAction_AddGameplayCuePath final`

```cpp
class UGameFeatureAction_AddGameplayCuePath final : public UGameFeatureAction
```

`final`：终点类，**不允许再被继承**（这个 Action 是具体的，不是基类）。

> 对比 P15.1 `WorldActionBase` 是 `UCLASS(Abstract)`（要继承），这个是完全相反。

### 3. `UPROPERTY` 的 meta：`RelativeToGameContentDir` + `LongPackageName`

```cpp
UPROPERTY(EditAnywhere, Category = "Game Feature | Gameplay Cues", meta = (RelativeToGameContentDir, LongPackageName))
TArray<FDirectoryPath> DirectoryPathsToAdd;
```

- `RelativeToGameContentDir`：编辑器里路径选择器以"游戏内容目录"为基准（选出来是相对路径）。
- `LongPackageName`：路径使用"长包名"格式（`/Game/...`）。

### 4. `FDirectoryPath`——目录路径类型

```cpp
DirectoryPathsToAdd.Add(FDirectoryPath{ TEXT("/GameplayCues") });
```

`FDirectoryPath` 是 UE 的"目录路径结构体"（含一个 `FString Path`）。构造时 `{ TEXT("/GameplayCues") }` 用聚合初始化赋 `Path`。

### 5. `IsDataValid` + `WITH_EDITOR`（编辑器数据校验）

```cpp
#if WITH_EDITOR
EDataValidationResult UGameFeatureAction_AddGameplayCuePath::IsDataValid(FDataValidationContext& Context) const
{
	EDataValidationResult Result = Super::IsDataValid(Context);
	for (const FDirectoryPath& Directory : DirectoryPathsToAdd)
	{
		if (Directory.Path.IsEmpty())
		{
			Context.AddError(InvalidCuePathError);
			Result = CombineDataValidationResults(Result, EDataValidationResult::Invalid);
		}
	}
	return CombineDataValidationResults(Result, EDataValidationResult::Valid);
}
#endif
```

- `#if WITH_EDITOR`：只在编辑器构建里编译（打包后不存在，省体积）。
- `IsDataValid`：编辑器"数据校验"钩子——在资产保存/校验时调用，检查数据合法性。
- `Context.AddError(...)`：往校验上下文加错误（编辑器 Errors 面板显示）。
- `CombineDataValidationResults`：合并校验结果（Invalid 优先）。

### 6. `LOCTEXT_NAMESPACE` / `LOCTEXT`——本地化文本

```cpp
#define LOCTEXT_NAMESPACE "GameFeatures"
const FText InvalidCuePathError = FText::Format(LOCTEXT("InvalidCuePathError", "'{0}' is not a valid path!"), ...);
#undef LOCTEXT_NAMESPACE
```

- `LOCTEXT(Key, 文本)`：声明可本地化文本（`FText`），`Key` 是唯一标识。
- `LOCTEXT_NAMESPACE`：给这段文本一个命名空间作用域，避免 Key 冲突，末尾 `#undef` 回收。
- `FText::Format`：格式化文本（`{0}` 占位符）。

> 注意：`LOCTEXT` 的**第二个参数是给本地化系统用的原文**，属于"本地化资源"而非代码注释。按铁律 21/28/36（注释中文化），**注释**要中文；但 `LOCTEXT` 是本地化字符串，不是注释，Lyra 原文保留即可（也可译成中文，取决于是否要做本地化）。

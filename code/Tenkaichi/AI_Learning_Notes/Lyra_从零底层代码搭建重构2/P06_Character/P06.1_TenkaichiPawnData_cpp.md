## 二、逐段讲解（先讲"为什么"再讲"是什么"）

### 1. `#include UE_INLINE_GENERATED_CPP_BY_NAME(TenkaichiPawnData)`

- 和 4.1 一样，这是 **UHT 自动生成代码**的拉入宏。
- 你写了 `GENERATED_BODY()`，构建时引擎生成 `TenkaichiPawnData.gen.cpp`（含反射/RTTI），
  这一行把它拉进当前编译单元，否则链接报缺符号。

### 2. 构造函数（把 3 个指针置空）

```cpp
UTenkaichiPawnData::UTenkaichiPawnData(const FObjectInitializer& ObjectInitializer)
	: Super(ObjectInitializer)
{
	PawnClass = nullptr;
	InputConfig = nullptr;
	DefaultCameraMode = nullptr;
}
```

- `Super(ObjectInitializer)`：先初始化父类 `UPrimaryDataAsset`。
- 把 `PawnClass`、`InputConfig`、`DefaultCameraMode` 置 `nullptr`：
  - **为什么**：构造时这些字段还没有值，先给安全空指针，等设计师在编辑器数据资产里填。
- **注意**：`AbilitySets`（数组）和 `TagRelationshipMapping`（对象指针）**不在这里置空**——和 Lyra 一致。
  - 数组默认就是空的；`TObjectPtr` 默认就是 `nullptr`，无需手动置空。
  - Lyra 只显式置空 3 个，我们一比一还原，**不加也不减**。

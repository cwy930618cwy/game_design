## 四、PossessedBy —— 接管（队伍接力第一棒）

```cpp
void ATenkaichiPawn::PossessedBy(AController* NewController)
{
	const FGenericTeamId OldTeamID = MyTeamID;

	Super::PossessedBy(NewController);

	// 从控制器抄当前队伍，并监听它未来的变化
	if (ITenkaichiTeamAgentInterface* ControllerAsTeamProvider = Cast<ITenkaichiTeamAgentInterface>(NewController))
	{
		MyTeamID = ControllerAsTeamProvider->GetGenericTeamId();
		ControllerAsTeamProvider->GetTeamChangedDelegateChecked().AddDynamic(this, &ThisClass::OnControllerChangedTeam);
	}
	ConditionalBroadcastTeamChanged(this, OldTeamID, MyTeamID);
}
```

| 行 | 干什么 |
|----|--------|
| `const FGenericTeamId OldTeamID = MyTeamID;` | 记下**接管前**的队伍（用来比对"变没变"） |
| `Super::PossessedBy(NewController);` | 先让父类做接管标准流程 |
| `Cast<ITenkaichiTeamAgentInterface>(NewController)` | 判断**控制器是否懂队伍**（是队伍提供者？） |
| `MyTeamID = ...GetGenericTeamId();` | **从控制器抄队伍**——Pawn 跟老板走 |
| `...AddDynamic(this, &ThisClass::OnControllerChangedTeam);` | **注册监听**：控制器以后换队，通知我这个 Pawn |
| `ConditionalBroadcastTeamChanged(this, OldTeamID, MyTeamID);` | 广播（若真变了）：队伍从 `OldTeamID` → `MyTeamID` |

> 类比：新老板（控制器）上任——我先记住"我原来是哪个队的"，然后抄老板的队，并跟老板说"你以后换队记得喊我"；最后对全场喊一嗓子"我现在这队了"。
>
> 关键：即使控制器**不是**队伍提供者（Cast 失败），也会执行最后的广播（因为可能已 `NoTeam`→某队，仍值得通知）。

## 五、UnPossessed —— 释放（队伍接力最后一棒）

```cpp
void ATenkaichiPawn::UnPossessed()
{
	AController* const OldController = GetController();

	// 停止监听旧控制器的队伍变化
	const FGenericTeamId OldTeamID = MyTeamID;
	if (ITenkaichiTeamAgentInterface* ControllerAsTeamProvider = Cast<ITenkaichiTeamAgentInterface>(OldController))
	{
		ControllerAsTeamProvider->GetTeamChangedDelegateChecked().RemoveAll(this);
	}

	Super::UnPossessed();

	// 决定释放后新队伍是什么
	MyTeamID = DetermineNewTeamAfterPossessionEnds(OldTeamID);
	ConditionalBroadcastTeamChanged(this, OldTeamID, MyTeamID);
}
```

| 行 | 干什么 |
|----|--------|
| `OldController = GetController();` | 先抓住旧控制器（后面解绑要用） |
| `OldTeamID = MyTeamID;` | 记下释放前队伍 |
| `Cast<ITenkaichiTeamAgentInterface>(OldController)` | 旧控制器懂队伍吗？ |
| `...RemoveAll(this);` | **解绑监听**：不再听旧老板换队 |
| `Super::UnPossessed();` | 父类释放标准流程 |
| `MyTeamID = DetermineNewTeamAfterPossessionEnds(OldTeamID);` | **调策略钩子**：默认 `NoTeam`，子类可覆写保留旧队 |
| `ConditionalBroadcastTeamChanged(...)` | 广播（若变了）：新队伍已定 |

> 类比：老板离职——先跟他说"你以后换队别喊我了"（解绑），办完离职手续，然后按公司制度决定"我变成哪个队的"（默认自由身），最后喊一嗓子。
>
> 关键：`DetermineNewTeamAfterPossessionEnds` 是 `.h` 里那个 protected 虚函数——这是"释放后队伍去向"的唯一决策点。

## 六、SetGenericTeamId / GetGenericTeamId / GetOnTeamIndexChangedDelegate

```cpp
void ATenkaichiPawn::SetGenericTeamId(const FGenericTeamId& NewTeamID)
{
	if (GetController() == nullptr)
	{
		if (HasAuthority())
		{
			const FGenericTeamId OldTeamID = MyTeamID;
			MyTeamID = NewTeamID;
			ConditionalBroadcastTeamChanged(this, OldTeamID, MyTeamID);
		}
		else
		{
			UE_LOG(LogTenkaichiTeams, Error, TEXT("You can't set the team ID on a pawn (%s) except on the authority"), *GetPathNameSafe(this));
		}
	}
	else
	{
		UE_LOG(LogTenkaichiTeams, Error, TEXT("You can't set the team ID on a possessed pawn (%s); it's driven by the associated controller"), *GetPathNameSafe(this));
	}
}

FGenericTeamId ATenkaichiPawn::GetGenericTeamId() const
{
	return MyTeamID;
}

FOnTenkaichiTeamIndexChangedDelegate* ATenkaichiPawn::GetOnTeamIndexChangedDelegate()
{
	return &OnTeamChangedDelegate;
}
```

| 方法 | 干什么 |
|------|--------|
| `SetGenericTeamId` | **设队**。两条红线：①必须**未被接管**（`GetController()==nullptr`）；②必须**权威端**（`HasAuthority()`）。否则报错。满足则改 `MyTeamID` + 广播 |
| `GetGenericTeamId` | **读队**，直接返回 `MyTeamID` |
| `GetOnTeamIndexChangedDelegate` | 返回 `OnTeamChangedDelegate` 的指针，让外部能绑监听 |

> 关键：`SetGenericTeamId` 的**双重防线**——"被接管就由控制器说了算，外部不许改" + "非权威端不许改"。这保证了队伍归属的唯一权威性。
>
> 类比：改队像"改公司工牌"——只有两种情况不行：①你在岗（被老板管着，工牌归老板管）；②你不是人事部（没权威）。两条都过了才能改，改完全公司广播。

## 七、OnControllerChangedTeam（控制器换队回调）+ OnRep_MyTeamID（复制回调）

```cpp
void ATenkaichiPawn::OnControllerChangedTeam(UObject* TeamAgent, int32 OldTeam, int32 NewTeam)
{
	const FGenericTeamId MyOldTeamID = MyTeamID;
	MyTeamID = IntegerToGenericTeamId(NewTeam);
	ConditionalBroadcastTeamChanged(this, MyOldTeamID, MyTeamID);
}

void ATenkaichiPawn::OnRep_MyTeamID(FGenericTeamId OldTeamID)
{
	ConditionalBroadcastTeamChanged(this, OldTeamID, MyTeamID);
}
```

| 方法 | 干什么 |
|------|--------|
| `OnControllerChangedTeam` | **控制器换队回调**（`PossessedBy` 里绑的监听）。把整型新队转成 `FGenericTeamId`，同步给 Pawn，广播 |
| `OnRep_MyTeamID` | **客户端复制回调**（`ReplicatedUsing = OnRep_MyTeamID` 触发）。服务器改队复制过来后，客户端本地广播，让 UI/标色等感知 |

> 类比：两条"队伍变更的喇叭线"——`OnControllerChangedTeam` 是"老板换队传话线"，`OnRep_MyTeamID` 是"网络同步到客户端后的本地广播线"。两条线最终都汇到 `ConditionalBroadcastTeamChanged` 这一根总喇叭。

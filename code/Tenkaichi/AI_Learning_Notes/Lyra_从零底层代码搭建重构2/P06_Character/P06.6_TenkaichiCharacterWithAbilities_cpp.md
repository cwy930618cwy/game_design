// 覆盖基类：返回本角色自己的 ASC

### 1.3 PostInitializeComponents —— 绑定 ASC 与 Actor

```cpp

```

| 行 | 干什么 |
|----|--------|
| `Super::PostInitializeComponents()` | 先跑父类初始化 |
| `check(AbilitySystemComponent)` | 断言 ASC 已创建 |
| `InitAbilityActorInfo(this, this)` | 把 ASC 和本角色绑定（owner=本角色，avatar=本角色） |

> 关键点：**owner 和 avatar 都是 `this`**——这个角色既是"谁拥有 ASC"，又是"ASC 表现在谁身上"。而 4.7.3 的 `Character` 是从 PlayerState 借 ASC，owner/avatar 会不同。这就是"自带"和"借"的本质区别。

## 二、FTenkaichiReplicatedAcceleration —— 压缩加速度

```cpp
/**
 * FTenkaichiReplicatedAcceleration: 加速度的压缩表示（FastShared 网络优化用）
 */
USTRUCT()
struct FTenkaichiReplicatedAcceleration
{
	GENERATED_BODY()

	UPROPERTY()
	uint8 AccelXYRadians = 0;	// XY 加速度的方向角，量化到 [0, 2*pi]

	UPROPERTY()
	uint8 AccelXYMagnitude = 0;	// XY 加速度的大小，量化到 [0, MaxAcceleration]

	UPROPERTY()
	int8 AccelZ = 0;	// Z 轴原始加速度，量化到 [-MaxAcceleration, MaxAcceleration]
};
```

| 行 | 干什么 |
|----|--------|
| `USTRUCT()` | 一个简单的 USTRUCT（结构体，可被 UHT 处理） |
| `AccelXYRadians`（uint8） | XY 方向角，压成 1 字节 |
| `AccelXYMagnitude`（uint8） | XY 大小，压成 1 字节 |
| `AccelZ`（int8） | Z 轴加速度，压成 1 字节 |

> 类比：这是"加速度的压缩打包盒"——把浮点加速度压进 3 个字节，网络传输更省。是 FastShared 优化的前置数据。

## 三、FSharedRepMovement —— 共享移动复制

```cpp
/** 我们用来发送 FastShared 移动更新的类型。 */
USTRUCT()
struct FTenkaichiSharedRepMovement
{
	GENERATED_BODY()

	FTenkaichiSharedRepMovement();

	bool FillForCharacter(ACharacter* Character);
	bool Equals(const FTenkaichiSharedRepMovement& Other, ACharacter* Character) const;

	bool NetSerialize(FArchive& Ar, class UPackageMap* Map, bool& bOutSuccess);

	UPROPERTY(Transient)
	FRepMovement RepMovement;

	UPROPERTY(Transient)
	float RepTimeStamp = 0.0f;

	UPROPERTY(Transient)
	uint8 RepMovementMode = 0;

	UPROPERTY(Transient)
	bool bProxyIsJumpForceApplied = false;

	UPROPERTY(Transient)
	bool bIsCrouched = false;
};

template<>
struct TStructOpsTypeTraits<FTenkaichiSharedRepMovement> : public TStructOpsTypeTraitsBase2<FTenkaichiSharedRepMovement>
{
	enum
	{
		WithNetSerializer = true,
		WithNetSharedSerialization = true,
	};
};
```

| 行 | 干什么 |
|----|--------|
| `FSharedRepMovement` | 一次"共享移动更新"的载体：存 RepMovement + 时间戳 + 移动模式 + 是否跳跃力 + 是否蹲伏 |
| `FillForCharacter` | 从一个 `ACharacter` 填满这个结构（取它的移动状态） |
| `Equals` | 比较两次更新是否相同（避免重复发送） |
| `NetSerialize` | 自定义网络序列化（压缩传输） |
| `TStructOpsTypeTraits` 特化 | 告诉引擎"这个结构支持网络序列化 + 共享序列化"——**FastShared 的开关** |

> 类比：这是"共享移动快递单"——一台角色把移动状态打包成一份，多人一起看，比每人单独发一整套省带宽。`TStructOpsTypeTraits` 是"这快递单能走专线"的许可证。

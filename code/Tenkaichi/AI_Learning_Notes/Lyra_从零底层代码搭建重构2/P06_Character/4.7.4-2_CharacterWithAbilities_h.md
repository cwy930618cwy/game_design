## 一、逐段拆解

### 1.1 include + 宏

```cpp
#include "Character/TenkaichiCharacter.h"

#include "TenkaichiCharacterWithAbilities.generated.h"

#define UE_API TENKAICHIGAME_API
```

| 行 | 干什么 |
|----|--------|
| `#include "Character/TenkaichiCharacter.h"` | 父类 `ATenkaichiCharacter`（✅4.7.3）——继承了它全部能力 |
| `TenkaichiCharacterWithAbilities.generated.h` | UHT 生成头（每个 UCLASS 必须） |
| `#define UE_API TENKAICHIGAME_API` | 宏别名：`UE_API` = `TENKAICHIGAME_API`（导出宏，省得每个函数都写长名） |

---

### 1.2 前置声明

```cpp
class UAbilitySystemComponent;
class UTenkaichiAbilitySystemComponent;
class UObject;
```

| 行 | 干什么 |
|----|--------|
| `class UAbilitySystemComponent;` | 引擎 GAS 的通用 ASC（返回类型，前置声明即可） |
| `class UTenkaichiAbilitySystemComponent;` | 项目 ASC（断点类，L5 才教；前置声明不阻塞编译） |
| `class UObject;` | 引擎根对象 |

> 这三个**都是前置声明**（`class X;`），`.h` 里只用指针/返回类型，不需要完整定义 → **不阻塞编译**（铁律 30/35）。

---


| 行 | 干什么 |
|----|--------|
| `UCLASS(MinimalAPI, Blueprintable)` | 只导出类 + 允许蓝图继承 |
| 继承 `ATenkaichiCharacter` | 只加"自带 ASC"这一个扩展点，其余全继承 |

> 类比：**这是"自配驾照版"的基类**——4.7.3 是"基础款"（驾照藏起来），这版在基础款上加了个"自带驾照槽位"。

### 1.4 3 个公开方法

```cpp
public:
```

| 行 | 干什么 |
|----|--------|
| 构造函数 | 创建 ASC + 2 个属性集（`.cpp` 实现） |
| `PostInitializeComponents` | 组件初始化后绑定 ASC 与 Actor（`.cpp` 实现） |
| `GetAbilitySystemComponent` | **覆盖** `ATenkaichiCharacter`（4.7.3）的虚函数，返回自己的 ASC |

> 关键点：4.7.3 `ATenkaichiCharacter::GetAbilitySystemComponent` 是 `virtual`（4.7.3 `.h` 行 206），所以这里用 `override` 正确覆盖。基类问 PlayerState 借 ASC，这个类直接返回自己身上的。

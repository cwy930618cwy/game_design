# P02 System 叶子 —— 一张图看懂（全局总结 / 反晕眩版）

> **这份 md 的定位**：教完 P02 你晕，多半是因为这 4 个类**彼此毫不相干**（不像 P05 那样是一台机器）。
> 这份不讲怎么教，只讲「**它们为什么会放在同一个文件夹里**」+ 每个干什么。
> 想看细节 → 回到各自 `总md / _h / _cpp`。

---

## 〇、先给一个类比：把 `System/` 想成「项目组的公共工具柜」

想象一个游戏项目组的**杂物柜**，里面放的不是某个玩法模块，而是**谁都可能随手拿起来用一下**的东西：

| 柜子里的东西 | 对应类 | 什么时候会去拿 |
|-------------|--------|--------------|
| 📋 **一张写着"现在谁是主机"的牌子** | `TenkaichiActorUtilities` | 写代码时要判断"这段逻辑该不该在客户端跑" |
| 🔧 **一把瑞士军刀**（查资产/改材质/切局） | `TenkaichiSystemStatics` | 要按 ID 找资产、批量改材质、跳下一局 |
| 📁 **一份全局配置档案**（伤害/治疗用哪个 GE） | `TenkaichiGameData` | GAS 要"默认的伤害效果是哪个" |
| 🧪 **一套调试仪表**（跳过开场？加载装饰背景？） | `TenkaichiDevelopmentStatics` | 开发期想快速进游戏、开关调试功能 |
| 🏷️ **一摞带计数的标签贴纸** | `TenkaichiGameplayTagStack`（P02.1） | 要表示"3 个手雷""2 层中毒" |

> **一句话**：P02 就是「**跟玩法无关、纯工具性质**」的函数仓库 —— 特征是**几乎全是 `static` 函数**（`UBlueprintFunctionLibrary`）。

> ⚠️ **注意**：Lyra 的 `System/` 文件夹有 **26 个文件**，但本阶段**只教这 4 个叶子**。
> 其余 `AssetManager` / `GameInstance` / `ReplicationGraph` 等是**收口类**（依赖整个项目），归 **P14** 教。**别以为漏了。**

## 二、逐文件一句话职责

| 文件 | 类型 | 干嘛的 | 挂起 |
|------|------|--------|------|
| `TenkaichiActorUtilities` | 函数库 | **判断当前网络模式**（服务器/客户端/单机），返回一个蓝图友好的枚举 | ✅ 无 |
| `TenkaichiSystemStatics` | 函数库 | **杂项工具集**：按资产ID取软引用、切下一局、批量改 Mesh 材质参数、按类找组件 | ⚠️ 1 函数（P13） |
| `TenkaichiGameData` | 数据资产 | **全局游戏数据**：存"默认伤害 GE / 治疗 GE / 动态标签 GE"三个软引用 | ⚠️ `Get()`（P14） |
| `TenkaichiDevelopmentStatics` | 函数库 | **开发调试查询**：跳过开场、装饰背景、机器人攻击、找 PIE 世界、按短名找类 | ⚠️ 组A 3 函数（P18） |
| `TenkaichiGameplayTagStack` | 结构体×2 | **带计数的标签栈**：表示"N 个某物"（3 个手雷、2 层中毒） | ✅ 无 |

**关键洞察（铁律 30）**：
> `TenkaichiGameData.h` 里 `UGameplayEffect` 只是**前置声明**，成员是 `TSoftClassPtr<UGameplayEffect>`（**软引用**）。
> **软引用不阻塞编译**！所以 `.h` 能独立编译 —— **只有 `.cpp` 的 `Get()` 硬调 `AssetManager` 才需要挂起。**
> 这就是为什么教学顺序是「`.h` 先教不挂起 → `.cpp` 挂起」。

## 五、常见混淆点

| 容易混 | 区别 |
|--------|------|
| **`System/` 的 26 个文件 vs 本阶段的 4 个** | 其余 22 个（AssetManager/GameInstance/ReplicationGraph…）是**收口类**，依赖整个项目，归 **P14** 教。**不是漏了** |
| **`ActorUtilities` vs `SystemStatics`** | 前者只干一件事（查网络模式）；后者是**杂货铺**（查资产/改材质/切局/找组件） |
| **`GameData` 是"数据"还是"逻辑"** | 纯**数据**（`UPrimaryDataAsset`），只存 3 个软引用。逻辑在 P05 的 Execution 里 |
| **软引用 `TSoftClassPtr` 为什么不阻塞编译** | 它只存一个路径字符串，不需要知道类的完整定义 → 前置声明就够 |
| **`GameplayTagStack` 跟 `GameplayTagContainer` 的区别** | `Container` 是**集合**（有/没有）；`Stack` 是**计数**（有几个）。"中毒"用前者，"2 层中毒"用后者 |

## 六、记忆口诀（3 句）

1. **P02 = 工具柜** —— 都是 static 工具函数，彼此不依赖。
2. **`.h` 基本都能编** —— 因为大量用前置声明 + 软引用。
3. **挂起的都是 `.cpp` 的 `Get()`/查询函数** —— 它们在等 P13/P14/P18 三个后期模块。

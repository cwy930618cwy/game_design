## 一、这个 `.h` 解决什么问题（为什么）

`.h` 声明一个**蓝图函数库**，提供"查询当前网络模式"的能力。核心是两件事：

1. **自定义一个蓝图友好枚举 `EBlueprintExposedNetMode`**——用 `UENUM()` 标记，蓝图里能直接当"Switch"节点用。
2. **声明静态函数 `SwitchOnNetMode`**——传入任意 `UObject`（Actor 或 Component），返回当前网络模式。

> 🔑 **一句话**：`.h` 定义"**查网络模式**"的开关——一个自定义枚举 + 一个查询函数。蓝图里用 `Switch On NetMode` 节点，就能按"单机/服务器/客户端"走不同分支。

## 二、完整代码（注释已中文化、前缀已替换，你照这个抄）

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

// 蓝图函数库基类：把静态函数暴露给蓝图
#include "Kismet/BlueprintFunctionLibrary.h"

// 生成头文件（UHT 用，放最后）
#include "TenkaichiActorUtilities.generated.h"

class UObject;
struct FFrame;

// 蓝图友好的网络模式枚举（对应引擎 ENetMode，但值是连续的、可被蓝图 Switch）
UENUM()
enum class EBlueprintExposedNetMode : uint8
{
	/** 单机：无网络，一个或多个本地玩家。因为具备全部服务器功能，所以也看作服务器。 */
	Standalone,

	/** 纯服务器（dedicated server）：没有本地玩家的服务器。 */
	DedicatedServer,

	/** 监听服务器（listen server）：自身带一个本地玩家、同时允许其他网络玩家加入的服务器。 */
	ListenServer,

	/**
	 * 网络客户端：连接远端服务器的客户端。
	 * 注意：所有小于 NM_Client 的模式都算某种服务器，所以"NetMode < NM_Client"恒为服务器。
	 */
	Client
};


UCLASS()
class UTenkaichiActorUtilities : public UBlueprintFunctionLibrary
{
	GENERATED_BODY()

public:
	/**
	 * 获取某个 Actor 或 Component 当前的网络模式（纯服务器/客户端/单机等）。
	 */
	UFUNCTION(BlueprintCallable, Category="Tenkaichi", meta=(WorldContext="WorldContextObject", ExpandEnumAsExecs=ReturnValue))
	static EBlueprintExposedNetMode SwitchOnNetMode(const UObject* WorldContextObject);
};
```

### include 区 + 前置声明

```cpp

```

| 行 | 干什么 |
|----|--------|
| `#include "Kismet/BlueprintFunctionLibrary.h"` | 引擎蓝图函数库基类——`UBlueprintFunctionLibrary` 在这里定义，`UTenkaichiActorUtilities` 继承它 |
| `#include "TenkaichiActorUtilities.generated.h"` | UHT 生成的反射代码（文件名带前缀 `Tenkaichi`） |
| `class UObject;` | `UObject` 前置声明（函数参数要用它，但不展开头文件） |
| `struct FFrame;` | `FFrame` 前置声明（蓝图函数库内部需要，先声明不展开） |

> 注意：这里**没有** `#include "CoreMinimal.h"`，而是直接包含 `Kismet/BlueprintFunctionLibrary.h`（它内部会带出需要的类型）。`class UObject;` / `struct FFrame;` 是**前置声明**——`.h` 里只用指针/引用时不必展开完整定义，能加快编译（铁律 30 提过：前置声明不阻塞编译）。

### UENUM —— EBlueprintExposedNetMode

```cpp
// 蓝图友好的网络模式枚举（对应引擎 ENetMode，但值是连续的、可被蓝图 Switch）
UENUM()
enum class EBlueprintExposedNetMode : uint8
{
	/** 单机：无网络，一个或多个本地玩家。因为具备全部服务器功能，所以也看作服务器。 */
	Standalone,

	/** 纯服务器（dedicated server）：没有本地玩家的服务器。 */
	DedicatedServer,

	/** 监听服务器（listen server）：自身带一个本地玩家、同时允许其他网络玩家加入的服务器。 */
	ListenServer,

	/**
	 * 网络客户端：连接远端服务器的客户端。
	 * 注意：所有小于 NM_Client 的模式都算某种服务器，所以"NetMode < NM_Client"恒为服务器。
	 */
	Client
};
```

| 行 | 干什么 |
|----|--------|
| `UENUM()` | 标记为蓝图反射枚举——蓝图里可用 |
| `enum class EBlueprintExposedNetMode : uint8` | C++11 强类型枚举，底层 `uint8`（省内存），枚举名 `EBlueprintExposedNetMode` |
| 4 个值 | `Standalone` / `DedicatedServer` / `ListenServer` / `Client`——对应引擎 `ENetMode` 的 4 种模式 |

> **为什么不用引擎的 `ENetMode`？** 引擎 `ENetMode` 的 `NM_*` 值不是 0/1/2/3 连续排布，蓝图 `Switch On Enum` 用起来别扭。这里**自定义一个连续枚举**，配合 `ExpandEnumAsExecs=ReturnValue`，蓝图端就能展开成干净的"四路分支"节点。
>
> 枚举名 `EBlueprintExposedNetMode` 在 Lyra 里就叫这个名字（无前缀），所以**不换前缀**（铁律 24 只换 `Lyra` 开头的类名）。

### UCLASS —— UTenkaichiActorUtilities

```cpp
UCLASS()
class UTenkaichiActorUtilities : public UBlueprintFunctionLibrary
{
	GENERATED_BODY()

public:
	/**
	 * 获取某个 Actor 或 Component 当前的网络模式（纯服务器/客户端/单机等）。
	 */
	UFUNCTION(BlueprintCallable, Category="Tenkaichi", meta=(WorldContext="WorldContextObject", ExpandEnumAsExecs=ReturnValue))
	static EBlueprintExposedNetMode SwitchOnNetMode(const UObject* WorldContextObject);
};
```

| 行 | 干什么 |
|----|--------|
| `UCLASS()` | 标记为反射类 |
| `class UTenkaichiActorUtilities : public UBlueprintFunctionLibrary` | 继承蓝图函数库基类——静态函数暴露给蓝图 |
| `UFUNCTION(BlueprintCallable, ...)` | 蓝图可调用 |
| `Category="Tenkaichi"` | 蓝图右键菜单分类（`Lyra`→`Tenkaichi`） |
| `meta=(WorldContext="WorldContextObject")` | 蓝图端自动把"World 上下文"填进去，用户不用手动传 |
| `meta=(... ExpandEnumAsExecs=ReturnValue)` | 让枚举返回值在蓝图端展开成"多分支执行节点" |
| `static EBlueprintExposedNetMode SwitchOnNetMode(const UObject* WorldContextObject)` | 静态函数：传任意 UObject，返回网络模式枚举 |

> **`ExpandEnumAsExecs=ReturnValue` 是关键**：正常情况下蓝图拿到枚举后还要再连一个 `Switch On Enum` 节点；加上这个 meta，`SwitchOnNetMode` 的**返回值直接展开成一排分支引脚**（Standalone / DedicatedServer / ListenServer / Client），连上就能按模式分流——一个节点搞定。

## 一、这个 `.h` 解决什么问题（为什么）

`.h` 声明一个**蓝图函数库**，集中放一批"系统级工具函数"。核心是 6 个静态函数，分三类：

| 分类 | 函数 | 干嘛 |
|------|------|------|
| 资产 | `GetTypedSoftObjectReferenceFromPrimaryAssetId` | 按资产 ID 拿软引用（不加载资产） |
| 资产 | `GetPrimaryAssetIdFromUserFacingExperienceName` | 按对外体验名算资产 ID（⚠️ .cpp 依赖 P13） |
| 关卡 | `PlayNextGame` | 无缝切换去下一局 |
| 材质 | `SetScalar/Vector/ColorParameterValueOnAllMeshComponents` | 批量改目标 Actor 所有 Mesh 材质参数 |
| 组件 | `FindComponentsByClass` | 按类型找目标 Actor 上的组件 |

> 🔑 **一句话**：`.h` 声明一批"**针对 Actor / 世界做查询或批量操作**"的静态工具函数，蓝图里直接调用。

## 二、完整代码（注释已中文化、前缀已替换，你照这个抄）

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

// 蓝图函数库基类：把静态函数暴露给蓝图
#include "Kismet/BlueprintFunctionLibrary.h"

// 软对象指针（TSoftObjectPtr）类型定义，用于"引用但不加载"资产
#include "UObject/SoftObjectPtr.h"

// 生成头文件（UHT 用，放最后）
#include "TenkaichiSystemStatics.generated.h"

// 模板类 TSubclassOf 的前置声明（类引用类型，这里只声明不展开）
template <typename T> class TSubclassOf;

class AActor;
class UActorComponent;
class UObject;
struct FFrame;

// 蓝图函数库：集中放一批系统级工具函数
UCLASS()
class UTenkaichiSystemStatics : public UBlueprintFunctionLibrary
{
	GENERATED_BODY()

public:

	/** 返回与主资产 ID 关联的软对象引用，即使资产未加载也能用（用 DeterminesOutputType 让蓝图推导输出类型） */
	UFUNCTION(BlueprintPure, Category = "AssetManager", meta=(DeterminesOutputType=ExpectedAssetType))
	static TSoftObjectPtr<UObject> GetTypedSoftObjectReferenceFromPrimaryAssetId(FPrimaryAssetId PrimaryAssetId, TSubclassOf<UObject> ExpectedAssetType);

	UFUNCTION(BlueprintCallable)
	static FPrimaryAssetId GetPrimaryAssetIdFromUserFacingExperienceName(const FString& AdvertisedExperienceID);

	UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly, Category="Tenkaichi", meta = (WorldContext = "WorldContextObject"))
	static void PlayNextGame(const UObject* WorldContextObject);

	// 把 TargetActor 上所有 Mesh 组件的所有 section 的标量参数 ParameterName 设为 ParameterValue
	UFUNCTION(BlueprintCallable, Category = "Rendering|Material", meta=(DefaultToSelf="TargetActor"))
	static void SetScalarParameterValueOnAllMeshComponents(AActor* TargetActor, const FName ParameterName, const float ParameterValue, bool bIncludeChildActors = true);

	// 把 TargetActor 上所有 Mesh 组件的所有 section 的向量参数 ParameterName 设为 ParameterValue
	UFUNCTION(BlueprintCallable, Category = "Rendering|Material", meta=(DefaultToSelf="TargetActor"))
	static void SetVectorParameterValueOnAllMeshComponents(AActor* TargetActor, const FName ParameterName, const FVector ParameterValue, bool bIncludeChildActors = true);

	// 把 TargetActor 上所有 Mesh 组件的所有 section 的颜色参数 ParameterName 设为 ParameterValue
	UFUNCTION(BlueprintCallable, Category = "Rendering|Material", meta=(DefaultToSelf="TargetActor"))
	static void SetColorParameterValueOnAllMeshComponents(AActor* TargetActor, const FName ParameterName, const FLinearColor ParameterValue, bool bIncludeChildActors = true);

	// 获取继承自给定类的所有组件
	UFUNCTION(BlueprintCallable, Category = "Actor", meta=(DefaultToSelf="TargetActor", ComponentClass="/Script/Engine.ActorComponent", DeterminesOutputType="ComponentClass"))
	static TArray<UActorComponent*> FindComponentsByClass(AActor* TargetActor, TSubclassOf<UActorComponent> ComponentClass, bool bIncludeChildActors = true);
};
```

## 三、逐段拆解（先讲清为什么，再给代码）

### include 区 + 前置声明

```cpp
#include "Kismet/BlueprintFunctionLibrary.h"
#include "UObject/SoftObjectPtr.h"
#include "TenkaichiSystemStatics.generated.h"

template <typename T> class TSubclassOf;
class AActor;
class UActorComponent;
class UObject;
struct FFrame;
```

| 行 | 干什么 |
|----|--------|
| `#include "Kismet/BlueprintFunctionLibrary.h"` | 引擎蓝图函数库基类——`UBlueprintFunctionLibrary` 在这里定义，`UTenkaichiSystemStatics` 继承它 |
| `#include "UObject/SoftObjectPtr.h"` | 提供 `TSoftObjectPtr<T>` 软引用模板（引用资产但不加载） |
| `#include "TenkaichiSystemStatics.generated.h"` | UHT 生成的反射代码（文件名带前缀 `Tenkaichi`） |
| `template <typename T> class TSubclassOf;` | `TSubclassOf` 模板类前置声明（函数参数要用它，但不展开） |
| `class AActor;` / `class UActorComponent;` | `AActor` / `UActorComponent` 前置声明 |
| `class UObject;` / `struct FFrame;` | `UObject` / `FFrame` 前置声明 |

> 注意：`FPrimaryAssetId` 是引擎类（定义在 `Engine/AssetManagerTypes.h`），这里**没有显式 include** 它——靠 `UObject/SoftObjectPtr.h` 间接带出。这是 Lyra 原样做法，照抄即可（铁律 30：`.h` 里这种间接引入能编译）。

### UCLASS —— UTenkaichiSystemStatics 的三个资产/关卡函数

```cpp
UFUNCTION(BlueprintPure, Category = "AssetManager", meta=(DeterminesOutputType=ExpectedAssetType))
static TSoftObjectPtr<UObject> GetTypedSoftObjectReferenceFromPrimaryAssetId(FPrimaryAssetId PrimaryAssetId, TSubclassOf<UObject> ExpectedAssetType);

UFUNCTION(BlueprintCallable)
static FPrimaryAssetId GetPrimaryAssetIdFromUserFacingExperienceName(const FString& AdvertisedExperienceID);

UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly, Category="Tenkaichi", meta = (WorldContext = "WorldContextObject"))
static void PlayNextGame(const UObject* WorldContextObject);
```

| 行 | 干什么 |
|----|--------|
| `BlueprintPure` | 纯函数（无副作用，蓝图里像"读取"节点），调用方不产生执行线 |
| `meta=(DeterminesOutputType=ExpectedAssetType)` | 让蓝图根据 `ExpectedAssetType` 输入推导 `TSoftObjectPtr` 的输出类型 |
| `GetTypedSoftObjectReferenceFromPrimaryAssetId` | 按资产 ID + 期望类型，返回软引用 |
| `GetPrimaryAssetIdFromUserFacingExperienceName` | 按对外体验名返回资产 ID（**.cpp 依赖 P13，届时挂起**） |
| `BlueprintAuthorityOnly` | 仅服务器（有权限端）可调用——切关卡只能服务器干 |
| `Category="Tenkaichi"` | 蓝图右键菜单分类（`Lyra`→`Tenkaichi`） |
| `WorldContext="WorldContextObject"` | 蓝图端自动填"World 上下文" |

> **`GetTypedSoftObjectReferenceFromPrimaryAssetId` 的关键 meta**：`DeterminesOutputType=ExpectedAssetType` —— 蓝图里你给它一个"期望的资产类型"，它的输出软引用就会自动变成那个类型的 `SoftObjectReference`，不用手动 Cast。

### UCLASS —— 三个改材质函数 + 找组件函数

```cpp
UFUNCTION(BlueprintCallable, Category = "Rendering|Material", meta=(DefaultToSelf="TargetActor"))
static void SetScalarParameterValueOnAllMeshComponents(AActor* TargetActor, const FName ParameterName, const float ParameterValue, bool bIncludeChildActors = true);

UFUNCTION(BlueprintCallable, Category = "Rendering|Material", meta=(DefaultToSelf="TargetActor"))
static void SetVectorParameterValueOnAllMeshComponents(AActor* TargetActor, const FName ParameterName, const FVector ParameterValue, bool bIncludeChildActors = true);

UFUNCTION(BlueprintCallable, Category = "Rendering|Material", meta=(DefaultToSelf="TargetActor"))
static void SetColorParameterValueOnAllMeshComponents(AActor* TargetActor, const FName ParameterName, const FLinearColor ParameterValue, bool bIncludeChildActors = true);

UFUNCTION(BlueprintCallable, Category = "Actor", meta=(DefaultToSelf="TargetActor", ComponentClass="/Script/Engine.ActorComponent", DeterminesOutputType="ComponentClass"))
static TArray<UActorComponent*> FindComponentsByClass(AActor* TargetActor, TSubclassOf<UActorComponent> ComponentClass, bool bIncludeChildActors = true);
```

| 行 | 干什么 |
|----|--------|
| `Category = "Rendering\|Material"` | 蓝图分类（竖线 = 子菜单层级） |
| `meta=(DefaultToSelf="TargetActor")` | 蓝图里 `TargetActor` 默认填"调用者自己"（Self） |
| `SetScalarParameterValueOnAllMeshComponents` | 批量改标量材质参数 |
| `SetVectorParameterValueOnAllMeshComponents` | 批量改向量材质参数 |
| `SetColorParameterValueOnAllMeshComponents` | 批量改颜色材质参数（内部转调向量版） |
| `FindComponentsByClass` | 按类型找组件，返回数组 |
| `ComponentClass="/Script/Engine.ActorComponent"` | 蓝图里该参数默认显示为引擎的 `ActorComponent` 类型 |
| `DeterminesOutputType="ComponentClass"` | 让返回的 `TArray<UActorComponent*>` 在蓝图里自动变成 ComponentClass 指定的具体类型数组 |

> **参数默认值 `bool bIncludeChildActors = true`**：`.h` 里给了默认值 `true`——默认连带处理子 Actor 的组件。`.cpp` 实现里不需要重复写默认值（C++ 规则：默认参数只在声明处写一次）。

### 段 3：`Get()`（12~15 行）⚠️ 挂起
```cpp
const UTenkaichiGameData& UTenkaichiGameData::Get()
{
	return UTenkaichiAssetManager::Get().GetGameData();

```
- `ULyraAssetManager::Get()`：拿资产管理器单例。
- `.GetGameData()`：从 AssetManager 里取出"这份全局游戏数据"。

> **`Get()` 为什么是"返回引用"而不是指针？** 它保证一定存在（AssetManager 启动时加载了全局游戏数据），所以返回 `const UTenkaichiGameData&`（引用）比指针更安全——调用方不用判空。这也是"全局唯一数据"的典型写法。

## 一、这个文件解决什么问题（为什么）

上一份 `TenkaichiActorUtilities` 回答"我是服务器还是客户端"。这一份 `SystemStatics` 是一批**更杂的系统级工具**，Lyra 把它们塞进一个静态函数库：

| 函数 | 干嘛 | 例子 |
|------|------|------|
| `GetTypedSoftObjectReferenceFromPrimaryAssetId` | 按资产 ID 拿软引用（资产**不用加载**也能拿到引用） | 拿"某张地图/某个配置"的软引用 |
| `GetPrimaryAssetIdFromUserFacingExperienceName` | 按"对外体验名"算回资产 ID | ⚠️ 依赖 P13 Experience |
| `PlayNextGame` | 无缝切换去下一局 | 打完一局直接开下一局 |
| `SetScalar/Vector/ColorParameterValueOnAllMeshComponents` | 给目标 Actor 上**所有** Mesh 组件的材质参数统一赋值 | 全模型高亮、变色 |
| `FindComponentsByClass` | 找目标 Actor 上所有指定类型的组件 | 找所有"武器"组件 |

**共性**：它们都回答"**针对某个 Actor/世界，我要批量/查询做一件事**"，与具体玩法解耦。

## 二、内部结构全景

```
ULyraSystemStatics : UBlueprintFunctionLibrary        ← 纯静态工具，无成员变量
├─ GetTypedSoftObjectReferenceFromPrimaryAssetId(Id, ExpectedType) → TSoftObjectPtr<UObject>
├─ GetPrimaryAssetIdFromUserFacingExperienceName(Name) → FPrimaryAssetId        ⚠️ P13
├─ PlayNextGame(WorldContext)                         ← 无缝切下一局
├─ SetScalarParameterValueOnAllMeshComponents(Actor, Name, Value, bIncludeChildActors)
├─ SetVectorParameterValueOnAllMeshComponents(Actor, Name, Value, bIncludeChildActors)
├─ SetColorParameterValueOnAllMeshComponents(Actor, Name, Value, bIncludeChildActors)
└─ FindComponentsByClass(Actor, ComponentClass, bIncludeChildActors) → TArray<UActorComponent*>
```

> 注意：`SetColor...` 内部只是转调 `SetVector...`（颜色转成 FVector），不做重复工作。

## 四、新知识点预告（教到时会拆开讲）

1. **`FPrimaryAssetId`**：资产的唯一 ID（类型名 + 资产名），引擎资产系统用它定位资产。
2. **`TSoftObjectPtr`**：软引用——引用资产但**不加载**，用到时才异步加载。
3. **`UAssetManager::GetPrimaryAssetPath`**：资产 ID → 资产路径。
4. **`GEngine->GetWorldContextFromWorldChecked` / `ServerTravel`**：世界上下文 + 服务器切换关卡。
5. **`AActor::ForEachComponent<T>()`**：遍历 Actor 上所有某类型组件（含/不含子 Actor）。
6. **`GetComponents(Class, out)`**：按类型批量取组件。
7. **`ensure` / `UE_LOG(LogLyra,...)`**：复用 P02.2 ActorUtilities 已学的 `ensure` + 第 0 步日志通道。

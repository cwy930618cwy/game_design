## 一、这个文件要解决什么问题（为什么）

**给蓝图/cheat 提供一套"开发调试"静态工具函数**。它是 `UBlueprintFunctionLibrary`（蓝图函数库）子类——蓝图里能直接拖出来的全局函数集合。

分两组功能：

**组 A（3 个，依赖 P18 Settings）**：查询"开发设置"来决定游戏逻辑行为——
| 函数 | 干嘛 | 非编辑器默认 |
|------|------|-------------|
| `ShouldSkipDirectlyToGameplay` | 是否跳过开场直接进玩法 | `false` |
| `ShouldLoadCosmeticBackgrounds` | 是否加载外观背景 | `true` |
| `CanPlayerBotsAttack` | 机器人（Bot）能否攻击 | `true` |

> 这三个都问 `UTenkaichiDeveloperSettings`（P18 基建/工具的 Settings 类）里的开关。**依赖 P18，挂起**。

**组 B（4 个，纯引擎可编译）**：类查找工具，供 cheat/开发命令用——
| 函数 | 干嘛 |
|------|------|
| `FindPlayInEditorAuthorityWorld` | 找 PIE 里的服务器世界（dedicated server 优先） |
| `GetAllBlueprints` | 扫描 AssetRegistry 拿所有蓝图 |
| `FindBlueprintClass` | 按名字找蓝图生成类 |
| `FindClassByShortName` | 按短名找类（原生类 + 蓝图都试） |

> 🔑 **一句话**：一组蓝图可调用的开发调试静态函数——一部分查"开发设置"（P18），一部分按名字查类/世界（纯引擎）。

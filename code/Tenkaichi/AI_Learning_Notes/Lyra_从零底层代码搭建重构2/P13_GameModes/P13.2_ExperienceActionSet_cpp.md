## 一、完整代码（可直接照抄）

```cpp
// 版权声明（可保留或省略，不影响编译）
#include "TenkaichiExperienceActionSet.h"
#include "GameFeatureAction.h"

#if WITH_EDITOR
#include "Misc/DataValidation.h"
#endif

#include UE_INLINE_GENERATED_CPP_BY_NAME(TenkaichiExperienceActionSet)

#define LOCTEXT_NAMESPACE "TenkaichiSystem"

UTenkaichiExperienceActionSet::UTenkaichiExperienceActionSet()
{
}

#if WITH_EDITOR
EDataValidationResult UTenkaichiExperienceActionSet::IsDataValid(FDataValidationContext& Context) const
{
	// 先算父类结果，默认"有效"。
	EDataValidationResult Result = CombineDataValidationResults(Super::IsDataValid(Context), EDataValidationResult::Valid);

	int32 EntryIndex = 0;
	for (const UGameFeatureAction* Action : Actions)
	{
		if (Action)
		{
			// 逐个让动作自校验，合并结果。
			EDataValidationResult ChildResult = Action->IsDataValid(Context);
			Result = CombineDataValidationResults(Result, ChildResult);
		}
		else
		{
			// Actions 数组里有空项 → 整体无效，并报错指出下标。
			Result = EDataValidationResult::Invalid;
			Context.AddError(FText::Format(LOCTEXT("ActionEntryIsNull", "Actions 里下标 {0} 处是空项"), FText::AsNumber(EntryIndex)));
		}

		++EntryIndex;
	}

	return Result;
}
#endif

#if WITH_EDITORONLY_DATA
void UTenkaichiExperienceActionSet::UpdateAssetBundleData()
{
	Super::UpdateAssetBundleData();

	// 把每个动作的附加资源打进资源包，保证依赖能被正确加载。
	for (UGameFeatureAction* Action : Actions)
	{
		if (Action)
		{
			Action->AddAdditionalAssetBundleData(AssetBundleData);
		}
	}
}
#endif // WITH_EDITORONLY_DATA

#undef LOCTEXT_NAMESPACE
```

## 二、关键点讲解

### 1. 空构造
```cpp
UTenkaichiExperienceActionSet::UTenkaichiExperienceActionSet() {}
```
无初始化逻辑，保留是因为 `.h` 声明了它。

### 2. `IsDataValid`：只校验 Actions 空项
```cpp
for (const UGameFeatureAction* Action : Actions)
```
- 用 `CombineDataValidationResults` 合并父类 + 每个动作的校验结果。
- 发现空项 → `Invalid` + `Context.AddError` 报错（带 `FText::AsNumber(EntryIndex)` 下标）。
- **没有** P13.1 里那段 `GetClass()->IsNative()` 检查——因为 `ExperienceActionSet` 本身就是"组合单元"，不需要防二次子类化（它 `NotBlueprintable`，本来就不能蓝图子类化）。

### 3. `UpdateAssetBundleData`：资源打包
```cpp
for (UGameFeatureAction* Action : Actions)
{
	Action->AddAdditionalAssetBundleData(AssetBundleData);
}
```
- `AssetBundleData` 来自父类 `UPrimaryDataAsset`。
- 每个动作把自己依赖的资产加进 Bundle，加载动作集时资源一起加载。

### 4. `#if WITH_EDITOR` / `#if WITH_EDITORONLY_DATA`
两个钩子条件编译，只进编辑器/编辑数据构建，游戏运行时跳过。

### 5. `#define LOCTEXT_NAMESPACE` / `#undef`
文件开头 define、结尾 undef，给 `LOCTEXT` 宏提供命名空间（`"TenkaichiSystem"`），避免污染其他翻译。

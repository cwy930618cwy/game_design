## 一、这个类解决什么问题（先讲为什么）

前面 P13.1~P13.6 讲了"经验"是什么、怎么加载、怎么等加载完。但还缺一个**总调度**——谁来决定"这局用哪个经验"？谁来在经验加载完后**生成玩家的 Pawn**？谁来处理玩家登录/重生/选择出生点？

`ATenkaichiGameMode`（游戏模式）就是这场游戏的**总调度器**。它是 UE 里一个关键角色：服务器端决定"这局游戏怎么玩、玩家怎么进场、Pawn 怎么生成"。

> **类比**：GameMode 是"导演 + 前台"——决定演哪出戏（用哪个经验）、演员（玩家）什么时候上场（生成 Pawn）、从哪个门上场（选出生点）、死了怎么返场（重生）。

它干的核心事：
1. **定经验**：开机时按优先级（URL 选项 → 开发者设置 → 命令行 → WorldSettings → 默认）选出这局的经验，交给 `ExperienceManagerComponent` 去加载。
2. **等经验**：经验加载完后，把已经登录但还没 Pawn 的玩家都生成 Pawn。
3. **管生成**：决定用什么 Pawn 类（从 PawnData 取）、从哪出生（交给 `PlayerSpawningManagerComponent`）、能否重生。

## 二、内部结构全景

### `.h`（89 行）公开/保护成员

| 成员 | 作用 |
|------|------|
| 构造 `ATenkaichiGameMode` | 指定 GameState/GameSession/PlayerController/Pawn/HUD 等默认类 |
| `GetPawnDataForController` | 查某控制器的 PawnData（从 PlayerState 或经验默认值） |

| `OnGameModePlayerInitialized` 委托 | 玩家初始化完成时广播 |
| 保护成员 | `OnExperienceLoaded`/`IsExperienceLoaded`/`OnMatchAssignmentGiven`/`HandleMatchAssignmentIfNotExpectingOne`/`TryDedicatedServerLogin`/`HostDedicatedServerMatch`/`OnUserInitializedForDedicatedServer` |

### `.cpp`（522 行）核心流程

1. **构造**：指定一堆默认类（GameState/PlayerController/Pawn/HUD…）
2. **InitGame → HandleMatchAssignmentIfNotExpectingOne**：按优先级选出经验
3. **OnMatchAssignmentGiven**：把经验交给 ExperienceManagerComponent 加载
4. **OnExperienceLoaded**：经验加载完，生成已登录玩家的 Pawn
5. **各种出生/重生逻辑**：ChoosePlayerStart / SpawnDefaultPawn / FinishRestartPlayer 等

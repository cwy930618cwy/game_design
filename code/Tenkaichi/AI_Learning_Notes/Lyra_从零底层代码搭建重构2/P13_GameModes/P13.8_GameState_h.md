## 〇、这个 `.h` 在解决什么

`ATenkaichiGameState` 是全局共享状态板。`.h` 声明了：1 个构造 + 4 个 `AActor` 接口覆写 + 3 个 `AGameStateBase` 接口覆写 + 1 个 `IAbilitySystemInterface` 实现 + 若干公开方法 + 2 个私有组件 + 2 个复制字段。

**类声明拆解：**

| 块 | 代码 | 作用 |
|----|------|------|
| ① 双基类 | `AModularGameStateBase` + `IAbilitySystemInterface` | 模块化 GameState + GAS 接口 |
| ② 特殊宏 | `UCLASS(MinimalAPI, Config=Game)` + `#define UE_API` | 精简导出 + 支持 ini 配置 |
| ③ 构造 | `ATenkaichiGameState` | 创建 ASC + 经验管理器子对象 |
| ④ AActor 接口 | `PreInitializeComponents`/`PostInitializeComponents`/`EndPlay`/`Tick` | 生命周期 |
| ⑤ GameStateBase 接口 | `AddPlayerState`/`RemovePlayerState`/`SeamlessTravelTransitionCheckpoint` | 玩家列表管理 |
| ⑥ GAS 接口 | `GetAbilitySystemComponent` | 返回全局 ASC |
| ⑦ 公开方法 | `GetLyraAbilitySystemComponent`/`MulticastMessageToClients`/... | 全局功能 |
| ⑧ 私有组件 | `ExperienceManagerComponent`/`AbilitySystemComponent` | 挂载的组件 |
| ⑨ 复制字段 | `ServerFPS`/`RecorderPlayerState` | 复制给客户端 |

## 一、完整代码（可直接照抄）

```cpp
// 版权声明（可保留或省略，不影响编译）
#pragma once

#include "AbilitySystemInterface.h"
#include "ModularGameState.h"

#include "TenkaichiGameState.generated.h"

#define UE_API TENKAICHIGAME_API

struct FTenkaichiVerbMessage;

class APlayerState;
class UAbilitySystemComponent;
class UTenkaichiAbilitySystemComponent;
class UTenkaichiExperienceManagerComponent;
class UObject;
struct FFrame;

/**
 * ATenkaichiGameState
 *
 *	本项目使用的基础游戏状态类。
 */
UCLASS(MinimalAPI, Config = Game)
class ATenkaichiGameState : public AModularGameStateBase, public IAbilitySystemInterface
{
	GENERATED_BODY()

public:

	// 构造函数：创建 AbilitySystemComponent + ExperienceManagerComponent 子对象。
	UE_API ATenkaichiGameState(const FObjectInitializer& ObjectInitializer = FObjectInitializer::Get());

	//~AActor 接口开始
	// 组件预初始化（先调父类）。
	UE_API virtual void PreInitializeComponents() override;
	// 组件后初始化（初始化全局 ASC 的 actor 信息）。
	UE_API virtual void PostInitializeComponents() override;
	// Actor 生命周期结束（先调父类）。
	UE_API virtual void EndPlay(const EEndPlayReason::Type EndPlayReason) override;
	// 每帧更新（服务器权威时更新 ServerFPS）。
	UE_API virtual void Tick(float DeltaSeconds) override;
	//~AActor 接口结束

	//~AGameStateBase 接口开始
	// 添加玩家状态（先调父类）。
	UE_API virtual void AddPlayerState(APlayerState* PlayerState) override;
	// 移除玩家状态（先调父类）。
	UE_API virtual void RemovePlayerState(APlayerState* PlayerState) override;
	// 无缝传送过渡检查点（移除 Bot 和非活跃玩家）。
	UE_API virtual void SeamlessTravelTransitionCheckpoint(bool bToTransitionMap) override;
	//~AGameStateBase 接口结束

	//~IAbilitySystemInterface 接口开始
	// 返回这个 GameState 的全局能力系统组件。
	UE_API virtual UAbilitySystemComponent* GetAbilitySystemComponent() const override;
	//~IAbilitySystemInterface 接口结束

	// 获取用于"游戏全局事物"的能力系统组件。
	UFUNCTION(BlueprintCallable, Category = "Tenkaichi|GameState")
	UTenkaichiAbilitySystemComponent* GetTenkaichiAbilitySystemComponent() const { return AbilitySystemComponent; }

	// 发送一条所有客户端（大概率）都会收到的消息
	// （只用于像淘汰、服务器加入消息等可以接受丢失的客户端通知）
	UFUNCTION(NetMulticast, Unreliable, BlueprintCallable, Category = "Tenkaichi|GameState")
	UE_API void MulticastMessageToClients(const FTenkaichiVerbMessage Message);

	// 发送一条保证所有客户端都会收到的消息
	// （只用于不能接受丢失的客户端通知）
	UFUNCTION(NetMulticast, Reliable, BlueprintCallable, Category = "Tenkaichi|GameState")
	UE_API void MulticastReliableMessageToClients(const FTenkaichiVerbMessage Message);

	// 获取服务器的 FPS（复制给客户端）。
	UE_API float GetServerFPS() const;

	// 标记本地玩家状态正在录制回放。
	UE_API void SetRecorderPlayerState(APlayerState* NewPlayerState);

	// 获取录制回放的玩家状态（如果有效）。
	UE_API APlayerState* GetRecorderPlayerState() const;

	// 回放玩家状态变化时调用的委托。
	DECLARE_MULTICAST_DELEGATE_OneParam(FOnRecorderPlayerStateChanged, APlayerState*);
	FOnRecorderPlayerStateChanged OnRecorderPlayerStateChangedEvent;

private:
	// 处理当前玩法经验的加载和管理。
	UPROPERTY()
	TObjectPtr<UTenkaichiExperienceManagerComponent> ExperienceManagerComponent;

	// 用于"游戏全局事物"（主要是 gameplay cue）的能力系统组件子对象。
	UPROPERTY(VisibleAnywhere, Category = "Tenkaichi|GameState")
	TObjectPtr<UTenkaichiAbilitySystemComponent> AbilitySystemComponent;

protected:
	// 服务器的 FPS（复制给客户端）。
	UPROPERTY(Replicated)
	float ServerFPS;

	// 录制回放的玩家状态，用来选择正确的 Pawn 跟随。
	// 只在回放流里设置，正常情况下不复制。
	UPROPERTY(Transient, ReplicatedUsing = OnRep_RecorderPlayerState)
	TObjectPtr<APlayerState> RecorderPlayerState;

	// 回放玩家状态复制回调。
	UFUNCTION()
	UE_API void OnRep_RecorderPlayerState();

};

#undef UE_API
```

## 二、关键点讲解

### 1. 双基类：`AModularGameStateBase` + `IAbilitySystemInterface`

```cpp
class ATenkaichiGameState : public AModularGameStateBase, public IAbilitySystemInterface
```

- `AModularGameStateBase`：S1 插件的模块化 GameState（支持 GameFeature 动态挂组件）。
- `IAbilitySystemInterface`：GAS 的接口，实现它就要提供 `GetAbilitySystemComponent()`。这样别的系统能通过这个接口拿到 GameState 的全局 ASC。

### 2. `UCLASS(MinimalAPI, Config = Game)`

同 P13.7：`MinimalAPI` 精简导出，`Config = Game` 支持 `DefaultGame.ini` 配置。

### 3. 内联实现 `GetTenkaichiAbilitySystemComponent`

```cpp
UTenkaichiAbilitySystemComponent* GetTenkaichiAbilitySystemComponent() const { return AbilitySystemComponent; }
```

注意这个函数**直接在 `.h` 里内联实现**（函数体就写在这里，不在 `.cpp`）。因为它只是简单返回成员，不需要 `UE_API` 导出标记（内联函数每个编译单元都有一份）。

### 4. 网络多播：`NetMulticast` + `Unreliable`/`Reliable`

```cpp
UFUNCTION(NetMulticast, Unreliable, BlueprintCallable, Category = "Tenkaichi|GameState")
void MulticastMessageToClients(const FTenkaichiVerbMessage Message);

UFUNCTION(NetMulticast, Reliable, BlueprintCallable, Category = "Tenkaichi|GameState")
void MulticastReliableMessageToClients(const FTenkaichiVerbMessage Message);
```

- `NetMulticast`：网络多播——服务器调用，会复制到所有客户端执行。
- `Unreliable`：不可靠（可能丢包，用于淘汰消息这类"丢了没关系"的通知）。
- `Reliable`：可靠（保证送达，用于"丢了不行"的通知）。
- 参数 `const FTenkaichiVerbMessage Message`：**按值传**（不是指针/引用），这是网络函数的要求（值类型才能序列化复制）。

### 5. 复制字段

```cpp
UPROPERTY(Replicated)
float ServerFPS;

UPROPERTY(Transient, ReplicatedUsing = OnRep_RecorderPlayerState)
TObjectPtr<APlayerState> RecorderPlayerState;
```

- `ServerFPS`：普通复制（`Replicated`），服务器每帧更新，复制给客户端。
- `RecorderPlayerState`：`ReplicatedUsing = OnRep_RecorderPlayerState`（复制后调回调）+ `Transient`（临时，不存盘）。

### 6. 委托 `DECLARE_MULTICAST_DELEGATE_OneParam`

```cpp
DECLARE_MULTICAST_DELEGATE_OneParam(FOnRecorderPlayerStateChanged, APlayerState*);
```

纯 C++ 多播委托，带 1 个参数（`APlayerState*`）。P13.5 已教过 `_OneParam` 的用法。

## 〇、这个 `.cpp` 在解决什么

`.h` 声明了"剧本单"的字段，`.cpp` 实现 3 件事：
1. **构造** `UTenkaichiExperienceDefinition()`（空实现）
2. **数据校验** `IsDataValid`（编辑器）：① 检查 Actions 数组没有空项 ② 禁止蓝图经验再被蓝图子类化
3. **资源打包** `UpdateAssetBundleData`（编辑器数据）：把 Actions 的依赖资产打进 Bundle

**实现拆解（3 个函数）：**

| 函数 | 环境 | 作用 |
|------|------|------|
| `UTenkaichiExperienceDefinition()` | 所有 | 空构造 |
| `IsDataValid` | `#if WITH_EDITOR` | 编辑器数据校验 |
| `UpdateAssetBundleData` | `#if WITH_EDITORONLY_DATA` | 资源包数据合并 |

## 一、完整代码（可直接照抄）

```cpp
// 版权声明（可保留或省略，不影响编译）
#include "TenkaichiExperienceDefinition.h"
#include "GameFeatureAction.h"

#if WITH_EDITOR
#include "Misc/DataValidation.h"
#endif

#include UE_INLINE_GENERATED_CPP_BY_NAME(TenkaichiExperienceDefinition)

#define LOCTEXT_NAMESPACE "TenkaichiSystem"

UTenkaichiExperienceDefinition::UTenkaichiExperienceDefinition()
{
}

#if WITH_EDITOR
EDataValidationResult UTenkaichiExperienceDefinition::IsDataValid(FDataValidationContext& Context) const
{
	// 先算父类校验结果，默认视为"有效"。
	EDataValidationResult Result = CombineDataValidationResults(Super::IsDataValid(Context), EDataValidationResult::Valid);

	int32 EntryIndex = 0;
	for (const UGameFeatureAction* Action : Actions)
	{
		if (Action)
		{
			// 逐个让动作自校验，合并结果。
			EDataValidationResult ChildResult = Action->IsDataValid(Context);
			Result = CombineDataValidationResults(Result, ChildResult);
		}
		else
		{
			// Actions 数组里有空项 → 整体无效，并报错指出下标。
			Result = EDataValidationResult::Invalid;
			Context.AddError(FText::Format(LOCTEXT("ActionEntryIsNull", "Actions 里下标 {0} 处是空项"), FText::AsNumber(EntryIndex)));
		}

		++EntryIndex;
	}

	// 禁止"蓝图经验"再被蓝图子类化（在 BP 里子类化一次可以，但不能套娃）。
	if (!GetClass()->IsNative())
	{
		const UClass* ParentClass = GetClass()->GetSuperClass();

		// 往上找最近的"原生 C++ 父类"。
		const UClass* FirstNativeParent = ParentClass;
		while ((FirstNativeParent != nullptr) && !FirstNativeParent->IsNative())
		{
			FirstNativeParent = FirstNativeParent->GetSuperClass();
		}

		if (FirstNativeParent != ParentClass)
		{
			// 说明这个蓝图经验是从另一个蓝图经验继承的 → 报错，建议用 ActionSets 组合代替继承。
			Context.AddError(FText::Format(LOCTEXT("ExperienceInheritenceIsUnsupported", "蓝图经验不支持被蓝图子类化（请改用 ActionSets 组合）。父类是 {0}，但应是 {1}。"),
				FText::AsCultureInvariant(GetPathNameSafe(ParentClass)),
				FText::AsCultureInvariant(GetPathNameSafe(FirstNativeParent))
			));
			Result = EDataValidationResult::Invalid;
		}
	}

	return Result;
}
#endif

#if WITH_EDITORONLY_DATA
void UTenkaichiExperienceDefinition::UpdateAssetBundleData()
{
	Super::UpdateAssetBundleData();

	// 把每个动作的附加资产打进资源包数据，保证依赖能被正确加载。
	for (UGameFeatureAction* Action : Actions)
	{
		if (Action)
		{
			Action->AddAdditionalAssetBundleData(AssetBundleData);
		}
	}
}
#endif // WITH_EDITORONLY_DATA

#undef LOCTEXT_NAMESPACE
```

## 二、关键点讲解

### 1. 空构造
```cpp
UTenkaichiExperienceDefinition::UTenkaichiExperienceDefinition() {}
```
没有任何初始化逻辑（4 个 UPROPERTY 字段都有默认值）。**保留**是因为 `.h` 声明了它。

### 2. `IsDataValid`：编辑器校验（两块逻辑）

**第一块：校验 `Actions` 数组**
```cpp
for (const UGameFeatureAction* Action : Actions)
```
- 用 `CombineDataValidationResults` 把"父类结果 + 每个动作的结果"逐层合并。
- 发现空项 → `Result = Invalid` + `Context.AddError` 报错（带 `FText::AsNumber(EntryIndex)` 下标）。
- `LOCTEXT` 宏生成本地化文本。

**第二块：禁止"蓝图经验被蓝图子类化"**
```cpp
if (!GetClass()->IsNative())  // 当前类是蓝图
```
- `IsNative()`：判断类是不是 C++ 原生类。
- 往上 `GetSuperClass()` 找到**最近的原生父类** `FirstNativeParent`。
- 若 `FirstNativeParent != ParentClass`，说明这个蓝图经验的父类**不是**原生类（而是另一个蓝图经验）→ 报错。
- 报错文案明确建议：**用 `ActionSets` 组合（P13.2）代替蓝图继承**——这正是为什么 `ActionSets` 存在。

### 3. `UpdateAssetBundleData`：资源打包
```cpp
for (UGameFeatureAction* Action : Actions)
{
	Action->AddAdditionalAssetBundleData(AssetBundleData);
}
```
- `AssetBundleData` 来自父类 `UPrimaryDataAsset`。
- 每个 `UGameFeatureAction` 通过 `AddAdditionalAssetBundleData` 把自己依赖的资产加进 Bundle，这样加载剧本单时动作需要的资源能一起加载。

### 4. `#if WITH_EDITOR` / `#if WITH_EDITORONLY_DATA`
两个钩子都用条件编译包裹，**只进编辑器/编辑数据构建**，游戏运行时编译会整个跳过。所以这两个函数不影响发布包。

### 5. `#define LOCTEXT_NAMESPACE` / `#undef`
`LOCTEXT` 宏需要命名空间前缀（`"TenkaichiSystem"`），文件开头 define、结尾 undef，避免污染其他翻译。

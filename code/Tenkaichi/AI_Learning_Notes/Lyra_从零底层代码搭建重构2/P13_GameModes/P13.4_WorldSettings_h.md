## 〇、这个 `.h` 在解决什么

`ATenkaichiWorldSettings` 继承 `AWorldSettings`（世界设置），给"这张地图"加一个"默认经验"字段，并提供一个查询方法把它解析成资产 ID。`.h` 声明 1 个构造 + 1 个查询方法 + 1 个编辑器校验 + 2 个字段。

**类声明拆解：**

| 块 | 代码 | 作用 |
|----|------|------|
| ① 基类 | `AWorldSettings` | 每张地图自带的"世界设置" Actor |
| ② 特殊宏 | `UCLASS(MinimalAPI)` + `#define UE_API LYRAGAME_API` | 精简导出（见关键点 1） |
| ③ 构造 | `ATenkaichiWorldSettings(const FObjectInitializer&)` | 空构造 |
| ④ 查询方法 | `GetDefaultGameplayExperience()` | 把默认经验软引用解析成 `FPrimaryAssetId` |
| ⑤ 字段 | `DefaultGameplayExperience`（`TSoftClassPtr`） | 这张图默认用哪个经验（软引用） |
| ⑥ 编辑器校验 | `CheckForErrors()`（`#if WITH_EDITOR`） | 地图检查时的警告钩子 |
| ⑦ 编辑器字段 | `ForceStandaloneNetMode`（`#if WITH_EDITORONLY_DATA`） | 编辑器中 Play 强制单机 |

#include "TenkaichiWorldSettings.generated.h"

	UE_API virtual void CheckForErrors() override;

	// 当服务器打开这张地图时，返回要用的默认经验（如果没被"面向用户的经验"覆盖的话）。

	UPROPERTY(EditDefaultsOnly, Category=GameMode)

public:

#if WITH_EDITORONLY_DATA
	// 这个关卡是不是"前端/独立经验"的一部分？

## 二、关键点讲解

### 1. `UCLASS(MinimalAPI)` + `#define UE_API LYRAGAME_API`（本文件最特殊的一点）

普通类用 `UCLASS()` 会把**所有**声明的东西都导出（`LYRAGAME_API`）。但 `ATenkaichiWorldSettings` 用 `UCLASS(MinimalAPI)`：

- `MinimalAPI`：**最小导出**——只导出"反射系统必需"的部分，其余默认不导出（节省导出符号、加快编译/链接）。
- 但有几个函数我们**确实想给别的模块用**（`GetDefaultGameplayExperience`、构造、`CheckForErrors`），所以手动给它们标 `UE_API`。
- 这里的 `UE_API` 是个**临时别名**：`#define UE_API TENKAICHIGAME_API`，文件末尾 `#undef UE_API` 回收。这样写 `UE_API` 就等价于写 `TENKAICHIGAME_API`，只是更短。

> 一句话：`MinimalAPI` 默认不导出，想导出的成员手动标 `UE_API`（本文件里 = `TENKAICHIGAME_API`）。

### 2. 基类 `AWorldSettings`

`AWorldSettings` 是引擎"世界设置" Actor，每张地图都有一个，存这张地图的默认配置（重力、默认 GameMode 等）。我们继承它，就是往"这张地图的默认设置"里追加"默认经验"。

### 3. 前置声明 + 软引用（为什么零挂起）

```cpp
class UTenkaichiExperienceDefinition;   // 只声明，不 include

TSoftClassPtr<UTenkaichiExperienceDefinition> DefaultGameplayExperience;
```

- `TSoftClassPtr<T>`：**软类指针**——只存一个"路径字符串"，不加载、不持有真实类。所以前置声明 `class X;` 就够，**不用 include**。
- 这保证 `.h` 不拖 P13.1 的完整定义，也保证 `DefaultGameplayExperience` 这个字段本身不阻塞编译。

### 4. `GetDefaultGameplayExperience()` 返回 `FPrimaryAssetId`

这个查询方法把软引用里的路径，交给引擎 `UAssetManager` 解析成一个**主资产 ID**（`FPrimaryAssetId`）。真正的解析逻辑在 `.cpp`，`.h` 只声明签名。

### 5. 两个编辑器区段

| 区段 | 内容 | 何时编译 |
|------|------|---------|
| `#if WITH_EDITOR` | `CheckForErrors()` 虚函数 | 只在编辑器编译 |
| `#if WITH_EDITORONLY_DATA` | `ForceStandaloneNetMode` 字段 | 只在编辑器数据编译 |

- `CheckForErrors()`：编辑器"地图检查"时被调用，用来警告地图里放了普通 `APlayerStart`（应换成 `ATenkaichiPlayerStart`）。
- `ForceStandaloneNetMode`：前端/独立场景勾上后，编辑器点 Play 强制单机（不连服务器）。

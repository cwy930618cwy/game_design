## 〇、这个 `.h` 在解决什么

`UTenkaichiUserFacingExperienceDefinition` 是面向玩家的大厅地图卡片定义。`.h` 声明了：12 个数据字段（全是 `UPROPERTY`）+ 1 个方法 `CreateHostingRequest`。

**类声明拆解：**

| 块 | 代码 | 作用 |
|----|------|------|
| ① 基类 | `UPrimaryDataAsset` | 引擎"主数据资产"基类 |
| ② 特殊宏 | `UCLASS(BlueprintType)` | 蓝图可用类型 |
| ③ 数据字段 | 12 个 `UPROPERTY(BlueprintReadWrite, EditAnywhere)` | 编辑器可配的大厅卡片数据 |
| ④ 方法 | `CreateHostingRequest` | 创建开局请求 |

## 一、完整代码（可直接照抄）

```cpp
// 版权声明（可保留或省略，不影响编译）
#pragma once

#include "Engine/DataAsset.h"

#include "TenkaichiUserFacingExperienceDefinition.generated.h"

class FString;
class UCommonSession_HostSessionRequest;
class UObject;
class UTexture2D;
class UUserWidget;
struct FFrame;

// 用于在 UI 里展示经验、并开启一场新会话的设置描述。
UCLASS(BlueprintType)
class UTenkaichiUserFacingExperienceDefinition : public UPrimaryDataAsset
{
	GENERATED_BODY()

public:
	// 要加载的具体地图。
	UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience, meta=(AllowedTypes="Map"))
	FPrimaryAssetId MapID;

	// 要加载的玩法经验。
	UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience, meta=(AllowedTypes="TenkaichiExperienceDefinition"))
	FPrimaryAssetId ExperienceID;

	// 作为 URL 选项传给游戏的额外参数。
	UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience)
	TMap<FString, FString> ExtraArgs;

	// UI 里的主标题。
	UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience)
	FText TileTitle;

	// 副标题。
	UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience)
	FText TileSubTitle;

	// 完整描述。
	UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience)
	FText TileDescription;

	// UI 里用的图标。
	UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience)
	TObjectPtr<UTexture2D> TileIcon;

	// 加载进入（或退出）某个经验时要显示的加载屏控件。
	UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=LoadingScreen)
	TSoftClassPtr<UUserWidget> LoadingScreenWidget;

	// 如果为 true，这是一个默认经验，应该用于快速游玩并在 UI 里优先展示。
	UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience)
	bool bIsDefaultExperience = false;

	// 如果为 true，这会出现在前端的经验列表里。
	UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience)
	bool bShowInFrontEnd = true;

	// 如果为 true，会为这场游戏录制回放。
	UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience)
	bool bRecordReplay = false;

	// 这场会话的最大玩家数。
	UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience)
	int32 MaxPlayerCount = 16;

public:
	// 创建一个请求对象，用于按这些设置真正开启一场会话。
	UFUNCTION(BlueprintCallable, BlueprintPure=false, meta = (WorldContext = "WorldContextObject"))
	UCommonSession_HostSessionRequest* CreateHostingRequest(const UObject* WorldContextObject) const;
};
```

## 二、关键点讲解

### 1. 基类 `UPrimaryDataAsset`（P13.1 已教过）

`UPrimaryDataAsset` 是引擎的"主数据资产"基类。继承它的类可以创建成数据资产（`.uasset`），用 `FPrimaryAssetId` 唯一标识、用 AssetManager 统一管理。P13.1 `UTenkaichiExperienceDefinition` 也是继承它。

### 2. `UCLASS(BlueprintType)`

对比 P13.1 的 `ExperienceDefinition` 用的 `UCLASS(BlueprintType, Const)`（`Const` = 只读），这里**没有 `Const`**——因为大厅卡片数据**允许被修改**（`BlueprintReadWrite` + `EditAnywhere`）。

### 3. 12 个数据字段——全是"编辑器可配"

```cpp
UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience, meta=(AllowedTypes="Map"))
FPrimaryAssetId MapID;
```

- `BlueprintReadWrite`：蓝图可读写。
- `EditAnywhere`：编辑器任何地方可编辑（这些字段是给策划在编辑器里配的）。
- `meta=(AllowedTypes="Map")`：限制这个 `FPrimaryAssetId` 只能选"Map"类型的主资产（编辑器下拉框只显示地图）。
- `meta=(AllowedTypes="TenkaichiExperienceDefinition")`：限制只能选玩法经验类型（注意：`LyraExperienceDefinition` 换成了 `TenkaichiExperienceDefinition`，铁律 24）。

### 4. `TObjectPtr` vs `TSoftClassPtr`

- `TObjectPtr<UTexture2D> TileIcon`：**硬引用**图标纹理（加载卡片时一起加载进内存）。
- `TSoftClassPtr<UUserWidget> LoadingScreenWidget`：**软引用**加载屏控件类（按需加载，不占内存）。

对比：图标是每张卡片都要显示的（硬引用合理），加载屏控件是进入游戏才用（软引用延迟加载）。

### 5. 字段默认值

```cpp
bool bIsDefaultExperience = false;
bool bShowInFrontEnd = true;
bool bRecordReplay = false;
int32 MaxPlayerCount = 16;
```

C++11 成员初始化（声明时给默认值）。`MaxPlayerCount = 16` 是 Lyra 的默认最大玩家数。

### 6. `CreateHostingRequest` 方法声明

```cpp
UFUNCTION(BlueprintCallable, BlueprintPure=false, meta = (WorldContext = "WorldContextObject"))
UCommonSession_HostSessionRequest* CreateHostingRequest(const UObject* WorldContextObject) const;
```

- `BlueprintCallable`：蓝图可调。
- `BlueprintPure=false`：**非纯函数**（有副作用，会创建对象，不是纯计算）。默认 `BlueprintCallable` 就是非纯，这里显式写出强调。
- `WorldContext = "WorldContextObject"`：定位 World。
- 返回 `UCommonSession_HostSessionRequest*`：开局请求对象（CommonSession 插件的类型，前置声明）。
- `const` 方法：不修改这个定义本身，只读字段生成请求。

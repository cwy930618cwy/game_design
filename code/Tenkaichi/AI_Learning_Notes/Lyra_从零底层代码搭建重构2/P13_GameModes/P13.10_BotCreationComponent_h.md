## 〇、这个 `.h` 在解决什么

`UTenkaichiBotCreationComponent` 是按配置生成机器人的组件。`.h` 声明了：1 个构造 + 1 个 `BeginPlay` + 1 个 `OnExperienceLoaded` + 5 个成员字段 + 3 个生成方法 + 3 个服务器专用方法。

**类声明拆解：**

| 块 | 代码 | 作用 |
|----|------|------|
| ① 基类 | `UGameStateComponent` | 挂 GameState 的组件 |
| ② 特殊宏 | `UCLASS(Blueprintable, Abstract)` | 蓝图可继承 + 抽象类 |
| ③ 构造 | `UTenkaichiBotCreationComponent` | 空实现 |
| ④ 生命周期 | `BeginPlay` | 监听经验加载完成 |
| ⑤ 成员字段 | `NumBotsToCreate`/`BotControllerClass`/`RandomBotNames`/`RemainingBotNames`/`SpawnedBotList` | 配置 + 状态 |
| ⑥ 生成方法 | `SpawnOneBot`/`RemoveOneBot`/`ServerCreateBots` | 增删 Bot |
| ⑦ 服务器专用 | `Cheat_AddBot`/`Cheat_RemoveBot`/`CreateBotName` | `#if WITH_SERVER_CODE` |

## 一、完整代码（可直接照抄）

```cpp
// 版权声明（可保留或省略，不影响编译）
#pragma once

#include "Components/GameStateComponent.h"

#include "TenkaichiBotCreationComponent.generated.h"

class UTenkaichiExperienceDefinition;
class UTenkaichiPawnData;
class AAIController;

// 按配置自动生成机器人的组件（挂在 GameState 上）。
UCLASS(Blueprintable, Abstract)
class UTenkaichiBotCreationComponent : public UGameStateComponent
{
	GENERATED_BODY()

public:
	// 构造函数：空实现（父类处理初始化）。
	UTenkaichiBotCreationComponent(const FObjectInitializer& ObjectInitializer = FObjectInitializer::Get());

	//~UActorComponent 接口开始
	// 组件开始游戏：监听"经验加载完成"。
	virtual void BeginPlay() override;
	//~UActorComponent 接口结束

private:
	// 经验加载完成的回调（最低优先级）。
	void OnExperienceLoaded(const UTenkaichiExperienceDefinition* Experience);

protected:
	// 要生成的 Bot 数量。
	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category=Gameplay)
	int32 NumBotsToCreate = 5;

	// Bot 用的 AI 控制器类。
	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category=Gameplay)
	TSubclassOf<AAIController> BotControllerClass;

	// 随机 Bot 名字池。
	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category=Gameplay)
	TArray<FString> RandomBotNames;

	// 还没用完的 Bot 名字池。
	TArray<FString> RemainingBotNames;

protected:
	// 已经生成的 Bot 控制器列表。
	UPROPERTY(Transient)
	TArray<TObjectPtr<AAIController>> SpawnedBotList;

	// 生成单个 Bot。
	UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly, Category=Gameplay)
	virtual void SpawnOneBot();

	// 如果可能，删除最后生成的一个 Bot。
	UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly, Category=Gameplay)
	virtual void RemoveOneBot();

	// 生成最多 NumBotsToCreate 个 Bot。
	UFUNCTION(BlueprintNativeEvent, BlueprintAuthorityOnly, Category=Gameplay)
	void ServerCreateBots();

#if WITH_SERVER_CODE
public:
	// 作弊：加一个 Bot。
	void Cheat_AddBot() { SpawnOneBot(); }
	// 作弊：删一个 Bot。
	void Cheat_RemoveBot() { RemoveOneBot(); }

	// 按玩家索引生成一个 Bot 名字。
	FString CreateBotName(int32 PlayerIndex);
#endif
};
```

## 二、关键点讲解

### 1. `UCLASS(Blueprintable, Abstract)`

```cpp
UCLASS(Blueprintable, Abstract)
class UTenkaichiBotCreationComponent : public UGameStateComponent
```

- `Blueprintable`：这个类**可以被蓝图继承**（蓝图里做子类覆盖默认配置）。
- `Abstract`：抽象类，**不能直接实例化**，必须被继承（C++ 或蓝图子类）才能用。

> 对比前面 P13.5 的 `ExperienceManagerComponent` 是 `UCLASS(MinimalAPI)` + `final`（终点类，不能继承）；这个 `BotCreationComponent` 相反，是 `Blueprintable` + `Abstract`（就是要你继承后配置）。

### 2. `TSubclassOf<AAIController>`

```cpp
UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category=Gameplay)
TSubclassOf<AAIController> BotControllerClass;
```

`TSubclassOf<T>` 是"限制类型的类引用"——存一个"类"（不是实例），且这个类必须继承自 `AAIController`。编辑器里会出现一个"类选择器"下拉框，只能选 AI 控制器子类。P07/P11 已教过 `TSubclassOf`。

### 3. `EditDefaultsOnly` vs `EditAnywhere`

- `EditDefaultsOnly`：只能**默认值**编辑（类默认对象 CDO 上编辑，不能每个实例单独改）。对比 P13.9 用的 `EditAnywhere`（每个实例都能改）。
- 这里 Bot 的配置是"组件类级别的默认配置"，所以用 `EditDefaultsOnly`。

### 4. `BlueprintAuthorityOnly`

```cpp
UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly, Category=Gameplay)
virtual void SpawnOneBot();
```

`BlueprintAuthorityOnly`：这个蓝图函数**只能在服务器（权威端）调用**。生成 Bot 是服务器的事，客户端调用会报错。

### 5. `BlueprintNativeEvent` vs `BlueprintCallable`

- `ServerCreateBots` 用 `BlueprintNativeEvent`：蓝图可以**覆写**（C++ 有默认实现 `_Implementation`，蓝图能覆盖）。
- `SpawnOneBot` / `RemoveOneBot` 用 `BlueprintCallable` + `virtual`：蓝图只能**调用**，不能覆写（但 C++ 子类可以 override）。

### 6. `#if WITH_SERVER_CODE` 条件编译

```cpp
#if WITH_SERVER_CODE
public:
	void Cheat_AddBot() { SpawnOneBot(); }
	void Cheat_RemoveBot() { RemoveOneBot(); }
	FString CreateBotName(int32 PlayerIndex);
#endif
```

`WITH_SERVER_CODE` 是一个编译宏：服务器构建（`Target.cs` 里 `bBuildServer`）时为 `true`。这段代码**只在服务器构建里编译**，客户端构建里不存在这些函数。

> 对比 `.cpp` 里的 `#if WITH_SERVER_CODE ... #else ... #endif`：服务器用真实现，客户端用空实现（`ensureMsgf(0)` 报错）。

### 7. `TObjectPtr<AAIController>` 数组

```cpp
UPROPERTY(Transient)
TArray<TObjectPtr<AAIController>> SpawnedBotList;
```

`TObjectPtr`（UE5 智能对象指针）+ `Transient`（临时，不存盘）——记录已生成的 Bot 控制器，方便 `RemoveOneBot` 时删。

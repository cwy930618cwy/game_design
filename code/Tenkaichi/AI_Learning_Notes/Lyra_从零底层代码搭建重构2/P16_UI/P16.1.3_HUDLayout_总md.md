## 一、这个类解决什么问题（先讲为什么）

`ATenkaichiHUD` 只是"告示牌架子"（P16.1.2 讲的）。真正把 UI **布局**放在 HUD 上的，是 `UTenkaichiHUDLayout`。

P15.7 `AddWidgets` 的 `Layout` 数组（`FLyraHUDLayoutRequest`）就是指向这个布局类——它把 `UTenkaichiHUDLayout` 推到 `UI.Layer.Game` 层，然后玩家就能看见血条、弹药等。

它做两件事：
1. **Esc 菜单**：监听 `UI.Action.Escape` 输入动作 → 按 Esc 时把 `EscapeMenuClass`（暂停菜单）推到 `UI.Layer.Menu` 层。
2. **手柄断线提示**：监听输入设备的连接/配对变化 → 如果玩家的手柄全断了，弹出"手柄已断开"提示屏（`ControllerDisconnectedScreen`）；重新连上手柄就隐藏。

> **类比**：HUD 架子（P16.1.2）立好后，`HUDLayout` 是"架子的分区总管"——它管"Esc 时弹出暂停菜单"、"手柄断了弹提示"这些"全局 UI 行为"。

## 一、这个类解决什么问题（先讲为什么）

P16.1.3 的 `UTenkaichiHUDLayout` 检测到"玩家手柄全断了"时，要弹一个"请重新连接手柄"的提示屏。**这个提示屏就是本类**。

它除了显示提示文字，还处理一个特殊场景：**某些平台（主机）要求"用户和手柄强绑定"**（strict pairing）——这种情况下，玩家可以通过这个屏上的"切换用户"按钮，选择另一个平台账号。这个按钮只在支持 strict pairing 的平台显示。

> **类比**：这个屏是"断线救援界面"——告诉你"手柄掉了"，如果平台支持，还给你一个"换个账号"的按钮。

#pragma once

#include "CommonActivatableWidget.h"
#include "GameplayTagContainer.h"

#include "TenkaichiControllerDisconnectedScreen.generated.h"

class UHorizontalBox;
class UObject;
class UCommonButtonBase;
struct FPlatformUserSelectionCompleteParams;

/**
 * 当用户所有手柄都断开、需要重新连接才能继续游戏时显示的屏。
 */
UCLASS(Abstract, BlueprintType, Blueprintable)
class UTenkaichiControllerDisconnectedScreen : public UCommonActivatableWidget
{
	GENERATED_BODY()
public:
	// 构造函数：加默认要求的平台 trait tag。
	UTenkaichiControllerDisconnectedScreen(const FObjectInitializer& ObjectInitializer);
	
protected:
	// 控件激活时的回调（设置"切换用户"按钮的可见性）。
	virtual void NativeOnActivated() override;

	// 点击"切换用户"按钮时的回调。
	virtual void HandleChangeUserClicked();

	/**
	 * 当用户在选择了"切换平台用户"提示之后完成切换时调用。
	 */
	virtual void HandleChangeUserCompleted(const FPlatformUserSelectionCompleteParams& Params);

	/**
	 * 如果应该显示"切换用户"按钮，返回 true。
	 * 这会在运行时检查 ICommonUIModule 的平台 trait tag。
	 */
	virtual bool ShouldDisplayChangeUserButton() const;

	/**
	 * 要求的平台 trait——满足时显示"切换用户"按钮，
	 * 允许玩家改变当前映射到输入设备的已登录用户。
	 */
	UPROPERTY(EditDefaultsOnly)
	FGameplayTagContainer PlatformSupportsUserChangeTags;

	/**
	 * 有"严格"用户配对要求的平台，可能想允许你直接从游戏内 UI 里切换用户。
	 * 这些平台在 CommonUI 里被打上 "Platform.Trait.Input.HasStrictControllerPairing" 标记。
	 *
	 * 如果所在平台没有该 trait，这个 HBox 会被设成不可见。
	 */
	UPROPERTY(meta = (BindWidget))
	TObjectPtr<UHorizontalBox> HBox_SwitchUser;

	/**
	* 一个按钮，用于在有严格用户配对要求的平台上切换用户。
	* 
	* @see HBox_SwitchUser
	*/
	UPROPERTY(meta = (BindWidget))
	TObjectPtr<UCommonButtonBase> Button_ChangeUser;
};

// 构造函数：加默认要求的平台 trait tag。
UTenkaichiControllerDisconnectedScreen::UTenkaichiControllerDisconnectedScreen(const FObjectInitializer& ObjectInitializer)
	: Super(ObjectInitializer)
{
	// 默认只有严格配对平台需要这个按钮。
	PlatformSupportsUserChangeTags.AddTag(TAG_Platform_Trait_Input_HasStrictControllerPairing);
}

// 控件激活时的回调（设置"切换用户"按钮的可见性）。
void UTenkaichiControllerDisconnectedScreen::NativeOnActivated()
{
	Super::NativeOnActivated();

	// 检查蓝图里是否绑定了必需的控件
	if (!HBox_SwitchUser)
	{
		UE_LOG(LogTenkaichi, Error, TEXT("Unable to find HBox_SwitchUser on Widget %s"), *GetNameSafe(this));
		return;
	}

	if (!Button_ChangeUser)
	{
		UE_LOG(LogTenkaichi, Error, TEXT("Unable to find Button_ChangeUser on Widget %s"), *GetNameSafe(this));
		return;
	}

	// 先都藏起来
	HBox_SwitchUser->SetVisibility(ESlateVisibility::Collapsed);
	Button_ChangeUser->SetVisibility(ESlateVisibility::Hidden);

	if (ShouldDisplayChangeUserButton())
	{
		// 这是"未配对"输入设备对应的平台用户。不是所有平台都支持这个，
		// 所以只在未配对用户有效时才设为可见。
		const FPlatformUserId UnpairedUserId = IPlatformInputDeviceMapper::Get().GetUserForUnpairedInputDevices();
		if (UnpairedUserId.IsValid())
		{
			HBox_SwitchUser->SetVisibility(ESlateVisibility::SelfHitTestInvisible);
			Button_ChangeUser->SetVisibility(ESlateVisibility::SelfHitTestInvisible);
		}		
	}

	Button_ChangeUser->OnClicked().AddUObject(this, &ThisClass::HandleChangeUserClicked);
}

// 是否应该显示"切换用户"按钮。
bool UTenkaichiControllerDisconnectedScreen::ShouldDisplayChangeUserButton() const
{
	bool bRequiresChangeUserButton = ICommonUIModule::GetSettings().GetPlatformTraits().HasAll(PlatformSupportsUserChangeTags);

	// 也检查我们在编辑器里可能模拟的 tag
#if WITH_EDITOR
	const FGameplayTagContainer& PlatformEmulationTags = UCommonUIVisibilitySubsystem::Get(GetOwningLocalPlayer())->GetVisibilityTags();
	bRequiresChangeUserButton |= PlatformEmulationTags.HasAll(PlatformSupportsUserChangeTags);
#endif	// WITH_EDITOR

	return bRequiresChangeUserButton;
}

// 点击"切换用户"后的处理。
void UTenkaichiControllerDisconnectedScreen::HandleChangeUserClicked()
{
	ensure(ShouldDisplayChangeUserButton());

	UE_LOG(LogTenkaichi, Log, TEXT("[%hs] Change user requested!"), __func__);

	const FPlatformUserId OwningPlayerId = GetOwningLocalPlayer()->GetPlatformUserId();
	const FInputDeviceId DeviceId = IPlatformInputDeviceMapper::Get().GetPrimaryInputDeviceForUser(OwningPlayerId);

		DeviceId,
		EPlatformUserSelectorFlags::Default,
		[this](const FPlatformUserSelectionCompleteParams& Params)
		{
			HandleChangeUserCompleted(Params);
		});
}

## 三、关键点讲解

### 1. `meta = (BindWidget)`——蓝图控件自动绑定

```cpp
UPROPERTY(meta = (BindWidget))
TObjectPtr<UHorizontalBox> HBox_SwitchUser;

UPROPERTY(meta = (BindWidget))
TObjectPtr<UCommonButtonBase> Button_ChangeUser;
```

`BindWidget`：告诉 UMG 编译系统"**在蓝图设计器里找一个同名控件，自动赋给这个 C++ 指针**"。

所以蓝图里的控件必须叫 exactly `HBox_SwitchUser` / `Button_ChangeUser`（同名）——否则绑定失败（编译警告 + 指针为空）。

> 这是 C++ 和 UMG 蓝图协作的标准方式：C++ 声明指针，蓝图放同名控件，自动连上。

### 2. `NativeOnActivated`——控件激活时

```cpp
virtual void NativeOnActivated() override;
```

`UCommonActivatableWidget` 的生命周期：**激活时**调用（对比 `NativeOnInitialized` 是初始化时、`NativeDestruct` 是销毁时）。

> 这里用 `NativeOnActivated` 而不是 `NativeOnInitialized`，因为每次**激活**都要重新检查按钮可见性（用户可能切走又切回来）。

### 3. 空指针检查 + 提前返回

```cpp
if (!HBox_SwitchUser)
{
	UE_LOG(LogTenkaichi, Error, TEXT("Unable to find HBox_SwitchUser on Widget %s"), *GetNameSafe(this));
	return;
}
```

蓝图忘了放同名控件 → 指针为空 → 打错误日志 + 提前返回（避免后面空指针崩溃）。

### 4. `Collapsed` vs `Hidden`

```cpp
HBox_SwitchUser->SetVisibility(ESlateVisibility::Collapsed);
Button_ChangeUser->SetVisibility(ESlateVisibility::Hidden);
```

| 值 | 含义 |
|----|------|
| `Collapsed` | 隐藏 + **不占布局空间** |
| `Hidden` | 隐藏 + **仍占布局空间** |

HBox 用 `Collapsed`（整个横向区都不占位），Button 用 `Hidden`（保留按钮位置，避免布局跳动）。

> 细微差异：因为 HBox 被 Collapsed 了，里面的 Button 本来也不显示，用 `Hidden` 是"预留正确状态"（如果以后 HBox 显示了，Button 还是隐藏的）。

### 5. `GetUserForUnpairedInputDevices()`——未配对用户

```cpp
const FPlatformUserId UnpairedUserId = IPlatformInputDeviceMapper::Get().GetUserForUnpairedInputDevices();
if (UnpairedUserId.IsValid())
```

"未配对用户"= 平台用来表示"当前没有归属任何玩家的设备"的特殊用户 ID。不是所有平台都有这个概念，所以 `IsValid()` 判断。

### 6. `Button_ChangeUser->OnClicked().AddUObject(...)`——绑定按钮点击

```cpp
Button_ChangeUser->OnClicked().AddUObject(this, &ThisClass::HandleChangeUserClicked);
```

`UCommonButtonBase::OnClicked()` 返回一个多播委托，`AddUObject` 绑成员函数。

### 7. `ShowPlatformUserSelector`——平台原生"选用户"界面

```cpp
FGenericPlatformApplicationMisc::ShowPlatformUserSelector(
	DeviceId,
	EPlatformUserSelectorFlags::Default,
	[this](const FPlatformUserSelectionCompleteParams& Params)
	{
		HandleChangeUserCompleted(Params);
	});
```

`FGenericPlatformApplicationMisc::ShowPlatformUserSelector`：调**平台原生**的"选择用户"对话框（主机上是系统 UI）。

- 第一个参数：用哪个输入设备（手柄）。
- 第三个参数：完成回调（lambda 转发到 `HandleChangeUserCompleted`）。

## 一、这个类解决什么问题（先讲为什么）

P16.2.2 的 `UTenkaichiUIMessaging::ShowConfirmation` 要弹一个确认框——那个确认框的**具体实现就是这个类**。

它继承 `UCommonGameDialog`（CommonGame 的"游戏对话框"基类），实现 `SetupDialog`：把描述（标题/正文/按钮动作）填进 UI 控件，并根据按钮动作类型（确认/拒绝/取消）**动态创建按钮**。

> **类比**：`UCommonGameDialog` 是"对话框模板"，`ULyraConfirmationScreen` 是"具体装配工"——它按描述把标题、正文、按钮都摆好。

### `TenkaichiConfirmationScreen.cpp`（100 行）

```cpp
// 版权声明（可保留或省略，不影响编译）
#include "TenkaichiConfirmationScreen.h"

#if WITH_EDITOR
#include "CommonInputSettings.h"
#include "Editor/WidgetCompilerLog.h"
#endif

#include "CommonBorder.h"
#include "CommonRichTextBlock.h"
#include "CommonTextBlock.h"
#include "Components/DynamicEntryBox.h"
#include "ICommonInputModule.h"
#include "TenkaichiButtonBase.h"

#include UE_INLINE_GENERATED_CPP_BY_NAME(TenkaichiConfirmationScreen)

// 装配对话框（填标题/正文，按动作创建按钮）。
void UTenkaichiConfirmationScreen::SetupDialog(UCommonGameDialogDescriptor* Descriptor, FCommonMessagingResultDelegate ResultCallback)
{
	Super::SetupDialog(Descriptor, ResultCallback);

	// 填标题和正文
	Text_Title->SetText(Descriptor->Header);
	RichText_Description->SetText(Descriptor->Body);

	// 先清空按钮容器（并清掉旧按钮的点击委托）
	EntryBox_Buttons->Reset<UTenkaichiButtonBase>([](UTenkaichiButtonBase& Button)
	{
		Button.OnClicked().Clear();
	});

	// 按每个按钮动作创建按钮
	for (const FConfirmationDialogAction& Action : Descriptor->ButtonActions)
	{
		FDataTableRowHandle ActionRow;

		// 按动作结果决定用哪个输入动作（确认=点击键 / 拒绝=返回键 / 取消=取消键）
		switch(Action.Result)
		{
			case ECommonMessagingResult::Confirmed:
				ActionRow = ICommonInputModule::GetSettings().GetDefaultClickAction();
				break;
			case ECommonMessagingResult::Declined:
				ActionRow = ICommonInputModule::GetSettings().GetDefaultBackAction();
				break;
			case ECommonMessagingResult::Cancelled:
				ActionRow = CancelAction;
				break;
			default:
				ensure(false);
				continue;
		}

		ULyraButtonBase* Button = EntryBox_Buttons->CreateEntry<UTenkaichiButtonBase>();
		Button->SetTriggeringInputAction(ActionRow);   // 设置触发这个按钮的输入动作
		Button->OnClicked().AddUObject(this, &ThisClass::CloseConfirmationWindow, Action.Result);
		Button->SetButtonText(Action.OptionalDisplayText);   // 设置按钮文字
	}

	OnResultCallback = ResultCallback;
}

// 关闭对话框。
void UTenkaichiConfirmationScreen::KillDialog()
{
	Super::KillDialog();
}

// 控件初始化（绑"点击空白关闭"事件）。
void UTenkaichiConfirmationScreen::NativeOnInitialized()
{
	Super::NativeOnInitialized();

	Border_TapToCloseZone->OnMouseButtonDownEvent.BindDynamic(this, &UTenkaichiConfirmationScreen::HandleTapToCloseZoneMouseButtonDown);
}

// 关闭确认窗口（触发回调）。
void UTenkaichiConfirmationScreen::CloseConfirmationWindow(ECommonMessagingResult Result)
{
	DeactivateWidget();
	OnResultCallback.ExecuteIfBound(Result);
}

// 处理"点击空白区域关闭"的鼠标事件。
FEventReply UTenkaichiConfirmationScreen::HandleTapToCloseZoneMouseButtonDown(FGeometry MyGeometry, const FPointerEvent& MouseEvent)
{
	FEventReply Reply;
	Reply.NativeReply = FReply::Unhandled();

	// 触摸事件 或 左键点击 → 当作"拒绝"关闭
	if (MouseEvent.IsTouchEvent() || MouseEvent.GetEffectingButton() == EKeys::LeftMouseButton)
	{
		CloseConfirmationWindow(ECommonMessagingResult::Declined);
		Reply.NativeReply = FReply::Handled();
	}

	return Reply;
}

#if WITH_EDITOR
// 编辑器默认值校验（CancelAction 必须配）。
void UTenkaichiConfirmationScreen::ValidateCompiledDefaults(IWidgetCompilerLog& CompileLog) const
{
	if (CancelAction.IsNull())
	{
		CompileLog.Error(FText::Format(FText::FromString(TEXT("{0} has unset property: CancelAction.")), FText::FromString(GetName())));
	}
}
#endif
```

## 三、关键点讲解

### 1. `SetupDialog`——装配三件事

```cpp
Text_Title->SetText(Descriptor->Header);          // ① 标题
RichText_Description->SetText(Descriptor->Body);  // ② 正文
EntryBox_Buttons->Reset<UTenkaichiButtonBase>(...);// ③ 清空按钮
// ... 然后按 ButtonActions 创建按钮
```

### 2. `EntryBox_Buttons->Reset<T>(lambda)`——清空 + 清理委托

```cpp
EntryBox_Buttons->Reset<UTenkaichiButtonBase>([](UTenkaichiButtonBase& Button)
{
	Button.OnClicked().Clear();
});
```

`UDynamicEntryBox::Reset<T>(lambda)`：销毁所有已有 `T` 类型的条目，销毁前对每个调 lambda（这里清掉点击委托，避免残留绑定）。

> **为什么必须清？** 对话框可能被复用（同一个实例反复 `SetupDialog`），不清旧委托会累积绑定 → 点一次触发多次。

### 3. `switch` 按动作结果选输入动作

```cpp
switch(Action.Result)
{
	case ECommonMessagingResult::Confirmed:
		ActionRow = ICommonInputModule::GetSettings().GetDefaultClickAction();   // 点击键（A/左键）
		break;
	case ECommonMessagingResult::Declined:
		ActionRow = ICommonInputModule::GetSettings().GetDefaultBackAction();    // 返回键（B/Esc）
		break;
	case ECommonMessagingResult::Cancelled:
		ActionRow = CancelAction;                                                // 自定义取消键
		break;
	default:
		ensure(false);    // 未知结果 → 断言
		continue;
}
```

三档：
- `Confirmed`（确认）→ 引擎配的"默认点击动作"（手柄 A / 鼠标左键）。
- `Declined`（拒绝）→ "默认返回动作"（手柄 B / Esc）。
- `Cancelled`（取消）→ 本类配置的 `CancelAction`。

> `continue` 跳过这个动作（不创建按钮）——防御性处理未知枚举值。

### 4. `CreateEntry<UTenkaichiButtonBase>()` + 三个设置

```cpp
ULyraButtonBase* Button = EntryBox_Buttons->CreateEntry<UTenkaichiButtonBase>();
Button->SetTriggeringInputAction(ActionRow);                          // ① 触发按钮的输入动作
Button->OnClicked().AddUObject(this, &ThisClass::CloseConfirmationWindow, Action.Result);  // ② 点击 → 关闭
Button->SetButtonText(Action.OptionalDisplayText);                    // ③ 按钮文字
```

注意 `AddUObject(this, &CloseConfirmationWindow, Action.Result)`——**带一个附加参数**（`Action.Result`），回调时自动传进去。

### 5. `OnResultCallback` + `CloseConfirmationWindow`

```cpp
OnResultCallback = ResultCallback;    // SetupDialog 里存下回调

void CloseConfirmationWindow(ECommonMessagingResult Result)
{
	DeactivateWidget();                       // ① 控件停用（会有淡出动画）
	OnResultCallback.ExecuteIfBound(Result);  // ② 通知调用方结果
}
```

`ExecuteIfBound`：回调已绑才执行（安全）。

### 6. `Border_TapToCloseZone->OnMouseButtonDownEvent.BindDynamic(...)`

```cpp
Border_TapToCloseZone->OnMouseButtonDownEvent.BindDynamic(this, &UTenkaichiConfirmationScreen::HandleTapToCloseZoneMouseButtonDown);
```

`BindDynamic`：绑**UFUNCTION**（因为 `OnMouseButtonDownEvent` 是动态委托，只能绑 `UFUNCTION`）。

所以 `HandleTapToCloseZoneMouseButtonDown` 必须是 `UFUNCTION()`（`.h` 里确实标了）。

### 7. `FEventReply` / `FReply::Handled()` vs `Unhandled()`

```cpp
FEventReply Reply;
Reply.NativeReply = FReply::Unhandled();     // 默认"不处理"（事件继续传递）

if (触摸 或 左键)
{
	CloseConfirmationWindow(ECommonMessagingResult::Declined);
	Reply.NativeReply = FReply::Handled();    // "已处理"（事件到此为止）
}
```

- `Handled()`：事件被吃掉，不再向其他控件传递。
- `Unhandled()`：不处理，继续传递。

> 只在真正处理了（点空白关闭）时才 `Handled`。

### 8. `ValidateCompiledDefaults`——必配项检查

```cpp
if (CancelAction.IsNull())
{
	CompileLog.Error(...);   // 编辑器里编译时直接报错
}
```

`CompileLog.Error`：编辑器编译时**报错**（不是警告）——强制要求配 `CancelAction`。

### 9. 4 个 `BindWidget`

```cpp
UPROPERTY(Meta = (BindWidget))
TObjectPtr<UCommonTextBlock> Text_Title;
// + RichText_Description / EntryBox_Buttons / Border_TapToCloseZone
```

蓝图侧必须有这 4 个同名控件（P16.3.1 讲过 `BindWidget`）。

### 10. `RowType` meta

```cpp
UPROPERTY(EditDefaultsOnly, meta = (RowType = "/Script/CommonUI.CommonInputActionDataBase"))
FDataTableRowHandle CancelAction;
```

`RowType`：限制 `FDataTableRowHandle` 选择的行类型（只能选 `CommonInputActionDataBase` 类型的行）。

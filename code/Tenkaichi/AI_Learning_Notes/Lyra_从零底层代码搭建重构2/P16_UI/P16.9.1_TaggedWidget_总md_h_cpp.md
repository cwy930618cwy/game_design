## 一、这个类解决什么问题（先讲为什么）

HUD 上有些控件应该**按玩家状态自动隐藏**——比如"新手提示"只在没完成教程时显示，"低血量警告"只在血量低时显示。

`ULyraTaggedWidget` 的设计意图：配一组 `HiddenByTags`（GameplayTag），**玩家身上有这些 tag 时自动隐藏**。

> ⚠️ **重要**：这个类在 Lyra 里是**半成品**——tag 检测逻辑**没实现**（`bHasHiddenTags = false` 硬编码 + 一堆 `@TODO`）。但**可见性管理框架是完整的**（`bWantsToBeVisible` / `ShownVisibility` / `HiddenVisibility` 三态逻辑）。
>
> 按铁律 23：**代码一比一照抄，包括 TODO 和硬编码的 false**。

## 三、关键点讲解

### 1. 三态可见性模型（核心设计）

```cpp
bool bWantsToBeVisible = true;              // ① 调用者想不想显示
ESlateVisibility ShownVisibility;           // ② 显示时用什么可见性
ESlateVisibility HiddenVisibility;          // ③ 隐藏时用什么可见性
```

**最终可见性 = `(bWantsToBeVisible && !bHasHiddenTags) ? ShownVisibility : HiddenVisibility`**

两个维度：
| 维度 | 来源 |
|------|------|
| `bWantsToBeVisible` | **代码/蓝图调用** `SetVisibility` |
| `bHasHiddenTags` | **玩家身上的 tag**（当前硬编码 false） |

> **为什么分三态？** 因为"我想显示"和"tag 要求隐藏"是**两个独立维度**。如果只有一个 `SetVisibility`，tag 隐藏后代码再调 `SetVisibility(Visible)` 就会覆盖 tag 的隐藏——不对。
>
> 三态模型让两者**互不干扰**：代码说"我想显示"（`bWantsToBeVisible = true`），tag 说"必须隐藏"（`bHasHiddenTags = true`）→ 最终隐藏。tag 解除后自动恢复显示。

### 2. `SetVisibility` 覆写——记住意图

```cpp
bWantsToBeVisible = ConvertSerializedVisibilityToRuntime(InVisibility).IsVisible();
if (bWantsToBeVisible)
{
	ShownVisibility = InVisibility;      // 想显示 → 记住"显示时用什么"
}
else
{
	HiddenVisibility = InVisibility;     // 想隐藏 → 记住"隐藏时用什么"
}
```

**关键**：调用 `SetVisibility(Visible)` 时，不是直接设可见性，而是**记住"显示时该用什么"**（`ShownVisibility`），然后按 tag 状态决定实际值。

`ConvertSerializedVisibilityToRuntime(...)`：把"序列化可见性"转成"运行时可见性"（UMG 的 `ESlateVisibility` 有序列化/运行时两套值）。

`.IsVisible()`：判断这个可见性是否"可见"（`Visible`/`HitTestInvisible`/`SelfHitTestInvisible` 都算可见）。

### 3. `#if WITH_EDITORONLY_DATA` + `IsDesignTime()`——设计器直通

```cpp
#if WITH_EDITORONLY_DATA
	if (IsDesignTime())
	{
		Super::SetVisibility(InVisibility);
		return;
	}
#endif
```

**设计器里**（UMG 编辑器）直接设可见性（不做 tag 逻辑）——因为设计器里没有"玩家"，tag 检测无意义。

> 注意用 `WITH_EDITORONLY_DATA`（比 `WITH_EDITOR` 更严格，只在需要编辑器数据时编译）。

### 4. `NativeConstruct` 里 `SetVisibility(GetVisibility())`——自触发初始化

```cpp

{

	if (!IsDesignTime())
	{

```

**效果**：把"蓝图里配的初始可见性"转成"三态模型里的初始状态"。

## 一、这个类解决什么问题（先讲为什么）

P16.6.3 的 `SCircumferenceMarkerWidget` 是 Slate 控件——**纯 C++，编辑器里用不了**（策划没法在 UMG 设计器里拖它、配参数）。

`UCircumferenceMarkerWidget` 就是它的**UMG 包装**：
- 把参数暴露成 `UPROPERTY(EditAnywhere)`（编辑器可配）。
- `RebuildWidget()` 里 `SNew` 出 Slate 控件并返回。
- 属性变了（`SynchronizeProperties`）转发给 Slate 控件。

> **类比**：`SCircumferenceMarkerWidget` 是"发动机"，`UCircumferenceMarkerWidget` 是"带仪表盘和方向盘的驾驶舱"——策划在 UMG 编辑器里通过驾驶舱操作发动机。

### `CircumferenceMarkerWidget.cpp`（49 行）

```cpp
// 版权声明（可保留或省略，不影响编译）
#include "CircumferenceMarkerWidget.h"


#include UE_INLINE_GENERATED_CPP_BY_NAME(CircumferenceMarkerWidget)

class SWidget;

// 构造函数：设默认可见性 + 易变标记。
UCircumferenceMarkerWidget::UCircumferenceMarkerWidget(const FObjectInitializer& ObjectInitializer)
	: Super(ObjectInitializer)
{
	SetVisibility(ESlateVisibility::HitTestInvisible);
	bIsVolatile = true;
}

// 释放 Slate 资源（控件销毁时重置指针）。
void UCircumferenceMarkerWidget::ReleaseSlateResources(bool bReleaseChildren)
{
	Super::ReleaseSlateResources(bReleaseChildren);

	MyMarkerWidget.Reset();
}

// 重建 Slate 控件（创建 S 层实例）。
TSharedRef<SWidget> UCircumferenceMarkerWidget::RebuildWidget()
{
	MyMarkerWidget = SNew(SCircumferenceMarkerWidget)
		.MarkerBrush(&MarkerImage)
		.Radius(this->Radius)
		.MarkerList(this->MarkerList);

	return MyMarkerWidget.ToSharedRef();
}

// 属性同步（把参数转发给 Slate 控件）。
void UCircumferenceMarkerWidget::SynchronizeProperties()
{
	Super::SynchronizeProperties();

	MyMarkerWidget->SetRadius(Radius);
	MyMarkerWidget->SetMarkerList(MarkerList);
}

// 设置圆的半径。
void UCircumferenceMarkerWidget::SetRadius(float InRadius)
{
	Radius = InRadius;
	if (MyMarkerWidget.IsValid())
	{
		MyMarkerWidget->SetRadius(InRadius);
	}
}
```

## 三、关键点讲解

### 1. `RebuildWidget()`——UMG 创建 Slate 控件的唯一入口

```cpp
TSharedRef<SWidget> UCircumferenceMarkerWidget::RebuildWidget()
{
	MyMarkerWidget = SNew(SCircumferenceMarkerWidget)
		.MarkerBrush(&MarkerImage)
		.Radius(this->Radius)
		.MarkerList(this->MarkerList);

	return MyMarkerWidget.ToSharedRef();
}
```

**这是 UMG ↔ Slate 的桥**：`UWidget` 子类**必须**覆写 `RebuildWidget()` 返回实际的 Slate 控件。

`SNew(类)` 是 Slate 的对象创建宏：
- 它 `new` 出对象 → 调 `Construct(FArguments)`。
- 链式调用 `.MarkerBrush(...)` 对应 `SLATE_ARGUMENT(const FSlateBrush*, MarkerBrush)`。
- 链式调用 `.Radius(...)` 对应 `SLATE_ATTRIBUTE(float, Radius)`。

> 对比 UMG 的 `NewObject<T>()`（UObject）——`SNew` 是 Slate 版的"创建 + 初始化"。

### 2. `.MarkerBrush(&MarkerImage)`——传 UMG 属性的地址

```cpp
.MarkerBrush(&MarkerImage)     // MarkerImage 是 UPROPERTY FSlateBrush
```

`SLATE_ARGUMENT(const FSlateBrush*, MarkerBrush)` 收的是**指针**。这里把 UMG 的 `MarkerImage` 成员**地址**传进去——所以 Slate 控件读的就是 UMG 里那份数据（同一块内存，改了立刻可见）。

> 这是"零拷贝共享"技巧：Slate 不复制画刷，直接引用 UMG 的。

### 3. `.Radius(this->Radius)`——值传递（不是引用）

```cpp
.Radius(this->Radius)      // SLATE_ATTRIBUTE(float, Radius) 收 TAttribute<float>
```

`SLATE_ATTRIBUTE` 接收 `TAttribute<T>`——传 float 会**隐式转成"固定值属性"**。

注意这里写 `this->Radius`（加了 `this->`）——因为参数名和成员名会冲突视觉上，Lyra 显式加 `this->`。

> 对比 `MarkerBrush` 传指针（共享），`Radius` 传值（拷贝）。因为半径是简单 float，拷贝开销可忽略；而且 Slate 的 `TAttribute` 支持"绑委托"更灵活。

### 4. 构造函数：`SetVisibility` + `bIsVolatile`

```cpp
SetVisibility(ESlateVisibility::HitTestInvisible);
bIsVolatile = true;
```

- `HitTestInvisible`：可见但**不吃鼠标点击**（准星不该拦截点击）。
- `bIsVolatile = true`：UMG 层的"易变"标记（对应 Slate 的 `ComputeVolatility()`）——每帧同步/重绘。

> 注意 UMG 层用 `bIsVolatile` 成员（bool），Slate 层用 `ComputeVolatility()` 虚函数覆写。两套机制。

### 5. `SynchronizeProperties()`——属性同步

```cpp
void UCircumferenceMarkerWidget::SynchronizeProperties()
{
	Super::SynchronizeProperties();

	MyMarkerWidget->SetRadius(Radius);
	MyMarkerWidget->SetMarkerList(MarkerList);
}
```

编辑器改属性 / 蓝图加载时调用，把 UMG 属性**推给** Slate 控件（用 Slate 的 Setter）。

> ⚠️ 注意 Lyra 这里**没有检查 `MyMarkerWidget` 是否有效**（直接 `->`）——如果 `SynchronizeProperties` 在 `RebuildWidget` 之前被调用会崩。Lyra 靠"UMG 的调用顺序保证"（先 `RebuildWidget` 再 `SynchronizeProperties`）。按铁律 23 照抄。

### 6. `ReleaseSlateResources()`——释放 Slate 资源

```cpp
void UCircumferenceMarkerWidget::ReleaseSlateResources(bool bReleaseChildren)
{
	Super::ReleaseSlateResources(bReleaseChildren);

	MyMarkerWidget.Reset();    // 释放共享指针
}
```

UMG 控件销毁/重建时调用，必须**重置 `TSharedPtr`**，否则 Slate 控件泄漏。

> `TSharedPtr::Reset()`：把智能指针置空（引用计数 -1，归零则销毁对象）。

### 7. `SetRadius`——同时改 UMG 属性和 Slate 控件

```cpp
void UCircumferenceMarkerWidget::SetRadius(float InRadius)
{
	Radius = InRadius;                          // ① 改 UMG 属性
	if (MyMarkerWidget.IsValid())               // ② 检查 Slate 控件存在
	{
		MyMarkerWidget->SetRadius(InRadius);    // ③ 转发给 Slate
	}
}
```

**双重检查**：因为 `SetRadius` 可能在 `RebuildWidget` 之前被调用（Slate 控件还没创建），所以 `IsValid()` 保护。

> 对比 `SynchronizeProperties` 没检查——因为那个时机保证 Slate 控件已存在。这里 `SetRadius` 是蓝图可调，时机不确定。

### 8. `SetMarkerList` 有非 const 引用参数

```cpp
void SetMarkerList(TArray<FCircumferenceMarkerEntry>& NewMarkerList);   // Slate 层
```

注意 Slate 的 `SetMarkerList` 收的是**非 const 引用**（`TArray<...>&`），所以传 `MarkerList`（UMG 成员）可以，但传临时值不行。

> Lyra 原文如此（可能是想避免拷贝但忘了加 const）。按铁律 23 照抄。

## 六、🎯 UMG ↔ Slate 包装模式总结

| 职责 | UMG 层（UWidget） | Slate 层（SWidget） |
|------|------------------|-------------------|
| 属性声明 | `UPROPERTY(EditAnywhere)` ✅ | `SLATE_ARGUMENT/ATTRIBUTE` |
| 编辑器可配 | ✅ | ❌ |
| 蓝图可用 | ✅ | ❌ |
| 真正绘制 | ❌ | `OnPaint` ✅ |
| 创建方式 | `CreateWidget`/编辑器拖 | `SNew` |
| 连接点 | `RebuildWidget()` 返回 Slate | `Construct()` 收参数 |
| 同步 | `SynchronizeProperties()` 推送 | `SetXxx()` 接收 |
| 释放 | `ReleaseSlateResources()` | `TSharedPtr::Reset()` |

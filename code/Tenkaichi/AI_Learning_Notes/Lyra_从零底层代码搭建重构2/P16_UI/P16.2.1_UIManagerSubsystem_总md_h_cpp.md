## 一、这个类解决什么问题（先讲为什么）

CommonGame 插件的 `UGameUIManagerSubsystem` 管理"每个本地玩家的 UI 布局根（`UPrimaryGameLayout`）"——它是所有 UI 层的容器。

Lyra 继承它，加了一个**每帧同步**：把引擎的 `AHUD::bShowHUD`（`~` 键开关 HUD）映射到 UI 根布局的**可见性**。

**为什么要做这个？**
- 引擎的 `~` 键只开关 `AHUD` 的调试绘制（不碰 CommonUI 的控件）。
- Lyra 希望"按 `~` 应该把整个游戏 UI 都藏起来"（方便看纯净画面/截图）。
- 所以每帧检查：`bShowHUD == false` → 把 RootLayout 设为 `Collapsed`；`true` → `SelfHitTestInvisible`（可见但不拦截输入）。

> **类比**：UIManager 是"UI 总闸"——引擎的 `~` 键是"关灯开关"，Lyra 让它同时控制"UI 总闸"。

### `TenkaichiUIManagerSubsystem.cpp`（68 行）

```cpp
// 版权声明（可保留或省略，不影响编译）
#include "TenkaichiUIManagerSubsystem.h"

#include "CommonLocalPlayer.h"
#include "Engine/GameInstance.h"
#include "GameFramework/HUD.h"
#include "GameUIPolicy.h"
#include "PrimaryGameLayout.h"

#include UE_INLINE_GENERATED_CPP_BY_NAME(TenkaichiUIManagerSubsystem)

class FSubsystemCollectionBase;

// 构造函数：空实现。
UTenkaichiUIManagerSubsystem::UTenkaichiUIManagerSubsystem()
{
}

// 初始化：注册每帧 ticker。
void UTenkaichiUIManagerSubsystem::Initialize(FSubsystemCollectionBase& Collection)
{
	Super::Initialize(Collection);

	TickHandle = FTSTicker::GetCoreTicker().AddTicker(FTickerDelegate::CreateUObject(this, &UTenkaichiUIManagerSubsystem::Tick), 0.0f);
}

// 反初始化：移除 ticker。
void UTenkaichiUIManagerSubsystem::Deinitialize()
{
	Super::Deinitialize();

	FTSTicker::GetCoreTicker().RemoveTicker(TickHandle);
}

// 每帧调用：同步 UI 可见性（返回 true = 持续 tick）。
bool UTenkaichiUIManagerSubsystem::Tick(float DeltaTime)
{
	SyncRootLayoutVisibilityToShowHUD();
	
	return true;
}

// 把 UI 根布局的可见性同步到 HUD 的 bShowHUD。
void UTenkaichiUIManagerSubsystem::SyncRootLayoutVisibilityToShowHUD()
{
	if (const UGameUIPolicy* Policy = GetCurrentUIPolicy())
	{
		for (const ULocalPlayer* LocalPlayer : GetGameInstance()->GetLocalPlayers())
		{
			bool bShouldShowUI = true;
			
			if (const APlayerController* PC = LocalPlayer->GetPlayerController(GetWorld()))
			{
				const AHUD* HUD = PC->GetHUD();

				// HUD 被关掉了（按 ~ 键），UI 也该藏起来
				if (HUD && !HUD->bShowHUD)
				{
					bShouldShowUI = false;
				}
			}

			if (UPrimaryGameLayout* RootLayout = Policy->GetRootLayout(CastChecked<UCommonLocalPlayer>(LocalPlayer)))
			{
				const ESlateVisibility DesiredVisibility = bShouldShowUI ? ESlateVisibility::SelfHitTestInvisible : ESlateVisibility::Collapsed;
				if (DesiredVisibility != RootLayout->GetVisibility())
				{
					RootLayout->SetVisibility(DesiredVisibility);	
				}
			}
		}
	}
}
```

## 五、关键点讲解

### 1. `Initialize` 注册每帧 ticker

```cpp
TickHandle = FTSTicker::GetCoreTicker().AddTicker(FTickerDelegate::CreateUObject(this, &UTenkaichiUIManagerSubsystem::Tick), 0.0f);
```

`AddTicker(委托, 延迟)`：第三个参数 `0.0f` = 每帧都跑（不延迟）。

对比 P16.1.3 的 `AddTicker` **没传延迟参数**（默认 0）+ `return false`（只跑一次）——这里 `Tick` 返回 `true`（持续跑）。

> `CreateUObject`（绑 UObject 成员）vs P16.1.3 的 `CreateWeakLambda`——因为子系统生命周期和引擎绑定，不需要弱引用防悬空。

### 2. `Deinitialize` 移除 ticker

```cpp
FTSTicker::GetCoreTicker().RemoveTicker(TickHandle);
```

**必须移除**（子系统反初始化后还在 tick 会崩）。

### 3. `GetCurrentUIPolicy()`——拿当前 UI 策略

```cpp
if (const UGameUIPolicy* Policy = GetCurrentUIPolicy())
```

`UGameUIPolicy` 是 CommonGame 的"UI 策略"——决定"用哪个 RootLayout 类、怎么创建"。由配置指定。

### 4. `Policy->GetRootLayout(UCommonLocalPlayer*)`——取玩家根布局

```cpp
if (UPrimaryGameLayout* RootLayout = Policy->GetRootLayout(CastChecked<UCommonLocalPlayer>(LocalPlayer)))
```

`UPrimaryGameLayout` 是 CommonGame 的"根布局"控件——它包含所有 UI 层（Game/GameMenu/Menu/Modal）。

`CastChecked<UCommonLocalPlayer>`：CommonGame 保证本地玩家都是这个类型，转不了就是严重 bug。

### 5. 两种可见性

```cpp
const ESlateVisibility DesiredVisibility = bShouldShowUI ? ESlateVisibility::SelfHitTestInvisible : ESlateVisibility::Collapsed;
```

| 值 | 含义 |
|----|------|
| `SelfHitTestInvisible` | **可见**，但自身不拦截鼠标点击（子控件仍可交互） |
| `Collapsed` | **完全隐藏** + 不占布局空间 |

**为什么用 `SelfHitTestInvisible` 而不是 `Visible`？** 因为 RootLayout 只是容器，它自己不该吃掉点击（点击应该传给子控件）。这是 Slate 的标准做法。

### 6. `if (DesiredVisibility != RootLayout->GetVisibility())` 避免无谓调用

```cpp
if (DesiredVisibility != RootLayout->GetVisibility())
{
	RootLayout->SetVisibility(DesiredVisibility);	
}
```

每帧都调 `SetVisibility` 会触发 Slate 重排（开销）。先比较再设置，只有真的变了才设。

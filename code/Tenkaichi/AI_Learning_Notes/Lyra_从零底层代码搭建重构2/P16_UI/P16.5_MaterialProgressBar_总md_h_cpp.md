## 一、这个类解决什么问题（先讲为什么）

普通进度条（`UProgressBar`）只能显示纯色填充。想要**更好看的进度条**（分段、光晕、描边、渐变填充），就得用**材质**做——用一张材质里的参数控制"填充多少、什么颜色、几段、边缘多软"。

`UMaterialProgressBar` 就是这个"材质进度条"：
- 内部是 `UImage`，但贴的是**进度条材质**（`StrokeMaterial` / `NoStrokeMaterial`）。
- 通过**动态材质实例（MID）**改参数：`Progress`/`StartProgress`/`ColorA`/`ColorB`/`Segments`/`GlowEdge` 等。
- 提供动画支持：`AnimateProgressFromStart` / `AnimateProgressFromCurrent` + `BoundAnim_FillBar`（控件动画）。

> **类比**：普通进度条是"用尺子画的刻度线"；材质进度条是"用魔法颜料画的"——能分段、发光、渐变，全靠材质参数调。

---

## 二、关键设计（先看整体）

### 三层结构

```
Layer 1（公开 API，BlueprintCallable）
  SetProgress / SetStartProgress / SetColorA/B/Background / AnimateProgressFromStart / AnimateProgressFromCurrent
        ↓ 都有"缓存比较"（值没变就不做）
Layer 2（内部实现，_Internal 后缀）
  SetProgress_Internal / SetStartProgress_Internal / SetColorX_Internal
        ↓ 全部通过 MID 设材质参数
Layer 3（MID 缓存）
  GetBarDynamicMaterial() → 懒创建 + 缓存 CachedMID
```

### 为什么分两层？

- **公开层**做"值没变就不调用"的过滤（`if (CachedProgress != Progress)`）——避免每帧重复设材质参数（开销大）。
- **内部层**真正设参数 + 更新缓存。

// 版权声明（可保留或省略，不影响编译）
#include "MaterialProgressBar.h"

#include "Animation/WidgetAnimation.h"
#include "Components/Image.h"
#include "Materials/MaterialInstanceDynamic.h"

#include UE_INLINE_GENERATED_CPP_BY_NAME(MaterialProgressBar)

// 同步属性（材质/参数变化时重建 MID）。
void UMaterialProgressBar::SynchronizeProperties()
{
	Super::SynchronizeProperties();

	if (Image_Bar)
	{
		// 按是否描边选材质
		Image_Bar->SetBrushFromMaterial(bUseStroke ? StrokeMaterial : NoStrokeMaterial);
		// 清空缓存（材质换了，MID 要重建）
		CachedMID = nullptr;
		CachedProgress = -1.0f;
		CachedStartProgress = -1.0f;

#if WITH_EDITORONLY_DATA
		if (IsDesignTime())
		{
			SetProgress_Internal(DesignTime_Progress);
		}
#endif

		// 把编辑器里配置的参数写进材质
		if (UMaterialInstanceDynamic* MID = GetBarDynamicMaterial())
		{
			if (bOverrideDefaultSegmentEdge)
			{
				MID->SetScalarParameterValue(TEXT("SegmentEdge"), SegmentEdge);
			}

			if (bOverrideDefaultSegments)
			{
				MID->SetScalarParameterValue(TEXT("Segments"), (float)Segments);
			}

			if (bOverrideDefaultFillEdgeSoftness)
			{
				MID->SetScalarParameterValue(TEXT("FillEdgeSoftness"), FillEdgeSoftness);
			}

			if (bOverrideDefaultGlowEdge)
			{
				MID->SetScalarParameterValue(TEXT("GlowEdge"), GlowEdge);
			}

			if (bOverrideDefaultGlowSoftness)
			{
				MID->SetScalarParameterValue(TEXT("GlowSoftness"), GlowSoftness);
			}

			if (bOverrideDefaultOutlineScale)
			{
				MID->SetScalarParameterValue(TEXT("OutlineScale"), OutlineScale);
			}
		}

		if (bOverrideDefaultColorA)
		{
			SetColorA_Internal(CachedColorA);
		}

		if (bOverrideDefaultColorB)
		{
			SetColorB_Internal(CachedColorB);
		}

		if (bOverrideDefaultColorBackground)
		{
			SetColorBackground_Internal(CachedColorBackground);
		}
	}
}

#if WITH_EDITOR
// 编辑器：控件重建时（从材质读取当前参数填入面板）。

{
	Super::OnWidgetRebuilt();

	if (IsDesignTime() && Image_Bar)
	{
		if (UMaterialInstanceDynamic* MID = GetBarDynamicMaterial())
		{
			// 没覆盖的项 → 从材质读默认值回填到面板，方便查看

			{
				MID->GetVectorParameterValue(TEXT("ColorA"), CachedColorA);
			}

			if (!bOverrideDefaultColorB)
			{
				MID->GetVectorParameterValue(TEXT("ColorB"), CachedColorB);
			}

			if (!bOverrideDefaultColorBackground)
			{
				MID->GetVectorParameterValue(TEXT("Unfilled Color"), CachedColorBackground);
			}

			if (!bOverrideDefaultSegmentEdge)
			{
				MID->GetScalarParameterValue(TEXT("SegmentEdge"), SegmentEdge);
			}

			if (!bOverrideDefaultSegments)
			{
				float SegmentsFloat;
				MID->GetScalarParameterValue(TEXT("Segments"), SegmentsFloat);

			}

			if (!bOverrideDefaultFillEdgeSoftness)
			{
				MID->GetScalarParameterValue(TEXT("FillEdgeSoftness"), FillEdgeSoftness);
			}

			if (!bOverrideDefaultGlowEdge)
			{
				MID->GetScalarParameterValue(TEXT("GlowEdge"), GlowEdge);
			}

			if (!bOverrideDefaultGlowSoftness)
			{
				MID->GetScalarParameterValue(TEXT("GlowSoftness"), GlowSoftness);
			}

			if (!bOverrideDefaultOutlineScale)
			{
				MID->GetScalarParameterValue(TEXT("OutlineScale"), OutlineScale);

		}

// 从当前填充位置动画到终点。
void UMaterialProgressBar::AnimateProgressFromCurrent(float End, float AnimSpeed)

	if (UMaterialInstanceDynamic* MID = GetBarDynamicMaterial())

		// 读材质当前的三个参数，算出当前实际填充位置

		const float NewStart = FMath::Lerp(CurrentStart, CurrentEnd, CurrentFill);
		AnimateProgressFromStart(NewStart, End, AnimSpeed);
	}
}

## 五、关键点讲解

### 1. `SynchronizeProperties`——UMG 属性同步钩子

```cpp
virtual void SynchronizeProperties() override;
```

`UUserWidget::SynchronizeProperties`：编辑器里改属性 / 蓝图加载时调用。这里做"材质重建 + 把配置参数写进材质"。

**注意清空缓存**：
```cpp
CachedMID = nullptr;         // 材质换了，MID 重建
CachedProgress = -1.0f;
CachedStartProgress = -1.0f;
```

### 2. `GetDynamicMaterial()`——动态材质实例

```cpp
CachedMID = Image_Bar->GetDynamicMaterial();
```

`UImage::GetDynamicMaterial()`：为图片的材质创建（或复用）一个**动态材质实例（MID）**——MID 是运行时可以改参数的材质副本。

**懒创建 + 缓存**：
```cpp
if (!CachedMID)
{
	CachedMID = Image_Bar->GetDynamicMaterial();
}
return CachedMID;
```

> **为什么缓存？** 每次调用 `GetDynamicMaterial` 有开销，且可能创建新实例。缓存一次，后续直接用。

### 3. `mutable TObjectPtr<UMaterialInstanceDynamic> CachedMID`

```cpp
UPROPERTY(Transient)
mutable TObjectPtr<UMaterialInstanceDynamic> CachedMID;
```

`mutable`：因为 `GetBarDynamicMaterial() const` 是 const 方法，但要在里面修改 `CachedMID`（懒创建）。所以 `CachedMID` 必须 `mutable`（P14.1 讲过同类用法）。

### 4. 公开层 + 内部层（缓存过滤）

```cpp
// 公开层：值没变就不做
void UMaterialProgressBar::SetProgress(float Progress)
{
	if (CachedProgress != Progress)
	{
		SetProgress_Internal(Progress);
	}
}

// 内部层：真正设参数 + 更新缓存
void UMaterialProgressBar::SetProgress_Internal(float Progress)
{
	if (UMaterialInstanceDynamic* MID = GetBarDynamicMaterial())
	{
		CachedProgress = Progress;
		MID->SetScalarParameterValue(TEXT("Progress"), CachedProgress);
	}
}
```

**为什么要过滤？** `SetScalarParameterValue` 会触发材质参数更新（渲染开销）。进度条每帧都可能 `SetProgress`，值没变就不该重复设。

### 5. `SetScalarParameterValue` vs `SetVectorParameterValue`

| 方法 | 类型 | 用于 |
|------|------|------|
| `SetScalarParameterValue` | float | `Progress`/`StartProgress`/`Segments`/`GlowEdge` 等 |
| `SetVectorParameterValue` | `FLinearColor` | `ColorA`/`ColorB`/`Unfilled Color` |

### 6. 材质参数名是**字符串字面量**

```cpp
MID->SetScalarParameterValue(TEXT("Progress"), CachedProgress);
MID->SetVectorParameterValue(TEXT("Unfilled Color"), CachedColorBackground);
```

这些名字必须和**材质里定义的参数名完全一致**（包括空格，如 `"Unfilled Color"`）。改错名字 = 参数不生效（无报错！）。

### 7. `AnimateProgressFromStart`——播控件动画

```cpp
SetStartProgress(Start);
SetProgress(End);
PlayAnimation(BoundAnim_FillBar, 0.0f, 1, EUMGSequencePlayMode::Forward, AnimSpeed);
```

`PlayAnimation(动画, 起始时间, 循环次数, 播放模式, 速度)`：
- `0.0f`：从 0 秒开始。
- `1`：播 1 次。
- `Forward`：正放。
- `AnimSpeed`：速度倍率。

动画本身在 UMG 里编辑（改材质参数的关键帧），C++ 只负责播放。

### 8. `AnimateProgressFromCurrent`——从当前填充位置续播

```cpp
const float CurrentStart = MID->K2_GetScalarParameterValue(TEXT("StartProgress"));
const float CurrentEnd = MID->K2_GetScalarParameterValue(TEXT("Progress"));
const float CurrentFill = MID->K2_GetScalarParameterValue(TEXT("FillAmount"));
const float NewStart = FMath::Lerp(CurrentStart, CurrentEnd, CurrentFill);
AnimateProgressFromStart(NewStart, End, AnimSpeed);
```

读材质当前的 `StartProgress`/`Progress`/`FillAmount`（动画播到一半的填充比例），用 `Lerp` 算出"当前实际填充到的位置"，从那里继续动画。

> 这样"动画播到一半又设新目标"时不会跳变。

### 9. `bOverrideDefaultXxx` + `InlineEditConditionToggle` 成对模式

```cpp
UPROPERTY(EditAnywhere, meta = (InlineEditConditionToggle = "CachedColorA"))
bool bOverrideDefaultColorA = false;

UPROPERTY(EditAnywhere, meta = (DisplayName = "Color A", EditCondition = "bOverrideDefaultColorA"))
FLinearColor CachedColorA;
```

9 组这样的开关 + 值。`InlineEditConditionToggle = "CachedColorA"` 把开关**内联**在 `CachedColorA` 那行显示（不单独占一行）。

> P14.6-2 讲过 `InlineEditConditionToggle` 的另一种写法（不带参数）。

### 10. `BindWidget` vs `BindWidgetAnim`

```cpp
UPROPERTY(BlueprintReadOnly, meta = (BindWidget, AllowPrivateAccess))
TObjectPtr<UImage> Image_Bar;

UPROPERTY(BlueprintReadOnly, Transient, meta = (BindWidgetAnim, AllowPrivateAccess))
TObjectPtr<UWidgetAnimation> BoundAnim_FillBar;
```

- `BindWidget`：绑定**控件**（`UImage`）。
- `BindWidgetAnim`：绑定**动画**（`UWidgetAnimation`）——UMG 里做的动画，C++ 通过它引用。

### 11. `OnAnimationFinished_Implementation`——动画结束回调

```cpp
void UMaterialProgressBar::OnAnimationFinished_Implementation(const UWidgetAnimation* Animation)
{
	Super::OnAnimationFinished_Implementation(Animation);

	if (BoundAnim_FillBar == Animation)     // 只关心"填充动画"
	{
		OnFillAnimationFinished.Broadcast();
	}
}
```

`UUserWidget::OnAnimationFinished` 是 `BlueprintNativeEvent`（所以带 `_Implementation`），**任何**动画结束都会调。这里过滤出"填充动画"，然后广播 `OnFillAnimationFinished`。

### 12. `#if WITH_EDITOR` 的 `OnWidgetRebuilt`

编辑器中"控件重建"时，**从材质读回当前参数值**填到面板（方便策划看材质默认值）。注意是 `!bOverrideDefaultXxx` 才读（没覆盖的才回填）。

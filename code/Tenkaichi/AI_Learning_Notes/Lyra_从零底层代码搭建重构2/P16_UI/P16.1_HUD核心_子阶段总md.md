## 一、这 4 个类的关系（先讲为什么）

| 类 | 角色 | 类比 |
|----|------|------|
| `ATenkaichiHUD` | HUD **Actor**（引擎 `AHUD` 子类） | "公告板本体" |
| `UTenkaichiHUDLayout` | HUD **布局管理器**（可激活控件） | "公告板的分区管理器" |
| `UTenkaichiActivatableWidget` | **可激活控件基类** | "所有 UI 零件的模板" |
| `UTenkaichiGameViewportClient` | 游戏**视口客户端**（控件栈） | "显示器和图层管理" |

### 关系图

```
ATenkaichiHUD (HUD Actor, 挂在世界里)
    └─ GameFeatureAction_AddWidgets 通过它加 UI（P15.7）
         └─ UTenkaichiHUDLayout (HUD 布局, 可激活控件)
              ├─ UI.Layer.Game  (游戏层: 血条/弹药)
              ├─ UI.Layer.GameMenu (游戏菜单层)
              └─ UI.Layer.Menu  (菜单层)
                   └─ 具体控件 (继承 UTenkaichiActivatableWidget)
```

`UTenkaichiGameViewportClient` 独立管"控件栈"（哪个控件在最上面、输入给谁）。

## 〇、先搞清 Slate 是什么（本节新概念多）

前面 P16.1~P16.5 都是 **UMG 层**（`UWidget`/`UUserWidget`）——用编辑器拖控件、蓝图连线。

**Slate** 是 UMG 底层的**纯 C++ UI 框架**：
- `SWidget` 是 Slate 控件基类（`S` 前缀）。
- **没有编辑器**，全靠 C++ 写。
- 性能更好（UMG 最终都转成 Slate 渲染）。
- 用来做"UMG 表达不了的复杂自绘控件"（比如这里的圆周标记、命中标记）。

> **关系**：UMG 是"Slate 的编辑器包装"。
> ```
> UMG（UWidget）        →  Slate（SWidget）
> 编辑器可配/蓝图可改       纯 C++/自绘/高性能
> ```

**为什么这个控件要 Slate？** 因为要在圆周上**任意角度**画多个标记，还要算旋转矩阵——UMG 做不到这种"逐帧自绘"，必须 `OnPaint`。

---

## 一、这个类解决什么问题（先讲为什么）

准星周围常有几个"角标"（散布指示器）——分布在圆周上（比如 0°/90°/180°/270°），随散布半径移动。

`SCircumferenceMarkerWidget` 就是画这个的：给一组"角度 + 旋转"（`FCircumferenceMarkerEntry`），在指定半径的圆周上把图标画出来。

> **类比**：这是"圆周画章机"——你给半径和每个章的角度，它在圆周对应位置盖章。

// 版权声明（可保留或省略，不影响编译）
#pragma once

#include "Styling/CoreStyle.h"
#include "Widgets/Accessibility/SlateWidgetAccessibleTypes.h"
#include "Widgets/DeclarativeSyntaxSupport.h"
#include "Widgets/SLeafWidget.h"

#include "SCircumferenceMarkerWidget.generated.h"

class FPaintArgs;
class FSlateRect;
class FSlateWindowElementList;
class FWidgetStyle;
struct FGeometry;
struct FSlateBrush;

// 一个圆周标记：位置角度 + 图片旋转角度。
USTRUCT(BlueprintType)
struct FCircumferenceMarkerEntry
{
	GENERATED_BODY()

	// 这个标记在圆周上的位置角度（度）
	UPROPERTY(EditAnywhere, BlueprintReadWrite, meta=(ForceUnits=deg))
	float PositionAngle = 0.0f;

	// 标记图片的旋转角度（度）
	UPROPERTY(EditAnywhere, BlueprintReadWrite, meta=(ForceUnits=deg))
	float ImageRotationAngle = 0.0f;
};

// Slate 控件：在圆周上绘制多个标记。
class SCircumferenceMarkerWidget : public SLeafWidget
{
	// Slate 控件的"参数声明"块（类似构造函数参数表）。
	SLATE_BEGIN_ARGS(SCircumferenceMarkerWidget)
		: _MarkerBrush(FCoreStyle::Get().GetBrush("Throbber.CircleChunk"))
		, _Radius(48.0f)
	{
	}
		/** 圆周上每个标记的样子 */
		SLATE_ARGUMENT(const FSlateBrush*, MarkerBrush)
		/** 在哪些角度画标记 */
		SLATE_ARGUMENT(TArray<FCircumferenceMarkerEntry>, MarkerList)
		/** 圆的半径 */
		SLATE_ATTRIBUTE(float, Radius)
		/** 标记的颜色和不透明度 */
		SLATE_ATTRIBUTE(FSlateColor, ColorAndOpacity)
	SLATE_END_ARGS()

public:
	// 构造（Slate 控件的初始化入口）。
	void Construct(const FArguments& InArgs);

	// 构造函数（默认构造，供 Slate 新建控件用）。
	SCircumferenceMarkerWidget();

	//~SWidget 接口开始
	// 绘制：在圆周上画所有标记。
	virtual int32 OnPaint(const FPaintArgs& Args, const FGeometry& AllottedGeometry, const FSlateRect& MyCullingRect, FSlateWindowElementList& OutDrawElements, int32 LayerId, const FWidgetStyle& InWidgetStyle, bool bParentEnabled) const override;
	// 期望尺寸：控件要多大的布局空间。
	virtual FVector2D ComputeDesiredSize(float) const override;
	// 是否易变（true = 每帧都可能变，强制重绘）。
	virtual bool ComputeVolatility() const override { return true; }
	//~SWidget 接口结束

	// 设置半径。
	void SetRadius(float NewRadius);
	// 设置标记列表。
	void SetMarkerList(TArray<FCircumferenceMarkerEntry>& NewMarkerList);

private:
	// 算某个标记的渲染变换（旋转 + 平移到圆周位置）。
	FSlateRenderTransform GetMarkerRenderTransform(const FCircumferenceMarkerEntry& Marker, const float BaseRadius, const float HUDScale) const;

private:
	/** 圆周上每个标记的样子 */
	const FSlateBrush* MarkerBrush;

	/** 用来在准星中心周围放置角标图标的角度列表 */
	TArray<FCircumferenceMarkerEntry> MarkerList;

	/** 圆的半径 */
	TAttribute<float> Radius;

	/** 标记的颜色和不透明度 */
	TAttribute<FSlateColor> ColorAndOpacity;
	bool bColorAndOpacitySet;

	/** 准星角标是否放在散布半径之外 */
	//@TODO: 把它改成一个 0~1 的浮点对齐值？(比如：在内/在圆上/在外)
	uint8 bReticleCornerOutsideSpreadRadius : 1;
};

## 三、完整代码：`.cpp`（99 行）

```cpp
// 版权声明（可保留或省略，不影响编译）
#include "UI/Weapons/SCircumferenceMarkerWidget.h"

#include "Engine/UserInterfaceSettings.h"
#include "Styling/SlateBrush.h"

#include UE_INLINE_GENERATED_CPP_BY_NAME(SCircumferenceMarkerWidget)

class FPaintArgs;
class FSlateRect;

// 构造函数（默认构造）。
SCircumferenceMarkerWidget::SCircumferenceMarkerWidget()
{
}

// 构造（Slate 控件的初始化入口：把参数存到成员）。
void SCircumferenceMarkerWidget::Construct(const FArguments& InArgs)
{
	MarkerBrush = InArgs._MarkerBrush;
	MarkerList = InArgs._MarkerList;
	Radius = InArgs._Radius;
	bColorAndOpacitySet = InArgs._ColorAndOpacity.IsSet();
	ColorAndOpacity = InArgs._ColorAndOpacity;
}

// 算某个标记的渲染变换（旋转 + 平移到圆周位置）。
FSlateRenderTransform SCircumferenceMarkerWidget::GetMarkerRenderTransform(const FCircumferenceMarkerEntry& Marker, const float BaseRadius, const float HUDScale) const
{
	// 决定角标用多大半径
	float XRadius = BaseRadius;
	float YRadius = BaseRadius;
	if (bReticleCornerOutsideSpreadRadius)
	{
		XRadius += MarkerBrush->ImageSize.X * 0.5f;
		YRadius += MarkerBrush->ImageSize.X * 0.5f;
	}

	// 取这个角标的角度和朝向
	const float LocalRotationRadians = FMath::DegreesToRadians(Marker.ImageRotationAngle);
	const float PositionAngleRadians = FMath::DegreesToRadians(Marker.PositionAngle);

	// ① 先把角标图片绕自己中心旋转
	FSlateRenderTransform RotateAboutOrigin(Concatenate(FVector2D(-MarkerBrush->ImageSize.X * 0.5f, -MarkerBrush->ImageSize.Y * 0.5f), FQuat2D(LocalRotationRadians), FVector2D(MarkerBrush->ImageSize.X * 0.5f, MarkerBrush->ImageSize.Y * 0.5f)));

	// ② 把旋转后的图片移动到散布圆周上的正确位置
	return TransformCast<FSlateRenderTransform>(Concatenate(RotateAboutOrigin, FVector2D(XRadius * FMath::Sin(PositionAngleRadians) * HUDScale, -YRadius * FMath::Cos(PositionAngleRadians) * HUDScale)));
}

// 绘制：在圆周上画所有标记。
int32 SCircumferenceMarkerWidget::OnPaint(const FPaintArgs& Args, const FGeometry& AllottedGeometry, const FSlateRect& MyCullingRect, FSlateWindowElementList& OutDrawElements, int32 LayerId, const FWidgetStyle& InWidgetStyle, bool bParentEnabled) const
{
	const bool bIsEnabled = ShouldBeEnabled(bParentEnabled);
	const ESlateDrawEffect DrawEffects = bIsEnabled ? ESlateDrawEffect::None : ESlateDrawEffect::DisabledEffect;
	const FVector2D LocalCenter = AllottedGeometry.GetLocalPositionAtCoordinates(FVector2D(0.5f, 0.5f));

	const bool bDrawMarkers = (MarkerList.Num() > 0) && (MarkerBrush != nullptr);

	if (bDrawMarkers == true)
	{
		// 决定标记颜色（有设置就用设置，否则用控件样式 + 画刷色调）
		const FLinearColor MarkerColor = bColorAndOpacitySet ?
			ColorAndOpacity.Get().GetColor(InWidgetStyle) :
			(InWidgetStyle.GetColorAndOpacityTint() * MarkerBrush->GetTint(InWidgetStyle));

		if (MarkerColor.A > KINDA_SMALL_NUMBER)
		{
			const float BaseRadius = Radius.Get();
			const float ApplicationScale = GetDefault<UUserInterfaceSettings>()->ApplicationScale;
			for (const FCircumferenceMarkerEntry& Marker : MarkerList)
			{
				const FSlateRenderTransform MarkerTransform = GetMarkerRenderTransform(Marker, BaseRadius, ApplicationScale);

				const FPaintGeometry Geometry(AllottedGeometry.ToPaintGeometry(MarkerBrush->ImageSize, FSlateLayoutTransform(LocalCenter - (MarkerBrush->ImageSize * 0.5f)), MarkerTransform, FVector2D(0.0f, 0.0f)));
				FSlateDrawElement::MakeBox(OutDrawElements, LayerId, Geometry, MarkerBrush, DrawEffects, MarkerColor);
			}
		}
	}

	return LayerId;
}

// 期望尺寸：控件要多大的布局空间。
FVector2D SCircumferenceMarkerWidget::ComputeDesiredSize(float) const
{
	check(MarkerBrush);
	const float SampledRadius = Radius.Get();
	return FVector2D((MarkerBrush->ImageSize.X + SampledRadius) * 2.0f, (MarkerBrush->ImageSize.Y + SampledRadius) * 2.0f);
}

// 设置半径。
void SCircumferenceMarkerWidget::SetRadius(float NewRadius)
{
	if (Radius.IsBound() || (Radius.Get() != NewRadius))
	{
		Radius = NewRadius;
		Invalidate(EInvalidateWidgetReason::Layout);
	}
}

// 设置标记列表。
void SCircumferenceMarkerWidget::SetMarkerList(TArray<FCircumferenceMarkerEntry>& NewMarkerList)
{
	MarkerList = NewMarkerList;
}
```

## 四、关键点讲解（Slate 核心概念）

### 1. `SLATE_BEGIN_ARGS` / `SLATE_END_ARGS`——Slate 控件的"参数表"

```cpp
class SCircumferenceMarkerWidget : public SLeafWidget
{
	SLATE_BEGIN_ARGS(SCircumferenceMarkerWidget)
		: _MarkerBrush(FCoreStyle::Get().GetBrush("Throbber.CircleChunk"))
		, _Radius(48.0f)
	{
	}
		SLATE_ARGUMENT(const FSlateBrush*, MarkerBrush)
		SLATE_ARGUMENT(TArray<FCircumferenceMarkerEntry>, MarkerList)
		SLATE_ATTRIBUTE(float, Radius)
		SLATE_ATTRIBUTE(FSlateColor, ColorAndOpacity)
	SLATE_END_ARGS()
```

这是 Slate 的"构造参数声明 DSL"。展开后本质是一个 `FArguments` 结构体。

- `SLATE_ARGUMENT(类型, 名)`：**静态参数**（构造时传一次，之后不变）。
- `SLATE_ATTRIBUTE(类型, 名)`：**动态属性**（`TAttribute<T>`，可以绑定委托，每帧求值——可用于动画/数据驱动）。
- 冒号后面的初始化列表（`_MarkerBrush(...)`, `_Radius(48.0f)`）：参数的**默认值**。

> 对比 UMG 的 `UPROPERTY(EditAnywhere)`（编辑器配）。Slate 没有编辑器，全靠这个 DSL 声明参数。

### 2. `Construct(const FArguments& InArgs)`——Slate 的"构造函数"

```cpp
void SCircumferenceMarkerWidget::Construct(const FArguments& InArgs)
{
	MarkerBrush = InArgs._MarkerBrush;
	MarkerList = InArgs._MarkerList;
	Radius = InArgs._Radius;
	bColorAndOpacitySet = InArgs._ColorAndOpacity.IsSet();
	ColorAndOpacity = InArgs._ColorAndOpacity;
}
```

Slate 控件真正的初始化在 `Construct`（不是 C++ 构造函数）。

> 用法：`SNew(SCircumferenceMarkerWidget).MarkerBrush(...).Radius(...)` —— `SNew` 会 new 出对象后调 `Construct`。

### 3. `TAttribute<T>`——可绑定的值

```cpp
TAttribute<float> Radius;
```

`TAttribute<T>`：可以是**固定值**，也可以**绑定到一个委托**（每帧求值）。

```cpp
void SetRadius(float NewRadius)
{
	if (Radius.IsBound() || (Radius.Get() != NewRadius))   // 绑定时不能直接比较值
	{
		Radius = NewRadius;
		Invalidate(EInvalidateWidgetReason::Layout);          // 请求重新布局
	}
}
```

`IsBound()`：是否绑了委托。绑定时不能直接比 `Get()`（每次求值可能不同）。

`Invalidate(原因)`：告诉 Slate"我变了，请重新布局/重绘"。

### 4. `ComputeVolatility() { return true; }`——每帧重绘

```cpp
virtual bool ComputeVolatility() const override { return true; }
```

`true` = 这个控件**每帧都可能变化**，Slate 不要做缓存优化（每帧都调 `OnPaint`）。因为半径/标记会随武器散布实时变。

### 5. `OnPaint`——绘制入口（参数最多）

```cpp
virtual int32 OnPaint(
	const FPaintArgs& Args,                       // 绘制参数
	const FGeometry& AllottedGeometry,            // 布局几何（位置/大小）
	const FSlateRect& MyCullingRect,               // 裁剪矩形
	FSlateWindowElementList& OutDrawElements,      // 输出：要画的元素列表
	int32 LayerId,                                 // 当前层级
	const FWidgetStyle& InWidgetStyle,             // 控件样式
	bool bParentEnabled) const override;           // 父级是否启用
```

`OnPaint` 是 Slate 控件的**核心**——你把"要画什么"塞进 `OutDrawElements`，Slate 负责真正渲染。返回"新的 LayerId"（后续控件从这个层级往上画）。

### 6. `FSlateDrawElement::MakeBox(...)`——画一个盒（图片）

```cpp
FSlateDrawElement::MakeBox(OutDrawElements, LayerId, Geometry, MarkerBrush, DrawEffects, MarkerColor);
```

参数：
1. `OutDrawElements`：输出列表。
2. `LayerId`：层级。
3. `Geometry`：`FPaintGeometry`（位置/大小/变换）。
4. `MarkerBrush`：画刷（图片）。
5. `DrawEffects`：绘制效果（`None` / `DisabledEffect` 灰化）。
6. `MarkerColor`：颜色。

> 除了 `MakeBox`，还有 `MakeLine`/`MakeText`/`MakeShapedText` 等。

### 7. `ToPaintGeometry(...)`——组装绘制几何

```cpp
const FPaintGeometry Geometry(AllottedGeometry.ToPaintGeometry(
	MarkerBrush->ImageSize,                                        // 大小
	FSlateLayoutTransform(LocalCenter - (MarkerBrush->ImageSize * 0.5f)),   // 布局变换（居中）
	MarkerTransform,                                                // 渲染变换（旋转+平移）
	FVector2D(0.0f, 0.0f)));                                        // 轴心
```

把"控件几何 + 图片大小 + 布局位置 + 渲染变换"合成一个 `FPaintGeometry`。

### 8. `GetMarkerRenderTransform`——旋转 + 平移的矩阵拼接

```cpp
// ① 绕图片中心旋转
FSlateRenderTransform RotateAboutOrigin(Concatenate(
	FVector2D(-ImageSize.X * 0.5f, -ImageSize.Y * 0.5f),   // 平移到中心
	FQuat2D(LocalRotationRadians),                          // 旋转
	FVector2D(ImageSize.X * 0.5f, ImageSize.Y * 0.5f)));    // 平移回来

// ② 再平移到圆周位置
return TransformCast<FSlateRenderTransform>(Concatenate(
	RotateAboutOrigin,
	FVector2D(XRadius * FMath::Sin(PositionAngleRadians) * HUDScale,
	          -YRadius * FMath::Cos(PositionAngleRadians) * HUDScale)));
```

**绕任意点旋转的标准技巧**：平移→旋转→平移回来。

**圆周位置**：`(R·sinθ, -R·cosθ)`——注意 Y 取负，因为 Slate 的 Y 轴向下（屏幕坐标），而角度按数学逆时针算。

**`HUDScale`（`ApplicationScale`）**：UI 缩放系数（4K 屏会把 UI 放大），所以半径也要跟着缩放。

### 9. `ComputeDesiredSize`——控件想要多大

```cpp
return FVector2D((ImageSize.X + Radius) * 2.0f, (ImageSize.Y + Radius) * 2.0f);
```

直径 = (图片宽 + 半径) × 2 —— 留出标记本身的宽度。

### 10. `SLeafWidget`——叶子控件（无子控件）

```cpp
class SCircumferenceMarkerWidget : public SLeafWidget
```

`SLeafWidget`：**没有子控件**的 Slate 控件（纯自绘）。对比 `SCompoundWidget`（有 1 个子控件）、`SPanel`（多个子控件）。

## 〇、为什么先建这个子阶段总 md

P16.7 是"世界空间指示器"——把 UI 图标贴到 3D 世界里的 Actor 身上（队友标记、任务标记、敌人血条）。这是**比 UMG 更底层的 Slate 自绘系统**（`SActorCanvas` 20.6KB）。

## 一、这 6 个类是什么

| 类 | 类型 | 行数 | 作用 |
|----|------|------|------|
| `IIndicatorWidgetInterface` | 接口 | 30 | 指示器控件接口（`BindIndicator`/`UnbindIndicator`） |
| `UIndicatorDescriptor` | `UObject` | ~200 | **一条指示器的数据**（绑哪个 Actor、用什么控件、偏移/朝向等） |
| `ULyraIndicatorManagerComponent` | `UControllerComponent` | 45 | 管理器（挂在 Controller 上，管所有指示器） |
| `UIndicatorLibrary` | `UBlueprintFunctionLibrary` | 29 | 蓝图函数库（便捷取管理器） |
| `SActorCanvas` | **Slate** | 20.6KB | **核心绘制**：把 3D 位置投影到屏幕并画 |
| `UIndicatorLayer` | `UWidget` | 31 | UMG 包装（包 `SActorCanvas`） |

### 系统关系

```
ULyraIndicatorManagerComponent（挂在 PlayerController）
   └─ 管理 N 个 UIndicatorDescriptor（每条指示器）
        ├─ 绑定的 Actor（世界位置）
        ├─ 用的控件类（IIndicatorWidgetInterface）
        └─ 屏幕偏移/箭头朝向等

UIndicatorLayer（UMG 控件，放在 HUD 里）
   └─ SActorCanvas（Slate）
        └─ 遍历所有 Descriptor → 把 Actor 位置投影到屏幕 → 画控件
```

> **类比**：`Descriptor` 是"一张任务卡"（要标记谁、用什么图标），`Manager` 是"卡片管理处"（增删卡），`SActorCanvas` 是"显示器"（把卡片贴到目标位置的屏幕上）。

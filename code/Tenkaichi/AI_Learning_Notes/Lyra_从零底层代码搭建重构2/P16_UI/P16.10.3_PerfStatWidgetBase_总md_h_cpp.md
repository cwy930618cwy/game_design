## 一、这个类解决什么问题（先讲为什么）

性能面板里每个数字（FPS / Ping / 延迟）都是一个**独立的 stat 控件**。它们结构相同，只是"显示哪个 stat"不同。

`ULyraPerfStatWidgetBase` 是这些控件的**基类**：
1. 配一个 `StatToDisplay`（要显示哪个 stat）。
2. `FetchStatValue()`：从 `ULyraPerformanceStatSubsystem` 取当前值。
3. `UpdateGraphData()`：把数据缓存指针交给曲线图（P16.10.2）。
4. 可选绑定一个 `PerfStatGraph`（曲线图控件）。

> **类比**：这是"仪表盘上的单个表盘"——每个表盘只管一个指标（速度/转速/油量），但结构一样。

## 三、关键点讲解

### 1. `FetchStatValue`——从子系统取缓存值

```cpp
double UTenkaichiPerfStatWidgetBase::FetchStatValue()
{
	if (UTenkaichiPerformanceStatSubsystem* Subsystem = GetStatSubsystem())
	{
		return CachedStatSubsystem->GetCachedStat(StatToDisplay);
	}
	else
	{
		return 0.0;
	}
}
```

**注意**：`Subsystem` 变量检查了但**没用**（实际用的是 `CachedStatSubsystem`）——Lyra 的冗余写法。

`GetCachedStat(StatToDisplay)`：从子系统拿"这个 stat 的缓存值"（子系统每帧采样，这里只读缓存）。

> 为什么用"缓存"而不是"实时算"？因为性能统计要**低开销**——每帧采样一次，UI 读缓存。

### 2. `GetStatSubsystem`——懒获取 + 缓存

```cpp
UTenkaichiPerformanceStatSubsystem* UTenkaichiPerfStatWidgetBase::GetStatSubsystem()
{
	if (CachedStatSubsystem == nullptr)
	{
		if (UWorld* World = GetWorld())
		{
			if (UGameInstance* GameInstance = World->GetGameInstance())
			{
				CachedStatSubsystem = GameInstance->GetSubsystem<UTenkaichiPerformanceStatSubsystem>();
			}
		}
	}

	return CachedStatSubsystem;
}
```

**三级链**：`World → GameInstance → Subsystem`。

**懒获取 + 缓存**：第一次调用时查，之后直接用 `CachedStatSubsystem`。

> 和 P16.7.5-4 的"懒获取管理器组件"是同一模式。

### 3. `UpdateGraphData`——把数据指针交给曲线图

```cpp
void UTenkaichiPerfStatWidgetBase::UpdateGraphData(const float ScaleFactor)
{
	if (PerfStatGraph)
	{
		if (const FSampledStatCache* GraphData = CachedStatSubsystem->GetCachedStatData(StatToDisplay))
		{
			PerfStatGraph->UpdateGraphData(GraphData, ScaleFactor);
		}	
	}
}
```

**注意**：`CachedStatSubsystem` **没有空检查**（直接 `->`）——因为调用前必须先 `GetStatSubsystem()`（`NativeConstruct` 里做了）。

> 这是"调用约定"——Lyra 靠"先调 GetStatSubsystem"保证非空。按铁律 23 照抄。

### 4. `NativeConstruct`——缓存子系统 + 配置曲线图

```cpp
void UTenkaichiPerfStatWidgetBase::NativeConstruct()
{
	Super::NativeConstruct();

	// 构造时缓存子系统，这也会确保曲线图是最新的
	GetStatSubsystem();
	
	if (PerfStatGraph)
	{
		PerfStatGraph->SetLineColor(GraphLineColor);
		PerfStatGraph->SetMaxYValue(GraphMaxYValue);
		PerfStatGraph->SetBackgroundColor(GraphBackgroundColor);
	}
}
```

**两件事**：
1. `GetStatSubsystem()`：缓存子系统（顺便确保曲线图数据最新）。
2. 如果绑了 `PerfStatGraph`，把三个配置（线色/最大值/背景色）推给它。

> `PerfStatGraph` 是 `BindWidget + OptionalWidget`（可选）——所以有 `if (PerfStatGraph)` 检查。

### 5. `meta=(BindWidget, OptionalWidget=true)`——可选绑定

```cpp
UPROPERTY(BlueprintReadWrite, meta=(BindWidget, OptionalWidget=true))
TObjectPtr<UTenkaichiPerfStatGraph> PerfStatGraph;
```

和 P16.9.5 的 `TopSettingsTabs` 一样（`BindWidget + OptionalWidget` 组合）。

**为什么可选？** 因为不是每个 stat 都要曲线图（比如 Ping 只要数字）。

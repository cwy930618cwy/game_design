class FChildren;

// 指示器画布：把指示器投影到屏幕并绘制（Slate 面板）。
class SActorCanvas : public SPanel, public FAsyncMixin, public FGCObject
{
public:
	/** 画布专用的槽位类 */
	class FSlot : public TSlotBase<FSlot>
	{
	public: 

		// 构造函数：初始化所有状态。
		FSlot(UIndicatorDescriptor* InIndicator)
			: TSlotBase<FSlot>()
			, Indicator(InIndicator)
			, ScreenPosition(FVector2D::ZeroVector)
			, Depth(0)
			, Priority(0.f)
			, bIsIndicatorVisible(true)
			, bInFrontOfCamera(true)
			, bHasValidScreenPosition(false)
			, bDirty(true)
			, bWasIndicatorClamped(false)
			, bWasIndicatorClampedStatusChanged(false)

		}

			if (ScreenPosition != InScreenPosition)
			{
				ScreenPosition = InScreenPosition;
				bDirty = true;

		double GetDepth() const { return Depth; }
		// 设置深度（变了就标脏）。
		void SetDepth(double InDepth)
		{
			if (Depth != InDepth)
			{

				bDirty = true;
			}
		}

		int32 GetPriority() const { return Priority; }
		// 设置排序优先级（变了就标脏）。
		void SetPriority(int32 InPriority)
		{
			if (Priority != InPriority)
			{
				Priority = InPriority;
				bDirty = true;
			}
		}

		// 设置是否在相机前方（变了就标脏 + 刷新可见性）。
		void SetInFrontOfCamera(bool bInFront)
		{
			if (bInFrontOfCamera != bInFront)
			{
				bInFrontOfCamera = bInFront;
				bDirty = true;
			}

			RefreshVisibility();
		}

		// 设置是否有有效屏幕位置（变了就标脏 + 刷新可见性）。
		void SetHasValidScreenPosition(bool bValidScreenPosition)
		{
			if (bHasValidScreenPosition != bValidScreenPosition)
			{
				bHasValidScreenPosition = bValidScreenPosition;
				bDirty = true;
			}

			RefreshVisibility();
		}

		// 是否脏（需要重新布局/绘制）。

		void ClearDirtyFlag()
		{
			bDirty = false;
		}

## 二、关键点讲解

### 1. 三继承：`SPanel` + `FAsyncMixin` + `FGCObject`

```cpp
class SActorCanvas : public SPanel, public FAsyncMixin, public FGCObject
```

| 基类 | 作用 |
|------|------|
| `SPanel` | Slate 面板（**可容纳多个子控件**，对比 `SLeafWidget` 无子控件） |
| `FAsyncMixin` | 异步任务管理（AsyncMixin 插件）——用于异步加载指示器控件 |
| `FGCObject` | **GC 追踪**——让 Slate 对象能持有 UObject 引用并报告给 GC |

**为什么需要 `FGCObject`？** 因为 `SActorCanvas` 是 Slate 对象（不是 UObject），但它持有 `TArray<TObjectPtr<UIndicatorDescriptor>>`（UObject）。如果不报告给 GC，这些 Descriptor 会被回收 → 崩溃。

> `FGCObject` 就是"非 UObject 对象持有 UObject 引用"的标准方案。

### 2. `FSlot`——指示器槽位（带脏标记）

```cpp
class FSlot : public TSlotBase<FSlot>
```

`TSlotBase<FSlot>`：Slate 的槽位基类（CRTP 模式，`FSlot` 继承 `TSlotBase<FSlot>`）。

**槽位存什么**：
| 成员 | 作用 |
|------|------|
| `Indicator` | 对应的 Descriptor（裸指针，由 `AddReferencedObjects` 保活） |
| `ScreenPosition` | 屏幕位置 |
| `Depth` | 到相机距离（排序用） |
| `Priority` | 排序优先级 |
| `bIsIndicatorVisible` | 期望可见 |
| `bInFrontOfCamera` | 在相机前方 |
| `bHasValidScreenPosition` | 有有效屏幕位置 |
| `bDirty` | **脏标记**（需要重新布局/绘制） |
| `bWasIndicatorClamped`（mutable） | 上一帧是否被钳制 |
| `bWasIndicatorClampedStatusChanged`（mutable） | 钳制状态是否变化 |

### 3. 所有 Setter 都"变了才标脏"

```cpp
void SetScreenPosition(FVector2D InScreenPosition)
{
	if (ScreenPosition != InScreenPosition)
	{
		ScreenPosition = InScreenPosition;
		bDirty = true;
	}
}
```

**统一模式**：值变了才 `bDirty = true`。避免无变化时触发重绘（性能优化，同 P16.5 的缓存过滤）。

### 4. `RefreshVisibility()`——两个条件都满足才显示

```cpp
void RefreshVisibility()
{
	const bool bIsVisible = bIsIndicatorVisible && bHasValidScreenPosition;
	GetWidget()->SetVisibility(bIsVisible ? EVisibility::SelfHitTestInvisible : EVisibility::Collapsed);
}
```

**必须同时满足**：
1. `bIsIndicatorVisible`（业务上要显示）。
2. `bHasValidScreenPosition`（投影成功，有屏幕位置）。

否则 `Collapsed`（完全隐藏）。

> 注意 `SetIsIndicatorVisible` / `SetInFrontOfCamera` / `SetHasValidScreenPosition` 三个 Setter 末尾都调 `RefreshVisibility()`——因为它们都影响可见性。

### 5. `mutable` 的两个钳制标记

```cpp
mutable uint8 bWasIndicatorClamped : 1;
mutable uint8 bWasIndicatorClampedStatusChanged : 1;
```

**为什么 `mutable`？** 因为它们在 `OnPaint`（**const 方法**）里被写入——绘制时发现"这个指示器被钳制了"，要记下来给下一帧用。

> 注释里 Lyra 自己说这是"半 hack 的 mutable 实现"（semi-hacky mutable implementation）。按铁律 23 照抄。

### 6. `SLATE_SLOT_BEGIN_ARGS` / `SLATE_SLOT_ARGUMENT`

```cpp
SLATE_SLOT_BEGIN_ARGS(FSlot, TSlotBase<FSlot>)
SLATE_SLOT_END_ARGS()
using TSlotBase<FSlot>::Construct;
```

`SLATE_SLOT_BEGIN_ARGS`：声明**槽位**的参数（对比 `SLATE_BEGIN_ARGS` 是控件的参数）。

```cpp
SLATE_SLOT_ARGUMENT(SActorCanvas::FSlot, Slots)
```

`SLATE_SLOT_ARGUMENT(槽位类型, 名)`：声明"这个控件支持这种槽位"（`Slots` 是槽位数组）。

> 用法：`SNew(SActorCanvas) + SActorCanvas::FSlot(Descriptor)` —— 用 `+` 添加槽位。

### 7. `FArrowSlot` 是空类

```cpp
class FArrowSlot : public TSlotBase<FArrowSlot>
{
};
```

**完全空**——只为了"类型区分"（箭头槽位 vs 指示器槽位）。因为 `TPanelChildren<FSlot>` 和 `TPanelChildren<FArrowSlot>` 是不同类型，分开存。

### 8. `FCombinedChildren`——合并两个容器

```cpp
SActorCanvas()
	: CanvasChildren(this)
	, ArrowChildren(this)
	, AllChildren(this)
{
	AllChildren.AddChildren(CanvasChildren);
	AllChildren.AddChildren(ArrowChildren);
}
```

`FCombinedChildren`：把多个 `FChildren` 合并成一个（`GetChildren()` 返回它）。

**为什么？** Slate 的 `GetChildren()` 只能返回**一个** `FChildren*`，但这里有两组子控件（指示器 + 箭头）。所以用 `FCombinedChildren` 合并。

### 9. `FUserWidgetPool IndicatorPool`——对象池

```cpp
FUserWidgetPool IndicatorPool;
```

`FUserWidgetPool`：UMG 的"控件对象池"——**复用** `UUserWidget` 实例（不销毁，回收再用）。

**为什么？** 指示器频繁增删（队友进出视野），每次 `CreateWidget` + 销毁开销大。对象池让"回收的控件"下次直接复用。

### 10. `ComputeDesiredSize` 返回 0

```cpp
virtual FVector2D ComputeDesiredSize(float) const override { return FVector2D::ZeroVector; }
```

画布**不占布局空间**（它是覆盖在屏幕上的浮层），所以期望尺寸是 0。

### 11. `FActiveTimerHandle`——活跃定时器

```cpp
TSharedPtr<FActiveTimerHandle> TickHandle;
```

`FActiveTimerHandle`：Slate 的"活跃定时器"句柄（`RegisterActiveTimer` 返回）。

**"活跃定时器" vs 普通定时器**：活跃定时器只在**控件可见时**才 tick（不可见时自动暂停）——省性能。

### 12. `OptionalPaintGeometry`（mutable）

```cpp
mutable TOptional<FGeometry> OptionalPaintGeometry;
```

缓存"上次绘制用的几何"（`OnPaint` 是 const，所以要 mutable）。用于 `OnArrangeChildren` 里判断"几何是否变了"。

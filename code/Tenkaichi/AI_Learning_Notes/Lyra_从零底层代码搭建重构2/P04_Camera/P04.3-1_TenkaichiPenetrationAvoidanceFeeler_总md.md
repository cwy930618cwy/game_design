## 一、这个类解决什么问题？

**定义"相机防穿墙"用的探测射线（探针）长什么样**。上一节 P04.2-2 `_ThirdPerson` 里有一段：

```cpp
// 探测射线组（0 号主射线 + 1+ 号预测射线）
UPROPERTY(EditDefaultsOnly, Category = "Collision")
TArray<FTenkaichiPenetrationAvoidanceFeeler> PenetrationAvoidanceFeelers;
```

这里的 `FTenkaichiPenetrationAvoidanceFeeler` 就是本结构体——**一条探测射线的完整配置**。相机防穿墙时，会按这些配置发射多条射线，每条射线都记录"从主射线偏转多少、命中世界/Pawn 各占多少权重、探测范围多大、多久打一次"。

| 做什么 | 类比 |
|--------|------|
| 定义一条探测射线的形状（偏转角、权重、范围、频率） | 定义一条"探针"的长短粗细和灵敏度 |

> 一句话：**它是 P04.2-2 防穿墙逻辑里"探测射线"的数据定义**——一组这样的 feeler 组成探测网，让相机提前发现墙并收镜。

## 二、全景（本结构体有哪些成员）

| 成员 | 类型 | 干什么 |
|------|------|--------|
| `AdjustmentRot` | `FRotator` | 相对主射线的偏转角度（0 号 feeler 偏转 0，其他 feeler 向四周散开） |
| `WorldWeight` | `float` | 命中**世界物体**时对该 feeler 结果的影响权重 |
| `PawnWeight` | `float` | 命中**Pawn（角色）**时的影响权重（设 0 则完全不跟 Pawn 碰撞） |
| `Extent` | `float` | 这条射线碰撞探测的范围半径（胶囊粗细） |
| `TraceInterval` | `int32` | 没命中时，隔多少帧再打这条射线（节流，省性能） |
| `FramesUntilNextTrace` | `int32` | 距离下一次探测还剩几帧（`transient` 运行期状态） |

### 构造函数

| 构造函数 | 干什么 |
|---------|--------|
| `FLyraPenetrationAvoidanceFeeler()` | 默认构造：所有成员归零 |
| `FLyraPenetrationAvoidanceFeeler(AdjustmentRot, WorldWeight, PawnWeight, Extent, TraceInterval, FramesUntilNextTrace)` | 带参构造：一次性给全部成员赋值（`TraceInterval`/`FramesUntilNextTrace` 有默认值 0） |

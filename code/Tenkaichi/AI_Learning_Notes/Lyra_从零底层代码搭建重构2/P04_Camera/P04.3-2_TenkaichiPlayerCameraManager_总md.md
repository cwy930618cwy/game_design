## 一、这个类解决什么问题？

**替换 UE 默认的玩家相机管理器，接入项目自己的相机组件 + UI 相机**。UE 引擎里每个玩家控制器（PlayerController）都有一个 `APlayerCameraManager` 负责计算"玩家看到的视图"。Lyra 继承它替换成自己的版本：

| 做的事 | 类比 |
|--------|------|
| **① 提供默认相机参数**：默认 FOV 80°、俯仰角 ±89° | 给相机设好出厂默认 |
| **② 内嵌一个 UI 相机组件**：`CreateDefaultSubobject<ULyraUICameraManagerComponent>` | 相机管理器的"副驾驶"——UI 需要时抢相机控制权 |
| **③ 覆盖 `UpdateViewTarget`**：UI 相机要接管时让给它，否则走默认 | 导演喊"切 UI 镜头"时让权 |
| **④ 覆盖 `DisplayDebug`**：showdebug 时打印相机信息 + 让相机组件画调试 | 后台打印相机状态 |
| **⑤ 提供 `GetUICameraComponent()`**：外部取 UI 相机组件 | 查"副驾驶在哪" |

> 一句话：**它把项目自己的相机组件和 UI 相机组件接进 UE 默认的玩家相机管理流程**，并设好默认参数。

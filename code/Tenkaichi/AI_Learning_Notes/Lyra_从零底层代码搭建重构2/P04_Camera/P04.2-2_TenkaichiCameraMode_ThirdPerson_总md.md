## 一、这个类解决什么问题？

**给基类 `UTenkaichiCameraMode` 加"第三人称"的具体表现**。基类只提供"相机贴着枢轴点看"的通用骨架；`_ThirdPerson` 把它变成游戏里真正看到的第三人称镜头，核心做三件事：

| 做的事 | 类比 |
|--------|------|
| **① 第三人称偏移**：根据俯仰角查曲线，把相机从枢轴点往后/往上拉，形成"角色背后"的镜头 | 摄影师扛着机器跟拍，镜头始终悬在角色肩后 |
| **② 蹲伏偏移**：角色下蹲时，相机平滑下降跟随眼睛高度 | 跟拍摄影师也蹲下来 |
| **③ 防穿墙（Penetration Prevention）**：相机被墙挡住时，往前收、不穿模，并且预先探测避免"弹跳" | 摄影师贴着墙走时会把镜头拉近，不会怼进墙里 |

> 一句话：**基类给"骨架"，_ThirdPerson 给"第三人称的具体姿态 + 防穿墙智能"**。

### 2.1 成员属性（.h）

| 分类 | 成员 | 类型 | 干什么 |
|------|------|------|--------|
| 偏移 | `TargetOffsetCurve` | `TObjectPtr<const UCurveVector>` | 用俯仰角查的偏移曲线（把相机从枢轴点拉开的距离） |
| 偏移 | `bUseRuntimeFloatCurves` | `bool` | 是否用运行时浮点曲线（替代资产曲线，PIE 里可实时编辑） |
| 偏移 | `TargetOffsetX/Y/Z` | `FRuntimeFloatCurve` | `bUseRuntimeFloatCurves` 为真时的三条 XYZ 偏移曲线 |
| 偏移 | `CrouchOffsetBlendMultiplier` | `float`（默认 5.0） | 蹲伏偏移的过渡速度 |
| 防穿墙 | `PenetrationBlendInTime` / `OutTime` | `float`（0.1 / 0.15） | 穿墙收镜/回弹的过渡时间 |
| 防穿墙 | `bPreventPenetration` | `bool`（true） | 是否做防穿墙碰撞检测 |
| 防穿墙 | `bDoPredictiveAvoidance` | `bool`（true） | 是否预先探测（避免怼墙瞬间的弹跳） |
| 防穿墙 | `CollisionPushOutDistance` | `float`（2.0） | 相机与墙保持的最小推出距离 |
| 防穿墙 | `ReportPenetrationPercent` | `float`（0） | 穿墙比例低于它时通知 assist 接口 |
| 防穿墙 | `PenetrationAvoidanceFeelers` | `TArray<FLyraPenetrationAvoidanceFeeler>` | 探测射线组（0 号主射线 + 1+ 号预测射线） |
| 内部 | `AimLineToDesiredPosBlockedPct` | `float`（Transient） | 瞄准线被挡的百分比（跨帧保留） |
| 内部 | `DebugActorsHitDuringCameraPenetration` | `TArray<...>` | 调试：记录被撞到的 Actor |
| 蹲伏 | `InitialCrouchOffset` / `TargetCrouchOffset` / `CurrentCrouchOffset` | `FVector` | 蹲伏偏移的起始/目标/当前值 |
| 蹲伏 | `CrouchOffsetBlendPct` | `float`（1.0） | 蹲伏偏移过渡进度 0~1 |

### 2.2 成员方法

| 方法 | 干什么 |
|------|--------|
| `UpdateView(DeltaTime)` | **覆盖基类**：每帧更新（偏移 + 蹲伏 + 防穿墙） |
| `UpdateForTarget(DeltaTime)` | 检测目标是否下蹲，设置蹲伏偏移目标 |
| `UpdatePreventPenetration(DeltaTime)` | 防穿墙入口：算安全点、打射线、调整相机位置 |
| `PreventCameraPenetration(...)` | 核心射线检测：多 feeler 打射线，算被挡比例，平滑收镜 |
| `SetTargetCrouchOffset(FVector)` | 设置蹲伏偏移目标并重置过渡 |
| `UpdateCrouchOffset(DeltaTime)` | 每帧平滑推进蹲伏偏移 |
| `DrawDebug(Canvas)` | 覆盖：打印被撞 Actor 调试信息 |


| 成员 | 干什么 |
|------|--------|
| `AdjustmentRot` | 相对**主射线**（索引 0，偏转 0）的偏转角。其他 feeler 用不同角度向四周散开，形成探测网 |
| `WorldWeight` | 命中世界几何体（墙/地）时，这条 feeler 的结果对最终相机位置的**影响权重** |
| `PawnWeight` | 命中 Pawn 时的影响权重。**设 0 = 不跟角色碰撞**（相机可以穿过队友） |
| `Extent` | 射线碰撞用的胶囊半径（决定"多粗的射线"） |
| `TraceInterval` | 没命中时隔几帧打一次（节流：相机静止时不用每帧全打，省性能） |
| `FramesUntilNextTrace` | 运行期状态：距下次探测还剩几帧（`transient` 不序列化） |

> 类比：**"一束探照灯"**——`AdjustmentRot` 是它的朝向（从主光偏开多少度），`WorldWeight`/`PawnWeight` 是照到墙/照到人时各算多重，`Extent` 是光束粗细，`TraceInterval` 是"没人时隔多久扫一次"。

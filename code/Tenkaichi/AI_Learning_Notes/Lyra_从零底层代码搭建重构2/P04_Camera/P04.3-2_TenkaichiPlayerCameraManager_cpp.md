### 1.4 UpdateViewTarget（核心：UI 相机优先级）

```cpp
// 覆盖引擎：更新视图目标（如果 UI 相机在观察某物，让它优先接管）。
void ATenkaichiPlayerCameraManager::UpdateViewTarget(FTViewTarget& OutVT, float DeltaTime)
{
	// 如果 UI 相机正在观察某物，让它优先接管。
	if (UICamera->NeedsToUpdateViewTarget())
	{
		Super::UpdateViewTarget(OutVT, DeltaTime);
		UICamera->UpdateViewTarget(OutVT, DeltaTime);
		return;
	}

	Super::UpdateViewTarget(OutVT, DeltaTime);
}
```

| 行 | 干什么 |
|----|--------|
| `UICamera->NeedsToUpdateViewTarget()` | 判断 UI 相机**是否要接管**（P04.3-3 实现，当前返回 false，即默认不让权） |
| `if` 为真 | **先走引擎默认 `Super::UpdateViewTarget`**，再让 UI 相机 `UpdateViewTarget` 覆盖视图，然后 `return` |
| `if` 为假 | 只走引擎默认 `Super::UpdateViewTarget` |

> 类比：**"相机权限调度"**——UI 相机说"我要接管"（`NeedsToUpdateViewTarget`），就让它最后再画一层覆盖玩法相机；否则照常走引擎默认。

> **注意**：`NeedsToUpdateViewTarget()` 当前在 P04.3-3 里**直接 return false**（骨架），所以此分支暂时不触发——这就是为什么 Lyra 的 UI 相机组件目前是个空壳。

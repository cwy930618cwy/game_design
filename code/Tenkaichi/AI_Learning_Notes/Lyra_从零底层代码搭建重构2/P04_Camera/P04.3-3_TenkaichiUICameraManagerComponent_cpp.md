### 1.5 SetViewTarget（转发给主相机管理器）

```cpp

void UTenkaichiUICameraManagerComponent::SetViewTarget(AActor* InViewTarget, FViewTargetTransitionParams TransitionParams)

	TGuardValue<bool> UpdatingViewTargetGuard(bUpdatingViewTarget, true);

	ViewTarget = InViewTarget;
	CastChecked<ATenkaichiPlayerCameraManager>(GetOwner())->SetViewTarget(ViewTarget, TransitionParams);

```

| 行 | 干什么 |
|----|--------|
| `TGuardValue<bool> UpdatingViewTargetGuard(bUpdatingViewTarget, true)` | **RAII 守卫**：进入时把 `bUpdatingViewTarget` 置 true，**离开作用域自动还原**（防重入） |
| `ViewTarget = InViewTarget` | 记录 UI 相机目标 |
| `CastChecked<ATenkaichiPlayerCameraManager>(GetOwner())` | 拿外层 PlayerCameraManager（**CastChecked：转型失败直接崩溃**，因为 `Within=` 保证一定是它） |
| `->SetViewTarget(ViewTarget, TransitionParams)` | **转发**给主相机管理器真正设置视图目标 |

> 类比：副驾驶把目的地（ViewTarget）记下，然后让驾驶员（主 PlayerCameraManager）真正执行转向。`TGuardValue` 是"进入时开锁、离开自动上锁"的保险。

# P07.8 UTenkaichiTeamCheats —— `.cpp` 实现层

## 一、本文件要解决什么

`.h` 声明了 3 个函数，`.cpp` 实现这 3 个：

| 函数 | 干什么 |
|------|--------|
| `CycleTeam()` | 查当前队 → 查所有队 → 算下一个（末尾绕回）→ 换过去 → 打印结果 |
| `SetTeam(TeamID)` | 判断队存在 → 换过去（队不存在就什么都不做） |
| `ListTeams()` | 取所有队伍 ID → 逐个打印 |

> 🔑 **一句话**：`.cpp` 就是"**取到 TeamSubsystem → 判空 → 调它的接口干活**"。
> 三个函数**结构完全一样**，学会一个就全会了。

这三个函数**能编译，但链接要等 ④ 解开**：

- `.cpp` include 的 `Teams/TenkaichiTeamSubsystem.h` **工程已落盘** ✅

## 三、完整代码（注释已中文化）

你新建文件：`Source/TenkaichiGame/Teams/TenkaichiTeamCheats.cpp`

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

#include "TenkaichiTeamCheats.h"

#include "Engine/World.h"
#include "GameFramework/PlayerController.h"
#include "HAL/IConsoleManager.h"
#include "Teams/TenkaichiTeamSubsystem.h"

#include UE_INLINE_GENERATED_CPP_BY_NAME(TenkaichiTeamCheats)

//////////////////////////////////////////////////////////////////////
// UTenkaichiTeamCheats

// 把当前玩家轮换到下一个队伍（到末尾则绕回第一个队伍）
void UTenkaichiTeamCheats::CycleTeam()
{
	if (UTenkaichiTeamSubsystem* TeamSubsystem = UWorld::GetSubsystem<UTenkaichiTeamSubsystem>(GetWorld()))
	{
		APlayerController* PC = GetPlayerController();

		const int32 OldTeamId = TeamSubsystem->FindTeamFromObject(PC);
		const TArray<int32> TeamIds = TeamSubsystem->GetTeamIDs();
		
		if (TeamIds.Num())
		{
			const int32 IndexOfOldTeam = TeamIds.Find(OldTeamId);
			const int32 IndexToUse = (IndexOfOldTeam + 1) % TeamIds.Num();

			const int32 NewTeamId = TeamIds[IndexToUse];

			TeamSubsystem->ChangeTeamForActor(PC, NewTeamId);
		}

		const int32 ActualNewTeamId = TeamSubsystem->FindTeamFromObject(PC);

		UE_LOG(LogConsoleResponse, Log, TEXT("Changed to team %d (from team %d)"), ActualNewTeamId, OldTeamId);
	}
}

// 把当前玩家移动到指定的队伍
void UTenkaichiTeamCheats::SetTeam(int32 TeamID)
{
	if (UTenkaichiTeamSubsystem* TeamSubsystem = UWorld::GetSubsystem<UTenkaichiTeamSubsystem>(GetWorld()))
	{
		if (TeamSubsystem->DoesTeamExist(TeamID))
		{
			APlayerController* PC = GetPlayerController();

			TeamSubsystem->ChangeTeamForActor(PC, TeamID);
		}
	}
}

// 打印所有队伍的列表
void UTenkaichiTeamCheats::ListTeams()
{
	if (UTenkaichiTeamSubsystem* TeamSubsystem = UWorld::GetSubsystem<UTenkaichiTeamSubsystem>(GetWorld()))
	{
		const TArray<int32> TeamIDs = TeamSubsystem->GetTeamIDs();

		for (const int32 TeamID : TeamIDs)
		{
			UE_LOG(LogConsoleResponse, Log, TEXT("Team ID %d"), TeamID);
		}
	}
}
```

## 四、逐段讲解

### 4.1 include 区（第 1~11 行）


| include | 给谁用 |
|---------|--------|
| `TenkaichiTeamCheats.h` | 自身（**永远第一个**，UE 约定） |
| `Engine/World.h` | `UWorld::GetSubsystem<>` 静态方法 |
| `GameFramework/PlayerController.h` | `APlayerController` 类型（`GetPlayerController()` 返回值） |
| `HAL/IConsoleManager.h` | ★ **`LogConsoleResponse` 日志分类的定义**。漏了这个会编译报"未声明的标识符" |
| `Teams/TenkaichiTeamSubsystem.h` | 核心依赖（P07.6，**已落盘**） |
| `UE_INLINE_GENERATED_CPP_BY_NAME(...)` | UHT 的 IWYU 优化宏，展开成本文件的 `.gen.cpp`。**参数填类名不带前缀后缀**（`TenkaichiTeamCheats`，不是 `UTenkaichiTeamCheats`） |

> 📌 **Lyra 的 include 顺序习惯**：自身头 → 空一行 → 引擎头（按字母序）→ 空一行 → `UE_INLINE_GENERATED_CPP_BY_NAME`。
> 本文件没有项目内其他依赖，所以引擎头之后直接就是 TeamSubsystem。

### 4.2 `GetPlayerController()` 从哪来的（重点）

```cpp
APlayerController* PC = GetPlayerController();
```

**它不在本类里声明** —— 来自基类 `UCheatManagerExtension`（引擎 `CheatManager.h`）。

> 教学分级：这是**引擎底层接口（① 只讲不拆）**——引擎自带，我们不用新建。
> 只需知道：**作弊扩展里想操作"当前玩家"，就调 `GetPlayerController()`**，不用自己存指针、不用从 World 里找。

### 4.3 `CycleTeam()`（第 17~40 行）

```cpp
if (UTenkaichiTeamSubsystem* TeamSubsystem = UWorld::GetSubsystem<UTenkaichiTeamSubsystem>(GetWorld()))
```

**这是 Lyra 的标准 pattern**：`if` 里直接声明 + 初始化，判空和取对象一步完成。
子系统可能还没创建（`GetWorld()` 也可能为 null），所以**必须判空**。

```cpp
const int32 OldTeamId = TeamSubsystem->FindTeamFromObject(PC);
const TArray<int32> TeamIds = TeamSubsystem->GetTeamIDs();
```

| 调用 | 返回 |
|------|------|
| `FindTeamFromObject(PC)` | 这个 PC 现在几队（没队返回 `INDEX_NONE`） |
| `GetTeamIDs()` | 所有存在的队伍 ID 数组 |

```cpp
const int32 IndexOfOldTeam = TeamIds.Find(OldTeamId);
const int32 IndexToUse = (IndexOfOldTeam + 1) % TeamIds.Num();
const int32 NewTeamId = TeamIds[IndexToUse];
TeamSubsystem->ChangeTeamForActor(PC, NewTeamId);
```

**绕回逻辑就靠一个 `%`（取模）**：

```
假设队伍是 [1, 2, 3]
当前在 3 队 → IndexOfOldTeam = 2
IndexToUse = (2 + 1) % 3 = 0  → 回到 TeamIds[0] = 1 队 ✅ 绕回
```

> ⚠️ **边界情况**：如果 `OldTeamId` 不在列表里（比如 `INDEX_NONE`），`Find` 返回 `INDEX_NONE` = `-1`，
> 那 `(-1 + 1) % 3 = 0` → 换到第 0 个队。**Lyra 没处理这个情况**，照抄即可（不算 bug，只是落到第一个队）。

```cpp
const int32 ActualNewTeamId = TeamSubsystem->FindTeamFromObject(PC);
UE_LOG(LogConsoleResponse, Log, TEXT("Changed to team %d (from team %d)"), ActualNewTeamId, OldTeamId);
```

⭐ **为什么换完要再查一次？**
因为 `ChangeTeamForActor` **不保证成功**（可能 Actor 不支持换队）。Lyra 选择**换完再查真实结果**来回显，而不是假设成功。
这是很严谨的写法——你自己写"改完就打日志"的代码，容易骗自己。

### 4.4 `SetTeam(TeamID)`（第 42~53 行）

```cpp
if (TeamSubsystem->DoesTeamExist(TeamID))
{
    APlayerController* PC = GetPlayerController();
    TeamSubsystem->ChangeTeamForActor(PC, TeamID);
}
```

**比 `CycleTeam` 更简单**：

| 步骤 | 说明 |
|------|------|
| ① 取子系统判空 | 同 `CycleTeam` |
| ② `DoesTeamExist(TeamID)` | ⭐ **先验证队存在**，不存在就什么都不做（**不打日志、不报错**） |
| ③ 换过去 | — |

> 📌 **注意**：这里**没有** `UE_LOG`。Lyra 对"非法输入"选择静默忽略。
> 对比 `CycleTeam` 有回显——因为它是"我帮你选"，要告诉你选了啥；`SetTeam` 是"你自己指定"，不需要回显。

### 4.5 `ListTeams()`（第 55~66 行）

```cpp
const TArray<int32> TeamIDs = TeamSubsystem->GetTeamIDs();

for (const int32 TeamID : TeamIDs)
{
    UE_LOG(LogConsoleResponse, Log, TEXT("Team ID %d"), TeamID);
}
```

最简单的一个：**取列表 → 逐个打印**。

> ⚠️ **注意**：这里没有 `GetPlayerController()`，因为打印的是**全局**队伍列表，跟"当前玩家"无关。
> 这也是它 `.h` 里**不加 `BlueprintAuthorityOnly`** 的原因——不改状态、不针对特定玩家。

### 4.6 两个易混点（本节重点）

#### ① `UWorld::GetSubsystem` vs `World->GetSubsystem`

| 写法 | 用在哪 |
|------|--------|
| `UWorld::GetSubsystem<UTeamSubsystem>(GetWorld())` | **本文件**（静态版本，World 可为 null） |
| `World->GetSubsystem<UTeamSubsystem>()` | `TeamStatics.cpp` / `TeamInfoBase.cpp`（成员版本） |

两者等价，Lyra 在本文件用的是**静态版本**。照抄即可，别"顺手统一"。

#### ② `LogConsoleResponse` vs `LogTenkaichiTeams`

| 分类 | 来源 | 用途 |
|------|------|------|
| `LogConsoleResponse` | **引擎内置**（`HAL/IConsoleManager.h`） | **回显给用户**——敲了命令，控制台能看到结果 |
| `LogTenkaichiTeams` | 项目自定义（第 0 步 LogChannels） | **开发日志**——调试用，玩家看不到 |

> 判断口诀：**"这条信息是要给敲命令的人看的吗？"** 是 → `LogConsoleResponse`；不是 → 项目日志。

	bIsPartOfTeam = false;

## 二、逐块讲解（先讲"为什么"再讲"是什么"）

### 块 1：`FindTeamFromObject`

**为什么 + 是什么**：蓝图调这个入口，拿"对象属于哪队 + 是否在队 + 外观资产"。实现是**两段式取世界**：
1. `GEngine->GetWorldFromContextObject(Agent, ...)` —— 从 Agent 拿到 `UWorld`
2. `World->GetSubsystem<UTenkaichiTeamSubsystem>()` —— 拿到队伍子系统

拿到子系统后：`FindTeamFromObject(Agent)` 查队号 → 队号有效则 `bIsPartOfTeam=true` + 查外观资产；外观资产为空且开了 `bLogIfNotSet` → 打日志（说明"查太早了，体验还没就绪"）。子系统不存在 → Error 日志。⚠️ 依赖 TeamSubsystem 实现（挂起）。

### 块 2：`GetTeamDisplayAsset`

**为什么 + 是什么**：纯查外观资产（`WorldContextObject` 拿世界 → GetSubsystem → `GetTeamDisplayAsset(TeamId, INDEX_NONE)`）。没世界/没子系统 → 返回 `Result`（nullptr）。

### 块 3~5：三个 `WithFallback`

**为什么 + 是什么**：三个函数**结构完全一样**，只是类型不同：
- `DisplayAsset->ScalarParameters.Find(ParameterName)` → 找到返回 `*pValue`，找不到返回 `DefaultValue`
- `ColorParameters` → `FLinearColor`；`TextureParameters` → `TObjectPtr<UTexture>`

`Find` 返回指针，`*pValue` 解引用取值——这就是"WithFallback（带默认值兜底）"的实现。**无子系统依赖，纯数据操作**。

```cpp
#include "Teams/TenkaichiTeamAgentInterface.h"

#include "TenkaichiLogChannels.h"
#include "UObject/ScriptInterface.h"

#include UE_INLINE_GENERATED_CPP_BY_NAME(TenkaichiTeamAgentInterface)

// 构造函数：交给父类（UGenericTeamAgentInterface）做初始化
UTenkaichiTeamAgentInterface::UTenkaichiTeamAgentInterface(const FObjectInitializer& ObjectInitializer)
	: Super(ObjectInitializer)
{
}

// 静态工具：判断队伍真的变了，才广播"队伍变更"委托给所有监听者
void ITenkaichiTeamAgentInterface::ConditionalBroadcastTeamChanged(TScriptInterface<ITenkaichiTeamAgentInterface> This, FGenericTeamId OldTeamID, FGenericTeamId NewTeamID)
{
	if (OldTeamID != NewTeamID)
	{
		// 把引擎队伍ID转成普通整数（没队伍就是 INDEX_NONE）
		const int32 OldTeamIndex = GenericTeamIdToInteger(OldTeamID); 
		const int32 NewTeamIndex = GenericTeamIdToInteger(NewTeamID);

		// 拿到实际的对象（比如某个角色），打日志用
		UObject* ThisObj = This.GetObject();
		UE_LOG(LogTenkaichiTeams, Verbose, TEXT("[%s] %s assigned team %d"), *GetClientServerContextString(ThisObj), *GetPathNameSafe(ThisObj), NewTeamIndex);

		// 拿到"队伍变更委托"并广播：告诉监听者"谁、从旧队、到新队"
		This.GetInterface()->GetTeamChangedDelegateChecked().Broadcast(ThisObj, OldTeamIndex, NewTeamIndex);
	}
}
```

## 二、逐段讲解（先讲"为什么"再讲"是什么"）

### 1. `#include UE_INLINE_GENERATED_CPP_BY_NAME(TenkaichiTeamAgentInterface)`

- 这是 UE 的**自动生成代码**宏。你写了 `GENERATED_UINTERFACE_BODY()` / `GENERATED_IINTERFACE_BODY()` 后，
  引擎的 UHT（Unreal Header Tool）会在构建时自动生成一个 `TenkaichiTeamAgentInterface.gen.cpp`，
  里面包含 RTTI、反射、序列化等底层实现。
- **为什么 `.cpp` 里必须写这一行**：它把那个生成的实现"拉"进本编译单元，否则链接会报缺符号。

### 2. 构造函数（空的，交给父类）

```cpp
UTenkaichiTeamAgentInterface::UTenkaichiTeamAgentInterface(const FObjectInitializer& ObjectInitializer)
	: Super(ObjectInitializer)
{
}
```

- 每个 `UINTERFACE` 的 U 壳类都要有构造函数，把初始化交给 `UGenericTeamAgentInterface`（父类）。
- 函数体是空的，因为接口本身不需要任何实例数据——它只是个"契约"。

### 3. `ConditionalBroadcastTeamChanged`（核心）

这是接口的**静态工具函数**，`This` 不是调用它的对象，而是**被当作参数传进来的队伍代理对象**。

逻辑三步：

1. **判断队伍是否真的变了**：`if (OldTeamID != NewTeamID)`
   → 只有确实换了队才广播，避免无意义刷新（比如 UI 反复刷同队）。

2. **转整数 + 打日志**：
   - `GenericTeamIdToInteger(...)` 把引擎队伍 ID 转成普通 int（没队伍 = `INDEX_NONE`）。
   - `UE_LOG(LogTenkaichiTeams, Verbose, ...)` 用 **Verbose** 级别记录"XX 被分到了第 N 队"。
   - `GetClientServerContextString(ThisObj)`：显示这个对象在服务器还是客户端（网络调试用）。

3. **广播委托**：
   ```cpp
   This.GetInterface()->GetTeamChangedDelegateChecked().Broadcast(ThisObj, OldTeamIndex, NewTeamIndex);
   ```
   - `GetInterface()`：从 `TScriptInterface` 拿到真正的 `ITenkaichiTeamAgentInterface*`。
   - `GetTeamChangedDelegateChecked()`：取"队伍变更委托"并断言非空（实现类必须覆写了 `GetOnTeamIndexChangedDelegate`）。
   - `.Broadcast(ThisObj, OldTeamIndex, NewTeamIndex)`：广播给所有监听者 → 谁换队、旧队、新队。

> 注意 `TScriptInterface` 的两种取法：
> - `This.GetObject()` → 返回 `UObject*`（拿对象本体）
> - `This.GetInterface()` → 返回 `ITenkaichiTeamAgentInterface*`（拿接口逻辑）

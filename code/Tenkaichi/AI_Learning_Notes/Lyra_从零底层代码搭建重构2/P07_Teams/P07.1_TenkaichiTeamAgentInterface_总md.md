# 4.1 TeamAgentInterface —— 总 md

## 一、为什么要有这一节

阶段四先讲 `TeamAgentInterface`（团队代理接口）。它是 **Teams（队伍/阵营）体系的地基接口**。

在多人对战游戏里，需要区分"谁在红队、谁在蓝队、队友/敌人"。Lyra 把所有"能属于某个队伍的对象"（角色、玩家状态、Pawn）
统一抽象成一个接口：**只要实现了 `TeamAgentInterface`，就能回答"我是哪队的"。**

它被 `PlayerState`、`Character`、`Pawn` 等角色类实现（阶段四后半段会看到）。

## 二、本文件里有什么（全景）

`TeamAgentInterface` 是**接口类**（`UINTERFACE`），不是一个能实例化的具体类。它包含：

### 1. 一个多播委托（队伍变更通知）

```cpp
DECLARE_DYNAMIC_MULTICAST_DELEGATE_ThreeParams(
	FOnTenkaichiTeamIndexChangedDelegate,
	UObject*, ObjectChangingTeam,   // 谁换了队伍
	int32, OldTeamID,               // 旧队伍
	int32, NewTeamID);              // 新队伍
```

任何"队伍变了"的对象都能通过这个委托通知外界（比如 UI 刷新阵营颜色）。

### 2. 两个内联转换函数（FGenericTeamId ↔ int）

```cpp
inline int32 GenericTeamIdToInteger(FGenericTeamId ID);   // 队伍ID → int（无队伍返回 INDEX_NONE）
inline FGenericTeamId IntegerToGenericTeamId(int32 ID);   // int → 队伍ID（INDEX_NONE 返回 NoTeam）
```

引擎的 `FGenericTeamId` 内部本质是个 `uint8`，Lyra 用这两个工具函数在"引擎队伍类型"和"普通 int"之间互转。

### 3. 接口本身（继承引擎的 `IGenericTeamAgentInterface`）

```cpp
UINTERFACE(MinimalAPI, meta=(CannotImplementInterfaceInBlueprint))
class UTenkaichiTeamAgentInterface : public UGenericTeamAgentInterface { ... };

class ITenkaichiTeamAgentInterface : public IGenericTeamAgentInterface
{
	virtual FOnTenkaichiTeamIndexChangedDelegate* GetOnTeamIndexChangedDelegate() { return nullptr; }
	static void ConditionalBroadcastTeamChanged(TScriptInterface<ITenkaichiTeamAgentInterface> This, FGenericTeamId OldTeamID, FGenericTeamId NewTeamID);
	...
};
```

- **继承引擎的 `UGenericTeamAgentInterface`**：所以它自动拥有了引擎提供的 `SetGenericTeamId` / `GetGenericTeamId` 等队伍查询接口。
- `GetOnTeamIndexChangedDelegate()`：返回"队伍变更委托"的指针（默认 `nullptr`，由实现类覆写）。
- `ConditionalBroadcastTeamChanged(...)`：**静态工具函数**，判断队伍确实变了，才广播变更委托。

## 四、一个要重点理解的机制：`UE_API` 宏 + `#define UE_API`

```cpp
#define UE_API LYRAGAME_API
...
class ULyraTeamAgentInterface ...
#undef UE_API
```

- 这是 Lyra 的**局部 API 宏重定义**：临时把 `UE_API` 定义成 `LYRAGAME_API`（本模块的导出宏），
  声明完成后 `#undef` 还原。目的是让这个接口的符号带本模块的 DLL 导出属性，又不污染全局。
- 你的工程里对应 `TENKAICHIGAME_API`（已定义在模块入口/LogChannels 里）。

## 一、这个类解决什么问题

P09 教了 `UTenkaichiEquipmentInstance`（装备实例）——"把一件物品穿在身上"。但装备是通用的（衣服、鞋子、武器都能当装备）。

**武器不一样**：武器有"开火时间、上次装备时间、手柄震动"这些武器专属的东西。

`UTenkaichiWeaponInstance` 就是**武器实例基类**：它继承装备实例，在装备的基础上加了一层"武器专属数据"。

一句话：**武器 = 一种特殊的装备**，`UTenkaichiWeaponInstance` 把"武器该有的记录"补上。

## 二、全景：这个类里有什么

| 成员 | 类型 | 作用 |
|------|------|------|
| `OnEquipped()` / `OnUnequipped()` | 覆写 | 装备/卸下时记录时间 + 应用/移除手柄震动 |
| `UpdateFiringTime()` | BlueprintCallable | 开火时调用，记录开火时间 |
| `GetTimeSinceLastInteractedWith()` | BlueprintPure | 距上次"开火或装备"过了多久（决定武器是否可切） |
| `EquippedAnimSet` / `UneuippedAnimSet` | 属性 | 装备/卸下时的动画层选择集 |
| `ApplicableDeviceProperties` | 属性 | 装备期间要应用的手柄震动属性 |
| `PickBestAnimLayer()` | BlueprintCallable | 按 GameplayTags 选最佳动画层 |
| `GetOwningUserId()` | BlueprintCallable | 取拥有者的平台用户 ID |
| `OnDeathStarted()` | 回调 | 宿主死亡时移除手柄震动 |
| `ApplyDeviceProperties()` / `RemoveDeviceProperties()` | 内部 | 应用/移除手柄震动 |

核心逻辑就两类：
1. **记录时间**（开火/装备），供"武器切换冷却"判断。
2. **手柄震动**（`ApplicableDeviceProperties`），装备时震动、卸下/死亡时停止。

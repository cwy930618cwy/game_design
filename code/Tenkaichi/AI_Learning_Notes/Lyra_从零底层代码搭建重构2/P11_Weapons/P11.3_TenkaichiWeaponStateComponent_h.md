## 一、本文件要解决什么

定义"武器状态组件"这个类：继承**引擎的 `UControllerComponent`**（挂在控制器上，不是 Pawn！）。它负责：
1. 每帧找到玩家手上那件**远程武器**，调用它的 `Tick()`（让散布/热量持续演化）。
2. 管理**命中反馈**：把服务器确认的命中位置换算成**屏幕坐标**，推给客户端画准星红/白点。

`.h` 里还定义了 2 个配套结构体：
- `FTenkaichiScreenSpaceHitLocation`：单次命中的屏幕坐标 + 命中部位标签 + 是否算"成功命中"。
- `FTenkaichiServerSideHitMarkerBatch`：一批待确认的命中标记（服务器确认后批量下发），带唯一 `UniqueId` 用于对账。

> ✅ **本 `.h` 零挂起点**：只依赖引擎的 `UControllerComponent` 和 `FGameplayTag`，可直接完整编译。

## 二、完整代码（`.h`，已替换前缀 + 注释中文化）

```cpp
// 版权声明（Lyra 项目自带，保留）
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "Components/ControllerComponent.h"
#include "GameplayTagContainer.h"

#include "TenkaichiWeaponStateComponent.generated.h"

class UObject;
struct FFrame;
struct FGameplayAbilityTargetDataHandle;
struct FGameplayEffectContextHandle;
struct FHitResult;

// 命中标记会显示在准星上，用来提示远程武器打中了哪里
// '成功的'命中标记 = 打中了敌人并造成伤害
struct FTenkaichiScreenSpaceHitLocation
{
	/** 命中点在视口上的屏幕坐标 */
	FVector2D Location;
	FGameplayTag HitZone;
	bool bShowAsSuccess = false;
};

struct FTenkaichiServerSideHitMarkerBatch
{
	FTenkaichiServerSideHitMarkerBatch() { }

	FTenkaichiServerSideHitMarkerBatch(uint16 InUniqueId) :
		UniqueId(InUniqueId)
	{ }

	TArray<FTenkaichiScreenSpaceHitLocation> Markers;

	uint16 UniqueId = 0;
};

// 追踪武器状态和最近确认的命中标记，用来在屏幕上显示
UCLASS()
class UTenkaichiWeaponStateComponent : public UControllerComponent
{
	GENERATED_BODY()

public:

	UTenkaichiWeaponStateComponent(const FObjectInitializer& ObjectInitializer = FObjectInitializer::Get());

	virtual void TickComponent(float DeltaTime, enum ELevelTick TickType, FActorComponentTickFunction* ThisTickFunction) override;

	UFUNCTION(Client, Reliable)
	void ClientConfirmTargetData(uint16 UniqueId, bool bSuccess, const TArray<uint8>& HitReplaces);

	void AddUnconfirmedServerSideHitMarkers(const FGameplayAbilityTargetDataHandle& InTargetData, const TArray<FHitResult>& FoundHits);

	/** 更新这个玩家最近一次打出伤害的时间 */
	void UpdateDamageInstigatedTime(const FGameplayEffectContextHandle& EffectContext);

	/** 获取这个玩家最近打出的伤害所在的屏幕坐标（用于准星命中提示） */
	void GetLastWeaponDamageScreenLocations(TArray<FTenkaichiScreenSpaceHitLocation>& WeaponDamageScreenLocations)
	{
		WeaponDamageScreenLocations = LastWeaponDamageScreenLocations;
	}

	/** 返回距最近一次"命中伤害"通知过了多久 */
	double GetTimeSinceLastHitNotification() const;

	/** 返回还有多少个"服务器还没确认"的命中标记 */
	int32 GetUnconfirmedServerSideHitMarkerCount() const
	{
		return UnconfirmedServerSideHitMarkers.Num();
	}

protected:
	// 过滤命中结果，决定这次命中是否算"成功命中"
	// 默认行为：打中了与拥有者控制器 Pawn 不同队伍的角色就算成功
	virtual bool ShouldShowHitAsSuccess(const FHitResult& Hit) const;

	virtual bool ShouldUpdateDamageInstigatedTime(const FGameplayEffectContextHandle& EffectContext) const;

	void ActuallyUpdateDamageInstigatedTime();

private:
	/** 这个控制器最近一次造成武器伤害的时刻 */
	double LastWeaponDamageInstigatedTime = 0.0;

	/** 我们最近造成的武器伤害所在的屏幕坐标（已确认的命中） */
	TArray<FTenkaichiScreenSpaceHitLocation> LastWeaponDamageScreenLocations;

	/** 还没被服务器确认的命中标记 */
	TArray<FTenkaichiServerSideHitMarkerBatch> UnconfirmedServerSideHitMarkers;
};
```

> 与 Lyra 原文件只差前缀：`ULyraWeaponStateComponent`→`UTenkaichiWeaponStateComponent`、`FLyraScreenSpaceHitLocation`→`FTenkaichiScreenSpaceHitLocation`、`FLyraServerSideHitMarkerBatch`→`FTenkaichiServerSideHitMarkerBatch`、`LyraWeaponStateComponent.generated.h`→`TenkaichiWeaponStateComponent.generated.h`。代码块里已是替换后的最终版，直接照抄即可。

## 三、逐段讲解

### 1. include

```cpp
#include "Components/ControllerComponent.h"
#include "GameplayTagContainer.h"
```

- `Components/ControllerComponent.h`：父类 `UControllerComponent`（引擎）。**它是"控制器组件"**，挂在 Controller 上，跟着控制器生命周期走——这是它和 P09/P11 那些挂在 Pawn 上的组件的最大区别。
- `GameplayTagContainer.h`：`FGameplayTag`（命中部位标签，如"头部/躯干"）。

### 2. 前置声明

```cpp
class UObject;
struct FFrame;
struct FGameplayAbilityTargetDataHandle;
struct FGameplayEffectContextHandle;
struct FHitResult;
```

- 前 4 个是引擎/UFUNCTION 宏展开需要的（RPC 编译要求）。
- `FGameplayAbilityTargetDataHandle`（P05 GAS）和 `FGameplayEffectContextHandle`（P05 GAS）是**前置声明**——`.h` 里只用指针/引用，不需要完整定义，cpp 里才 include。

### 3. 两个结构体

```cpp
struct FTenkaichiScreenSpaceHitLocation
{
	FVector2D Location;
	FGameplayTag HitZone;
	bool bShowAsSuccess = false;
};
```

- `Location`：命中点换算成**屏幕坐标**（视口像素位置，准星 UI 直接画点）。
- `HitTag`：命中部位标签（从被击中物的物理材质读出来，如"头部"）。
- `bShowAsSuccess`：是否算"成功命中"（打中敌人=成功，打中墙壁=失败）。

```cpp
struct FTenkaichiServerSideHitMarkerBatch
{
	FTenkaichiServerSideHitMarkerBatch() { }
	FTenkaichiServerSideHitMarkerBatch(uint16 InUniqueId) : UniqueId(InUniqueId) { }
	TArray<FTenkaichiScreenSpaceHitLocation> Markers;
	uint16 UniqueId = 0;
};
```

- 这是**一批**命中标记（一次射击可能弹道命中多个点）。
- `UniqueId`：唯一编号，服务器确认时靠它**对账**（客户端发的批次和服务器回的批次一一对应）。
- 两个构造函数：默认 + 带 `UniqueId` 初始化。

### 4. 类标记与继承

```cpp
UCLASS()
class UTenkaichiWeaponStateComponent : public UControllerComponent
```

- 继承 **`UControllerComponent`**——组件挂控制器，随玩家登录/控制切换而存在。
- `UCLASS()`：注意这里**没有** `MinimalAPI`（不像 P11.1 的 `UTenkaichiWeaponInstance`），因为它不需要被外部模块直接调用，走的是引擎组件机制。

### 5. 构造函数

```cpp
UTenkaichiWeaponStateComponent(const FObjectInitializer& ObjectInitializer = FObjectInitializer::Get());
```

- 带默认 `FObjectInitializer`，允许无参构造。
- `.cpp` 里会：开启复制（`SetIsReplicatedByDefault(true)`）、开启 Tick。

### 6. Tick 覆写

```cpp
virtual void TickComponent(float DeltaTime, enum ELevelTick TickType, FActorComponentTickFunction* ThisTickFunction) override;
```

- 组件每帧回调。`.cpp` 里：找到手上远程武器 → 调它的 `Tick(DeltaTime)`。
- 注意签名里 `enum ELevelTick TickType` —— 这是引擎 Tick 的标准三参签名。

### 7. RPC：ClientConfirmTargetData

```cpp
UFUNCTION(Client, Reliable)
void ClientConfirmTargetData(uint16 UniqueId, bool bServer, const TArray<uint8>& HitReplaces);
```

- **这是本项目第一个 RPC 网络同步**：
  - `Client`：这个函数在**客户端**执行（服务器调用它）。
  - `Reliable`：可靠投递，服务器保证客户端收到（命中反馈必须可靠，不能丢包）。
  - `bServer` 参数名：表示"这批命中是否被服务器判定成功"。真正的实现体在 `.cpp` 用 `_Implementation` 后缀写。
- `HitReplaces`：服务器告诉客户端"哪些命中点要换成命中标记"（按命中序号）。

### 8. 添加待确认命中标记

```cpp
void AddUnconfirmedServerSideHitMarkers(const FGameplayAbilityTargetDataHandle& InTargetData, const TArray<FHitResult>& FoundHits);
```

- 玩家射击命中后，本地先把这批命中记录到 `UnconfirmedServerSideHitMarkers`（带屏幕坐标 + 部位标签 + 是否成功）。
- `.cpp` 里会：取 `InTargetData.UniqueId` 作为批次号，遍历 `FoundHits` 把每个命中点投影到屏幕坐标。

### 9. 更新"最近伤害时间"

```cpp
void UpdateDamageInstigatedTime(const FGameplayEffectContextHandle& EffectContext);

protected:
virtual bool ShouldUpdateDamageInstigatedTime(const FGameplayEffectContextHandle& EffectContext) const;
void ActuallyUpdateDamageInstigatedTime();
```

- `UpdateDamageInstigatedTime`：公开入口，外部在造成伤害时调用。
- `ShouldUpdateDamageInstigatedTime`：**虚函数**——过滤"这次伤害算不算武器伤害"（默认：只要 `EffectContext` 有施害者就算）。
- `ActuallyUpdateDamageInstigatedTime`：真正更新时间戳 + 清空过期屏幕坐标（>0.1秒 的旧命中清掉）。

### 10. 查询接口

```cpp
void GetLastWeaponDamageScreenLocations(TArray<FTenkaichiScreenSpaceHitLocation>& WeaponDamageScreenLocations)
{
	WeaponDamageScreenLocations = LastWeaponDamageScreenLocations;
}

double GetLastTimeSinceHitNotification() const;
int32 GetUnconfirmedServerSideHitMarkerCount() const
{
	return UnconfirmedServerSideHitMarkers.Num();
}
```

- `GetLastWeaponDamageScreenLocations`：准星 UI 调它取"最近成功命中位置"画红点/白点。
- `GetTimeSinceLastHitNotification`：距最近一次命中提示过了多久（UI 用它做命中动画/消失）。
- `GetUnconfirmedServerSideHitMarkerCount`：待确认命中数（客户端可能在等服务器确认）。

### 11. 私有字段

```cpp
double LastWeaponDamageInstigatedTime = 0.0;
TArray<FTenkaichiScreenSpaceHitLocation> LastWeaponDamageScreenLocations;
TArray<FTenkaichiServerSideHitMarkerBatch> UnconfirmedServerSideHitMarkers;
```

- 三个都是运行时状态（不需要 `UPROPERTY` 序列化）：
  - 最近伤害时刻（double 世界时间）
  - 已确认的命中屏幕坐标列表
  - 待确认的命中批次队列

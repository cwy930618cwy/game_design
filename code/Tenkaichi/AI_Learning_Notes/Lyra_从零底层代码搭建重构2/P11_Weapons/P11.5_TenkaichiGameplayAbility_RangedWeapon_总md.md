## 一、这个类解决什么问题

P11.1~P11.4 已经把"枪"（武器实例）和"枪怎么算准"（散布/热量/衰减）、"枪打到哪"（命中反馈）都讲完了。但还差最关键的一步：**玩家扣扳机，怎么真的开枪？**

`UTenkaichiGameplayAbility_RangedWeapon` 就是**"开枪"这个技能本身**。它是一个 GAS 技能（继承 P09 的 `GameplayAbility_FromEquipment`），负责把"瞄准 → 射线追踪 → 目标选取 → 开火"整条链路打通：

1. **扣扳机触发**：当玩家按开火键，这个技能被激活（`ActivateAbility`）。
2. **射线追踪**：从镜头/枪口沿准星方向打一条射线，找出打中了谁（`PerformLocalTargeting` → `TraceBulletsInCartridge`）。
3. **目标选取**：把射线打中的结果封装成 GAS 的"目标数据"（`FGameplayAbilityTargetDataHandle`）。
4. **上报服务器**：客户端把瞄准结果同步给服务器确认（`OnTargetDataReadyCallback`），并驱动命中反馈（走 P11.3）。
5. **结算**：服务器确认后，调用蓝图接口 `OnRangedWeaponTargetDataReady`，让蓝图为所欲为（伤害、特效、声音…）。

> 一句话：**P11.2 是"枪"，P11.3 是"反馈"，P11.4 是"捡枪"，P11.5 是"开枪"。**

## 二、全景：这个类里有什么

### 一个内部结构体
| 结构体 | 作用 |
|--------|------|
| `FRangedWeaponFiringInput` | 一次开火的输入：射线起点 `StartTrace`、瞄准终点 `EndAim`、方向 `AimDir`、武器实例 `WeaponData`、能否播放弹道特效 `bCanPlayBulletFX` |

### 核心成员
| 成员 | 类型 | 作用 |
|------|------|------|
| 构造函数 | — | 把"禁止开火"标签（`Ability.Weapon.NoFiring`）加进 `SourceBlockedTags`，有该标签时技能无法激活 |
| `GetWeaponInstance()` | 方法 | 取关联的远程武器实例（`GetAssociatedEquipment()` 强转成 `ULyraRangedWeaponInstance`） |
| `CanActivateAbility()` | 覆写 | 校验：必须有远程武器实例才能开火，否则报错 |
| `ActivateAbility()` | 覆写 | 绑定"目标数据就绪"回调 → 更新武器开火时间 → 真正激活 |
| `EndAbility()` | 覆写 | 解绑回调、清掉已消费的目标数据 |
| `PerformLocalTargeting()` | 方法 | 本地射线追踪：算射线起点/方向/终点，打出一串命中结果 |
| `TraceBulletsInCartridge()` | 方法 | 按"每弹夹子弹数"循环，每颗子弹算散布角再单独打射线 |
| `DoSingleBulletTrace()` | 方法 | 单颗子弹：先尝试射线，打空再回退到"球体扫描" |
| `WeaponTrace()` | 方法 | 真正调用物理引擎打射线/扫描，去重命中 |
| `FindFirstPawnHitResult()` | 静态 | 在一堆命中里找第一个命中 Pawn（或其挂载物）的索引 |
| `GetWeaponTargetingSourceLocation()` | 方法 | 取枪口/角色的发射点（当前简单取 Pawn 位置） |
| `GetTargetingTransform()` | 方法 | 按 5 种瞄准模式算射线起点+朝向 |
| `OnTargetDataReadyCallback()` | 回调 | 目标数据就绪：上报服务器 + 提交技能 + 触发蓝图接口 |
| `StartRangedWeaponTargeting()` | 蓝图可调 | 触发一次"瞄准→射线→回调"完整链路 |

### 瞄准模式枚举 `ELyraAbilityTargetingSource`
| 值 | 含义 |
|----|------|
| `CameraTowardsFocus` | 从镜头朝"焦点"打（默认，FPS 手感） |
| `PawnForward` | 从 Pawn 中心朝 Pawn 朝向 |
| `PawnTowardsFocus` | 从 Pawn 中心朝焦点 |
| `WeaponForward` | 从枪口沿 Pawn 朝向 |
| `WeaponTowardsFocus` | 从枪口朝焦点 |
| `Custom` | 蓝图自定义（需蓝图单独处理起点） |

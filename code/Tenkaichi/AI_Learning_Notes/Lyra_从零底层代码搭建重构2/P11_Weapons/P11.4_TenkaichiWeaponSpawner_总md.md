## 一、这个类解决什么问题

P11.1~P11.3 讲了"武器是什么、枪怎么算准、命中怎么反馈"。但还有一个问题没解决：**地图上怎么摆一把枪让玩家捡？**

`ATenkaichiWeaponSpawner` 就是**武器生成器**：它是地图上的一个"武器刷新点"（一个柱子 + 一圈碰撞体 + 一把悬浮旋转的枪）。它负责：

1. **展示**：地上摆一把悬浮旋转的枪（`WeaponMesh`）+ 底座（`PadMesh`）。
2. **拾取**：玩家走进碰撞范围 → 自动触发拾取 → 调 P09 的"拾取逻辑"把枪发给玩家。
3. **冷却重生**：枪被捡走后隐藏 → 计时（`CoolDownTime`）→ 到时重新显示 + 播放重生特效。
4. **联网同步**：谁捡走了、什么时候重生，靠 `bIsWeaponAvailable` 属性复制同步给所有客户端。

> 一句话：**P11.4 是"地图上的武器补给点"**——放枪、捡枪、重生，全自动。

## 二、全景：这个类里有什么

### 继承与结构
- 继承 **`AActor`**（普通场景 Actor，不是 Pawn/Character）。
- 用 `CreateDefaultSubobject` 搭三个组件：
  | 组件 | 类型 | 作用 |
  |------|------|------|
  | `CollisionVolume` | `UCapsuleComponent` | 碰撞范围（根组件），玩家走进就触发拾取 |
  | `PadMesh` | `UStaticMeshComponent` | 底座（地面圆盘） |
  | `WeaponMesh` | `UStaticMeshComponent` | 悬浮旋转的枪模型 |

### 核心数据
| 成员 | 类型 | 作用 |
|------|------|------|
| `WeaponDefinition` | `TObjectPtr<ULyraWeaponPickupDefinition>` | 数据配置（DisplayMesh / PickedUpSound / SpawnCoolDownSeconds 等），P09.4 ✅ |
| `bIsWeaponAvailable` | `bool` | 枪现在可不可以捡（复制同步，`ReplicatedUsing`） |
| `CoolDownTime` | `float` | 重生冷却时间（秒） |
| `CheckExistingOverlapDelay` | `float` | 重生后延迟检测"是否有人站在上面" |
| `CoolDownPercentage` | `float` | 重生进度 0~1（驱动 UI 进度条） |
| `WeaponMeshRotationSpeed` | `float` | 枪旋转速度 |

### 方法一览
| 方法 | 作用 |
|------|------|
| `BeginPlay` / `EndPlay` / `Tick` | 生命周期：配置冷却、清理计时器、驱动进度 + 旋转 |
| `OnConstruction` | 编辑器里实时预览武器外观 |
| `OnOverlapBegin` | 碰撞回调：玩家走进 → 尝试拾取 |
| `CheckForExistingOverlaps` | 重生后检测"上面是否站着人" |
| `AttemptPickUpWeapon` | 核心：尝试把枪发给玩家（BlueprintNativeEvent） |
| `GiveWeapon` | 真正发枪（BlueprintImplementableEvent，蓝图实现） |
| `StartCoolDown` / `ResetCoolDown` / `OnCoolDownTimerComplete` | 冷却生命周期 |
| `SetWeaponPickupVisibility` | 显示/隐藏枪 |
| `PlayPickupEffects` / `PlayRespawnEffects` | 拾取/重生的音效 + 特效（BlueprintNativeEvent） |
| `GetDefaultStatFromItemDef` | 静态工具：从物品定义读武器属性 |

## 三、教学难点预读

1. **"生成器"不是"物品"**：它是个 `AActor` 场景对象，自己不带物品数据，只是拿 `WeaponDefinition`（P09.4 的拾取配置）当"说明书"。
2. **拾取是"事件驱动 + 蓝图可覆盖"**：
   - `AttemptPickUpWeapon` 是 `BlueprintNativeEvent`（C++ 提供默认实现，蓝图可覆盖）。
   - `GiveWeapon` 是 `BlueprintImplementableEvent`（纯蓝图实现，C++ 只声明不实现）。
3. **联网三件套**：`bIsWeaponAvailable` 复制 + `OnRep_WeaponAvailability` 回调 + `DOREPLIFETIME` 注册。
4. **重生进度条**：`CoolDownPercentage` 每帧按"剩余时间/总时间"计算，UI 直接绑定。
5. **编辑器预览**：`OnConstruction` 让设计师放枪时就能看到实际外观。

#pragma once

#include "Components/ActorComponent.h"
#include "GameFramework/GameplayMessageSubsystem.h"

#include "TenkaichiDamageLogDebuggerComponent.generated.h"

namespace EEndPlayReason { enum Type : int; }

class UObject;
struct FGameplayTag;
struct FTenkaichiVerbMessage;

// 单帧受击统计：把同一帧的多次受击合并成一条记录
struct FFrameDamageEntry
{
	int32 NumImpacts = 0;      // 这一帧被打了几次
	double SumDamage = 0.0;    // 这一帧累计的伤害值
	double TimeOfFirstHit = 0.0; // 这一帧第一次被打的时间点
};

UCLASS(Blueprintable, meta=(BlueprintSpawnableComponent))
class UTenkaichiDamageLogDebuggerComponent : public UActorComponent
{
	GENERATED_BODY()

public:

	// 构造函数：在 .cpp 里开启 Tick（PrimaryComponentTick.bCanEverTick = true）
	UTenkaichiDamageLogDebuggerComponent(const FObjectInitializer& ObjectInitializer = FObjectInitializer::Get());

	// 组件激活时调用：向消息总线注册"受伤"消息监听
	virtual void BeginPlay() override;

	// 组件结束/销毁时调用：反注册消息监听，防止内存泄漏
	virtual void EndPlay(const EEndPlayReason::Type EndPlayReason) override;

	// 每帧调用：检查距上次受击是否超过阈值，超时则汇总打印这一波伤害
	virtual void TickComponent(float DeltaTime, enum ELevelTick TickType, FActorComponentTickFunction* ThisTickFunction) override;

	// 可调参数：距离上次受伤超过该秒数，就结算一次伤害日志
	UPROPERTY(EditAnywhere)
	double SecondsBetweenDamageBeforeLogging = 1.0;

private:
	// 消息监听句柄：EndPlay 里用它反注册
	FGameplayMessageListenerHandle ListenerHandle;

	// 上一次受伤的时间点：Tick 里用它判断是否超时结算
	double LastDamageEntryTime = 0.0;

	// 帧号 → 该帧受击统计（按帧合并同一波伤害）
	TMap<int64, FFrameDamageEntry> DamageLog;

private:
	// 收到"受伤"消息时的回调：把伤害按帧记进 DamageLog
	void OnDamageMessage(FGameplayTag Channel, const FTenkaichiVerbMessage& Payload);
};

## 二、逐行讲解

### 1. 头文件依赖

```cpp
#include "Components/ActorComponent.h"
#include "GameFramework/GameplayMessageSubsystem.h"
```

| 头文件 | 提供什么 |
|--------|---------|
| `Components/ActorComponent.h` | 基类 `UActorComponent`（可挂到 Actor 上的组件） |
| `GameFramework/GameplayMessageSubsystem.h` | S1 插件的 `UGameplayMessageSubsystem` + `FGameplayMessageListenerHandle`（消息监听） |

### 2. 前置声明

```cpp
namespace EEndPlayReason { enum { : int; } }

class UObject;
struct FGameplayTag;
struct FTenkaichiVerbMessage;
```

| 声明 | 用途 |
|------|------|
| `namespace EEndPlayReason` | `EndPlay` 参数类型（前向声明，不用 include） |
| `class UObject;` | 通用对象（Lyra 原版保留） |
| `struct FGameplayTag;` | 消息频道参数（回调函数签名用） |
| `struct FTenkaichiVerbMessage;` | **P01 的** `FTenkaichiVerbMessage`（消息体，只传引用，前置声明够用） |

### 3. 核心数据结构 `FFrameDamageEntry`

```cpp
struct FFrameDamageEntry
{
	int32 NumImpacts = 0;      // 这一帧被打了几次
	double SumDamage = 0.0;    // 这一帧累计伤害
	double TimeOfFirstHit = 0.0; // 这一帧第一次被打的时间点
};
```

- **普通 struct**（不是 USTRUCT），因为它只是 `.h` 内部私有的临时数据结构，不需要反射、不需要蓝图暴露。
- **按"帧"分组**：同帧多段伤害（如霰弹枪）自动合并成一条记录。

### 4. 类声明

```cpp
UCLASS(Blueprintable, meta=(BlueprintSpawnableComponent))
class UTenkaichiDamageLogDebuggerComponent : public UActorComponent
{
	GENERATED_BODY()
```

| 部分 | 含义 |
|------|------|
| `UCLASS(Blueprintable, meta=(BlueprintSpawnableComponent))` | 可做蓝图类，且**可在蓝图里作为组件添加**到 Actor 上 |
| `: public UActorComponent` | 继承引擎组件基类 |
| `GENERATED_BODY()` | UHT 宏，必须有 |

### 5. 构造函数 + 三个生命周期方法

```cpp
UTenkaichiDamageLogDebuggerComponent(const FObjectInitializer& ObjectInitializer = FObjectInitializer::Get());

virtual void BeginPlay() override;
virtual void EndPlay(const EEndPlayReason::Type EndPlayReason) override;
virtual void TickComponent(float DeltaTime, enum ELevelTick TickType, FActorComponentTickFunction* ThisTickFunction) override;
```

| 方法 | 作用 |
|------|------|
| 构造函数 | `.cpp` 里开启 `PrimaryComponentTick.bCanEverTick = true`（让 Tick 生效） |
| `BeginPlay()` | 注册消息监听 `RegisterListener(...)` |
| `EndPlay()` | 反注册监听（防泄漏） |
| `TickComponent()` | 每帧检查"上次被打到现在是否超时"，超时则汇总打印 |

### 6. 可调参数

```cpp
UPROPERTY(EditAnywhere)
double SecondsDamageBetweenLogging = 1.0;
```

- **多少秒没被打**就触发汇总。默认 1 秒。
- `EditAnywhere` → 编辑器里每个组件实例可单独调。

### 7. 私有成员

```cpp
FGameplayMessageListenerHandle ListenerHandle;
double LastDamageEntryTime = 0.0;
TMap<int64, FFrameDamageEntry> DamageLog;
```

| 成员 | 作用 |
|------|------|
| `ListenerHandle` | 消息监听句柄，`EndPlay` 里用它反注册 |
| `LastDamageEntryTime` | 上次被打的时间点，Tick 里判断超时 |
| `DamageLog` | 帧号 → 该帧受击统计 的字典 |

### 8. 回调方法

```cpp
void OnDamageMessage(FGameplayTag Channel, const FTencentVerbMessage& Payload);
```

- **私有回调**，被 `BeginPlay` 里 `RegisterListener` 注册。
- 收到 `TAG_Tenkaichi_Damage_Message` 频道的消息时触发。
- `const FTenkaichiVerbMessage& Payload` → 消息体（含 `Target` 受伤对象、`Magnitude` 伤害值）。

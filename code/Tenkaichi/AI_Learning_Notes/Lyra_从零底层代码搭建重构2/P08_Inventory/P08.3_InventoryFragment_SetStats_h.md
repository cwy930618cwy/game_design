## 三、逐段讲解

### 1. include 与前置声明

```cpp
#include "GameplayTagContainer.h"
#include "Inventory/TenkaichiInventoryItemDefinition.h"
```

- `GameplayTagContainer.h`：`FGameplayTag` 的完整定义。因为 `.h` 里直接写 `TMap<FGameplayTag, int32>`（**不是指针/引用**），需要完整类型，所以**必须 include**（不是前置声明）。
- `TenkaichiInventoryItemDefinition.h`：因为**继承**自 `UTenkaichiInventoryItemFragment`（要 extends 它，必须知道它的完整定义），所以也要 include。

```cpp
class UTenkaichiInventoryItemInstance;
class UObject;
struct FGameplayTag;
```

- 这三个用**前置声明**就够：`OnInstanceCreated` 参数是 `UTenkaichiInventoryItemInstance*`（指针）、`GetItemByTag` 参数是 `FGameplayTag`（按值传，但只声明函数原型不需要完整定义）、`UObject*` 是继承链里的基类提醒。
- **指针参数 → 前置声明就够**（编译期只需知道这是个类型名，不需要 sizeof）。

### 2. 类声明

```cpp
class UInventoryFragment_SetStats : public UTenkaichiInventoryItemFragment
```

- 无 `Lyra` 前缀，**原名保持**。
- 继承 P08.1 的碎片基类，变成"有内容的真碎片"。

### 3. 初始属性表

```cpp
protected:
	UPROPERTY(EditDefaultsOnly, Category=Equipment)
	TMap<FGameplayTag, int32> InitialItemStats;
```

- `TMap<FGameplayTag, int32>`：**键是 Tag，值是数量**。例：`{Equipment.ClipAmmo : 30, Equipment.Durability : 100}`。
- `EditDefaultsOnly`：**只在类默认值里可编辑**（不是每个物品实例的资产属性），符合"出厂设置卡"定位。
- `Category=Equipment`：Lyra 源码原样（虽然目录是 Inventory，但分类名沿用源码）。
- `protected`：给子类留空间，外部不可直接改。

### 4. 覆写钩子 + 查询函数

```cpp
	virtual void OnInstanceCreated(UTenkaichiInventoryItemInstance* Instance) const override;
	int32 GetItemStatByTag(FGameplayTag Tag) const;
```

- `OnInstanceCreated`：覆写基类钩子（`override`），实例出生时被调用，把 `InitialItemStats` 灌进实例（实现见 `.cpp`）。
- `GetItemStatByTag`：**普通成员函数**（非虚、非 override），按 Tag 查初始表里的值，查不到返回 0。

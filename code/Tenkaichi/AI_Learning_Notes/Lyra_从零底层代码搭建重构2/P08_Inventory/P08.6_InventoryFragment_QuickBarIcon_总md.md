## 一、本文件要解决什么

前三个碎片：
- `SetStats`（P08.3）→ 属性
- `EquippableItem`（P08.4）→ 能力
- `PickupIcon`（P08.5）→ 掉落外观

本文件 `QuickBarIcon` → 管**快捷栏显示**：这个物品**装进快捷栏（道具栏）时图标长什么样、装备时显示什么名字**。

> 📌 注意区分：`PickupIcon`（P08.5）是**掉在地上**的 3D 外观；`QuickBarIcon`（P08.6）是**在快捷栏 UI 里**的 2D 图标。一个管"世界里的样子"，一个管"界面里的样子"。

## 二、全景：`.h` 里有什么（26 行）

| 成员 | 类型 | 作用 |
|------|------|------|
| `Brush` | `FSlateBrush`（`EditAnywhere`+`BlueprintReadOnly`+`Category=Appearance`） | 快捷栏主图标 |
| `AmmoBrush` | `FSlateBrush`（同上） | 弹药/数量角标图标 |
| `DisplayNameWhenEquipped` | `FText`（同上） | 装备时显示的物品名 |

> 📌 `FSlateBrush` 是 Slate UI 的**画笔**结构（图片/颜色/绘制方式），快捷栏图标用它画出来。三个字段都是 `BlueprintReadOnly`（同 P08.5，供 UI 读）。

```cpp
// 版权声明（Lyra 项目自带，保留）

#include "IPickupable.h"

#include "GameFramework/Actor.h"
#include "TenkaichiInventoryManagerComponent.h"
#include "UObject/ScriptInterface.h"

#include UE_INLINE_GENERATED_CPP_BY_NAME(IPickupable)

class UActorComponent;

// 构造函数：调用父类（蓝图函数库）的默认构造
UPickupableStatics::UPickupableStatics()
	: Super(FObjectInitializer::Get())
{
}

// 从 Actor 上找出第一个"能捡的"接口（先看 Actor 自己，再看它的组件）
TScriptInterface<IPickupable> UPickupableStatics::GetFirstPickupableFromActor(AActor* Actor)
{
	// 先看 Actor 自己是不是就能捡（直接把它转成接口试试）
	TScriptInterface<IPickupable> PickupableActor(Actor);
	if (PickupableActor)
	{
		return PickupableActor;
	}

	// 如果 Actor 自己不能捡，它可能有某个组件实现了拾取接口
	TArray<UActorComponent*> PickupableComponents = Actor ? Actor->GetComponentsByInterface(UPickupable::StaticClass()) : TArray<UActorComponent*>();
	if (PickupableComponents.Num() > 0)
	{
		// 取第一个能捡的组件（需要更精细的区分逻辑时，留到别处解决）
		return TScriptInterface<IPickupable>(PickupableComponents[0]);
	}

	// 都没有 → 返回空接口
	return TScriptInterface<IPickupable>();
}

// 把掉落包里的东西塞进背包管理器（服务器权限）
void UPickupableStatics::AddPickupToInventory(UTenkaichiInventoryManagerComponent* InventoryComponent, TScriptInterface<IPickupable> Pickup)
{
	if (InventoryComponent && Pickup)
	{
		// 拿到掉落包
		const FInventoryPickup& PickupInventory = Pickup->GetPickupInventory();

		// 第一类：模板（按定义 + 数量批量造）
		for (const FPickupTemplate& Template : PickupInventory.Templates)
		{
			InventoryComponent->AddItemDefinition(Template.ItemDef, Template.StackCount);
		}

		// 第二类：现成实例（直接塞）
		for (const FPickupInstance& Instance : PickupInventory.Instances)
		{
			InventoryComponent->AddItemInstance(Instance.Item);
		}
	}
}
```

### 1. include 与前置声明


- `UObject/ScriptInterface.h`：`TScriptInterface` 的完整定义（`.cpp` 里要实际构造它，不能只前置声明）。
- `UE_INLINE_GENERATED_CPP_BY_NAME(IPickupable)`：文件名必须一致（`IPickupable`）。
- `class UActorComponent;`：前置声明，`GetComponentsByInterface` 返回 `TArray<UActorComponent*>`，只用指针。

### 3. `GetFirstPickupableFromActor`（找能捡的）

```cpp
TScriptInterface<IPickupable> PickupableActor(Actor);
if (PickupableActor)
{
	return PickupableActor;
}
```

- **第一步：直接试 Actor 自己**。`TScriptInterface<IPickupable>(Actor)` 会检查这个 Actor 是否实现了 `IPickupable` 接口；实现了就转成功（真值），没实现就是空（假值）。
- `if (PickupableActor)`：接口智能指针有 `operator bool`，非空说明"这个 Actor 能捡"。

```cpp
TArray<UActorComponent*> PickupableComponents = Actor ? Actor->GetComponentsByInterface(UPickupable::StaticClass()) : TArray<UActorComponent*>();
if (PickupableComponents.Num() > 0)
{
	return TScriptInterface<IPickupable>(PickupableComponents[0]);
}
```

- **第二步：找组件**。`GetComponentsByInterface(UPickupable::StaticClass())` 返回这个 Actor 身上**所有实现了拾取接口的组件**。
- `Actor ? ... : TArray<...>()`：三目表达式，防止 `Actor` 为空时解引用崩溃。
- 取第一个（`[0]`），转成接口返回。注释里说"需要更精细区分时再解决"——目前只取第一个够用。

```cpp
return TScriptInterface<IPickupable>();
```

- **第三步：都没有 → 返回空接口**（默认构造的空 `TScriptInterface`）。

> 整体逻辑：**Actor 自己 → 它的组件 → 空**，三级查找。

### 4. `AddPickupToInventory`（塞进背包）

```cpp
if (InventoryComponent && Pickup)
{
	const FInventoryPickup& PickupInventory = Pickup->GetPickupInventory();
	...
}
```

- 先判空：管理器存在 + 掉落物接口有效，才继续。
- `Pickup->GetPickupInventory()`：调用接口的纯虚方法，拿到掉落包（`FInventoryPickup`）。

```cpp
for (const FPickupTemplate& Template : PickupInventory.Templates)
{
	InventoryComponent->AddItemDefinition(Template.ItemDef, Template.StackCount);
}
```

- **第一类：模板**。遍历 `Templates`，每个模板调用 P08.7 的 `AddItemDefinition(定义, 数量)`——按定义批量造物品。

```cpp
for (const FPickupInstance& Instance : PickupInventory.Instances)
{
	InventoryComponent->AddItemInstance(Instance.Item);
}
```

- **第二类：实例**。遍历 `Instances`，每个现成实例调用 P08.7 的 `AddItemInstance(实例)`——直接塞进背包。

> 两种东西对应 P08.7 管理器的两个增函数：`AddItemDefinition`（造新）+ `AddItemInstance`（塞现成）。这就是"桥"落地的瞬间。

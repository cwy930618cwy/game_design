## 一、本文件要解决什么

## 三、逐段讲解

### 1. include 自己的 `.h`

```cpp
#include "InventoryFragment_PickupIcon.h"
```

- 引入声明（含字段定义）。

### 2. UE 生成器宏

```cpp
#include UE_INLINE_GENERATED_CPP_BY_NAME(InventoryFragment_PickupIcon)
```

- UE5 固定宏（P04 讲过），参数 = 类名。提供反射链接。

### 3. 构造函数

```cpp
UInventoryFragment_PickupIcon::UInventoryFragment_PickupIcon()
{
	PadColor = FLinearColor::Green;
}
```

- 空参数构造函数，函数体里**给 `PadColor` 赋默认值** `FLinearColor::Green`。
- 为什么放 `.cpp` 而不是 `.h` 里给字段初值？因为 UHT 反射要求构造函数定义在 `.cpp`（声明在 `.h`，实现分离是 UE 标准做法）。这样构造的对象（CDO）`PadColor` 一开始就是绿色。
- `FLinearColor::Green`：UE 预定义的静态颜色常量。

> 📌 对比 P08.4：那边**没有**构造函数（纯字段类），本文件**有**一个构造函数——因为这里需要"默认值"，那边不需要。是否需要构造函数，看有没有"初始值"要设。

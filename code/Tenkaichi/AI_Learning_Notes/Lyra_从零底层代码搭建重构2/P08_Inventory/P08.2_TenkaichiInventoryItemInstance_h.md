## 三、完整代码（`.h`，注释已中文化）

```cpp
// 版权声明（Lyra 项目自带，保留）
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "System/GameplayTagStack.h"
#include "Templates/SubclassOf.h"

#include "TenkaichiInventoryItemInstance.generated.h"

// 前置声明：FLifetimeProperty（网络复制属性登记用，引擎结构体）
class FLifetimeProperty;

// 前置声明：物品定义（P08.1 已教，这里只需类名）
class UTenkaichiInventoryItemDefinition;

// 前置声明：物品碎片（P08.1 已教）
class UTenkaichiInventoryItemFragment;

// 前置声明：FFrame（引擎结构体）
struct FFrame;

// 前置声明：FGameplayTag（引擎 GameplayTags 结构体）
struct FGameplayTag;

//////////////////////////////////////////////////////////////////////

/**
 * UTenkaichiInventoryItemInstance
 *
 * 物品实例：定义（菜谱）的"活个体"，存「这件物品现在怎么样」的实时数据（弹药数、耐久等）。
 */
UCLASS(BlueprintType)
class UTenkaichiInventoryItemInstance : public UObject
{
	GENERATED_BODY()

public:
	// 构造函数：带 FObjectInitializer（UObject 子类标准写法，默认值给 Get()）
	UTenkaichiInventoryItemInstance(const FObjectInitializer& ObjectInitializer = FObjectInitializer::Get());

	//~UObject 接口开始
	// 允许这个 UObject 参与网络复制（返回 true）
	virtual bool IsSupportedForNetworking() const override { return true; }
	//~UObject 接口结束

public:
	// 给指定 Tag 增加指定数量的堆叠（StackCount 小于 1 时什么都不做）
	UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly, Category=Inventory)
	void AddStatTagStack(FGameplayTag Tag, int32 StackCount);

	// 从指定 Tag 移除指定数量的堆叠（StackCount 小于 1 时什么都不做）
	UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly, Category=Inventory)
	void RemoveStatTagStack(FGameplayTag Tag, int32 StackCount);

	// 返回指定 Tag 的堆叠数量（Tag 不存在时返回 0）
	UFUNCTION(BlueprintCallable, Category=Inventory)
	int32 GetStatTagStackCount(FGameplayTag Tag) const;

	// 若指定 Tag 至少有 1 个堆叠则返回 true
	UFUNCTION(BlueprintCallable, Category=Inventory)
	bool HasStatTag(FGameplayTag Tag) const;

	// 返回本实例指向的物品定义类（菜谱）
	TSubclassOf<UTenkaichiInventoryItemDefinition> GetItemDef() const
	{
		return ItemDef;
	}

	// 按碎片类型，从本实例所属定义里找出对应碎片（DeterminesOutputType 让蓝图正确推断返回类型）
	UFUNCTION(BlueprintCallable, BlueprintPure=false, meta=(DeterminesOutputType=FragmentClass))
	const UTenkaichiInventoryItemFragment* FindFragmentByClass(TSubclassOf<UTenkaichiInventoryItemFragment> FragmentClass) const;

	// 模板版 FindFragmentByClass：由返回类型自动推导碎片类，免写 StaticClass
	template <typename ResultClass>
	const ResultClass* FindFragmentByClass() const
	{
		return (ResultClass*)FindFragmentByClass(ResultClass::StaticClass());
	}

private:
#if UE_WITH_IRIS
	// Iris 复制框架：注册这个对象的所有复制片段（新复制系统用）
	virtual void RegisterReplicationFragments(UE::Net::FFragmentRegistrationContext& Context, UE::Net::EFragmentRegistrationFlags RegistrationFlags) override;
#endif // UE_WITH_IRIS

	// 设置本实例指向的物品定义类（仅供 FLyraInventoryList 友元调用）
	void SetItemDef(TSubclassOf<UTenkaichiInventoryItemDefinition> InDef);

	// 友元：FTenkaichiInventoryList（P08.7 才定义，负责创建/管理实例，需要直接调 SetItemDef）
	friend struct FTenkaichiInventoryList;

private:
	// 带数量的属性仓库（弹药数、耐久等），用 GameplayTag 作键，支持网络复制
	UPROPERTY(Replicated)
	FGameplayTagStackContainer StatTags;

	// 本实例指向的物品定义（菜谱），支持网络复制
	UPROPERTY(Replicated)
	TSubclassOf<UTenkaichiInventoryItemDefinition> ItemDef;
};
```

## 四、逐段讲解

### 1. 头部：include + 前置声明

```cpp
#include "System/GameplayTagStack.h"
#include "Templates/SubclassOf.h"
#include "TenkaichiInventoryItemInstance.generated.h"

class FLifetimeProperty;
class UTenkaichiInventoryItemDefinition;
class UTenkaichiInventoryItemFragment;
struct FFrame;
struct FGameplayTag;
```

- `System/GameplayTagStack.h`：字段 `StatTags` 的类型 `FGameplayTagStackContainer` 来自这里（P02 老朋友，**硬 include**，因为要完整定义）。
- `Templates/SubclassOf.h`：`TSubclassOf` 模板（`.h` 里就用到了完整类型，所以直接 include，不像 P08.1 那样只前置声明）。
- `.generated.h`：UE 反射要求，放最后一个 include。
- 5 个前置声明：
  - `FLifetimeProperty`：`.cpp` 里 `GetLifetimeReplicatedProps` 用，`.h` 里其实没直接用，Lyra 原样保留。
  - `UTenkaichiInventoryItemDefinition` / `UTenkaichiInventoryItemFragment`：`ItemDef` 字段 + `FindFragmentByClass` 参数用到，前置声明即可（完整定义在 `.cpp` 里 include）。
  - `FFrame` / `FGameplayTag`：引擎结构体前置声明。

### 2. 类头 + 构造函数 + 复制开关

```cpp
UCLASS(BlueprintType)
class UTenkaichiInventoryItemInstance : public UObject
```

- `UCLASS(BlueprintType)`：允许蓝图认识这个类型（但**不是** `Blueprintable`，实例由 C++ 创建，蓝图只用来传参/取值）。

```cpp
virtual bool IsSupportedForNetworking() const override { return true; }
```

- `IsSupportedForNetworking` 是 `UObject` 的虚函数，默认返回 `false`（普通 UObject 不参与复制）。这里覆写返回 `true`，**让这个实例能网络复制**——因为"这把枪剩几发子弹"是每个玩家都要同步的。这是本类最关键的一行。

### 3. 四个 Tag 堆叠接口

```cpp
UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly, Category=Inventory)
void AddStatTagStack(FGameplayTag Tag, int32 StackCount);
```

- `AddStatTagStack` / `RemoveStatTagStack` 带 `BlueprintAuthorityOnly`：**改数量只能由服务器权威端做**，防客户端乱改（和 P07 里见过的 `BlueprintAuthorityOnly` 同理）。
- `GetStatTagStackCount` / `HasStatTag` 不带 `BlueprintAuthorityOnly`：**查询谁都能查**（读不改变状态，客户端本地也能读）。
- 四个都是 `BlueprintCallable`：蓝图节点直接可用。

### 4. 取定义 + 找碎片

```cpp
TSubclassOf<UTenkaichiInventoryItemDefinition> GetItemDef() const
{
	return ItemDef;
}
```

- `GetItemDef`：内联 getter，返回 `ItemDef`（指向菜谱的类引用）。

```cpp
const UTenkaichiInventoryItemFragment* FindFragmentByClass(TSubclassOf<UTenkaichiInventoryItemFragment> FragmentClass) const;
```

- 普通版 `FindFragmentByClass`：声明，实现放 `.cpp`（内部委托给定义）。

```cpp
template <typename ResultClass>
const ResultClass* FindFragmentByClass() const
{
	return (ResultClass*)FindFragmentByClass(ResultClass::StaticClass());
}
```

- 模板版 `FindFragmentByClass`：**同一个名字的重载**。调用时不用手动写 `XX::StaticClass()`，编译器从返回类型自动推导。内联在 `.h` 里（模板函数必须放 `.h`）。

### 5. 私有区：Iris 复制 + SetItemDef + 友元

```cpp
#if UE_WITH_IRIS
	virtual void RegisterReplicationFragments(...) override;
#endif // UE_WITH_IRIS
```

- `RegisterReplicationFragments`：UE5 新复制框架（Iris）的注册入口，`#if UE_WITH_IRIS` 条件编译（开了 Iris 才编译）。实现放 `.cpp`。

```cpp
void SetItemDef(TSubclassOf<UTenkaichiInventoryItemDefinition> InDef);
friend struct FTenkaichiInventoryList;
```

- `SetItemDef`：private，设置 `ItemDef`。
- `friend struct FTenkaichiInventoryList`：**友元声明**——`FTenkaichiInventoryList`（P08.7 的结构）负责创建/管理实例，需要直接调私有的 `SetItemDef`。这里先声明为友元，P08.7 才定义它（`FTenkaichiInventoryList` 是结构体，用 `struct` 关键字）。

### 6. 两个复制字段

```cpp
UPROPERTY(Replicated)
FGameplayTagStackContainer StatTags;

UPROPERTY(Replicated)
TSubclassOf<UTenkaichiInventoryItemDefinition> ItemDef;
```

- `StatTags`：`FGameplayTagStackContainer`，带数量的属性仓库（P02 的 `GameplayTagStack`），存"弹药数/耐久"这类个体差异。
- `ItemDef`：`TSubclassOf<...Definition>`，指向菜谱的类引用。
- 两个都 `Replicated`：通过 `GetLifetimeReplicatedProps` 登记（`.cpp` 里）。

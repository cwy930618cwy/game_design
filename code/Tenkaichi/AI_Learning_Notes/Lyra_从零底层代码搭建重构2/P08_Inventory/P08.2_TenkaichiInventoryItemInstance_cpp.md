// 从指定 Tag 移除指定数量的堆叠
void UTenkaichiInventoryItemInstance::RemoveStatTagStack(FGameplayTag Tag, int32 StackCount)

	StatTags.RemoveStack(Tag, StackCount);
}

int32 UTenkaichiInventoryItemInstance::GetStatTagStackCount(FGameplayTag Tag) const

	return StatTags.GetStackCount(Tag);
}

// 若指定 Tag 至少有 1 个堆叠则返回 true
bool UTenkaichiInventoryItemInstance::HasStatTag(FGameplayTag Tag) const

	return StatTags.ContainsTag(Tag);
}

// 设置本实例指向的物品定义类（菜谱）
void UTenkaichiInventoryItemInstance::SetItemDef(TSubclassOf<UTenkaichiInventoryItemDefinition> InDef)

	ItemDef = InDef;

const UTenkaichiInventoryItemFragment* UTenkaichiInventoryItemInstance::FindFragmentByClass(TSubclassOf<UTenkaichiInventoryItemFragment> FragmentClass) const
{
	if ((ItemDef != nullptr) && (FragmentClass != nullptr))
	{
		return GetDefault<UTenkaichiInventoryItemDefinition>(ItemDef)->FindFragmentByClass(FragmentClass);
	}

	return nullptr;
}

## 四、逐段讲解

### 1. 头部 include

```cpp
#include "TenkaichiInventoryItemInstance.h"
#include "Inventory/TenkaichiInventoryItemDefinition.h"
#include "Net/UnrealNetwork.h"
```

- 第一个是它自己的 `.h`。
- `Inventory/TenkaichiInventoryItemDefinition.h`：`.h` 里 `ItemDef` 只是前置声明，`.cpp` 里要用 `GetDefault<UTenkaichiInventoryItemDefinition>(...)` 和它的 `FindFragmentByClass`，所以需要**完整定义**。
- `Net/UnrealNetwork.h`：`DOREPLIFETIME` 宏 + `FLifetimeProperty` 所在。

```cpp
#if UE_WITH_IRIS
#include "Iris/ReplicationSystem/ReplicationFragmentUtil.h"
#endif // UE_WITH_IRIS
```

- Iris 复制框架的工具头，开了 Iris 才 include（配 `.h` 里的 `#if UE_WITH_IRIS`）。

```cpp
#include UE_INLINE_GENERATED_CPP_BY_NAME(TenkaichiInventoryItemInstance)
class FLifetimeProperty;
```

- `UE_INLINE_GENERATED_CPP_BY_NAME`：UE5 固定宏（P04 讲过）。
- `class FLifetimeProperty;`：Lyra 原样保留的前置声明（`GetLifetimeReplicatedProps` 的参数用，`UnrealNetwork.h` 其实已提供，但照抄不删）。

### 2. 构造函数 + 复制登记

```cpp
UTenkaichiInventoryItemInstance::UTenkaichiInventoryItemInstance(const FObjectInitializer& ObjectInitializer)
	: Super(ObjectInitializer)
{
}
```

- 标准 UObject 子类构造函数，`Super(ObjectInitializer)` 传父类，函数体空。

```cpp
void UTenkaichiInventoryItemInstance::GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const
{
	Super::GetLifetimeReplicatedProps(OutLifetimeProps);

	DOREPLIFETIME(ThisClass, StatTags);
	DOREPLIFETIME(ThisClass, ItemDef);
}
```

- `GetLifetimeReplicatedProps`：登记"哪些 `UPROPERTY(Replicated)` 字段要复制"。
- `DOREPLIFETIME(ThisClass, Xxx)`：逐个登记。这里登记 `StatTags` 和 `ItemDef` 两个（和 `.h` 里两个 `Replicated` 字段一一对应）。
- `ThisClass`：UE 宏自动展开成当前类。

### 3. Iris 复制片段注册

```cpp
#if UE_WITH_IRIS
void UTenkaichiInventoryItemInstance::RegisterReplicationFragments(...)
{
	using namespace UE::Net;
	FReplicationFragmentUtil::CreateAndRegisterFragmentsForObject(this, Context, RegistrationFlags);
}
#endif // UE_WITH_IRIS
```

- Iris 新复制框架的注册入口，`CreateAndRegisterFragmentsForObject` 自动为本对象所有复制属性建片段。开了 Iris 才编译（`#if UE_WITH_IRIS` 包裹，配 `.h`）。

### 4. 四个 Tag 接口（转发给 StatTags）

```cpp
void UTenkaichiInventoryItemInstance::AddStatTagStack(FGameplayTag Tag, int32 StackCount)
{
	StatTags.AddStack(Tag, StackCount);
}
```

- `AddStatTagStack` → `StatTags.AddStack`；`RemoveStatTagStack` → `StatTags.RemoveStack`；`GetStatTagStackCount` → `StatTags.GetStackCount`；`HasStatTag` → `StatTags.ContainsTag`。
- **全是薄转发**：`StatTags` 是 `FGameplayTagStackContainer`（P02 教的容器），实例不自己实现堆叠逻辑，直接调容器的方法。

### 5. SetItemDef + FindFragmentByClass

```cpp
void UTenkaichiInventoryItemInstance::SetItemDef(TSubclassOf<UTenkaichiInventoryItemDefinition> InDef)
{
	ItemDef = InDef;
}
```

- `SetItemDef`：简单赋值。private，只能被友元 `FTenkaichiInventoryList` 调。

```cpp
const UTenkaichiInventoryItemFragment* UTenkaichiInventoryItemInstance::FindFragmentByClass(TSubclassOf<UTenkaichiInventoryItemFragment> FragmentClass) const
{
	if ((ItemDef != nullptr) && (FragmentClass != nullptr))
	{
		return GetDefault<UTenkaichiInventoryItemDefinition>(ItemDef)->FindFragmentByClass(FragmentClass);
	}
	return nullptr;
}
```

- 先判 `ItemDef` 和 `FragmentClass` 都非空。
- **关键委托**：`GetDefault<UTenkaichiInventoryItemDefinition>(ItemDef)` 拿到"菜谱"的 CDO，再调它的 `FindFragmentByClass`——**实例自己不存碎片，查碎片交给定义**（总 md 讲的核心设计）。

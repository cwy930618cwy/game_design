#include "Kismet/BlueprintFunctionLibrary.h"

#include "TenkaichiInventoryItemDefinition.generated.h"

// 前置声明：TSubclassOf 模板类（避免引完整定义，加快编译）
template <typename T> class TSubclassOf;

// 前置声明：物品实例（P08.2 才教，这里只需知道有这个类名）
class UTenkaichiInventoryItemInstance;

// 前置声明：FFrame 结构体（引擎）
struct FFrame;

class UTenkaichiInventoryItemFragment : public UObject

	GENERATED_BODY()

public:

	virtual void OnInstanceCreated(UTenkaichiInventoryItemInstance* Instance) const {}

 * UTenkaichiInventoryItemDefinition

class UTenkaichiInventoryItemDefinition : public UObject

	GENERATED_BODY()

## 四、逐段讲解

### 1. 头部：include + 前置声明

```cpp
#include "Kismet/BlueprintFunctionLibrary.h"
#include "TenkaichiInventoryItemDefinition.generated.h"

template <typename T> class TSubclassOf;
class UTenkaichiInventoryItemInstance;
struct FFrame;
```

- `Kismet/BlueprintFunctionLibrary.h`：因为 ③ 号类继承 `UBlueprintFunctionLibrary`，得引基类头文件。
- `.generated.h`：UE 反射系统要求，**必须放最后一个 include**（任何 UCLASS 都这样）。
- 三个前置声明：
  - `TSubclassOf`：模板类，`TSubclassOf<X>` 是"指向 X 子类的类引用"类型，声明里用到但不需要完整定义。
  - `UTenkaichiInventoryItemInstance`：① 号碎片的 `OnInstanceCreated` 参数用到它，只需前置声明（P08.2 才教）。
  - `FFrame`：Lyra 原样保留的前置声明（引擎结构体）。

### 2. ① 碎片基类

```cpp
UCLASS(MinimalAPI, DefaultToInstanced, EditInlineNew, Abstract)
class UTenkaichiInventoryItemFragment : public UObject
{
	GENERATED_BODY()
public:
	virtual void OnInstanceCreated(UTenkaichiInventoryItemInstance* Instance) const {}
};
```

- `MinimalAPI`：这个类只暴露最小导出接口（跨模块导出优化，非教学重点，一比一保留）。
- `DefaultToInstanced + EditInlineNew + Abstract`：碎片机制三件套（见总 md 第三节），让蓝图能往数组加不同子类。
- 唯一的虚函数 `OnInstanceCreated`：空实现 `{}` 的钩子，子类覆写它来"物品实例创建时干点事"。

### 3. ② 物品定义类

```cpp
UCLASS(Blueprintable, Const, Abstract)
class UTenkaichiInventoryItemDefinition : public UObject
```

- `Blueprintable`：蓝图能继承它做数据资产（`B_xxx`）。
- `Const`：标记为常量类，实例数据不可变（菜谱永不变）。
- `Abstract`：本身不直接实例化，只做基类。

两个字段 + 一个方法：

```cpp
UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category=Display)
FText DisplayName;

UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category=Display, Instanced)
TArray<TObjectPtr<UTenkaichiInventoryItemFragment>> Fragments;
```

- `DisplayName`：`FText` 类型（可本地化的显示文本）。
- `Fragments`：碎片数组，`TObjectPtr` 是 UE5 的智能指针包装；`Instanced` 标记配合碎片基类的 `EditInlineNew`，让数组里能存不同子类的独立实例。
- `FindFragmentByClass`：声明了方法，实现放 `.cpp`（下一步）。

### 4. ③ 蓝图工具库

```cpp
UCLASS()
class UTenkaichiInventoryFunctionLibrary : public UBlueprintFunctionLibrary
{
	GENERATED_BODY()
	UFUNCTION(BlueprintCallable, meta=(DeterminesOutputType=FragmentClass))
	static const UTenkaichiInventoryItemFragment* FindItemDefinitionFragment(...);
};
```

- 继承 `UBlueprintFunctionLibrary`：纯静态函数库，蓝图节点可直接拖用。
- `static`：静态方法，不需要对象实例。
- `meta=(DeterminesOutputType=FragmentClass)`：告诉蓝图"返回值类型由 `FragmentClass` 参数决定"，节点能正确推断类型。

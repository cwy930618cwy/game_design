## 三、逐段讲解

### 1. include

```cpp
#include "Inventory/TenkaichiInventoryItemDefinition.h"
#include "Styling/SlateBrush.h"
```

- 第一个：继承 `UTenkaichiInventoryItemFragment`（P08.1 ✅），需完整定义。
- 第二个：`FSlateBrush` 所在头文件。这是 Slate UI 的画笔结构（描述"用什么图片、怎么画"），字段是值类型（非指针），所以要 include 拿到完整定义。

### 2. 类声明

```cpp
class UInventoryFragment_QuickBarIcon : public UTenkaichiInventoryItemFragment
```

- 无 `Lyra` 前缀，原样。
- 继承 P08.1 碎片基类，最后一个碎片。

### 3. 三个 UI 字段

```cpp
	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category=Appearance)
	FSlateBrush Brush;

	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category=Appearance)
	FSlateBrush AmmoBrush;

	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category=Appearance)
	FText DisplayNameWhenEquipped;
```

| 字段 | 类型 | 作用 |
|------|------|------|
| `Brush` | `FSlateBrush` | 快捷栏主图标（枪械本体图标） |
| `AmmoBrush` | `FSlateBrush` | 弹药/数量角标（显示"还剩几发"的角标图标） |
| `DisplayNameWhenEquipped` | `FText` | 装备时显示的物品名（如"AK-47"） |

- 三个字段**字段名不同**但类型有 `FSlateBrush` ×2 + `FText` ×1，都是 `BlueprintReadOnly`（供 UI 读，同 P08.5）。

> 📌 **为什么没有构造函数？** 不需要默认值——`FSlateBrush`/`FText` 有各自的默认构造，直接让它们默认就好（P08.5 有构造函数是因为要设 `PadColor` 绿色）。

# P02.2 批量改 Mesh 材质参数（SetScalar/Vector/ColorParameterValueOnAllMeshComponents）—— 是什么

> 疑问来源：P02.2 `TenkaichiSystemStatics.h` 的三个函数 `SetScalarParameterValueOnAllMeshComponents` / `SetVectorParameterValueOnAllMeshComponents` / `SetColorParameterValueOnAllMeshComponents`。
> 源码依据：`E:\ue5\LyraStarterGame5.6\LyraStarterGame\Source\LyraGame\System\LyraSystemStatics.cpp`（75~100 行）

---

## 一、一句话回答

这三个函数做的是同一件事的三种参数类型变体：**把一个"材质参数"批量设置到目标 Actor 身上的所有 Mesh 组件（模型）上**——标量版改"数字"、向量版改"三维向量"、颜色版改"颜色"。

用大白话说：**你指定一个 Actor，它身上的所有模型材质里的某个参数，一次性全改掉。**

---

## 二、为什么要"批量改所有 Mesh"（这解决什么问题）

**场景 1：高亮/选中效果**
敌人被你瞄准时，整个模型（可能由几十个 Mesh 部件拼成）的所有材质同时变亮或描边。你不会一个一个部件去改——那太蠢了。传一个 `TargetActor`，一次性把所有 Mesh 都改了。

**场景 2：受击变色/特效反馈**
角色受击，全身闪白一下再恢复。闪白 = 把材质里的"自发光强度"参数（标量）临时调大，再调回。

**场景 3：通用视觉开关**
比如把所有模型的"受伤程度"、"发光颜色"、"透明度"参数统一改掉。

> **核心**：一个 Actor 身上可能挂着一堆 Mesh 组件（身体、武器、披风……甚至子 Actor 的部件），这三个函数让你"一句代码/一个蓝图节点"就把它们**全部**处理完，不用手动遍历。

---

## 三、它们内部到底怎么做的（看 Lyra 源码）

三个函数的核心都长一样，只是参数类型不同。看标量版（`LyraSystemStatics.cpp` 75~84 行）：

```cpp
void ULyraSystemStatics::SetScalarParameterValueOnAllMeshComponents(AActor* TargetActor, const FName ParameterName, const float ParameterValue, bool bIncludeChildActors)
{
	if (TargetActor != nullptr)
	{
		TargetActor->ForEachComponent<UMeshComponent>(bIncludeChildActors, [=](UMeshComponent* InComponent)
		{
			InComponent->SetScalarParameterValueOnMaterials(ParameterName, ParameterValue);
		});
	}
}
```

拆解这段代码：

| 行 | 干嘛 |
|----|------|
| `if (TargetActor != nullptr)` | 目标为空就直接返回（安全保护） |
| `TargetActor->ForEachComponent<UMeshComponent>(bIncludeChildActors, ...)` | **遍历**这个 Actor 上的所有 `UMeshComponent`（网格组件）。`bIncludeChildActors=true` 时连挂在子 Actor 上的也一起遍历 |
| `InComponent->SetScalarParameterValueOnMaterials(ParameterName, ParameterValue)` | 对每个 Mesh 组件，调用它自带的"**给所有材质 section 设置标量参数**"函数 |

向量版（86~95 行）一模一样，只是参数是 `FVector`、调用的是 `SetVectorParameterValueOnMaterials`：

```cpp
InComponent->SetVectorParameterValueOnMaterials(ParameterName, ParameterValue);
```

**颜色版最特别**（97~100 行）——它不重复实现，而是**直接转调向量版**：

```cpp
void ULyraSystemStatics::SetColorParameterValueOnAllMeshComponents(AActor* TargetActor, const FName ParameterName, const FLinearColor ParameterValue, bool bIncludeChildActors)
{
	SetVectorParameterValueOnAllMeshComponents(TargetActor, ParameterName, FVector(ParameterValue), bIncludeChildActors);
}
```

> 为什么颜色能转成向量？`FLinearColor`（RGBA）和 `FVector`（XYZ）都是 3~4 个分量，`FVector(颜色)` 就是把 R、G、B 存进 X、Y、Z。材质系统里"颜色参数"和"向量参数"底层是一套存储，所以可以互相转。

---

## 四、三个函数的参数差异一览

| 函数 | 参数类型 | 改的是什么材质参数 | 例子 |
|------|---------|-------------------|------|
| `SetScalarParameterValueOnAllMeshComponents` | `float`（标量） | 一个数字参数 | 自发光强度、透明度、UV 偏移量 |
| `SetVectorParameterValueOnAllMeshComponents` | `FVector`（三维向量） | 一个向量参数 | 法线偏移、流动方向 |
| `SetColorParameterValueOnAllMeshComponents` | `FLinearColor`（颜色） | 一个颜色参数 | 模型颜色、发光颜色、血量变色 |

**共同点**：
- 都传 `TargetActor`（要改哪个角色/物体）+ `ParameterName`（改哪个材质参数，名字要和材质蓝图里的参数名一致）+ `bIncludeChildActors`（要不要连子 Actor 一起，默认 `true`）。
- 都不需要提前知道 Actor 上有哪些 Mesh——`ForEachComponent` 自动找到所有。

---

## 五、一个完整类比（帮助记忆）

把 Actor 想象成**一辆由多块"车身零件"拼成的车**，每个零件都刷了漆（材质）。

- 你要让**整辆车**都变成红色 → 不用一个个零件去喷漆，喊一声"这辆车，颜色改红"——`SetColorParameterValueOnAllMeshComponents` 就是这句"喊话"，`ForEachComponent` 就是"自动挨个零件刷漆"。
- `ParameterName` = 你要改的是"颜色"还是"亮度"这个**槽位名**（比如材质里那个参数叫 `Color`、`EmissiveIntensity`）。
- `bIncludeChildActors` = 连车里的座椅、后视镜（挂在子 Actor 上的零件）要不要一起刷。

---

## 六、什么时候用到（在 Lyra 里它的价值）

这三个函数在 Lyra 里属于**通用工具**，本身不绑定具体玩法，但上层（比如武器高亮、受击反馈、敌人标记）会用到：
- 蓝图上想"给某个角色整体做个视觉反馈"，一个节点搞定，不用遍历组件。
- 因为它是 `UBlueprintFunctionLibrary` 的静态函数，**蓝图里直接能调**。

> ⚠️ 注意：`.h` 声明里 `meta=(DefaultToSelf="TargetActor")`——蓝图里 `TargetActor` 默认填"调用者自己"，所以多数情况你连它都不用传。

---

## 七、结论

这三个函数 = **"把某个材质参数，批量设置到目标 Actor 的所有 Mesh 组件上"** 的三种类型版本（标量/向量/颜色）。内部靠 `AActor::ForEachComponent<UMeshComponent>()` 自动遍历所有网格组件，再对每个组件调 `Set*ParameterValueOnMaterials`。颜色版内部转调向量版，不重复写。用于高亮、变色、特效反馈这类"整体改一个 Actor 外观"的场景。

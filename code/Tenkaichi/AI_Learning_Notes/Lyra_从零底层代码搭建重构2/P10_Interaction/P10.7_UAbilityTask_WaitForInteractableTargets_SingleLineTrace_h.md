### 1. 头文件引入（第 1~13 行）


| 头文件 | 作用 |
|--------|------|
| `InteractionQuery.h` | 用 `FInteractionQuery`（P10.1 教的交互查询结构）。 |
| `AbilityTask_WaitForInteractableTargets.h` | 用基类（P10.6）。 |
| `.generated.h` | UHT 生成。 |
| `FCollisionProfileName` 前向声明 | 用引用/指针时只需前向声明（软引用）。 |
| `UGameplayAbility`、`UObject`、`FFrame` | 前向声明，避免重头文件。 |

### 2. 类声明（第 15~18 行）

```cpp

class UAbilityTask_WaitForInteractableTargets_SingleLineTrace : public UAbilityTask_WaitForInteractableTargets
{
	GENERATED_UCLASS_BODY()
```

- 继承自 P10.6 基类。
- `GENERATED_UCLASS_BODY()`：配合 `.cpp` 里带 `FObjectInitializer` 的构造函数。

### 3. `Activate` 重写（第 20 行）

```cpp
	virtual void Activate() override;
```

- UAbilityTask 生命周期入口，任务启动时被调用。子类在这里**初始化瞄准方向、启动定时检测**。

### 4. 静态工厂方法（第 22~24 行）

```cpp
	/** 直到等，直到我们扫出新的可交互目标集合。此任务会自动循环（逐帧/定时重新检测）。 */
	UFUNCTION(BlueprintCallable, Category="Ability|Tasks", meta = (HideIn = "OwningAbility", DefaultToSelf = "OwningAbility", BlueprintInternalUseOnly = "TRUE"))
	static UAbilityTask_WaitForInteractableTargets_SingleLineTrace* WaitForInteractableTargets_SingleLineTrace(UGameplayAbility* OwningAbility, FInteractionQuery InteractionQuery, FCollisionProfileName TraceProfile, FGameplayAbilityTargetingLocationInfo StartLocation, float InteractionScanRange = 100, float InteractionScanRate = 0.100, bool bShowDebug = false);
```

- **`static` 工厂函数**：蓝图/代码创建任务的入口。
- `BlueprintCallable` + `BlueprintInternalUseOnly`：作为"能力任务"节点被蓝图内部调用，隐藏 OwningAbility 参数。
- **参数**：
  - `OwningAbility`：所属能力；
  - `InteractionQuery`：交互查询条件（P10.1）；
  - `TraceProfile`：射线用的碰撞 Profile 名；
  - `StartLocation`：起始位置（能力目标定位信息）；
  - `InteractionScanRange`：扫描距离，默认 100；
  - `InteractionScanRate`：**扫描频率**（多少秒扫一次），默认 0.1 秒；
  - `bShowDebug`：是否显示调试射线。

### 5. 私有区：生命周期 + 内部逻辑（第 26~30 行）

```cpp
private:

	virtual void OnDestroy(bool AbilityEnded) override;

	void PerformTrace();
```

- `OnDestroy`：任务销毁时停止定时器。
- `PerformTrace`：**真正执行射线检测**的私有方法（由定时器反复触发）。

### 6. 私有成员变量（第 32~42 行）

```cpp
	UPROPERTY()
	FInteractionQuery InteractionQuery;

	UPROPERTY()
	FGameplayAbilityTargetingLocationInfo StartLocation;

	float InteractionScanRange = 100;
	float InteractionScanRate = 0.100;
	bool bShowDebug = false;

	FTimerHandle TimerHandle;
```

- `InteractionQuery`、`StartLocation`：工厂函数传入并保存。
- `InteractionScanRange` / `InteractionScanRate` / `bShowDebug`：扫描参数，**C++ 默认成员初始化**（= 100 / 0.1 / false）。
- `FTimerHandle TimerHandle`：定时器句柄，配合 `InteractionScanRate` 每隔一段时间扫一次（不是每帧扫，是**每 0.1 秒**扫一次，省性能）。

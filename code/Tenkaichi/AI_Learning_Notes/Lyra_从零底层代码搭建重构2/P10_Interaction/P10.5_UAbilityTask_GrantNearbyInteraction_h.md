## 二、完整代码

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.
#pragma once

#include "Abilities/Tasks/AbilityTask.h"

#include "AbilityTask_GrantNearbyInteraction.generated.h"

class UGameplayAbility;
class UObject;
struct FFrame;
struct FGameplayAbilitySpecHandle;
struct FObjectKey;

// 能力任务：周期性扫描周围空间，找出能交互的目标并给玩家授权对应的交互能力
UCLASS()
class UAbilityTask_GrantNearbyInteraction : public UAbilityTask
{
	GENERATED_UCLASS_BODY()

	// 任务启动入口：在这里挂上定时器，周期性触发扫描
	virtual void Activate() override;

	// 工厂方法：创建本任务实例，并指定扫描半径与扫描间隔（蓝图可调用）
	UFUNCTION(BlueprintCallable, Category="Ability|Tasks", meta = (HidePin = "OwningAbility", DefaultToSelf = "OwningAbility", BlueprintInternalUseOnly = "TRUE"))
	static UAbilityTask_GrantNearbyInteraction* GrantAbilitiesForNearbyInteractors(UGameplayAbility* OwningAbility, float InteractionScanRange, float InteractionScanRate);

private:

	// 任务销毁时被调用：负责取消定时器、收尾
	virtual void OnDestroy(bool AbilityEnded) override;

	// 核心扫描逻辑：做一次球形检测，收集可交互目标并授权
	void QueryInteractables();

	// 扫描半径（厘米），默认 100
	float InteractionScanRange = 100;

	// 扫描间隔（秒），默认 0.1 秒扫一次
	float InteractionScanRate = 0.100;

	// 定时器句柄，控制周期性扫描
	FTimerHandle QueryTimerHandle;

	// 缓存：记录「已授权过的交互能力」，避免重复授权
	TMap<FObjectKey, FGameplayAbilitySpecHandle> InteractionAbilityCache;
};
```

## 三、逐段讲解

### 1. 头文件引入（第 1~13 行）

```cpp
#pragma once

#include "Abilities/Tasks/AbilityTask.h"
#include "AbilityTask_GrantNearbyInteraction.generated.h"

class UGameplayAbility;
class UObject;
struct FFrame;
struct FGameplayAbilitySpecHandle;
struct FObjectKey;
```

| 头文件/前置声明 | 作用 |
|----------------|------|
| `AbilityTask.h` | 引入 `UAbilityTask` 基类（本类继承它）。 |
| `AbilityTask_GrantNearbyInteraction.generated.h` | UHT 生成代码，`UCLASS` 必须有。 |
| `class UGameplayAbility;` 等前置声明 | 工厂方法参数 `UGameplayAbility*` 只用指针，不需要完整定义，保持头文件轻量（铁律 30）。 |

> 💡 本 `.h` 里没有直接用到引擎 GAS 的 `AbilitySystemComponent` 等类型（在 `.cpp` 才 include），所以头文件很干净。

### 2. `UCLASS()` + 继承 `UAbilityTask`（第 15~18 行）

```cpp
UCLASS()
class UAbilityTask_GrantNearbyInteraction : public UAbilityTask
{
	GENERATED_UCLASS_BODY()
```

- 继承 `UAbilityTask`，说明这是一个**能力任务**（挂接在 GameplayAbility 上的异步子任务）。
- `GENERATED_UCLASS_BODY()`：注意和普通 `GENERATED_BODY()` 的区别——它要求提供**带 `FObjectInitializer` 参数**的构造函数（在 `.cpp` 里写 `UAbilityTask_GrantNearbyInteraction::UAbilityTask_GrantNearbyInteraction(const FObjectInitializer& ObjectInitializer)`）。

### 3. `Activate()` 虚函数（第 20~21 行）

```cpp
	virtual void Activate() override;
```

- `UAbilityTask` 提供 `Activate()`，在任务被启动时由系统调用。这里声明重写，具体逻辑（挂定时器）放 `.cpp`。
- 这是能力任务的核心入口——任务激活才真正开始干活。

### 4. 静态工厂方法（第 24~25 行）

```cpp
	UFUNCTION(BlueprintCallable, Category="Ability|Tasks", meta = (HidePin = "OwningAbility", DefaultToSelf = "OwningAbility", BlueprintInternalUseOnly = "TRUE"))
	static UAbilityTask_GrantNearbyInteraction* GrantAbilitiesForNearbyInteractors(UGameplayAbility* OwningAbility, float InteractionScanRange, float InteractionScanRate);
```

- **`static` 工厂方法**：GAS 能力任务的标准写法——能力任务不直接 `new`，而是通过一个静态方法创建实例（内部调 `NewAbilityTask`）。
- **参数**：`OwningAbility`（归属技能）、`InteractionScanRange`（扫描半径）、`InteractionScanRate`（扫描间隔）。
- **`UFUNCTION(BlueprintCallable)`**：蓝图可调用。
- **meta 元数据**：
  - `HidePin` / `DefaultToSelf`：隐藏 `OwningAbility` 引脚，默认填当前技能自己，简化蓝图连线。
  - `BlueprintInternalUseOnly`：仅蓝图内部使用，不暴露为可独立调用的蓝图节点。

### 5. 私有区：生命周期 + 扫描核心（第 27~37 行）

```cpp
private:

	virtual void OnDestroy(bool AbilityEnded) override;
	void QueryInteractables();

	float InteractionScanRange = 100;
	float InteractionScanRate = 0.100;

	FTimerHandle QueryTimerHandle;

	TMap<FObjectKey, FGameplayAbilityObjectSpecHandle> InteractionAbilityCache;
};
```

- `OnDestroy(bool)`：任务销毁时清资源（取消定时器），重写自 `UAbilityTask`。
- `QueryInteractables()`：真正的扫描逻辑，定时器触发后执行。
- 数据成员：`InteractionScanRange`/`InteractionScanRate`（默认值）、`QueryTimerHandle`（定时器句柄）、`InteractionAbilityCache`（能力授权缓存，防止重复授权）。

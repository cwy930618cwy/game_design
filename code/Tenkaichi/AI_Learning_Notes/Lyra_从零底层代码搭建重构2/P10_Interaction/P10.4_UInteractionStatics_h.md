## 二、完整代码

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "Kismet/BlueprintFunctionLibrary.h"

#include "InteractionStatics.generated.h"

template <typename InterfaceType> class TScriptInterface;

class AActor;
class IInteractableTarget;
class UObject;
struct FFrame;
struct FHitResult;
struct FOverlapResult;

// 交互静态工具类：把 Actor / 命中 / 重叠结果翻译成一批 IInteractableTarget 候选
UCLASS()
class UInteractionStatics : public UBlueprintFunctionLibrary
{
	GENERATED_BODY()

public:
	UInteractionStatics();

public:
	// 从「可交互目标」反推它归属的 Actor（对象本身，或它所在的组件所属的 Actor）
	UFUNCTION(BlueprintCallable)
	static AActor* GetActorFromInteractableTarget(TScriptInterface<IInteractableTarget> InteractableTarget);

	// 取出一个 Actor 身上所有能交互的目标（Actor 自身 + 身上实现接口的组件）
	UFUNCTION(BlueprintCallable)
	static void GetInteractableTargetsFromActor(AActor* Actor, TArray<TScriptInterface<IInteractableTarget>>& OutInteractableTargets);

	// 从一批重叠命中结果里，把每个命中的 Actor / 组件中能交互的追加进输出数组（仅 C++ 用）
	static void AppendInteractableTargetsFromOverlapResults(const TArray<FOverlapResult>& OverlapResults, TArray<TScriptInterface<IInteractableTarget>>& OutInteractableTargets);

	// 从单次射线命中结果里，把命中的 Actor / 组件中能交互的追加进输出数组（仅 C++ 用）
	static void AppendInteractableTargetsFromHitResult(const FHitResult& HitResult, TArray<TScriptInterface<IInteractableTarget>>& OutInteractableTargets);
};
```

## 三、逐段讲解

### 1. 头文件引入（第 5~16 行）

```cpp
#include "Kismet/BlueprintFunctionLibrary.h"
#include "InteractionStatics.generated.h"

template <typename InterfaceType> class TScriptInterface;

class AActor;
class IInteractableTarget;
class UObject;
struct FFrame;
struct FHitResult;
struct FOverlapResult;
```

| 行 | 作用 |
|----|------|
| `BlueprintFunctionLibrary.h` | 引入 `UBlueprintFunctionLibrary`（蓝图函数库基类，让静态函数能暴露给蓝图）。 |
| `InteractionStatics.generated.h` | UHT 生成代码，`UCLASS` 必须有。 |
| `template <typename InterfaceType> class TScriptInterface;` | 前置声明 `TScriptInterface` 模板（函数签名里要用它，但不用展开）。 |
| `class AActor;` / `class IInteractableTarget;` / `class UObject;` / `struct FFrame;` / `struct FHitResult;` / `struct FOverlapResult;` | 全是**前置声明**。头文件里这些类型只以指针/引用出现，不需要完整定义，保持头文件轻量、避免循环 include（铁律 30）。 |

### 2. `UCLASS()` 工具类（第 19~22 行）

```cpp
UCLASS()
class UInteractionStatics : public UBlueprintFunctionLibrary
{
	GENERATED_BODY()

public:
	UInteractionStatics();
```

- 继承 `UBlueprintFunctionLibrary`，所以里面的 `static` 函数能暴露给蓝图（凡标 `UFUNCTION(BlueprintCallable)` 的）。
- 注意：**没有** `BlueprintType` / `Config` 之类额外修饰，是**最简单的 `UCLASS()`**。
- 构造函数 `UInteractionStatics()` 声明在 `.h`，定义放在 `.cpp`（空实现）。

### 3. 两个蓝图函数（第 27~35 行）

```cpp
	// 从「可交互目标」反推它归属的 Actor
	UFUNCTION(BlueprintCallable)
	static AActor* GetActorFromInteractableTarget(TScriptInterface<IInteractableTarget> InteractableTarget);

	// 取出一个 Actor 身上所有能交互的目标
	UFUNCTION(BlueprintCallable)
	static void GetInteractableTargetsFromActor(AActor* Actor, TArray<TScriptInterface<IInteractableTarget>>& OutInteractableTargets);
```

- **`UFUNCTION(BlueprintCallable)`**：蓝图里可直接调用。
- **`static`**：不用创建对象就能调，全局工具。
- `GetActorFromInteractableTarget`：输入一个 `TScriptInterface<IInteractableTarget>`（接口包装），输出它归属的 `AActor*`。逻辑（在 `.cpp`）：如果这个对象本身是 Actor 就返回它；如果是 ActorComponent 就返回它的 `GetOwner()`。
- `GetInteractorTargetsFromActor`：输入一个 Actor，把它的**自身 + 所有实现了 `IInteractableTarget` 的组件**都追加进 `OutInteractorTargets` 数组（用 `GetComponentsByInterface` 查询组件）。

### 4. 两个仅 C++ 用的函数（第 37~41 行）

```cpp
	// 从一组重叠命中结果里追加可交互目标
	static void AppendInteractorTargetsFromOverlapResults(const TArray<FOverlapResult>& OverlapResults, TArray<TScriptInterface<IInteractorTarget>>& OutInteractorTargets);

	// 从单次射线命中结果里追加可交互目标
	static void AppendInteractorTargetsFromHitResult(const FHitResult& HitResult, TArray<TScriptInterface<IInteractorTarget>>& OutInteractorTargets);
```

- **没有** `UFUNCTION`，所以只供 C++ 内部调用，蓝图看不见。
- `Append...`（追加）语义：调用方传入已经收集好的一批目标（`OutInteractorTargets`），这两个函数把新发现的往**数组末尾追加**（用 `AddUnique` 防重复），而不是覆盖。这样多个来源（重叠 + 命中）可以累积到同一个结果集。
- 这俩会被 P10.5（重叠）和 P10.7（命中）调用。

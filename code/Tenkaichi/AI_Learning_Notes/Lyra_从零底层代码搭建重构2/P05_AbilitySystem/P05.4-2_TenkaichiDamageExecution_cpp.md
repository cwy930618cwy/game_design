# P05.4-2 DamageExecution —— 教 .cpp

## 一、本文件要解决什么

把 `Execute_Implementation`（伤害算法）落成真实的 `.cpp`。`.h` 里只声明了构造函数和这个虚函数，真正的伤害计算逻辑全在 `.cpp`。

**本文件完成两件事**：
1. **构造函数**：告诉 GAS "我要抓取 `BaseDamage` 属性"（注册捕获定义）。
2. **`Execute_Implementation`**：GE 执行时被 GAS 调用，完整算出"这次打多少伤害"：
   - 从 `CombatSet` 抓 `BaseDamage`（基础伤害）
   - 处理命中结果（没命中就退回目标 Actor 位置）
   - 队伍规则（`CanCauseDamage` 判断能不能打）
   - 距离衰减 + 物理材质衰减
   - 输出到 `HealthSet` 的 `Damage` 元属性（HealthSet 再把它转成 -Health）

// 伤害计算的静态数据：把"要抓取的属性"提前算好存起来
struct FDamageStatics
{
	// 基础伤害属性的捕获定义（从源对象 CombatSet 抓取）
	FGameplayEffectAttributeCaptureDefinition BaseDamageDef;

	// 构造函数：用 CombatSet 的 BaseDamage 属性 + 源来源 + 可选 构建捕获定义
	FDamageStatics()
	{
		BaseDamageDef = FGameplayEffectAttributeCaptureDefinition(UTenkaichiCombatSet::GetBaseDamageAttribute(), EGameplayEffectAttributeCaptureSource::Source, true);
	}

// 返回伤害计算的静态单例（第一次调用时构造，之后复用）
static FDamageStatics& DamageStatics()
{
	static FDamageStatics Statics;
	return Statics;
}


// 构造函数：往捕获列表注册基础伤害属性，GAS 执行时就会帮我们抓取它
UTenkaichiDamageExecution::UTenkaichiDamageExecution()
{
	RelevantAttributesToCapture.Add(DamageStatics().BaseDamageDef);
}

// 执行计算的核心虚函数：GE 施加时被调用，算出这次打多少伤害
void UTenkaichiDamageExecution::Execute_Implementation(const FGameplayEffectCustomExecutionParameters& ExecutionParams, FGameplayEffectCustomExecutionOutput& OutExecutionOutput) const
{
#if 0	// ⚠️【注释挂起】依赖 P05.5 TenkaichiGameplayEffectContext + 阶段四 TeamSubsystem，就位后放开
#if WITH_SERVER_CODE
	const FGameplayEffectSpec& Spec = ExecutionParams.GetOwningSpec();
	FTenkaichiGameplayEffectContext* TypedContext = FTenkaichiGameplayEffectContext::ExtractEffectContext(Spec.GetContext());
	check(TypedContext);

	const FGameplayTagContainer* SourceTags = Spec.CapturedSourceTags.GetAggregatedTags();
	const FGameplayTagContainer* TargetTags = Spec.CapturedTargetTags.GetAggregatedTags();

	// 评估参数：带上源/目标标签，让属性聚合能正确计算
	FAggregatorEvaluateParameters EvaluateParameters;
	EvaluateParameters.SourceTags = SourceTags;
	EvaluateParameters.TargetTags = TargetTags;

	// 从捕获里取出基础伤害值
	float BaseDamage = 0.0f;
	ExecutionParams.AttemptCalculateCapturedAttributeMagnitude(DamageStatics().BaseDamageDef, EvaluateParameters, BaseDamage);

	// 从 EffectContext 里取"施加者"和"命中结果"
	const AActor* EffectCauser = TypedContext->GetEffectCauser();
	const FHitResult* HitActorResult = TypedContext->GetHitResult();

	AActor* HitActor = nullptr;
	FVector ImpactLocation = FVector::ZeroVector;
	FVector ImpactNormal = FVector::ZeroVector;
	FVector StartTrace = FVector::ZeroVector;
	FVector EndTrace = FVector::ZeroVector;

	// 命中 Actor、表面、区域、距离的计算都依赖"这次计算有没有命中结果"
	// 直接施加、没有经过瞄准的 GE 总是没有命中结果，必须退回到默认信息
	if (HitActorResult)
	{
		const FHitResult& CurHitResult = *HitActorResult;
		HitActor = CurHitResult.HitObjectHandle.FetchActor();
		if (HitActor)
		{
			ImpactLocation = CurHitResult.ImpactPoint;
			ImpactNormal = CurHitResult.ImpactNormal;
			StartTrace = CurHitResult.TraceStart;
			EndTrace = CurHitResult.TraceEnd;
		}
	}

	// 处理"没有命中结果"或"命中结果没返回 Actor"的情况
	UAbilitySystemComponent* TargetAbilitySystemComponent = ExecutionParams.GetTargetAbilitySystemComponent();
	if (!HitActor)
	{
		HitActor = TargetAbilitySystemComponent ? TargetAbilitySystemComponent->GetAvatarActor_Direct() : nullptr;
		if (HitActor)
		{
			ImpactLocation = HitActor->GetActorLocation();
		}
	}

	// 应用队伍伤害/自伤等规则
	float DamageInteractionAllowedMultiplier = 0.0f;
	if (HitActor)
	{
		UTenkaichiTeamSubsystem* TeamSubsystem = HitActor->GetWorld()->GetSubsystem<UTenkaichiTeamSubsystem>();
		if (ensure(TeamSubsystem))
		{
			DamageInteractionAllowedMultiplier = TeamSubsystem->CanCauseDamage(EffectCauser, HitActor) ? 1.0 : 0.0;
		}
	}

	// 计算距离
	double Distance = WORLD_MAX;

	if (TypedContext->HasOrigin())
	{
		Distance = FVector::Dist(TypedContext->GetOrigin(), ImpactLocation);
	}
	else if (EffectCauser)
	{
		Distance = FVector::Dist(EffectCauser->GetActorLocation(), ImpactLocation);
	}
	else
	{
		UE_LOG(LogTenkaichiAbilitySystem, Error, TEXT("Damage Calculation cannot deduce a source location for damage coming from %s; Falling back to WORLD_MAX dist!"), *GetPathNameSafe(Spec.Def));
	}

	// 应用技能来源修饰器（物理材质衰减 + 距离衰减）
	float PhysicalMaterialAttenuation = 1.0f;
	float DistanceAttenuation = 1.0f;
	if (const ITenkaichiAbilitySourceInterface* AbilitySource = TypedContext->GetAbilitySource())
	{
		if (const UPhysicalMaterial* PhysMat = TypedContext->GetPhysicalMaterial())
		{
			PhysicalMaterialAttenuation = AbilitySource->GetPhysicalMaterialAttenuation(PhysMat, SourceTags, TargetTags);
		}

		DistanceAttenuation = AbilitySource->GetDistanceAttenuation(Distance, SourceTags, TargetTags);
	}
	DistanceAttenuation = FMath::Max(DistanceAttenuation, 0.0f);

	// 钳制是在伤害被转成 -health 时做的
	const float DamageDone = FMath::Max(BaseDamage * DistanceAttenuation * PhysicalMaterialAttenuation * DamageInteractionAllowedMultiplier, 0.0f);

	if (DamageDone > 0.0f)
	{
		// 施加一个伤害修饰器，这会在目标上转成 -health
		OutExecutionOutput.AddOutputModifier(FGameplayModifierEvaluatedData(UTenkaichiHealthSet::GetDamageAttribute(), EGameplayModOp::Additive, DamageDone));
	}
#endif // #if WITH_SERVER_CODE
#endif // ⚠️【注释挂起】结束
}

### 2. 捕获定义（FDamageStatics）

```cpp
struct FDamageStatics
{
	FGameplayEffectAttributeCaptureDefinition BaseDamageDef;
	FDamageStatics()
	{
		BaseDamageDef = FGameplayEffectAttributeCaptureDefinition(UTenkaichiCombatSet::GetBaseDamageAttribute(), EGameplayEffectAttributeCaptureSource::Source, true);
	}
};
static FDamageStatics& DamageStatics()
{
	static FDamageStatics Statics;
	return Statics;
}
```

- **`FGameplayEffectAttributeCaptureDefinition`**：引擎结构，描述"要抓取哪个属性 + 从哪抓（源/目标）+ 是否可选"。
- **`EGameplayEffectAttributeCaptureSource::Source`**：从**来源**（施法者）抓 `BaseDamage`。
- **第三个参数 `true`**：`bSnapshot`，是否在 GE 施加时快照属性值。
- **`DamageStatics()`**：局部静态单例（函数内 static 只构造一次），Lyra 用这种模式避免重复构造。

### 3. 构造函数

```cpp

}
```

- `RelevantAttributesToCapture`：基类提供的捕获列表。Add 进去后，GAS 每次执行就会自动抓取 `BaseDamage`。

### 4. Execute_Implementation（伤害算法，⚠️ 挂起）

完整函数体已挂起，讲解逻辑（等 P05.5 + 阶段四就位后这些才会真正跑）：

1. **取 Spec + EffectContext**：`ExtractEffectContext` 拿到 `FTenkaichiGameplayEffectContext`，里面带着施加者、命中结果、技能来源、物理材质等。
2. **抓 BaseDamage**：`AttemptCalculateCapturedAttributeMagnitude` 用捕获定义把基础伤害算出来。
3. **命中处理**：有 `HitResult` 就取命中 Actor/撞击点/法线/起止点；没有就退回目标 ASC 的 AvatarActor 位置。
4. **队伍规则**：`TeamSubsystem->CanCauseDamage` 判断能不能打，不能打伤害倍率 = 0。
5. **距离衰减**：从 EffectContext 原点或施加者位置到撞击点算距离，交给 `GetDistanceAttenuation`。
6. **物理材质衰减**：命中表面的物理材质交给 `GetPhysicalMaterialAttenuation`。
7. **算最终伤害**：`BaseDamage × 距离衰减 × 物理材质衰减 × 队伍倍率`，钳到 ≥0。
8. **输出**：`AddOutputModifier` 把伤害以 `Additive` 方式加到 `HealthSet` 的 `Damage` 元属性。

## 六、几个要记住的点

1. **捕获定义是"声明我要什么"**：`RelevantAttributesToCapture` + `FGameplayEffectAttributeCaptureDefinition` 是 GAS 执行计算的固定写法。
2. **Execution 只算数值、不改状态**：它只输出 modifier，真正扣血由 HealthSet 的 `PostGameplayEffectExecute` 做。
3. **`WITH_SERVER_CODE`**：Lyra 把执行逻辑包在服务端宏里，客户端不跑伤害算法（伤害是服务端权威）。
4. **三档衰减**：队伍规则（0 或 1）+ 距离衰减 + 物理材质衰减，三者相乘。

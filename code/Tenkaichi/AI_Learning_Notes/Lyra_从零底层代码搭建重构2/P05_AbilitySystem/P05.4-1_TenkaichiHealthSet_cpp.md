# P05.4-1 HealthSet —— 教 .cpp

## 一、本文件要解决什么

把上一节 `.h` 声明的 HealthSet 落到真实实现。这是 GAS 伤害/治疗的核心逻辑。`TenkaichiHealthSet.cpp` 做五件事：

1. **定义 5 个 GameplayTag**（`.h` 只声明，`.cpp` 用 `UE_DEFINE_GAMEPLAY_TAG` 真正定义 + 给字符串值）。
2. **构造函数**：`Health`/`MaxHealth` 初始化为 `100.0f`。
3. **复制注册**：`Health`/`MaxHealth` 无条件复制（`COND_None`）。
4. **OnRep 回调**：复制回来后广播变化/归零委托。
5. **GE 生命周期逻辑**（重头戏）：
   - `PreGameplayEffectExecute`：**拦截**伤害（伤害免疫 / 上帝模式时伤害归零）。
   - `PostGameplayEffectExecute`：把 `Damage`/`Healing` **映射**成 `Health` 变化并钳制，广播委托，发伤害消息。
   - `Pre/PostAttributeChange`、`PreAttributeBaseChange`、`ClampAttribute`：**钳制**生命值（`0~MaxHealth`）、最大生命值（不低于 1）。

// Copyright Epic Games, Inc. All Rights Reserved.

#include "TenkaichiHealthSet.h"
#include "AbilitySystem/Attributes/TenkaichiAttributeSet.h"
#include "TenkaichiGameplayTags.h"
#include "Net/UnrealNetwork.h"
#include "AbilitySystem/TenkaichiAbilitySystemComponent.h"
#include "Engine/World.h"
#include "GameplayEffectExtension.h"
#include "Messages/TenkaichiVerbMessage.h"
#include "GameFramework/GameplayMessageSubsystem.h"

#include UE_INLINE_GENERATED_CPP_BY_NAME(TenkaichiHealthSet)

// 定义生命值相关的 GameplayTag 字符串值
UE_DEFINE_GAMEPLAY_TAG(TAG_Gameplay_Damage, "Gameplay.Damage");
UE_DEFINE_GAMEPLAY_TAG(TAG_Gameplay_DamageImmunity, "Gameplay.DamageImmunity");
UE_DEFINE_GAMEPLAY_TAG(TAG_Gameplay_DamageSelfDestruct, "Gameplay.Damage.SelfDestruct");
UE_DEFINE_GAMEPLAY_TAG(TAG_Gameplay_FellOutOfWorld, "Gameplay.Damage.FellOutOfWorld");
UE_DEFINE_GAMEPLAY_TAG(TAG_Tenkaichi_Damage_Message, "Tenkaichi.Damage.Message");

// 构造函数：生命值初始化为满血，并清零跟踪变量
UTenkaichiHealthSet::UTenkaichiHealthSet()
	: Health(100.0f)
	, MaxHealth(100.0f)
{
	bOutOfHealth = false;
	MaxHealthBeforeAttributeChange = 0.0f;
	HealthBeforeAttributeChange = 0.0f;
}

// 声明这两个属性的网络复制条件（无条件复制给所有人，变化时总是通知）
void UTenkaichiHealthSet::GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const
{
	Super::GetLifetimeReplicatedProps(OutLifetimeProps);

	DOREPLIFETIME_CONDITION_NOTIFY(UTenkaichiHealthSet, Health, COND_None, REPNOTIFY_Always);
	DOREPLIFETIME_CONDITION_NOTIFY(UTenkaichiHealthSet, MaxHealth, COND_None, REPNOTIFY_Always);
}

// Health 复制回来时的回调：广播生命值变化/归零事件（但没有施加者信息）
void UTenkaichiHealthSet::OnRep_Health(const FGameplayAttributeData& OldValue)
{
	GAMEPLAYATTRIBUTE_REPNOTIFY(UTenkaichiHealthSet, Health, OldValue);

	// 调用变化回调，但不带施加者（未来可改成显式 RPC）
	// 客户端上的这些事件不应再改变属性

	const float CurrentHealth = GetHealth();
	const float EstimatedMagnitude = CurrentHealth - OldValue.GetCurrentValue();
	
	OnHealthChanged.Broadcast(nullptr, nullptr, nullptr, EstimatedMagnitude, OldValue.GetCurrentValue(), CurrentHealth);

	if (!bOutOfHealth && CurrentHealth <= 0.0f)
	{
		OnOutOfHealth.Broadcast(nullptr, nullptr, nullptr, EstimatedMagnitude, OldValue.GetCurrentValue(), CurrentHealth);
	}

	bOutOfHealth = (CurrentHealth <= 0.0f);
}

// MaxHealth 复制回来时的回调：广播最大生命值变化事件
void UTenkaichiHealthSet::OnRep_MaxHealth(const FGameplayAttributeData& OldValue)
{
	GAMEPLAYATTRIBUTE_REPNOTIFY(UTenkaichiHealthSet, MaxHealth, OldValue);

	// 调用变化回调，但不带施加者（未来可改成显式 RPC）
	OnMaxHealthChanged.Broadcast(nullptr, nullptr, nullptr, GetMaxHealth() - OldValue.GetCurrentValue(), OldValue.GetCurrentValue(), GetMaxHealth());
}

// 游戏效果实际执行之前：处理伤害拦截（伤害免疫/上帝模式）、并保存当前生命值
bool UTenkaichiHealthSet::PreGameplayEffectExecute(FGameplayEffectModCallbackData &Data)
{
	if (!Super::PreGameplayEffectExecute(Data))
	{
		return false;
	}

	// 处理修改"传入的普通伤害"
	if (Data.EvaluatedData.Attribute == GetDamageAttribute())
	{
		if (Data.EvaluatedData.Magnitude > 0.0f)
		{
			const bool bIsDamageFromSelfDestruct = Data.EffectSpec.GetDynamicAssetTags().HasTagExact(TAG_Gameplay_DamageSelfDestruct);

			if (Data.Target.HasMatchingGameplayTag(TAG_Gameplay_DamageImmunity) && !bIsDamageFromSelfDestruct)
			{
				// 不扣生命值
				Data.EvaluatedData.Magnitude = 0.0f;
				return false;
			}

#if !UE_BUILD_SHIPPING
			// 检查上帝模式作弊（无限生命在下面检查）
			if (Data.Target.HasMatchingGameplayTag(TenkaichiGameplayTags::Cheat_GodMode) && !bIsDamageFromSelfDestruct)
			{
				// 不扣生命值
				Data.EvaluatedData.Magnitude = 0.0f;
				return false;
			}
#endif // #if !UE_BUILD_SHIPPING
		}
	}

	// 保存当前生命值
	HealthBeforeAttributeChange = GetHealth();
	MaxHealthBeforeAttributeChange = GetMaxHealth();

	return true;
}

// 游戏效果实际执行之后：把伤害/治疗映射成生命值变化、钳制并广播
void UTenkaichiHealthSet::PostGameplayEffectExecute(const FGameplayEffectModCallbackData& Data)
{
	Super::PostGameplayEffectExecute(Data);

	const bool bIsDamageFromSelfDestruct = Data.EffectSpec.GetDynamicAssetTags().HasTagExact(TAG_Gameplay_DamageSelfDestruct);
	float MinimumHealth = 0.0f;

#if !UE_BUILD_SHIPPING
	// 上帝模式和无限生命阻止死亡（除非是自毁）
	if (!bIsDamageFromSelfDestruct &&
		(Data.Target.HasMatchingGameplayTag(TenkaichiGameplayTags::Cheat_GodMode) || Data.Target.HasMatchingGameplayTag(TenkaichiGameplayTags::Cheat_UnlimitedHealth) ))
	{
		MinimumHealth = 1.0f;
	}
#endif // #if !UE_BUILD_SHIPPING

	const FGameplayEffectContextHandle& EffectContext = Data.EffectSpec.GetEffectContext();
	AActor* Instigator = EffectContext.GetOriginalInstigator();
	AActor* Causer = EffectContext.GetEffectCauser();

	if (Data.EvaluatedData.Attribute == GetDamageAttribute())
	{
		// 发送标准化的动词消息，供其他系统观察
		if (Data.EvaluatedData.Magnitude > 0.0f)
		{
			FTenkaichiVerbMessage Message;
			Message.Verb = TAG_Tenkaichi_Damage_Message;
			Message.Instigator = Data.EffectSpec.GetEffectContext().GetEffectCauser();
			Message.InstigatorTags = *Data.EffectSpec.CapturedSourceTags.GetAggregatedTags();
			Message.Target = GetOwningActor();
			Message.TargetTags = *Data.EffectSpec.CapturedTargetTags.GetAggregatedTags();
			//@TODO: 填充上下文标签，以及任何非能力系统的来源/施加者标签
			//@TODO: 判断是敌方击杀、自杀还是友军误伤等
			Message.Magnitude = Data.EvaluatedData.Magnitude;

			UGameplayMessageSubsystem& MessageSystem = UGameplayMessageSubsystem::Get(GetWorld());
			MessageSystem.BroadcastMessage(Message.Verb, Message);
		}

		// 转换成 -Health 然后钳制
		SetHealth(FMath::Clamp(GetHealth() - GetDamage(), MinimumHealth, GetMaxHealth()));
		SetDamage(0.0f);
	}
	else if (Data.EvaluatedData.Attribute == GetHealingAttribute())
	{
		// 转换成 +Health 然后钳制
		SetHealth(FMath::Clamp(GetHealth() + GetHealing(), MinimumHealth, GetMaxHealth()));
		SetHealing(0.0f);
	}
	else if (Data.EvaluatedData.Attribute == GetHealthAttribute())
	{
		// 钳制并落入下面的归零处理
		SetHealth(FMath::Clamp(GetHealth(), MinimumHealth, GetMaxHealth()));
	}
	else if (Data.EvaluatedData.Attribute == GetMaxHealthAttribute())
	{
		// TODO 钳制当前生命值?

		// 广播任何请求的最大生命值变化
		OnMaxHealthChanged.Broadcast(Instigator, Causer, &Data.EffectSpec, Data.EvaluatedData.Magnitude, MaxHealthBeforeAttributeChange, GetMaxHealth());
	}

	// 如果生命值确实变了，激活回调
	if (GetHealth() != HealthBeforeAttributeChange)
	{
		OnHealthChanged.Broadcast(Instigator, Causer, &Data.EffectSpec, Data.EvaluatedData.Magnitude, HealthBeforeAttributeChange, GetHealth());
	}

	if ((GetHealth() <= 0.0f) && !bOutOfHealth)
	{
		OnOutOfHealth.Broadcast(Instigator, Causer, &Data.EffectSpec, Data.EvaluatedData.Magnitude, HealthBeforeAttributeChange, GetHealth());
	}

	// 再检查一次生命值，以防上面的某个事件改了它
	bOutOfHealth = (GetHealth() <= 0.0f);
}

// 属性的基础值即将改变之前：钳制
void UTenkaichiHealthSet::PreAttributeBaseChange(const FGameplayAttribute& Attribute, float& NewValue) const
{
	Super::PreAttributeBaseChange(Attribute, NewValue);

	ClampAttribute(Attribute, NewValue);
}

// 属性当前值即将改变之前：钳制
void UTenkaichiHealthSet::PreAttributeChange(const FGameplayAttribute& Attribute, float& NewValue)
{
	Super::PreAttributeChange(Attribute, NewValue);

	ClampAttribute(Attribute, NewValue);
}

// 属性当前值改变之后：处理最大生命值变化对当前生命值的影响，并复位归零标记
void UTenkaichiHealthSet::PostAttributeChange(const FGameplayAttribute& Attribute, float OldValue, float NewValue)
{
	Super::PostAttributeChange(Attribute, OldValue, NewValue);

	if (Attribute == GetMaxHealthAttribute())
	{
		// 确保当前生命值不超过新的最大生命值
		if (GetHealth() > NewValue)
		{
			UTenkaichiAbilitySystemComponent* TenkaichiASC = GetTenkaichiAbilitySystemComponent();
			check(TenkaichiASC);

			TenkaichiASC->ApplyModToAttribute(GetHealthAttribute(), EGameplayModOp::Override, NewValue);
		}
	}

	if (bOutOfHealth && (GetHealth() > 0.0f))
	{
		bOutOfHealth = false;
	}
}

// 把属性值钳制到允许的范围（生命值 0~最大，最大生命值不低于 1）
void UTenkaichiHealthSet::ClampAttribute(const FGameplayAttribute& Attribute, float& NewValue) const
{
	if (Attribute == GetHealthAttribute())
	{
		// 不允许生命值变负或超过最大生命值
		NewValue = FMath::Clamp(NewValue, 0.0f, GetMaxHealth());
	}
	else if (Attribute == GetMaxHealthAttribute())
	{
		// 不允许最大生命值低于 1
		NewValue = FMath::Max(NewValue, 1.0f);
	}
}

- `TenkaichiVerbMessage.h` + `GameplayMessageSubsystem.h`：伤害广播消息。

### 3. OnRep 回调（客户端复制后广播）

- 复制回来后，用旧值算变化量 `EstimatedMagnitude`，广播 `OnHealthChanged`（施加者传 `nullptr`，因为客户端没有 instigator 信息）。
- 若生命值首次归零，广播 `OnOutOfHealth`，并更新 `bOutOfHealth` 标记（避免重复广播归零）。

### 4. PreGameplayEffectExecute（伤害拦截）

```cpp
bool UTenkaichiHealthSet::PreGameplayEffectExecute(FGameplayEffectModCallbackData &Data)
{
	if (!Super::PreGameplayEffectExecute(Data)) return false;

	if (Data.EvaluatedData.Attribute == GetDamageAttribute())
	{
		if (Data.EvaluatedData.Magnitude > 0.0f)
		{
			const bool bIsDamageFromSelfDestruct = Data.EffectSpec.GetDynamicAssetTags().HasTagExact(TAG_Gameplay_DamageSelfDestruct);

			if (Data.Target.HasMatchingGameplayTag(TAG_Gameplay_DamageImmunity) && !bIsDamageFromSelfDestruct)
			{
				Data.EvaluatedData.Magnitude = 0.0f;  // 伤害免疫：伤害归零
				return false;
			}
			// GodMode 同理（#if !UE_BUILD_SHIPPING 只在非发布版生效）
		}
	}
	HealthBeforeAttributeChange = GetHealth();
	MaxHealthBeforeAttributeChange = GetMaxHealth();
	return true;
}
```

- **在 GE 真正改属性前拦截**：如果目标有 `DamageImmunity`（伤害免疫）且不是自毁伤害 → 把伤害设 0 并返回 false（阻止执行）。
- **GodMode（上帝模式）**：`#if !UE_BUILD_SHIPPING`（只在非发布版编译）——作弊代码不放进正式版。
- 返回 true 前**保存当前生命值**（给 `Post` 比较用）。

### 5. PostGameplayEffectExecute（核心：伤害/治疗映射 + 广播）

```cpp
void UTenkaichiHealthSet::PostGameplayEffectExecute(const FGameplayEffectModCallbackData& Data)
{
	Super::PostGameplayEffectExecute(Data);

	// GodMode/UnlimitedHealth → MinimumHealth = 1（不会死）...

	AActor* Instigator = EffectContext.GetOriginalInstigator();
	AActor* Causer = EffectContext.GetEffectCauser();

	if (Data.EvaluatedData.Attribute == GetDamageAttribute())
	{
		// 发伤害消息 FTenkaichiVerbMessage（VerbMessage 子系统）
		// ...
		SetHealth(FMath::Clamp(GetHealth() - GetDamage(), MinimumHealth, GetMaxHealth()));
		SetDamage(0.0f);          // 清空伤害元属性
	}
	else if (Data.EvaluatedData.Attribute == GetHealingAttribute())
	{
		SetHealth(FMath::Clamp(GetHealth() + GetHealing(), MinimumHealth, GetMaxHealth()));
		SetHealing(0.0f);         // 清空治疗元属性
	}
	else if (Data.EvaluatedData.Attribute == GetHealthAttribute())
	{
		SetHealth(FMath::Clamp(GetHealth(), MinimumHealth, GetMaxHealth()));
	}
	else if (Data.EvaluatedData.Attribute == GetMaxHealthAttribute())
	{
		OnMaxHealthChanged.Broadcast(...);
	}

	// 生命值变了就广播变化
	if (GetHealth() != HealthBeforeAttributeChange)
	{
		OnHealthChanged.Broadcast(Instigator, Causer, &Data.EffectSpec, Data.EvaluatedData.Magnitude, HealthBeforeAttributeChange, GetHealth());
	}
	// 首次归零广播
	if ((GetHealth() <= 0.0f) && !bOutOfHealth)
	{
		OnOutOfHealth.Broadcast(...);
	}
	bOutOfHealth = (GetHealth() <= 0.0f);
}
```

**这段是伤害/治疗的"结算中心"**：
1. **伤害**：`Health -= Damage`（钳制在 `[MinimumHealth, MaxHealth]`），然后 `SetDamage(0)` 清空元属性。
2. **治疗**：`Health += Healing`，然后 `SetHealing(0)` 清空。
3. **直接改 Health/MaxHealth**：只钳制 + 广播。
4. **广播**：`OnHealthChanged`（生命值变化）、`OnOutOfHealth`（首次归零）——带真实的 `Instigator`/`Causer`。
5. **伤害消息**：用 `FTenkaichiVerbMessage` + `UGameplayMessageSubsystem` 广播（P01 教的 VerbMessage 总线），供击杀提示/伤害数字等系统监听。

### 6. 钳制 + 最大生命值联动

```cpp
void UTenkaichiHealthSet::ClampAttribute(const FGameplayAttribute& Attribute, float& NewValue) const
{
	if (Attribute == GetHealthAttribute())
	{
		NewValue = FMath::Clamp(NewValue, 0.0f, GetMaxHealth());  // 生命 0~最大
	}
	else if (Attribute == GetMaxHealthAttribute())
	{
		NewValue = FMath::Max(NewValue, 1.0f);  // 最大生命不低于 1
	}
}

void UTenkaichiHealthSet::PostAttributeChange(const FGameplayAttribute& Attribute, float OldValue, float NewValue)
{
	Super::PostAttributeChange(Attribute, OldValue, NewValue);

	if (Attribute == GetMaxHealthAttribute())
	{
		if (GetHealth() > NewValue)  // 最大生命降低到当前生命以下
		{
			UTenkaichiAbilitySystemComponent* TenkaichiASC = GetTenkaichiAbilitySystemComponent();
			check(TenkaichiASC);
			TenkaichiASC->ApplyModToAttribute(GetHealthAttribute(), EGameplayModOp::Override, NewValue);
		}
	}
	if (bOutOfHealth && (GetHealth() > 0.0f)) bOutOfHealth = false;
}
```

- **`ClampAttribute`**：任何生命值改动都钳到 `[0, MaxHealth]`；最大生命值不低于 1。
- **`PostAttributeChange`**：若最大生命降到当前生命以下 → 用 ASC 的 `ApplyModToAttribute(Override)` 把当前生命压到新最大值。
- `bOutOfHealth` 若生命值回升到 >0 则复位（复活）。

## 六、几个要记住的点

1. **`.h` 声明 tag、`.cpp` 定义 tag**：`UE_DECLARE_GAMEPLAY_TAG_EXTERN` / `UE_DEFINE_GAMEPLAY_TAG`。
2. **伤害/治疗的结算**：元属性（Damage/Healing）在 `PostGameplayEffectExecute` 里映射成 `Health` 变化，然后**清零**。
3. **三处广播**：`OnHealthChanged`（变化）、`OnOutOfHealth`（首次归零）、`OnMaxHealthChanged`（最大变化）。
4. **`#if !UE_BUILD_SHIPPING`**：作弊代码（GodMode/UnlimitedHealth）只在非发布版生效。
5. **伤害拦截在 `Pre`，结算在 `Post`**：`Pre` 决定"要不要扣"，`Post` 决定"扣多少 + 通知谁"。
6. **VerbMessage 总线**：伤害发一条 `FTenkaichiVerbMessage`（P01 教的），给击杀/伤害数字系统监听。

# P05.5-1 GameplayEffectContext —— 教 .h

## 一、本文件要解决什么

把总 md 里"效果上下文"这个核心结构落成真实的 `.h` 文件。`TenkaichiGameplayEffectContext.h` 定义一个 `FTenkaichiGameplayEffectContext`——**Lyra 对引擎 `FGameplayEffectContext` 的扩展**。

**为什么需要它**：引擎的 `FGameplayEffectContext` 只带基础信息（施加者、命中结果等），Lyra 要额外带"能力来源（武器/道具）"和"弹夹 ID"，所以扩展出这个结构体。

**本 `.h` 完成的事**：
1. 定义结构体 `FTenkaichiGameplayEffectContext`（继承引擎 `FGameplayEffectContext`）
2. 加 2 个新字段：`CartridgeID`（弹夹 ID）、`AbilitySourceObject`（能力来源弱引用）
3. 声明核心方法：`ExtractEffectContext`（从 handle 取出）、`SetAbilitySource`/`GetAbilitySource`、`GetPhysicalMaterial`、`Duplicate`、`NetSerialize`
4. 声明 `TStructOpsTypeTraits`（支持网络序列化 + 拷贝）

> 依赖只有引擎 `GameplayEffectTypes.h` + 前置声明（`ILyraAbilitySourceInterface` 等），**零挂起可编译**。

## 三、完整代码（注释已中文化）

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "GameplayEffectTypes.h"

#include "TenkaichiGameplayEffectContext.generated.h"

class AActor;
class FArchive;
class ITenkaichiAbilitySourceInterface;
class UObject;
class UPhysicalMaterial;

USTRUCT()
struct FTenkaichiGameplayEffectContext : public FGameplayEffectContext
{
	GENERATED_BODY()

	FTenkaichiGameplayEffectContext()
		: FGameplayEffectContext()
	{
	}

	FTenkaichiGameplayEffectContext(AActor* InInstigator, AActor* InEffectCauser)
		: FGameplayEffectContext(InInstigator, InEffectCauser)
	{
	}

	// 从 handle 里取出包裹的 FTenkaichiGameplayEffectContext，若不存在或类型不对则返回 nullptr
	static TENKAICHIGAME_API FTenkaichiGameplayEffectContext* ExtractEffectContext(struct FGameplayEffectContextHandle Handle);

	// 设置作为能力来源的对象
	void SetAbilitySource(const ITenkaichiAbilitySourceInterface* InObject, float InSourceLevel);

	// 返回与来源对象关联的能力来源接口。仅在权威端有效。
	const ITenkaichiAbilitySourceInterface* GetAbilitySource() const;

	virtual FGameplayEffectContext* Duplicate() const override
	{
		FTenkaichiGameplayEffectContext* NewContext = new FTenkaichiGameplayEffectContext();
		*NewContext = *this;
		if (GetHitResult())
		{
			// 对命中结果做深拷贝
			NewContext->AddHitResult(*GetHitResult(), true);
		}
		return NewContext;
	}

	virtual UScriptStruct* GetScriptStruct() const override
	{
		return FTenkaichiGameplayEffectContext::StaticStruct();
	}

	// 重写以序列化新增字段
	virtual bool NetSerialize(FArchive& Ar, class UPackageMap* Map, bool& bOutSuccess) override;

	// 若有命中结果则返回其物理材质
	const UPhysicalMaterial* GetPhysicalMaterial() const;

public:
	// 用于标识同一弹匣里多颗子弹的 ID
	UPROPERTY()
	int32 CartridgeID = -1;

protected:
	// 能力来源对象（应实现 ITenkaichiAbilitySourceInterface）。目前不复制。
	UPROPERTY()
	TWeakObjectPtr<const UObject> AbilitySourceObject;
};

template<>
struct TStructOpsTypeTraits<FTenkaichiGameplayEffectContext> : public TStructOpsTypeTraitsBase2<FTenkaichiGameplayEffectContext>
{
	enum
	{
		WithNetSerializer = true,
		WithCopy = true
	};
};
```

## 四、逐段讲解

### 1. 头文件与前置声明

```cpp
#include "GameplayEffectTypes.h"
#include "TenkaichiGameplayEffectContext.generated.h"

class AActor;
class FArchive;
class ITenkaichiAbilitySourceInterface;
class UObject;
class UPhysicalMaterial;
```

- `GameplayEffectTypes.h`：引擎 GAS 头，提供基类 `FGameplayEffectContext`。
- `TenkaichiGameplayEffectContext.generated.h`：UE 反射生成头。
- 前置声明 `ITenkaichiAbilitySourceInterface` 等：只声明不引完整定义（铁律 30，`.h` 前置声明不阻塞编译）。

### 2. 结构体声明 + 两个构造函数

```cpp
USTRUCT()
struct FTenkaichiGameplayEffectContext : public FGameplayEffectContext
{
	GENERATED_BODY()

	FTenkaichiGameplayEffectContext()
		: FGameplayEffectContext() {}

	FTenkaichiGameplayEffectContext(AActor* InInstigator, AActor* InEffectCauser)
		: FGameplayEffectContext(InInstigator, InEffectCauser) {}
```

- **注意这是 `USTRUCT()` 不是 `UCLASS()`**：效果上下文是数据载体，不是对象，用结构体。
- 继承引擎 `FGameplayEffectContext`。
- 两个构造函数：默认构造 + 带"施加者/效果发起者"的构造，都委托给基类。

### 3. 核心方法声明

- **`ExtractEffectContext`**：静态方法，从 `FGameplayEffectContextHandle` 里安全取出本类型（类型不对返回 nullptr）。这是 DamageExecution 里 `ExtractEffectContext` 的源头。
- **`SetAbilitySource` / `GetAbilitySource`**：设置/读取能力来源（武器/道具），内部用弱引用存。
- **`Duplicate`**：深拷贝（命中结果也要深拷贝）。
- **`GetScriptStruct`**：返回本结构体的反射信息（GAS 需要）。
- **`NetSerialize`**：网络序列化（`.cpp` 实现）。
- **`GetPhysicalMaterial`**：从命中结果取物理材质（DamageExecution 的物理材质衰减用）。

### 4. 两个新字段

```cpp
public:
	UPROPERTY()
	int32 CartridgeID = -1;

protected:
	UPROPERTY()
	TWeakObjectPtr<const UObject> AbilitySourceObject;
```

- **`CartridgeID`**：弹夹 ID，标识同一弹匣里的多颗子弹（网络同步）。
- **`AbilitySourceObject`**：能力来源的弱引用（`TWeakObjectPtr` 防止悬空指针），目前不复制。

### 5. TStructOpsTypeTraits（关键）

```cpp
template<>
struct TStructOpsTypeTraits<FTenkaichiGameplayEffectContext> : public TStructOpsTypeTraitsBase2<FTenkaichiGameplayEffectContext>
{
	enum { WithNetSerializer = true, WithCopy = true };
};
```

- **`WithNetSerializer = true`**：告诉 UE 这个结构体有自定义网络序列化（`NetSerialize`）。
- **`WithCopy = true`**：告诉 UE 用自定义 `Duplicate` 拷贝（不是默认 memcpy）。
- 这是 USTRUCT 要支持网络复制 + 深拷贝的固定写法。

## 五、几个要记住的点

1. **它是结构体不是类**：`USTRUCT()` + 继承引擎 `FGameplayEffectContext`，是"效果身份证"的数据载体。
2. **`ExtractEffectContext` 是核心入口**：DamageExecution 靠它从 handle 里安全取出本类型，取不到就 nullptr。
3. **`TStructOpsTypeTraits` 是网络复制的钥匙**：`WithNetSerializer` + `WithCopy` 让它能跨网络 + 深拷贝。
4. **零挂起**：只依赖引擎 GAS + 前置声明，`.h` 可独立编译。

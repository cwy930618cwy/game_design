# P05.4-1 HealthSet —— 教 .h

## 一、本文件要解决什么

`TenkaichiHealthSet.h` 是 AttributeSet 主题里**最核心的类**——定义"生命值"相关的属性。它比前两个类复杂，要处理：

1. **4 个属性**：`Health`（当前生命值）、`MaxHealth`（最大生命值）、`Healing`（元属性-治疗）、`Damage`（元属性-伤害）。
2. **3 个委托**：生命值变化、最大生命值变化、生命值归零——用来广播给 UI/逻辑。
3. **5 个 GameplayTag 声明**：伤害、伤害免疫、自毁、坠落、伤害消息。
4. **一组 GE 生命周期虚函数**：在伤害/治疗执行前后钳制生命值（生命值不能超过最大、不能低于 0）。

**一句话**：CombatSet 提供"伤害/治疗的基础量"，HealthSet 提供"真正的生命值"，并保证生命值在合理范围内。

## 三、完整代码（注释已中文化）

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "AbilitySystemComponent.h"
#include "TenkaichiAttributeSet.h"
#include "NativeGameplayTags.h"

#include "TenkaichiHealthSet.generated.h"

#define UE_API TENKAICHIGAME_API

class UObject;
struct FFrame;

TENKAICHIGAME_API UE_DECLARE_GAMEPLAY_TAG_EXTERN(TAG_Gameplay_Damage);
TENKAICHIGAME_API UE_DECLARE_GAMEPLAY_TAG_EXTERN(TAG_Gameplay_DamageImmunity);
TENKAICHIGAME_API UE_DECLARE_GAMEPLAY_TAG_EXTERN(TAG_Gameplay_DamageSelfDestruct);
TENKAICHIGAME_API UE_DECLARE_GAMEPLAY_TAG_EXTERN(TAG_Gameplay_FellOutOfWorld);
TENKAICHIGAME_API UE_DECLARE_GAMEPLAY_TAG_EXTERN(TAG_Tenkaichi_Damage_Message);

struct FGameplayEffectModCallbackData;


/**
 * UTenkaichiHealthSet
 *
 *	定义承受伤害所必需的属性的类。
 *	属性示例包括：生命值、护盾和抗性。
 */
UCLASS(MinimalAPI, BlueprintType)
class UTenkaichiHealthSet : public UTenkaichiAttributeSet
{
	GENERATED_BODY()

public:

	// 构造函数
	UE_API UTenkaichiHealthSet();

	// 为 Health 生成访问函数（Get/Set/Init/GetAttribute）
	ATTRIBUTE_ACCESSORS(UTenkaichiHealthSet, Health);
	// 为 MaxHealth 生成访问函数（Get/Set/Init/GetAttribute）
	ATTRIBUTE_ACCESSORS(UTenkaichiHealthSet, MaxHealth);
	// 为 Healing 生成访问函数（Get/Set/Init/GetAttribute）
	ATTRIBUTE_ACCESSORS(UTenkaichiHealthSet, Healing);
	// 为 Damage 生成访问函数（Get/Set/Init/GetAttribute）
	ATTRIBUTE_ACCESSORS(UTenkaichiHealthSet, Damage);

	// 生命值因伤害/治疗而变化时的委托（客户端上部分信息可能缺失）
	mutable FTenkaichiAttributeEvent OnHealthChanged;

	// 最大生命值变化时的委托
	mutable FTenkaichiAttributeEvent OnMaxHealthChanged;

	// 生命值归零时要广播的委托
	mutable FTenkaichiAttributeEvent OnOutOfHealth;

protected:

	// Health 复制回来时的回调
	UFUNCTION()
	UE_API void OnRep_Health(const FGameplayAttributeData& OldValue);

	// MaxHealth 复制回来时的回调
	UFUNCTION()
	UE_API void OnRep_MaxHealth(const FGameplayAttributeData& OldValue);

	// 在游戏效果实际执行之前调用（处理伤害/治疗前的时机）
	UE_API virtual bool PreGameplayEffectExecute(FGameplayEffectModCallbackData& Data) override;
	// 在游戏效果实际执行之后调用（把伤害/治疗算进生命值）
	UE_API virtual void PostGameplayEffectExecute(const FGameplayEffectModCallbackData& Data) override;

	// 在属性的基础值即将改变之前调用
	UE_API virtual void PreAttributeBaseChange(const FGameplayAttribute& Attribute, float& NewValue) const override;
	// 在属性值即将改变之前调用
	UE_API virtual void PreAttributeChange(const FGameplayAttribute& Attribute, float& NewValue) override;
	// 在属性值改变之后调用
	UE_API virtual void PostAttributeChange(const FGameplayAttribute& Attribute, float OldValue, float NewValue) override;

	// 把属性值钳制到允许的范围内
	UE_API void ClampAttribute(const FGameplayAttribute& Attribute, float& NewValue) const;

private:

	// 当前生命值属性。生命值会被最大生命值封顶。生命值对修饰器隐藏，只能由执行（Executions）修改。
	UPROPERTY(BlueprintReadOnly, ReplicatedUsing = OnRep_Health, Category = "Tenkaichi|Health", Meta = (HideFromModifiers, AllowPrivateAccess = true))
	FGameplayAttributeData Health;

	// 当前最大生命值属性。最大生命值也是属性，因为游戏效果可以修改它。
	UPROPERTY(BlueprintReadOnly, ReplicatedUsing = OnRep_MaxHealth, Category = "Tenkaichi|Health", Meta = (AllowPrivateAccess = true))
	FGameplayAttributeData MaxHealth;

	// 用来跟踪生命值是否归零
	bool bOutOfHealth;

	// 在任何变化之前保存生命值
	float MaxHealthBeforeAttributeChange;
	float HealthBeforeAttributeChange;

	// -------------------------------------------------------------------
	//	元属性（请把不"有状态"的属性放在下面）
	// -------------------------------------------------------------------

	// 传入的治疗量。直接映射到 +Health
	UPROPERTY(BlueprintReadOnly, Category="Tenkaichi|Health", Meta=(AllowPrivateAccess=true))
	FGameplayAttributeData Healing;

	// 传入的伤害量。直接映射到 -Health
	UPROPERTY(BlueprintReadOnly, Category="Tenkaichi|Health", Meta=(HideFromModifiers, AllowPrivateAccess=true))
	FGameplayAttributeData Damage;
};

#undef UE_API
```

## 四、逐段讲解

### 1. 头文件与 API 宏

```cpp
#define UE_API TENKAICHIGAME_API
...
TENKAICHIGAME_API UE_DECLARE_GAMEPLAY_TAG_EXTERN(TAG_Gameplay_Damage);
...
#undef UE_API
```

- **`#define UE_API TENKAICHIGAME_API`**：把 `UE_API` 临时重定义为 `TENKAICHIGAME_API`（模块导出宏），这样类里所有方法都默认带导出。文件末尾 `#undef UE_API` 撤销，不影响其他文件。
- **`UE_DECLARE_GAMEPLAY_TAG_EXTERN(TAG_Gameplay_Damage)`**：声明一个**外部 GameplayTag**（"这个 tag 在别的文件里定义，这里只是声明"）。具体值在 `.cpp` 里用 `UE_DEFINE_GAMEPLAY_TAG` 定义。
- 5 个 tag：`TAG_Gameplay_Damage`（伤害）、`TAG_Gameplay_DamageImmunity`（伤害免疫）、`TAG_Gameplay_DamageSelfDestruct`（自毁）、`TAG_Gameplay_FellOutOfWorld`（坠落出世界）、`TAG_Tenkaichi_Damage_Message`（伤害消息）。

### 2. 类声明 + 4 个属性访问宏 + 3 个委托

```cpp
UCLASS(MinimalAPI, BlueprintType)
class UTenkaichiHealthSet : public UTenkaichiAttributeSet
{
public:
	UE_API UTenkaichiHealthSet();
	ATTRIBUTE_ACCESSORS(UTenkaichiHealthSet, Health);
	ATTRIBUTE_ACCESSORS(UTenkaichiHealthSet, MaxHealth);
	ATTRIBUTE_ACCESSORS(UTenkaichiHealthSet, Healing);
	ATTRIBUTE_ACCESSORS(UTenkaichiHealthSet, Damage);

	mutable FTenkaichiAttributeEvent OnHealthChanged;
	mutable FTenkaichiAttributeEvent OnMaxHealthChanged;
	mutable FTenkaichiAttributeEvent OnOutOfHealth;
```

- **`UCLASS(MinimalAPI, BlueprintType)`**：`MinimalAPI` = 只导出少量 API（配合 `UE_API` 逐方法导出，省体积）；`BlueprintType` = 蓝图可用。
- **4 个 `ATTRIBUTE_ACCESSORS`**：给 `Health`/`MaxHealth`/`Healing`/`Damage` 各生成一组访问函数。
- **3 个 `mutable FTenkaichiAttributeEvent`**：`mutable`（const 方法里也能改，方便在 const 回调里广播）、`FTenkaichiAttributeEvent` 是基类定义的委托（`FGameplayAttributeData` 参数，见基类 md）。

### 3. GE 生命周期虚函数 + 复制回调

```cpp
protected:
	UFUNCTION()
	UE_API void OnRep_Health(const FGameplayAttributeData& OldValue);
	UE_API void OnRep_MaxHealth(const FGameplayAttributeData& OldValue);

	UE_API virtual bool PreGameplayEffectExecute(FGameplayEffectModCallbackData& Data) override;
	UE_API virtual void PostGameplayEffectExecute(const FGameplayEffectModCallbackData& Data) override;

	UE_API virtual void PreAttributeBaseChange(const FGameplayAttribute& Attribute, float& NewValue) const override;
	UE_API virtual void PreAttributeChange(const FGameplayAttribute& Attribute, float& NewValue) override;
	UE_API virtual void PostAttributeChange(const FGameplayAttribute& Attribute, float OldValue, float NewValue) override;

	UE_API void ClampAttribute(const FGameplayAttribute& Attribute, float& NewValue) const;
```

- **`OnRep_Health`/`OnRep_MaxHealth`**：网络复制回调（同 CombatSet 的 `OnRep_BaseDamage`）。
- **`PreGameplayEffectExecute`**：GE 真正修改属性**之前**调用。这里可拦截（返回 false 阻止）。
- **`PostGameplayEffectExecute`**：GE 真正修改属性**之后**调用。**核心**：把 `Damage`/`Healing` 元属性**映射**到 `Health`（`Health -= Damage`、`Health += Healing`），再清零元属性。
- **`PreAttributeBaseChange`**：属性**基础值**改变前。
- **`PreAttributeChange`**：属性**当前值**改变前（钳制生命值在这）。
- **`PostAttributeChange`**：属性当前值改变后。
- **`ClampAttribute`**：把属性值钳制到 `[0, MaxHealth]`。

> 这些虚函数的**具体逻辑**在 `.cpp` 里展开，`.h` 只声明。

### 4. 私有属性（状态属性 + 元属性）

```cpp
private:
	UPROPERTY(BlueprintReadOnly, ReplicatedUsing = OnRep_Health, Category = "Tenkaichi|Health", Meta = (HideFromModifiers, AllowPrivateAccess = true))
	FGameplayAttributeData Health;
	UPROPERTY(BlueprintReadOnly, ReplicatedUsing = OnRep_MaxHealth, Category = "Tenkaichi|Health", Meta = (AllowPrivateAccess = true))
	FGameplayAttributeData MaxHealth;

	bool bOutOfHealth;
	float MaxHealthBeforeAttributeChange;
	float HealthBeforeAttributeChange;

	UPROPERTY(BlueprintReadOnly, Category="Tenkaichi|Health", Meta=(AllowPrivateAccess=true))
	FGameplayAttributeData Healing;
	UPROPERTY(BlueprintReadOnly, Category="Tenkaichi|Health", Meta=(HideFromModifiers, AllowPrivateAccess=true))
	FGameplayAttributeData Damage;
```

- **`Health`**：当前生命值。`HideFromModifiers` = **对修饰器隐藏**，只能由执行（`Executions/`）改它，防止 GE 直接改。
- **`MaxHealth`**：最大生命值。普通属性，GE 可改（比如加血上限 buff）。
- **`bOutOfHealth`**：记录是否归零（`PostGameplayEffectExecute` 里判断用）。
- **`MaxHealthBeforeAttributeChange`/`HealthBeforeAttributeChange`**：变化前的旧值缓存（钳制后要还原比例用）。
- **`Healing`**/**`Damage`**：**元属性**（meta attribute）——不是"状态"，只是"临时输入桶"。`PostGameplayEffectExecute` 把 `Damage` 映射为 `-Health`、`Healing` 映射为 `+Health`，然后清零。这也是为什么它们**不复制、不 HideFromModifiers 也只在 Damage 上**。

## 五、几个要记住的点

1. **状态属性 vs 元属性**：`Health`/`MaxHealth` 是状态（有复制、有 OnRep）；`Healing`/`Damage` 是"临时输入桶"（不复制，算完就清零）。
2. **`HideFromModifiers`**：`Health`/`Damage` 对修饰器隐藏，只能靠执行（Executions）间接改。
3. **委托 `mutable`**：const 回调里也能广播。
4. **GameplayTag 声明在 `.h`、定义在 `.cpp`**：`UE_DECLARE_GAMEPLAY_TAG_EXTERN`（.h）/ `UE_DEFINE_GAMEPLAY_TAG`（.cpp）。
5. **`#define UE_API`**：临时重定义导出宏，配合 `MinimalAPI` 逐方法导出。
6. **`.cpp` 是重头戏**：伤害/治疗映射、钳制、归零广播全在 `.cpp`。

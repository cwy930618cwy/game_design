# P05.3-3 GlobalAbilitySystem —— 教 .h

## 一、本文件要解决什么

把上一节总 md 的"全局技能系统"落成真实的 `.h` 文件。`TenkaichiGlobalAbilitySystem.h` 里有**三种东西**：
两个 USTRUCT（`FGlobalAppliedAbilityList` / `FGlobalAppliedEffectList`）+ 一个 UCLASS（`UTenkaichiGlobalAbilitySystem`）。

- 两个 USTRUCT：记录"某个全局技能/效果 → 已授给哪些 ASC、句柄是多少"的映射表。
- UCLASS：全局系统本体，提供批量授予/移除 + ASC 注册/注销。

## 三、完整代码（注释已中文化）

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "ActiveGameplayEffectHandle.h"
#include "Subsystems/WorldSubsystem.h"
#include "GameplayAbilitySpecHandle.h"
#include "Templates/SubclassOf.h"

#include "TenkaichiGlobalAbilitySystem.generated.h"

class UGameplayAbility;
class UGameplayEffect;
class UTenkaichiAbilitySystemComponent;
class UObject;
struct FActiveGameplayEffectHandle;
struct FFrame;
struct FGameplayAbilitySpecHandle;

/** 记录「一个全局技能」被授给了哪些 ASC、各自的技能句柄是什么 */
USTRUCT()
struct FGlobalAppliedAbilityList
{
	GENERATED_BODY()

	UPROPERTY()
	TMap<TObjectPtr<UTenkaichiAbilitySystemComponent>, FGameplayAbilitySpecHandle> Handles;

	// 把这个全局技能授给指定的 ASC
	void AddToASC(TSubclassOf<UGameplayAbility> Ability, UTenkaichiAbilitySystemComponent* ASC);
	// 从指定的 ASC 上移除这个全局技能
	void RemoveFromASC(UTenkaichiAbilitySystemComponent* ASC);
	// 从所有 ASC 上移除这个全局技能
	void RemoveFromAll();
};

/** 记录「一个全局效果」被加到了哪些 ASC、各自的效果句柄是什么 */
USTRUCT()
struct FGlobalAppliedEffectList
{
	GENERATED_BODY()

	UPROPERTY()
	TMap<TObjectPtr<UTenkaichiAbilitySystemComponent>, FActiveGameplayEffectHandle> Handles;

	// 把这个全局效果加给指定的 ASC
	void AddToASC(TSubclassOf<UGameplayEffect> Effect, UTenkaichiAbilitySystemComponent* ASC);
	// 从指定的 ASC 上移除这个全局效果
	void RemoveFromASC(UTenkaichiAbilitySystemComponent* ASC);
	// 从所有 ASC 上移除这个全局效果
	void RemoveFromAll();
};

/** 全局技能系统：给世界里的所有 ASC 批量授予/移除技能和效果 */
UCLASS()
class UTenkaichiGlobalAbilitySystem : public UWorldSubsystem
{
	GENERATED_BODY()

public:
	// 构造函数
	UTenkaichiGlobalAbilitySystem();

	// 把技能授给所有已注册的 ASC（仅服务器授权）
	UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly, Category="Tenkaichi")
	void ApplyAbilityToAll(TSubclassOf<UGameplayAbility> Ability);

	// 把效果加给所有已注册的 ASC（仅服务器授权）
	UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly, Category="Tenkaichi")
	void ApplyEffectToAll(TSubclassOf<UGameplayEffect> Effect);

	// 把所有 ASC 上的这个技能移除（仅服务器授权）
	UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly, Category = "Tenkaichi")
	void RemoveAbilityFromAll(TSubclassOf<UGameplayAbility> Ability);

	// 把所有 ASC 上的这个效果移除（仅服务器授权）
	UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly, Category = "Tenkaichi")
	void RemoveEffectFromAll(TSubclassOf<UGameplayEffect> Effect);

	/** 把某个 ASC 注册进全局系统，并补授所有已全局应用的技能/效果 */
	void RegisterASC(UTenkaichiAbilitySystemComponent* ASC);

	/** 把某个 ASC 从全局系统移除，并移除它身上所有全局应用的技能/效果 */
	void UnregisterASC(UTenkaichiAbilitySystemComponent* ASC);

private:
	UPROPERTY()
	TMap<TSubclassOf<UGameplayAbility>, FGlobalAppliedAbilityList> AppliedAbilities;

	UPROPERTY()
	TMap<TSubclassOf<UGameplayEffect>, FGlobalAppliedEffectList> AppliedEffects;

	UPROPERTY()
	TArray<TObjectPtr<UTenkaichiAbilitySystemComponent>> RegisteredASCs;
};
```

## 四、逐段讲解

### 1. 头文件与前置声明

```cpp
#pragma once
#include "ActiveGameplayEffectHandle.h"
#include "Subsystems/WorldSubsystem.h"
#include "GameplayAbilitySpecHandle.h"
#include "Templates/SubclassOf.h"
#include "TenkaichiGlobalAbilitySystem.generated.h"

class UGameplayAbility;
class UGameplayEffect;
class UTenkaichiAbilitySystemComponent;
class UObject;
struct FActiveGameplayEffectHandle;
struct FFrame;
struct FGameplayAbilitySpecHandle;
```

- 四个 `#include`：`ActiveGameplayEffectHandle.h`（效果句柄）、`WorldSubsystem.h`（基类）、
  `GameplayAbilitySpecHandle.h`（技能句柄）、`SubclassOf.h`（`TSubclassOf` 模板）。
- `generated.h` 放最后。
- 一堆前置声明：`.h` 里只用这些类型的**指针/句柄**，前置声明足够，不用 include 完整定义 →
  `.h` 可独立编译零挂起。`UTenkaichiAbilitySystemComponent` 也前置声明（P05.2 虽已落盘，但 `.h`
  不必 include，保持轻依赖，和 Lyra 一致）。

### 2. FGlobalAppliedAbilityList（技能映射表）

```cpp
USTRUCT()
struct FGlobalAppliedAbilityList
{
	GENERATED_BODY()

	UPROPERTY()
	TMap<TObjectPtr<UTenkaichiAbilitySystemComponent>, FGameplayAbilitySpecHandle> Handles;

	void AddToASC(TSubclassOf<UGameplayAbility> Ability, UTenkaichiAbilitySystemComponent* ASC);
	void RemoveFromASC(UTenkaichiAbilitySystemComponent* ASC);
	void RemoveFromAll();
};
```

- `USTRUCT()` + `GENERATED_BODY()`：这是**反射结构体**（可被 UPROPERTY 引用、序列化）。
- `Handles`：一个 `TMap`，键是某个 ASC，值是这个 ASC 上那个技能的 `FGameplayAbilitySpecHandle`。
  **一个全局技能 → 这张表记录它被授给的所有 ASC 和对应句柄**。
- 三个方法：`AddToASC`（授给单个 ASC）、`RemoveFromASC`（从单个 ASC 移除）、`RemoveFromAll`（全部移除）。
  注意这三个方法**没有 `U` 前缀的类，是普通 C++ 结构体方法**，在 `.cpp` 实现。

### 3. FGlobalAppliedEffectList（效果映射表）

```cpp
USTRUCT()
struct FGlobalAppliedEffectList
{
	GENERATED_BODY()

	UPROPERTY()
	TMap<TObjectPtr<UTenkaichiAbilitySystemComponent>, FActiveGameplayEffectHandle> Handles;

	void AddToASC(TSubclassOf<UGameplayEffect> Effect, UTenkaichiAbilitySystemComponent* ASC);
	void RemoveFromASC(UTenkaichiAbilitySystemComponent* ASC);
	void RemoveFromAll();
};
```

- 和上面结构**几乎一模一样**，只是存的是**效果**：`TMap<ASC, FActiveGameplayEffectHandle>`。
- 键不变（哪个 ASC），值是效果句柄 `FActiveGameplayEffectHandle`。

### 4. UTenkaichiGlobalAbilitySystem（全局系统本体）

```cpp
UCLASS()
class UTenkaichiGlobalAbilitySystem : public UWorldSubsystem
{
	GENERATED_BODY()
public:
	UTenkaichiGlobalAbilitySystem();
	...
};
```

- `UCLASS()` + `GENERATED_BODY()` + `UWorldSubsystem` 基类：**每世界一个**的全局系统，生命周期跟着世界走。
- 构造函数空实现（`.cpp` 里）。

### 5. 四个批量操作（蓝图标）

```cpp
UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly, Category="Tenkaichi")
void ApplyAbilityToAll(TSubclassOf<UGameplayAbility> Ability);

UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly, Category="Tenkaichi")
void ApplyEffectToAll(TSubclassOf<UGameplayEffect> Effect);

UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly, Category = "Tenkaichi")
void RemoveAbilityFromAll(TSubclassOf<UGameplayAbility> Ability);

UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly, Category = "Tenkaichi")
void RemoveEffectFromAll(TSubclassOf<UGameplayEffect> Effect);
```

- `BlueprintCallable`：可在蓝图里调用。
- `BlueprintAuthorityOnly`：**只在服务器端生效**（客户端调了也不执行）——防止客户端作弊改全局技能。
- `Category="Tenkaichi"`：蓝图面板分组（前缀替换时 `Lyra`→`Tenkaichi`）。
- 参数 `TSubclassOf<UGameplayAbility>`：要全局应用的**技能类**（不是实例）。

### 6. 注册/注销

```cpp
void RegisterASC(UTenkaichiAbilitySystemComponent* ASC);
void UnregisterASC(UTenkaichiAbilitySystemComponent* ASC);
```

- 没有 `UFUNCTION` 宏：**C++ 内部调用**，不暴露给蓝图。
- `RegisterASC`：ASC 初始化完成时调用，补授所有已全局应用的技能/效果，并记入 `RegisteredASCs`。
- `UnregisterASC`：ASC 销毁时调用，移除它身上所有全局技能/效果，并从列表剔除。
- **这两个方法正是 P05.2 ASC.cpp 挂起段（㉓）里调用的**——ASC 的 `EndPlay` 调 `UnregisterASC`，
  `InitAbilityActorInfo` 里调 `RegisterASC`。

### 7. 私有数据

```cpp
private:
	UPROPERTY()
	TMap<TSubclassOf<UGameplayAbility>, FGlobalAppliedAbilityList> AppliedAbilities;

	UPROPERTY()
	TMap<TSubclassOf<UGameplayEffect>, FGlobalAppliedEffectList> AppliedEffects;

	UPROPERTY()
	TArray<TObjectPtr<UTenkaichiAbilitySystemComponent>> RegisteredASCs;
```

- `AppliedAbilities`：已全局应用的**技能类 → 它的授予表**。
- `AppliedEffects`：已全局应用的**效果类 → 它的应用表**。
- `RegisteredASCs`：所有已注册的 ASC 列表（新注册的 ASC 会把上面两表里的内容补授给它）。

## 五、几个要记住的点

1. **USTRUCT + UCLASS 混搭**：一个 `.h` 里两个反射结构体 + 一个反射类，是全局系统的"数据表 + 操作入口"结构。
2. **BlueprintAuthorityOnly**：全局批量操作只允许服务器做，防止客户端作弊。
3. **TSubclassOf<UGameplayAbility>**：传的是**类**（CDO 配置），不是具体实例——`.cpp` 里靠 CDO 造技能。
4. **`.h` 零挂起**：所有依赖只用前置声明/指针，`UTenkaichiAbilitySystemComponent` 也前置声明。

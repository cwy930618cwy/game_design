# P05.4-1 CombatSet —— 教 .cpp

## 一、本文件要解决什么

把上一节 `.h` 声明的 CombatSet 落到真实实现。`TenkaichiCombatSet.cpp` 做四件事：

1. **构造函数**：把 `BaseDamage`/`BaseHeal` 初始化为 `0.0f`。
2. **`GetLifetimeReplicatedProps`**：声明两个属性的网络复制条件（仅所有者收到、变化时总是通知）。
3. **两个 `OnRep_*` 回调**：属性复制回来后，调用 GAS 的 `GAMEPLAYATTRIBUTE_REPNOTIFY` 宏，通知 GAS"属性值变了"。

## 三、完整代码（注释已中文化）

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

#include "TenkaichiCombatSet.h"

#include "AbilitySystem/Attributes/TenkaichiAttributeSet.h"
#include "Net/UnrealNetwork.h"

#include UE_INLINE_GENERATED_CPP_BY_NAME(TenkaichiCombatSet)

class FLifetimeProperty;


// 构造函数：把两个战斗属性的初始值设为 0
UTenkaichiCombatSet::UTenkaichiCombatSet()
	: BaseDamage(0.0f)
	, BaseHeal(0.0f)
{
}

// 声明这两个属性的网络复制条件（仅所有者收到，且变化时总是通知）
void UTenkaichiCombatSet::GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const
{
	Super::GetLifetimeReplicatedProps(OutLifetimeProps);

	DOREPLIFETIME_CONDITION_NOTIFY(UTenkaichiCombatSet, BaseDamage, COND_OwnerOnly, REPNOTIFY_Always);
	DOREPLIFETIME_CONDITION_NOTIFY(UTenkaichiCombatSet, BaseHeal, COND_OwnerOnly, REPNOTIFY_Always);
}

// BaseDamage 复制回来时的回调：通知 GAS 属性值变了
void UTenkaichiCombatSet::OnRep_BaseDamage(const FGameplayAttributeData& OldValue)
{
	GAMEPLAYATTRIBUTE_REPNOTIFY(UTenkaichiCombatSet, BaseDamage, OldValue);
}

// BaseHeal 复制回来时的回调：通知 GAS 属性值变了
void UTenkaichiCombatSet::OnRep_BaseHeal(const FGameplayAttributeData& OldValue)
{
	GAMEPLAYATTRIBUTE_REPNOTIFY(UTenkaichiCombatSet, BaseHeal, OldValue);
}
```

## 四、逐段讲解

### 1. 头文件与复制宏

```cpp
#include "TenkaichiCombatSet.h"

#include "AbilitySystem/Attributes/TenkaichiAttributeSet.h"
#include "Net/UnrealNetwork.h"

#include UE_INLINE_GENERATED_CPP_BY_NAME(TenkaichiCombatSet)

class FLifetimeProperty;
```

- `TenkaichiCombatSet.h`：本类自己的头。
- `AbilitySystem/Attributes/TenkaichiAttributeSet.h`：**基类**——因为构造函数里调用了 `Super::GetLifetimeReplicatedProps`（基类的方法），需要完整 include 基类。注意路径是 `AbilitySystem/Attributes/`（Lyra 一比一）。
- `Net/UnrealNetwork.h`：`DOREPLIFETIME_*` 复制宏。
- `UE_INLINE_GENERATED_CPP_BY_NAME(TenkaichiCombatSet)`：UE 内联反射代码生成宏。
- `class FLifetimeProperty;`：前置声明（`GetLifetimeReplicatedProps` 的 `TArray<FLifetimeProperty>&` 参数）。

### 2. 构造函数

```cpp
UTenkaichiCombatSet::UTenkaichiCombatSet()
	: BaseDamage(0.0f)
	, BaseHeal(0.0f)
{
}
```

- 用初始化列表把两个属性设成 `0.0f`（默认基础伤害/治疗为 0）。

### 3. GetLifetimeReplicatedProps（网络复制注册）

```cpp
void UTenkaichiCombatSet::GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const
{
	Super::GetLifetimeReplicatedProps(OutLifetimeProps);

	DOREPLIFETIME_CONDITION_NOTIFY(UTenkaichiCombatSet, BaseDamage, COND_OwnerOnly, REPNOTIFY_Always);
	DOREPLIFETIME_CONDITION_NOTIFY(UTenkaichiCombatSet, BaseHeal, COND_OwnerOnly, REPNOTIFY_Always);
}
```

- **每个要网络复制的 USTRUCT/属性都要在 `GetLifetimeReplicatedProps` 里注册**，否则不复制。
- 先 `Super::GetLifetimeReplicatedProps`（让基类注册它自己的复制属性）。
- `DOREPLIFETIME_CONDITION_NOTIFY(类, 属性, 条件, 通知)`：
  - `COND_OwnerOnly`：**只复制给属性的所有者**（玩家本人），其他人看不到这个值。
  - `REPNOTIFY_Always`：值变化时**总是触发 `OnRep` 通知**（即使新旧值相同也通知）。
- 这跟 `.h` 里 `ReplicatedUsing = OnRep_BaseDamage` 配套：`.h` 声明"复制到客户端时调哪个回调"，这里声明"什么时候复制、复制给谁"。

### 4. OnRep_BaseDamage / OnRep_BaseHeal（复制回调）

```cpp
void UTenkaichiCombatSet::OnRep_BaseDamage(const FGameplayAttributeData& OldValue)
{
	GAMEPLAYATTRIBUTE_REPNOTIFY(UTenkaichiCombatSet, BaseDamage, OldValue);
}
```

- 服务器改值 → 复制到客户端 → 触发 `OnRep_BaseDamage`。
- **`GAMEPLAYATTRIBUTE_REPNOTIFY(类, 属性, OldValue)`**：GAS 提供的宏，通知 ASC"这个属性被复制更新了"，让 GAS 重新计算属性聚合、触发变化回调（如 HealthSet 的 `OnHealthChanged`）。
- 没有这一步，客户端收到新值但 GAS 不会感知，UI/逻辑不会更新。

## 五、几个要记住的点

1. **`.h` 声明"回调"、`.cpp` 注册"复制条件"**：`ReplicatedUsing`（.h）决定复制后调谁，`GetLifetimeReplicatedProps`（.cpp）决定何时复制给谁。
2. **`COND_OwnerOnly`**：战斗属性只给所有者看。
3. **`GAMEPLAYATTRIBUTE_REPNOTIFY`**：GAS 属性复制的"最后一公里"——让 ASC 感知属性更新。
4. **`.cpp` 依赖基类 `TenkaichiAttributeSet`**（上一节已落盘）+ 引擎复制宏，**可编译零挂起**。

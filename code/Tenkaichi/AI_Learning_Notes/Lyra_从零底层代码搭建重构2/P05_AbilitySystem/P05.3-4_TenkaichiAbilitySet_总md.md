# P05.3-4 AbilitySet —— 总 md

## 一、这个类解决什么问题

上一节 `GlobalAbilitySystem` 是"给**所有** ASC 批量授予"。而**单个角色**想一次性获得"一组技能 + 一组效果 + 一组属性集"
（比如"近战职业包"），需要一个**可配置的数据资产**来打包这些东西。

`ULyraAbilitySet` 就是这样一个 **DataAsset（数据资产）**：
- 在编辑器里用 `TArray` 配好：要授哪些技能、哪些效果、哪些属性集
- 运行时调用 `GiveToAbilitySystem` 一次性全授给某个 ASC
- 返回的 `FLyraAbilitySet_GrantedHandles` 记录所有授予句柄，方便之后 `TakeFromAbilitySystem` 全部收回

你写 **1 个 `.h` + 1 个 `.cpp`**，放在 `Source/TenkaichiGame/AbilitySystem/` 目录下。

| 内容 | 一句话 |
|------|--------|
| 4 个 USTRUCT | `GameplayAbility` / `GameplayEffect` / `AttributeSet` 三种"要授的东西"数据 + `GrantedHandles`（授予句柄收集器） |
| 1 个 UCLASS | `UTenkaichiAbilitySet : UPrimaryDataAsset`（可配置的技能/效果/属性集打包资产） |

# P05.4-1 AttributeSet 基类 —— 教 .h

## 一、本文件要解决什么

把上一节总 md 的"项目属性集基类"落成真实的 `.h` 文件。`TenkaichiAttributeSet.h` 里有两样东西：

1. **`ATTRIBUTE_ACCESSORS` 宏** —— 写属性集的标准模板，一行宏自动生成 `Get/Set/Init/Get...Attribute` 一组访问函数。
2. **`UTenkaichiAttributeSet` 基类** —— 项目所有属性集（CombatSet / HealthSet）的共同基类，提供"拿到世界、拿到项目 ASC"两个通用方法。
3. 附带一个 **`FTenkaichiAttributeEvent` 委托** —— 属性变化时广播给外界（UI 等）的六参委托。

## 三、完整代码（注释已中文化）

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "AttributeSet.h"

#include "TenkaichiAttributeSet.generated.h"

#define UE_API TENKAICHIGAME_API

class AActor;
class UTenkaichiAbilitySystemComponent;
class UObject;
class UWorld;
struct FGameplayEffectSpec;


/**
 * 这个宏定义了一组用于访问和初始化属性的辅助函数。
 *
 * 宏的用法示例：
 *		ATTRIBUTE_ACCESSORS(UTenkaichiHealthSet, Health)
 * 会生成以下函数：
 *		static FGameplayAttribute GetHealthAttribute();
 *		float GetHealth() const;
 *		void SetHealth(float NewVal);
 *		void InitHealth(float NewVal);
 */
#define ATTRIBUTE_ACCESSORS(ClassName, PropertyName) \
	GAMEPLAYATTRIBUTE_PROPERTY_GETTER(ClassName, PropertyName) \
	GAMEPLAYATTRIBUTE_VALUE_GETTER(PropertyName) \
	GAMEPLAYATTRIBUTE_VALUE_SETTER(PropertyName) \
	GAMEPLAYATTRIBUTE_VALUE_INITTER(PropertyName)

/**
 * 用于广播属性事件的委托，其中一些参数在客户端上可能为 null：
 * @param EffectInstigator	造成这次事件的原始发起者
 * @param EffectCauser		物理上造成这次变化的对象
 * @param EffectSpec		这次变化的完整效果规格
 * @param EffectMagnitude	原始数值大小，这是在做钳制之前的值
 * @param OldValue			属性在改变之前的值
 * @param NewValue			属性在改变之后的值
 */
DECLARE_MULTICAST_DELEGATE_SixParams(FTenkaichiAttributeEvent, AActor* /*EffectInstigator*/, AActor* /*EffectCauser*/, const FGameplayEffectSpec* /*EffectSpec*/, float /*EffectMagnitude*/, float /*OldValue*/, float /*NewValue*/);

/**
 * UTenkaichiAttributeSet
 *
 *	项目的属性集基类。
 */
UCLASS(MinimalAPI)
class UTenkaichiAttributeSet : public UAttributeSet
{
	GENERATED_BODY()

public:

	// 构造函数
	UE_API UTenkaichiAttributeSet();

	// 拿到这个属性集所属的世界
	UE_API UWorld* GetWorld() const override;

	// 拿到这个属性集所属的项目的 AbilitySystemComponent
	UE_API UTenkaichiAbilitySystemComponent* GetTenkaichiAbilitySystemComponent() const;
};

#undef UE_API
```

## 四、逐段讲解

### 1. 头文件与前置声明

```cpp
#pragma once
#include "AttributeSet.h"
#include "TenkaichiAttributeSet.generated.h"

#define UE_API TENKAICHIGAME_API

class AActor;
class UTenkaichiAbilitySystemComponent;
class UObject;
class UWorld;
struct FGameplayEffectSpec;
```

- `AttributeSet.h`：引擎 GAS 的属性集基类 `UAttributeSet`。
- `TenkaichiAttributeSet.generated.h`：UE 反射代码生成头，必须 `#include`。
- `#define UE_API TENKAICHIGAME_API`：**临时重定义 `UE_API`** 为项目的导出宏。下面每个成员函数前都用 `UE_API` 前缀，等价于 `TENKAICHIGAME_API`，给这些函数加 DLL 导出属性（跨模块链接用）。
- 前置声明：`AActor`/`UTenkaichiAbilitySystemComponent`/`UObject`/`UWorld`/`FGameplayEffectSpec` —— `.h` 里只用到它们的指针/引用，前置声明足够 → 零挂起。

### 2. ATTRIBUTE_ACCESSORS 宏（写属性集的标准模板）

```cpp
#define ATTRIBUTE_ACCESSORS(ClassName, PropertyName) \
	GAMEPLAYATTRIBUTE_PROPERTY_GETTER(ClassName, PropertyName) \
	GAMEPLAYATTRIBUTE_VALUE_GETTER(PropertyName) \
	GAMEPLAYATTRIBUTE_VALUE_SETTER(PropertyName) \
	GAMEPLAYATTRIBUTE_VALUE_INITTER(PropertyName)
```

- 这是**写属性集最核心的宏**。它把 GAS 提供的 4 个 `GAMEPLAYATTRIBUTE_*` 宏组合起来，一键生成一组访问函数。
- 以 `ATTRIBUTE_ACCESSORS(UTenkaichiHealthSet, Health)` 为例会生成：
  - `GAMEPLAYATTRIBUTE_PROPERTY_GETTER` → `static FGameplayAttribute GetHealthAttribute()`（拿属性的反射句柄）
  - `GAMEPLAYATTRIBUTE_VALUE_GETTER` → `float GetHealth() const`（读当前值）
  - `GAMEPLAYATTRIBUTE_VALUE_SETTER` → `void SetHealth(float NewVal)`（设值）
  - `GAMEPLAYATTRIBUTE_VALUE_INITTER` → `void InitHealth(float NewVal)`（初始化，仅在首次生效）
- 后面 CombatSet / HealthSet 每个属性都用这一行宏生成访问函数。

### 3. FTenkaichiAttributeEvent 委托（属性变化广播）

```cpp
DECLARE_MULTICAST_DELEGATE_SixParams(FTenkaichiAttributeEvent,
	AActor* EffectInstigator, AActor* EffectCauser,
	const FGameplayEffectSpec* EffectSpec, float EffectMagnitude,
	float OldValue, float NewValue);
```

- **六参多播委托**：当属性值变化时，把"谁造成的、原始数值、旧值、新值"等广播出去。
- HealthSet 里会用它定义 `OnHealthChanged` / `OnMaxHealthChanged` / `OnOutOfHealth` 等事件，UI 可以订阅。
- 注意：客户端上 `EffectInstigator`/`EffectCauser`/`EffectSpec` 可能是 `null`（这些只在服务器上有意义），所以参数注释里特别说明了。

### 4. UTenkaichiAttributeSet 基类

```cpp
UCLASS(MinimalAPI)
class UTenkaichiAttributeSet : public UAttributeSet
{
	GENERATED_BODY()
public:
	UE_API UTenkaichiAttributeSet();
	UE_API UWorld* GetWorld() const override;
	UE_API UTenkaichiAbilitySystemComponent* GetTenkaichiAbilitySystemComponent() const;
};
```

- `UCLASS(MinimalAPI)`：**MinimalAPI** —— 类本身不导出，但暴露 `UE_API` 标记的成员函数供跨模块调用。
- 继承 `UAttributeSet`（引擎 GAS 基类），`GENERATED_BODY()` 必须有。
- `GetWorld()`：重写引擎方法，`.cpp` 里从 `GetOuter()` 拿到外层对象再拿世界。
- `GetTenkaichiAbilitySystemComponent()`：`Cast` 从 `GetOwningAbilitySystemComponent()` 拿到**项目自己的** ASC（`.cpp` 里实现）。
- 每个成员函数前都有 `UE_API`（= `TENKAICHIGAME_API`）导出标记。

## 五、几个要记住的点

1. **`ATTRIBUTE_ACCESSORS` 是模板**：以后每个属性集属性都用它生成访问函数，不用手写。
2. **`UE_API` 临时重定义**：`#define UE_API TENKAICHIGAME_API` 在文件头定义、`#undef UE_API` 在文件尾回收，作用域仅限本文件。
3. **`FTenkaichiAttributeEvent` 是六参委托**：属性变化广播的标准载体，HealthSet 里会用到。
4. **`.h` 零挂起**：全部前置声明 + 引擎 GAS，可独立编译。

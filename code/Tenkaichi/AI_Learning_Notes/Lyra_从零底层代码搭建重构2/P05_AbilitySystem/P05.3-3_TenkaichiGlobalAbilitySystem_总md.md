# P05.3-3 GlobalAbilitySystem —— 总 md

## 一、这个类解决什么问题

GAS 里，**技能/效果通常是"授给某个具体的 ASC"**（挂在某个角色身上）。但有些技能/效果
（比如全局的"移动模式"、"游戏内全角色生效的 buff"）**希望一次性批量授给世界里的所有 ASC**。

`ULyraGlobalAbilitySystem` 就是一个 **全局技能系统**（继承引擎 `UWorldSubsystem`，每个世界一个）：
- 记住"已经全局应用了哪些技能/效果"
- 有 ASC 注册进来时，自动把已全局应用的技能/效果补授给它
- 提供 `ApplyAbilityToAll` / `ApplyEffectToAll` / `RemoveAbilityFromAll` / `RemoveEffectFromAll` 批量操作

你写 **1 个 `.h` + 1 个 `.cpp`**，放在 `Source/TenkaichiGame/AbilitySystem/` 目录下。

| 内容 | 一句话 |
|------|--------|
| 2 个 USTRUCT | `FGlobalAppliedAbilityList` / `FGlobalAppliedEffectList`（记录"某个全局技能/效果 → 各 ASC 的句柄"） |
| 1 个 UCLASS | `UTenkaichiGlobalAbilitySystem : UWorldSubsystem`（全局系统本体） |

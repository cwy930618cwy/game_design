# P05.4-2 DamageExecution —— 教 .h

## 一、本文件要解决什么

把总 md 里"伤害执行计算"这个类落成真实的 `.h` 文件。`TenkaichiDamageExecution.h` 定义一个 `UTenkaichiDamageExecution` 类——它是引擎 `UGameplayEffectExecutionCalculation`（**执行计算基类**）的子类，负责在 GE 执行时**算出伤害量**。

**这个 `.h` 很简单**：类本身没有属性、没有 UPROPERTY，只声明了：
1. **构造函数** `UTenkaichiDamageExecution()`——在 `.cpp` 里往捕获列表注册 `BaseDamage`。
2. **重写的核心虚函数** `Execute_Implementation()`——伤害算法真正落在这里（`.cpp` 教）。

> 依赖只有引擎的 `UGameplayEffectExecutionCalculation`，**无工程依赖，可独立编译零挂起**。

## 四、逐段讲解

### 1. 头文件与前置声明

```cpp
#pragma once
#include "GameplayEffectExecutionCalculation.h"
#include "TenkaichiDamageExecution.generated.h"

class UObject;
```

- `GameplayEffectExecutionCalculation.h`：**基类头**，`UGameplayEffectExecutionCalculation` 就定义在这。这是引擎 GAS 提供的"执行计算"基类——**所有伤害/治疗执行类都继承它**。
- `TenkaichiDamageExecution.generated.h`：UE 反射代码生成头（每个 UCLASS 都要有）。
- 前置声明 `class UObject;`：Lyra 原文件有，虽然后面没直接用，但保留以保持一致（铁律 23 一字不砍）。

### 2. 类声明

```cpp
UCLASS()
class UTenkaichiDamageExecution : public UGameplayEffectExecutionCalculation
{
	GENERATED_BODY()
public:
	UTenkaichiDamageExecution();
protected:
	virtual void Execute_Implementation(const FGameplayEffectCustomExecutionParameters& ExecutionParams, FGameplayEffectCustomExecutionOutput& OutExecutionOutput) const override;
};
```

- **`UCLASS()`**：无参数（不需要蓝图可见/编辑器可见之类）。
- **继承 `UGameplayEffectExecutionCalculation`**：核心。这个基类让本类能作为一个"Execution"挂到 GameplayEffect 上，在 GE 施加时被 GAS 调用。
- **构造函数**：`.cpp` 里用 `RelevantAttributesToCapture.Add(...)` 告诉 GAS"我要抓取 `BaseDamage` 属性"。
- **`Execute_Implementation`**：执行计算基类的核心虚函数。**每次 GE 施加这个 Execution 时，GAS 都会调用它**，传入：
  - `ExecutionParams`：执行参数（包含 spec、源/目标标签、捕获的属性值等）。
  - `OutExecutionOutput`：输出结构，伤害量通过它写回去。
- **`override`**：重写基类虚函数，`protected` 保持基类原访问级别。

> 注意：参数类型 `FGameplayEffectCustomExecutionParameters` 和 `FGameplayEffectCustomExecutionOutput` 都来自引擎，不用我们管，`.cpp` 里直接用。

## 五、几个要记住的点

1. **Execution 是"算数值"的插件**：挂在 GE 上，GE 执行时 GAS 自动调 `Execute_Implementation`。
2. **这个 `.h` 只有骨架**：没有属性，全靠构造函数（注册要抓的属性）+ 重写虚函数（算伤害）。
3. **真正的东西在 `.cpp`**：构造注册 `BaseDamage`、`Execute_Implementation` 里的完整伤害算法（物理材质/距离/队伍衰减）。
4. **`.h` 可独立编译**：只依赖引擎基类，无工程依赖。

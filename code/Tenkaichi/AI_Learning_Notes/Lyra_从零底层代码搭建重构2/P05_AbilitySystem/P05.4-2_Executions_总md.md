# P05.4-2 Executions（伤害/治疗执行计算）—— 总 md

## 一、这个主题要解决什么

上一节 P05.4-1 教完了属性集（`AttributeSet`）：`CombatSet` 提供"伤害/治疗基础量"，`HealthSet` 提供"真正的生命值 + 结算逻辑"。

**那"伤害到底怎么算"？** 这一节 `Executions/` 就是答案——**执行计算类**（`UGameplayEffectExecutionCalculation`）负责在 GE（GameplayEffect）执行时**算出具体伤害/治疗量**，再写回属性。

**一句话流程**：
```
GE 施加 → Execution 被调用 → 从 CombatSet 抓 BaseDamage/BaseHeal
       → 应用衰减/距离/队伍规则 → 算出 DamageDone/HealingDone
       → 输出到 HealthSet 的 Damage/Healing 元属性
       → HealthSet::PostGameplayEffectExecute 把它转成 Health 变化
```

## 二、全景：这个主题有 2 个类

| 类 | 文件（Lyra） | 作用 |
|----|------|------|
| `ULyraDamageExecution` | `Executions/LyraDamageExecution.h/.cpp` | 算**伤害**：抓 `BaseDamage`，应用物理材质衰减、距离衰减、队伍伤害规则，输出到 `Damage` 元属性 |
| `ULyraHealExecution` | `Executions/LyraHealExecution.h/.cpp` | 算**治疗**：抓 `BaseHeal`，输出到 `Healing` 元属性 |

**结构**：两个类几乎一模一样，都是 `UGameplayEffectExecutionCalculation` 的子类，只重写一个虚函数 `Execute_Implementation`。

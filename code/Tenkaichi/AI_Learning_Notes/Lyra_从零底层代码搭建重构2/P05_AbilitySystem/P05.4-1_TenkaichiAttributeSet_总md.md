# P05.4-1 AttributeSet —— 总 md

## 一、这个类组解决什么问题

GAS 里，**"属性"（Attribute，如生命值、攻击力）是角色数值的载体**。要定义项目自己的数值（生命、伤害、治疗、护盾……），
必须写**属性集（AttributeSet）**——它告诉 GAS：角色有哪些属性、怎么变化、怎么同步、怎么被技能/效果修改。

`Attributes/` 子目录有 **3 个类**（基类 + 2 个派生），构成一套数值体系：

| 类 | 作用 | 属性 |
|----|------|------|
| `ULyraAttributeSet`（基类） | 项目属性集基类，提供"拿到世界、拿到项目 ASC"的通用方法 | 无具体属性 |
| `ULyraCombatSet` | 战斗数值（伤害/治疗的"基础量"） | `BaseDamage`、`BaseHeal` |
| `ULyraHealthSet` | 生命数值（当前/最大生命 + 元属性） | `Health`、`MaxHealth`、`Healing`、`Damage` |

**核心知识点**：`ATTRIBUTE_ACCESSORS` 宏——它用 `GAMEPLAYATTRIBUTE_*_GETTER/SETTER/INITTER` 自动生成
`GetHealth()` / `SetHealth()` / `InitHealth()` / `GetHealthAttribute()` 等一组访问函数，是写属性集的标准模板。

你写 **3 个 `.h` + 3 个 `.cpp`**，放在 `Source/TenkaichiGame/AbilitySystem/Attributes/` 子目录下。

## 四、HealthSet 自带的 GameplayTag（跟类一起教）

HealthSet 用到 5 个原生 tag，声明在 `.h`、定义在 `.cpp`（**不属于第0步的 `TenkaichiGameplayTags`，是本类自带**）：

| Tag 符号 | 字符串 |
|----------|--------|
| `TAG_Gameplay_Damage` | `Gameplay.Damage` |
| `TAG_Gameplay_DamageImmunity` | `Gameplay.DamageImmunity` |
| `TAG_Gameplay_DamageSelfDestruct` | `Gameplay.Damage.SelfDestruct` |
| `TAG_Gameplay_FellOutOfWorld` | `Gameplay.Damage.FellOutOfWorld` |
| `TAG_Lyra_Damage_Message` | `Lyra.Damage.Message` |

> ⚠️ `TAG_Lyra_Damage_Message` 这个**符号名**带 `Lyra`——它属于"标签字符串标识符"，保持 Lyra 原名
> （`TAG_Lyra_Damage_Message`），不适用前缀替换（字符串是 `Lyra.Damage.Message`，是给 GameplayTags 系统用的固定字符串）。教 HealthSet 时细讲。

```

  Health / MaxHealth / Healing / Damage
  5 个 TAG_Gameplay_* 声明
  OnHealthChanged / OnMaxHealthChanged / OnOutOfHealth 委托

```

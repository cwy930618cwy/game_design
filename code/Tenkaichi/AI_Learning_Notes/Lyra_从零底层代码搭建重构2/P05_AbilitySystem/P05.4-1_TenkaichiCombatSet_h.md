# P05.4-1 CombatSet —— 教 .h

## 一、本文件要解决什么

把总 md 里"战斗数值"这个派生属性集落成真实的 `.h` 文件。`TenkaichiCombatSet.h` 定义**两个属性**：`BaseDamage`（基础伤害）和 `BaseHeal`（基础治疗）——它们是伤害/治疗计算（P05.4 的 `Executions/`）要用的"基础量"。

**核心**：用上一节教的 `ATTRIBUTE_ACCESSORS` 宏，一行生成一组访问函数（`Get/Set/Init/Get...Attribute`）。这是第一个真正用宏写属性的类。

## 三、完整代码（注释已中文化）

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "AbilitySystemComponent.h"
#include "TenkaichiAttributeSet.h"

#include "TenkaichiCombatSet.generated.h"

class UObject;
struct FFrame;


/**
 * UTenkaichiCombatSet
 *
 *	定义应用伤害或治疗所必需的属性的类。
 *	属性示例包括：伤害、治疗、攻击力和护盾穿透。
 */
UCLASS(BlueprintType)
class UTenkaichiCombatSet : public UTenkaichiAttributeSet
{
	GENERATED_BODY()

public:

	// 构造函数
	UTenkaichiCombatSet();

	// 为 BaseDamage 生成访问函数（GetBaseDamage / SetBaseDamage / InitBaseDamage / GetBaseDamageAttribute）
	ATTRIBUTE_ACCESSORS(UTenkaichiCombatSet, BaseDamage);

	// 为 BaseHeal 生成访问函数（GetBaseHeal / SetBaseHeal / InitBaseHeal / GetBaseHealAttribute）
	ATTRIBUTE_ACCESSORS(UTenkaichiCombatSet, BaseHeal);

protected:

	// BaseDamage 属性复制回来时的回调（服务器→客户端同步后触发）
	UFUNCTION()
	void OnRep_BaseDamage(const FGameplayAttributeData& OldValue);

	// BaseHeal 属性复制回来时的回调（服务器→客户端同步后触发）
	UFUNCTION()
	void OnRep_BaseHeal(const FGameplayAttributeData& OldValue);

private:

	// 在伤害执行中要应用的基础伤害量
	UPROPERTY(BlueprintReadOnly, ReplicatedUsing = OnRep_BaseDamage, Category = "Tenkaichi|Combat", Meta = (AllowPrivateAccess = true))
	FGameplayAttributeData BaseDamage;

	// 在治疗执行中要应用的基础治疗量
	UPROPERTY(BlueprintReadOnly, ReplicatedUsing = OnRep_BaseHeal, Category = "Tenkaichi|Combat", Meta = (AllowPrivateAccess = true))
	FGameplayAttributeData BaseHeal;
};
```

## 四、逐段讲解

### 1. 头文件与前置声明

```cpp
#pragma once
#include "AbilitySystemComponent.h"
#include "TenkaichiAttributeSet.h"
#include "TenkaichiCombatSet.generated.h"

class UObject;
struct FFrame;
```

- `AbilitySystemComponent.h`：`FGameplayAttributeData` 类型的定义头（属性数据载体）。
- `TenkaichiAttributeSet.h`：本类基类 `UTenkaichiAttributeSet`（上一节教的基类）。
- `TenkaichiCombatSet.generated.h`：UE 反射代码生成头。
- 前置声明 `UObject`/`FFrame`：`.h` 里只在宏/属性内部间接用到，前置声明足够。

### 2. 类声明与两个属性

```cpp
UCLASS(BlueprintType)
class UTenkaichiCombatSet : public UTenkaichiAttributeSet
{
	GENERATED_BODY()
public:
	UTenkaichiCombatSet();
	ATTRIBUTE_ACCESSORS(UTenkaichiCombatSet, BaseDamage);
	ATTRIBUTE_ACCESSORS(UTenkaichiCombatSet, BaseHeal);
protected:
	UFUNCTION()
	void OnRep_BaseDamage(const FGameplayAttributeData& OldValue);
	UFUNCTION()
	void OnRep_BaseHeal(const FGameplayAttributeData& OldValue);
private:
	UPROPERTY(BlueprintReadOnly, ReplicatedUsing = OnRep_BaseDamage, Category = "Tenkaichi|Combat", Meta = (AllowPrivateAccess = true))
	FGameplayAttributeData BaseDamage;
	UPROPERTY(BlueprintReadOnly, ReplicatedUsing = OnRep_BaseHeal, Category = "Tenkaichi|Combat", Meta = (AllowPrivateAccess = true))
	FGameplayAttributeData BaseHeal;
};
```

- **继承 `UTenkaichiAttributeSet`**（基类）而不是直接继承引擎 `UAttributeSet`——这样 CombatSet 自动拥有基类的 `GetWorld()`/`GetTenkaichiAbilitySystemComponent()`。
- **两个 `ATTRIBUTE_ACCESSORS`**：一行宏 = 生成 `GetBaseDamage()`/`SetBaseDamage()`/`InitBaseDamage()`/`GetBaseDamageAttribute()` 一组函数（以及 BaseHeal 对应的一组）。
- **两个属性**都是 `FGameplayAttributeData`（GAS 的属性数据载体，内部含当前值 + 基础值 + 变化回调）。
- **`ReplicatedUsing = OnRep_BaseDamage`**：属性要**网络复制**，从服务器同步到客户端时触发 `OnRep_BaseDamage` 回调。
- **`BlueprintReadOnly`**：蓝图可读不可写。`Meta = (AllowPrivateAccess = true)`：属性是 `private`，但允许蓝图反射访问。
- **`Category = "Tenkaichi|Combat"`**：在蓝图/编辑器里按 `Tenkaichi > Combat` 分组显示。

## 五、几个要记住的点

1. **这是第一个真正用 `ATTRIBUTE_ACCESSORS` 宏写属性的类**——以后每个属性集属性都这么写。
2. **属性都要 `FGameplayAttributeData`**：GAS 属性不是普通 `float`，是带复制/回调的数据结构。
3. **`ReplicatedUsing` + `OnRep`**：网络复制的标准写法，服务器改值→同步→客户端 `OnRep` 回调。
4. **继承项目基类 `UTenkaichiAttributeSet`**：白拿基类的世界/ASC 方法。

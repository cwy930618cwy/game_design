### 2. ToString() —— 消息体 → 可读字符串

```cpp
FString FTenkaichiVerbMessage::ToString() const
{
	FString HumanReadableMessage;
	FTenkaichiVerbMessage::StaticStruct()->ExportText(/*out*/ HumanReadableMessage, this, /*Defaults=*/ nullptr, /*OwnerObject=*/ nullptr, PPF_None, /*ExportRootScope=*/ nullptr);
	return HumanReadableMessage;
}
```

| 行 | 干什么 |
|----|--------|
| `StaticStruct()->ExportText(...)` | 引擎反射方法：把结构体的所有字段序列化成一个可读字符串 |
| `/*out*/ HumanReadableMessage` | 输出参数（通过引用写回结果） |
| `this` | 要序列化的对象（本消息体） |

> 🔑 一句话：**`ToString()` 用引擎反射把消息体的所有字段（Verb/Instigator/Target/...）打印成一行可读文本**，方便调试日志。这就是 P01.1 声明、P01.5 落地实现的方法。

### 3. GetPlayerStateFromObject —— 反查 PlayerState

```cpp
APlayerState* UTenkaichiVerbMessageHelpers::GetPlayerStateFromObject(UObject* Object)
{
	if (APlayerController* PC = Cast<APlayerController>(Object))
	{
		return PC->PlayerState;
	}
	if (APlayerState* TargetPS = Cast<APlayerState>(Object))
	{
		return TargetPS;
	}
	if (APawn* TargetPawn = Cast<APawn>(Object))
	{
		if (APlayerState* TargetPS = TargetPawn->GetPlayerState())
		{
			return TargetPS;
		}
	}
	return nullptr;
}
```

| 部分 | 干什么 |
|------|--------|
| 传入的是 `APlayerController` | 直接返回 `PC->PlayerState` |
| 传入的是 `APlayerState` | 它自己就是 PlayerState，直接返回 |
| 传入的是 `APawn` | 调 `TargetPawn->GetPlayerState()` 拿所属 PlayerState |
| 都匹配不上 | 返回 `nullptr` |

> 🔑 一句话：**按 Controller→PlayerState→Pawn 逐层尝试，找出对象的 PlayerState**。常用于"这条消息的发起者是谁的玩家状态"。

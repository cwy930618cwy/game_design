# P01.4 UGameplayMessageProcessor —— 教 `.h`

## 一、本文件要解决什么

把 P01.4 总 md 里的"全景"落成真实的 `.h`。你要写的是 `GameplayMessageProcessor.h`，
里面是一个**消息处理器基类** `UGameplayMessageProcessor`：

1. **继承 `UActorComponent`** —— 作为一个组件挂在 Actor 上
2. **管好"监听消息"的生命周期** —— `BeginPlay` 时开始监听、`EndPlay` 时停止并注销所有监听句柄
3. **把具体逻辑留给子类** —— `StartListening`/`StopListening` 是虚函数空实现，子类覆盖

> 类比：它是一个"消息监听盒"的**底座**——盒子自己负责"通电时接线、断电时拆线"，至于**接哪些线（监听哪些消息）、怎么处理**，由子类填。

## 三、完整代码（注释已中文化）

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "Components/ActorComponent.h"
#include "GameFramework/GameplayMessageSubsystem.h"

#include "GameplayMessageProcessor.generated.h"

#define UE_API TENKAICHIGAME_API

namespace EEndPlayReason { enum Type : int; }

class UObject;

/**
 * UGameplayMessageProcessor
 *
 * 任何"观察其他玩法消息、并可能重新发出更新消息"的处理器基类（比如检测到连击/连杀就重发一条）。
 *
 * 注意：这些处理器在服务器上只生成一次（不是每个玩家一个），
 * 如果只想对部分玩家生效，处理器要自己做内部过滤。
 */
UCLASS(MinimalAPI, BlueprintType, Blueprintable, meta=(BlueprintSpawnableComponent))
class UGameplayMessageProcessor : public UActorComponent
{
	GENERATED_BODY()

public:
	//~UActorComponent 接口开始
	// 组件开始运行时调用：启动监听
	UE_API virtual void BeginPlay() override;
	// 组件结束运行时调用：停止监听并清理所有监听句柄
	UE_API virtual void EndPlay(const EEndPlayReason::Type EndPlayReason) override;
	//~UActorComponent 接口结束

	// 开始监听消息（虚函数，子类覆盖：在这里注册要听的消息）
	UE_API virtual void StartListening();
	// 停止监听消息（虚函数，子类覆盖：在这里停止听）
	UE_API virtual void StopListening();

protected:
	// 把一个新的监听句柄存进数组（方便 EndPlay 时统一注销）
	UE_API void AddListenerHandle(FGameplayMessageListenerHandle&& Handle);
	// 获取服务器时间（用 GameState 的服务器时钟）
	UE_API double GetServerTime() const;

private:
	// 所有监听句柄（EndPlay 时统一注销）
	TArray<FGameplayMessageListenerHandle> ListenerHandles;
};

#undef UE_API
```

## 四、逐段讲解

### 1. include 区 + 前置声明 + 导出宏技巧

```cpp
#include "Components/ActorComponent.h"
#include "GameFramework/GameplayMessageSubsystem.h"

#include "GameplayMessageProcessor.generated.h"

#define UE_API TENKAICHIGAME_API

namespace EEndPlayReason { enum Type : int; }

class UObject;
```

| 行 | 干什么 |
|----|--------|
| `#include "Components/ActorComponent.h"` | 引擎的组件基类 `UActorComponent`——本类继承它 |
| `#include "GameFramework/GameplayMessageSubsystem.h"` | **S1 插件的消息系统头**——`FGameplayMessageListenerHandle`（监听句柄）在这里定义 |
| `#include "GameplayMessageProcessor.generated.h"` | UHT 生成的反射代码 |
| `#define UE_API TENKAICHIGAME_API` | **导出宏技巧**：把 `UE_API` 临时定义为 `TENKAICHIGAME_API`（你的模块导出宏）。配合 `UCLASS(MinimalAPI)`，让下面每个方法都能独立被导出 |
| `namespace EEndPlayReason { enum Type : int; }` | **前置声明**引擎的 `EEndPlayReason::Type`（`EndPlay` 参数类型） |
| `class UObject;` | 前置声明 `UObject` |

> 🔑 **`MinimalAPI` + `#define UE_API` 是什么**：`MinimalAPI` 类**默认不导出任何符号**（别的模块想用它的方法，得每个方法单独标导出）。这里用 `#define UE_API TENKAICHIGAME_API` 让 `UE_API` 变成导出宏，再在每个方法前面手动加 `UE_API`，就能**按需导出**。文件末尾 `#undef UE_API` 把宏还原，不影响后面代码。

### 3. UActorComponent 生命周期重写

```cpp
	//~UActorComponent 接口开始
	// 组件开始运行时调用：启动监听
	UE_API virtual void BeginPlay() override;
	// 组件结束运行时调用：停止监听并清理所有监听句柄
	UE_API virtual void EndPlay(const EEndPlayReason::Type EndPlayReason) override;
	//~UActorComponent 接口结束
```

| 部分 | 干什么 |
|------|--------|
| `BeginPlay() override` | 重写组件开始回调——`.cpp` 里会在调用父类后 `StartListening()` |
| `EndPlay(...) override` | 重写组件结束回调——`.cpp` 里会 `StopListening()` + 注销所有监听句柄 |
| `//~UActorComponent 接口开始/结束` | 接口分界标记（已中文化，铁律 36） |

> 🔑 一句话：**这个基类自己接管了"开始监听 / 结束监听"的时机**——组件一运行就 `StartListening`，一销毁就清理。子类只需要关心"听什么"。

### 4. 虚函数钩子（留给子类）

```cpp
	// 开始监听消息（虚函数，子类覆盖：在这里注册要听的消息）
	UE_API virtual void StartListening();
	// 停止监听消息（虚函数，子类覆盖：在这里停止听）
	UE_API virtual void StopListening();
```

| 部分 | 干什么 |
|------|--------|
| `virtual void StartListening()` | 虚函数，**空实现**（`.cpp` 里函数体为空）——子类覆盖它，在这里用 `AddListenerHandle` 注册要听的消息 |
| `virtual void StopListening()` | 虚函数，**空实现**——子类覆盖它，停止监听 |

> 🔑 一句话：**这是给子类留的"插槽"**。基类只负责在正确时机调用它们，具体"监听哪些消息"由子类填。

### 5. 受保护工具函数 + 私有监听句柄数组

```cpp
protected:
	// 把一个新的监听句柄存进数组（方便 EndPlay 时统一注销）
	UE_API void AddListenerHandle(FGameplayMessageListenerHandle&& Handle);
	// 获取服务器时间（用 GameState 的服务器时钟）
	UE_API double GetServerTime() const;

private:
	// 所有监听句柄（EndPlay 时统一注销）
	TArray<FGameplayMessageListenerHandle> ListenerHandles;
```

| 部分 | 干什么 |
|------|--------|
| `AddListenerHandle(FGameplayMessageListenerHandle&& Handle)` | **受保护工具**：子类在 `StartListening` 里调用它，把新监听句柄存进 `ListenerHandles`。参数是**右值引用**（`&&`），配合 `MoveTemp` 高效移动 |
| `GetServerTime() const` | 受保护工具：返回服务器时间（`.cpp` 里用 GameState 的服务器时钟） |
| `ListenerHandles` | **私有数组**：存所有监听句柄，`EndPlay` 时统一 `UnregisterListener` 注销 |

> 🔑 设计核心：**子类注册的监听句柄都集中存进 `ListenerHandles`**，这样基类 `EndPlay` 能一次性清理干净，子类不用自己记着注销。

## 一、这个类解决什么问题（为什么）

前两个消息体（P01.1 `FLyraVerbMessage`、P01.2 `FLyraNotificationMessage`）只是**装数据的袋子**。但游戏是**联网**的——服务器产生了一条"击杀消息"，**要广播给所有客户端**，让每个客户端都能收到并处理。

问题来了：服务器上的消息是**瞬时的**（发完就没），客户端怎么可靠地收到？靠普通属性复制不行（瞬时的对象无法单独同步）。

`FLyraVerbMessageReplication` 就是**"消息复制器"**：

> **服务器把一堆瞬时消息暂存在一个数组里，用 UE 的高效网络复制机制（FastArray）把"新增的"消息同步给客户端；客户端收到后，再通过 GameplayMessageRouter 插件在本地重新广播出去**，让本地所有订阅了该消息的人都收到。

> 🔑 **一句话**：P01.1 定义"消息长啥样"，P01.3 负责"**让消息从服务器飞到客户端**"。它是消息总线的"网络通道"。

## 二、内部结构全景

```
USTRUCT(BlueprintType) struct FLyraVerbMessageReplicationEntry : public FFastArraySerializerItem
└─ 一个条目 = 一条待复制的消息
      └─ UPROPERTY() FLyraVerbMessage Message        ← 存 P01.1 那条消息
      └─ FString GetDebugString() const              ← 调试用，调 Message.ToString()

USTRUCT(BlueprintType) struct FLyraVerbMessageReplication : public FFastArraySerializer
├─ 装着"要复制的消息"的数组容器（用 FastArray 高效同步）
├─ void SetOwner(UObject* InOwner)                   ← 记录持有者（用于找到 World → MessageSystem）
├─ void AddMessage(const FLyraVerbMessage& Message)   ← 服务器往数组里加一条消息并标记脏
├─ PreReplicatedRemove / PostReplicatedAdd / PostReplicatedChange  ← FastArray 复制的三回调（客户端收到后触发）
├─ bool NetDeltaSerialize(FNetDeltaSerializeInfo&)   ← 自定义增量序列化（FastArray 接入点）
└─ private:
     ├─ void RebroadcastMessage(...)                  ← 客户端本地重新广播给订阅者
     ├─ TArray<FLyraVerbMessageReplicationEntry> CurrentMessages  ← 被复制的数组
     └─ TObjectPtr<UObject> Owner                     ← 持有者（用来找 World）

template<> struct TStructOpsTypeTraits<FLyraVerbMessageReplication>
└─ WithNetDeltaSerializer = true                     ← 告诉 UE"这个结构体要用自定义增量序列化"
```

> 两个结构体：**Entry**（一条消息）装进 **Replication**（数组容器）。容器继承引擎的 `FFastArraySerializer`，启用 UE 的高效"数组增量复制"——只同步新增/变更的那几条，不整组重发。

## 四、新知识点预告（教到时会拆开讲）

1. **`FFastArraySerializer`**（引擎网络复制机制）：UE 的"高效数组复制"——服务器只把数组里**新增/变更的项**增量同步给客户端，而不是整组重发。这是 P01.3 的灵魂。✅ **引擎底层接口，只讲不拆**（懂它干嘛 + 何时被调用即可）。
2. **FastArray 三回调**（`PreReplicatedRemove` / `PostReplicatedAdd` / `PostReplicatedChange`）：客户端收到增量后，UE 按"增/删/改"回调对应函数，P01.3 在 `PostReplicatedAdd/Change` 里把新消息重新广播。
3. **`TStructOpsTypeTraits` 特化 + `WithNetDeltaSerializer = true`**：告诉 UE"这个结构体自带自定义增量序列化"（即 `NetDeltaSerialize`），从而走 FastArray 通道。
4. **`UGameplayMessageSubsystem::BroadcastMessage`**：S1 插件的广播 API——客户端收到消息后，用它重新广播给本地订阅者。

# P01.3 FLyraVerbMessageReplication —— 教 `.h`

## 一、本文件要解决什么

把 P01.3 总 md 里的"全景"落成真实的 `.h`。你要写的是 `TenkaichiVerbMessageReplication.h`，
里面是**两个结构体 + 一个模板特化**，共同组成"消息复制器"：

1. **`FTenkaichiVerbMessageReplicationEntry`** —— 一条待复制的消息（装 P01.1 的 `FTenkaichiVerbMessage`）
2. **`FTenkaichiVerbMessageReplication`** —— 装这些消息的**数组容器**，用 UE 的 FastArray 高效同步给客户端
3. **`TStructOpsTypeTraits<FTenkaichiVerbMessageReplication>` 特化** —— 告诉 UE"这个结构体走自定义增量序列化"

> 类比：`Entry` 是"一张快递单"，`Replication` 是"一个快递袋"（袋子能用网络把里面的单子增量发出去）。

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "GameplayTagContainer.h"
#include "TenkaichiVerbMessage.h"
#include "Net/Serialization/FastArraySerializer.h"

#include "TenkaichiVerbMessageReplication.generated.h"

class UObject;
struct FTenkaichiVerbMessageReplication;
struct FNetDeltaSerializeInfo;

/**
 * 表示一条动词消息
 */
USTRUCT(BlueprintType)
struct FTenkaichiVerbMessageReplicationEntry : public FFastArraySerializerItem
{
	GENERATED_BODY()

	FTenkaichiVerbMessageReplicationEntry()
	{}

	FTenkaichiVerbMessageReplicationEntry(const FTenkaichiVerbMessage& InMessage)
		: Message(InMessage)
	{
	}

	// 返回这条消息的调试字符串（调 Message.ToString()）
	FString GetDebugString() const;

private:
	friend FTenkaichiVerbMessageReplication;

	UPROPERTY()
	FTenkaichiVerbMessage Message;
};

/** 要复制的动词消息容器 */
USTRUCT(BlueprintType)
struct FTenkaichiVerbMessageReplication : public FFastArraySerializer
{
	GENERATED_BODY()

	FTenkaichiVerbMessageReplication()
	{
	}

public:
	// 设置持有者（用于找到世界、进而找到消息系统）
	void SetOwner(UObject* InOwner) { Owner = InOwner; }

	// 从服务器向客户端广播一条消息
	void AddMessage(const FTenkaichiVerbMessage& Message);

	//~FFastArraySerializer 接口开始
	// 元素被移除时调用（FastArray 回调）
	void PreReplicatedRemove(const TArrayView<int32> RemovedIndices, int32 FinalSize);
	// 元素被新增时调用（FastArray 回调）
	void PostReplicatedAdd(const TArrayView<int32> AddedIndices, int32 FinalSize);
	// 元素被变更时调用（FastArray 回调）
	void PostReplicatedChange(const TArrayView<int32> ChangedIndices, int32 FinalSize);
	//~FFastArraySerializer 接口结束

	// 自定义增量序列化（FastArray 的接入点，直接把数组交给引擎的 FastArrayDeltaSerialize）
	bool NetDeltaSerialize(FNetDeltaSerializeInfo& DeltaParms)
	{
		return FFastArraySerializer::FastArrayDeltaSerialize<FTenkaichiVerbMessageReplicationEntry, FTenkaichiVerbMessageReplication>(CurrentMessages, DeltaParms, *this);
	}

private:
	// 在客户端把收到的消息重新广播给本地订阅者
	void RebroadcastMessage(const FTenkaichiVerbMessage& Message);

private:
	// 被复制的消息列表
	UPROPERTY()
	TArray<FTenkaichiVerbMessageReplicationEntry> CurrentMessages;
	
	// 持有者（用于找到世界）
	UPROPERTY()
	TObjectPtr<UObject> Owner = nullptr;
};

template<>
struct TStructOpsTypeTraits<FTenkaichiVerbMessageReplication> : public TStructOpsTypeTraitsBase2<FTenkaichiVerbMessageReplication>
{
	enum
	{
		WithNetDeltaSerializer = true,
	};
};
```

## 四、逐段讲解

### 1. include 区 + 前置声明


| 行 | 干什么 |
|----|--------|
| `#include "GameplayTagContainer.h"` | 引擎 GameplayTags 头（消息体里用到的 `FGameplayTag` 相关） |
| `#include "TenkaichiVerbMessage.h"` | **P01.1 的消息体**——复制器装的就是它 |
| `#include "Net/Serialization/FastArraySerializer.h"` | **引擎的 FastArray 高效数组复制机制**（`FFastArraySerializerItem`/`FFastArraySerializer`/`FNetDeltaSerializeInfo` 都在这里） |

| `struct FNetDeltaSerializeInfo;` | 前置声明引擎的网络序列化信息结构体 |

### 2. Entry —— 一条消息的条目

```cpp
/**
 * 表示一条动词消息
 */
USTRUCT(BlueprintType)
struct FTenkaichiVerbMessageReplicationEntry : public FFastArraySerializerItem
{
	GENERATED_BODY()

	FTenkaichiVerbMessageReplicationEntry()
	{}

	FTenkaichiVerbMessageReplicationEntry(const FTenkaichiVerbMessage& InMessage)
		: Message(InMessage)
	{
	}

	// 返回这条消息的调试字符串（调 Message.ToString()）
	FString GetDebugString() const;

private:
	friend FTenkaichiVerbMessageReplication;

	UPROPERTY()
	FTenkaichiVerbMessage Message;

```

| 部分 | 干什么 |
|------|--------|
| `: public FFastArraySerializerItem` | 继承引擎的 FastArray 条目基类——让这一条能作为 FastArray 数组的一个元素被网络增量同步 |
| 两个构造函数 | 默认空构造 + 用一个 `FTenkaichiVerbMessage` 初始化 `Message` 的构造 |
| `GetDebugString() const` | 调试用，返回这条消息的字符串（`.cpp` 里调 `Message.ToString()`） |
| `friend FTenkaichiVerbMessageReplication;` | 允许复制器容器访问私有成员 `Message` |
| `UPROPERTY() FTenkaichiVerbMessage Message;` | **真正要复制的数据**——P01.1 那条消息（`private`，只让容器碰） |

> 🔑 一句话：**Entry 就是"一条消息的包装"，让它具备被 FastArray 复制的资格**。它只装一个 `Message`，其它都是 FastArray 的配套。

### 3. Replication —— 消息复制容器（核心）

```cpp
/** 要复制的动词消息容器 */
USTRUCT(BlueprintType)
struct FTenkaichiVerbMessageReplication : public FFastArraySerializer
{
	GENERATED_BODY()

	FTenkaichiVerbMessageReplication()
	{
	}

public:
	// 设置持有者（用于找到世界、进而找到消息系统）
	void SetOwner(UObject* InOwner) { Owner = InOwner; }

	// 从服务器向客户端广播一条消息
	void AddMessage(const FTenkaichiVerbMessage& Message);

	//~FFastArraySerializer 接口开始
	// 元素被移除时调用（FastArray 回调）
	void PreReplicatedRemove(const TArrayView<int32> RemovedIndices, int32 FinalSize);
	// 元素被新增时调用（FastArray 回调）
	void PostReplicatedAdd(const TArrayView<int32> AddedIndices, int32 FinalSize);
	// 元素被变更时调用（FastArray 回调）
	void PostReplicatedChange(const TArrayView<int32> ChangedIndices, int32 FinalSize);
	//~FFastArraySerializer 接口结束

	// 自定义增量序列化（FastArray 的接入点，直接把数组交给引擎的 FastArrayDeltaSerialize）
	bool NetDeltaSerialize(FNetDeltaSerializeInfo& DeltaParms)
	{
		return FFastArraySerializer::FastArrayDeltaSerialize<FTenkaichiVerbMessageReplicationEntry, FTenkaichiVerbMessageReplication>(CurrentMessages, DeltaParms, *this);
	}

private:
	// 在客户端把收到的消息重新广播给本地订阅者
	void RebroadcastMessage(const FTenkaichiVerbMessage& Message);

private:
	// 被复制的消息列表
	UPROPERTY()
	TArray<FTenkaichiVerbMessageReplicationEntry> CurrentMessages;
	
	// 持有者（用于找到世界）
	UPROPERTY()
	TObjectPtr<UObject> Owner = nullptr;
};
```

| 部分 | 干什么 |
|------|--------|
| `: public FFastArraySerializer` | 继承引擎的 FastArray 数组基类——这个结构体就是一个"能增量复制的数组" |
| `SetOwner(UObject*)` | 记录持有者（`.cpp` 里用 `Owner` 找到 World → 找到消息系统） |
| `AddMessage(...)` | 服务器调它，把一条消息加进数组并标记脏（`MarkItemDirty`） |
| `PreReplicatedRemove/PostReplicatedAdd/PostReplicatedChange` | **FastArray 三回调**：客户端收到"删/增/改"时，UE 调对应函数。P01.3 在增/改里重新广播 |
| `NetDeltaSerialize(...)` | **自定义增量序列化接入点**——把 `CurrentMessages` 交给引擎的 `FastArrayDeltaSerialize` 处理 |
| `RebroadcastMessage(...)` | 私有工具：客户端把收到的新消息重新广播给本地订阅者 |
| `CurrentMessages` | 被复制的消息数组（`private`） |
| `Owner` | 持有者对象指针（`private`） |

> 🔑 **FastArray 三回调 + NetDeltaSerialize 就是"复制器的引擎"**：
> - `NetDeltaSerialize` 让 UE 知道"这个结构体用 FastArray 增量同步"；
> - 客户端每次收到新增/变更，UE 调 `PostReplicatedAdd`/`PostReplicatedChange`，里面调用 `RebroadcastMessage` 把消息广播出去。
>
> `FFastArraySerializer` 是引擎底层机制，**只讲不拆**——你只需知道：它是 UE 的"高效数组复制"，只同步新增/变更的项，不整组重发。

### 4. 模板特化 —— 启用增量序列化

```cpp
template<>
struct TStructOpsTypeTraits<FTenkaichiVerbMessageReplication> : public TStructOpsTypeTraitsBase2<FTenkaichiVerbMessageReplication>
{
	enum
	{
		WithNetDeltaSerializer = true,
	};
};
```

| 部分 | 干什么 |
|------|--------|
| `template<> struct TStructOpsTypeTraits<FTenkaichiVerbMessageReplication>` | 为 `FTenkaichiVerbMessageReplication` 特化引擎的"结构体操作特性"模板 |
| `: public TStructOpsTypeTraitsBase2<...>` | 继承默认特性基类 |
| `WithNetDeltaSerializer = true` | **关键**：告诉 UE"这个结构体自带自定义增量序列化"（即它实现了上面的 `NetDeltaSerialize`），从而走 FastArray 通道 |

> 🔑 一句话：**这个模板特化是"开关"——把 `WithNetDeltaSerializer` 打开，UE 才认这个结构体的 `NetDeltaSerialize`**。没有它，`NetDeltaSerialize` 不会被引擎调用。

#pragma once

#include "Kismet/BlueprintFunctionLibrary.h"

#include "TenkaichiVerbMessageHelpers.generated.h"

#define UE_API TENKAICHIGAME_API

class APlayerState;
class UObject;

/**

	UE_API static FTenkaichiVerbMessage CueParametersToVerbMessage(const FGameplayCueParameters& GameplayCueParameters);
};

#undef UE_API

## 四、逐段讲解

### 1. include 区 + 前置声明 + 导出宏技巧

```cpp
#include "Kismet/BlueprintFunctionLibrary.h"

#include "TenkaichiVerbMessageHelpers.generated.h"

#define UE_API TENKAICHIGAME_API

class APlayerController;
class APlayerState;
class UObject;
struct FGameplayCueParameters;
struct FTenkaichiVerbMessage;
```

| 行 | 干什么 |
|----|--------|
| `#include "Kismet/BlueprintFunctionLibrary.h"` | 引擎的蓝图函数库基类 `UBlueprintFunctionLibrary`——本类继承它 |
| `#include "TenkaichiVerbMessageHelpers.generated.h"` | UHT 生成的反射代码 |
| `#define UE_API TENKAICHIGAME_API` | **导出宏技巧**（同 P01.4）：临时把 `UE_API` 定义为你的模块导出宏，让每个方法单独导出 |
| `class APlayerController;` / `class APlayerState;` / `class UObject;` | **前置声明**引擎类（`.h` 里只用作参数类型，不用完整定义） |
| `struct FGameplayCueParameters;` | **前置声明** GAS 类型（`.h` 只声明不实现，所以**不阻塞编译**——GAS 核心 P05 才教） |
| `struct FTenkaichiVerbMessage;` | 前置声明 P01.1 的消息体 |

> 🔑 关键点（铁律 30）：**`.h` 里 `FGameplayCueParameters` 只是前置声明**，没有 `#include "GameplayEffectTypes.h"`。所以**`.h` 能独立编译**，只有 `.cpp` 里用到完整定义（访问其成员）时才需要 GAS。

| 部分 | 干什么 |

### 3. 4 个静态工具函数

```cpp
public:
	// 从任意对象（Actor/Pawn/Controller/PlayerState 等）反查它所属的 PlayerState
	UE_API static APlayerState* GetPlayerStateFromObject(UObject* Object);
	// 从任意对象反查它所属的 PlayerController
	UE_API static APlayerController* GetPlayerControllerFromObject(UObject* Object);
	// 把一条 VerbMessage 转换成 GameplayCue 参数（⚠️ 依赖 GAS，.cpp 里挂起）
	UE_API static FGameplayCueParameters VerbMessageToCueParameters(const FTenkaichiVerbMessage& VerbMessage);
	// 把 GameplayCue 参数转换回一条 VerbMessage（⚠️ 依赖 GAS，.cpp 里挂起）
	UE_API static FTenkaichiVerbMessage CueParametersToVerbMessage(const FGameplayCueParameters& GameplayCueParameters);
```

| 函数 | 干什么 |
|------|--------|
| `GetPlayerStateFromObject(UObject*) → APlayerState*` | 从任意对象反查它的 PlayerState（`.cpp` 里按 Actor→Pawn→Controller→PlayerState 逐层找） |
| `GetPlayerControllerFromObject(UObject*) → APlayerController*` | 从任意对象反查它的 PlayerController |
| `VerbMessageToCueParameters(...) → FGameplayCueParameters` | 消息 → GAS 参数（**⚠️ `.cpp` 里挂起**，依赖 GAS `FGameplayCueParameters`） |
| `CueParametersToVerbMessage(...) → FTenkaichiVerbMessage` | GAS 参数 → 消息（**⚠️ `.cpp` 里挂起**） |

> 🔑 注意两个**前两个函数 `.cpp` 可编译**（只依赖引擎），**后两个 `.cpp` 需挂起**（依赖 GAS `FGameplayCueParameters` 完整定义）——但 `.h` 声明本身都写全，一个不省（铁律 23/25）。

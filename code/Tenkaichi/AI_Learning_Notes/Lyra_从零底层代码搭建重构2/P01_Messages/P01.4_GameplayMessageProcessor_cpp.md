# P01.4 UGameplayMessageProcessor —— 教 `.cpp`

## 一、本文件要解决什么

把 `.h` 里**声明**的方法**实现**出来。`.cpp` 有 57 行，实现五件事：

1. **`BeginPlay()`** —— 组件开始运行时，先调父类，再 `StartListening()`
2. **`EndPlay()`** —— 组件结束时，先调父类，再 `StopListening()` + **注销所有监听句柄**
3. **`StartListening()` / `StopListening()`** —— 空实现（子类覆盖）
4. **`AddListenerHandle()`** —— 把监听句柄存进数组（`MoveTemp` 移动）
5. **`GetServerTime()`** —— 返回服务器时间（用 GameState 的服务器时钟）

> 🔑 一句话：**`.cpp` 是"消息处理器的生命周期动作"——开始监听、结束清理、以及给子类用的两个工具函数**。

## 四、逐段讲解

### 1. include 区

```cpp
#include "GameplayMessageProcessor.h"

#include "Engine/World.h"
#include "GameFramework/GameStateBase.h"

#include UE_INLINE_GENERATED_CPP_BY_NAME(GameplayMessageProcessor)
```

| 行 | 干什么 |
|----|--------|
| `#include "GameplayMessageProcessor.h"` | 引入对应 `.h`（实现它声明的方法） |
| `#include "Engine/World.h"` | 引擎世界头（`GetWorld()` 需要） |
| `#include "GameFramework/GameStateBase.h"` | 引擎 GameState 头（`GetServerTime` 里要用） |
| `#include UE_INLINE_GENERATED_CPP_BY_NAME(GameplayMessageProcessor)` | UHT 生成的反射代码（UE5.4+ 标配） |

### 2. BeginPlay / EndPlay —— 生命周期钩子

```cpp
void UGameplayMessageProcessor::BeginPlay()
{
	Super::BeginPlay();

	StartListening();
}

void UGameplayMessageProcessor::EndPlay(const EEndPlayReason::Type EndPlayReason)
{
	Super::EndPlay(EndPlayReason);

	StopListening();

	// 移除所有监听句柄
	UGameplayMessageSubsystem& MessageSubsystem = UGameplayMessageSubsystem::Get(this);
	for (FGameplayMessageListenerHandle& Handle : ListenerHandles)
	{
		MessageSubsystem.UnregisterListener(Handle);
	}
	ListenerHandles.Empty();
}
```

| 行 | 干什么 |
|----|--------|
| `BeginPlay` | 组件开始运行时：先 `Super::BeginPlay()`，再 `StartListening()` 启动监听 |
| `EndPlay` | 组件结束时：先 `Super::EndPlay(...)`，再 `StopListening()` |
| `UGameplayMessageSubsystem::Get(this)` | 从本组件找到全局消息系统（S1 插件提供） |
| `for (... : ListenerHandles)` + `UnregisterListener(Handle)` | 遍历所有监听句柄，**逐个注销**监听 |
| `ListenerHandles.Empty()` | 清空句柄数组 |

> 🔑 设计核心：**子类在 `StartListening` 里注册的监听句柄，全部集中存在 `ListenerHandles` 数组**。组件一销毁，`EndPlay` 就把它们**统一注销干净**，不留泄漏。子类完全不用自己记着清理。

### 3. StartListening / StopListening —— 空实现（子类覆盖）

```cpp
void UGameplayMessageProcessor::StartListening()
{

}

void UGameplayMessageProcessor::StopListening()
{
}
```

| 函数 | 干什么 |
|------|--------|
| `StartListening()` | **空实现**——子类覆盖它，在这里用 `AddListenerHandle` 注册要听的消息 |
| `StopListening()` | **空实现**——子类覆盖它，停止监听 |

> 🔑 一句话：**基类只负责在正确时机调用它们**（`BeginPlay` 调 `StartListening`，`EndPlay` 调 `StopListening`），具体"监听哪些消息"由子类填。

### 4. AddListenerHandle —— 存监听句柄

```cpp
void UGameplayMessageProcessor::AddListenerHandle(FGameplayMessageListenerHandle&& Handle)
{
	ListenerHandles.Add(MoveTemp(Handle));
}
```

| 行 | 干什么 |
|----|--------|
| `FGameplayMessageListenerHandle&& Handle` | **右值引用参数**——接收一个临时/可移动的监听句柄 |
| `ListenerHandles.Add(MoveTemp(Handle))` | 用 `MoveTemp` **移动**进数组（避免拷贝，高效） |

> 🔑 一句话：**子类在 `StartListening` 里拿到一个新监听句柄后，调 `AddListenerHandle` 把它存进数组**，这样 `EndPlay` 能统一注销。右值引用 + `MoveTemp` 是"零拷贝转移"的惯用写法。

### 5. GetServerTime —— 服务器时间

```cpp
double UGameplayMessageProcessor::GetServerTime() const
{
	if (AGameStateBase* GameState = GetWorld()->GetGameState())
	{
		return GameState->GetServerWorldTimeSeconds();
	}
	else
	{
		return 0.0;
	}
}
```

| 行 | 干什么 |
|----|--------|
| `GetWorld()->GetGameState()` | 拿到当前世界的 GameState |
| `GameState->GetServerWorldTimeSeconds()` | 返回**服务器时钟**时间（秒）——服务器和客户端时钟可能不同步，这个函数取的是服务器权威时间 |
| `else return 0.0` | 拿不到 GameState 就返回 0 |

> 🔑 一句话：**服务器权威时间**——比如要判断"这条连杀消息是否在 3 秒内"，就用这个时间而不是客户端本地时间（避免不同步）。

## 一、这个 `.h` 解决什么问题（为什么）

游戏里"有人被击杀了"、"有人拾取了物品"、"有人发出技能效果"——这些事件要广播给关心它的人。广播需要**一个统一的"事件描述格式"**，否则每个功能自己发明一套，消息总线没法统一收发。

`FLyraVerbMessage` 就是消息总线用的**万能消息体（数据格式）**：

> **"谁（Instigator）用啥动词（Verb）对谁（Target）做了什么，带多少数值（Magnitude），以及各自的标签（InstigatorTags / TargetTags / ContextTags）。"**

`.h` 定义一个 `USTRUCT` 结构体，把这条"事件"的所有信息装进一个可被消息总线收发、可被蓝图读写的对象里。

> 🔑 **一句话**：`.h` 定义一张**通用"快递单"**——不管寄什么（击杀/拾取/通知），都用同一张单子，字段齐全，谁都能填、谁都能读。

## 二、完整代码（注释已中文化，你照这个抄）

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "CoreMinimal.h"
#include "GameplayTagContainer.h"

#include "TenkaichiVerbMessage.generated.h"

// 表示形如「发起者 动词 目标（带上下文与数值）」的通用消息
USTRUCT(BlueprintType)
struct FTenkaichiVerbMessage
{
	GENERATED_BODY()

	UPROPERTY(BlueprintReadWrite, Category=Gameplay)
	FGameplayTag Verb;

	UPROPERTY(BlueprintReadWrite, Category=Gameplay)
	TObjectPtr<UObject> Instigator = nullptr;

	UPROPERTY(BlueprintReadWrite, Category=Gameplay)
	TObjectPtr<UObject> Target = nullptr;

	UPROPERTY(BlueprintReadWrite, Category=Gameplay)
	FGameplayTagContainer InstigatorTags;

	UPROPERTY(BlueprintReadWrite, Category=Gameplay)
	FGameplayTagContainer TargetTags;

	UPROPERTY(BlueprintReadWrite, Category=Gameplay)
	FGameplayTagContainer ContextTags;

	UPROPERTY(BlueprintReadWrite, Category=Gameplay)
	double Magnitude = 1.0;

	// 返回这个消息的调试字符串表示
	TENKAICHIGAME_API FString ToString() const;
};
```

## 三、逐段拆解（先讲清为什么，再给代码）

### include 区

```cpp
#include "CoreMinimal.h"
#include "GameplayTagContainer.h"

#include "TenkaichiVerbMessage.generated.h"
```

| 行 | 干什么 |
|----|--------|
| `#include "CoreMinimal.h"` | 引擎核心基础头（`FString`/`double`/`TObjectPtr` 都在这里） |
| `#include "GameplayTagContainer.h"` | 引擎 GameplayTags 模块的标签容器——`FGameplayTag`/`FGameplayTagContainer` 在这里定义 |
| `#include "TenkaichiVerbMessage.generated.h"` | UHT 生成的反射代码（文件名带前缀 `Tenkaichi`） |

> 类比：`CoreMinimal.h` 是"C++ 工具箱"，`GameplayTagContainer.h` 是"标签袋"——消息体要装标签，必须先拿到袋子。

### USTRUCT —— FTenkaichiVerbMessage

```cpp
// 表示形如「发起者 动词 目标（带上下文与数值）」的通用消息
USTRUCT(BlueprintType)
struct FTenkaichiVerbMessage
{
	GENERATED_BODY()
```

| 行 | 干什么 |
|----|--------|
| 顶部 `//` 注释 | 说明这个消息体的含义："表示形如『发起者 动词 目标（带上下文与数值）』的通用消息" |
| `USTRUCT(BlueprintType)` | 标记为 USTRUCT 反射结构体，`BlueprintType` = 蓝图里可当变量用 |
| `struct FTenkaichiVerbMessage` | 定义结构体（`F` 前缀 = 非 UObject 的普通结构体） |
| `GENERATED_BODY()` | UHT 要求的标准宏 |

> 为什么用 `struct` 不用 `UCLASS`？消息体是**纯数据载体**，不需要对象生命周期、不需要继承、不需要复制管理——`USTRUCT` 结构体轻量又够用，还能在蓝图里读写。

### 七个 UPROPERTY 成员（核心）

```cpp
	UPROPERTY(BlueprintReadWrite, Category=Gameplay)
	FGameplayTag Verb;

	UPROPERTY(BlueprintReadWrite, Category=Gameplay)
	TObjectPtr<UObject> Instigator = nullptr;

	UPROPERTY(BlueprintReadWrite, Category=Gameplay)
	TObjectPtr<UObject> Target = nullptr;

	UPROPERTY(BlueprintReadWrite, Category=Gameplay)
	FGameplayTagContainer InstigatorTags;

	UPROPERTY(BlueprintReadWrite, Category=Gameplay)
	FGameplayTagContainer TargetTags;

	UPROPERTY(BlueprintReadWrite, Category=Gameplay)
	FGameplayTagContainer ContextTags;

	UPROPERTY(BlueprintReadWrite, Category=Gameplay)
	double Magnitude = 1.0;
```

| 成员 | 类型 | 含义 |
|------|------|------|
| `Verb` | `FGameplayTag` | **事件类型标签**（如 `Lyra.Elimination.Message`）——订阅方靠它过滤消息 |
| `Instigator` | `TObjectPtr<UObject>` | 发起者（谁干的），默认 `nullptr` |
| `Target` | `TObjectPtr<UObject>` | 目标（对谁干的），默认 `nullptr` |
| `InstigatorTags` | `FGameplayTagContainer` | 发起者身上的标签 |
| `TargetTags` | `FGameplayTagContainer` | 目标身上的标签 |
| `ContextTags` | `FGameplayTagContainer` | 环境/上下文标签 |
| `Magnitude` | `double` | 数值（如伤害量），默认 `1.0` |

| 通用点 | 说明 |
|--------|------|
| `UPROPERTY(BlueprintReadWrite, Category=Gameplay)` | 蓝图可读可写，归到"Gameplay"分类（7 个成员统一写法） |
| `TObjectPtr<UObject> ... = nullptr` | 智能对象指针，默认置空（不指向任何对象） |
| `FGameplayTagContainer` | 标签容器，默认空容器 |
| `Magnitude = 1.0` | 数值默认 1.0（乘性默认值，不填就是"1 倍"） |

> 一句话：**`Verb` 是"事件名"，`Instigator`/`Target` 是"谁和谁"，三组 `Tags` 是"上下文"，`Magnitude` 是"程度"**。整套字段凑齐，一次事件就被完整描述了。

### ToString —— 唯一方法

```cpp
	// 返回这个消息的调试字符串表示
	TENKAICHIGAME_API FString ToString() const;
```

| 行 | 干什么 |
|----|--------|
| `//` 注释 | 说明这个方法的用途："返回这个消息的调试字符串表示" |
| `TENKAICHIGAME_API` | 模块导出宏（`TenkaichiGame` 全大写 + `_API`）——让外部模块能调用这个方法 |
| `FString ToString() const` | 返回字符串，`const` = 不修改自身 |
| `;` | **只声明，不实现**——实现在 P01.5 的 `LyraVerbMessageHelpers.cpp`（Lyra 没有独立的 `LyraVerbMessage.cpp`） |

> `ToString()` 用引擎的 `ExportText` 把整个结构体序列化成可读字符串（实现在 P01.5 的 `LyraVerbMessageHelpers.cpp`），方便调试打印。

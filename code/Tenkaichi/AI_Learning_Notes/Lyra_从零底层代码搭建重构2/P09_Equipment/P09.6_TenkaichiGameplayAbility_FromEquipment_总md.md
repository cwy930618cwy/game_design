## 一、本文件要解决什么

P09 讲完了装备的穿脱。但还有一个关键问题：**装备授予的技能，怎么知道"我是哪个装备授予的"？**

当一件装备授予了一个技能（P09.3 的 `GiveToAbilitySystem`），这个技能需要**反过来拿到"关联的装备"**——比如"这把剑的技能"要知道自己是哪把剑，才能读剑的属性、算伤害。

`TenkaichiGameplayAbility_FromEquipment` 就是**"装备技能"的基类**：

- 它继承 P05.3-B 的 `TenkaichiGameplayAbility`（Lyra 技能基类）。
- 提供 `GetAssociatedEquipment()`：拿到"授予我这个技能的装备实例"。
- 提供 `GetAssociatedItem()`：拿到"装备对应的物品实例"（装备的 Instigator 就是物品）。

一句话：**装备技能基类 = 让一个技能能追溯到"我是哪件装备授予的、对应哪个物品"。**

## 五、核心概念：技能如何"追溯"到装备

关键在 `GetAssociatedEquipment()`：

```cpp
if (FGameplayAbilitySpec* Spec = UGameplayAbility::GetCurrentAbilitySpec())
{
	return Cast<ULyraEquipmentInstance>(Spec->SourceObject.Get());
}
```

- 每个技能运行时，都有一个 `FGameplayAbilitySpec`（技能描述符）。
- 装备授予技能时（P09.3 `GiveToAbilitySystem(ASC, &GrantedHandles, Result)`），把**装备实例 `Result` 作为 `SourceObject`** 存进技能描述符。
- 技能运行时，`GetCurrentAbilitySpec()` 拿到自己的描述符，`SourceObject` 就是"授予我的那个装备"。

> 类比：技能是"员工"，装备是"老板"。员工入职时（授予技能），老板的信息被登记（SourceObject）；员工干活时（技能运行），查登记就能知道"我老板是谁"。

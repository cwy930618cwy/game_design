## 一、本文件要解决什么

P09.1 是"装备菜谱"、P09.2 是"一件装备"。但**谁来管理"当前穿了哪些装备"？** 就是本组件。

`TenkaichiEquipmentManagerComponent` = **装备管理器**，挂在角色身上：
- 保存"已穿装备列表"（`FTenkaichiEquipmentList`，FastArray 增量同步）
- 提供 `EquipItem`（穿）/ `UnequipItem`（脱）
- 穿上时：**授予技能集**（`AbilitySet->GiveToAbilitySystem`）+ **生成装备 Actor**（武器模型）
- 脱下时：**回收技能** + **销毁 Actor**

它是 P08.7 `InventoryManagerComponent` 的"装备版"，但多了一个关键动作——**管理 GAS 技能集的授予与回收**。

一句话：**装备管理器 = 拥有并操作"已穿装备"的组件，负责穿/脱 + 授予/回收技能 + 生成/销毁 Actor。**

## 五、核心难点：授予/回收技能集

穿上装备时要授予技能，脱下时要回收——这是 P08 Inventory 没有的新概念：

```cpp
// 穿上：授予
AbilitySet->GiveToAbilitySystem(ASC, &NewEntry.GrantedHandles, Result);
// 脱下：回收
Entry.GrantedHandles.TakeFromAbilitySystem(ASC);
```

- `GiveToAbilitySystem`：把技能集里的所有技能（GameplayAbility / GameplayEffect / AttributeSet）授予给 ASC，返回**句柄**（`GrantedHandles`）。
- `GrantedHandles` 记录"我授予了哪些"，脱下时用 `TakeFromAbilitySystem` 按句柄**精确回收**。
- `GrantedHandles` 标 `NotReplicated`——**只在服务器记录**（授予/回收是服务器权威操作）。

> 类比：技能集是"一箱技能"，句柄是"取货凭证"。穿上 = 凭凭证取货；脱下 = 凭凭证退货。没有凭证就退不了，所以句柄必须存起来。

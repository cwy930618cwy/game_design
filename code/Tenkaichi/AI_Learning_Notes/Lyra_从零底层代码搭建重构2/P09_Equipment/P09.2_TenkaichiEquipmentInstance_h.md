## 二、完整代码（`.h`，注释已中文化）

```cpp
// 版权声明（Lyra 项目自带，保留）
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "Engine/World.h"

#include "TenkaichiEquipmentInstance.generated.h"

class AActor;
class APawn;
struct FFrame;
struct FTenkaichiEquipmentActorToSpawn;

/**
 * UTenkaichiEquipmentInstance
 *
 * 一件"生成并穿到角色身上"的装备
 */
UCLASS(BlueprintType, Blueprintable)
class UTenkaichiEquipmentInstance : public UObject
{
	GENERATED_BODY()

public:
	// 构造函数
	UTenkaichiEquipmentInstance(const FObjectInitializer& ObjectInitializer = FObjectInitializer::Get());

	//~UObject 接口
	// 支持网络复制（返回 true）
	virtual bool IsSupportedForNetworking() const override { return true; }
	// 取世界：返回穿戴 Pawn 的世界
	virtual UWorld* GetWorld() const override final;
	//~UObject 接口结束

	// 取穿戴者（谁穿的这件装备）
	UFUNCTION(BlueprintPure, Category=Equipment)
	UObject* GetInstigator() const { return Instigator; }

	// 设置穿戴者
	void SetInstigator(UObject* InInstigator) { Instigator = InInstigator; }

	// 取穿戴的 Pawn
	UFUNCTION(BlueprintPure, Category=Equipment)
	APawn* GetPawn() const;

	// 取穿戴的 Pawn（带类型检查，返回指定类型或空）
	UFUNCTION(BlueprintPure, Category=Equipment, meta=(DeterminesOutputType=PawnType))
	APawn* GetTypedPawn(TSubclassOf<APawn> PawnType) const;

	// 取生成的 Actor 列表
	UFUNCTION(BlueprintPure, Category=Equipment)
	TArray<AActor*> GetSpawnedActors() const { return SpawnedActors; }

	// 按定义生成装备 Actor（武器模型等），挂到角色身上
	virtual void SpawnEquipmentActors(const TArray<FTenkaichiEquipmentActorToSpawn>& ActorsToSpawn);
	// 销毁生成的装备 Actor
	virtual void DestroyEquipmentActors();

	// 装备时的钩子（可覆写）
	virtual void OnEquipped();
	// 卸下时的钩子（可覆写）
	virtual void OnUnequipped();

protected:
#if UE_WITH_IRIS
	// 注册所有复制片段（Iris 网络复制系统）
	virtual void RegisterReplicationFragments(UE::Net::FFragmentRegistrationContext& Context, UE::Net::EFragmentRegistrationFlags RegistrationFlags) override;
#endif // UE_WITH_IRIS

	// 蓝图可覆写事件：装备时触发
	UFUNCTION(BlueprintImplementableEvent, Category=Equipment, meta=(DisplayName="OnEquipped"))
	void K2_OnEquipped();

	// 蓝图可覆写事件：卸下时触发
	UFUNCTION(BlueprintImplementableEvent, Category=Equipment, meta=(DisplayName="OnUnequipped"))
	void K2_OnUnequipped();

private:
	// Instigator 复制回调
	UFUNCTION()
	void OnRep_Instigator();

private:
	// 穿戴者（谁穿的），复制时触发 OnRep_Instigator
	UPROPERTY(ReplicatedUsing=OnRep_Instigator)
	TObjectPtr<UObject> Instigator;

	// 生成的 Actor 列表（武器模型等），随网络复制
	UPROPERTY(Replicated)
	TArray<TObjectPtr<AActor>> SpawnedActors;
};
```

## 三、逐段讲解

### 1. include 与前置声明

```cpp
#include "Engine/World.h"
```

- `Engine/World.h`：`UWorld`。因为 `GetWorld()` 返回 `UWorld*`（指针），按理前置声明就够，但 Lyra 原样 include 了（照抄）。

```cpp
class AActor;
class APawn;
struct FFrame;
struct FTenkaichiEquipmentActorToSpawn;
```

- 前置声明：`AActor`（引擎）、`APawn`（引擎）、`FFrame`、`FTenkaichiEquipmentActorToSpawn`（P09.1 的结构体）。
- `FTenkaichiEquipmentActorToSpawn` 在 `SpawnEquipmentActors` 参数里用（`const TArray<...>&`），只声明函数原型，前置声明够。

### 2. 类标记

```cpp
UCLASS(BlueprintType, Blueprintable)
class UTenkaichiEquipmentInstance : public UObject
```

- 继承 `UObject`（不是 Actor/组件）。
- `BlueprintType` + `Blueprintable`：可暴露给蓝图、可建蓝图子类（和 Definition 的 `Abstract` 不同，这里是**可实例化的具体类**）。

### 3. UObject 接口覆写

```cpp
virtual bool IsSupportedForNetworking() const override { return true; }
virtual UWorld* GetWorld() const override final;
```

- `IsSupportedForNetworking`：**返回 true**，告诉引擎"这个 UObject 支持网络复制"（普通 UObject 默认不支持，装备实例要复制，所以覆写返回 true）。
- `GetWorld`：覆写取世界，`final` 表示子类不能再覆写。实现里通过 `GetPawn()->GetWorld()` 拿世界（`.cpp` 里）。

### 4. 穿戴者相关

```cpp
UObject* GetInstigator() const { return Instigator; }
void SetInstigator(UObject* InInstigator) { Instigator = InInstigator; }
APawn* GetPawn() const;
APawn* GetTypedPawn(TSubclassOf<APawn> PawnType) const;
```

- `GetInstigator` / `SetInstigator`：内联实现（直接读写字段）。
- `GetPawn`：返回穿戴的 Pawn（实现 `Cast<APawn>(GetOuter())`，Outer 就是 Pawn）。
- `GetTypedPawn`：带类型检查，`meta=(DeterminesOutputType=PawnType)` 让蓝图能推断返回类型。

### 5. 生成/销毁 Actor + 钩子

```cpp
virtual void SpawnEquipmentActors(const TArray<FTenkaichiEquipmentActorToSpawn>& ActorsToSpawn);
virtual void DestroyEquipmentActors();
virtual void OnEquipped();
virtual void OnUnequipped();
```

- `SpawnEquipmentActors`：按 P09.1 定义里的 `ActorsToSpawn` 生成 Actor（武器模型），挂到角色身上。
- `DestroyEquipmentActors`：销毁这些 Actor。
- `OnEquipped` / `OnUnequipped`：装备/卸下钩子，`virtual` 可覆写（C++ 扩展点）。

### 6. 蓝图事件 + 复制

```cpp
UFUNCTION(BlueprintImplementableEvent, Category=Equipment, meta=(DisplayName="OnEquipped"))
void K2_OnEquipped();
UFUNCTION(BlueprintImplementableEvent, Category=Equipment, meta=(DisplayName="OnUnequipped"))
void K2_OnUnequipped();
```

- `BlueprintImplementableEvent`：**只在蓝图中实现**，C++ 不实现（引擎自动生成调用桩）。`DisplayName` 给蓝图显示的名字（`OnEquipped`，去掉 `K2_` 前缀）。

```cpp
UPROPERTY(ReplicatedUsing=OnRep_Instigator)
TObjectPtr<UObject> Instigator;
UPROPERTY(Replicated)
TArray<TObjectPtr<AActor>> SpawnedActors;
```

- `Instigator`：`ReplicatedUsing=OnRep_Instigator` —— 复制这个字段时，客户端调用 `OnRep_Instigator` 回调（当前空实现，留扩展位）。
- `SpawnedActors`：`Replicated` —— 直接复制，无回调。

### 7. Iris 复制（条件编译）

```cpp
#if UE_WITH_IRIS
virtual void RegisterReplicationFragments(...) override;
#endif // UE_WITH_IRIS
```

- `UE_WITH_IRIS` 是 UE5 的新网络复制系统（Iris）开关，**默认关闭**。这段是 Iris 专用的注册函数，`#if` 包起来，正常编译不生效，照抄保留。

## 二、完整代码（`.h`，注释已中文化）

```cpp
// 版权声明（Lyra 项目自带，保留）
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "Components/ControllerComponent.h"
#include "Inventory/TenkaichiInventoryItemInstance.h"

#include "TenkaichiQuickBarComponent.generated.h"

class AActor;
class UTenkaichiEquipmentInstance;
class UTenkaichiEquipmentManagerComponent;
class UObject;
struct FFrame;

// 快捷栏组件：挂在 Controller 上，管理装备槽位
UCLASS(Blueprintable, meta=(BlueprintSpawnableComponent))
class UTenkaichiQuickBarComponent : public UControllerComponent
{
	GENERATED_BODY()

public:
	// 构造函数
	UTenkaichiQuickBarComponent(const FObjectInitializer& ObjectInitializer = FObjectInitializer::Get());

	// 向前循环切换激活槽
	UFUNCTION(BlueprintCallable, Category="Tenkaichi")
	void CycleActiveSlotForward();

	// 向后循环切换激活槽
	UFUNCTION(BlueprintCallable, Category="Tenkaichi")
	void CycleActiveSlotBackward();

	// 设置激活槽下标（服务器 RPC，只在服务器执行）
	UFUNCTION(Server, Reliable, BlueprintCallable, Category="Tenkaichi")
	void SetActiveSlotIndex(int32 NewIndex);

	// 取所有槽位
	UFUNCTION(BlueprintCallable, BlueprintPure=false)
	TArray<UTenkaichiInventoryItemInstance*> GetSlots() const
	{
		return Slots;
	}

	// 取当前激活槽下标
	UFUNCTION(BlueprintCallable, BlueprintPure=false)
	int32 GetActiveSlotIndex() const { return ActiveSlotIndex; }

	// 取当前激活槽的物品
	UFUNCTION(BlueprintCallable, BlueprintPure = false)
	UTenkaichiInventoryItemInstance* GetActiveSlotItem() const;

	// 取下一个空槽下标（没有返回 INDEX_NONE）
	UFUNCTION(BlueprintCallable, BlueprintPure=false)
	int32 GetNextFreeItemSlot() const;

	// 往某槽放物品（服务器权限）
	UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly)
	void AddItemToSlot(int32 SlotIndex, UTenkaichiInventoryItemInstance* Item);

	// 从某槽取物品（服务器权限）
	UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly)
	UTenkaichiInventoryItemInstance* RemoveItemFromSlot(int32 SlotIndex);

	// 组件开始运行时调用
	virtual void BeginPlay() override;

private:
	// 脱下当前槽的装备
	void UnequipItemInSlot();
	// 穿上当前槽的装备
	void EquipItemInSlot();

	// 找角色的装备管理器
	UTenkaichiEquipmentManagerComponent* FindEquipmentManager() const;

protected:
	// 槽位数量（默认 3）
	UPROPERTY()
	int32 NumSlots = 3;

	// 槽位变化复制回调
	UFUNCTION()
	void OnRep_Slots();

	// 激活槽变化复制回调
	UFUNCTION()
	void OnRep_ActiveSlotIndex();

private:
	// 槽位数组（复制时触发 OnRep_Slots）
	UPROPERTY(ReplicatedUsing=OnRep_Slots)
	TArray<TObjectPtr<UTenkaichiInventoryItemInstance>> Slots;

	// 当前激活槽下标（-1 = 无，复制时触发 OnRep_ActiveSlotIndex）
	UPROPERTY(ReplicatedUsing=OnRep_ActiveSlotIndex)
	int32 ActiveSlotIndex = -1;

	// 当前穿上的装备（不复制，本地记录）
	UPROPERTY()
	TObjectPtr<UTenkaichiEquipmentInstance> EquippedItem;
};


// 槽位变化消息：槽位数组变了时广播
USTRUCT(BlueprintType)
struct FTenkaichiQuickBarSlotsChangedMessage
{
	GENERATED_BODY()

	// 谁的快捷栏
	UPROPERTY(BlueprintReadOnly, Category=Inventory)
	TObjectPtr<AActor> Owner = nullptr;

	// 最新槽位数组
	UPROPERTY(BlueprintReadOnly, Category = Inventory)
	TArray<TObjectPtr<UTenkaichiInventoryItemInstance>> Slots;
};


// 激活槽变化消息：激活槽下标变了时广播
USTRUCT(BlueprintType)
struct FTenkaichiQuickBarActiveIndexChangedMessage
{
	GENERATED_BODY()

	// 谁的快捷栏
	UPROPERTY(BlueprintReadOnly, Category=Inventory)
	TObjectPtr<AActor> Owner = nullptr;

	// 最新激活槽下标
	UPROPERTY(BlueprintReadOnly, Category=Inventory)
	int32 ActiveIndex = 0;
};
```

## 三、逐段讲解

### 1. include 与前置声明

```cpp
#include "Components/ControllerComponent.h"
#include "Inventory/TenkaichiInventoryItemInstance.h"
```

- `Components/ControllerComponent.h`：`UControllerComponent`（挂 Controller 的组件基类）。
- `Inventory/TenkaichiInventoryItemInstance.h`：P08.2 的物品实例。因为 `GetSlots()` 内联返回 `TArray<UTenkaichiInventoryItemInstance*>`，且字段 `Slots` 是 `TArray<TObjectPtr<...>>`，需要完整类型（不是纯前置声明）。

```cpp
class AActor;
class UTenkaichiEquipmentInstance;
class UTenkaichiEquipmentManagerComponent;
class UObject;
struct FFrame;
```

- 前置声明：`AActor`（消息结构体用）、`UTenkaichiEquipmentInstance`/`UTenkaichiEquipmentManagerComponent`（P09.2/09.3，只用指针）。

### 2. 类声明

```cpp
UCLASS(Blueprintable, meta=(BlueprintSpawnableComponent))
class UTenkaichiQuickBarComponent : public UControllerComponent
```

- 继承 `UControllerComponent`（挂 Controller，不是 Pawn）。
- `Blueprintable` + `BlueprintSpawnableComponent`：可建蓝图子类、可在蓝图里作为组件添加。

### 3. 切换方法

```cpp
UFUNCTION(BlueprintCallable, Category="Tenkaichi")
void CycleActiveSlotForward();
UFUNCTION(BlueprintCallable, Category="Tenkaichi")
void CycleActiveSlotBackward();
```

- 向前/向后循环切换激活槽（滚轮切武器）。
- 注意 `Category="Tenkaichi"`（Lyra 原文是 `Category="Lyra"`，换前缀）。

### 4. Server RPC

```cpp
UFUNCTION(Server, Reliable, BlueprintCallable, Category="Tenkaichi")
void SetActiveSlotIndex(int32 NewIndex);
```

- **`Server` 关键字**：这是一个 **Server RPC**——客户端调用，但**只在服务器执行**（对应 `SetActiveSlotIndex_Implementation`）。
- `Reliable`：可靠传输（保证送达）。
- 为什么服务器执行：切换装备是权威操作。

### 5. 查询方法（内联）

```cpp
TArray<UTenkaichiInventoryItemInstance*> GetSlots() const { return Slots; }
int32 GetActiveSlotIndex() const { return ActiveSlotIndex; }
```

- `GetSlots` / `GetActiveSlotIndex` 内联实现（直接返回字段）。
- `GetActiveSlotItem` / `GetNextFreeItemSlot` 声明在 `.h`，实现在 `.cpp`。

### 6. 增删槽位

```cpp
UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly)
void AddItemToSlot(int32 SlotIndex, UTenkaichiInventoryItemInstance* Item);
UFUNCTION(BlueprintCallable, BlueprintAuthorityOnly)
UTenkaichiInventoryItemInstance* RemoveItemFromSlot(int32 SlotIndex);
```

- 放/取物品，`BlueprintAuthorityOnly`（服务器权限）。

### 7. 私有方法 + 字段

```cpp
private:
	void UnequipItemInSlot();
	void EquipItemInSlot();
	UTenkaichiEquipmentManagerComponent* FindEquipmentManager() const;
```

- 三个私有方法：穿/脱当前槽装备 + 找装备管理器（内部辅助）。

```cpp
protected:
	UPROPERTY()
	int32 NumSlots = 3;
	UFUNCTION()
	void OnRep_Slots();
	UFUNCTION()
	void OnRep_ActiveSlotIndex();
private:
	UPROPERTY(ReplicatedUsing=OnRep_Slots)
	TArray<TObjectPtr<UTenkaichiInventoryItemInstance>> Slots;
	UPROPERTY(ReplicatedUsing=OnRep_ActiveSlotIndex)
	int32 ActiveSlotIndex = -1;
	UPROPERTY()
	TObjectPtr<UTenkaichiEquipmentInstance> EquippedItem;
```

- `NumSlots`（默认 3）：`protected`，子类可改。
- `Slots`：`ReplicatedUsing=OnRep_Slots`（复制时广播槽位变化）。
- `ActiveSlotIndex`（默认 -1）：`ReplicatedUsing=OnRep_ActiveSlotIndex`（复制时广播激活槽变化）。
- `EquippedItem`：**不复制**（`UPROPERTY()` 无 `Replicated`）——它是"本地穿的装备"，服务器和客户端各自维护。

### 8. 两个消息结构体

```cpp
USTRUCT(BlueprintType)
struct FTenkaichiQuickBarSlotsChangedMessage
{
	GENERATED_BODY()
	UPROPERTY(BlueprintReadOnly, Category=Inventory)
	TObjectPtr<AActor> Owner = nullptr;
	UPROPERTY(BlueprintReadOnly, Category = Inventory)
	TArray<TObjectPtr<UTenkaichiInventoryItemInstance>> Slots;
};
```

- 槽位变化消息：`Owner`（谁的）+ `Slots`（最新数组）。
- 激活槽变化消息：`Owner` + `ActiveIndex`（最新下标）。
- 都是纯数据消息体（`BlueprintType` + `BlueprintReadOnly`），供 UI 监听。

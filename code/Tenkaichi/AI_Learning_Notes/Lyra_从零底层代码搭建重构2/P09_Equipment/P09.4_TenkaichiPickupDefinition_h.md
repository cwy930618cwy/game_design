## 二、完整代码（`.h`，注释已中文化）

```cpp
// 版权声明（Lyra 项目自带，保留）
// Copyright Epic Games, Inc. All Rights Reserved.

#pragma once

#include "Engine/DataAsset.h"

#include "TenkaichiPickupDefinition.generated.h"

class UTenkaichiInventoryItemDefinition;
class UNiagaraSystem;
class UObject;
class USoundBase;
class UStaticMesh;

/**
 * 拾取物定义：配置"地上的战利品"是什么、长什么样、什么音效特效
 */
UCLASS(MinimalAPI, Blueprintable, BlueprintType, Const, Meta = (DisplayName = "Tenkaichi Pickup Data", ShortTooltip = "用于配置一个拾取物的数据资产。"))
class UTenkaichiPickupDefinition : public UDataAsset
{
	GENERATED_BODY()

public:

	// 捡起来得到什么物品（P08 的物品定义）
	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Tenkaichi|Pickup|Equipment")
	TSubclassOf<UTenkaichiInventoryItemDefinition> InventoryItemDefinition;

	// 地上显示的模型
	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Tenkaichi|Pickup|Mesh")
	TObjectPtr<UStaticMesh> DisplayMesh;

	// 拾取物重生冷却时间（秒）
	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Tenkaichi|Pickup")
	int32 SpawnCoolDownSeconds;

	// 捡起时播放的音效
	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Tenkaichi|Pickup")
	TObjectPtr<USoundBase> PickedUpSound;

	// 重生时播放的音效
	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Tenkaichi|Pickup")
	TObjectPtr<USoundBase> RespawnedSound;

	// 捡起时播放的特效
	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Tenkaichi|Pickup")
	TObjectPtr<UNiagaraSystem> PickedUpEffect;

	// 重生时播放的特效
	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Tenkaichi|Pickup")
	TObjectPtr<UNiagaraSystem> RespawnedEffect;
};


/**
 * 武器拾取物定义：在基础拾取定义上，多加武器模型的偏移和缩放
 */
UCLASS(MinimalAPI, Blueprintable, BlueprintType, Const, Meta = (DisplayName = "Tenkaichi Weapon Pickup Data", ShortTooltip = "用于配置一个武器拾取物的数据资产。"))
class UTenkaichiWeaponPickupDefinition : public UTenkaichiPickupDefinition
{
	GENERATED_BODY()

public:

	// 武器显示模型相对生成点的高度偏移
	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Tenkaichi|Pickup|Mesh")
	FVector WeaponMeshOffset;

	// 武器显示模型的缩放（默认 1,1,1）
	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Tenkaichi|Pickup|Mesh")
	FVector WeaponMeshScale = FVector(1.0f, 1.0f, 1.0f);
};
```

## 三、逐段讲解

### 1. include 与前置声明

```cpp
#include "Engine/DataAsset.h"
```

- `UDataAsset` 的完整定义（要继承它，必须 include）。

```cpp
class UTenkaichiInventoryItemDefinition;
class UNiagaraSystem;
class UObject;
class USoundBase;
class UStaticMesh;
```

- 五个前置声明：`UTenkaichiInventoryItemDefinition`（P08 类型）、`UNiagaraSystem`/`USoundBase`/`UStaticMesh`（引擎表现类型）、`UObject`。
- **为什么前置声明够**：这些字段都是 `TSubclassOf<...>` 或 `TObjectPtr<...>`（指针/类引用），不实例化，编译期只需类型名。

### 2. 基础类：`UTenkaichiPickupDefinition`

```cpp
UCLASS(MinimalAPI, Blueprintable, BlueprintType, Const, Meta = (DisplayName = "Tenkaichi Pickup Data", ShortTooltip = "用于配置一个拾取物的数据资产。"))
class UTenkaichiPickupDefinition : public UDataAsset
```

- 继承 `UDataAsset`（纯数据对象）。
- `MinimalAPI`：只导出最小 API。
- `Blueprintable` + `BlueprintType`：可建蓝图子类、可暴露蓝图。
- `Const`：实例只读（配置卡定位）。
- `Meta=(DisplayName=..., ShortTooltip=...)`：编辑器里显示的名字和提示（蓝图资产选择器里看到）。

### 3. 七个字段

```cpp
UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Tenkaichi|Pickup|Equipment")
TSubclassOf<UTenkaichiInventoryItemDefinition> InventoryItemDefinition;
```

- `InventoryItemDefinition`：捡到的是什么物品（P08）。
- `Category = "Tenkaichi|Pickup|Equipment"`：编辑器分类（注意 Lyra 原文是 `Lyra|Pickup|Equipment`，换前缀 `Tenkaichi`）。

```cpp
UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Tenkaichi|Pickup|Mesh")
TObjectPtr<UStaticMesh> DisplayMesh;
UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Tenkaichi|Pickup")
int32 SpawnCoolDownSeconds;
```

- `DisplayMesh`：地上显示的模型（静态网格）。
- `SpawnCoolDownSeconds`：重生冷却（`int32`，没有默认值，Lyra 原样）。

```cpp
TObjectPtr<USoundBase> PickedUpSound;    // 捡起音效
TObjectPtr<USoundBase> RespawnedSound;   // 重生音效
TObjectPtr<UNiagaraSystem> PickedUpEffect;    // 捡起特效
TObjectPtr<UNiagaraSystem> RespawnedEffect;   // 重生特效
```

- 两组音效 + 两组特效（捡起 / 重生各一套）。
- `UNiagaraSystem`：UE5 的新粒子系统（替代旧的 Cascade）。

### 4. 子类：`UTenkaichiWeaponPickupDefinition`

```cpp
UCLASS(MinimalAPI, Blueprintable, BlueprintType, Const, Meta = (DisplayName = "Tenkaichi Weapon Pickup Data", ...))
class UTenkaichiWeaponPickupDefinition : public UTenkaichiPickupDefinition
{
	GENERATED_BODY()
public:
	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Tenkaichi|Pickup|Mesh")
	FVector WeaponMeshOffset;
	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Tenkaichi|Pickup|Mesh")
	FVector WeaponMeshScale = FVector(1.0f, 1.0f, 1.0f);
};
```

- 继承 `UTenkaichiPickupDefinition`，**复用父类全部 7 个字段**。
- 额外 2 个字段：`WeaponMeshOffset`（模型偏移）+ `WeaponMeshScale`（模型缩放，默认 1,1,1）。
- **为什么武器要单独子类**：武器拾取物（枪、剑）需要调整模型在地面上的位置和大小（枪太长、剑有柄），普通拾取物（药水）不需要。

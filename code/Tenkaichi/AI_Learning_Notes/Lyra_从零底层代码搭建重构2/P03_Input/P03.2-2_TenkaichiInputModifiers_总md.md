## 一、为什么要有这一节

**输入修饰器（InputModifier）**：在"原始输入值"到达游戏逻辑**之前**，对输入值做各种处理。

这是 EnhancedInput 插件的核心概念——一个输入动作的原始值，会先经过一串"修饰器"加工，最后才进入游戏逻辑。Lyra 定义了自己的 4 个修饰器：

| 修饰器类 | 一句话职责 |
|---------|-----------|
| `ULyraSettingBasedScalar` | 按设置里的属性值，缩放输入轴的 XYZ |
| `ULyraInputModifierDeadZone` | 死区（摇杆在小范围内不响应，防漂移） |
| `ULyraInputModifierGamepadSensitivity` | 手柄灵敏度（查 P03.2-1 的灵敏度表） |
| `ULyraInputModifierAimInversion` | 瞄准轴反转（上下/左右） |

> 🔑 **一句话**：Lyra 的 4 个修饰器，都是"从共享设置（Settings）读配置，去加工输入值"——死区大小、灵敏度、反转开关，全都走设置类，不写死在代码里。

## 三、本文件里有什么（全景）

一个 `.h` 里定义 **4 个修饰器类 + 2 个枚举**：

### 1. 枚举 `EDeadzoneStick`（死区属于哪个摇杆）

```cpp
UENUM()
enum class EDeadzoneStick : uint8
{
	MoveStick = 0,   // 移动摇杆的死区
	LookStick = 1,   // 视角摇杆的死区
};
```

### 2. 枚举 `ELyraTargetingType`（瞄准类型）

```cpp
UENUM()
enum class ELyraTargetingType : uint8
{
	Normal = 0,   // 平时环视
	ADS = 1,      // 开镜瞄准（Aim Down Sights）
};
```

### 3. `ULyraSettingBasedScalar`（按设置缩放轴）

```cpp
UCLASS(NotBlueprintable, MinimalAPI, meta = (DisplayName = "Setting Based Scalar"))
class ULyraSettingBasedScalar : public UInputModifier
{
	FName XAxisScalarSettingName;   // X 轴缩放用哪个设置属性
	FName YAxisScalarSettingName;   // Y 轴
	FName ZAxisScalarSettingName;   // Z 轴
	FVector MaxValueClamp;          // 缩放上限
	FVector MinValueClamp;          // 缩放下限
};
```

### 4. `ULyraInputModifierDeadZone`（死区）

```cpp
UCLASS(NotBlueprintable, MinimalAPI, meta = (DisplayName = "Lyra Settings Driven Dead Zone"))
class ULyraInputModifierDeadZone : public UInputModifier
{
	EDeadZoneType Type;              // 死区类型（径向/轴向，引擎定义）
	float UpperThreshold;            // 上限阈值
	EDeadzoneStick DeadzoneStick;    // 属于哪个摇杆
};
```

### 5. `ULyraInputModifierGamepadSensitivity`（手柄灵敏度）

```cpp
UCLASS(NotBlueprintable, MinimalAPI, meta = (DisplayName = "Lyra Gamepad Sensitivity"))
class ULyraInputModifierGamepadSensitivity : public UInputModifier
{
	ELyraTargetingType TargetingType;                 // 瞄准类型（普通/ADS）
	TObjectPtr<const ULyraAimSensitivityData> SensitivityLevelTable;  // 灵敏度表（P03.2-1）
};
```

### 6. `ULyraInputModifierAimInversion`（瞄准反转）

```cpp
UCLASS(NotBlueprintable, MinimalAPI, meta = (DisplayName = "Lyra Aim Inversion Setting"))
class ULyraInputModifierAimInversion : public UInputModifier
{
	// 重写 ModifyRaw：按设置里的反转开关翻转轴
};
```

## 四、关键点

1. **都继承 `UInputModifier`**（引擎 EnhancedInput 的修饰器基类），重写 `ModifyRaw_Implementation`（加工输入值）——这是修饰器真正干活的函数。
2. **`NotBlueprintable` + `MinimalAPI`**：不能在蓝图子类化（只能作为资产直接配置使用）+ 最小导出。
3. **`ULyraInputModifierGamepadSensitivity` 引用 `SensitivityLevelTable`**（P03.2-1 的 `AimSensitivityData`）：这就是为什么先教 AimSensitivityData——它给 GamepadSensitivity 提供灵敏度表。
4. **`.cpp` 依赖 P12 + P18**：4 个修饰器都要 `ULyraLocalPlayer`（P12）拿 `GetSharedSettings()`（P18 `ULyraSettingsShared`），所以 `.cpp` 挂起。

## 五、逐段讲解

### 1. 头文件


- 第三行：`UE_INLINE_GENERATED_CPP_BY_NAME(TenkaichiAimSensitivityData)`——UHT 内联生成宏，名字须与类名一致。

### 2. 构造函数（`#if 0` 挂起）

```cpp

	: Super(ObjectInitializer)

```

- `: Super(ObjectInitializer)`：调用基类 `UPrimaryDataAsset` 的构造函数。
- 函数体给 `SensitivityMap` 填默认表：**10 档**，从 `Slow`（0.5）到 `Insane`（2.5），`Normal` 是 1.0 基准。
- 每个档位名（`Slow`/`SlowPlus`…）都是 P18 枚举的成员，所以这段要挂起。

### 3. 查询函数 `SensitivtyEnumToFloat`（`#if 0` 挂起）

```cpp
const float UTenkaichiAimSensitivityData::SensitivtyEnumToFloat(const ELyraGamepadSensitivity InSensitivity) const
{
	if (const float* Sens = SensitivityMap.Find(InSensitivity))
	{
		return *Sens;
	}
	return 1.0f;
}
```

逻辑拆解：
1. **`SensitivityMap.Find(InSensitivity)`**：在映射表里找传入档位；`Find` 返回**指针**（找到返回指向值的指针，找不到返回 `nullptr`）。
2. **`if (const float* Sens = ...)`**：C++17 的 if 初始化——声明指针 `Sens` 并判断是否非空。非空 → 进入分支。
3. **`return *Sens;`**：解引用返回实际数值。
4. **兜底 `return 1.0f`**：找不到档位（表里没有这个档位）就返回基准值 1.0。

> 因为 `.h` 里前置声明枚举无法实例化完整 `TMap` 类型，这段函数体也依赖 P18，一并挂起。

## 六、几个要记住的点

1. **`.cpp` 硬依赖 include**：只有 `.cpp` 要实例化完整 `TMap<ELyraGamepadSensitivity, float>` 才需要 `TenkaichiSettingsShared.h`（铁律 30 硬调用）。
2. **`Super(ObjectInitializer)`**：基类构造调用。
3. **`TMap::Find` 返回指针**：用它做"查得到 / 查不到"判断，解引用返回实际值。
4. **兜底返回值**：找不到返回 `1.0f`（基准灵敏度）。

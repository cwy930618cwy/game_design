## 三、插件结构解剖

每个插件的典型目录结构：

```
PluginName/
├── PluginName.uplugin     ← 插件描述文件
├── Source/                ← C++ 源码
│   ├── PluginName/        ← 主模块
│   │   ├── PluginName.Build.cs    ← 模块依赖
│   │   ├── Public/        ← 公开头文件
│   │   └── Private/       ← 私有实现
│   └── ...                ← 可能有多个模块
├── Content/               ← 蓝图/材质/音效资产
├── Config/                ← 配置文件
├── Resources/             ← 图标/缩略图
└── Binaries/              ← 编译产物
```

### .uplugin 文件示例

```json
{
    "FileVersion": 3,
    "Version": 1,
    "VersionName": "1.0",
    "FriendlyName": "Gameplay Abilities",
    "Description": "Ability System for games.",
    "Category": "Gameplay",
    "EnabledByDefault": false,
    "Modules": [
        {
            "Name": "GameplayAbilities",
            "Type": "Runtime",
            "LoadingPhase": "Default"
        }
    ]
}
```

## 四、插件加载阶段（LoadingPhase）

```cpp
enum class ELoadingPhase : uint8
{
    EarliestPossible,    // 最早
    PreEarlyLoadingScreen,
    PreLoadingScreen,
    PreDefault,
    Default,             // ⭐ 最常用
    PostDefault,
    PostConfigInit,
    PostSplashScreen,
    Latest               // 最晚
};
```

**Lyra 中的用法**：GameFeature 插件通常用 `PostDefault` 或更晚的阶段加载。

## 五、学习建议

1. **优先熟悉 Runtime/** — 这是 Lyra 用到的核心插件集合
2. **每个插件看 .uplugin** — 快速了解插件元信息
3. **找对应关系** — 教程里提到的每个系统对应哪个插件
4. **不要全看** — 100+ 插件不可能都学，按需深入

# 故事版总结：一场"开火"大戏是怎么演出来的

> **定位**：这篇是 [05 配置速查](./05_各资产配置项速查手册.md)、[06 为什么是蓝图](./06_为什么技能是蓝图_事件图表在干嘛.md)、[07 拆解真实蓝图](./07_实战_拆解真实的GA_Weapon_Fire蓝图.md) 三篇的**大白话浓缩版**。代码概念太多看晕了？看这一篇就够了——一个故事 + 几张图，讲清"开火"到底怎么回事。
>
> **一句话**：**C++ 写好"所有戏通用的规矩"，蓝图填"这一场戏怎么演"，配置格子决定"用什么道具"。**

---

## 一、先记住 3 个角色（就 3 个！）

把"技能"想象成**剧院里的一场戏**。一场"开火"戏，只有三层：

```
📜 剧本模板（C++ 基类）     = 规定"每场戏都要有：何时上台、耗什么道具、失败怎么办"
🎬 这场戏的演法（蓝图）     = "开火"这场戏具体怎么演：开枪、命中、扣血
📋 道具清单（配置格子）     = 用什么枪、什么动画、打多少血（换道具=换枪）
```

| 层 | 剧院类比 | 谁来做 | 对应技术 |
|----|---------|--------|---------|
| 剧本模板 | 每场戏通用的规矩 | 程序员（写一次） | C++ 基类 `ULyraGameplayAbility` |
| 这场戏的演法 | "开火"具体怎么演 | 策划（每场一份） | 蓝图 `GA_Weapon_Fire` |
| 道具清单 | 用什么枪/动画/伤害 | 策划填格子 | 配置变量（动画/GE/特效） |

## 二、故事：玩家按下开火键，发生了什么？

```
🎮 玩家按下开火键
        │
        ▼
① 导演喊："开火技能，上台！"          ← 技能被激活
        │
        ▼
② 演员同时做两件事（一人分饰两角）：
   ├─ 左半边：朝敌人"瞄准射击"（射线检测，看打中没）
   └─ 右半边：做出"开枪"的动作（播开火动画）
        │
        ▼
③ 瞄准结果出来了："打中了吗？"
        │
   ┌────┴────┐
  没中        中了
   │          │
   │          ├─▶ 🎆 先放"命中火花特效"（让所有人看得见）
   │          │
   │          └─▶ 🩸 再"扣敌人血"（只有服务器说了算，防外挂）
   │
   ▼
④ 演员谢幕（技能结束）
```

**就这么简单！** 一场开火 = **瞄准 + 放动画 → 判断中没中 → 中了就放特效 + 扣血 → 结束**。

---

## 三、关键图：为什么"特效"和"扣血"要分开？

这是整件事**最聪明**的地方。记住这个比喻：

```
🎆 命中特效（火花/音效）  =  舞台上的"烟火表演"
      → 全场观众都能看得到（所有客户端都能放）

🩸 扣血（真实伤害）      =  后台的"记分员算分"
      → 只有"裁判"（服务器）能改分数，防止玩家作弊
```

> **为什么分开？** 特效随便放没关系（好看就行），但"扣多少血"必须服务器说了算——不然玩家改一下自己电脑就能"无敌"了。
>
> 技术上：特效是 `Execute Gameplay Cue`（全客户端），伤害是 `Apply Gameplay Effect`（仅服务器 `Has Authority`）。

## 四、为什么非要"蓝图"？不能全写代码吗？

**能，但会很蠢。** 看对比：

```
❌ 全写代码：
   想做 10 把枪 → 程序员写 10 遍代码 → 每改一次要重新编译
   （像每演一场戏都要重新盖一个剧院）

✅ 用蓝图：
   程序员写好"开火这套动作"（1 次）
   策划复制一份 → 换个动画、换个伤害数 → 新枪就好了
   （像换个道具就能演新戏，剧院不用重建）
```

> **本质**：**程序员造"舞台和通用机关"，策划用"道具"搭出不同的戏。** 这就是分工。

## 五、一张总图（把三篇全串起来）

```
┌─────────────────────────────────────────────────┐
│  📜 C++ 基类（骨架/剧本模板）                      │
│  "每个技能都这样：本地预测、耗蓝、失败播提示、     │
│   和其他技能互斥"  —— 写一次，所有技能共用          │
└───────────────────┬─────────────────────────────┘
                    │ 留出"钩子"，让蓝图来填
                    ▼
┌─────────────────────────────────────────────────┐
│  🎬 蓝图 GA_Weapon_Fire（血肉/这场戏的演法）       │
│                                                   │
│   激活 → 瞄准+播动画 → 命中？                      │
│              ├ 中 → 放特效🎆(全客户端)             │
│              │     + 扣血🩸(仅服务器)              │
│              └ 空 → 结束                          │
└───────────────────┬─────────────────────────────┘
                    │ 用到的"道具"来自配置格子
                    ▼
┌─────────────────────────────────────────────────┐
│  📋 配置格子（道具清单，换枪就换这些）             │
│  • 开火动画 = 哪段动画                            │
│  • 伤害效果 = 打多少血                            │
│  • 命中特效 = 什么火花                            │
└─────────────────────────────────────────────────┘
```

## 六、记住这 3 句话就够了

1. **C++ 是骨架，蓝图是血肉** —— 通用规矩写 C++，具体演法画蓝图。
2. **开火 = 瞄准 + 动画 → 命中判断 → 特效（人人能放）+ 扣血（服务器算）**。
3. **特效和伤害分开** —— 特效图好看，伤害防作弊。

# 21 — 教学铁律：教学代码里的注释，一律写成中文

> **定位**：本文件规定教学代码里**注释的语言**。新对话开始教学前，除 00~20 外，**必须读本文件**。
>
> **一句话**：贴给用户的代码（`.h` / `.cpp` 等），**注释要写成中文**，不要照抄 Lyra 的英文注释。

---

## 一、这条铁律怎么来的（真实需求，2026-09-28）

教 P04 第 1 步（建 `TenkaichiInputConfig.h`）时，AI 一比一照抄了 Lyra 的代码，**连英文注释也一起抄了**：

```cpp
/**
 * FTenkaichiInputAction
 *
 *	Struct used to map a input action to a gameplay input tag.
 */
USTRUCT(BlueprintType)
struct FTenkaichiInputAction
{ ... };
```

用户当场提出：**"能不能把注释也改为中文。"**

**根因**：AI 把「一比一还原」理解成了「连注释都要逐字照抄」。但注释是给人看的说明文字，**不是代码逻辑本身**——用户是中文学习者，英文注释会增加理解负担。

---

## 二、核心规则

**教学代码里的注释，一律翻译成中文；代码本身（标识符、关键字、宏名、API 名）保持原样不动。**

| 部分 | 语言 | 说明 |
|------|------|------|
| **注释**（`//`、`/* */`、`/** */`） | **中文** | 解释性文字，翻译成人话 |
| **代码**（类名、变量、函数、宏、关键字） | 英文（原样） | 这是要一比一对应 Lyra 的部分，不能动 |
| **字符串字面量**（`UE_LOG` 里的提示等） | 中文可、英文也可 | 看语境，一般中文更友好 |

> 判断标准：**用户读注释能秒懂「这段在干嘛」，不用去啃英文**。

---

## 三、注释翻译的原则

1. **保留注释的结构**：Lyra 的 `/** ... */` 文档注释、`//` 行注释，**格式照旧**，只把内容换成中文。
2. **说人话**：不是机械直译，而是用大白话讲清「这段是干嘛的」。
3. **能留则留**：Lyra 的注释如果确实有价值（解释设计意图），翻译后保留；如果只是无意义的占位注释，翻译成简洁中文即可。

### 翻译示例

```cpp
/**
 * FTenkaichiInputAction
 *
 *	用于把「一个输入动作（InputAction）」映射到「一个 GameplayTag」的结构体。
 */
USTRUCT(BlueprintType)
struct FTenkaichiInputAction
{ ... };
```

```cpp
// 宿主使用的输入动作列表。这些输入动作映射到 GameplayTag，需要手动绑定。
UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Meta = (TitleProperty = "InputAction"))
TArray<FTenkaichiInputAction> NativeInputActions;
```

## 四、和「一比一还原」铁律的关系（澄清，不冲突）

- **01/14/15/17 号铁律**要求的是**代码逻辑、结构、命名、文件路径**一比一对应 Lyra——这些是「要还原的东西」。
- **注释**是**给人看的说明文字，不属于代码逻辑本身**，翻译成中文**不破坏**「一比一还原」。
- 一句话：**代码一比一还原，注释中文化**，两者各管各的。

---

## 五、对照表（做什么 / 不做什么）

| 场景 | ✅ 我做 | ❌ 我不做 |
|------|--------|----------|
| 贴教学代码 | 注释翻译成中文，代码原样 | 连英文注释一起照抄 |
| 还原 Lyra | 类名/结构/逻辑/路径一比一对应 | 因翻译注释而改代码逻辑 |
| 文档注释 `/** */` | 保留格式，内容换成中文 | 删掉注释 |

## 六、执行要求（贴代码前自检）

1. **扫注释**：这段代码里有哪些注释？都翻译成中文了吗？
2. **代码原样**：类名、函数名、宏、关键字有没有因翻译被误改？（不能改）
3. **配合其他铁律**：仍遵守 [01](./01_一比一还原Lyra_只教不写代码.md)（代码一比一还原）、[08](./08_教学md开头要先讲为什么再给代码.md)（注释也是「讲为什么」的一部分）。

---

## 七、一句话结论

**教学代码里的注释一律写成中文（说人话），代码本身（类名/函数/宏/关键字）一比一对应 Lyra 原样不动。注释是给人看的，翻译成中文不破坏「一比一还原」。**

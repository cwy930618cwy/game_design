---

## 一、为什么要单独深入角色系统

角色系统是 Lyra 所有功能的**交汇点**：

```
                    ┌──► GAS（技能/属性）
角色（Character）───┼──► 输入（Enhanced Input）
                    ├──► 相机（Camera Mode）
                    ├──► 队伍（Team）
                    └──► 初始化流程（InitState）
```

搞懂角色系统，就搞懂了 Lyra "一个对象如何把各种能力组合起来"。这也是你以后写任何角色相关功能（新武器、新技能、新移动方式）的入口。

## 二、Character/ 目录里有什么（真实结构）

```
Source/LyraGame/Character/
├── LyraPawn.cpp/h                  ← 基础 Pawn（能控制 + 队伍）
├── LyraCharacter.cpp/h             ← 人形角色（核心基类）
├── LyraCharacterMovementComponent  ← 角色移动组件（自定义移动）
├── LyraCharacterWithAbilities      ← 带技能的玩家角色（GA 容器）
├── LyraHealthComponent             ← 血量组件
├── LyraHeroComponent               ← 英雄组件（输入/相机绑定）
├── LyraPawnData                    ← 玩家数据（DataAsset）
└── LyraPawnExtensionComponent      ← 角色扩展组件（初始化中枢）
```

## 三、继承关系（先看骨架）

```
AModularPawn（引擎模块化 Pawn）
   └── ALyraPawn                     ← 加了"能控制 + 队伍"
         └── AModularCharacter（引擎模块化 Character）
               └── ALyraCharacter    ← 人形角色基类（4 接口 + 3 组件）
                     └── ALyraCharacterWithAbilities  ← 加上技能能力
                           └── 蓝图子类（具体玩家/敌人角色）
```

## 五、核心设计一句话（务必记住）

看源码注释（`LyraCharacter.h`）原文：

> "Responsible for sending events to pawn components. **New behavior should be added via pawn components when possible.**"
> "负责向 Pawn 组件发送事件。**新行为应尽可能通过 Pawn 组件添加。**"

这就是 Lyra 角色系统的灵魂：

```
❌ 传统：ACharacter { 移动+血量+技能+相机+背包+... }  ← 臃肿
✅ Lyra：ALyraCharacter 只当"骨架 + 事件分发"
          具体功能全拆成组件（Health/Camera/Hero/PawnExtension）
```

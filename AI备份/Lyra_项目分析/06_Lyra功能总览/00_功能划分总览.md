## 二、功能按"系统"划分（核心）

把这 24 个目录，按功能归成几大系统：

### ① 技能/战斗系统
| 目录 | 功能 |
|------|------|
| `AbilitySystem/` | GAS 技能（ASC/GA/GE/AttributeSet） |
| `Weapons/` | 武器系统 |
| `Feedback/` | 伤害反馈（数字/特效） |

### ② 角色系统
| 目录 | 功能 |
|------|------|
| `Character/` | 角色（Pawn/Character） |
| `Camera/` | 相机 |
| `Animation/` | 动画 |
| `Cosmetics/` | 换装/外观 |
| `Player/` | 玩家（Controller/State） |

### ③ 玩法/规则系统
| 目录 | 功能 |
|------|------|
| `GameModes/` | 游戏模式（Experience） |
| `Teams/` | 队伍系统 |
| `GameFeatures/` | 玩法模块 |

### ④ 物品/交互系统
| 目录 | 功能 |
|------|------|
| `Inventory/` | 背包/库存 |
| `Equipment/` | 装备 |
| `Interaction/` | 交互（拾取） |

### ⑤ 输入/UI 系统
| 目录 | 功能 |
|------|------|
| `Input/` | 输入（EnhancedInput + Tag） |
| `UI/` | UI（79 文件，最大） |
| `Messages/` | 消息路由 |

### ⑥ 系统/工具
| 目录 | 功能 |
|------|------|
| `System/` | 系统工具 |
| `Settings/` | 游戏设置 |
| `Audio/` | 音频 |
| `Physics/` | 物理 |
| `Hotfix/` | 热修复 |
| `Replays/` | 回放 |
| `Performance/` | 性能 |
| `Development/` | 开发工具 |
| `Tests/` | 测试 |

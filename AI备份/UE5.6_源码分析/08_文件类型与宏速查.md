# 08 - 文件类型与宏速查

> 快速查阅 UE5.6 源码中常见的文件类型和宏定义。

---

## 一、文件扩展名速查

### 1.1 C++ 源码

| 扩展名 | 含义 | 示例 |
|--------|------|------|
| `.h` | 头文件 | `LyraCharacter.h` |
| `.cpp` | 实现文件 | `LyraCharacter.cpp` |
| `.hpp` | C++ 头文件（第三方） | `std::vector` |
| `.inl` | 内联实现 | `TArray.inl` |
| `.ispc` | ISPC 向量程序 | `ChaosSolver.ispc` |
| `.cs` | C# 构建脚本 | `LyraGame.Build.cs` |

### 1.2 生成文件

| 扩展名 | 含义 | 生成者 |
|--------|------|--------|
| `.generated.h` | 反射代码 | UHT |
| `.obj` | 目标文件 | 编译器 |
| `.lib` | 静态库 | 链接器 |
| `.dll` | 动态库 | 链接器 |
| `.pdb` | 调试符号 | 编译器 |
| `.precompiled` | 预编译头 | UBT |

### 1.3 资产文件

| 扩展名 | 含义 |
|--------|------|
| `.uasset` | UE 资产 |
| `.umap` | 关卡地图 |
| `.uplugin` | 插件描述 |
| `.uproject` | 项目描述 |
| `.ini` | 配置文件 |
| `.usf` | 着色器文件 |
| `.ush` | 着色器头文件 |

### 1.4 文档与工具

| 扩展名 | 含义 |
|--------|------|
| `.tps` | 性能追踪标记 |
| `.udn` | 文档文件 |
| `.natvis` | VS 可视化器 |
| `.sln` | VS 解决方案 |
| `.vcxproj` | VS 项目 |

## 二、UCLASS/USTRUCT/UENUM 修饰符

### 2.1 UCLASS 常用

| 修饰符 | 说明 |
|--------|------|
| `Blueprintable` | 可在蓝图中派生 |
| `BlueprintType` | 可作为蓝图变量类型 |
| `Abstract` | 抽象类（不能实例化） |
| `Const` | 常量类 |
| `DefaultToInstanced` | 默认实例化 |
| `HideCategories=(...)` | 隐藏分类 |
| `ShowCategories=(...)` | 显示分类 |
| `ClassGroup=(...)` | 类分组 |
| `Within=XXX` | 必须在某类内部 |

### 2.2 USTRUCT 常用

| 修饰符 | 说明 |
|--------|------|
| `BlueprintType` | 可作为蓝图变量类型 |
| `Blueprintable` | 可在蓝图中派生 |
| `Atomic` | 原子操作 |
| `WithNoDestructor` | 无析构函数 |
| `WithCopyFromList` | 列表复制 |

### 2.3 UENUM 常用

| 修饰符 | 说明 |
|--------|------|
| `BlueprintType` | 可作为蓝图变量类型 |
| `Bitflags` | 位标志 |
| `Flags` | 枚举标志 |
| `Hidden` | 隐藏 |
| `NotBlueprintType` | 不能作为蓝图类型 |

## 三、UPROPERTY 修饰符大全

### 3.1 可见性

| 修饰符 | 说明 |
|--------|------|
| `EditAnywhere` | 任何地方可编辑 |
| `EditDefaultsOnly` | 仅默认值可编辑 |
| `EditInstanceOnly` | 仅实例可编辑 |
| `VisibleAnywhere` | 可见但不可编辑 |
| `VisibleDefaultsOnly` | 仅默认值可见 |
| `VisibleInstanceOnly` | 仅实例可见 |
| `BlueprintReadOnly` | 蓝图只读 |
| `BlueprintReadWrite` | 蓝图读写 |
| `Transient` | 不序列化 |
| `SaveGame` | 存档 |

### 3.2 网络

| 修饰符 | 说明 |
|--------|------|
| `Replicated` | 复制 |
| `ReplicatedUsing=OnRep_Xxx` | 复制 + 回调 |
| `RepNotifyCondition=COND_Xxx` | 复制条件 |
| `DOREPLIFETIME` | 宏声明复制 |
| `DOREPLIFETIME_CONDITION` | 条件复制 |

### 3.3 容器

| 修饰符 | 说明 |
|--------|------|
| `AllowPrivateAccess=true` | 允许私有访问 |
| `ArrayClamp=(...)` | 数组大小限制 |
| `SetNativeBreakFunc` | 原生断点函数 |
| `SetNativeMakeFunc` | 原生构造函数 |

### 3.4 元数据 (meta)

| 修饰符 | 说明 |
|--------|------|
| `meta=(DisplayName="...")` | 显示名称 |
| `meta=(ToolTip="...")` | 提示文本 |
| `meta=(Category="...")` | 分类 |
| `meta=(ClampMin="0")` | 最小值 |
| `meta=(ClampMax="100")` | 最大值 |
| `meta=(UIMin="0")` | UI 最小值 |
| `meta=(UIMax="100")` | UI 最大值 |
| `meta=(ForceUnits="cm")` | 强制单位 |
| `meta=(AllowedClasses="...")` | 允许的类 |
| `meta=(DisallowedClasses="...")` | 禁止的类 |
| `meta=(MustApplyChanges)` | 必须应用更改 |
| `meta=(DeprecatedProperty)` | 已废弃 |

## 五、常用宏

### 5.1 日志

```cpp
DECLARE_LOG_CATEGORY_EXTERN(LogMyClass, Log, All);
DEFINE_LOG_CATEGORY(LogMyClass);

UE_LOG(LogMyClass, Log, TEXT("Info message"));
UE_LOG(LogMyClass, Warning, TEXT("Warning"));
UE_LOG(LogMyClass, Error, TEXT("Error"));
UE_LOG(LogMyClass, Verbose, TEXT("Verbose"));
```

### 5.2 检查

```cpp
check(expr);              // 断言（Shipping 移除）
checkf(expr, TEXT("msg")); // 带消息的断言
ensure(expr);             // 确保（Shipping 保留）
ensureMsgf(expr, TEXT("msg"));
verify(expr);             // 验证（Shipping 也执行）
verifyf(expr, TEXT("msg"));
```

### 5.3 性能

```cpp
TRACE_CPUPROFILER_EVENT_SCOPE(FunctionName);
TRACE_CPUPROFILER_EVENT_SCOPE_TEXT(TEXT("Name"));
SCOPE_CYCLE_COUNTER(STAT_XXX);
CSV_SCOPED_TIMING_STAT_EXCLUSIVE(XXX);
```

### 5.4 内存

```cpp
TSharedPtr<T> MakeShared<T>();
TUniquePtr<T> MakeUnique<T>();
TWeakObjectPtr<T> WeakThis(this);
```

### 5.5 平台

```cpp
#if PLATFORM_WINDOWS
    // Windows 特定代码
#elif PLATFORM_LINUX
    // Linux 特定代码
#elif PLATFORM_MAC
    // Mac 特定代码
#endif

#if WITH_EDITOR
    // 仅编辑器
#endif

#if UE_BUILD_SHIPPING
    // 仅 Shipping
#endif

#if !UE_BUILD_SHIPPING
    // 非 Shipping（Debug/Development）
#endif
```

### 5.6 其他

```cpp
FORCEINLINE              // 强制内联
virtual                  // 虚函数
override                 // 重写基类函数
GENERATED_BODY()         // 生成代码体
GENERATED_UCLASS_BODY()  // 旧式生成
this->GetWorld()->GetTimerManager().SetTimer(...);  // 定时器
FTimerHandle TimerHandle;
```

## 六、命名规范

### 6.1 类型前缀

| 前缀 | 类型 | 示例 |
|------|------|------|
| `A` | Actor | `ALyraCharacter` |
| `U` | UObject | `ULyraHealthComponent` |
| `F` | 普通 C++ 类/结构体 | `FVector`, `FString` |
| `E` | 枚举 | `ELyraGameMode` |
| `I` | 接口 | `ILyraInteractable` |
| `T` | 模板类 | `TArray`, `TMap` |
| `S` | Slate 控件 | `SButton`, `STextBlock` |

### 6.2 变量前缀

| 前缀 | 类型 | 示例 |
|------|------|------|
| `b` | bool | `bIsAlive` |
| `f` | float | `fHealth` |
| `d` | double | `dTime` |
| `i` | int32 | `iCount` |
| `ui` | uint32 | `uiScore` |
| `Int64` | int64 | `Int64BigNumber` |
| `UInt64` | uint64 | `UInt64Timestamp` |
| `Str` | FString | `StrName` |
| `Name` | FName | `NameID` |
| `Text` | FText | `TextDescription` |
| `Obj` | UObject* | `ObjTarget` |
| `Actor` | AActor* | `ActorOwner` |
| `Comp` | UActorComponent* | `CompMovement` |
| `Ptr` | 指针 | `PtrData` |
| `Weak` | TWeakObjectPtr | `WeakThis` |
| `Shared` | TSharedPtr | `SharedData` |

### 6.3 函数命名

| 前缀 | 用途 | 示例 |
|------|------|------|
| `Get` | 获取值 | `GetHealth()` |
| `Set` | 设置值 | `SetHealth()` |
| `Is` | 布尔查询 | `IsAlive()` |
| `Has` | 拥有查询 | `HasWeapon()` |
| `Can` | 能力查询 | `CanJump()` |
| `Should` | 应该查询 | `ShouldTick()` |
| `On` | 事件回调 | `OnDeath()` |
| `Begin` | 开始 | `BeginPlay()` |
| `End` | 结束 | `EndPlay()` |
| `Tick` | 每帧 | `Tick()` |
| `Initialize` | 初始化 | `Initialize()` |
| `Cleanup` | 清理 | `Cleanup()` |

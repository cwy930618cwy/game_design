## 一、ReplicationGraph — 网络复制优化

### 1.1 传统复制的问题

UE 默认的网络复制会**向所有客户端广播所有 Actor**，导致：
- 带宽浪费（大量无关 Actor 被复制）
- 延迟增加（数据包过大）
- 服务器负载高

### 1.2 ReplicationGraph 的解决方案

**基于空间的分组复制**：

```
┌─────────────────────────────────────┐
│           游戏世界                   │
├─────────────────────────────────────┤
│  ┌─────────┐  ┌─────────┐          │
│  │ Grid 1  │  │ Grid 2  │          │
│  │ PlayerA │  │ PlayerB │          │
│  │ 只看到  │  │ 只看到  │          │
│  │ 附近Actor│  │ 附近Actor│          │
│  └─────────┘  └─────────┘          │
└─────────────────────────────────────┘
```

### 1.3 核心概念

| 类 | 作用 |
|----|------|
| `UReplicationGraph` | 复制图基类 |
| `ULyraReplicationGraph` | Lyra 的实现 |
| `UNetReplicationGraphConnection` | 连接管理 |
| `FGlobalActorReplicationInfo` | Actor 复制信息 |

### 1.4 复制策略

| 策略 | 说明 |
|------|------|
| **Spatialize** | 基于距离的空间化（只复制附近的） |
| **AlwaysRelevant** | 始终相关（如 GameMode） |
| **TeamOnly** | 仅队伍可见 |
| **Dormant** | 休眠（不变化时不复制） |

## 二、Significance Manager — 重要性管理

### 2.1 什么是 Significance？

**重要性** = 对象对玩家的相对重要程度，用于：
- LOD 切换（远处用低精度模型）
- Tick 频率调整（远处少 Tick）
- 特效降级（远处简化粒子）

### 2.2 核心概念

| 类 | 作用 |
|----|------|
| `USignificanceManager` | 管理器 |
| `FManagedObjectInfo` | 管理对象信息 |
| `ESignificanceLevel` | 重要性等级 |

### 2.3 使用方式

```cpp
// 注册对象
SignificanceManager->RegisterObject(this, SignificanceFunction);

// 定义重要性计算函数
float MySignificanceFunction(const FTransform& Viewpoint)
{
    float Distance = FVector::Dist(GetActorLocation(), Viewpoint.GetLocation());
    return 1.0f / (1.0f + Distance);  // 越远越低
}

// 根据重要性调整行为
void OnSignificanceChanged(ESignificanceLevel NewLevel)
{
    switch (NewLevel)
    {
        case ESignificanceLevel::High:   // 高精度
        case ESignificanceLevel::Medium: // 中精度
        case ESignificanceLevel::Low:    // 低精度
    }
}
```

## 三、Lyra 中的实际应用

### 3.1 ReplicationGraph 配置

```cpp
// ULyraReplicationGraph::InitGlobalActorClassSettings
void ULyraReplicationGraph::InitGlobalActorClassSettings()
{
    // GameMode 始终相关
    GlobalActorReplicationInfoMap.Add(ALyraGameMode::StaticClass(), 
        FGlobalActorReplicationInfo::AlwaysRelevant());
    
    // 玩家 Pawn 基于空间化
    GlobalActorReplicationInfoMap.Add(ALyraCharacter::StaticClass(), 
        FGlobalActorReplicationInfo::Spatialize());
}
```

### 3.2 Significance 在 Lyra 中的用途

- **角色 LOD** — 远处玩家用低精度骨骼
- **特效降级** — 远处爆炸简化粒子
- **Tick 优化** — 远处 AI 降低更新频率

## 五、性能优化最佳实践

### 5.1 网络优化

| 优化点 | 方法 |
|--------|------|
| 减少复制 Actor 数量 | ReplicationGraph 空间化 |
| 减少复制频率 | Dormancy 休眠 |
| 压缩数据 | NetSerializer 自定义序列化 |
| 预测 | GAS 客户端预测 |

### 5.2 性能优化

| 优化点 | 方法 |
|--------|------|
| 减少 Tick | Significance 调整频率 |
| LOD | 基于距离切换精度 |
| 池化 | 对象池复用 |
| 异步 | 异步加载资产 |

| 目录 | 作用 | 规模 |

## 三、Engine/ 目录详解

```
Engine/
├── Binaries/          ← 编译产物（DLL/PDB/Python 脚本）
├── Build/             ← 构建脚本（.bat/.sh/.plist）
├── Config/            ← 引擎默认配置 (.ini)
├── Content/           ← 引擎内置资产（材质/UI/音效）
├── DerivedDataCache/  ← DDC 着色器缓存
├── Documentation/     ← 离线文档 (udn)
├── Extras/            ← 附加工具（Python/SDK）
├── Intermediate/      ← 中间产物（.obj/.lib/.precompiled）
├── Platforms/         ← 各平台特定代码（Win/Mac/Linux/Android/iOS）
├── Plugins/           ← 🔥 引擎级插件（100+ 个）
├── Programs/          ← 独立程序（如 UnrealLightmass）
├── Saved/             ← 运行时生成数据
├── Shaders/           ← 着色器源码 (.usf/.ush)
└── Source/            ← 🔥🔥🔥 C++ 源码（核心！）
```

### 关键目录说明

#### 📦 Binaries/（13,985 文件）
- `Win64/` — Windows 64 位 DLL
- `ThirdParty/` — 第三方库（Python 2.7/3.x 等）
- 你不需要改这里，但调试时会用到 PDB 符号文件

#### ⚙️ Config/（81 文件）
- `DefaultEngine.ini` — 引擎默认设置
- `DefaultGame.ini` — 游戏默认设置
- `Base*.ini` — 各子系统基础配置
- **学习点**：了解渲染/音频/网络的基础配置项

#### 🎨 Content/（28,465 文件）
- 引擎内置材质、UI 控件、音效、粒子
- `EngineMaterials/` — 默认材质球
- `EngineSounds/` — 编辑器音效
- `Slate/` — 编辑器 UI 皮肤

#### 🧩 Plugins/（94,579 文件）⭐
**这是最大的部分**，包含 100+ 个官方插件，详见 [02_插件体系](./02_插件体系.md)

#### 📝 Source/（63,078 文件）⭐⭐⭐
**学习的核心**，详见 [03_源码目录全景](./03_源码目录全景.md)

## 四、Source/ 顶层结构（6 大块）

```
Engine/Source/
├── Runtime/           ← 运行时模块（游戏运行必需）
├── Editor/            ← 编辑器模块（只在编辑器下编译）
├── Developer/         ← 开发工具模块（打包/分析/调试）
├── Programs/          ← 独立可执行程序源码
├── ThirdParty/        ← 第三方库源码（protobuf/openssl 等）
├── UnrealEditor.Target.cs   ← 编辑器 Target
└── UnrealGame.Target.cs     ← 游戏 Target
```

### 四大模块分类对比

| 类型 | 何时编译 | 是否打进游戏包 | 典型用途 |
|------|---------|---------------|---------|
| **Runtime** | 总是 | ✅ 是 | 游戏逻辑/渲染/物理/音频 |
| **Editor** | 仅编辑器 | ❌ 否 | 编辑器 UI/资产工具 |
| **Developer** | 开发时 | ❌ 否 | 打包/性能分析/调试 |
| **ThirdParty** | 按需 | 视情况 | 外部依赖库 |

## 五、文件类型速查

在源码中你会遇到这些扩展名：

| 扩展名 | 含义 | 数量 |
|--------|------|------|
| `.h` | C++ 头文件 | 80,337 |
| `.cpp` | C++ 实现文件 | 32,389 |
| `.hpp` | C++ 头文件（第三方为主） | 17,956 |
| `.cs` | C# 构建脚本（UBT/UHT 用） | 2,378 |
| `.uasset` | UE 资产文件 | 14,577 |
| `.usf` / `.ush` | 着色器源码 | ~1,100 |
| `.inl` | 内联实现文件 | ~150 |
| `.tps` | 性能追踪标记 | ~200 |

## 六、学习建议

1. **先看全景**：理解 `Engine/` → `Source/` → `Runtime|Editor|Developer` 三层结构
2. **聚焦 Runtime**：游戏逻辑相关的全在这里
3. **善用 IDE**：VS/Rider 的"解决方案资源管理器"比文件浏览器好用
4. **搜索优先**：用 `Ctrl+Shift+F` 全局搜索类名/函数名

## ① `ATTRIBUTE_ACCESSORS`（Lyra 的便利壳）

**文件**：`LyraAttributeSet.h:29-33`

```cpp
#define ATTRIBUTE_ACCESSORS(ClassName, PropertyName) \
	GAMEPLAYATTRIBUTE_PROPERTY_GETTER(ClassName, PropertyName) \
	GAMEPLAYATTRIBUTE_VALUE_GETTER(PropertyName) \
	GAMEPLAYATTRIBUTE_VALUE_SETTER(PropertyName) \
	GAMEPLAYATTRIBUTE_VALUE_INITTER(PropertyName)
```

**它自己什么都不做**，只是把下面 4 个 GAS 宏一次性全调出来。就是个"一键安装器"。

---

## ② `GAMEPLAYATTRIBUTE_PROPERTY_GETTER`（GAS 引擎）

**文件**：`AttributeSet.h:430-435`

```cpp
#define GAMEPLAYATTRIBUTE_PROPERTY_GETTER(ClassName, PropertyName) \
	static FGameplayAttribute Get##PropertyName##Attribute() \
	{ \
		static FProperty* Prop = FindFieldChecked<FProperty>(ClassName::StaticClass(), GET_MEMBER_NAME_CHECKED(ClassName, PropertyName)); \
		return Prop; \
	}
```

**作用**：生成"拿这个属性的反射句柄"的函数。
- 生成函数名：`Get##PropertyName##Attribute()`（`##` 是拼接符号）
- 比如属性叫 `Health` → 生成 `GetHealthAttribute()`
- 里面用反射 `FindFieldChecked` 找到 `Health` 这个成员，返回它的 `FGameplayAttribute` 句柄
- **GAS 靠这个句柄知道"我要改的是哪个属性"**（改血、加 buff 都要先拿到句柄）

## ③ `GAMEPLAYATTRIBUTE_VALUE_GETTER`（GAS 引擎）

**文件**：`AttributeSet.h:437-441`

```cpp
#define GAMEPLAYATTRIBUTE_VALUE_GETTER(PropertyName) \
	FORCEINLINE float Get##PropertyName() const \
	{ \
		return PropertyName.GetCurrentValue(); \
	}
```

**作用**：生成"读当前值"的函数。
- 属性叫 `Health` → 生成 `float GetHealth() const`
- 里面调 `Health.GetCurrentValue()` 返回当前血量

## ④ `GAMEPLAYATTRIBUTE_VALUE_SETTER`（GAS 引擎）

**文件**：`AttributeSet.h:443-451`

```cpp
#define GAMEPLAYATTRIBUTE_VALUE_SETTER(PropertyName) \
	FORCEINLINE void Set##PropertyName(float NewVal) \
	{ \
		UAbilitySystemComponent* AbilityComp = GetOwningAbilitySystemComponent(); \
		if (ensure(AbilityComp)) \
		{ \
			AbilityComp->SetNumericAttributeBase(Get##PropertyName##Attribute(), NewVal); \
		}; \
	}
```

**作用**：生成"改值"的函数（**走 ASC，不直接改**）。
- 属性叫 `Health` → 生成 `void SetHealth(float NewVal)`
- 关键：**它不直接 `Health = NewVal`**，而是：
  1. `GetOwningAbilitySystemComponent()` 拿到技能总管（ASC）
  2. `AbilityComp->SetNumericAttributeBase(GetHealthAttribute(), NewVal)` 通过 ASC 改
- **这就是 GAS 铁律"改属性必须走 ASC"的体现**——`Set` 内部自动帮你走 ASC，你不用自己写。

---

## ⑤ `GAMEPLAYATTRIBUTE_VALUE_INITTER`（GAS 引擎）

**文件**：`AttributeSet.h:453-458`

```cpp
#define GAMEPLAYATTRIBUTE_VALUE_INITTER(PropertyName) \
	FORCEINLINE void Init##PropertyName(float NewVal) \
	{ \
		PropertyName.SetBaseValue(NewVal); \
		PropertyName.SetCurrentValue(NewVal); \
	}
```

**作用**：生成"初始化值"的函数（构造时设初值用）。
- 属性叫 `Health` → 生成 `void InitHealth(float NewVal)`
- 里面把**基础值**和**当前值**都设成 `NewVal`
- 只在"出生设初值"时用（构造函数里 `InitHealth(100.0f)`）

## 展开示例：`ATTRIBUTE_ACCESSORS(UTenkaichiHealthSet, Health)` 会变成啥

在血量集 `.h` 里写一行：

```cpp
ATTRIBUTE_ACCESSORS(UTenkaichiHealthSet, Health)
```

**预处理后**（4 个宏全部展开）等价于：

```cpp
// 来自 ② PROPERTY_GETTER
static FGameplayAttribute GetHealthAttribute()
{
	static FProperty* Prop = FindFieldChecked<FProperty>(UTenkaichiHealthSet::StaticClass(), GET_MEMBER_NAME_CHECKED(UTenkaichiHealthSet, Health));
	return Prop;
}

// 来自 ③ VALUE_GETTER
FORCEINLINE float GetHealth() const
{
	return Health.GetCurrentValue();
}

// 来自 ④ VALUE_SETTER
FORCEINLINE void SetHealth(float NewVal)
{
	UAbilitySystemComponent* AbilityComp = GetOwningAbilitySystemComponent();
	if (ensure(AbilityComp))
	{
		AbilityComp->SetNumericAttributeBase(GetHealthAttribute(), NewVal);
	}
}

// 来自 ⑤ VALUE_INITTER
FORCEINLINE void InitHealth(float NewVal)
{
	Health.SetBaseValue(NewVal);
	Health.SetCurrentValue(NewVal);
}
```

**一行宏 = 4 个函数**（拿句柄 / 读 / 写 / 初始化）。这就是它存在的意义：**省去每个属性集手写这 4 个重复函数**。

## 剧场故事（回扣人物谱）

血型档案卡（属性集）上要能"查血、调血、初始登记"。GAS 引擎给了 4 个**标准操作按钮**（4 个宏）：

| 按钮（宏） | 干的事 |
|-----------|--------|
| `PROPERTY_GETTER` | "这卡上血量那一栏在哪"（找句柄） |
| `VALUE_GETTER` | "读一下当前血量" |
| `VALUE_SETTER` | "调血量"（但必须通过技能总管，不能私自改） |
| `VALUE_INITTER` | "出生登记，初始血量写 100" |

Lyra 嫌每次装这 4 个按钮太麻烦，于是做了个**一键安装器** `ATTRIBUTE_ACCESSORS`——按一个钮，4 个按钮全装上。

> 类比：GAS 是"零件厂"，生产 4 个标准按钮；Lyra 是"总装线"，做了个一键把 4 个按钮装到档案卡上的夹具。你（血量集）只要说"给我装一套"（`ATTRIBUTE_ACCESSORS`），4 个按钮自动到位。

---

## 一句话总结

- **`ATTRIBUTE_ACCESSORS`**：Lyra 的便利壳，文件 `LyraAttributeSet.h:29`。
- **另外 4 个 `GAMEPLAYATTRIBUTE_*`**：GAS 引擎的真货，文件 `AttributeSet.h:430-458`。
- **关系**：便利壳里包的就是 GAS 的 4 个宏。一行 `ATTRIBUTE_ACCESSORS` 展开 = 4 个函数（拿句柄/读/写/初始化）。

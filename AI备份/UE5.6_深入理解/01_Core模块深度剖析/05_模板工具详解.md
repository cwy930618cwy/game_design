# 05 — 模板工具详解（Templates/）

> **定位**：`Core/Public/Templates/` 是 Core 里放"模板类和模板工具"的目录。它不是一个单一的东西，而是一**整柜 C++ 模板工具**。
>
> **一句话**：`Templates/` 里装的是 **T 开头的通用模板工具**——智能指针、类型判断、排序、移动语义等。你其实已经在用（TSharedPtr 就在这），只是没意识到它们是同一个目录的。
>
> **文件**：`Engine/Source/Runtime/Core/Public/Templates/`

---

## 一、这个目录到底是什么（先消除神秘感）

回到 `01_Core模块深度剖析.md` 的目录结构：

```
Runtime/Core/Public/
├── Containers/          ← 容器：TArray、TMap、TSet、FString
├── Math/                ← 数学：FVector、FRotator、FMath
├── Delegates/           ← 委托：单播/多播/动态委托
├── Templates/           ← ★ 模板工具（这篇）
├── HAL/                 ← 硬件抽象层
└── ...
```

**`Templates/` 是 Core 的一个子目录**，专门放"**模板类（带 T 前缀的工具）**"。它不是指 C++ 的"模板语法"，而是**"这一柜子里全是通用的模板工具"**。

> 关键：你之前学的 `TSharedPtr`、`TUniquePtr`、`TWeakPtr`、`MakeShared` 的源码，**就在这个 `Templates/` 目录里**（`SharedPointer.h`）！你已经用过它了，只是没意识到它属于这里。

---

## 二、目录里装了什么（四大类）

```
Core/Public/Templates/
├── 智能指针：SharedPointer.h、SharedPointerInternals.h
│            （TSharedPtr / TWeakPtr / TUniquePtr / MakeShared）
├── 类型特征：TypeTraits.h、AreTypesEqual.h...
│            （编译期类型判断）
├── 移动语义：Move.h、UnrealTemplate.h、Function.h...
│            （MoveTemp / 完美转发 / 元组）
└── 通用算法：Sorting.h、Invoke.h、Tuple.h...
              （排序 / 调用转发 / 元组）
```

| 类别 | 代表文件 | 作用 |
|------|---------|------|
| **智能指针** | `SharedPointer.h` | 你已学的 TSharedPtr 等 |
| **类型特征** | `TypeTraits.h` | 编译期判断类型（是不是指针？是不是同类型？） |
| **移动语义** | `Move.h` | `MoveTemp` 移动对象，避免拷贝开销 |
| **通用算法** | `Sorting.h` | 排序、二分查找 |
| **函数/元组** | `Function.h` / `Tuple.h` | 函数包装器、元组 |

## 三、四大类逐个讲（配具体场景）

### 3.1 类型特征（TypeTraits）—— 编译期类型判断

在**编译的时候**就知道"这个类型是啥"，用来写通用代码。

```cpp
// 判断 T 是不是指针类型
TIsPointer_V<TArray<int>>   // false（TArray 不是指针）
TIsPointer_V<int*>          // true（int* 是指针）

// 判断两个类型是否相同
TIsSame_V<int, int>         // true
TIsSame_V<int, float>       // false
```

**具体场景**：写一个"既能接普通值、又能接指针"的通用函数，编译期判断类型决定走哪条逻辑：

```cpp
// 编译期判断：如果是指针就解引用，否则直接用
template<typename T>
void LogValue(T&& Val) {
    if constexpr (TIsPointer_V<T>) {
        UE_LOG(LogTemp, Log, TEXT("值: %p"), Val);       // 指针
    } else {
        UE_LOG(LogTemp, Log, TEXT("值: %s"), *Val.ToString());  // 普通值
    }
}
```

**用处**：这些是写**通用模板库**时才需要的。日常游戏逻辑**基本用不到**——了解有这个东西即可。

### 3.2 移动语义（Move）—— MoveTemp 避免拷贝

`MoveTemp`（等价于 `std::move`）把对象**"移动"而不是"拷贝"**，避免复制大数据的开销。

```cpp
// 拷贝：把整个数组复制一份（大数据，慢）
TArray<int> B = A;

// 移动：把 A 的数据"搬"给 B，A 变空（快）
TArray<int> B = MoveTemp(A);
// 之后 A 为空，数据归 B 所有
```

**具体场景**：把一个大容器从函数返回 / 传给另一个系统，用 MoveTemp 避免整份复制：

```cpp
TArray<FItem> BuildInventory() {
    TArray<FItem> Items;
    Items.Add(...);  // 装很多物品
    return MoveTemp(Items);   // 移动返回，不复制整份
}
```

**用处**：写**高性能代码**时常用，日常小数据无所谓。记住"大数据转移用 MoveTemp 更快"即可。

### 3.3 排序（Sorting）—— 排序和查找

```cpp
TArray<int> Arr = {3, 1, 2};
Algo::Sort(Arr);            // 排序 → {1, 2, 3}
Algo::Sort(Arr, [](int A, int B) { return A > B; });  // 降序

// 二分查找（要求已排序）
int32 Idx = Algo::BinarySearch(Arr, 2);   // 找到 2 的位置
```

**具体场景**：排行榜按分数排序、背包按稀有度排序：

```cpp
// 按稀有度降序排背包物品
Algo::Sort(Inventory, [](const FItem& A, const FItem& B) {
    return A.Rarity > B.Rarity;   // 稀有度高的在前
});
```

### 3.4 函数包装器 / 元组

```cpp
// TFunction：类似 std::function，存任意可调用对象
TFunction<int32(int32)> Square = [](int32 X) { return X * X; };
Square(4);   // 16

// 元组：把不同类型打包
TTuple<int32, FString, float> Data = MakeTuple(42, TEXT("Hi"), 1.5f);
Get<0>(Data);   // 42
```

**具体场景**：TFunction 常用来做回调存储，元组用来临时打包多个返回值。

## 四、和之前学的对应（重要！）

你可能会想："这些我好像没见过？" —— 但其实你**一直在用这个目录里的东西**：

| 你之前学的 | 它就在 Templates/ |
|-----------|:---:|
| `TSharedPtr` / `TWeakPtr` / `TUniquePtr` | ✅ `SharedPointer.h` |
| `MakeShared` | ✅ `SharedPointer.h` |
| `auto` / 模板类型推断 | ✅ `TypeTraits.h` |
| `TArray` 的 `Sort` | ✅ `Sorting.h` |

**所以这篇不是学"新东西"，而是"把那些 T 开头的工具，归拢到一个目录下看"**。Templates/ 就是"通用模板工具的家"。

## 五、日常开发要学吗？—— 分轻重

| 工具 | 日常用得勤吗 | 建议 |
|------|:---:|------|
| `MoveTemp` | 偶尔（大数据转移） | **了解一下**，看代码认识 |
| `Algo::Sort` | 常用 | **记住会排** |
| `TFunction` | 常见（回调） | 认识即可 |
| `TypeTraits` / `TIsPointer` | 很少 | **遇到再看**，不用学 |
| `Tuple` | 很少 | 认识即可 |

**结论**：`Templates/` 里大部分工具，**日常游戏逻辑用不到**。你真正需要的是：
1. 知道它是什么（模板工具的家）
2. 认识 `MoveTemp`、`Algo::Sort` 这两个常用的
3. 其余（TypeTraits、Tuple）**遇到再看**，不用主动学

## 六、总结速查

```
Templates/ = Core 里"模板工具"的目录
├── 智能指针：TSharedPtr/TWeakPtr/TUniquePtr（已学）
├── 类型特征：TIsPointer/TIsSame（编译期判断，少用）
├── 移动语义：MoveTemp（大数据转移用，快）
├── 排序：   Algo::Sort/BinarySearch（常用）
└── 函数/元组：TFunction/TTuple（回调/打包，认识即可）

日常记住：MoveTemp 和 Algo::Sort 就够了
其余：遇到再看，不用主动学
```

**一句话**：`Templates/` 是"T 开头通用模板工具的家"，你之前学的智能指针就在里面。日常只需记住 `MoveTemp`（移动不拷贝）和 `Algo::Sort`（排序），其他都是"遇到再看"的进阶货。

## 七、什么时候深入？

- **现在**：认识 `MoveTemp`、`Algo::Sort`，知道 Templates/ 是啥即可
- **写通用工具库/插件**时：再研究 TypeTraits、Function、完美转发
- **性能优化**时：深入研究 MoveTemp、移动语义

> 和内存分配一样：**先会用常见的（MoveTemp、Sort），再深入冷门的（TypeTraits、Tuple）**。

> **定位**：Core 里一批"**进阶/工具/实验**"性质的目录。**日常开发几乎不用碰**，但知道它们是干嘛的，读引擎代码时不懵。

> **一句话**：这批目录装的是 **文件缓存、实验代码、第三方分析工具、内存检查、事务内存、资产虚拟化、单元测试**——都是进阶/工具类，**了解即可，不用学**。

## 二、逐个认识（配场景）

### 2.1 FileCache/ —— 文件缓存

缓存文件读取结果，避免反复读磁盘。

```cpp
// 把文件内容缓存起来，下次直接读缓存，更快
// 一般你不需要直接用，引擎内部在用
```

**场景**：引擎加载大量小文件（配置、材质参数）时，用缓存避免反复读盘。**你一般不直接碰。**

### 2.2 Experimental/ —— 实验性代码

放"还不稳定、正在试验"的功能，如 `ConcurrentLinearAllocator`（并发线性分配器）。

```cpp
// Experimental 里的东西：
// 1. 可能不稳定、API 会变
// 2. 生产环境慎用
```

**场景**：你看到某个类在 `Experimental/` 下，就知道它**还不成熟**，**生产项目慎用**。**了解一下即可。**

### 2.3 FramePro/ MemPro/ —— 第三方性能分析工具

接入了两个**第三方商业性能分析工具**（FramePro、MemPro），用于深入分析帧耗时和内存。

**场景**：专业团队用 FramePro 分析每帧每个函数的耗时。**普通开发用不到**（用免费的 Unreal Insights 就够）。

### 2.4 Sanitizer/ —— 内存检查（ASan/UBSan）

接入**内存消毒器**（ASan = 地址消毒器，UBSan = 未定义行为消毒器），在调试时检查内存错误（越界、悬垂）。

```cpp
// 调试模式开启 ASan，能抓出内存越界/悬垂等 bug
// 代价：运行变慢，只在开发/测试用
```

**场景**：项目崩溃怀疑内存问题，用 Sanitizer 找出具体哪行越界。**进阶排错工具。**

### 2.5 AutoRTFM/ —— 事务内存（实验性）

**事务内存**：一种实验性的原子内存系统，让多线程访问共享数据更安全。

```
事务内存 = 把一组内存操作当成"一个事务"
  要么全部成功，要么全部回滚
  类似数据库事务，用于多线程
```

**场景**：实验性的多线程内存同步方案。**非常前沿，一般用不到。**

### 2.6 Virtualization/ —— 资产虚拟化

**资产虚拟化**：让超大资产（贴图/网格）"按需加载"，不占满内存。配合 UE5 大世界（World Partition）。

```
资产虚拟化：
  不把巨大资产全加载进内存
  用到哪块，加载哪块
  省内存，适合超大项目
```

**场景**：大世界项目避免一次性加载海量资产导致爆内存。**了解即可。**

### 2.7 Tests/ —— 单元测试基础

Core 自带的单元测试基础框架，用于验证代码正确性。

```cpp
// 写测试：验证某个函数行为对不对
// 自动化回归，防止改坏
```

**场景**：给核心代码写测试，改完自动验证没改坏。**进阶工程化。**

4. 其余遇到再说

# 10 — 算法库（Algo/）与音频（Audio/）

> **定位**：Core 里 `Algo/`（算法库，日常常用）和 `Audio/`（音频基础类型，一般不用碰）。
>
> **一句话**：`Algo/` = 操作容器的**算法工具**（排序、查找、遍历、变换），类似 C++ 标准库的 `<algorithm>`；`Audio/` = 音频相关的**基础数据结构**，日常开发很少直接碰。
>
> **文件**：`Core/Public/Algo/`（44 个文件）、`Core/Public/Audio/`

---

## 一、Algo/ 是什么（先搞懂）

`Algo/` 是 UE 的**算法库**，专门提供"操作容器（TArray/TMap 等）"的函数。你可以把它理解成"**C++ 标准库 `<algorithm>` 的 UE 版**"。

| | C++ 标准库 | UE 的 Algo/ |
|---|---|---|
| 排序 | `std::sort` | `Algo::Sort` |
| 查找 | `std::find` | `Algo::Find` / `Algo::BinarySearch` |
| 计数 | `std::count` | `Algo::Count` |
| 变换 | `std::transform` | `Algo::Transform` |

**核心价值**：用 `Algo::` 开头，直接操作 UE 容器，不用手写循环。**日常开发很常用**，尤其是排序。

---

## 二、Algo/ 里最常用的算法（配具体场景）

### 2.1 排序（Algo::Sort）—— 最常用

```cpp
TArray<int32> Scores = {30, 10, 20};
Algo::Sort(Scores);              // 升序 → {10, 20, 30}

// 自定义排序（降序）
Algo::Sort(Scores, [](int32 A, int32 B) { return A > B; });  // {30, 20, 10}
```

**具体场景：排行榜按分数排序**

```cpp
// 玩家按分数从高到低排
Algo::Sort(Players, [](const FPlayer& A, const FPlayer& B) {
    return A.Score > B.Score;
});
```

### 2.2 查找（Find / BinarySearch）

```cpp
TArray<int32> Arr = {5, 3, 8, 1};

// 线性查找（找到返回索引，找不到返回 INDEX_NONE）
int32 Idx = Algo::Find(Arr, 8);   // 返回 2

// 二分查找（要求数组已排序，更快）
Algo::Sort(Arr);                   // 先排成 {1,3,5,8}
int32 Bi = Algo::BinarySearch(Arr, 5);   // 返回 2
```

**具体场景：在物品列表里找特定物品**

```cpp
// 找 ID 匹配的武器
int32 Idx = Algo::FindByPredicate(Inventory, [](const FItem& It) {
    return It.Id == TEXT("Sword");
});
if (Idx != INDEX_NONE) { /* 找到了 */ }
```

### 2.3 遍历（ForEach / Transform）

```cpp
// 遍历并做操作
Algo::ForEach(Items, [](FItem& Item) {
    Item.Durability -= 1;
});

// 变换：把 TArray<A> 转成 TArray<B>
TArray<AActor*> Actors;
TArray<FVector> Positions;
Algo::Transform(Actors, Positions, [](AActor* A) {
    return A->GetActorLocation();
});
```

**具体场景：把所有敌人的位置收集起来**

```cpp
TArray<AActor*> Enemies;
TArray<FVector> EnemyPositions;
Algo::Transform(Enemies, EnemyPositions, [](AActor* E) {
    return E->GetActorLocation();   // 得到每个敌人的位置
});
```

### 2.4 其他常用

```cpp
// 判断是否所有元素都满足
bool All = Algo::AllOf(Items, [](const FItem& I) { return I.Count > 0; });

// 判断是否有任意一个满足
bool Any = Algo::AnyOf(Items, [](const FItem& I) { return I.Count == 0; });

// 清空并重新填充（复用）
Algo::Copy(Source, Dest);
```

## 三、Algo/ 完整工具清单（了解）

| 类别 | 函数 |
|------|------|
| **排序** | Sort、IsSorted、SortBy |
| **查找** | Find、FindByPredicate、BinarySearch、IndexOf |
| **遍历** | ForEach、Transform、Count |
| **判断** | AllOf、AnyOf、NoneOf |
| **比较** | Compare、IsSorted |
| **复制/填充** | Copy、CopyIf、RemoveIf |
| **极值** | MinElement、MaxElement |

> 不用全记，日常高频的记住 **Sort（排序）、Find（查找）、ForEach（遍历）、Transform（变换）** 这几个就够。

## 四、Audio/ —— 音频基础类型

`Audio/` 里放的是**音频相关的数据结构**，不是音频引擎（音频引擎在 `Engine` 模块）。主要是这些基础类型：

| 类型 | 作用 |
|------|------|
| `FVolume` | 音量 |
| `FPitch` | 音高 |
| `FDynamicFrequencyRange` | 动态频率范围 |
| 衰减/空间化类型 | 声音随距离变化 |

**具体场景**：如果你做音频相关的游戏逻辑（比如控制某个音效的音量），可能会碰到：

```cpp
// 控制背景音乐音量
MyAudioComponent->SetVolume(0.5f);   // 音量设为 50%
```

**但注意**：日常开发你**基本不会直接碰 Audio/ 这个目录**——真正做音效是拖音频资产到 `UAudioComponent`，或者用音频资产，很少写 Audio/ 底层的 C++ 类型。

## 五、日常开发要学吗？—— 分轻重

| 主题 | 日常用得勤吗 | 建议 |
|------|:---:|------|
| `Algo::Sort`（排序） | **非常常用** | **必学** |
| `Algo::Find`（查找） | 常用 | 学会 |
| `Algo::Transform`（变换） | 偶尔 | 了解 |
| `Algo::ForEach`（遍历） | 常用 | 了解 |
| `Audio/` | 很少 | **不用主动学** |

**结论**：
1. **`Algo/` 值得学**，尤其 `Algo::Sort`（排序）几乎天天用
2. `Algo` 其他（Find/Transform/ForEach）**遇到再用**，记住有这些工具
3. **`Audio/` 不用主动学**，做音频相关时再查

## 六、常见陷阱

**① 二分查找前忘了排序**
```cpp
// ❌ BinarySearch 要求已排序，没排序结果错误
Algo::BinarySearch(Arr, 5);   // Arr 没排过序
// ✅ 先排序
Algo::Sort(Arr);
Algo::BinarySearch(Arr, 5);
```

**② 用 Algo 却忘了 include**
```cpp
// Algo 函数需要包含对应头文件
#include "Algo/Sort.h"   // 或 Algo/Find.h 等
```

**③ 手写循环代替 Algo（不必要）**
```cpp
// ❌ 手写循环找最大值，麻烦
int32 Max = Arr[0];
for (int32 i = 1; i < Arr.Num(); i++) if (Arr[i] > Max) Max = Arr[i];

// ✅ 用 Algo
int32 Max = *Algo::MaxElement(Arr);
```

## 七、总结速查

```
Algo/ = 算法库（操作容器，类似 std::algorithm）
├── Sort：      排序（最常用）
├── Find：      查找 / BinarySearch 二分查找
├── ForEach：   遍历
├── Transform： 变换（A数组 → B数组）
├── AllOf/AnyOf：判断
└── MaxElement/MinElement：极值

Audio/ = 音频基础类型（音量、音高），日常不直接碰

日常重点：Algo::Sort（排序）+ Find（查找）
其余 Algo：遇到再用
Audio/：不用主动学
```

**一句话**：`Algo/` 是操作容器的算法工具，**`Algo::Sort` 排序最常用**；`Audio/` 是音频基础类型，日常不用主动学。用 `Algo` 能少写很多手写循环，代码更简洁。

---

## 八、什么时候深入？

- **现在**：掌握 `Algo::Sort`（排序），了解有 Find/Transform/ForEach 这些工具
- **处理大量容器数据**时：用 Algo 少写循环
- **做音频相关**时：再查 Audio/

> 和其他笔记一样：**先会用高频的（Algo::Sort），冷门的（Audio/）遇到再看**。

# 2026-09-11

## 项目初始化
- 创建 `天下第一武斗会` 游戏设计大纲（README.md）
- 类型：Steam 单机动作战斗，UE5 开发
- 对标：Jump 大乱斗系列
- 核心系统：打击感（卡肉+冲击波+震屏）、技能系统（GAS）、飞行、变身
- 流程：开始动画→主界面→选关卡→选角色→加载→战斗→结算→回主界面
- 主界面布局：左上每日人物+抽卡、左下角色信息、中间3D建模、右上功能按钮、下方开始游戏
- HUD：左下血量/气力/变身槽、右下技能栏、右上小地图
- 敌人AI：行为树驱动，支持杂兵/精英/BOSS分级

## 项目结构设计
- 创建 `设计大纲/项目结构设计.md`
- 引擎：UE 5.6
- 美术风格：**幻兽帕鲁式简约3D**（清晰线条、低毛发复杂度、强轮廓辨识度、战斗可读性优先）
- 建模：推荐 Blender 4.x，角色15k~25k面（简约风格降低面数），场景200k~500k面
- 贴图：Substance Painter，主体2048×2048
- 动画：手工Key帧，单角色50~80个动画片段，30fps制作60fps插值
- 特效：UE5 Niagara（冲击波/技能/变身/飞行尾迹）
- 音频：FMOD Studio
- 版本控制：Git + Git LFS
- 完整目录结构：Characters/Levels/UI/VFX/Audio/Data/Blueprints/Materials/Movies
- 命名规范：CH_/SK_/SM_/A_/ABP_/BP_/GA_/GE_/NS_/M_/T_/WBP_ 等前缀

## 美术设计流程
- 创建 `美术/美术设计步骤/美术设计流程.md`
- 7步角色制作流程：概念设计→建模→贴图→骨骼绑定→动画→特效(Niagara)→引擎整合
- 首个角色预估7周，后续角色4~5周/个
- 场景制作：概念→建模（模块化）→贴图光照
- UI设计：扁平化风格，主界面+战斗HUD+图标+字体+动效

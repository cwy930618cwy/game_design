# 天下第一武斗会

> **类型**：Steam 单机动作战斗  
> **引擎**：Unreal Engine 5.6  
> **对标**：Jump 大乱斗系列（Jump Ultimate Stars / 火影忍者：究极风暴）  
> **美术风格**：幻兽帕鲁式简约3D（清晰线条、低毛发复杂度、强轮廓辨识度）  
> **核心体验**：打击感 · 冲击波 · 技能释放 · 飞行 · 变身

---

## 一、游戏流程总览

```
开始游戏动画 → 主界面 → 选择关卡 → 选择角色 → 加载界面 → 战斗场景 → 结算界面 → 返回主界面
```

## 三、核心战斗系统

### 3.1 基础操作

| 操作 | 按键（参考） | 说明 |
|------|-------------|------|
| 轻攻击 | 鼠标左键 / A | 快速连段，低伤害高频率 |
| 重攻击 | 鼠标右键 / B | 慢速高伤，可击飞敌人 |
| 特殊技 | Q / 手柄LB | 消耗气力释放角色专属技能 |
| 超必杀 | E / 手柄RB | 消耗满气释放终极技能 |
| 闪避/瞬身 | Shift / 手柄B | 短暂无敌位移 |
| 防御 | 长按 S / 手柄LT | 格挡减少伤害 |
| 受身 | 被击飞后按对应键 | 快速恢复站立 |
| 飞行 | 空格 / 手柄LS | 部分角色可空中飞行 |
| 变身 | F / 手柄LS+RS | 消耗特殊资源进入变身状态 |

### 3.2 打击感系统

| 要素 | 实现方式 |
|------|----------|
| **卡肉（Hit Stop）** | 命中瞬间双方动画暂停 0.05~0.15s，根据攻击等级调整 |
| **屏幕震动** | 轻攻击微震、重攻击中震、必杀技强震 |
| **冲击波** | 重击/技能命中产生可视化冲击波扩散（Niagara粒子） |
| **受击反馈** | 敌人受击产生硬直、击退、击飞三种状态 |
| **音效配合** | 命中音效分层：打击音 + 冲击音 + 角色语音 |
| **镜头效果** | 必杀技演出时镜头拉近 + 慢动作 |

### 3.3 技能系统

```
角色技能树
├── 普通技（无需资源）
│   ├── 轻攻击连段（3~5连）
│   ├── 重攻击
│   └── 空中攻击
├── 特殊技（消耗气力条）
│   ├── 技能1：远程冲击波
│   ├── 技能2：突进技
│   └── 技能3：范围AOE
├── 超必杀技（消耗满气力条）
│   └── 角色专属超必杀（带演出）
└── 变身技（消耗变身槽）
    └── 进入变身状态（全属性提升 + 新技能组）
```

### 3.4 飞行系统

- 部分角色拥有飞行能力
- 飞行消耗气力，落地恢复
- 空中可释放空中专属技能
- 飞行高度影响战斗策略（躲避地面AOE）

### 3.5 变身系统

| 阶段 | 说明 |
|------|------|
| 常态 | 角色基础形态 |
| 变身触发 | 满足条件（气力满/血量低/剧情触发） |
| 变身过程 | 短暂无敌 + 特效演出 |
| 变身状态 | 外观变化 + 攻击力↑ + 速度↑ + 解锁专属技能 |
| 持续时间 | 根据角色设定，通常 15~30 秒 |
| 变身结束 | 强制落地 + 短暂虚弱 |

## 四、关卡系统

### 4.1 关卡选择流程

```
开始游戏 → 关卡列表（多个场景可选）→ 选择角色 → 加载 → 进入战斗
```

### 4.2 关卡设计

每个场景 = 一个独立关卡，包含：

| 要素 | 说明 |
|------|------|
| 场景类型 | 小型竞技场景（约 50m × 50m） |
| 场景数量 | 初期 5~8 个主题场景 |
| 场景破坏 | 部分场景支持环境破坏（增加打击感） |
| 场景互动 | 场景内可拾取道具/武器 |

```

│                                          ┌──────────┐   │
│                                          │  小地图   │   │

│                                                          │
│                                                          │
│  ┌──────────┐                            ┌──────────┐   │
```

| HUD 位置 | 内容 |
|-----------|------|

## 五、敌人 AI 系统

### 5.1 AI 行为树

```
敌人AI
├── 巡逻状态（Idle/Patrol）
├── 索敌状态（发现玩家 → 追击）
├── 战斗状态
│   ├── 近距离：普通攻击连段
│   ├── 中距离：突进技/冲击波
│   ├── 远距离：远程技能
│   └── 危险时：闪避/防御/逃跑
├── 强化状态（血量低于阈值 → 狂暴模式）
└── 死亡状态（死亡动画 + 消失）
```

### 5.2 敌人类型

| 类型 | 说明 |
|------|------|
| 普通杂兵 | 低AI，少量攻击模式 |
| 精英怪 | 中等AI，多技能切换 |
| BOSS | 高AI，多阶段 + 特殊机制 |
| 稀有角色 | 高AI，模拟玩家操作风格 |

### 5.3 敌人生成

- 根据关卡难度动态调整敌人数量与强度
- 支持波次生成（Wave System）
- BOSS 关卡单独设计

## 六、角色系统

### 6.1 角色属性

| 属性 | 说明 |
|------|------|
| 生命值（HP） | 归零则败北 |
| 气力值（MP/Gas） | 释放技能消耗 |
| 攻击力 | 影响所有伤害输出 |
| 防御力 | 减少受到的物理伤害 |
| 速度 | 移动速度 + 攻击速度 |
| 变身槽 | 积累满可触发变身 |

### 6.2 角色获取

- **每日人物**：每日免费获得一个临时角色使用权
- **抽卡**：消耗游戏货币/付费货币获取永久角色
- **剧情解锁**：通关特定关卡解锁

### 6.3 角色成长

- 等级提升 → 基础属性提升
- 技能树解锁 → 新技能/强化技能
- 装备系统（可选）→ 额外属性加成

## 八、技术架构（UE5）

### 8.1 模块划分

| 模块 | 职责 |
|------|------|
| 战斗系统 | 攻击判定、伤害计算、打击感反馈 |
| 技能系统 | GAS（Gameplay Ability System）管理技能 |
| AI 系统 | 行为树 + 黑板 + 环境查询系统(EQS) |
| 角色管理 | 角色数据、等级、属性 |
| UI 系统 | UMG 界面管理 |
| 关卡管理 | 关卡加载/卸载、场景切换 |
| 存档系统 | 本地存档 + 云存档 |
| 抽卡系统 | 概率表 + 保底机制 |

### 8.2 关键技术点

- **GAS（Gameplay Ability System）**：技能/Buff/Debuff 统一管理
- **Niagara**：冲击波、技能特效、变身特效
- **Motion Warping**：攻击动作自动对齐目标
- **Combo Graph**：连招系统可视化配置
- **AI Director**：动态调整战斗节奏

## 十、差异化卖点

1. **极致打击感**：卡肉 + 冲击波 + 震屏 + 音效四层反馈
2. **变身系统**：战斗中实时变身，改变战斗风格
3. **飞行空战**：立体空间战斗增加策略深度
4. **华丽技能演出**：必杀技带镜头演出 + 慢动作
5. **场景互动**：可破坏环境 + 场景道具利用

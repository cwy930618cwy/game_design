# 天下第一武斗会 — 项目结构设计

> **引擎**：Unreal Engine 5.6  
> **目标平台**：Steam（PC Windows）  
> **开发模式**：单人/小团队独立开发

---

## 一、美术风格建议

### 1.1 整体风格定位

| 方向 | 说明 |
|------|------|
| **推荐风格** | **幻兽帕鲁式简约3D（Stylized Realism / 简洁卡通3D）** |
| 参考 | 幻兽帕鲁、原神（角色建模部分）、堡垒之夜 |
| 渲染管线 | 前向渲染（Forward Rendering）+ 简化Toon Shader（仅基础明暗二分） |
| 轮廓线 | 轻量描边（可选，仅用于角色与背景分离） |
| 核心原则 | **战斗可读性优先**：造型简洁、轮廓清晰、动作辨识度高 |

### 1.2 风格特征

- **简约线条**：角色造型以清晰几何形体为主，不追求复杂毛发/布料细节
- **低毛发复杂度**：头发/毛发用块面表现（几片几何面+贴图），不做逐根毛发
- **强轮廓辨识**：每个角色通过剪影即可区分（类似幻兽帕鲁的角色设计逻辑）
- **战斗导向**：模型设计服务于战斗可读性——攻击范围、武器朝向、身体动态一目了然
- **适度夸张比例**：头身比 6.5~7.5 头身，手部/脚部略大以强化动作感知
- **贴图风格**：扁平化色彩 + 简单渐变阴影，避免复杂PBR写实质感

### 1.3 美术管线总览

```
概念设计 → 高模雕刻 → 低模拓扑 → UV展开 → 贴图绘制 → 骨骼绑定 → 动画制作 → 引擎导入
   ↓                                                                              ↓
 原画/设定图                                                              Niagara特效 + Toon Shader
```

## 二、建模方案建议

### 2.1 角色建模

| 项目 | 规格 |
|------|------|
| 面数预算 | 主角/可操作角色：15k~25k 三角面（简约风格降低面数） |
| | 精英怪：15k~20k 三角面 |
| | 杂兵：8k~12k 三角面 |
| | BOSS：30k~50k 三角面 |
| 建模软件 | **Blender**（免费，功能全面）或 Maya（行业标准） |
| 雕刻软件 | 不需要高模雕刻，直接中模起步（风格简约无需高模细节） |
| 拓扑方式 | 手工拓扑，保证动画变形质量，关节处布线充足 |
| UV 规范 | 1 套 UV 即可，身体+头部共用一张贴图 |
| 骨骼数量 | 50~65 根骨骼（精简骨骼，满足战斗动画即可） |
| 毛发处理 | **块面建模**：头发/胡须用几片几何面+贴图表现，不做复杂毛发系统 |
| 服装处理 | 简洁几何剪裁，避免复杂布料层次；装饰物用贴图绘制而非建模 |
| 设计原则 | 每个角色先出剪影测试（Silhouette Check），确保远距离可辨识 |

### 2.2 贴图规范

| 贴图类型 | 分辨率 | 说明 |
|----------|--------|------|
| 主体贴图（BaseColor） | 1024×1024 | 角色主体颜色（扁平化色彩，简单阴影渐变） |
| 法线贴图（Normal） | 1024×1024 | 轻量法线，仅大结构凹凸 |
| 自发光（Emissive） | 1024×1024 | 技能纹路/变身发光/眼睛发光 |
| 描边贴图（Outline） | 512×512 | 控制描边粗细变化（可选） |

> **注**：不需要 PBR 全套贴图（Roughness/Metallic/AO），简约风格只需 BaseColor + 少量法线 + Emissive 即可。

### 2.3 场景建模

| 项目 | 规格 |
|------|------|
| 场景尺寸 | 50m × 50m 竞技区域 |
| 面数预算 | 单个场景 200k~500k 三角面（含环境物件） |
| 建模策略 | 模块化拼接（Modular Kit），复用组件 |
| 碰撞体 | 简化碰撞（Simple Collision），避免使用复杂网格碰撞 |
| 可破坏物 | 单独建模，使用 Chaos Destruction 系统 |

### 2.4 特效建模

| 项目 | 规格 |
|------|------|
| 冲击波 | Niagara 粒子系统 + 冲击波网格（平面 + 扭曲材质） |
| 技能特效 | Niagara 粒子 + Flipbook 序列帧贴图 |
| 变身特效 | 全屏后处理 + 角色材质切换 + Niagara 包裹效果 |
| 飞行尾迹 | Niagara Ribbon（飘带粒子） |
| 受击特效 | 命中点火花/冲击粒子（小尺寸高频） |

## 三、动画方案

### 3.1 动画制作

| 项目 | 说明 |
|------|------|
| 制作方式 | 手工 Key 帧动画（Blender/Maya） |
| 动画风格 | 幻兽帕鲁式流畅动作（自然夸张，不过度日式变形） |
| 帧率 | 30fps 制作，引擎内 60fps 插值 |
| 关键动画 | 每个角色约 40~60 个动画片段（简约模型减少动画数量） |
| 核心要求 | 动作清晰、力量感强、攻击前摇/后摇可读性高 |

### 3.2 动画列表（单角色）

| 类别 | 数量 | 说明 |
|------|------|------|
| 待机/移动 | 4~6 | 待机、行走、奔跑、跳跃 |
| 轻攻击 | 3~5 连段 | 每段独立动画 |
| 重攻击 | 2~3 | 上/下/横向 |
| 特殊技 | 3~4 | 冲击波/突进/AOE |
| 超必杀 | 1~2 | 带演出镜头 |
| 受击/击飞 | 4~5 | 轻受击、重受击、击飞、落地 |
| 防御/闪避 | 2~3 | 防御姿态、闪避翻滚 |
| 变身 | 2~3 | 变身进入/退出动画 |
| 飞行 | 3~4 | 起飞、悬停、空中攻击、落地 |
| 死亡 | 1~2 | 死亡倒地 |

### 3.3 动画蓝图（Animation Blueprint）

```
角色动画蓝图
├── 状态机（Locomotion）
│   ├── Idle → Walk → Run → Jump → Fall → Land
│   └── 空中状态（飞行角色额外分支）
├── 攻击层（Attack Layer）
│   ├── 上半身覆盖（Upper Body Override）
│   └── 全身覆盖（Full Body）
├ 混合空间（Blend Space）
│   ├── 8方向移动混合
│   └── 瞄准偏移（Aim Offset）
└── 特殊状态
    ├── 变身状态切换
    └── 受击/硬直覆盖
```

## 七、渲染方案

### 7.1 简约卡通渲染管线

```
角色渲染流程：
1. BasePass：简化Toon Shader（二分光照：亮面/暗面，无中间过渡）
2. 描边：Back-face Outline（轻量描边，仅角色边缘）
3. 后处理：Bloom（技能发光）+ Color Grading（鲜艳色调）+ Vignette
4. 特效叠加：Niagara 粒子半透明渲染
```

> **风格要点**：渲染追求"干净利落"，不要复杂的光影层次。明暗分界清晰（类似幻兽帕鲁/原神的二分光影），让角色在战斗混乱场景中依然醒目。

### 7.2 光照方案

| 场景 | 方案 |
|------|------|
| 主界面 | Lumen + 动态点光源（角色展示打光） |
| 战斗场景 | 烘焙 Lightmap + 动态补光（性能优先） |
| 必杀技演出 | 临时切换为全动态光照 + 后处理 |

### 7.3 性能目标

| 指标 | 目标 |
|------|------|
| 分辨率 | 1080p |
| 帧率 | 稳定 60fps |
| 同屏敌人 | 最多 4~6 个 |
| 粒子数量 | 单帧峰值 < 500 粒子 |
| Draw Call | < 2000 / 帧 |

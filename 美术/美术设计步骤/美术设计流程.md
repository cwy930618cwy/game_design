# 天下第一武斗会 — 美术设计流程

> **风格基准**：幻兽帕鲁式简约3D  
> **核心原则**：战斗可读性优先、线条简洁、低毛发复杂度、强轮廓辨识

---

## 一、整体流程总览

```
角色概念设计 → 角色建模 → 贴图绘制 → 骨骼绑定 → 动画制作 → 特效制作 → 引擎整合
     ↓              ↓           ↓           ↓           ↓           ↓           ↓
  原画设定图     中模+低模    BaseColor    Rig骨架    Key帧动画   Niagara    材质/蓝图
```

---

## 二、角色设计流程

### Step 1：概念设计（原画）

| 步骤 | 内容 | 产出 |
|------|------|------|
| 1.1 | 确定角色主题/元素（火/水/雷/风等） | 主题关键词 |
| 1.2 | 绘制角色正面/侧面/背面三视图 | 三视图设定稿 |
| 1.3 | 绘制角色表情/配色方案 | 表情+配色稿 |
| 1.4 | 武器/装备单独设计 | 武器设定稿 |
| 1.5 | **剪影测试**（纯黑色块检查辨识度） | 剪影通过确认 |

> **要点**：每个角色必须在 3 米外只看剪影就能区分，这是幻兽帕鲁风格的核心。

---

### Step 2：建模（Blender）

| 步骤 | 内容 | 说明 |
|------|------|------|
| 2.1 | 搭建基础人体骨架（比例参考） | 6.5~7.5 头身 |
| 2.2 | 大形块搭建（Body Blockout） | 用简单几何体拼出身体大形 |
| 2.3 | 中模雕刻（头部/躯干/四肢） | 不用ZBrush高模，直接在Blender中模起步 |
| 2.4 | 低模拓扑（Retopology） | 关节处充足布线，面数控制在 15k~25k |
| 2.5 | 头发/毛发块面制作 | 几片几何面表现，不做逐根毛发 |
| 2.6 | 服装/配饰建模 | 简洁几何剪裁，装饰用贴图表现 |
| 2.7 | 武器建模 | 独立模型，面数 3k~5k |
| 2.8 | UV 展开 | 1套UV，身体+头部共用 1024×1024 |
| 2.9 | 导出 FBX | 检查法线方向、坐标轴 |

> **时间预估**：单个主角角色建模约 3~5 天

---

### Step 3：贴图绘制（Substance Painter / Photoshop）

| 步骤 | 内容 | 说明 |
|------|------|------|
| 3.1 | 导入低模+UV | Substance Painter 项目设置 |
| 3.2 | BaseColor 绘制 | 扁平化色彩，大面积色块为主 |
| 3.3 | 阴影渐变绘制 | 简单二分阴影（亮面/暗面） |
| 3.4 | 自发光区域绘制（Emissive） | 技能纹路、眼睛、变身发光区域 |
| 3.5 | 轻量法线烘焙 | 仅大结构凹凸（肌肉走向、铠甲边缘） |
| 3.6 | 描边贴图（可选） | 控制描边粗细变化的遮罩 |
| 3.7 | 导出贴图 | BaseColor + Normal + Emissive（PNG/TGA） |

> **时间预估**：单角色贴图约 1~2 天

---

### Step 4：骨骼绑定（Rigging）

| 步骤 | 内容 | 说明 |
|------|------|------|
| 4.1 | 导入引擎验证骨骼 | 50~65 根骨骼 |
| 4.2 | 全身骨骼架设 | 包含：脊柱(5)、四肢(各4)、手指(各3~5)、头部(3~5) |
| 4.3 | 权重绘制（Skin Weights） | 关节处平滑过渡，避免穿插 |
| 4.4 | 面部绑定（简化） | 口型张合 + 眨眼 + 眉毛（5~8根面部骨骼） |
| 4.5 | IK 骨骼设置 | 脚部IK + 手部IK（战斗动作需要） |
| 4.6 | 物理骨骼（可选） | 头发/尾巴/披风简单物理（2~3根骨骼控制） |
| 4.7 | 导出最终骨骼网格体 | 导入 UE5 验证 |

> **时间预估**：单角色绑定约 2~3 天

---

### Step 5：动画制作

| 步骤 | 内容 | 说明 |
|------|------|------|
| 5.1 | 基础移动动画 | 待机、行走、奔跑、跳跃、落地 |
| 5.2 | 轻攻击连段 | 3~5 连段动画（每段独立） |
| 5.3 | 重攻击 | 2~3 种方向（上劈/横扫/下砸） |
| 5.4 | 特殊技动画 | 冲击波/突进/AOE 各 1 个 |
| 5.5 | 超必杀动画 | 带演出镜头的终极技 |
| 5.6 | 受击/击飞/死亡 | 轻受击、重受击、击飞、落地、死亡 |
| 5.7 | 防御/闪避 | 防御姿态、闪避翻滚 |
| 5.8 | 变身动画 | 变身进入/退出 |
| 5.9 | 飞行相关 | 起飞、悬停、空中攻击、俯冲 |
| 5.10 | 导入引擎调试 | Animation Blueprint 状态机连接 |

> **时间预估**：单角色全套动画约 5~7 天

---

### Step 6：特效制作（Niagara）

| 步骤 | 内容 | 说明 |
|------|------|------|
| 6.1 | 通用命中特效 | 拳脚命中火花、冲击波环 |
| 6.2 | 角色专属技能特效 | 根据角色元素主题设计 |
| 6.3 | 冲击波特效 | 地面冲击波扩散（平面+扭曲材质） |
| 6.4 | 变身特效 | 全身光柱/能量爆发 |
| 6.5 | 飞行尾迹 | Ribbon 飘带粒子 |
| 6.6 | 受击/死亡特效 | 受击点火花、死亡消散 |
| 6.7 | 超必杀演出特效 | 全屏特效 + 后处理配合 |

> **时间预估**：单角色特效约 2~3 天

---

### Step 7：引擎整合

| 步骤 | 内容 | 说明 |
|------|------|------|
| 7.1 | 导入骨骼网格体 | 检查材质槽、LOD |
| 7.2 | 导入动画序列 | 批量导入+重定向验证 |
| 7.3 | 设置材质 | Toon Shader 材质实例配置 |
| 7.4 | 配置 Animation Blueprint | 状态机 + 混合空间 |
| 7.5 | 挂载特效到骨骼插槽 | Socket 位置确认 |
| 7.6 | 碰撞体设置 | 简化碰撞胶囊体 |
| 7.7 | 性能测试 | 帧率、Draw Call、粒子数 |

## 三、场景设计流程

### Step 1：场景概念

| 步骤 | 内容 |
|------|------|
| 1.1 | 确定场景主题（火山/冰原/城市/森林等） |
| 1.2 | 绘制场景氛围图（全景+战斗区域标注） |
| 1.3 | 确定场景边界与战斗区域（50m×50m） |

### Step 2：场景建模

| 步骤 | 内容 | 说明 |
|------|------|------|
| 2.1 | 地形搭建 | 地面+高差+边界 |
| 2.2 | 模块化建筑/物件 | 复用组件拼接 |
| 2.3 | 远景简模 | 低面数背景山体/建筑轮廓 |
| 2.4 | 可破坏物建模 | 独立模型+简化碰撞 |
| 2.5 | 道具建模 | 可拾取武器/回复道具 |

### Step 3：场景贴图与光照

| 步骤 | 内容 | 说明 |
|------|------|------|
| 3.1 | 场景贴图 | 1024×1024 为主，大场景可用 2048 |
| 3.2 | 光照烘焙 | Lightmap 烘焙（性能优先） |
| 3.3 | 动态补光 | 角色展示灯、技能闪光 |

| 步骤 | 内容 | 说明 |

## 五、首个角色制作排期（参考）

| 周 | 任务 | 产出 |
|----|------|------|
| 第1周 | 概念设计 + 三视图 + 剪影确认 | 设定稿 |
| 第2周 | 建模（大形+中模+低模+UV） | FBX |
| 第3周 | 贴图 + 骨骼绑定 | 贴图+Rig |
| 第4周 | 基础动画（移动+轻攻击+重攻击） | 动画序列 |
| 第5周 | 技能动画 + 受击 + 变身 | 动画序列 |
| 第6周 | 特效制作 | Niagara资产 |
| 第7周 | 引擎整合 + 调试 + 性能优化 | 可玩角色 |

> **总计**：首个角色约 7 周（含调试），后续角色可缩短至 4~5 周/个（流程成熟后）

## 六、质量检查清单

### 角色检查

- [ ] 剪影辨识度测试通过（3米外可区分）
- [ ] 面数在预算范围内
- [ ] 贴图无接缝、无溢出
- [ ] 骨骼无穿插、权重无塌陷
- [ ] 所有动画帧率一致、无跳帧
- [ ] 特效不遮挡角色本体
- [ ] 引擎内 60fps 稳定运行
- [ ] 攻击判定与视觉表现一致

### 场景检查

- [ ] 战斗区域边界明确
- [ ] 无穿模死角
- [ ] 光照不刺眼/不过暗
- [ ] 可破坏物碰撞正确
- [ ] 小地图渲染正确
